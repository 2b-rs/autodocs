Yn = Yn-1 + (((Xn - Yn-1) * fac) >> n) Where 'n' is a shift that depends on the types used by the functions for the factor

SWS_Efx_00007 requirement

In order to converge all the time, the result is corrected for value saturation using the following logic: If (Yn == Yn-1) If (((Xn - Yn-1) * fac) > 0) Yn ++ Else If (((Xn - Yn-1) * fac) < 0) Yn – End If Endif
