Limite do namespace

ara::idsm contém as APIs de evento, provedor e receptor junto com seus dados comuns e tipos de erro. SWS IdsM §8.2 «common.h» define os tipos comuns; Eles atribuem os outros cabeçalhos às respectivas interfaces de porta.

Interpretação: O namespace agrupa os objetos de acesso ao evento, ao provedor e ao destinatário, incluindo tipos de dados e representação de erros; Seu acoplamento específico aos protótipos de porta é determinado através do modelo e do ara::core::InstanceSpecifier.

Classes e estruturas

  • ContextDataProvider Disponibiliza dados de contexto modificáveis para o IdsM.
  • EventReporter Meldet Security Events an IdsM.
  • IdsmErrorDomain Domínio de erro para ara::idsm.
  • IdsmException Tipo de exceção para ara::idsm.
  • QualifiedEventsReceiver Recebe eventos qualificados.
  • ReportingModeProvider Lê e define os reporting modes.
  • TimestampProvider Stellt optionale Zeitstempel bereit.
