Namespace e escopos de função

A API Safe Hardware Acceleration está localizada em ara::shwa [AP_SWS_SHWA_00013]. As classes são divididas em acesso a dados (Buffer, Accessor, Range, Id), execução de tarefas (Queue, Event, TaskHandler) e gerenciamento/monitorização de dispositivos (Device, Selector, Platform, DeviceMonitor).

Fontes de conceito

SWS SHWA §7.1 — Architecture e EXP Safe Hardware Acceleration API §4.3 explicam esta classificação. Interpretação: o agrupamento serve para a navegação e não altera os contratos da API.

Classes

  • Accessor Accessor manages read and write access to allocated memory by Buffer. Designed as not copyable, since it’s owning resources. Intended to be managed exclusively by std::unique_ptr, which may be moved.
  • Buffer Buffer manages memory allocation for operations on the host or/and HWA. Designed as not copyable, since it’s owning resources. Intended to be managed exclusively by std::unique_ptr, which may be moved.
  • Device Device class represents HWA device. Provides access to the device but not controlling it. Designed as copyable since not owning resources.
  • DeviceMonitor DeviceMonitor API class. Designed as copyable since not owning resources.
  • AcceleratorSelector AcceleratorSelector manages accelerator selection for operations on HWA if available.
  • CpuSelector CpuSelector manages CPU selection for operations on HWA if available Allows to get a device from any supported backends for which the device type is CPU.
  • DeviceSelector Class allowing to choose the most appropriate device of the available ones. This is a callable object taking a device reference and returning an integer rank. One of the device with the highest non-negative value is selected.
  • GpuSelector GpuSelector manages GPU selection for operations on HWA if available Select a device from any supported backends for which the device type is GPU.
  • ErrorHandler ErrorHandler manages asynchronous error handling for operations on HWA.
  • Event Event class helps to manage task execution synchronization between HWA and Host application. Can be created only inside of the Queue otherwise it’s meaningless.
  • Id Id API class. Designed as copyable since not owning resources.
  • Platform Platform class is responsible for extracting different HWA platforms available for current application and listing Devices bind to each platform. Designed as copyable since not owning resources.
  • PropertyList Property List class is designed to enable vendor specific SHWA functionality extension and adjustment. Properties are not standardized and can be defined by Vendor. Class using Property list is obliged to have HasProperty() and GetProperty() methods defined.
  • Queue Queue API provides the functionality for parallel processing on selected Device. Designed as not copyable, since it’s owning resources. Intended to be managed exclusively by std::unique_ ptr, which may be moved.
  • Range Defines size of Buffer for one, two or three dimensions. Designed as copyable since not owning resources.
  • ShwaErrorDomain Defines the error domain for Safe Hardware Acceleration.
  • ShwaException Exception type could be thrown by application or other FC using Safe Hardware Acceleration. Safe Hardware Acceleration API is exception free and can only return an ErrorCode, but user code can transform this error to exception and throw if it’s alligned with system error handling architecture.
  • TaskHandler Handles tasks execution on the selected Device Can be created only inside of the Queue otherwise it’s meaningless.
