Ponto de extensão para rastreamento modelado

apext::log::TraceArti é o ponto de extensão para mensagens Trace modeladas. A decisão de routing pode ocorrer já em tempo de compilação para mensagem, namespace e Executable, evitando assim sobrecarga em tempo de execução. SWS Log and Trace §7.6 «Tracing» [SWS_LOG_20001] [SWS_LOG_20004]

Desacoplar rastreamento e log

Dependendo da configuração, a especialização gerada leva apenas ao logger, apenas ao ARTI, a ambos, ou descarta a mensagem. (Interpretação: O namespace é, portanto, a ponte deliberadamente estreita entre o código da ferramenta de rastreamento gerado e a API de log padrão.)

função TraceArti [SWS_LOG_20000] Upstream: RS_LT_00003

template <typename MsgId, typename... Params> void TraceArti (const MsgId &msg_id, const Params &...                       params) noexcept;

Handles a modeled message, specific to the used trace tool. This function is only called internally by the Logger framework when switching between Log and TraceArti. It represents the interface to trace tools. The runtime overhead of this function shall be kept as minimal as possible, e.g. by using specializations based on the MsgId.
