Fornece interfaces para o controle de Firewall dependente de estado, bem como códigos de erro padronizados.

O namespace ara::fw disponibiliza tipos e interfaces para o controle de Firewall, bem como seu tratamento padronizado de erros na AUTOSAR Adaptive Platform. O módulo define com FirewallStateSwitchInterface uma interface para estados de Firewall e gera, por meio da função segura para threads MakeErrorCode, objetos de erro tipados com base no domínio de erro FwErrorDomain [AP_SWS_Fw_83003]. Problemas ocorridos são mapeados pela enumeração FwErrc, que indica, entre outros, serviços indisponíveis ou configurações inválidas dependentes de estado [AP_SWS_Fw_83001]. Todas as funções centrais para geração de erros são seguras para threads e declaradas como noexcept.

Contexto

O namespace ara::fw reúne as interfaces de programação e os tipos para a funcionalidade de Firewall da AUTOSAR Adaptive Platform no Release R25-11. A função primária do módulo consiste na disponibilização de mecanismos para filtragem e proteção da comunicação de rede interna do veículo. Entre os componentes centrais do namespace estão a interface FirewallStateSwitchInterface e os componentes para o tratamento de erros padronizado, constituídos por FwErrorDomain, FwException e pelos respectivos códigos de erro. A arquitetura integra-se perfeitamente ao conceito de erros da plataforma de ara::core. Parceiros de interação externos, como serviços de plataforma gerenciadores de estado ou aplicações, utilizam o namespace para controlar estados de Firewall relevantes para a segurança ou para resolver erros de execução ocorridos. Interpretação: a classe FirewallStateSwitchInterface serve presumivelmente como interface primária para a ativação e comutação de conjuntos de regras em função do estado do sistema de nível superior.

Diagrama de contexto: interação entre a aplicação, FirewallStateSwitchInterface e FwErrorDomain na resolução de erros. Fontes: [AP_SWS_Fw_83001], [AP_SWS_Fw_83002], [AP_SWS_Fw_83003].

Caminho de utilização

O caminho de uso típico no namespace ara::fw compreende o início de alterações de estado, bem como a geração, o repasse e a avaliação de estados de erro durante a execução de funções de Firewall. Se uma operação no contexto de FirewallStateSwitchInterface falhar ou se uma solicitação de estado não puder ser atendida, o módulo recorre ao domínio de erro específico para fornecer ao chamador um resultado de diagnóstico preciso. Para instanciar tal erro, chama-se a função MakeErrorCode [AP_SWS_Fw_83003]. Essa função gera um ara::core::ErrorCode ao receber um valor de erro de FwErrc [AP_SWS_Fw_83001] e dados adicionais opcionais específicos do fabricante do tipo ara::core::ErrorDomain::SupportDataType [AP_SWS_Fw_83003]. Como MakeErrorCode é declarada como constexpr e noexcept, a criação do código de erro pode ocorrer de maneira econômica em termos de recursos e determinística.

No lado do chamador, o erro retornado geralmente é recebido em um objeto de resultado (como ara::core::Result). Para a verificação programática da origem do erro, utiliza-se a função livre GetFwErrorDomain [AP_SWS_Fw_83002], que retorna uma referência constante ao singleton do domínio de erro FwErrorDomain. Com isso, os chamadores podem conferir se um erro ocorrido provém de fato do módulo de Firewall e determinar sua descrição textual. Interpretação: em arquiteturas de sistema que empregam exceções C++, a classe FwException serve presumivelmente ao propósito de encapsular o ara::core::ErrorCode de forma capturável e encaminhá-lo sincronamente para rotinas de tratamento de erros de nível superior.

Cenários de erro

Para situações de erro, a enumeração FwErrc no namespace ara::fw define causas de erro específicas para o domínio de erro FwErrorDomain [AP_SWS_Fw_83001]. O arquivo de cabeçalho ara/fw/fw_error_domain.h declara os seguintes estados de erro padronizados:

  • kServiceNotAvailable (valor 1): indica que o serviço de Firewall endereçado não está acessível em tempo de execução ou não está operacional no momento [AP_SWS_Fw_83001]. Possíveis causas residem em componentes de segundo plano ainda não inicializados ou em quedas temporárias de conexão. As pré-condições para chamadas subsequentes não são atendidas, de modo que os chamadores devem consultar o status do serviço ou repetir a solicitação em um momento posterior.
  • kInvalidStateDependentFirewall (valor 2): ocorre quando uma configuração de Firewall solicitada dependente de estado é inválida ou quando foi solicitada uma transição de estado inválida [AP_SWS_Fw_83001]. A pré-condição para operações de comutação bem-sucedidas é que o Firewall de destino suporte os estados desejados e que o sistema se encontre em um estado básico permissível. Após a ocorrência desse erro, o Firewall permanece inalterado no modo de proteção anterior.

Ambos os valores de erro baseiam-se no tipo básico ara::core::ErrorDomain::CodeType [AP_SWS_Fw_83001]. As funções GetFwErrorDomain [AP_SWS_Fw_83002] e MakeErrorCode [AP_SWS_Fw_83003] são expressamente declaradas como seguras para threads (thread-safe) e noexcept, garantindo um tratamento de erro seguro mesmo em contextos altamente concorrentes ou de tempo crítico.
