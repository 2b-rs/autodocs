Configuração por ID de dados

Esta interface de serviço fornece configuração de status de verificação para o contexto de proteção determinado por um ID de dados. Faz parte da integração da plataforma em torno de E2E-/Freshness-Value-Management, e não de um serviço modelado por um aplicação especializado.

Incorporação

A especificação de gestão de comunicação especifica as interfaces de status de verificação relacionadas ao processamento SecOC/Freshness. Um chamador deve usar o ID de dados e a configuração associada de forma consistente no mesmo contexto de implantação. (Interpretação: O requisito de consistência segue a atribuição baseada na configuração das funções de segurança.) SWS CM §7.3.2 «Secure Communication» fornece o contexto.

Colaboração: A extensão da plataforma FVM fornece ou verifica valores de atualização para SecOC; o status de verificação é fornecido à interface de status configurada. Fontes: SWS CM §7.3.2 «Secure Communication», EXP SW Architecture §9.3.1.1.3 «Interfaces for freshness value management».
