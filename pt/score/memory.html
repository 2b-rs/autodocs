Memory & Persistence

component Persistence & Memory

O componente S-Core Persistence & Memory fornece armazenamento não volátil de dados resiliente, bancos de dados de armazenamento chave-valor POSIX, interfaces de armazenamento em bloco, mecanismos atômicos de atualização de arquivos e gerenciamento de nivelamento de desgaste de flash.
