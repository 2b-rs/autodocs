classe ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

Interface de cursor comum

FileAccessor agrupa operações de posição e tamanho para ficheiros abertos. É a base comum de acessadores de leitura, gravação e leitura/gravação; Isso significa que a posição do cursor descreve o acesso exatamente a este ficheiro aberto.

Disciplina posicional

GetPosition, SetPosition e MovePosition são para navegação, enquanto GetSize fornece ou tamanho atual do ficheiro. As operações do acessador não são thread-safe: um identificador não deve, portanto, ser usado por vários threads ao mesmo tempo sem sincronização externa. SWS Persistency §7.4 «File Storage specific Features»

Nota de utilização

Abra o ficheiro através de FileStorage, execute as operações do cursor sob a posse do mesmo UniqueHandle e liberte-o em seguida. Uma alteração de posição não é uma operação de persistência; os dados a escrever requerem a operação de escrita adequada e, se necessário, sincronização.

Um armazenamento de ficheiros gerencia um conjunto de ficheiros nomeados; o acessador tem propriedade exclusiva do acesso aberto específico. Fontes: SWS Persistency §7.4 «File Storage specific Features» [SWS_PER_00113].
