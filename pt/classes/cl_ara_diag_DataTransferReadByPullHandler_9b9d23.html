Finalidade de uso

DataTransferReadByPullHandler implementa transferências de dados de leitura para RequestReadFile ou RequestReadDirectory, onde AraDiag recupera os dados do aplicativo aos poucos. Para isso, Read() recebe um intervalo de bytes graváveis ​​pré-alocado pelo sistema e entrega de forma assíncrona os bytes efetivamente inseridos. [SWS_DM_01506] [SWS_DM_01513]

Ciclo de vida & Propriedade

O manipulador não pode ser copiado para uso único por sessão individual de transferência de ficheiros, mas é móvel e pode ser movido. Ele só pode ser destruído após ExitRead() ter sido chamado. Este método encerra a sessão de transferência atual e retorna de forma assíncrona o registo do parâmetro de resposta de transferência ou um erro UDS.
