Finalidade de uso

ara::core::Promise<void, E> é a especialização para operações assíncronas sem valor. O tipo de erro deve ser ara::core::ErrorCode; junto com Future, a classe permite a entrega subsequente de sucesso ou falha, sem threads e sem exceções. [SWS_CORE_06340] [SWS_CORE_10800]

Ciclo de vida & Propriedade

A cópia é proibida (=delete), a movimentação é possível. A atribuição de movimentação e o destruidor abandonam qualquer estado compartilhado anterior. [SWS_CORE_06350] [SWS_CORE_06351] [SWS_CORE_06342] [SWS_CORE_06343] [SWS_CORE_06349]

Interação com outras aulas

get_future() devolve uma única vez a Future<void,E> com Shared State idêntico. set_value() disponibiliza o sucesso void; SetError() e SetResult() definem o erro ou Result<void,E>. [SWS_CORE_06344] [SWS_CORE_06345] [SWS_CORE_06353] [SWS_CORE_06354] [SWS_CORE_06355] [SWS_CORE_06356]

Restrições & tratamento de erros

Várias chamadas de configuração e setter sem estado partilhado são especificadas como violações. [SWS_CORE_13015] [SWS_CORE_13016]

Return an associated Future with the same shared state as *this The returned Future is set as soon as this Promise receives the result, value, or an error. This fuction must only be called once as it is not allowed to have multiple Futures per Promise.

get_future (ara::core::Promise<void, E>) retorna um objeto ara::core::Future pertencente a ara::core::Promise<void, E> com o mesmo estado compartilhado. O Future retornado é definido assim que esta Promise recebe um resultado, um valor ou um erro. A função só pode ser chamada uma vez por promessa, pois não são permitidos vários futuros por promessa.
