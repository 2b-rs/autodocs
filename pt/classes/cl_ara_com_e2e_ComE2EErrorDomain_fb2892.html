Domínio de erros para proteção E2E

ComE2EErrorDomain isola erros de verificação ponta a ponta do espaço geral de erros de comunicação. Faz parte dos caminhos de dados para eventos, métodos e campos para os quais o respectivo perfil E2E está configurado. SWS CM §7.4 «Safety» descreve a função de proteção.

Avaliação

Name(), Message() e ThrowAsException() formam o mesmo mecanismo de domínio de erros que a área geral de comunicação. Para Samples recebidos, ProfileCheckStatus fornece a informação mais detalhada visível por Sample; por isso, um ErrorCode não tem de ser equiparado a cada estado. EXP ARAComAPI §4.7 «Error Handling» fornece o modelo geral.

Diagrama de Atividades: A verificação E2E é mapeada para o status da amostra; Os aplicações avaliam o ProfileCheckStatus individual. Fonte: SWS CM §7.4.1 «End-to-end communication protection for SOMEIP».
