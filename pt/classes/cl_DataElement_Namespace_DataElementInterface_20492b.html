Finalidade de uso

A classe <DataElementInterface> é a interface de um elemento de dados de diagnóstico. Uma aplicação implementa o método puramente virtual Read(); o Diagnostic Manager encaminha solicitações para este manipulador após Offer(). O resultado é retornado de forma assíncrona como ara::core::Future com uma saída de leitura. [SWS_DM_00603] [SWS_DM_00596] [SWS_DM_00597]

Criação e Destruição

A instância é criada com ara::core::InstanceSpecifier e ConcurrencyType. Offer() ativa o encaminhamento pelo DM, StopOffer() desativa novamente; uma nova oferta é rejeitada com DiagOfferErrc::kAlreadyOffered. [SWS_DM_00587] [SWS_DM_00597] [SWS_DM_00617]

Ciclo de vida & Propriedade

A cópia, bem como a construção e a atribuição por movimento, estão desativadas (=delete). A classe possui um destrutor virtual noexcept. [SWS_DM_01659] [SWS_DM_01660] [SWS_DM_01661] [SWS_DM_01662] [SWS_DM_00588]

Restrições & tratamento de erros

Read() obtém MetaInfo e um CancellationHandler. A implementação pode usar isso para verificar ou status de aborto ou registar um notificador; Em caso de falha técnica, deverá ser utilizado um DiagUdsNrcErrc adequado. Read(), Offer e StopOffer não são thread-safe. [SWS_DM_00596] [SWS_DM_00597] [SWS_DM_00617]
