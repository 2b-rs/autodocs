Finalidade de uso

SovdConfiguration implementa uma interface genérica de configuração SOVD. RequestGetConfiguration() devolve uma sessão de leitura com SovdConfigurationMetaInfo para uma ID de configuração; RequestPutConfiguration() devolve a sessão de escrita correspondente. [SWS_DM_01860] [SWS_DM_01870] [SWS_DM_01871] Para um pedido de escrita de uma configuração SOVD explicitamente modelada, o Diagnostic Server chama RequestPutConfiguration(). [SWS_DM_01788]
