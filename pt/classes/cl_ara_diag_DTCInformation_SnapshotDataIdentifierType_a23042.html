SnapshotDataIdentifierType descreve um identificador de dados em um conjunto de dados de captura instantânea. O campo dataIdentifier identifica o DiagnosticDataIdentifier, enquanto data contém os dados do registro de snapshot específico. O tipo é usado como elemento do vetor SnapshotDataRecordType::snapshotDataIdentifiers. Portanto, inclui exclusivamente a atribuição de um identificador aos dados instantâneos associados.
