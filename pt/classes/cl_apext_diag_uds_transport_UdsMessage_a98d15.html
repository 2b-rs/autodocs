classe apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

Finalidade de uso

UdsMessage representa uma mensagem UDS entre o núcleo DM genérico ou UdsTransportProtocolMgr e uma implementação concreta de UdsTransportProtocolHandler. O objeto fornece armazenamento para solicitações e respostas UDS. [SWS_DM_00291]

Geração e Propriedade

Instâncias com alocação de recursos otimizada são criadas exclusivamente pelo núcleo DM; um Protocol Handler pode lê-las e escrevê-las, mas não deve criá-las ele próprio. Por isso, o construtor Default é protected. Para uma indicação aceite, um UdsMessagePtr possui um objeto válido com pelo menos um byte de capacidade; inicialmente, o buffer devolvido por GetPayload() está vazio. [SWS_DM_09012] [SWS_DM_00385] [SWS_DM_00392]

Interação com outras aulas

O acesso à carga útil não constante retorna um ByteSpan gravável; O acesso constante entrega os dados UDS do SID sem acesso de gravação. Após a indicação bem-sucedida, um manipulador de transporte preenche a carga do SID até a capacidade ou até o final da mensagem recebida. O tipo de endereço de origem, destino e destino físico ou funcional estão disponíveis por meio de getters; AddMetaInfo() adiciona metainformações.
