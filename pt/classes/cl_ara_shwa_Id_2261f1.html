Contexto

A classe ara::shwa::Id representa, dentro do módulo shwa da AUTOSAR Adaptive Platform, um identificador tipificado projetado para indexação multidimensional. A definição da classe é implementada como template de classe template <int Dimensions = 1> class Id final. Interpretação: O módulo shwa endereça estruturas de shared hardware ou workloads, no qual ara::shwa::Id serve presumivelmente como chave estruturada de coordenadas ou de índices para o endereçamento inequívoco de pacotes de trabalho, buffers ou pontos de dados ao longo de até três dimensões.

Os parceiros de interação de ara::shwa::Id são sobretudo aplicações adaptativas que a utilizam, bem como componentes funcionais do subsistema shwa. A classe encapsula dimensões e índices, de modo que funções de processamento de nível superior possam receber parâmetros posicionais com segurança de tipos. Como a classe é especificada como final, uma derivação está excluída; ela atua como um tipo de valor autocontido.

Ciclo de vida

O ciclo de vida de uma instância de ara::shwa::Id começa obrigatoriamente através de métodos factory estáticos. O construtor padrão está explicitamente excluído ([AP_SWS_SHWA_00702]), impedindo instâncias incompletamente inicializadas em tempo de compilação. Em vez disso, a criação de objetos ocorre por meio de métodos Create sobrecarregados, que retornam, cada um, uma instância encapsulada em um ara::core::Result:

  • Inicialização unidimensional por meio de Create(const std::size_t dim0) ([AP_SWS_SHWA_00707]). Esta variante é indicada como thread-safe.
  • Inicialização bidimensional por meio de Create(std::size_t dim0, std::size_t dim1) ([AP_SWS_SHWA_00708]). Esta variante é declarada como não thread-safe.
  • Inicialização tridimensional por meio de Create(std::size_t dim0, std::size_t dim1, std::size_t dim2) ([AP_SWS_SHWA_00709]). Esta variante também é declarada como não thread-safe.

Em relação à posse e ao modelo de cópia, ara::shwa::Id comporta-se como um tipo por valor regular. O construtor de cópia ([AP_SWS_SHWA_00703]) e o operador de atribuição por cópia ([AP_SWS_SHWA_00704]) estão definidos como noexcept=default e garantem total segurança contra exceções (Exception Safe). Da mesma forma, o construtor de movimento ([AP_SWS_SHWA_00705]) e o operador de atribuição por movimento ([AP_SWS_SHWA_00706]) estão disponíveis com noexcept=default. As instâncias podem, portanto, ser movidas e copiadas eficientemente, além de serem mantidas em contêineres padrão. Ao sair do escopo, a instância é automaticamente destruída; etapas adicionais de limpeza ou destruição não são prescritas.

No que diz respeito à concorrência em instâncias existentes, deve-se observar que os acessos de leitura e escrita via Get ([AP_SWS_SHWA_00710]) e Set ([AP_SWS_SHWA_00711]) não são thread-safe de acordo com a especificação. Caso múltiplas threads de execução modifiquem a mesma instância ou leiam e escrevam simultaneamente, o chamador deve assegurar uma sincronização externa.

Caminho de utilização

O fluxo de uso regular compreende a instanciação por meio de uma das funções factory, a avaliação do ara::core::Result, o ajuste opcional de valores dimensionais individuais e a leitura dos índices.

  1. Criação: A aplicação chama, por exemplo, ara::shwa::Id::Create(dim0) ([AP_SWS_SHWA_00707]) ou uma das sobrecargas multidimensionais ([AP_SWS_SHWA_00708], [AP_SWS_SHWA_00709]).
  2. Verificação de resultado: O ara::core::Result<Id> retornado é verificado quanto à ausência de erros (por exemplo, via HasValue()). Em caso de sucesso, a instância é desempacotada.
  3. Modificação: Através de Set(dimension, index) ([AP_SWS_SHWA_00711]), um índice para uma dimensão específica pode ser atualizado de forma direcionada.
  4. Consulta: Por meio de Get(dimension) ([AP_SWS_SHWA_00710]), a aplicação consulta o índice armazenado da dimensão especificada.

Diagrama de sequência: fluxo típico de criação, modificação e consulta de uma instância de Id. Fontes: [AP_SWS_SHWA_00707], [AP_SWS_SHWA_00710], [AP_SWS_SHWA_00711]

Cenários de erro

Situações de erro durante a criação do objeto são sinalizadas através do padrão AUTOSAR ara::core::Result sem exceções C++. Os métodos Create possuem a classificação de exceção "exception safe" e são declarados como noexcept ([AP_SWS_SHWA_00707], [AP_SWS_SHWA_00708], [AP_SWS_SHWA_00709]). Em caso de erro, os retornos contêm um código de erro:

  • ShwaErrorCode::kRuntime: Erro geral de tempo de execução durante a execução da factory (General runtime error). Neste caso, aplica-se a semântica de rollback, de modo que nenhuma instância inválida permaneça.

Para os métodos de acesso a elementos Get ([AP_SWS_SHWA_00710]) e Set ([AP_SWS_SHWA_00711]), a especificação indica a classificação "not exception safe". O chamador deve assegurar que seja passado como dimension um índice de dimensão válido, situado dentro do dimensionamento do objeto, pois valores de parâmetros inválidos podem levar a erros de tempo de execução.

Este guia baseia-se exclusivamente nos requisitos de especificação do AUTOSAR Adaptive Release R25-11.

  <h4>Contexto</h4>
  <p>
    A classe <code>ara::shwa::Id</code> representa, dentro do módulo <code>shwa</code> da AUTOSAR Adaptive Platform, um identificador tipificado projetado para indexação multidimensional. A definição da classe é implementada como template de classe <code>template &lt;int Dimensions = 1&gt; class Id final</code>. Interpretação: O módulo <code>shwa</code> endereça estruturas de shared hardware ou workloads, no qual <code>ara::shwa::Id</code> serve presumivelmente como chave estruturada de coordenadas ou de índices para o endereçamento inequívoco de pacotes de trabalho, buffers ou pontos de dados ao longo de até três dimensões.
  </p>
  <p>
    Os parceiros de interação de <code>ara::shwa::Id</code> são sobretudo aplicações adaptativas que a utilizam, bem como componentes funcionais do subsistema <code>shwa</code>. A classe encapsula dimensões e índices, de modo que funções de processamento de nível superior possam receber parâmetros posicionais com segurança de tipos. Como a classe é especificada como <code>final</code>, uma derivação está excluída; ela atua como um tipo de valor autocontido.
  </p>

  <h4>Ciclo de vida</h4>
  <p>
    O ciclo de vida de uma instância de <code>ara::shwa::Id</code> começa obrigatoriamente através de métodos factory estáticos. O construtor padrão está explicitamente excluído (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00702" href="../spec/record.html?id=AP_SWS_SHWA_00702">[AP_SWS_SHWA_00702]</a>), impedindo instâncias incompletamente inicializadas em tempo de compilação. Em vez disso, a criação de objetos ocorre por meio de métodos <code>Create</code> sobrecarregados, que retornam, cada um, uma instância encapsulada em um <code>ara::core::Result</code>:
  </p>
  <ul>
    <li>Inicialização unidimensional por meio de <code>Create(const std::size_t dim0)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00707" href="../spec/record.html?id=AP_SWS_SHWA_00707">[AP_SWS_SHWA_00707]</a>). Esta variante é indicada como thread-safe.</li>
    <li>Inicialização bidimensional por meio de <code>Create(std::size_t dim0, std::size_t dim1)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00708" href="../spec/record.html?id=AP_SWS_SHWA_00708">[AP_SWS_SHWA_00708]</a>). Esta variante é declarada como não thread-safe.</li>
    <li>Inicialização tridimensional por meio de <code>Create(std::size_t dim0, std::size_t dim1, std::size_t dim2)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00709" href="../spec/record.html?id=AP_SWS_SHWA_00709">[AP_SWS_SHWA_00709]</a>). Esta variante também é declarada como não thread-safe.</li>
  </ul>
  <p>
    Em relação à posse e ao modelo de cópia, <code>ara::shwa::Id</code> comporta-se como um tipo por valor regular. O construtor de cópia (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00703" href="../spec/record.html?id=AP_SWS_SHWA_00703">[AP_SWS_SHWA_00703]</a>) e o operador de atribuição por cópia (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00704" href="../spec/record.html?id=AP_SWS_SHWA_00704">[AP_SWS_SHWA_00704]</a>) estão definidos como <code>noexcept=default</code> e garantem total segurança contra exceções (Exception Safe). Da mesma forma, o construtor de movimento (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00705" href="../spec/record.html?id=AP_SWS_SHWA_00705">[AP_SWS_SHWA_00705]</a>) e o operador de atribuição por movimento (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00706" href="../spec/record.html?id=AP_SWS_SHWA_00706">[AP_SWS_SHWA_00706]</a>) estão disponíveis com <code>noexcept=default</code>. As instâncias podem, portanto, ser movidas e copiadas eficientemente, além de serem mantidas em contêineres padrão. Ao sair do escopo, a instância é automaticamente destruída; etapas adicionais de limpeza ou destruição não são prescritas.
  </p>
  <p>
    No que diz respeito à concorrência em instâncias existentes, deve-se observar que os acessos de leitura e escrita via <code>Get</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00710" href="../spec/record.html?id=AP_SWS_SHWA_00710">[AP_SWS_SHWA_00710]</a>) e <code>Set</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00711" href="../spec/record.html?id=AP_SWS_SHWA_00711">[AP_SWS_SHWA_00711]</a>) não são thread-safe de acordo com a especificação. Caso múltiplas threads de execução modifiquem a mesma instância ou leiam e escrevam simultaneamente, o chamador deve assegurar uma sincronização externa.
  </p>

  <h4>Caminho de utilização</h4>
  <p>
    O fluxo de uso regular compreende a instanciação por meio de uma das funções factory, a avaliação do <code>ara::core::Result</code>, o ajuste opcional de valores dimensionais individuais e a leitura dos índices.
  </p>
  <ol>
    <li>
      <strong>Criação:</strong> A aplicação chama, por exemplo, <code>ara::shwa::Id::Create(dim0)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00707" href="../spec/record.html?id=AP_SWS_SHWA_00707">[AP_SWS_SHWA_00707]</a>) ou uma das sobrecargas multidimensionais (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00708" href="../spec/record.html?id=AP_SWS_SHWA_00708">[AP_SWS_SHWA_00708]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00709" href="../spec/record.html?id=AP_SWS_SHWA_00709">[AP_SWS_SHWA_00709]</a>).
    </li>
    <li>
      <strong>Verificação de resultado:</strong> O <code>ara::core::Result&lt;Id&gt;</code> retornado é verificado quanto à ausência de erros (por exemplo, via <code>HasValue()</code>). Em caso de sucesso, a instância é desempacotada.
    </li>
    <li>
      <strong>Modificação:</strong> Através de <code>Set(dimension, index)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00711" href="../spec/record.html?id=AP_SWS_SHWA_00711">[AP_SWS_SHWA_00711]</a>), um índice para uma dimensão específica pode ser atualizado de forma direcionada.
    </li>
    <li>
      <strong>Consulta:</strong> Por meio de <code>Get(dimension)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00710" href="../spec/record.html?id=AP_SWS_SHWA_00710">[AP_SWS_SHWA_00710]</a>), a aplicação consulta o índice armazenado da dimensão especificada.
    </li>
  </ol>

  <h4>Cenários de erro</h4>
  <p>
    Situações de erro durante a criação do objeto são sinalizadas através do padrão AUTOSAR <code>ara::core::Result</code> sem exceções C++. Os métodos <code>Create</code> possuem a classificação de exceção "exception safe" e são declarados como <code>noexcept</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00707" href="../spec/record.html?id=AP_SWS_SHWA_00707">[AP_SWS_SHWA_00707]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00708" href="../spec/record.html?id=AP_SWS_SHWA_00708">[AP_SWS_SHWA_00708]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00709" href="../spec/record.html?id=AP_SWS_SHWA_00709">[AP_SWS_SHWA_00709]</a>). Em caso de erro, os retornos contêm um código de erro:
  </p>
  <ul>
    <li>
      <code>ShwaErrorCode::kRuntime</code>: Erro geral de tempo de execução durante a execução da factory (General runtime error). Neste caso, aplica-se a semântica de rollback, de modo que nenhuma instância inválida permaneça.
    </li>
  </ul>
  <p>
    Para os métodos de acesso a elementos <code>Get</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00710" href="../spec/record.html?id=AP_SWS_SHWA_00710">[AP_SWS_SHWA_00710]</a>) e <code>Set</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00711" href="../spec/record.html?id=AP_SWS_SHWA_00711">[AP_SWS_SHWA_00711]</a>), a especificação indica a classificação "not exception safe". O chamador deve assegurar que seja passado como <code>dimension</code> um índice de dimensão válido, situado dentro do dimensionamento do objeto, pois valores de parâmetros inválidos podem levar a erros de tempo de execução.
  </p>
