Finalidade de uso

Esta classe de campo esqueleto é gerada para cada elemento do ServiceInterface modelado como um campo. O namespace, o nome e o cabeçalho <SiNamespaceDerivedDirectoryPath>/<SiShortname>_skeleton.h são derivados do modelo ServiceInterface do manifesto ARXML. Ele é usado por meio de sua própria implementação de serviço que herda da classe Skeleton gerada. [SWS_CM_00007]

usar

Update(value) atualiza o valor do campo interno e aciona a transmissão dos dados atualizados aos assinantes; uma notificação é enviada se o notificador do campo estiver presente. O valor de retorno sinaliza sucesso ou um ComErrc correspondente. [SWS_CM_00119]

Os manipuladores assíncronos podem ser registrados para solicitações getter ou setter recebidas. O manipulador get existe apenas em Field.hasGetter == TRUE, o manipulador set apenas em Field.hasSetter == TRUE; ambos têm sobrecargas para um contexto de execução fornecido. Um manipulador de falhas de transporte pode ser definido e removido. [SWS_CM_00114] [SWS_CM_11360] [SWS_CM_00116] [SWS_CM_11362] [SWS_CM_00096] [SWS_CM_00097] [SWS_CM_00098]
