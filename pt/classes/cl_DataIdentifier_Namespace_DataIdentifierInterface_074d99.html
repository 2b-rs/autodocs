Finalidade de uso

<DataIdentifierInterface> fornece uma interface de aplicação para identificadores de dados de diagnóstico. O aplicação implementa Read() para a função de leitura e Write() para a função de gravação; Ambas as operações entregam seus resultados de forma assíncrona via ara::core::Future. [SWS_DM_00601] [SWS_DM_00640] [SWS_DM_00598]

Criação e Destruição

O construtor vincula a interface por meio de ara::core::InstanceSpecifier e define a contenção de implementação pretendida com ConcurrencyType. Offer() ativa o encaminhamento de pedidos para o manipulador, StopOffer() desliga. Se o serviço já for oferecido, a Oferta entrega DiagOfferErrc::kAlreadyOffered.
