Finalidade de uso

SovdAuthorization implementa autorização SOVD no nível do aplicação. GetAuthorizationUrl() e GetTokenUrl() fornecem a URL para autorização e solicitação de token, respectivamente; o DM responde a isso com HTTP 307 e um cabeçalho Location com este URL. [SWS_DM_01485] [SWS_DM_01484] [SWS_DM_01472] [SWS_DM_01471] ValidateAuthorization() valida o token do cabeçalho de autorização HTTP e marca as funções autorizadas no ClientAuthentication passado. Contexto de acesso SOVD

A autorização SOVD usa tokens OAuth no cabeçalho da solicitação. Para tal solicitação, o Diagnostic Manager usa SovdAuthorization para solicitar a função de autorização codificada da aplicação; com base nesta função, decide se a operação SOVD solicitada está autorizada. This function validates the authorization token sent by the SOVD client. The application shall validate the authorization token according to the authorization protocol used in the system and then according to the outcome set the respective roles as authorized in the clientAuthentication that is passed as parameter. If OAuth 2.0 is used, this would implement the validation that is supposed to happen in the Resource Server.

O método virtual ValidateAuthorization valida o token (token) enviado por um cliente SOVD através do cabeçalho HTTP-Authorization, de acordo com o protocolo de autorização utilizado no sistema; no caso de OAuth 2.0, isto corresponde à verificação pelo Resource Server. Com base no resultado, a aplicação define como autorizadas [SWS_DM_01483] as funções correspondentes no objeto passado pelo parâmetro clientAuthentication. Adicionalmente, é passada a metaInfo da porta de diagnóstico.
