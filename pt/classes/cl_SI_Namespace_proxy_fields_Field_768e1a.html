Finalidade de uso

Esta classe final de Proxy-Field é gerada para cada elemento modelado como Field no ServiceInterface. O namespace, o nome da classe e o header <SiNamespaceDerivedDirectoryPath>/<SiShortname>_proxy.h derivam do modelo ServiceInterface do Manifest ARXML. [SWS_CM_00008]

usar

Get() lê o valor do campo atual de forma assíncrona e só estará presente se o campo tiver um getter. Set() define um novo valor de forma assíncrona e só é criado se um setter estiver presente; Um erro de aplicação pode ser identificado por um valor de retorno diferente do valor solicitado. Ambas as chamadas retornam um ara::core::Future<FieldType>. [SWS_CM_00112] [SWS_CM_00113]

Para notificações de campo, primeiro chame Subscribe(maxSampleCount) e depois use GetNewSamples() para atualizar o cache de notificação local. A mesma assinatura já ativa ou pendente não será reexecutada; Unsubscribe() sem uma assinatura existente permanece ineficaz. O espaço de cache livre pode ser consultado com GetFreeSampleCount(). Os manipuladores de estado de recebimento e assinatura podem ser registrados, executados em um contexto fornecido e removidos novamente.
