Contexto de ciclo para processamento de eventos

OperationCycle torna as alterações em um ciclo operacional configurado visíveis no lado do aplicação. O DM utiliza ciclos de operação no processamento de status de eventos e memória de erros; O ciclo é, portanto, o contexto temporal no qual os resultados do teste e certos bits de status são interpretados SWS Diagnostics §7.3.4.3 «Operation Cycles Management» SWS Diagnostics §7.3.4.1.6 «Event Status processing».

Os ciclos de operação fornecem contexto temporal para processamento de eventos e status do DTC; a interface relata alterações do ciclo para o aplicação. Fontes: SWS Diagnostics §7.3.4.3 «Operation Cycles Management», SWS Diagnostics §7.3.4.1.6 «Event Status processing», SWS Diagnostics §7.3.4.4 «Event memory». Interpretação parcial: os nomes dos estados resumem a função temporal da API do Ciclo de Operação.

Notificador como transferência de estado

SetNotifier regista um retorno de chamada para alterações não ciclo de operação; um registo subsequente substitui ou retorno de chamada anterior [SWS_DM_00755]. A implementação do notificador deve apenas assumir ou estado do ciclo ou iniciar ou encerrar suas próprias trilhas de auditoria, e não escrever os próprios bits de status do evento.

Classifique a reinicialização semanticamente

RestartOperationCycle é uma pedido DM explícita para reiniciar um Operation Cycle. Se e quais consequências de eventos/DTC surgem disso depende do processamento de eventos configurado. Portanto, primeiro atribua claramente o ciclo notificado ou configurado e só depois utilize o reinício; As ações do monitor continuam a ser relatadas via Monitor.
