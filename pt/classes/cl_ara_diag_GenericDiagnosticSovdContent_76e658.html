Finalidade de uso

A interface processa dados genéricos de conteúdo SOVD. O Diagnostic Manager usa a instância mapeada acima DiagnosticSovdContentPortMapping para ler dados SOVD. Read devolve DiagnosticSovdContentData de forma assíncrona para um nome de conteúdo; Write aceita tais dados para «Write a Data Value». [SWS_DM_02186] [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_02164]

Interação com outras aulas

Para uma pedido de leitura, o gerenciador chama Read e forma a resposta SOVD a partir dos elementos de conteúdo agregados. Para uma pedido de gravação, ele chama Write com DiagnosticSovdContentData, cujos elementos são construídos usando SetName e SetContent. [SWS_DM_01432] [SWS_DM_02166]

Restrições & tratamento de erros

Read e Write devolvem um erro SOVD se ou resultado é negativo. CancellationHandler não se pode armazenar ni utilizar para além de a vida útil de a operação atual. Offer activa ou encaminhamento de solicitações, StopOffer ou para; DiagOfferErrc::kAlreadyOffered informa uma interface que ya se ofrece. As funções presentadas são seguras para threads. Regras de parâmetros e resultados Read recebe Content Name, MetaInfo e CancellationHandler e devolve dados SOVD Content abstratos para uma resposta positiva ou um erro SOVD. Write recebe as mesmas informações de contexto, bem como os dados Content a escrever; estes dados são válidos até ao cumprimento da Future ou à anulação. O construtor e o destrutor são exception-safe e thread-safe. [SWS_DM_02187] [SWS_DM_02188] [SWS_DM_02191] [SWS_DM_02192]

As operações assíncronas são pontos de interface puramente virtuais; O processamento concreto, portanto, implementa a aplicação fornecedora. A resposta externa é formada pelo Diagnostic Manager com base nos Futures cumpridos. [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_01432]
