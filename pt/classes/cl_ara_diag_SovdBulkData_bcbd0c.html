Finalidade de uso

SovdBulkData é a interface genérica para dados em massa SOVD. Ele lê metadados, inicia sessões de download ou upload e exclui todos os dados de uma categoria ou de uma instância específica. Interação com outras aulas

Um download fornece uma sessão de leitura com BulkDataMetaDataDescriptor ou um HttpRedirect. [SWS_DM_01873] Um upload fornece uma sessão de escrita com um descritor de metadados; DeleteAllBulkData() fornece DeleteByCategoryResult. [SWS_DM_01854] [SWS_DM_01855]
