Finalidade de uso

A classe permite que o aplicação acione anúncios de veículos do Diagnostic Manager para um ID de interface de rede. A função estática GetDoIPTriggerVehicleAnnouncement fornece uma referência de resultado para a interface; TriggerVehicleAnnouncement é puramente virtual. [SWS_DM_00820] [SWS_DM_00821] [SWS_DM_00822]

Interação com outras aulas

Após chamar TriggerVehicleAnnouncement, o gerenciador aciona as mensagens de anúncio do veículo conforme ISO 13400-2 na interface especificada por networkInterfaceId. [SWS_DM_00815]
