Finalidade de uso

GenericDiagnosticSovdOperation é a interface do aplicação para uma operação genérica de diagnóstico SOVD. O Diagnostic Manager (DM) chama StartExecution quando uma solicitação SOVD é recebida para iniciar a operação especificada; Se necessário, a validação do desafio de proximidade deve primeiro ser bem sucedida. [SWS_DM_02203] [SWS_DM_02210] [SWS_DM_02174] A implementação fornece de forma assíncrona uma resposta de início síncrona ou assíncrona. Para uma resposta síncrona, o DM deriva os parâmetros da resposta SOVD positiva do DiagnosticSovdContentData retornado. [SWS_DM_02210] [SWS_DM_02176]

Criação e Destruição

A instância é criada com um InstanceSpecifier para um PortPrototype de DiagnosticDataIdentifierGenericInterface e um ConcurrencyType. Offer() ativa o encaminhamento de solicitações pelo DM, StopOffer() desativa novamente. [SWS_DM_02204] [SWS_DM_02211] [SWS_DM_02212] Uma nova oferta será rejeitada com DiagOfferErrc::kAlreadyOffered. [SWS_DM_02211]

Ciclo de vida & Propriedade

A interface é móvel: a construção e a atribuição de movimentos são fornecidas. [SWS_DM_02206] [SWS_DM_02207] O destruidor é noexcept, exception-safe e thread-safe. [SWS_DM_02205]

Restrições & tratamento de erros

Os dados do parâmetro sovd_content_data só permanecem válidos até que a promessa seja cumprida ou até que uma mensagem de aborto seja processada. O CancellationHandler não pode ser armazenado ou usado além do tempo de vida desta operação. Os erros de execução devem ser fornecidos como um código de erro SOVD aplicável. [SWS_DM_02210] Offer() e StopOffer() não são thread-safe; StartExecution é thread-safe. [SWS_DM_02211] [SWS_DM_02212] [SWS_DM_02210]

StartExecution pode retornar uma resposta de início síncrona ou assíncrona como uma variante e é uma função virtual pura que deve, portanto, ser implementada pela aplicação. [SWS_DM_02210] O construtor em si é seguro para exceções e threads. [SWS_DM_02204]

Para casos de uso de SOVD correspondentes a UDS, a reutilização da mesma instância de porta do serviço UDS correspondente é um princípio orientador; Aplicam-se as mesmas regras relativas à reentrada e execução paralela.
