DataTransferReadSession encapsula as variantes de uma transferência de dados de leitura. Para TransferData 0x36 no contexto de RequestFileTransfer, o Servidor de Diagnóstico chama o método Read do manipulador apropriado registrado por meio dos construtores de modelo; para RequestTransferExit 0x37 ele chama seu método de saída.
