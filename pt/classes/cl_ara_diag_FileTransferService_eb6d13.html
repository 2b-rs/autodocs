Finalidade de uso

A interface lida com solicitações RequestFileTransfer de ficheiros e diretórios. Os métodos virtuais puros cobrem a leitura de um ficheiro, a leitura de um diretório, a gravação, a retomada de uma gravação e a exclusão; os resultados são entregues de forma assíncrona como futuros. [SWS_DM_01320] [SWS_DM_01331] [SWS_DM_01332] [SWS_DM_01333] [SWS_DM_01334] [SWS_DM_01335]

Interação com outras aulas

Em AddFile, o Diagnostic Server chama RequestWriteFile com WriteFileMode::kAdd; em ReadFile ou ReadDir, chama os métodos de leitura adequados. As operações de leitura devolvem uma DataTransferReadSession e as de escrita uma DataTransferWriteSession; os tamanhos dos ficheiros são transmitidos ou devolvidos como FileSizes.
