Finalidade de uso

UdsTransportProtocolPeriodicHandler suporta a função UDS 0x2A para transmissão periódica de dados. Ele fornece os limites específicos de transporte e conexão e a operação de transferência. [SWS_DM_01064]

Interação com outras aulas

GetMaxPayloadLength() retorna o comprimento máximo de carga útil permitido de uma única transmissão periódica para um canal. O DM usa ReadDataByPeriodicIdentifier para verificar o comprimento de cada identificador solicitado e responde com NRC 0x14 se for excedido. GetNumberOfPeriodicMessages() fornece o número permitido de mensagens periódicas para a conexão. [SWS_DM_01066] [SWS_DM_01050] [SWS_DM_01065]

PeriodicTransmit() envia a lista de mensagens passadas em ordem. Caso uma transmissão falhe, o processo de envio é encerrado e uma confirmação periódica de transmissão é acionada com a mesma lista e o número de mensagens enviadas; o DM usa esta operação para transmissões PDID acionadas.
