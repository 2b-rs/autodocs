Papel no modelo

Accessor representa o acesso tipado a um Buffer. O tipo de acesso e o destino são parâmetros de template; para acessos Read, o tipo de referência é const, para outros acessos é gravável.

Referência de fonte

SWS SHWA §7.3 descreve os acessadores como uma ponte entre o kernel e os dados; o AccessMode suporta o planejamento do acesso aos dados.
