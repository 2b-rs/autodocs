Finalidade de uso

ara::core::Optional<T> implementa std::optional<T> e modela um valor possivelmente presente. Suporta construção vazia ou nullopt, construção in-place, emplace(), reset(), consultas de estado e acesso ao valor. Opcionalidade em conjuntos de dados modelados

Optional não é apenas um tipo de conveniência geral: o Core o chama especificamente para elementos de registo opcionais de um StdCppImplementationDataType da categoria STRUCTURE. Os campos obrigatórios, por outro lado, aparecem diretamente com seu tipo de dados de implementação. Alternativamente, Optional pode expressar o possível valor de retorno ausente de uma função.
