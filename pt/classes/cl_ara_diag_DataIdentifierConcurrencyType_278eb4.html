DataIdentifierConcurrencyType configura as propriedades de contenção de uma porta relativada ao DataIdentifier. Os campos read e write controlam chamadas de leitura e gravação, respectivamente, e o padrão é ConcurrencyType::kNotConcurrent. [SWS_DM_00936] [SWS_DM_00937] [SWS_DM_00938]

readWrite descreve se Read e Write podem ser chamados em paralelo. Somente com ConcurrencyType::kConcurrent o DM pode chamar as duas APIs ao mesmo tempo; Este campo também é não simultâneo por padrão. [SWS_DM_00939]

  • write Concurrency type for Writes.
