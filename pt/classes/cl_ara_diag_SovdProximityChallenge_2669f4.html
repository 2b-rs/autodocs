Finalidade de uso

SovdProximityChallenge implementa a interface SOVD para desafios de proximidade. GetChallenge() retorna um desafio gerado pela aplicação incluindo a data de validade; Se a prova de proximidade for necessária para uma operação SOVD, o Servidor de Diagnóstico coloca esse valor na resposta correspondente. [SWS_DM_01481] [SWS_DM_01494] [SWS_DM_01398] ValidateResponse() verifica a resposta fornecida pelo cliente. [SWS_DM_01493] [SWS_DM_01395]

Restrições & tratamento de erros

A resposta de proximidade só é válida até ao cumprimento da promessa ou processamento de cancelamento. [SWS_DM_01493] Para agendar uma operação SOVD, o Diagnostic Server deve verificar um proximity_response existente com ValidateResponse(). Contexto de acesso SOVD

Um desafio de proximidade SOVD solicita prova de proximidade antes de executar uma operação SOVD. A interface SovdProximityChallenge passa o procedimento de desafio para a aplicação e informa o resultado ao Gerenciador de Diagnóstico; com base nisso ele realiza a operação.
