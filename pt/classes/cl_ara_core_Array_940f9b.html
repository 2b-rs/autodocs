Finalidade de uso

ara::core::Array<T, N> implementa o tipo std::array para um número de elementos [SWS_CORE_01201] especificados em tempo de compilação por N. Ele fornece iteradores de ponteiro, consultas de tamanho e iteração para frente/para trás [SWS_CORE_01212] [SWS_CORE_01262] [SWS_CORE_01250] [SWS_CORE_01254].

Ciclo de vida & Propriedade

A especificação não declara explicitamente as funções-membro especiais implícitas; sua semântica é baseada em std::array [SWS_CORE_01201]. fill() e swap() são condicionalmente seguros para exceções [SWS_CORE_01241] [SWS_CORE_01242] dependendo das propriedades de T.

Interação com outras aulas

Um ponteiro para os elementos está disponível via data(); para tamanho zero nullptr é entregue [SWS_CORE_01271] [SWS_CORE_01272]. O tipo suporta integração tuple_element; um índice I >= N é um erro em tempo de compilação [SWS_CORE_01281] [SWS_CORE_01285].

Restrições & tratamento de erros

at() aciona IsoStdOutOfRangeViolation em vez de std::out_of_range quando n >= size() aciona [SWS_CORE_01273] [SWS_CORE_01274]. front() e back() em um array vazio são erros de tempo de compilação [SWS_CORE_01267] [SWS_CORE_01268] [SWS_CORE_01269] [SWS_CORE_01270].
