classe ara::core::ErrorCode

class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

Finalidade de uso

ErrorCode encapsula um valor de erro bruto específico do domínio, uma referência ao ErrorDomain associado e dados adicionais opcionais específicos do fornecedor. O tipo é um tipo literal. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

Restrições & tratamento de erros

As comparações têm em conta exclusivamente o valor de erro e o domínio de erro, não os dados adicionais. ErrorCode e os seus Members podem ser utilizados independentemente de ara::core::Initialize e Deinitialize. [SWS_CORE_10301] [SWS_CORE_15002]

Contexto de erro em vez de valores de erro genéricos

Um ErrorCode associa um valor de erro digitado ao seu contexto ErrorDomain; opcionalmente, pode conter uma mensagem e informações adicionais específicas do fabricante. As interfaces ARA usam-no em Result para erros recuperáveis. EXP InterfacesGuidelines §3.1.2 «Result» EXP ARAComAPI §4.7 «Error Handling»

Os códigos de erro específicos do fabricante exigem seus próprios dominios de erro; As aplicações portátiles e de pila neutral devem tratar referidos dominios como um caso predefinido general. EXP InterfacesGuidelines §3.1.5 «Standardized vs Vendor-specific ErrorCodes»

Diagrama de colaboração: ErrorCode obtém contexto e mensagem de seu domínio; a transformação de exceção é o caminho de exceção explícito. Fontes: EXP InterfacesGuidelines §3.1.2 «Result» RS General §4.1.3 «The use of noexcept».

Digite o valor de erro apagado

A SWS descreve ErrorCode como um valor de erro com contexto de domínio: o código específico do domínio é apagado do tipo para um valor inteiro, de modo a permitir o transporte uniforme; podem ser transmitidos dados de suporte adicionais. As comparações consideram o valor e o domínio, não os dados de suporte. SWS Core §7.2 «Error handling» SWS Core §7.2.5.1 «ErrorCode» [SWS_CORE_10301] [SWS_CORE_10302]
