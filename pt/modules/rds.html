Classificação e Finalidade

Os fluxos de dados brutos transmitem dados binários como uma conexão entre cliente e servidor por meio de protocolos baseados em IP. RawDataStreamClient e RawDataStreamServer são criados para interfaces de porta modeladas [SWS_RDS_10481] [SWS_RDS_11311].

Processo baseado em IP

O cliente se conecta ao Connect, o lado do servidor aguarda via WaitForConnection; Ambos os lados leem ou gravam dados e encerram a conexão via Shutdown [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].
