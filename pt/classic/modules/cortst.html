Core Test (CorTst)

AUTOSAR Classic Microcontroller Drivers-Modul Core Test (CorTst, Spezifikation: AUTOSAR_CP_SWS_CoreTest.pdf, AUTOSAR_SWS_CoreTest.pdf).

Funktionen — Übersicht

  • void CorTst_Init (const CorTst_ConfigType* ConfigPtr); Service for initialization and change of state of the Core Test
  • void CorTst_DeInit (void); Service to change from CORTST_ ABORT or CORTST_ INIT to CORTST_ UNINIT state
  • void CorTst_Abort (void); Service to change from CORTST_ INIT to CORTST_ ABORT state
  • CorTst_StateType CorTst_GetState (void); Service for Core Test to immediately return status on currently executed Core Test.
  • void CorTst_GetCurrentStatus (CorTst_ErrOkType* ErrOk); Service for Core Test to get indicator of the last executed Core Test result
  • CorTst_CsumSignatureBgndType CorTst_GetSignature (void); Service to get signature of the last executed Core Test in background mode.
  • CorTst_CsumSignatureType CorTst_GetFgndSignature (void); Service to get signature of the last executed Core Test in foreground mode.
  • Std_ReturnType CorTst_Start (CorTst_TestIdFgndType TestId); Service for executing foreground Core Test.
  • void CorTst_MainFunction (void); Cyclically called by scheduler to perform processing of Core Test.
  • void CorTst_TestCompletedNotification (CorTst_ErrOkType ResultOfLastCorTstRun); The function Cor Tst_ Test Completed Notification shall be called every time when a complete test cycle has been executed.
  • void CorTst_GetVersionInfo (Std_VersionInfoType* versioninfo); Service returns the version information of this module.

requirement SWS_CorTst_00009 [SWS_CorTst_00009] 📄 PDF

The Core Test shall provide an Interrupt Controller and Exception detection test. Especially the detection of an interrupt itself and a branch to a valid interrupt service address shall be part of the test. It is regardless if the test is triggered by soft ware exceptions or by a dedicated hardware unit built in silicon.

The Core Test shall provide a core memory interface test. This explicitly excludes tests on memory locations themselves which are connected external to a core itself or reside internal in a core.

requirement SWS_CorTst_00013 [SWS_CorTst_00013] 📄 PDF

The Core Test shall provide a memory protection unit test (MPU). This is vali d even if a Memory Management Unit (MMU) executes MPU functionality.

requirement SWS_CorTst_00014 [SWS_CorTst_00014] 📄 PDF

The Core Test shall provide a Cache Controller Test. Especially the coherency and consistency between data or instructions located in memory out side the core and its appropriate cache entry representation shall be tested.
