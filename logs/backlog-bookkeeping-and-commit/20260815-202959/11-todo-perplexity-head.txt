## Feature: 0021 — Website-Initiated Specification Review Flags

**PREREQ:** 0021:0005, 0021:0006

**Goal:** Let a website user request a traceable re-review of any published
specification record—including an element currently curated as valid—without
directly changing that record's status or factual content. The website must
produce an authenticated or self-declared review/curation request package that
can be ingested into the existing queue/lifecycle, reviewed by the responsible
roles, and linked back to the originating record and its published history; the
GitHub path submits the package, while the JSON path exports it for later
transfer and ingestion.

**Scope and safety boundary:** "Flag for review" is a request for re-curation,
not an in-place edit, publication withdrawal, approval, or rejection. No
browser user, agent, or client-side code may transition a record to `valid/*`,
rewrite a record, or close a curation item.
