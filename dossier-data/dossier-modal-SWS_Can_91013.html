<p>Der Enumerationstyp <code>Can_ControllerStateType</code> definiert die grundlegenden Betriebszustände eines CAN-Controllers: <code>CAN_CS_UNINIT</code>, <code>CAN_CS_STARTED</code>, <code>CAN_CS_STOPPED</code> und <code>CAN_CS_SLEEP</code> <a class="spec-record-ref" data-req="SWS_Can_91013" href="../../spec/record.html?id=SWS_Can_91013">[SWS_Can_91013]</a>. Der Typ wird modulübergreifend zur softwaregesteuerten Zustandsführung der CAN-Controller-Zustandsmaschine verwendet <a class="spec-record-ref" data-req="SWS_Can_00017" href="../../spec/record.html?id=SWS_Can_00017">[SWS_Can_00017]</a>.</p>
  <p>Die Werte werden in folgenden Kontexten eingesetzt:</p>
  <ul>
    <li><strong>Zustandsanforderung:</strong> In <code>Can_SetControllerMode</code> dient der Typ als Übergangswert (Parameter <code>Transition</code>) zur asynchronen Anforderung eines neuen Betriebszustands <a class="spec-record-ref" data-req="SWS_Can_00230" href="../../spec/record.html?id=SWS_Can_00230">[SWS_Can_00230]</a>; korrespondierend dazu existiert <code>CanIf_SetControllerMode</code> <a class="docref internal-spec-ref" href="../../spec/record.html?doc=AUTOSAR_SWS_CANInterface&amp;page=76">AUTOSAR_SWS_CANInterface §- „CanIf_SetControllerMode“</a>. Der Treiber reicht die Anforderung an die Controller-Hardware weiter, wobei die tatsächliche Zustandsänderung unmittelbar oder nach einigen Millisekunden wirksam wird <a class="docref internal-spec-ref" href="../../spec/record.html?doc=AUTOSAR_SWS_CANInterface&amp;page=144">AUTOSAR_SWS_CANInterface §- „Can_SetControllerMode“</a>. Ein Übergang nach <code>CAN_CS_STARTED</code> löst zudem eine Reinitialisierung des Controllers aus <a class="spec-record-ref" data-req="SWS_Can_00384" href="../../spec/record.html?id=SWS_Can_00384">[SWS_Can_00384]</a>.</li>
    <li><strong>Statusabfrage:</strong> Über <code>Can_GetControllerMode</code> kann der aktuelle Zustand synchron über den Ausgabepointer <code>ControllerModePtr</code> abgefragt werden <a class="spec-record-ref" data-req="SWS_Can_91014" href="../../spec/record.html?id=SWS_Can_91014">[SWS_Can_91014]</a>, <a class="spec-record-ref" data-req="SWS_Can_91015" href="../../spec/record.html?id=SWS_Can_91015">[SWS_Can_91015]</a> (analog in <code>CanIf_GetControllerMode</code> <a class="docref internal-spec-ref" href="../../spec/record.html?doc=AUTOSAR_SWS_CANInterface&amp;page=77">AUTOSAR_SWS_CANInterface §- „CanIf_GetControllerMode“</a>).</li>
    <li><strong>Zustandsindikation:</strong> Nach vollzogenem Wechsel benachrichtigen Callbacks wie <code>CanSM_ControllerModeIndication</code> <a class="spec-record-ref" data-req="SWS_CanSM_00396" href="../../spec/record.html?id=SWS_CanSM_00396">[SWS_CanSM_00396]</a>, <code>CanIf_ControllerModeIndication</code> <a class="docref internal-spec-ref" href="../../spec/record.html?doc=AUTOSAR_SWS_CANInterface&amp;page=108">AUTOSAR_SWS_CANInterface §- „CanIf_ControllerModeIndication“</a> sowie Anwender-Callbacks <a class="docref internal-spec-ref" href="../../spec/record.html?doc=AUTOSAR_SWS_CANInterface&amp;page=125">AUTOSAR_SWS_CANInterface §- „User_ControllerModeIndication“</a> übergeordnete Schichten synchron über den neuen Controller-Modus.</li>
  </ul>
  <p>Hinsichtlich Nebenläufigkeit und Fehlerbehandlung gilt: Die Treiberfunktionen <code>Can_SetControllerMode</code> und <code>Can_GetControllerMode</code> sind nicht reentrant <a class="spec-record-ref" data-req="SWS_Can_00230" href="../../spec/record.html?id=SWS_Can_00230">[SWS_Can_00230]</a>, <a class="spec-record-ref" data-req="SWS_Can_91014" href="../../spec/record.html?id=SWS_Can_91014">[SWS_Can_91014]</a>. Bei Aufruf von <code>Can_GetControllerMode</code> vor der Treiberinitialisierung wird der Entwicklungsfehler <code>CAN_E_UNINIT</code> gemeldet und <code>E_NOT_OK</code> zurückgegeben <a class="spec-record-ref" data-req="SWS_Can_91016" href="../../spec/record.html?id=SWS_Can_91016">[SWS_Can_91016]</a>. Die Callback-Funktion <code>CanSM_ControllerModeIndication</code> ist für unterschiedliche Controller reentrant und meldet eine unkonfigurierte Controller-ID mit <code>CANSM_E_PARAM_CONTROLLER</code> an das DET <a class="spec-record-ref" data-req="SWS_CanSM_00396" href="../../spec/record.html?id=SWS_CanSM_00396">[SWS_CanSM_00396]</a>, <a class="spec-record-ref" data-req="SWS_CanSM_00397" href="../../spec/record.html?id=SWS_CanSM_00397">[SWS_CanSM_00397]</a>.</p>
