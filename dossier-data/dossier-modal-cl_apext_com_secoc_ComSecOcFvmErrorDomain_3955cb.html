<h4>Context</h4>
<p>The class <code>apext::com::secoc::ComSecOcFvmErrorDomain</code> defines the error domain for the Freshness Value Manager (FVM) of Secure Onboard Communication (SecOC) within the AUTOSAR Adaptive Platform <a class="spec-record-ref" data-req="SWS_CM_12514" href="../spec/record.html?id=SWS_CM_12514">[SWS_CM_12514]</a>. It is located in module <code>com</code> and declared in header file <code>apext/com/secoc/fvm_error_domain.h</code> <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_CommunicationManagement&amp;page=543">AUTOSAR_AP_SWS_CommunicationManagement §C.2.3 “Class: ComSecOcFvmErrorDomain”</a>. <h4>Usage Path</h4>
<p>The regular workflow for signaling and evaluating errors of the Freshness Value Manager follows standardized steps:</p>
<ol>
<li><strong>Error identification:</strong> If an error occurs in the FVM, an error value of the enumeration type <code>Errc</code> (<a class="spec-record-ref" data-req="SWS_CM_12515" href="../spec/record.html?id=SWS_CM_12515">[SWS_CM_12515]</a>) is generated. Together with the reference to <code>ComSecOcFvmErrorDomain</code>, which is obtained via <code>GetComSecOcFvmErrorDomain()</code> <a class="spec-record-ref" data-req="SWS_CM_12521" href="../spec/record.html?id=SWS_CM_12521">[SWS_CM_12521]</a>, an <code>ara::core::ErrorCode</code> is constructed.</li>
<li><strong>Domain check:</strong> The application can query the associated string constant of the error domain via <code>Name()</code> <a class="spec-record-ref" data-req="SWS_CM_12518" href="../spec/record.html?id=SWS_CM_12518">[SWS_CM_12518]</a> to verify the origin of the error.</li>
<li><strong>Message evaluation:</strong> For logging or diagnostic purposes, the caller passes the numeric error code to <code>Message(errorCode)</code> <a class="spec-record-ref" data-req="SWS_CM_12519" href="../spec/record.html?id=SWS_CM_12519">[SWS_CM_12519]</a> and receives a pointer to the textual error description.</li>
<li><strong>Exception handling:</strong> If exception handling is desired, the processing subsystem calls <code>ThrowAsException(errorCode)</code> <a class="spec-record-ref" data-req="SWS_CM_12520" href="../spec/record.html?id=SWS_CM_12520">[SWS_CM_12520]</a>. The domain then instantiates an exception object of type <code>Exception</code> (<a class="spec-record-ref" data-req="SWS_CM_12516" href="../spec/record.html?id=SWS_CM_12516">[SWS_CM_12516]</a>) and throws it.</li>
</ol>
