<h4>Verwendung und Semantik</h4>
<p>Die statische Fabrikmethode <code>Create</code> dient gemäß <a class="spec-record-ref" data-req="SWS_CM_10438" href="../spec/record.html?id=SWS_CM_10438">[SWS_CM_10438]</a> der ausnahmefreien Erzeugung einer Proxy-Instanz (<code>&lt;SI&gt;Proxy</code>) nach dem Named-Constructor-Idiom. Sie erfordert als Parameter <code>handle</code> ein zuvor ermitteltes Dienst-Handle gemäß <a class="spec-record-ref" data-req="SWS_CM_00131" href="../spec/record.html?id=SWS_CM_00131">[SWS_CM_00131]</a>. Der Aufruf erfolgt synchron und ist als <code>noexcept</code> deklariert. Das Ergebnis wird in einem <code>ara::core::Result</code> zurückgegeben, das im Erfolgsfall die betriebsbereite Proxy-Instanz enthält.</p>
<h4>Fehlerbehandlung</h4>
<p>Tritt während der Instanziierung ein Fehler auf, liefert <code>Create</code> über das <code>ara::core::Result</code> einen Fehlercode vom Typ <code>ara::com::ComErrc</code> <a class="spec-record-ref" data-req="SWS_CM_10438" href="../spec/record.html?id=SWS_CM_10438">[SWS_CM_10438]</a>:</p>
<ul>
<li><code>ComErrc::kServiceNotAvailable</code>: Der Dienst ist nach vorherigem Angebot via <code>OfferService()</code> nicht mehr verfügbar.</li>
<li><code>ComErrc::kCommunicationFailure</code>: Das Netzwerk-Binding meldet einen behebbaren Kommunikationsfehler oder das Scheitern einer gesicherten Verbindung.</li>
</ul>
<p>Beide Fehler weisen eine Rollback-Semantik auf <a class="spec-record-ref" data-req="SWS_CM_10438" href="../spec/record.html?id=SWS_CM_10438">[SWS_CM_10438]</a>. Bei strukturellen oder sicherheitsbezogenen Fehlern greifen spezifizierte Verletzungen (Violations): Ist das übergebene Handle null oder korrumpiert, liegt eine <code>ErroneousServiceHandleViolation</code> vor. Fehlen dem aufrufenden Prozess im Rahmen des Grant Enforcements die notwendigen Berechtigungen für die Instanz, wird die Anfrage abgewiesen und als <code>InsufficientPermissionsViolation</code> behandelt (<a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_CommunicationManagement&amp;page=210">SWS CommunicationManagement §8 „Security“</a>, <a class="spec-record-ref" data-req="SWS_CM_10438" href="../spec/record.html?id=SWS_CM_10438">[SWS_CM_10438]</a>).</p>
<h4>Nebenläufigkeit und Randbedingungen</h4>
<p>Interpretation: Da <code>Create</code> synchron arbeitet und Kommunikationsressourcen bindet, dürfte der Aufruf für unterschiedliche Handles reentrant sein, sollte jedoch wegen möglicher Netzwerkinitialisierungen nicht in zeitkritischen Hard-Realtime-Schleifen ausgeführt werden.</p>
