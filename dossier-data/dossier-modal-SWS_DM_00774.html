<h4>Verwendung</h4>
<p>Die virtuelle Methode <code>ara::diag::ServiceValidation::Validate</code> wird für jede eingehende Diagnoseanforderungsnachricht aufgerufen <a class="spec-record-ref" data-req="SWS_DM_00774" href="../spec/record.html?id=SWS_DM_00774">[SWS_DM_00774]</a>. Der Diagnostic Server (DM) führt darüber konfigurierte herstellerspezifische <a class="spec-record-ref" data-req="SWS_DM_01252" href="../spec/record.html?id=SWS_DM_01252">[SWS_DM_01252]</a> sowie zuliefererspezifische Serviceprüfungen <a class="spec-record-ref" data-req="SWS_DM_01253" href="../spec/record.html?id=SWS_DM_01253">[SWS_DM_01253]</a> nach ISO 14229-1 aus. Die Zuordnung als Hersteller- oder Zuliefererprüfung richtet sich nach der Modellierung im Konstruktor <a class="spec-record-ref" data-req="SWS_DM_00772" href="../spec/record.html?id=SWS_DM_00772">[SWS_DM_00772]</a>.</p>
<p>Die Funktion nimmt die Diagnosedaten inklusive Service Identifier (SID) über <code>requestData</code> sowie Metainformationen über <code>metaInfo</code> entgegen <a class="spec-record-ref" data-req="SWS_DM_00774" href="../spec/record.html?id=SWS_DM_00774">[SWS_DM_00774]</a>. Der Puffer <code>requestData</code> bleibt gültig, bis das zurückgegebene <code>ara::core::Future&lt;void&gt;</code> über das zugehörige Promise erfüllt oder die Ausführung abgebrochen wird <a class="spec-record-ref" data-req="SWS_DM_00774" href="../spec/record.html?id=SWS_DM_00774">[SWS_DM_00774]</a>. Wird die Validierung erfolgreich ohne Fehler abgeschlossen, setzt der Diagnostic Server die Verarbeitung der Anforderung gemäß ISO 14229-1 fort <a class="spec-record-ref" data-req="SWS_DM_01254" href="../spec/record.html?id=SWS_DM_01254">[SWS_DM_01254]</a>.</p>
<h4>Fehlerbehandlung und Randbedingungen</h4>
<p>Schlägt die Prüfung fehl, ist ein passender NRC gemäß ISO 14229-1 mittels <code>DiagUdsNrcErrc</code> zurückzugeben <a class="spec-record-ref" data-req="SWS_DM_00774" href="../spec/record.html?id=SWS_DM_00774">[SWS_DM_00774]</a>. Liefert <code>Validate</code> den Fehler <code>kNoProcessingNoResponse</code>, verwirft die Instanz des Diagnostic Servers die Nachricht ohne weitere Antwort <a class="spec-record-ref" data-req="SWS_DM_00860" href="../spec/record.html?id=SWS_DM_00860">[SWS_DM_00860]</a>.</p>
<p>Hinsichtlich der Nebenläufigkeit ist <code>Validate</code> als ausnahmesicher (<em>exception safe</em>), jedoch als nicht threadsicher (<em>not thread-safe</em>) spezifiziert <a class="spec-record-ref" data-req="SWS_DM_00774" href="../spec/record.html?id=SWS_DM_00774">[SWS_DM_00774]</a>.
