<h4>Rolle des DEM im Diagnose-Stack</h4>
<p>Der Diagnostic Event Manager sammelt alle Diagnoseereignisse eines Steuergeräts. Pro ECU gibt es genau ein DEM-Modul <a class="spec-record-ref" data-req="SWS_Dem_00126" href="../../spec/record.html?id=SWS_Dem_00126">[SWS_Dem_00126]</a>. Jedes Ereignis wird durch eine eindeutige <code>EventId</code> und einen zugehörigen Namen dargestellt <a class="spec-record-ref" data-req="SWS_Dem_00153" href="../../spec/record.html?id=SWS_Dem_00153">[SWS_Dem_00153]</a>. Im Typ <code>Dem_EventIdType</code> ist der Wert 0 nicht zulässig <a class="spec-record-ref" data-req="SWS_Dem_00925" href="../../spec/record.html?id=SWS_Dem_00925">[SWS_Dem_00925]</a>. Auf der Eingangsseite melden SW-Cs und BSW-Module ihre Testergebnisse über <code>Dem_SetEventStatus</code> <a class="spec-record-ref" data-req="SWS_Dem_00183" href="../../spec/record.html?id=SWS_Dem_00183">[SWS_Dem_00183]</a>. Auf der Ausgangsseite nutzt der DCM den DEM, um Fehlercodes, Status und zugehörige Daten zu lesen und zu löschen <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DCM_SECTION_7_6_2_1_General_behavior_using_DEM_interfaces.html" data-snip="SNIP_CLASSIC_DCM_SECTION_7_6_2_1_General_behavior_using_DEM_interfaces">SWS DCM S. 103</a>.</p>
<p>Weitere Partner des DEM:</p>
<ul>
<li>Der NvM übernimmt die persistente Ablage <a class="spec-record-ref" data-req="SWS_Dem_00164" href="../../spec/record.html?id=SWS_Dem_00164">[SWS_Dem_00164]</a> <a class="spec-record-ref" data-req="SWS_Dem_00329" href="../../spec/record.html?id=SWS_Dem_00329">[SWS_Dem_00329]</a>.</li>
<li>Der FiM wird über Statusänderungen informiert <a class="spec-record-ref" data-req="SWS_Dem_00029" href="../../spec/record.html?id=SWS_Dem_00029">[SWS_Dem_00029]</a> <a class="spec-record-ref" data-req="SWS_Dem_01132" href="../../spec/record.html?id=SWS_Dem_01132">[SWS_Dem_01132]</a>.</li>
<li>Monitore werden über <code>InitMonitorForEvent</code> neu initialisiert, jeweils mit einem Grund aus <code>Dem_InitMonitorReasonType</code> <a class="spec-record-ref" data-req="SWS_Dem_00003" href="../../spec/record.html?id=SWS_Dem_00003">[SWS_Dem_00003]</a> <a class="spec-record-ref" data-req="SWS_Dem_00942" href="../../spec/record.html?id=SWS_Dem_00942">[SWS_Dem_00942]</a>.</li>
<li>Die J1939-Unterstützung steht zur Verfügung, wenn <code>DemGeneralJ1939</code> konfiguriert ist <a class="spec-record-ref" data-req="SWS_Dem_00845" href="../../spec/record.html?id=SWS_Dem_00845">[SWS_Dem_00845]</a>.</li>
</ul>

<h4>Hochlauf, Betrieb und Shutdown</h4>
<p>Der DEM unterscheidet zwischen einem vorinitialisierten Modus und dem voll initialisierten Betrieb <a class="spec-record-ref" data-req="SWS_Dem_00169" href="../../spec/record.html?id=SWS_Dem_00169">[SWS_Dem_00169]</a>.</p>
<ul>
<li><code>Dem_PreInit</code> initialisiert die internen Zustände, die für die Ereignisverarbeitung nötig sind <a class="spec-record-ref" data-req="SWS_Dem_00180" href="../../spec/record.html?id=SWS_Dem_00180">[SWS_Dem_00180]</a>. Dazu gehört die DEM-interne Entprellung <a class="spec-record-ref" data-req="SWS_Dem_01213" href="../../spec/record.html?id=SWS_Dem_01213">[SWS_Dem_01213]</a>.</li>
<li>Ab diesem Zeitpunkt sind entprellte Meldungen möglich <a class="spec-record-ref" data-req="SWS_Dem_01212" href="../../spec/record.html?id=SWS_Dem_01212">[SWS_Dem_01212]</a>.</li>
<li>Meldungen, die vor <code>Dem_Init</code> eintreffen, puffert der DEM in einer Warteschlange <a class="spec-record-ref" data-req="SWS_Dem_00167" href="../../spec/record.html?id=SWS_Dem_00167">[SWS_Dem_00167]</a>. Deren Größe ist konfigurierbar <a class="spec-record-ref" data-req="SWS_Dem_00207" href="../../spec/record.html?id=SWS_Dem_00207">[SWS_Dem_00207]</a> <a class="spec-record-ref" data-req="SWS_Dem_01079" href="../../spec/record.html?id=SWS_Dem_01079">[SWS_Dem_01079]</a>.</li>
<li>Diese frühen Meldungen lösen keine Monitorstatus-Callbacks aus <a class="spec-record-ref" data-req="SWS_Dem_01289" href="../../spec/record.html?id=SWS_Dem_01289">[SWS_Dem_01289]</a> <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_7_42.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_7_42">SWS DEM S. 169</a>.</li>
</ul>
<p><code>Dem_Init</code> erhält einen Zeiger auf <code>Dem_ConfigType</code> und initialisiert bzw. reinitialisiert das Modul <a class="spec-record-ref" data-req="SWS_Dem_00181" href="../../spec/record.html?id=SWS_Dem_00181">[SWS_Dem_00181]</a> <a class="spec-record-ref" data-req="SWS_Dem_00924" href="../../spec/record.html?id=SWS_Dem_00924">[SWS_Dem_00924]</a>.</p>
<ul>
<li>Erst dabei wird der Monitorstatus initialisiert. Vorher liefert <code>Dem_GetMonitorStatus</code> den Wert <code>E_NOT_OK</code> <a class="spec-record-ref" data-req="SWS_Dem_01326" href="../../spec/record.html?id=SWS_Dem_01326">[SWS_Dem_01326]</a>.</li>
<li>Nach <code>Dem_Init</code> ist der DEM voll betriebsbereit <a class="spec-record-ref" data-req="SWS_Dem_00340" href="../../spec/record.html?id=SWS_Dem_00340">[SWS_Dem_00340]</a>.</li>
<li>Ein vorher angeforderter Neustart eines Betriebszyklus wird erst danach verarbeitet <a class="spec-record-ref" data-req="SWS_Dem_01318" href="../../spec/record.html?id=SWS_Dem_01318">[SWS_Dem_01318]</a>.</li>
<li>Alle nicht ereignisgetriebenen Aufgaben erledigt <code>Dem_MainFunction</code> <a class="spec-record-ref" data-req="SWS_Dem_00125" href="../../spec/record.html?id=SWS_Dem_00125">[SWS_Dem_00125]</a> <a class="spec-record-ref" data-req="SWS_Dem_00266" href="../../spec/record.html?id=SWS_Dem_00266">[SWS_Dem_00266]</a>.</li>
<li><code>Dem_Shutdown</code> schließt offene Operationen ab <a class="spec-record-ref" data-req="SWS_Dem_00102" href="../../spec/record.html?id=SWS_Dem_00102">[SWS_Dem_00102]</a>. Geänderte nichtflüchtige Daten werden spätestens während des Shutdowns zum NVRAM angestoßen <a class="spec-record-ref" data-req="SWS_Dem_00341" href="../../spec/record.html?id=SWS_Dem_00341">[SWS_Dem_00341]</a>.</li>
</ul>

<h4>Vom Monitorergebnis zum qualifizierten Ereignis</h4>
<p><code>Dem_SetEventStatus</code> übermittelt Werte aus <code>Dem_EventStatusType</code> <a class="spec-record-ref" data-req="SWS_Dem_00926" href="../../spec/record.html?id=SWS_Dem_00926">[SWS_Dem_00926]</a>:</p>
<ul>
<li><code>DEM_EVENT_STATUS_PASSED</code> und <code>DEM_EVENT_STATUS_FAILED</code> sind bereits qualifizierte Ergebnisse.</li>
<li><code>…_PREPASSED</code> und <code>…_PREFAILED</code> sind Vorab-Ergebnisse, die der DEM intern entprellt <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_SECTION_8_6_1_9_Dem_EventStatusType.html" data-snip="SNIP_CLASSIC_DEM_SECTION_8_6_1_9_Dem_EventStatusType">SWS DEM S. 351</a>.</li>
</ul>
<p>Der Entprellalgorithmus wird je Ereignis konfiguriert <a class="spec-record-ref" data-req="SWS_Dem_00413" href="../../spec/record.html?id=SWS_Dem_00413">[SWS_Dem_00413]</a>. Zur Wahl stehen zählerbasiert <a class="spec-record-ref" data-req="SWS_Dem_00414" href="../../spec/record.html?id=SWS_Dem_00414">[SWS_Dem_00414]</a>, zeitbasiert <a class="spec-record-ref" data-req="SWS_Dem_00426" href="../../spec/record.html?id=SWS_Dem_00426">[SWS_Dem_00426]</a> oder monitorintern <a class="spec-record-ref" data-req="SWS_Dem_00437" href="../../spec/record.html?id=SWS_Dem_00437">[SWS_Dem_00437]</a>.</p>
<p>Zählerbasierte Entprellung:</p>
<ul>
<li>Vorab-Ergebnisse erhöhen bzw. verringern den internen Zähler um die konfigurierte Schrittweite <a class="spec-record-ref" data-req="SWS_Dem_00418" href="../../spec/record.html?id=SWS_Dem_00418">[SWS_Dem_00418]</a> <a class="spec-record-ref" data-req="SWS_Dem_00419" href="../../spec/record.html?id=SWS_Dem_00419">[SWS_Dem_00419]</a>.</li>
<li>Qualifizierte Ergebnisse setzen den Zähler direkt <a class="spec-record-ref" data-req="SWS_Dem_00420" href="../../spec/record.html?id=SWS_Dem_00420">[SWS_Dem_00420]</a> <a class="spec-record-ref" data-req="SWS_Dem_00421" href="../../spec/record.html?id=SWS_Dem_00421">[SWS_Dem_00421]</a>.</li>
<li>Schwellwerte legen den Fehler- bzw. Gutzustand fest <a class="spec-record-ref" data-req="SWS_Dem_00416" href="../../spec/record.html?id=SWS_Dem_00416">[SWS_Dem_00416]</a> <a class="spec-record-ref" data-req="SWS_Dem_00417" href="../../spec/record.html?id=SWS_Dem_00417">[SWS_Dem_00417]</a>.</li>
<li>Optional ist ein Sprungverhalten konfigurierbar <a class="spec-record-ref" data-req="SWS_Dem_00422" href="../../spec/record.html?id=SWS_Dem_00422">[SWS_Dem_00422]</a> <a class="spec-record-ref" data-req="SWS_Dem_00424" href="../../spec/record.html?id=SWS_Dem_00424">[SWS_Dem_00424]</a>.</li>
<li>Der Zähler wird linear auf den Fault Detection Counter (−128…+127) abgebildet <a class="spec-record-ref" data-req="SWS_Dem_00415" href="../../spec/record.html?id=SWS_Dem_00415">[SWS_Dem_00415]</a> <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_7_28.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_7_28">SWS DEM S. 108</a>.</li>
</ul>
<p>Bei der zeitbasierten Entprellung startet ein Vorab-Ergebnis einen Timer <a class="spec-record-ref" data-req="SWS_Dem_00428" href="../../spec/record.html?id=SWS_Dem_00428">[SWS_Dem_00428]</a> <a class="spec-record-ref" data-req="SWS_Dem_00432" href="../../spec/record.html?id=SWS_Dem_00432">[SWS_Dem_00432]</a>.</p>

Quellen: <a class="spec-record-ref" data-req="SWS_Dem_00415" href="../../spec/record.html?id=SWS_Dem_00415">[SWS_Dem_00415]</a>–<a class="spec-record-ref" data-req="SWS_Dem_00421" href="../../spec/record.html?id=SWS_Dem_00421">[SWS_Dem_00421]</a>, <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_7_28.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_7_28">SWS DEM S. 108</a>, <a class="spec-record-ref" data-req="SWS_Dem_00414" href="../../spec/record.html?id=SWS_Dem_00414">[SWS_Dem_00414]</a>, <a class="spec-record-ref" data-req="SWS_Dem_00424" href="../../spec/record.html?id=SWS_Dem_00424">[SWS_Dem_00424]</a>, <a class="spec-record-ref" data-req="SWS_Dem_00422" href="../../spec/record.html?id=SWS_Dem_00422">[SWS_Dem_00422]</a></p>
<p>Die Verarbeitung ist zweigeteilt:</p>
<ul>
<li>Synchron im Kontext des Aufrufers laufen die zählerbasierte Entprellung <a class="spec-record-ref" data-req="SWS_Dem_01279" href="../../spec/record.html?id=SWS_Dem_01279">[SWS_Dem_01279]</a> und die Bits 0 und 1 des Monitorstatus <a class="spec-record-ref" data-req="SWS_Dem_01280" href="../../spec/record.html?id=SWS_Dem_01280">[SWS_Dem_01280]</a>.</li>
<li>Den UDS-Status berechnet der DEM dagegen asynchron <a class="spec-record-ref" data-req="SWS_Dem_01285" href="../../spec/record.html?id=SWS_Dem_01285">[SWS_Dem_01285]</a>.</li>
</ul>
<p>Freigabe- und Speicherbedingungen:</p>
<ul>
<li>Freigabebedingungen werden je Ereignis geprüft <a class="spec-record-ref" data-req="SWS_Dem_00447" href="../../spec/record.html?id=SWS_Dem_00447">[SWS_Dem_00447]</a> und über <code>Dem_SetEnableCondition</code> gesetzt <a class="spec-record-ref" data-req="SWS_Dem_00201" href="../../spec/record.html?id=SWS_Dem_00201">[SWS_Dem_00201]</a>.</li>
<li>Solange eine Freigabebedingung nicht erfüllt ist, werden Meldungen nicht angenommen <a class="spec-record-ref" data-req="SWS_Dem_00449" href="../../spec/record.html?id=SWS_Dem_00449">[SWS_Dem_00449]</a> <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_6_10_DIAGNOSTICEXTRACTTEMPLATE.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_6_10_DIAGNOSTICEXTRACTTEMPLATE">DEXT S. 198</a>. Je nach <code>DemDebounceBehavior</code> wird die Entprellung dann zurückgesetzt oder eingefroren <a class="spec-record-ref" data-req="SWS_Dem_00654" href="../../spec/record.html?id=SWS_Dem_00654">[SWS_Dem_00654]</a> <a class="spec-record-ref" data-req="SWS_Dem_00655" href="../../spec/record.html?id=SWS_Dem_00655">[SWS_Dem_00655]</a>.</li>
<li>Speicherbedingungen steuern dagegen nur, ob das Ereignis im Speicher abgelegt wird <a class="spec-record-ref" data-req="SWS_Dem_00459" href="../../spec/record.html?id=SWS_Dem_00459">[SWS_Dem_00459]</a> <a class="spec-record-ref" data-req="SWS_Dem_00556" href="../../spec/record.html?id=SWS_Dem_00556">[SWS_Dem_00556]</a>.</li>
</ul>

<h4>Ereignisspeicher, Statusbyte und Betriebszyklen</h4>
<p>Der DEM führt standardmäßig alle UDS-Statusbits <a class="spec-record-ref" data-req="SWS_Dem_00006" href="../../spec/record.html?id=SWS_Dem_00006">[SWS_Dem_00006]</a>. Jeder Bitübergang ist einzeln festgelegt, etwa für TestFailed <a class="spec-record-ref" data-req="SWS_Dem_00386" href="../../spec/record.html?id=SWS_Dem_00386">[SWS_Dem_00386]</a>, ConfirmedDTC <a class="spec-record-ref" data-req="SWS_Dem_00391" href="../../spec/record.html?id=SWS_Dem_00391">[SWS_Dem_00391]</a> und WarningIndicatorRequested <a class="spec-record-ref" data-req="SWS_Dem_00395" href="../../spec/record.html?id=SWS_Dem_00395">[SWS_Dem_00395]</a> <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_7_19.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_7_19">SWS DEM S. 88</a>.</p>
<p>Aufbau des Ereignisspeichers:</p>
<ul>
<li>Es gibt einen Primärspeicher <a class="spec-record-ref" data-req="SWS_Dem_00010" href="../../spec/record.html?id=SWS_Dem_00010">[SWS_Dem_00010]</a> und optional benutzerdefinierte Speicher <a class="spec-record-ref" data-req="SWS_Dem_00548" href="../../spec/record.html?id=SWS_Dem_00548">[SWS_Dem_00548]</a>.</li>
<li>Diese sind in Ereignisspeicher-Sätzen organisiert <a class="spec-record-ref" data-req="SWS_Dem_01247" href="../../spec/record.html?id=SWS_Dem_01247">[SWS_Dem_01247]</a>.</li>
<li>Der Auslöser für das Anlegen eines Eintrags ist konfigurierbar <a class="spec-record-ref" data-req="SWS_Dem_00783" href="../../spec/record.html?id=SWS_Dem_00783">[SWS_Dem_00783]</a>–<a class="spec-record-ref" data-req="SWS_Dem_00786" href="../../spec/record.html?id=SWS_Dem_00786">[SWS_Dem_00786]</a> <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_7_27.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_7_27">SWS DEM S. 94</a>.</li>
</ul>
<p>Wenn der Speicher voll ist:</p>
<ul>
<li>Der DEM setzt eine Überlaufanzeige <a class="spec-record-ref" data-req="SWS_Dem_00397" href="../../spec/record.html?id=SWS_Dem_00397">[SWS_Dem_00397]</a>, die über <code>Dem_GetEventMemoryOverflow</code> lesbar ist <a class="spec-record-ref" data-req="SWS_Dem_00559" href="../../spec/record.html?id=SWS_Dem_00559">[SWS_Dem_00559]</a>.</li>
<li>Er sucht gemäß der Verdrängungsstrategie einen Kandidaten <a class="spec-record-ref" data-req="SWS_Dem_00400" href="../../spec/record.html?id=SWS_Dem_00400">[SWS_Dem_00400]</a> <a class="spec-record-ref" data-req="SWS_Dem_00401" href="../../spec/record.html?id=SWS_Dem_00401">[SWS_Dem_00401]</a>.</li>
<li>Gibt es keinen Kandidaten, verwirft er die Speicheranfrage <a class="spec-record-ref" data-req="SWS_Dem_00407" href="../../spec/record.html?id=SWS_Dem_00407">[SWS_Dem_00407]</a>.</li>
</ul>
<p>Freeze Frames und Extended Data Records werden je nach konfiguriertem Trigger erfasst <a class="spec-record-ref" data-req="SWS_Dem_00799" href="../../spec/record.html?id=SWS_Dem_00799">[SWS_Dem_00799]</a>–<a class="spec-record-ref" data-req="SWS_Dem_00802" href="../../spec/record.html?id=SWS_Dem_00802">[SWS_Dem_00802]</a> <a class="spec-record-ref" data-req="SWS_Dem_00809" href="../../spec/record.html?id=SWS_Dem_00809">[SWS_Dem_00809]</a>. Ein vorab gespeicherter Freeze Frame hat dabei Vorrang <a class="spec-record-ref" data-req="SWS_Dem_00464" href="../../spec/record.html?id=SWS_Dem_00464">[SWS_Dem_00464]</a>.</p>

<h4>Fehlerspeicherzugriff nach dem Prinzip „Auswählen und Abfragen“</h4>
<p>Viele DCM-Dienste arbeiten nach demselben Muster: Ein Client wählt zuerst einen DTC oder eine DTC-Gruppe aus und ruft dann Funktionen auf, die auf dieser Auswahl arbeiten <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_SECTION_7_11_2_2_Accessing_diagnostic_fault_memory.html" data-snip="SNIP_CLASSIC_DEM_SECTION_7_11_2_2_Accessing_diagnostic_fault_memory">SWS DEM S. 215</a>.</p>
<ul>
<li><code>Dem_SelectDTC</code> legt das Ziel unter anderem für <code>Dem_ClearDTC</code>, <code>Dem_GetStatusOfDTC</code> und <code>Dem_SelectFreezeFrameData</code> fest <a class="spec-record-ref" data-req="SWS_Dem_91016" href="../../spec/record.html?id=SWS_Dem_91016">[SWS_Dem_91016]</a> <a class="spec-record-ref" data-req="SWS_Dem_01253" href="../../spec/record.html?id=SWS_Dem_01253">[SWS_Dem_01253]</a>.</li>
<li>Die Auswahl bezieht sich auf den Ereignisspeicher, der der <code>ClientId</code> zugeordnet ist <a class="spec-record-ref" data-req="SWS_Dem_01254" href="../../spec/record.html?id=SWS_Dem_01254">[SWS_Dem_01254]</a>.</li>
<li>Clients mit unterschiedlicher <code>ClientId</code> dürfen parallel arbeiten <a class="spec-record-ref" data-req="SWS_Dem_01251" href="../../spec/record.html?id=SWS_Dem_01251">[SWS_Dem_01251]</a>.</li>
<li>Ruft derselbe Client <code>Dem_SelectDTC</code> erneut auf, während die vorige Operation noch läuft, erhält er <code>DEM_BUSY</code> <a class="spec-record-ref" data-req="SWS_Dem_01306" href="../../spec/record.html?id=SWS_Dem_01306">[SWS_Dem_01306]</a>.</li>
</ul>
<p>Lesen von Freeze Frames und Extended Data:</p>
<ul>
<li><code>Dem_SelectFreezeFrameData</code> und <code>Dem_SelectExtendedDataRecord</code> bauen auf der DTC-Auswahl auf <a class="spec-record-ref" data-req="SWS_Dem_01268" href="../../spec/record.html?id=SWS_Dem_01268">[SWS_Dem_01268]</a> <a class="spec-record-ref" data-req="SWS_Dem_01272" href="../../spec/record.html?id=SWS_Dem_01272">[SWS_Dem_01272]</a>.</li>
<li>Danach liefern Größen- und Next-Funktionen die Daten <a class="spec-record-ref" data-req="SWS_Dem_00074" href="../../spec/record.html?id=SWS_Dem_00074">[SWS_Dem_00074]</a> <a class="spec-record-ref" data-req="SWS_Dem_00071" href="../../spec/record.html?id=SWS_Dem_00071">[SWS_Dem_00071]</a> <a class="spec-record-ref" data-req="SWS_Dem_00075" href="../../spec/record.html?id=SWS_Dem_00075">[SWS_Dem_00075]</a>. Ein Freeze Frame hat das Format <code>{RecordNumber, NumOfDIDs, DID, data…}</code> <a class="docref internal-spec-ref" href="../../../spec/snippets/SNIP_CLASSIC_DEM_FIGURE_Figure_7_48.html" data-snip="SNIP_CLASSIC_DEM_FIGURE_Figure_7_48">SWS DEM S. 225</a>.</li>
<li>Ist ein gültiger, aber nicht gespeicherter Record angefordert, gibt der DEM <code>E_OK</code> mit leerem Puffer zurück <a class="spec-record-ref" data-req="SWS_Dem_00630" href="../../spec/record.html?id=SWS_Dem_00630">[SWS_Dem_00630]</a>.</li>
