<h4>Kontext</h4>
<p>Die Klasse <code>ara::shwa::Device</code> dient im Modul für sichere Hardwarebeschleunigung (Safe Hardware Acceleration) als primäre Abstraktion für physische Recheneinheiten <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_SafeHardwareAcceleration&amp;page=12">AUTOSAR_AP_SWS_SafeHardwareAcceleration S. 12</a>. Innerhalb der Adaptive Platform ermöglicht sie Adaptive Applications sowie anderen funktionalen Clustern den Zugriff auf und die Verwaltung von Beschleuniger-Ressourcen. Ein typisches Gesamtsystem kombiniert Instanzen von <code>Device</code> mit Ausführungswarteschlangen (Queues) und Speicherpuffern (Buffers), um rechenintensive Aufgaben strukturiert an Beschleunigerhardware zu delegieren <a class="docref internal-spec-ref" href="../spec/record.html?doc=SWS_SafeHardwareAcceleration&amp;page=22">SWS_SafeHardwareAcceleration S. 22</a>.</p>

<h4>Lebenszyklus</h4>
<p>Die Erzeugung von <code>ara::shwa::Device</code>-Objekten ist streng kontrolliert: Der Standardkonstruktor ist explizit gelöscht <a class="spec-record-ref" data-req="AP_SWS_SHWA_00302" href="../spec/record.html?id=AP_SWS_SHWA_00302">[AP_SWS_SHWA_00302]</a>. Instanzen können ausschließlich über die statischen Factory-Methoden <code>Create()</code> erzeugt werden, entweder ohne Parameter für ein Standardgerät <a class="spec-record-ref" data-req="AP_SWS_SHWA_00308" href="../spec/record.html?id=AP_SWS_SHWA_00308">[AP_SWS_SHWA_00308]</a> oder parametrisiert über ein Selektor-Objekt mittels <code>Create(const DeviceSelector&amp;)</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00309" href="../spec/record.html?id=AP_SWS_SHWA_00309">[AP_SWS_SHWA_00309]</a>. Beide Methoden liefern ein <code>ara::core::Result&lt;Device&gt;</code> zurück.</p>

<p>Hinsichtlich des Ressourcenbesitzes besitzt die Klasse reguläre Kopier- und Verschiebesemantik: Sowohl Kopierkonstruktor <a class="spec-record-ref" data-req="AP_SWS_SHWA_00303" href="../spec/record.html?id=AP_SWS_SHWA_00303">[AP_SWS_SHWA_00303]</a> und Kopierzuweisungsoperator <a class="spec-record-ref" data-req="AP_SWS_SHWA_00304" href="../spec/record.html?id=AP_SWS_SHWA_00304">[AP_SWS_SHWA_00304]</a> als auch Verschiebekonstruktor <a class="spec-record-ref" data-req="AP_SWS_SHWA_00305" href="../spec/record.html?id=AP_SWS_SHWA_00305">[AP_SWS_SHWA_00305]</a> und Verschiebezuweisungsoperator <a class="spec-record-ref" data-req="AP_SWS_SHWA_00306" href="../spec/record.html?id=AP_SWS_SHWA_00306">[AP_SWS_SHWA_00306]</a> sind als <code>noexcept=default</code> deklariert. Interpretation: Das Objekt dürfte intern als leichtgewichtiger Handle auf die eigentliche Hardware-Ressource ausgelegt sein, sodass Kopien unaufwändig und ausnahmesicher möglich sind. <a class="interp-q interp-q-open" data-q="Q-a6ff4d89f19b0f36" data-q-status="open" href="../versions.html?tab=q&amp;id=Q-a6ff4d89f19b0f36" title="Frage Q-a6ff4d89f19b0f36 (offen): Device fungiert intern vermutlich als leichtgewichtiger Deskriptor/Handle auf eine Hardware-Einheit">Frage Q-a6ff4d89f19b0f36 (offen)</a> Die Lebensdauer der physischen Hardwareschnittstelle ist an die Laufzeit des zugrundeliegenden Treibers bzw. Subsystems gekoppelt, während die Instanz auf Anwendungsebene wie ein regulärer Werttyp weitergegeben werden kann. Sämtliche Factory-Aufrufe und Methoden der Klasse sind als nicht threadsicher spezifiziert.</p>

<h4>Nutzungspfad</h4>
<p>Ein typischer Nutzungspfad beginnt mit der Instanziierung über eine der Factory-Methoden. Nach erfolgreicher Rückgabe wird die Instanz inspiziert, um die Art der Recheneinheit zu bestimmen und gerätespezifische Parameter abzufragen. Anschließend wird das Gerät typischerweise Warteschlangen und Puffern zugewiesen, um Verarbeitungsaufträge auszuführen.</p>

<li><strong>Instanziierung:</strong> Aufruf von <code>Create()</code> oder <code>Create(deviceSelector)</code> zur Bereitstellung des Geräts <a class="spec-record-ref" data-req="AP_SWS_SHWA_00308" href="../spec/record.html?id=AP_SWS_SHWA_00308">[AP_SWS_SHWA_00308]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00309" href="../spec/record.html?id=AP_SWS_SHWA_00309">[AP_SWS_SHWA_00309]</a>.</li>
<li><strong>Typprüfung:</strong> Validierung der Hardware-Kategorie über die Prädikate <code>IsCpu()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00310" href="../spec/record.html?id=AP_SWS_SHWA_00310">[AP_SWS_SHWA_00310]</a>, <code>IsGpu()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00311" href="../spec/record.html?id=AP_SWS_SHWA_00311">[AP_SWS_SHWA_00311]</a> oder <code>IsAccelerator()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00312" href="../spec/record.html?id=AP_SWS_SHWA_00312">[AP_SWS_SHWA_00312]</a>.</li>
<li><strong>Konfigurationsabfrage:</strong> Auslesen detaillierter Geräteinformationen über die Template-Methode <code>GetInfo&lt;InfoType&gt;()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00313" href="../spec/record.html?id=AP_SWS_SHWA_00313">[AP_SWS_SHWA_00313]</a>.</li>
</ol>

<h4>Fehlerszenarien</h4>
<p>Methoden von <code>ara::shwa::Device</code> kommunizieren Fehlerzustände deterministisch über den Fehlertyp <code>ara::core::Result</code>. Folgende Fehlerfälle sind spezifiziert:</p>

<ul>
<li><code>ShwaErrorCode::kResourceBusy</code>: Tritt auf, wenn eine Ressource zum Zeitpunkt der Anfrage belegt ist. Dies kann sowohl während der Instanz-Erzeugung <a class="spec-record-ref" data-req="AP_SWS_SHWA_00308" href="../spec/record.html?id=AP_SWS_SHWA_00308">[AP_SWS_SHWA_00308]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00309" href="../spec/record.html?id=AP_SWS_SHWA_00309">[AP_SWS_SHWA_00309]</a> als auch bei Prüfoperationen wie <code>IsCpu()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00310" href="../spec/record.html?id=AP_SWS_SHWA_00310">[AP_SWS_SHWA_00310]</a>, <code>IsGpu()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00311" href="../spec/record.html?id=AP_SWS_SHWA_00311">[AP_SWS_SHWA_00311]</a> oder <code>IsAccelerator()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00312" href="../spec/record.html?id=AP_SWS_SHWA_00312">[AP_SWS_SHWA_00312]</a> ausgelöst werden.</li>
<li><code>ShwaErrorCode::kFeatureNotSupported</code>: Wird gemeldet, wenn eine angeforderte Eigenschaft oder Gerätekonfiguration vom System nicht unterstützt wird. Dies betrifft die Erzeugungsmethoden <a class="spec-record-ref" data-req="AP_SWS_SHWA_00308" href="../spec/record.html?id=AP_SWS_SHWA_00308">[AP_SWS_SHWA_00308]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00309" href="../spec/record.html?id=AP_SWS_SHWA_00309">[AP_SWS_SHWA_00309]</a> sowie das Abfragen von Merkmalsstrukturen über <code>GetInfo&lt;InfoType&gt;()</code> <a class="spec-record-ref" data-req="AP_SWS_SHWA_00313" href="../spec/record.html?id=AP_SWS_SHWA_00313">[AP_SWS_SHWA_00313]</a>.</li>
</ul>
