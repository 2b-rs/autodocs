  <h4>Usage and Parameters</h4>
  <p>
    The call is made by BSW modules upon detection of a development error, passing the exact error context (<a class="spec-record-ref" data-req="SWS_Det_00009" href="../../spec/record.html?id=SWS_Det_00009">[SWS_Det_00009]</a>):

    <li><code>ApiId</code>: Identifier of the API service in which the error occurred.</li>
    <li><code>ErrorId</code>: Identifier of the specific development error according to the specification of the calling module.</li>
  </ul>
  <p>
    Formally, the function has the return type <code>Std_ReturnType</code>, but does not return any value; it possesses this type solely for compatibility with services and hooks (<a class="spec-record-ref" data-req="SWS_Det_00009" href="../../spec/record.html?id=SWS_Det_00009">[SWS_Det_00009]</a>). A classification into synchronous or asynchronous semantics is not applicable because <code>Det_ReportError</code> never returns to the caller according to the specification (<a class="spec-record-ref" data-req="SWS_Det_00009" href="../../spec/record.html?id=SWS_Det_00009">[SWS_Det_00009]</a>).

  <h4>Concurrency and execution</h4>
  <p>
