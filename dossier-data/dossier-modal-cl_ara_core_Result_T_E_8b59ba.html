<p class="ai-level ai-oneliner-lead" data-ai-level="1">Dient der fehlertoleranten Rückgabe einer Referenz auf ein vorhandenes Objekt oder eines aufgetretenen Fehlercodes.</p>
<div class="ai-level" data-ai-level="2">
<p>Die Spezialisierung <code>ara::core::Result&lt;T&amp;, E&gt;</code> kapselt entweder eine nicht besitzende Referenz auf ein erfolgreiches Operationsergebnis vom Typ <code>T&amp;</code> (<a class="spec-record-ref" data-req="SWS_CORE_00902" href="../spec/record.html?id=SWS_CORE_00902">[SWS_CORE_00902]</a>) oder einen aufgetretenen Fehlercode vom Typ <code>E</code>. Anwender prüfen das Vorliegen eines Werts typischerweise über <code>HasValue()</code> (<a class="spec-record-ref" data-req="SWS_CORE_00918" href="../spec/record.html?id=SWS_CORE_00918">[SWS_CORE_00918]</a>), bevor sie über Dereferenzierungsoperatoren oder <code>Value()</code> auf das referenzierte Zielobjekt zugreifen. Da die Instanz das referenzierte Objekt nicht selbst besitzt, dürfte der Aufrufer sicherstellen müssen, dass dieses während der gesamten Nutzungsdauer des Ergebnisses im Speicher gültig bleibt.</p>

<div class="ai-level" data-ai-level="4">
<h4>Kontext</h4>
<p>Die Vorlagenspezialisierung <code>ara::core::Result&lt;T&amp;, E&gt;</code> kapselt entweder eine Referenz auf ein erfolgreiches Operationsergebnis vom Typ <code>value_type</code> (<a class="spec-record-ref" data-req="SWS_CORE_00902" href="../spec/record.html?id=SWS_CORE_00902">[SWS_CORE_00902]</a>) oder einen Fehlerwert vom Typ <code>error_type</code> (<a class="spec-record-ref" data-req="SWS_CORE_00903" href="../spec/record.html?id=SWS_CORE_00903">[SWS_CORE_00903]</a>). Als standardisierte Rückgabestruktur im Modul <code>core</code> ermöglicht sie eine fehlerrobuste Programmierung ohne den zwingenden Einsatz von C++-Ausnahmen im regulären Ablauf. Gemäß Spezifikation erzwingt die Implementierung zur Übersetzungszeit, dass der Fehlertyp <code>E</code> dem Typ <code>ara::core::ErrorCode</code> entspricht; eine abweichende Belegung führt zu einem Übersetzungsfehler. Zu den Interaktionspartnern zählen datenliefernde Dienste, aufrufende Komponenten zur Ergebnisprüfung sowie das außerhalb verwaltete Zielobjekt, auf welches direkt über die gebundene Referenz zugegriffen wird.</p>

<h4>Lebenszyklus</h4>
<p>Eine Instanz wird deterministisch entweder mit einer Referenz auf einen bestehenden Lvalue oder mit einem Fehler initialisiert. Die Initialisierung mit einer Referenz erfolgt über den Konstruktor <a class="spec-record-ref" data-req="SWS_CORE_00908" href="../spec/record.html?id=SWS_CORE_00908">[SWS_CORE_00908]</a> oder die statische Fabrikmethode <code>FromValue</code> <a class="spec-record-ref" data-req="SWS_CORE_00904" href="../spec/record.html?id=SWS_CORE_00904">[SWS_CORE_00904]</a>; die Übergabe von Rvalues ist unzulässig. Fehlerzustände werden über Konstruktoren (<a class="spec-record-ref" data-req="SWS_CORE_00909" href="../spec/record.html?id=SWS_CORE_00909">[SWS_CORE_00909]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00910" href="../spec/record.html?id=SWS_CORE_00910">[SWS_CORE_00910]</a>) oder Fabriken wie <code>FromError</code> (<a class="spec-record-ref" data-req="SWS_CORE_00905" href="../spec/record.html?id=SWS_CORE_00905">[SWS_CORE_00905]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00906" href="../spec/record.html?id=SWS_CORE_00906">[SWS_CORE_00906]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00907" href="../spec/record.html?id=SWS_CORE_00907">[SWS_CORE_00907]</a>) erzeugt. Ein Standardkonstruktor existiert nicht. Kopier- und Verschiebekonstruktoren (<a class="spec-record-ref" data-req="SWS_CORE_00911" href="../spec/record.html?id=SWS_CORE_00911">[SWS_CORE_00911]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00912" href="../spec/record.html?id=SWS_CORE_00912">[SWS_CORE_00912]</a>) übernehmen den aktuellen Zustand einer anderen Instanz.</p>
<p>Hinsichtlich der Besitzverhältnisse bindet <code>Result&lt;T&amp;, E&gt;</code> lediglich eine Referenz und übernimmt kein Eigentum oder Lebensdauermanagement für das referenzierte Zielobjekt. Der Aufrufer dürfte daher gewährleisten müssen, dass das Zielobjekt über die gesamte Existenzdauer der Result-Instanz gültig bleibt. Zustandswechsel im laufenden Betrieb werden über Zuweisungsoperatoren (<a class="spec-record-ref" data-req="SWS_CORE_00914" href="../spec/record.html?id=SWS_CORE_00914">[SWS_CORE_00914]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00915" href="../spec/record.html?id=SWS_CORE_00915">[SWS_CORE_00915]</a>) durchgeführt, welche die interne Referenz auf das neue Ziel umbinden oder einen Fehler übertragen. Zudem versetzt <code>EmplaceError</code> <a class="spec-record-ref" data-req="SWS_CORE_00916" href="../spec/record.html?id=SWS_CORE_00916">[SWS_CORE_00916]</a> die Instanz direkt in einen Fehlerzustand, während <code>Swap</code> <a class="spec-record-ref" data-req="SWS_CORE_00917" href="../spec/record.html?id=SWS_CORE_00917">[SWS_CORE_00917]</a> die Inhalte zweier Instanzen tauscht. Der Destruktor <a class="spec-record-ref" data-req="SWS_CORE_00913" href="../spec/record.html?id=SWS_CORE_00913">[SWS_CORE_00913]</a> verhält sich trivial, sofern <code>E</code> trivial destruierbar ist. Parallele Lesezugriffe auf Wert oder Fehler sind threadsicher, während zustandsverändernde Operationen wie Zuweisungen, <code>Swap</code> oder <code>EmplaceError</code> nicht threadsicher sind.</p>

<h4>Nutzungspfad</h4>
<p>Der reguläre Ablauf umfasst die Zustandskontrolle sowie die zielgerichtete Auswertung:</p>
<ul>
<li><strong>Zustandsprüfung:</strong> Vor dem Zugriff prüft der Aufrufer über <code>HasValue()</code> <a class="spec-record-ref" data-req="SWS_CORE_00918" href="../spec/record.html?id=SWS_CORE_00918">[SWS_CORE_00918]</a> oder den Konvertierungsoperator <code>operator bool</code> <a class="spec-record-ref" data-req="SWS_CORE_00919" href="../spec/record.html?id=SWS_CORE_00919">[SWS_CORE_00919]</a>, ob ein Wert vorliegt.</li>
<li><strong>Direkter Zugriff:</strong> Im Erfolgsfall stellen <code>Value()</code> (<a class="spec-record-ref" data-req="SWS_CORE_00924" href="../spec/record.html?id=SWS_CORE_00924">[SWS_CORE_00924]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00925" href="../spec/record.html?id=SWS_CORE_00925">[SWS_CORE_00925]</a>), <code>operator*</code> (<a class="spec-record-ref" data-req="SWS_CORE_00920" href="../spec/record.html?id=SWS_CORE_00920">[SWS_CORE_00920]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00921" href="../spec/record.html?id=SWS_CORE_00921">[SWS_CORE_00921]</a>) und <code>operator-&gt;</code> (<a class="spec-record-ref" data-req="SWS_CORE_00922" href="../spec/record.html?id=SWS_CORE_00922">[SWS_CORE_00922]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00923" href="../spec/record.html?id=SWS_CORE_00923">[SWS_CORE_00923]</a>) die Referenz bzw. einen Zeiger auf das Zielobjekt bereit.</li>
<li><strong>Optionale und rückfallbasierte Zugriffe:</strong> Über <code>Ok()</code> (<a class="spec-record-ref" data-req="SWS_CORE_00926" href="../spec/record.html?id=SWS_CORE_00926">[SWS_CORE_00926]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00927" href="../spec/record.html?id=SWS_CORE_00927">[SWS_CORE_00927]</a>) kann die Referenz in ein <code>ara::core::Optional</code> überführt werden. Die Methode <code>ValueOr()</code> (<a class="spec-record-ref" data-req="SWS_CORE_00933" href="../spec/record.html?id=SWS_CORE_00933">[SWS_CORE_00933]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00934" href="../spec/record.html?id=SWS_CORE_00934">[SWS_CORE_00934]</a>) liefert eine Kopie des referenzierten Werts oder einen übergebenen Ersatzwert.</li>
<li><strong>Monadische Operationen:</strong> Mit <code>Bind()</code> <a class="spec-record-ref" data-req="SWS_CORE_00941" href="../spec/record.html?id=SWS_CORE_00941">[SWS_CORE_00941]</a> wird eine Transformationsfunktion auf die Referenz angewendet und das Ergebnis verpackt, während Fehler automatisch weitergeleitet werden. <code>Resolve()</code> (<a class="spec-record-ref" data-req="SWS_CORE_00939" href="../spec/record.html?id=SWS_CORE_00939">[SWS_CORE_00939]</a>, <a class="spec-record-ref" data-req="SWS_CORE_00940" href="../spec/record.html?id=SWS_CORE_00940">[SWS_CORE_00940]</a>) ruft bei Fehlern eine Ersatzfunktion auf, die eine kompatible Referenz bereitstellt.</li>
</ul>
