<h4>Kontext</h4>
<p>Die Klasse <code>ara::exec::FunctionGroupState</code> repräsentiert einen im AUTOSAR-Metamodell (ARXML) definierten Funktionsgruppenzustand. <h4>Lebenszyklus</h4>

<ul>
<li><strong>Kopieren:</strong> Ein Kopierkonstruktor <a class="spec-record-ref" data-req="SWS_EM_02325" href="../spec/record.html?id=SWS_EM_02325">[SWS_EM_02325]</a> und ein Kopierzuweisungsoperator <a class="spec-record-ref" data-req="SWS_EM_02330" href="../spec/record.html?id=SWS_EM_02330">[SWS_EM_02330]</a> ermöglichen das Duplizieren von Instanzen.</li>
<li><strong>Verschieben:</strong> Über den Move-Konstruktor <a class="spec-record-ref" data-req="SWS_EM_02331" href="../spec/record.html?id=SWS_EM_02331">[SWS_EM_02331]</a> und den Move-Zuweisungsoperator <a class="spec-record-ref" data-req="SWS_EM_02332" href="../spec/record.html?id=SWS_EM_02332">[SWS_EM_02332]</a> können Ressourcen effizient auf neue oder bestehende Instanzen übertragen werden.</li>
<li><strong>Zerstörung:</strong> Der Destruktor gibt die Ressourcen der Instanz ordnungsgemäß frei <a class="spec-record-ref" data-req="SWS_EM_02272" href="../spec/record.html?id=SWS_EM_02272">[SWS_EM_02272]</a>.</li>

<p>Hinsichtlich der Nebenläufigkeit ist die Erzeugung einer Instanz über den Konstruktor thread-safe <a class="spec-record-ref" data-req="SWS_EM_02324" href="../spec/record.html?id=SWS_EM_02324">[SWS_EM_02324]</a>.
