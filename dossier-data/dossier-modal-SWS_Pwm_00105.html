<p>Die kanalbezogene Benachrichtigungsfunktion <code>Pwm_Notification_&lt;#Channel&gt;</code> wird vom PWM-Modul synchron aufgerufen, sobald das für den jeweiligen Kanal konfigurierte Flankenereignis eintritt <a class="spec-record-ref" data-req="SWS_Pwm_00105" href="../../spec/record.html?id=SWS_Pwm_00105">[SWS_Pwm_00105]</a>. Die Funktion besitzt die Signatur <code>void Pwm_Notification_&lt;#Channel&gt;(void)</code>, nimmt keine Übergabeparameter entgegen und liefert keinen Rückgabewert <a class="spec-record-ref" data-req="SWS_Pwm_00105" href="../../spec/record.html?id=SWS_Pwm_00105">[SWS_Pwm_00105]</a>. Sie ist in der Datei <code>Pwm_Externals.h</code> deklariert und muss vom Anwender bereitgestellt werden <a class="spec-record-ref" data-req="SWS_Pwm_00105" href="../../spec/record.html?id=SWS_Pwm_00105">[SWS_Pwm_00105]</a>.</p>
  <p>Der Aufruf erfolgt in Abhängigkeit vom letzten Aufruf von <code>Pwm_EnableNotification</code> für den betreffenden Kanal <a class="spec-record-ref" data-req="SWS_Pwm_00105" href="../../spec/record.html?id=SWS_Pwm_00105">[SWS_Pwm_00105]</a>. Die auslösenden Ereignisse orientieren sich an den Werten von <code>Pwm_EdgeNotificationType</code>, welcher steigende (<code>PWM_RISING_EDGE</code>), fallende (<code>PWM_FALLING_EDGE</code>) oder beide Signalflanken (<code>PWM_BOTH_EDGES</code>) unterscheidet <a class="spec-record-ref" data-req="SWS_Pwm_00109" href="../../spec/record.html?id=SWS_Pwm_00109">[SWS_Pwm_00109]</a>. Vor der Signalerzeugung und Ereignisbenachrichtigung muss das PWM-Modul über <code>Pwm_Init</code> mit einer hardwareabhängigen <code>Pwm_ConfigType</code>-Struktur initialisiert worden sein <a class="spec-record-ref" data-req="SWS_Pwm_00095" href="../../spec/record.html?id=SWS_Pwm_00095">[SWS_Pwm_00095]</a>, <a class="spec-record-ref" data-req="SWS_Pwm_00111" href="../../spec/record.html?id=SWS_Pwm_00111">[SWS_Pwm_00111]</a>.</p>
  <p>Hinsichtlich der Nebenläufigkeit ist die Reentranz der Callback-Funktion explizit als anwenderabhängig definiert (<code>PWM user implementation dependant</code>) <a class="spec-record-ref" data-req="SWS_Pwm_00105" href="../../spec/record.html?id=SWS_Pwm_00105">[SWS_Pwm_00105]</a>.
