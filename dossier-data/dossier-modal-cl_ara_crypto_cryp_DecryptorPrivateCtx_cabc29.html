<h4>Context</h4>
<p>The interface <code>ara::crypto::cryp::DecryptorPrivateCtx</code> defines the standardized interface for asymmetric decryption in the cryptography module of the AUTOSAR Adaptive Platform. The class performs the transformation of received ciphertext into plaintext using asymmetric cryptographic methods.</p>
<p>Central interaction partners of the context are:</p>
<ul>
<li><strong>Caller (application):</strong> Controls the initialization, configures key objects, queries required buffer capacities, and passes data blocks for processing.</li>
<li><strong>Key material:</strong> The context binds asymmetric keys for decryption either directly as a <code>PrivateKey</code> object via <a class="spec-record-ref" data-req="SWS_CRYPT_50157" href="../spec/record.html?id=SWS_CRYPT_50157">[SWS_CRYPT_50157]</a> or indirectly via a persistent or volatile key slot <code>KeySlot</code> via <a class="spec-record-ref" data-req="SWS_CRYPT_50066" href="../spec/record.html?id=SWS_CRYPT_50066">[SWS_CRYPT_50066]</a>.</li>
<li><strong>Memory buffers:</strong> Data is transported via buffer areas of type <code>ReadOnlyMemRegion</code> (ciphertext input) and <code>ReadWriteMemRegion</code> (plaintext output).</li>
</ul>
<p>Management and the lifecycle of the context are performed via the provided smart pointer type <code>Sptr</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50156" href="../spec/record.html?id=SWS_CRYPT_50156">[SWS_CRYPT_50156]</a>). Since <code>DecryptorPrivateCtx</code> is structured as a pure virtual interface, the creation of concrete instances is likely performed via corresponding factory methods of a higher-level crypto provider.</p>

<h4>Lifecycle</h4>
<p>From its creation to the execution of cryptographic transformations, the context passes through a sequence of deterministic states:</p>
<ul>
<li><strong>Not initialized (Uninitialized):</strong> After creation, the context does not yet have a key assignment. Calling operational decryption methods or buffer queries directly in this state fails with error code <code>ara::crypto::CryptoErrc::kUninitializedContext</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50159" href="../spec/record.html?id=SWS_CRYPT_50159">[SWS_CRYPT_50159]</a>).</li>
<li><strong>Key configured (Ready):</strong> By assigning a key using <code>SetKey()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50157" href="../spec/record.html?id=SWS_CRYPT_50157">[SWS_CRYPT_50157]</a> or <a class="spec-record-ref" data-req="SWS_CRYPT_50066" href="../spec/record.html?id=SWS_CRYPT_50066">[SWS_CRYPT_50066]</a>), the context transitions to operational readiness. In this state, chunk sizes can be queried (<a class="spec-record-ref" data-req="SWS_CRYPT_50071" href="../spec/record.html?id=SWS_CRYPT_50071">[SWS_CRYPT_50071]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50160" href="../spec/record.html?id=SWS_CRYPT_50160">[SWS_CRYPT_50160]</a>), buffer sizes can be calculated (<a class="spec-record-ref" data-req="SWS_CRYPT_50159" href="../spec/record.html?id=SWS_CRYPT_50159">[SWS_CRYPT_50159]</a>), single-step decryptions can be executed (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>), or streaming operations can be initiated (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>).</li>
<li><strong>Streaming processing active (Processing):</strong> Calling <code>Start()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>) opens a multi-step decryption. Data is decrypted iteratively with <code>Update()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50158" href="../spec/record.html?id=SWS_CRYPT_50158">[SWS_CRYPT_50158]</a>). The sequence terminates either regularly via <code>Finish()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>) or prematurely via <code>Cancel()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50069" href="../spec/record.html?id=SWS_CRYPT_50069">[SWS_CRYPT_50069]</a>).</li>
</ul>
<p>Interpretation: After regular completion via <code>Finish()</code> or after cancellation via <code>Cancel()</code>, the context presumably transitions back to the configured state (Ready), so that a subsequent decryption can be executed with the existing key.</p>
<p>With regard to concurrency and fault tolerance, all methods of the interface are specified as <code>thread-safe</code> and <code>exception safe</code>.</p>

<h4>Usage Path</h4>
<p>The interface supports two typical usage modes for decrypting ciphertext:</p>
<p><strong>1. Single-step decryption (Single-Call):</strong></p>
<ol>
<li><strong>Key assignment:</strong> Configuration of the context with a private key via <code>SetKey()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50157" href="../spec/record.html?id=SWS_CRYPT_50157">[SWS_CRYPT_50157]</a> or <a class="spec-record-ref" data-req="SWS_CRYPT_50066" href="../spec/record.html?id=SWS_CRYPT_50066">[SWS_CRYPT_50066]</a>).</li>
<li><strong>Buffer dimensioning:</strong> Querying the maximum and minimum processable input sizes via <code>GetMaximumChunkSize()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50071" href="../spec/record.html?id=SWS_CRYPT_50071">[SWS_CRYPT_50071]</a>) and <code>GetMinimumChunkSize()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50160" href="../spec/record.html?id=SWS_CRYPT_50160">[SWS_CRYPT_50160]</a>). Determining the required output capacity via <code>GetRequiredOutputBufferSize(inputSize, true)</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50159" href="../spec/record.html?id=SWS_CRYPT_50159">[SWS_CRYPT_50159]</a>).</li>
<li><strong>Execution:</strong> Call of <code>Decrypt(in, out)</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>). Upon successful execution, the result provides the plaintext size actually written to the output buffer.</li>
</ol>
<p><strong>2. Multi-step streaming decryption:</strong></p>
<ol>
<li><strong>Initialization:</strong> After key assignment, the streaming operation is initiated with <code>Start()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>).</li>
<li><strong>Chunk processing:</strong> Sequential passing of ciphertext chunks to <code>Update(in, out)</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50158" href="../spec/record.html?id=SWS_CRYPT_50158">[SWS_CRYPT_50158]</a>). The output buffer can be dimensioned in advance via <code>GetRequiredOutputBufferSize(chunkSize, false)</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50159" href="../spec/record.html?id=SWS_CRYPT_50159">[SWS_CRYPT_50159]</a>).</li>
<li><strong>Finalization or cancellation:</strong> Processing of the last data block and completion of the decryption via <code>Finish(in, out)</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>). If an ongoing operation is to be discarded, cancellation is performed via <code>Cancel()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50069" href="../spec/record.html?id=SWS_CRYPT_50069">[SWS_CRYPT_50069]</a>).</li>
</ol>

<h4>Error Scenarios</h4>
<p>Methods of <code>DecryptorPrivateCtx</code> return errors via <code>ara::core::Result</code> and have rollback semantics, so that the state is consistently reset in the event of an error:</p>
<ul>
<li><strong>State errors:</strong>
<ul>
<li><code>ara::crypto::CryptoErrc::kUninitializedContext</code>: Occurs with <code>Start()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>), <code>Decrypt()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>), or <code>GetRequiredOutputBufferSize()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50159" href="../spec/record.html?id=SWS_CRYPT_50159">[SWS_CRYPT_50159]</a>) if no key was assigned beforehand.</li>
<li><code>ara::crypto::CryptoErrc::kProcessingNotStarted</code>: Is returned by <code>Update()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50158" href="../spec/record.html?id=SWS_CRYPT_50158">[SWS_CRYPT_50158]</a>), <code>Finish()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>), and <code>Cancel()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50069" href="../spec/record.html?id=SWS_CRYPT_50069">[SWS_CRYPT_50069]</a>) if no streaming operation with <code>Start()</code> is active.</li>
</ul>
</li>
<li><strong>Key and permission errors:</strong>
<ul>
<li><code>ara::crypto::CryptoErrc::kUsageViolation</code>: Occurs if the key usage rules of the provided key do not permit data decryption (<code>kAllowData Decryption</code>) (<a class="spec-record-ref" data-req="SWS_CRYPT_50157" href="../spec/record.html?id=SWS_CRYPT_50157">[SWS_CRYPT_50157]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>).</li>
<li><code>ara::crypto::CryptoErrc::kIncompatibleObject</code>: Indicates that the provided key or KeySlot is incompatible with the requested decryption transformation (<a class="spec-record-ref" data-req="SWS_CRYPT_50066" href="../spec/record.html?id=SWS_CRYPT_50066">[SWS_CRYPT_50066]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50157" href="../spec/record.html?id=SWS_CRYPT_50157">[SWS_CRYPT_50157]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>).</li>
<li><code>ara::crypto::CryptoErrc::kEmptyKeySlot</code>: Occurs with <code>Start()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>) or <code>Decrypt()</code> (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>) if a configured <code>KeySlot</code> does not contain a key at the time of processing.</li>
</ul>
</li>
<li><strong>Buffer and parameter errors:</strong>
<ul>
<li><code>ara::crypto::CryptoErrc::kInsufficientCapacity</code>: The output buffer <code>out</code> is insufficient for the result (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50158" href="../spec/record.html?id=SWS_CRYPT_50158">[SWS_CRYPT_50158]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>).</li>
<li><code>ara::crypto::CryptoErrc::kInvalidInputSize</code>: The input size of the buffer <code>in</code> cannot be processed by the context (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50158" href="../spec/record.html?id=SWS_CRYPT_50158">[SWS_CRYPT_50158]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>).</li>
<li><code>ara::crypto::CryptoErrc::kInvalidArgument</code>: The provided input data contains incorrect or invalid values (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>).</li>
</ul>
</li>
<li><strong>Resource and configuration constraints:</strong>
<ul>
<li><code>ara::crypto::CryptoErrc::kBusyResource</code>: A hardware or software resource required for the cryptographic computation is busy (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>).</li>
<li><code>ara::crypto::CryptoErrc::kUnsupported</code>: The specific context implementation does not support the respective mode, such as single-call decryption (<a class="spec-record-ref" data-req="SWS_CRYPT_50070" href="../spec/record.html?id=SWS_CRYPT_50070">[SWS_CRYPT_50070]</a>), streaming processing (<a class="spec-record-ref" data-req="SWS_CRYPT_50067" href="../spec/record.html?id=SWS_CRYPT_50067">[SWS_CRYPT_50067]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50158" href="../spec/record.html?id=SWS_CRYPT_50158">[SWS_CRYPT_50158]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50068" href="../spec/record.html?id=SWS_CRYPT_50068">[SWS_CRYPT_50068]</a>), or the chosen key assignment type (<a class="spec-record-ref" data-req="SWS_CRYPT_50066" href="../spec/record.html?id=SWS_CRYPT_50066">[SWS_CRYPT_50066]</a>, <a class="spec-record-ref" data-req="SWS_CRYPT_50157" href="../spec/record.html?id=SWS_CRYPT_50157">[SWS_CRYPT_50157]</a>).</li>
</ul>
</li>
</ul>
