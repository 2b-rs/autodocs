<p class="ai-level ai-oneliner-lead" data-ai-level="1">Bietet eine effiziente, nicht-besitzende Sicht auf zusammenhängende Speicherbereiche beliebiger Container oder Puffer.</p>
<div class="ai-level" data-ai-level="2">
<p>Die Klasse <code>ara::core::Span</code> stellt eine nicht-besitzende, zusammenhängende Sicht auf Speicherbereiche bereit und erlaubt die effiziente Kapselung von Arrays oder Puffern ohne Kopierkosten <a class="spec-record-ref" data-req="SWS_CORE_01942" href="../spec/record.html?id=SWS_CORE_01942">[SWS_CORE_01942]</a>. Anwendungen nutzen die Klasse typischerweise zur Übergabe von Datenfenstern sowie zur Erzeugung von Teilsichten mittels Slicing-Operationen. Aufrufer müssen strikt sicherstellen, dass die Lebensdauer des zugrundeliegenden Speichers die der Sicht überdauert und dass bei Operationen wie <code>subspan()</code> gültige Grenzen eingehalten werden, da Grenzverletzungen undefiniertes Verhalten auslösen <a class="spec-record-ref" data-req="SWS_CORE_01966" href="../spec/record.html?id=SWS_CORE_01966">[SWS_CORE_01966]</a>.</p>

<h4>Kontext</h4>
<p>Die Klasse <code>ara::core::Span</code> stellt eine standardkonforme Implementierung einer zusammenhängenden Sequenzansicht dar, die sich an <code>std::span</code> aus <code>[views.span]</code> orientiert. Als leichtgewichtige Abstraktion kapselt sie einen Zeiger auf das erste Element sowie die Anzahl der verfügbaren Elemente, ohne selbst Eigentümer der Daten zu sein. Sie dient als einheitliche Schnittstelle zwischen Komponenten, die Daten bereitstellen, und Algorithmen, die diese Daten verarbeiten.</p>
<p>Zu den primären Interaktionspartnern gehören:</p>
<ul>
<li><strong>Aufrufende Anwendungslogik:</strong> Nutzt die Sicht für Lese- oder Schreibzugriffe auf sequenzielle Speicherbereiche ohne Speicherallokationen oder Kopieraufwand.</li>
<li><strong>Speicherquellen und Container:</strong> Beliebige zusammenhängende Speicherbereiche wie native C-Arrays <a class="spec-record-ref" data-req="SWS_CORE_01944" href="../spec/record.html?id=SWS_CORE_01944">[SWS_CORE_01944]</a>, standardisierte Plattform-Container wie <code>ara::core::Array</code> <a class="spec-record-ref" data-req="SWS_CORE_01945" href="../spec/record.html?id=SWS_CORE_01945">[SWS_CORE_01945]</a> <a class="spec-record-ref" data-req="SWS_CORE_01946" href="../spec/record.html?id=SWS_CORE_01946">[SWS_CORE_01946]</a>, generische Containerstrukturen <a class="spec-record-ref" data-req="SWS_CORE_01947" href="../spec/record.html?id=SWS_CORE_01947">[SWS_CORE_01947]</a> <a class="spec-record-ref" data-req="SWS_CORE_01948" href="../spec/record.html?id=SWS_CORE_01948">[SWS_CORE_01948]</a> oder rohe Puffer mit Zeiger und Längenangabe <a class="spec-record-ref" data-req="SWS_CORE_01942" href="../spec/record.html?id=SWS_CORE_01942">[SWS_CORE_01942]</a>.</li>
<li><strong>Teilsichten (Subspans):</strong> Weitere Instanzen von <code>ara::core::Span</code>, die durch Zerlegung aus einer übergeordneten Sicht hervorgehen <a class="spec-record-ref" data-req="SWS_CORE_01965" href="../spec/record.html?id=SWS_CORE_01965">[SWS_CORE_01965]</a> <a class="spec-record-ref" data-req="SWS_CORE_01966" href="../spec/record.html?id=SWS_CORE_01966">[SWS_CORE_01966]</a>.</li>
</ul>

<h4>Lebenszyklus</h4>
<p>Instanzen von <code>ara::core::Span</code> sind als reine Werteobjekte ohne eigene Ressourcenverwaltung konzipiert. Die Erzeugung erfolgt wahlweise als leerer Span über den Standardkonstruktor <a class="spec-record-ref" data-req="SWS_CORE_01941" href="../spec/record.html?id=SWS_CORE_01941">[SWS_CORE_01941]</a>, durch direkte Angabe von Startadresse und Elementanzahl <a class="spec-record-ref" data-req="SWS_CORE_01942" href="../spec/record.html?id=SWS_CORE_01942">[SWS_CORE_01942]</a> oder über ein Zeigerintervall aus Anfang und Ende <a class="spec-record-ref" data-req="SWS_CORE_01943" href="../spec/record.html?id=SWS_CORE_01943">[SWS_CORE_01943]</a>. Zudem stehen typisierte Konstruktoren für C-Arrays <a class="spec-record-ref" data-req="SWS_CORE_01944" href="../spec/record.html?id=SWS_CORE_01944">[SWS_CORE_01944]</a>, Container des Typs <code>ara::core::Array</code> <a class="spec-record-ref" data-req="SWS_CORE_01945" href="../spec/record.html?id=SWS_CORE_01945">[SWS_CORE_01945]</a> <a class="spec-record-ref" data-req="SWS_CORE_01946" href="../spec/record.html?id=SWS_CORE_01946">[SWS_CORE_01946]</a> sowie generische Container <a class="spec-record-ref" data-req="SWS_CORE_01947" href="../spec/record.html?id=SWS_CORE_01947">[SWS_CORE_01947]</a> <a class="spec-record-ref" data-req="SWS_CORE_01948" href="../spec/record.html?id=SWS_CORE_01948">[SWS_CORE_01948]</a> zur Verfügung. Bestehende Spans lassen sich per Standard-Kopierkonstruktor <a class="spec-record-ref" data-req="SWS_CORE_01949" href="../spec/record.html?id=SWS_CORE_01949">[SWS_CORE_01949]</a> oder über konvertierende Konstruktoren mit kompatiblen Elementtypen und Extents duplizieren <a class="spec-record-ref" data-req="SWS_CORE_01950" href="../spec/record.html?id=SWS_CORE_01950">[SWS_CORE_01950]</a>.</p>
<p>Da <code>ara::core::Span</code> keinerlei Besitz an den referenzierten Daten übernimmt, besitzt der Destruktor die Standard-Implementierung und ist als <code>noexcept=default</code> spezifiziert <a class="spec-record-ref" data-req="SWS_CORE_01951" href="../spec/record.html?id=SWS_CORE_01951">[SWS_CORE_01951]</a>. Daraus ergibt sich die fundamentale Invariante (Interpretation: Annahme 1), dass die Lebensdauer des zugrundeliegenden Speicherpuffers stets mindestens die Lebensdauer aller darauf verweisenden Span-Objekte umfassen muss; bei Zerstörung des Puffers werden verbleibende Spans ungültig. Die Zuweisung über den Zuweisungsoperator erfolgt trivial per Flachkopie <a class="spec-record-ref" data-req="SWS_CORE_01952" href="../spec/record.html?id=SWS_CORE_01952">[SWS_CORE_01952]</a>. Da sämtliche Zugriffsfunktionen als <code>noexcept</code> deklariert sind und keine internen Synchronisationsmechanismen besitzen, dürfte der gleichzeitige lesende Zugriff auf dieselbe Span-Instanz aus mehreren Threads sicher sein, sofern der zugrundeliegende Speicherbereich nicht parallel modifiziert wird (Interpretation: Annahme 2).</p>

<h4>Nutzungspfad</h4>
<p>Ein typischer Anwendungsfall umfasst das Kapseln eines vorhandenen Datenblocks, das Prüfen von Dimensionen, die Extraktion relevanter Abschnitte und den Zugriff auf die Elemente:</p>
<ol>
<li><strong>Sichterzeugung:</strong> Die Anwendung instanziiert <code>ara::core::Span</code> auf einem zusammenhängenden Puffer, etwa aus einer Instanz von <code>ara::core::Array</code> <a class="spec-record-ref" data-req="SWS_CORE_01945" href="../spec/record.html?id=SWS_CORE_01945">[SWS_CORE_01945]</a> oder über Rohdatenzeiger mit Längenangabe <a class="spec-record-ref" data-req="SWS_CORE_01942" href="../spec/record.html?id=SWS_CORE_01942">[SWS_CORE_01942]</a>.</li>
<li><strong>Zustands- und Dimensionsprüfung:</strong> Vor der Weiterverarbeitung wird die Dimensionierung über <code>empty()</code> <a class="spec-record-ref" data-req="SWS_CORE_01969" href="../spec/record.html?id=SWS_CORE_01969">[SWS_CORE_01969]</a>, <code>size()</code> <a class="spec-record-ref" data-req="SWS_CORE_01967" href="../spec/record.html?id=SWS_CORE_01967">[SWS_CORE_01967]</a> oder <code>size_bytes()</code> <a class="spec-record-ref" data-req="SWS_CORE_01968" href="../spec/record.html?id=SWS_CORE_01968">[SWS_CORE_01968]</a> verifiziert, oder die Basisadresse wird mittels <code>data()</code> <a class="spec-record-ref" data-req="SWS_CORE_01971" href="../spec/record.html?id=SWS_CORE_01971">[SWS_CORE_01971]</a> abgefragt.</li>
<li><strong>Slicing / Subspan-Bildung:</strong> Zur Fokussierung auf relevante Datenfenster erzeugt die Anwendung Teilsichten über Präfixe mit <code>first()</code> <a class="spec-record-ref" data-req="SWS_CORE_01961" href="../spec/record.html?id=SWS_CORE_01961">[SWS_CORE_01961]</a> <a class="spec-record-ref" data-req="SWS_CORE_01962" href="../spec/record.html?id=SWS_CORE_01962">[SWS_CORE_01962]</a>, Suffixe mit <code>last()</code> <a class="spec-record-ref" data-req="SWS_CORE_01963" href="../spec/record.html?id=SWS_CORE_01963">[SWS_CORE_01963]</a> <a class="spec-record-ref" data-req="SWS_CORE_01964" href="../spec/record.html?id=SWS_CORE_01964">[SWS_CORE_01964]</a> oder beliebige Teilbereiche mittels <code>subspan()</code> <a class="spec-record-ref" data-req="SWS_CORE_01965" href="../spec/record.html?id=SWS_CORE_01965">[SWS_CORE_01965]</a> <a class="spec-record-ref" data-req="SWS_CORE_01966" href="../spec/record.html?id=SWS_CORE_01966">[SWS_CORE_01966]</a>.</li>
<li><strong>Elementverarbeitung:</strong> Der eigentliche Datenzugriff erfolgt wahlfrei über den Indexoperator <code>operator[]</code> <a class="spec-record-ref" data-req="SWS_CORE_01970" href="../spec/record.html?id=SWS_CORE_01970">[SWS_CORE_01970]</a>, Randelementzugriffe über <code>front()</code> <a class="spec-record-ref" data-req="SWS_CORE_01959" href="../spec/record.html?id=SWS_CORE_01959">[SWS_CORE_01959]</a> und <code>back()</code> <a class="spec-record-ref" data-req="SWS_CORE_01960" href="../spec/record.html?id=SWS_CORE_01960">[SWS_CORE_01960]</a> oder sequenziell über Iteratoren von <code>begin()</code> bis <code>end()</code> <a class="spec-record-ref" data-req="SWS_CORE_01972" href="../spec/record.html?id=SWS_CORE_01972">[SWS_CORE_01972]</a> <a class="spec-record-ref" data-req="SWS_CORE_01973" href="../spec/record.html?id=SWS_CORE_01973">[SWS_CORE_01973]</a>.</li>
</ol>

<h4>Fehlerszenarien</h4>
<p>Alle Methoden von <code>ara::core::Span</code> sind als ausnahmesicher und <code>noexcept</code> deklariert; es werden weder C++-Exceptions ausgelöst noch Fehlerobjekte wie <code>ara::core::ErrorCode</code> zurückgegeben. Fehlerzustände resultieren primär aus Verletzungen von Vorbedingungen, die unmittelbar zu undefiniertem Verhalten (Undefined Behavior) führen:</p>
<ul>
<li><strong>Größenüberschreitung bei Präfixen und Suffixen:</strong> Wird bei <code>first()</code> eine Anzahl angefordert, die die aktuelle Größe übersteigt (<code>Count &gt; size()</code> bzw. <code>count &gt; size()</code>), ist das Verhalten undefiniert <a class="spec-record-ref" data-req="SWS_CORE_01961" href="../spec/record.html?id=SWS_CORE_01961">[SWS_CORE_01961]</a> <a class="spec-record-ref" data-req="SWS_CORE_01962" href="../spec/record.html?id=SWS_CORE_01962">[SWS_CORE_01962]</a>.
