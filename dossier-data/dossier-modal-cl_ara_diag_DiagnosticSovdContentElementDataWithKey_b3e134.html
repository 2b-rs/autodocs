<h4>Kontext</h4>
<p>Die Klasse <code>ara::diag::DiagnosticSovdContentElementDataWithKey</code> dient innerhalb der Adaptive Platform als Datenkapsel für ein einzelnes Diagnose-Inhaltselement im Kontext von ASAM SOVD (Service-Oriented Vehicle Diagnostics) und ordnet einem Nutzdatenobjekt einen eindeutigen Schlüsselbezeichner zu <a class="spec-record-ref" data-req="SWS_DM_02375" href="../spec/record.html?id=SWS_DM_02375">[SWS_DM_02375]</a>. SOVD-Daten werden über das Modellelement <code>DiagnosticSovdContent</code> strukturiert, welches sich aus mindestens einem <code>DiagnosticSovdContentElement</code> zusammensetzt <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=205">AUTOSAR_AP_SWS_Diagnostics §7.3.3.3.2 „SOVD Data – Conversion“</a>. Während Leseabfragen über <code>GenericDiagnosticSovdContent::Read</code> abgewickelt werden <a class="spec-record-ref" data-req="SWS_DM_01432" href="../spec/record.html?id=SWS_DM_01432">[SWS_DM_01432]</a>, interagiert die Klasse primär mit dem Diagnostic Management (DM) und der Serviceschnittstelle <code>GenericDiagnosticSovdContent::Write</code>, um strukturierte Schreibzugriffe auf Datenressourcen auszuführen <a class="spec-record-ref" data-req="SWS_DM_01431" href="../spec/record.html?id=SWS_DM_01431">[SWS_DM_01431]</a>, <a class="spec-record-ref" data-req="SWS_DM_02166" href="../spec/record.html?id=SWS_DM_02166">[SWS_DM_02166]</a>.</p>

<h4>Lebenszyklus</h4>
<p>Die Instanziierung und Zerstörung von <code>ara::diag::DiagnosticSovdContentElementDataWithKey</code> erfolgt unter Einhaltung des RAII-Prinzips. Der Destruktor sowie die zugehörigen Kopier- und Verschiebeoperationen (Move-/Copy-Konstruktoren und Zuweisungsoperatoren) sind explizit als <code>noexcept</code> deklariert <a class="spec-record-ref" data-req="SWS_DM_02376" href="../spec/record.html?id=SWS_DM_02376">[SWS_DM_02376]</a>. Bezüglich des Besitzverhältnisses übernimmt die Klasse den Nutzdateninhalt per Wertübergabe in <code>SetContent</code> <a class="spec-record-ref" data-req="SWS_DM_02381" href="../spec/record.html?id=SWS_DM_02381">[SWS_DM_02381]</a>, während der Schlüsselname als <code>ara::core::StringView</code> übergeben wird <a class="spec-record-ref" data-req="SWS_DM_02378" href="../spec/record.html?id=SWS_DM_02378">[SWS_DM_02378]</a>. Das Diagnostic Management dürfte intern sicherstellen, dass die zugrunde liegende Zeichenkette während des Zugriffs gültig bleibt oder in internen Speicher kopiert wird. Alle Elementfunktionen der Klasse sind laut Spezifikation threadsicher und exceptionsicher ausgelegt <a class="spec-record-ref" data-req="SWS_DM_02376" href="../spec/record.html?id=SWS_DM_02376">[SWS_DM_02376]</a>, <a class="spec-record-ref" data-req="SWS_DM_02377" href="../spec/record.html?id=SWS_DM_02377">[SWS_DM_02377]</a>, <a class="spec-record-ref" data-req="SWS_DM_02378" href="../spec/record.html?id=SWS_DM_02378">[SWS_DM_02378]</a>, <a class="spec-record-ref" data-req="SWS_DM_02379" href="../spec/record.html?id=SWS_DM_02379">[SWS_DM_02379]</a>, <a class="spec-record-ref" data-req="SWS_DM_02380" href="../spec/record.html?id=SWS_DM_02380">[SWS_DM_02380]</a>, <a class="spec-record-ref" data-req="SWS_DM_02381" href="../spec/record.html?id=SWS_DM_02381">[SWS_DM_02381]</a>.</p>

<h4>Nutzungspfad</h4>
<p>Der typische Nutzungspfad tritt beim Empfang einer SOVD-Schreibanforderung für eine Entitäts-Datenressource auf <a class="spec-record-ref" data-req="SWS_DM_01431" href="../spec/record.html?id=SWS_DM_01431">[SWS_DM_01431]</a>. Das Diagnostic Management erzeugt oder nutzt eine Instanz und setzt zunächst mit <code>SetName</code> den <code>shortName</code> des jeweiligen <code>DiagnosticSovdContentElement</code> <a class="spec-record-ref" data-req="SWS_DM_02166" href="../spec/record.html?id=SWS_DM_02166">[SWS_DM_02166]</a>, <a class="spec-record-ref" data-req="SWS_DM_02378" href="../spec/record.html?id=SWS_DM_02378">[SWS_DM_02378]</a>. Anschließend wird der eingehende Wert anhand der Konvertierungsregeln transformiert <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=205">AUTOSAR_AP_SWS_Diagnostics §7.3.3.3.2 „SOVD Data – Conversion“</a> und über <code>SetContent</code> zugewiesen <a class="spec-record-ref" data-req="SWS_DM_02166" href="../spec/record.html?id=SWS_DM_02166">[SWS_DM_02166]</a>, <a class="spec-record-ref" data-req="SWS_DM_02381" href="../spec/record.html?id=SWS_DM_02381">[SWS_DM_02381]</a>. Die auf diese Weise aggregierten Daten werden danach an <code>GenericDiagnosticSovdContent::Write</code> weitergereicht <a class="spec-record-ref" data-req="SWS_DM_02166" href="../spec/record.html?id=SWS_DM_02166">[SWS_DM_02166]</a>. Konsumenten können den Schlüsselnamen über <code>GetName</code> abfragen <a class="spec-record-ref" data-req="SWS_DM_02377" href="../spec/record.html?id=SWS_DM_02377">[SWS_DM_02377]</a> und den Dateninhalt über die konstante oder nicht-konstante Überladung von <code>GetContent</code> inspizieren bzw. manipulieren <a class="spec-record-ref" data-req="SWS_DM_02379" href="../spec/record.html?id=SWS_DM_02379">[SWS_DM_02379]</a>, <a class="spec-record-ref" data-req="SWS_DM_02380" href="../spec/record.html?id=SWS_DM_02380">[SWS_DM_02380]</a>.</p>

<h4>Fehlerszenarien</h4>
<p>Im Fehlerfall verzichtet die Klasse auf C++-Exceptions und meldet Fehlschläge stattdessen über den Rückgabetyp <code>ara::core::Result&lt;void&gt;</code> von <code>SetContent</code> <a class="spec-record-ref" data-req="SWS_DM_02381" href="../spec/record.html?id=SWS_DM_02381">[SWS_DM_02381]</a>. Schlägt das Setzen des Inhalts fehl – beispielsweise wenn der übergebene Inhaltstyp nicht zur Zielstruktur passt oder ungültig ist –, wird der Fehlercode <code>DiagErrc::kInvalidArgument</code> zurückgegeben <a class="spec-record-ref" data-req="SWS_DM_02381" href="../spec/record.html?id=SWS_DM_02381">[SWS_DM_02381]</a>. Der Aufrufer muss das zurückgegebene Ergebnis prüfen, bevor das Objekt an <code>GenericDiagnosticSovdContent::Write</code> übergeben wird <a class="spec-record-ref" data-req="SWS_DM_02166" href="../spec/record.html?id=SWS_DM_02166">[SWS_DM_02166]</a>.</p>
