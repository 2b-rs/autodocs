<p>
Die synchrone Methode <code>ara::diag::ExternalAuthentication::Get</code> dient einer adaptiven Anwendung dazu, die für eine Diagnoseanfrage zuständige Instanz von <code>ara::diag::ClientAuthentication</code> abzurufen <a class="spec-record-ref" data-req="SWS_DM_01199" href="../spec/record.html?id=SWS_DM_01199">[SWS_DM_01199]</a>. Als Parameter wird eine Referenz auf <code>metaInfo</code> (<code>const ara::diag::MetaInfo&amp;</code>) übergeben, welche Metainformationen aus dem Kontext der Diagnoseanfrage bereitstellt <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=113">SWS Diagnostics §7.3.1.1 „MetaInfo class“</a>. Der Rückgabewert vom Typ <code>ara::core::Result&lt;ClientAuthentication&gt;</code> kapselt das entsprechende Authentifizierungsobjekt zur Verwaltung des Authentifizierungszustands des Clients <a class="spec-record-ref" data-req="SWS_DM_01202" href="../spec/record.html?id=SWS_DM_01202">[SWS_DM_01202]</a>.
</p>
<p>
Tritt ein Fehler auf, enthält das zurückgegebene <code>Result</code> den spezifischen Fehlercode <code>DiagErrc::kServiceNotAvailable</code> <a class="spec-record-ref" data-req="SWS_DM_01199" href="../spec/record.html?id=SWS_DM_01199">[SWS_DM_01199]</a>. Dieser signalisiert mit Rollback-Semantik, dass der Aufruf nicht ausgeführt werden kann, weil wesentliche Funktionen des Diagnostic Managers (DM) zur Aufrufzeit nicht zur Verfügung stehen <a class="spec-record-ref" data-req="SWS_DM_01199" href="../spec/record.html?id=SWS_DM_01199">[SWS_DM_01199]</a>.
</p>
<p>
Hinsichtlich der Nebenläufigkeit ist die Funktion als thread-safe sowie exception safe spezifiziert und mit <code>noexcept</code> deklariert <a class="spec-record-ref" data-req="SWS_DM_01199" href="../spec/record.html?id=SWS_DM_01199">[SWS_DM_01199]</a>. Sie kann daher ohne anwendungsseitige Sperrmechanismen sicher aus parallelen Threads heraus aufgerufen werden.
</p>
<p>
Die Methode steht im Zusammenspiel mit der überladenen Variante <code>Get(Address sourceAddress)</code> <a class="spec-record-ref" data-req="SWS_DM_01200" href="../spec/record.html?id=SWS_DM_01200">[SWS_DM_01200]</a>, welche denselben Abruf direkt über die Quelladresse des Clients ermöglicht <a class="spec-record-ref" data-req="SWS_DM_01202" href="../spec/record.html?id=SWS_DM_01202">[SWS_DM_01202]</a>. Die Anzahl der verfügbaren Instanzen wird durch die Modellelemente <code>DiagnosticExternalAuthenticationIdentification</code> bestimmt <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=129">SWS Diagnostics „Get ClientAuthentication Instance“</a>.
