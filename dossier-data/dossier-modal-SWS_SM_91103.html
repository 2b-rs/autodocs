<h4>Verwendung</h4>
<p>
Die Service-Methode <code>PrepareUpdate</code> wird von Update and Configuration Management (UCM) aufgerufen, um das State Management zur Vorbereitung der Aktualisierung einer Menge von Funktionsgruppen aufzufordern <a class="spec-record-ref" data-req="SWS_SM_00206" href="../spec/record.html?id=SWS_SM_00206">[SWS_SM_00206]</a>, <a class="spec-record-ref" data-req="SWS_SM_91103" href="../spec/record.html?id=SWS_SM_91103">[SWS_SM_91103]</a>. Sie wird über das Service-Interface <code>UpdateRequest</code> bereitgestellt und nimmt als Eingabeparameter die Liste <code>functionGroupList</code> vom Typ <code>FunctionGroupListType</code> entgegen, welche die zu aktualisierenden Funktionsgruppen innerhalb des Software-Clusters spezifiziert <a class="spec-record-ref" data-req="SWS_SM_91103" href="../spec/record.html?id=SWS_SM_91103">[SWS_SM_91103]</a>. Da Fire &amp; Forget deaktiviert ist, besitzt der Aufruf eine synchrone Antwortsemantik mit Rückmeldung an den Aufrufer <a class="spec-record-ref" data-req="SWS_SM_91103" href="../spec/record.html?id=SWS_SM_91103">[SWS_SM_91103]</a>.
</p>

<h4>Reihenfolgebedingungen und Nebenläufigkeit</h4>
<p>
Ein Aufruf ist nur innerhalb einer zuvor durch <code>RequestUpdateSession</code> erfolgreich initiierten Update-Sitzung zulässig <a class="spec-record-ref" data-req="SWS_SM_91103" href="../spec/record.html?id=SWS_SM_91103">[SWS_SM_91103]</a>. Während des Aufrufs kennzeichnet der steuernde Prozess alle Zustandsmaschinen, die eine der übergebenen Funktionsgruppen verwalten, als <code>ImpactedByUpdate</code> <a class="spec-record-ref" data-req="SWS_SM_00654" href="../spec/record.html?id=SWS_SM_00654">[SWS_SM_00654]</a>. Betrifft dies eine Zustandsmaschine vom Typ Agent, wird automatisch auch die übergeordnete Controller-Zustandsmaschine als <code>ImpactedByUpdate</code> markiert <a class="spec-record-ref" data-req="SWS_SM_00655" href="../spec/record.html?id=SWS_SM_00655">[SWS_SM_00655]</a>. Solange dieser Zustand vorliegt, werden externe Zustandsübergänge blockiert: Jeder Aufruf von <code>RequestTransition</code> wird mit <code>kUpdateInProgress</code> beantwortet <a class="spec-record-ref" data-req="SWS_SM_00649" href="../spec/record.html?id=SWS_SM_00649">[SWS_SM_00649]</a>. Zudem werden Recovery-Anforderungen bei Ausführungsfehlern (<code>ExecutionErrorEvent::executionError</code>) ignoriert und lediglich protokolliert <a class="spec-record-ref" data-req="SWS_SM_00664" href="../spec/record.html?id=SWS_SM_00664">[SWS_SM_00664]</a>.
</p>
