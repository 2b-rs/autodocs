<p class="ai-level ai-oneliner-lead" data-ai-level="1">Verwaltet den exklusiven, verschiebbaren Zugriff auf Datei-Accessor-Objekte mit RAII-Semantik.</p>
<div class="ai-level" data-ai-level="2">
<p>Das Klassentemplate <code>ara::per::UniqueHandle</code> verwaltet den exklusiven Besitz von Datei-Accessor-Objekten der AUTOSAR-Persistenz im Rahmen einer strikten Move-Only-Semantik. Nach dem Erhalt über Dateizugriffsfunktionen muss die Instanz vor jeglicher Nutzung verpflichtend mittels <code>operator bool()</code> auf Gültigkeit geprüft werden <a class="spec-record-ref" data-req="SWS_PER_00371" href="../spec/record.html?id=SWS_PER_00371">[SWS_PER_00371]</a>. Ein Aufruf anderer Operatoren an einem leeren oder transferierten Handle führt zu undefiniertem Verhalten <a class="spec-record-ref" data-req="SWS_PER_00399" href="../spec/record.html?id=SWS_PER_00399">[SWS_PER_00399]</a>. Sämtliche Operationen sind als <code>noexcept</code> deklariert, wobei Lesezugriffe threadsicher sind, modifizierende Operationen hingegen nicht.</p>

</div>
<div class="ai-level" data-ai-level="4">
<h4>Kontext</h4>
<p>Das Klassentemplate <code>ara::per::UniqueHandle</code> dient als typsicherer Zugriffs-Handle auf Ressourcenobjekte der AUTOSAR-Adaptive-Persistenz, namentlich <code>ReadAccessor</code> oder <code>ReadWriteAccessor</code>. Es wird als Rückgabewert der Funktionen <code>OpenFileReadOnly()</code>, <code>OpenFileWriteOnly()</code> sowie <code>OpenFileReadWrite()</code> bereitgestellt und kapselt den exklusiven Besitz der geöffneten Dateizugriffsschnittstelle.</p>

<h4>Lebenszyklus</h4>
<p>Die Klasse implementiert eine strikte Move-Only-Semantik (Unique Ownership). Um versehentliche Duplizierungen des Zugriffs oder geteilten Besitz zu unterbinden, sind sowohl der Kopierkonstruktor <a class="spec-record-ref" data-req="SWS_PER_00373" href="../spec/record.html?id=SWS_PER_00373">[SWS_PER_00373]</a> als auch der Kopierzuweisungsoperator <a class="spec-record-ref" data-req="SWS_PER_00374" href="../spec/record.html?id=SWS_PER_00374">[SWS_PER_00374]</a> als gelöscht (<code>delete</code>) definiert. Eigentumsrechte können ausschließlich durch Verschieben übertragen werden: Beim Aufruf des Move-Konstruktors <a class="spec-record-ref" data-req="SWS_PER_00371" href="../spec/record.html?id=SWS_PER_00371">[SWS_PER_00371]</a> oder der Move-Zuweisung <a class="spec-record-ref" data-req="SWS_PER_00372" href="../spec/record.html?id=SWS_PER_00372">[SWS_PER_00372]</a> wird das übergebene Quellobjekt invalidiert und darf danach nicht mehr verwendet werden.</p>

<p>Ein <code>UniqueHandle</code> befindet sich zu jedem Zeitpunkt entweder in einem gültigen Zustand (es repräsentiert ein valides Objekt der parametrierten Klasse) oder in einem leeren bzw. invalidierten Zustand, wie er nach einem Move-Transfer vorliegt <a class="spec-record-ref" data-req="SWS_PER_00399" href="../spec/record.html?id=SWS_PER_00399">[SWS_PER_00399]</a>. Bei Beendigung des Gültigkeitsbereichs wird der Destruktor <a class="spec-record-ref" data-req="SWS_PER_00569" href="../spec/record.html?id=SWS_PER_00569">[SWS_PER_00569]</a> ausgeführt. Vermutlich schließt bzw. bereinigt die Zerstörung eines gültigen Handles die gekapselte Zugriffsressource automatisch.</p>

<h4>Nutzungspfad</h4>
<p>Die typische Verwendung von <code>UniqueHandle</code> folgt einer festgelegten Abfolge von Schritten:</p>
<ol>
<li><strong>Übernahme des Handles:</strong> Die Anwendung empfängt das Handle als Ergebnis eines Dateizugriffsaufrufs wie <code>OpenFileReadOnly()</code>, <code>OpenFileWriteOnly()</code> oder <code>OpenFileReadWrite()</code>.</li>
<li><strong>Zustandsprüfung:</strong> Vor jeder weiteren Operation muss der Status der Instanz verpflichtend mittels <code>operator bool()</code> verifiziert werden <a class="spec-record-ref" data-req="SWS_PER_00371" href="../spec/record.html?id=SWS_PER_00371">[SWS_PER_00371]</a>, <a class="spec-record-ref" data-req="SWS_PER_00372" href="../spec/record.html?id=SWS_PER_00372">[SWS_PER_00372]</a>. Der Operator gibt <code>true</code> zurück, falls ein gültiges Objekt vorliegt, und <code>false</code>, wenn das Handle leer ist <a class="spec-record-ref" data-req="SWS_PER_00399" href="../spec/record.html?id=SWS_PER_00399">[SWS_PER_00399]</a>.</li>
<li><strong>Zugriff auf das gekapselte Objekt:</strong> Bei gültigem Status wird über die Pfeil-Operatoren <code>operator-&gt;</code> (nicht-konstant <a class="spec-record-ref" data-req="SWS_PER_00360" href="../spec/record.html?id=SWS_PER_00360">[SWS_PER_00360]</a> oder konstant <a class="spec-record-ref" data-req="SWS_PER_00361" href="../spec/record.html?id=SWS_PER_00361">[SWS_PER_00361]</a>) oder über Dereferenzierung mittels <code>operator*</code> (nicht-konstant <a class="spec-record-ref" data-req="SWS_PER_00400" href="../spec/record.html?id=SWS_PER_00400">[SWS_PER_00400]</a> oder konstant <a class="spec-record-ref" data-req="SWS_PER_00401" href="../spec/record.html?id=SWS_PER_00401">[SWS_PER_00401]</a>) auf die Methoden und Daten des Ziels zugegriffen.</li>
<li><strong>Besitzübergabe oder Zerstörung:</strong> Das Handle kann bei Bedarf per <code>std::move</code> an eine andere Komponente übertragen werden <a class="spec-record-ref" data-req="SWS_PER_00371" href="../spec/record.html?id=SWS_PER_00371">[SWS_PER_00371]</a> oder wird am Ende der Lebensdauer automatisch zerstört <a class="spec-record-ref" data-req="SWS_PER_00569" href="../spec/record.html?id=SWS_PER_00569">[SWS_PER_00569]</a>.</li>
</ol>

<h4>Fehlerszenarien</h4>
<p>Ein zentrales Fehlerszenario stellt der Zugriff auf ein leeres oder transferiertes Handle dar: Die Verwendung anderer Operatoren als <code>operator bool()</code> an einem leeren Handle führt laut Spezifikation zu undefiniertem Verhalten (Undefined Behavior) <a class="spec-record-ref" data-req="SWS_PER_00399" href="../spec/record.html?id=SWS_PER_00399">[SWS_PER_00399]</a>. Vor jeglicher Dereferenzierung ist daher zwingend eine Prüfung vorgeschrieben <a class="spec-record-ref" data-req="SWS_PER_00371" href="../spec/record.html?id=SWS_PER_00371">[SWS_PER_00371]</a>, <a class="spec-record-ref" data-req="SWS_PER_00372" href="../spec/record.html?id=SWS_PER_00372">[SWS_PER_00372]</a>.</p>

<ul>
<li><strong>Ausnahmesicherheit:</strong> Sämtliche Methoden und Operatoren sind mit <code>noexcept</code> versehen und als ausnahmesicher (exception safe) spezifiziert (<a class="spec-record-ref" data-req="SWS_PER_00371" href="../spec/record.html?id=SWS_PER_00371">[SWS_PER_00371]</a>, <a class="spec-record-ref" data-req="SWS_PER_00372" href="../spec/record.html?id=SWS_PER_00372">[SWS_PER_00372]</a>, <a class="spec-record-ref" data-req="SWS_PER_00399" href="../spec/record.html?id=SWS_PER_00399">[SWS_PER_00399]</a>, <a class="spec-record-ref" data-req="SWS_PER_00400" href="../spec/record.html?id=SWS_PER_00400">[SWS_PER_00400]</a>, <a class="spec-record-ref" data-req="SWS_PER_00401" href="../spec/record.html?id=SWS_PER_00401">[SWS_PER_00401]</a>, <a class="spec-record-ref" data-req="SWS_PER_00360" href="../spec/record.html?id=SWS_PER_00360">[SWS_PER_00360]</a>, <a class="spec-record-ref" data-req="SWS_PER_00361" href="../spec/record.html?id=SWS_PER_00361">[SWS_PER_00361]</a>, <a class="spec-record-ref" data-req="SWS_PER_00569" href="../spec/record.html?id=SWS_PER_00569">[SWS_PER_00569]</a>).</li>
