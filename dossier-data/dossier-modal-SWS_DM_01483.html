<div class="ai-level" data-ai-level="4">
<p>Die rein virtuelle Methode <code>ValidateAuthorization</code> wird vom diagnostischen Server aufgerufen, wenn eine Anfrage eines SOVD-Clients einen <code>Authorization</code>-HTTP-Header enthält und dessen Token noch nicht gültig validiert vorliegt <a class="spec-record-ref" data-req="SWS_DM_01470" href="../spec/record.html?id=SWS_DM_01470">[SWS_DM_01470]</a>. Die Anwendung prüft das übergebene Autorisierungstoken nach dem im System konfigurierten Protokoll (beispielsweise OAuth 2.0 im Kontext eines Resource Servers) und weist dem Client die entsprechenden Rollen zu <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>.</p>
<p>Die Schnittstellenspezifikation umfasst folgende Parameter und Rückgaben <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=699">SWS Diagnostics §8.52.1.1.3.5 „ValidateAuthorization“</a>:</p>
<ul>
<li><code>token</code> (<code>ara::core::StringView</code>): Das aus dem HTTP-Header übermittelte Zugriffstoken <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>.</li>
<li><code>metaInfo</code> (<code>const MetaInfo&amp;</code>): Metainformationen des diagnostischen Service-Ports <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>.</li>
<li><code>clientAuthentication</code> (<code>ClientAuthentication&amp;</code>): Objekt, über das die Anwendung die authentifizierten Rollen des SOVD-Clients setzt <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>. Nach Bereitstellung des zurückgegebenen <code>Future</code> darf die Anwendung diese Referenz nicht mehr verwenden <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>.</li>
<li>Rückgabewert: Ein <code>ara::core::Future&lt;ValidateAuthorizationOutput&gt;</code> <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>. Bei erfolgreicher Validierung enthält die Struktur <code>ValidateAuthorizationOutput</code> <a class="spec-record-ref" data-req="SWS_DM_01927" href="../spec/record.html?id=SWS_DM_01927">[SWS_DM_01927]</a> den Gültigkeitszeitstempel <code>validUntil</code> <a class="spec-record-ref" data-req="SWS_DM_01820" href="../spec/record.html?id=SWS_DM_01820">[SWS_DM_01820]</a> sowie die Client-Kennung <code>identity</code> <a class="spec-record-ref" data-req="SWS_DM_01819" href="../spec/record.html?id=SWS_DM_01819">[SWS_DM_01819]</a>.</li>
</ul>
<p>Der Diagnostic Server betrachtet zugewiesene Rollen für Anfragen mit identischem Token bis zum Erreichen von <code>validUntil</code> als authentifiziert <a class="spec-record-ref" data-req="SWS_DM_01469" href="../spec/record.html?id=SWS_DM_01469">[SWS_DM_01469]</a> und erkennt den SOVD-Client anhand des Tokens oder der Identität wieder <a class="spec-record-ref" data-req="SWS_DM_01781" href="../spec/record.html?id=SWS_DM_01781">[SWS_DM_01781]</a> <a class="spec-record-ref" data-req="SWS_DM_01782" href="../spec/record.html?id=SWS_DM_01782">[SWS_DM_01782]</a>. Diese Wiedererkennung ist unter anderem für temporäre Operationen und SOVD-Sperren erforderlich, da unauthentifizierten Clients der Sperrzugriff mit HTTP 401 verwehrt wird <a class="spec-record-ref" data-req="SWS_DM_01783" href="../spec/record.html?id=SWS_DM_01783">[SWS_DM_01783]</a>.</p>
<p>Im Fehlerfall wird das <code>Future</code> mit <code>DiagSovdErrc::kInvalidAccessToken</code> (ungültiges Token) oder <code>DiagSovdErrc::kTemporarilyNotAvailable</code> (z.&nbsp;B. Authentifizierungsserver vorübergehend nicht erreichbar) aufgelöst <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>. Die Funktion ist als <code>noexcept</code> und exceptionsicher spezifiziert; ob die Implementierung threadsicher sein muss, wird über den im Konstruktor übergebenen <code>ConcurrencyType</code> gesteuert <a class="spec-record-ref" data-req="SWS_DM_01483" href="../spec/record.html?id=SWS_DM_01483">[SWS_DM_01483]</a>.</p>
