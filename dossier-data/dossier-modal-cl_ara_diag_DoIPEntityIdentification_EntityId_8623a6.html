<h4>Context</h4>
<p>The data structure <code>ara::diag::DoIPEntityIdentification::EntityId</code> is defined in the header <code>ara/diag/doip_entity_identification.h</code> as an embedded type of the interface class <code>ara::diag::DoIPEntityIdentification</code> (<a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=576">SWS Diagnostics §8.33 “Header: ara/diag/doip_entity_identification.h”</a>, <a class="spec-record-ref" data-req="SWS_DM_01362" href="../spec/record.html?id=SWS_DM_01362">[SWS_DM_01362]</a>). Its purpose is to encapsulate and provide the <em>Entity Identification</em> value (EID) standardized in ISO 13400-2:2019 for the DoIP protocol (Diagnostic communication over Internet Protocol). For this purpose, the structure encapsulates the member <code>entityIdentification</code> as a fixed byte array of type <code>ara::core::Array&lt;std::uint8_t, 6&gt;</code> (<a class="spec-record-ref" data-req="SWS_DM_01496" href="../spec/record.html?id=SWS_DM_01496">[SWS_DM_01496]</a>).</p>
<p>In the overall system, essentially three components interact when using <code>EntityId</code>:</p>
<ul>
<li><strong>Adaptive Application (AA):</strong> Implements or instantiates the API class <code>ara::diag::DoIPEntityIdentification</code> (<a class="spec-record-ref" data-req="SWS_DM_01364" href="../spec/record.html?id=SWS_DM_01364">[SWS_DM_01364]</a>) to provide the system-specific entity identification. Interpretation: The 6-byte identifier is likely to be typically based on a MAC address or an analogous hardware identification of the DoIP instance in accordance with ISO 13400-2:2019.</li>
<li><strong>Diagnostic Management (DM):</strong> Acts as the central interaction partner in the Adaptive daemon. If the system is configured to the value <code>DoIpEidRetrievalEnum.eidUseApi</code> via the parameter <code>DoIpNetworkConfiguration.eidRetrieval</code>, the DM actively requests the EID via the method <code>ara::diag::DoIPEntityIdentification::GetEntityId</code> (<a class="spec-record-ref" data-req="SWS_DM_01361" href="../spec/record.html?id=SWS_DM_01361">[SWS_DM_01361]</a>, <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=107">SWS Diagnostics §7.2.1.2</a>).</li>
<li><strong>DoIP network / external tester:</strong> The peer at the network level to which the DM transmits the received EID within standardized DoIP messages (such as the Vehicle Announcement Message) (<a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=107">SWS Diagnostics §7.2.1.2</a>).</li>
</ul>

<h4>Error Scenarios</h4>
<p>When providing and processing <code>EntityId</code>, the following error conditions and preconditions must be observed:</p>
<ul>
<li><strong>Precondition:</strong> Retrieval via the C++ API strictly requires that <code>DoIpNetworkConfiguration.eidRetrieval</code> is configured to <code>eidUseApi</code> (<a class="spec-record-ref" data-req="SWS_DM_01361" href="../spec/record.html?id=SWS_DM_01361">[SWS_DM_01361]</a>). Otherwise, the method <code>GetEntityId</code> is not called by the DM.</li>
<li><strong>Interface not provided:</strong> If the interface <code>ara::diag::DoIPEntityIdentification</code> is not yet offered at the time of the EID query by the DM or if reading the EID fails (<a class="spec-record-ref" data-req="SWS_DM_01528" href="../spec/record.html?id=SWS_DM_01528">[SWS_DM_01528]</a>, <a class="docref internal-spec-ref" href="../spec/record.html?doc=AUTOSAR_AP_SWS_Diagnostics&amp;page=107">SWS Diagnostics §7.2.1.2</a>), a standardized fallback takes effect.</li>
<li><strong>Fallback behavior (EID replacement value):</strong> In the event of an error, the DM transmits a firmly defined 6-byte replacement value in the DoIP protocol messages, where all bytes are set to <code>0xFF</code> (<code>0xFF 0xFF 0xFF 0xFF 0xFF 0xFF</code>) (<a class="spec-record-ref" data-req="SWS_DM_01528" href="../spec/record.html?id=SWS_DM_01528">[SWS_DM_01528]</a>).</li>
<li><strong>Postcondition:</strong> After successful execution, the DM has a complete 6-byte identifier (<a class="spec-record-ref" data-req="SWS_DM_01496" href="../spec/record.html?id=SWS_DM_01496">[SWS_DM_01496]</a>) so that conformant DoIP messages can be generated without resorting to the replacement value.</li>
</ul>
