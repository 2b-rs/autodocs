<h4>Context</h4>
<p>The class <code>ara::tsync::TsyncErrorDomain</code> defines the specific error domain for time synchronization (module <code>tsync</code>) within the AUTOSAR Adaptive Platform. As a final specialization of the base class <code>ara::core::ErrorDomain</code>, it forms the infrastructural basis for the standardized error handling model of the module. Its functional responsibility includes the unique identification of the error domain, the assignment of numerical error codes to readable description texts, as well as the conversion of error values into typed C++ exceptions.</p>
<p>For semantic typing and decoupling, the class provides two type-defining aliases. Via the type alias <code>Errc</code> <a class="spec-record-ref" data-req="SWS_TS_01266" href="../spec/record.html?id=SWS_TS_01266">[SWS_TS_01266]</a>, the domain binds the enumeration <code>TsyncErrc</code>, which defines all specific error causes of time synchronization. The type alias <code>Exception</code> <a class="spec-record-ref" data-req="SWS_TS_01267" href="../spec/record.html?id=SWS_TS_01267">[SWS_TS_01267]</a> refers to the exception class <code>TsyncException</code>, which serves as the base type for exception handling in the event of an error.</p>
<p>Essential interaction partners of the class are:</p>
<ul>
<li><code>ara::core::ErrorDomain</code>: Higher-level base class of the AUTOSAR core, which prescribes the interface for domain-specific error mappings.</li>
<li><code>ara::core::ErrorCode</code>: Encapsulates concrete error numbers and references the responsible error domain for interpretation.</li>
<li><code>TsyncErrc</code>: Domain-specific error code enumeration, accessible via the type-internal alias <code>Errc</code> <a class="spec-record-ref" data-req="SWS_TS_01266" href="../spec/record.html?id=SWS_TS_01266">[SWS_TS_01266]</a>.</li>
<li><code>TsyncException</code>: Represents the corresponding exception class, accessible via the alias <code>Exception</code> <a class="spec-record-ref" data-req="SWS_TS_01267" href="../spec/record.html?id=SWS_TS_01267">[SWS_TS_01267]</a>.</li>
</ul>
