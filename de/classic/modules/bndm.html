requirement SWS_BNDM_00001 [SWS_BNDM_00001] 📄 PDF

The BndM shall manage its BndM blocks ( BndMBlockDe- scriptor ) in the direct accessible memory (i.e. via pointer).

requirement SWS_BNDM_00002 [SWS_BNDM_00002] 📄 PDF

A call of BndM_GetBlockPtr shall deliver the base pointer to the corresponding BndM block ( BndMBlockDescriptor ) in the currently active partition.

requirement SWS_BNDM_00003 [SWS_BNDM_00003] 📄 PDF

A call of BndM_WriteStart shall trigger the preparation of the 2nd (free) partition.

requirement SWS_BNDM_00004 [SWS_BNDM_00004] 📄 PDF

A call of BndM_WriteBlock shall trigger the writing of the data to the 2nd (unused) partition. The data (ImplementationDataType) shall be not modified to allow a pointer access.

requirement SWS_BNDM_00005 [SWS_BNDM_00005] 📄 PDF

A call of BndM_WriteFinalize shall trigger the finalization of the 2nd (unused) partition. In background the BndM shall make the 2nd (unused) parti- tion consistent by coping all unchanged BndMBlockDescriptor to the 2nd (unused) partition. If the finalization is successful the BndM shall make the 2nd (unused) partition to the active partition and trigger the callback Xxx_BndMWriteFinalizeFinish with the result set to E_OK .

requirement SWS_BNDM_00006 [SWS_BNDM_00006] 📄 PDF

Type of error Related error code Error value API service called with wrong parameter BNDM_E_PARAM 0x01 API called in wrong sequence BNDM_E_WRONG_SEQUENCE 0x02

requirement SWS_BNDM_00007 [SWS_BNDM_00007] 📄 PDF

After preparation of the 2nd (free) partition [SWS_BndM_00003] is successfully finished (writing to the 2nd partition is pos- sible) the callback Xxx_BndMWriteStartFinish with the result set to E_OK shall be triggered in the context of the BndM_MainFunction .

requirement SWS_BNDM_00008 [SWS_BNDM_00008] 📄 PDF

After writing of [SWS_BndM_00004] the 2nd (free) partition is finished the callback Xxx_BndMWriteBlockFinish with the result set to E_OK shall be triggered in the context of the BndM_MainFunction .

requirement SWS_BNDM_00009 [SWS_BNDM_00009] 📄 PDF

If the finalization is NOT successful (the 2nd partition is not con- sistent and could therefore not be used) the BndM shall keep the current active parti- tion as the active partition and trigger the callback Xxx_BndMWriteFinalizeFinish with the result set to E_NOT_OK .

requirement SWS_BNDM_00010 [SWS_BNDM_00010] 📄 PDF

A call of BndM_WriteFinalize without a previously called BndM_WriteStart or within the finalization mode of the BndM the DET BndM_E_- WRONG_SEQUENCE error shall be thrown.

requirement SWS_BNDM_00011 [SWS_BNDM_00011] 📄 PDF

A call of BndM_WriteBlock shall be rejected with the error- Code E_NOT_OK , if the call is done without a previous call of BndM_WriteStart . or while another writing of the same or another block is ongoing or the call is done within the finalization mode of the BndM.

requirement SWS_BNDM_00012 [SWS_BNDM_00012] 📄 PDF

A call of BndM_WriteBlock shall be rejected with the error- Code E_NOT_OK , if the call is done while another writing of the same or another block is ongoing.

requirement SWS_BNDM_00013 [SWS_BNDM_00013] 📄 PDF

A call of BndM_WriteBlock shall be rejected with the error- Code E_NOT_OK , if the call is done within or after the finalization mode of the BndM.

requirement SWS_BNDM_00014 [SWS_BNDM_00014] 📄 PDF

A call of BndM_WriteStart shall be rejected with the error- Code E_NOT_OK , if the call is done within an active writing phase (phase between BndM_WriteStart and BndM_WriteFinalize ).

requirement SWS_BNDM_01019 [SWS_BNDM_01019] 📄 PDF

There are no mandatory interfaces.

requirement SWS_BNDM_01020 [SWS_BNDM_01020] 📄 PDF
