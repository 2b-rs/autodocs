Core Execution Environment

component Core Execution Environment

The S-Core Core Execution Environment defines the fundamental OS abstraction, POSIX runtime guarantees, container technologies, process privilege models, and coding standards for all Eclipse S-Core services.

Execution Architecture & Key Requirements

The following requirements have been extracted from release pin v0.6.0 and are managed through the S-Core curation lifecycle:

Requirement IDCategorySafety / SecurityDescription
aou_req__platform__posix_operating_systemPlatform / OSSafety: QMRequires an underlying operating system compliant with IEEE Std 1003.1 (POSIX), 2004 edition or later.
stkh_req__hardware_support__container_techContainer / HardwareSecurity: YESRequires Linux kernel isolation mechanisms including cgroups, security policies (secpol), and namespaces for workload containment.

aou_req__os__nonrootSecurity / ProcessSecurity: YESApplication components must run as unprivileged non-root users with isolated UID/GID namespaces.
