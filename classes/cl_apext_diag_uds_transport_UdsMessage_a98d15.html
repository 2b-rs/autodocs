class apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

Verwendungszweck

UdsMessage repräsentiert eine UDS-Nachricht zwischen dem generischen DM-Kern beziehungsweise UdsTransportProtocolMgr und einer konkreten Implementierung von UdsTransportProtocolHandler. Das Objekt stellt Speicher für UDS-Anfragen und -Antworten bereit. [SWS_DM_00291]

Erzeugung & Ownership

Instanzen mit optimierter Ressourcenallokation werden ausschließlich vom DM-Kern erzeugt; ein Protocol Handler darf sie lesen und schreiben, soll sie aber nicht selbst erzeugen. Der Default-Konstruktor ist deshalb geschützt. Bei akzeptierter Indikation besitzt ein UdsMessagePtr ein gültiges Objekt mit mindestens einem Byte Kapazität; zunächst ist dessen von GetPayload() gelieferter Puffer leer. [SWS_DM_09012] [SWS_DM_00385] [SWS_DM_00392]

Zusammenspiel mit anderen Klassen

Der nichtkonstante Payload-Zugriff liefert einen beschreibbaren ByteSpan; der konstante Zugriff liefert die UDS-Daten ab SID ohne Schreibzugriff. Ein Transport-Handler füllt nach erfolgreicher Indikation den Payload ab SID bis zur Kapazität oder bis zum Ende der empfangenen Nachricht. Quelle, Ziel und physische beziehungsweise funktionale Zieladressart sind über Getter verfügbar; AddMetaInfo() ergänzt Metainformationen. [SWS_DM_00301] [SWS_DM_00300] [SWS_DM_00388] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00302]

Einschränkungen

Der Destruktor ist virtuell, standardmäßig implementiert und ausnahmesicher. Die Adress-Getter sind reentrant; beide Payload-Zugriffe und AddMetaInfo() sind als nicht threadsicher ausgewiesen. [SWS_DM_09010] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00300] [SWS_DM_00301] [SWS_DM_00302]
