Rolle im Modell

Buffer besitzt die für Host und Beschleuniger benötigte Speicherressource. Direkter Datentransfer wird nicht über Buffer-Methoden, sondern über Accessor-Objekte ausgedrückt.

Quellenbezug

Für die Speicherbeschreibung arbeitet Buffer mit SWS SHWA §7.5 — Memory Allocation Specifics. Der Zugriff wird laut SWS SHWA §7.3 — Data Access Specifics über Accessor ausgedrückt.
