HttpRedirect beschreibt eine HTTP-Umleitung für eine verschobene oder unter einer anderen URI verfügbare SOVD-Ressource. Der SOVD-Server verwendet den Typ, um dem SOVD-Client den neuen Ort mitzuteilen. [SWS_DM_01828] Das Feld url enthält die URL, an die die Anfrage umgeleitet werden soll.
