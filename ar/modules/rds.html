التصنيف & الغرض

تنقل تدفقات البيانات الأولية البيانات الثنائية كاتصال بين العميل والخادم عبر البروتوكولات المستندة إلى IP. يتم إنشاء RawDataStreamClient وRawDataStreamServer لنموذج Port-Interfaces [SWS_RDS_10481] [SWS_RDS_11311].

تدفق قائم على IP

يتصل العميل بـ Connect، وينتظر جانب الخادم عبر WaitForConnection؛ ثم يقرأ الطرفان البيانات أو يكتبانها وينهيان الاتصال عبر Shutdown [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].

تسلسل الاتصال والنقل. المصدر: SWS Raw Data Stream §7.1.4، الفصل 8. الملخص الزمني تفسير.

IEEE 1722

لنقل البيانات على طبقة ربط البيانات، تصف API مخططات البيانات IEEE-1722 المكتوبة بالإضافة إلى فئات المنتج وConsumer [SWS_RDS_90225] [SWS_RDS_90311] [SWS_RDS_90322].

حالات الاتصال

مخطط حالة اتصال الدفق. المصدر: SWS Raw Data Stream §7.1.4. التفسير: تكثف الحالات عمليات الإنشاء والاتصال وإيقاف التشغيل.

سياق النظام

الواجهة مخصصة لتدفقات البيانات الفعالة بالإضافة إلى الاتصالات الموجهة نحو الخدمة (EXP ARACom API)؛ تصف المواصفات التكوين والتحكم في الوصول والقنوات الآمنة في الفصل السابع.

تفسير: تضع الصفحة واجهات API المنفصلة الخاصة بـ IP وIEEE-1722 في منظور استخدام مشترك.
