التصنيف & الغرض

يقوم جدار الحماية بفحص وتصفية حزم الشبكة. يمكنه تطبيق القواعد وفقًا لحالة جدار الحماية؛ يربط API المنافذ النموذجية FirewallStateSwitchInterface بـ ara::fw::FirewallStateSwitchInterface [AP_SWS_Fw_82001].

تغيير الحالة

يقوم أحد التطبيقات بإنشاء الواجهة باستخدام InstanceSpecifier ويطلب بشكل غير متزامن التغيير إلى [AP_SWS_Fw_82002] [AP_SWS_Fw_82008] عبر SwitchFirewallState. يتم إنشاء أنواع الحالات المحتملة وقيم العداد من حالات جدار الحماية النموذجية وفقًا لـ ara::fw::states [AP_SWS_Fw_81001] [AP_SWS_Fw_81002].

معالجة الأخطاء

يميز FwErrc بين الاتصال المتقطع لبرنامج جدار الحماية والحالة التي لا يتم استخدامها بواسطة أي قاعدة جدار حماية ذات حالة [AP_SWS_Fw_83001]. يوفر مجال الخطأ رمز الخطأ وارتباطات الاستثناء [AP_SWS_Fw_83002] [AP_SWS_Fw_83006].

السياق المعماري

تُصنّف Firewall في تصميم المنصة بوصفها وظيفة أمان بين الوصول إلى الشبكة والتطبيقات (EXP Platform Design). يصف الربط بـ State Management في المخطط سياق القواعد المرتبطة بالحالة، لا API عامة إضافية.

تفسير: يلخص التسلسل سياق State Management واستدعاء API غير المتزامن في سير مفهوم.

تغيير حالة جدار الحماية مع سياق إدارة الحالة. المصدر: SWS Firewall §7.3، [AP_SWS_Fw_82008]. التفسير الجزئي: يظهر التنسيق مع State Management من الناحية المفاهيمية.
