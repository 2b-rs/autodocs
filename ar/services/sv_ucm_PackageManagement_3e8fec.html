واجهة خدمة PackageManagement

واجهة مُنمذجة بوصفها خدمة ara::com؛ وتُستدعى Methods/Fields عبر Proxies/Skeletons مولدة (اتجاه المعلمات IN/OUT).

دليل المستخدم مولَّد بالذكاء الاصطناعي / AI generated

وصف مولد تلقائياً، مشتق من حيث المحتوى من وثائق AUTOSAR R25-11 المشار إليها (مواصفة SWS والوثائق المعيارية المصاحبة) — وليس نصاً رسمياً لـ AUTOSAR. العبارات المعلّمة بأنها تفسير هي استنتاجات من المصادر.

خدمة واحدة، ثلاثة مستويات احترافية

يفصل PackageManagement بين قبول الحزم ومعالجة الحزم وتغيير مجموعة Software-Cluster قيد التشغيل. تمثل CurrentStatus العرض العام لمرحلة UCM الجاري تنفيذها؛ وتعيّن معرّفات النقل عمليات النقل الفردية تعيينًا فريدًا. SWS UCM الفصل 7 «Functional specification» [SWS_UCM_00361]

نقل كتلة قوية

يحتفظ TransferStart بالموارد ويوفر Transfer-ID والحد الأقصى لحجم الكتلة. يقوم TransferData بالتحقق من ID وترتيبه وحجمه، وإذا لزم الأمر، تناسق الكتلة. لا يُسمح باستخدام TransferExit إلا بعد كتل البيانات والتحقق من اكتمالها وتنسيق الحزمة. ولذلك يجب التعامل مع الأخطاء في النقل لكل عملية نقل وعدم تفسيرها على أنها أخطاء تنشيط. [SWS_UCM_00272] [SWS_UCM_00275] [SWS_UCM_00276]

مخطط النشاط من نقل الكتلة إلى التنشيط. المصادر: SWS UCM §7.3 «Transfer and processing»، SWS UCM §7.5 «Activation and rollback». التفسير الجزئي: يؤكد التمثيل على طلب العميل، على الرغم من أن التحويلات الفردية والمعالجة قد يتم فصلها بمرور الوقت.

المعالجة والتفعيل والسحب

بعد ProcessSwPackage، لا يجوز بدء Activate إلا من مرحلة التحضير للحزم المعالجة. ويطلب التفعيل Update-Session من SM. ويقرر التحقق الإكمال أو الاستعادة؛ ولـ Rollback مخرج فشل صريح ويمكن إعادة محاولته من kRollingBackFailed. [SWS_UCM_00241] [SWS_UCM_00257] [SWS_UCM_00300] [SWS_UCM_00301]

عمليات الحالة والاستعلام

تُستخدم GetProgress وGetSwPackages واستعلامات Cluster وGetHistory للمراقبة وقابلية التدقيق؛ ولا تحل محل فحص الحالة قبل عملية مرتبطة بحالة. تتعلق Suspend/Resume بالإجراءات طويلة الأمد ويجب تفسيرها في سياق CurrentStatus. SWS UCM §7.6 «Progress and interruption»

قائمة تحقق العميل

  1. استخدم الحد الأقصى لحجم الكتلة ومعرف النقل المقدم بواسطة TransferStart دون تغيير.
  2. قم بنقل جميع الكتل قبل TransferExit وقم بتقييم السبب الخاص بمعرف النقل لكل خطأ.
  3. بعد المعالجة، راقب CurrentStatus واستدعِ Activate فقط في المرحلة المسموح بها.
  4. عند نتيجة تحقق سلبية، اختر مسار Rollback الموثق بدل إعادة تفعيل جديدة.

مزيد من الأدلة التي تم الحصول عليها من الكتلة السابقة: [SWS_UCM_00361] [SWS_UCM_00343] [SWS_UCM_00344] [SWS_UCM_00345] [SWS_UCM_00346] [SWS_UCM_00347] [SWS_UCM_00348] [SWS_UCM_00349] [SWS_UCM_00351] [SWS_UCM_00350] [SWS_UCM_00352] [SWS_UCM_00353] [SWS_UCM_00354] [SWS_UCM_00355] [SWS_UCM_00356] [SWS_UCM_00357] [SWS_UCM_00358] [SWS_UCM_00359] [SWS_UCM_00360] [SWS_UCM_00390] [SWS_UCM_00397] [SWS_UCM_00398] [SWS_UCM_00030] EXP PlatformDesign §13.2 «Update protocol» EXP SWArchitecture §9.7.1.1.1 «General» [RS_UCM_00026] [RS_UCM_00006] [RS_UCM_00021] [RS_UCM_00008] [RS_UCM_00027].

الأعضاء

  • Activate This method activates the Software Clusters extracted from the processed Software Packages.
  • Cancel This method aborts an ongoing processing of a Software Package.
  • CurrentStatus The current status of UCM.
  • DeleteTransfer Delete a transferred Software Package.
  • Finish This method finishes the processing for the current set of processed Software Packages
  • GetHistory Getter method to retrieve all actions that have been performed by UCM.
  • GetId Get the UCM Instance Identifier.
  • GetProgress Get the progress information of the currently active state in the Package Management state machine.
  • GetSwClusterChangeInfo This method returns a list pending changes to the set of SoftwareClusters on the adaptive platform
  • GetSwClusterInfo This method returns a list with information of all SoftwareClusters that are in state kPresent.
  • GetSwClusterManifestInfo This method returns the general information of a Software Cluster that are in state kPresent.
  • GetSwPackages This method returns the Software Packages that available in UCM.
  • ProcessSwPackage Process a previously transferred Software Package or a partly transferred Software Package from a stream.
  • RegisterSoftwarePackage registers a package that could already be in Machine’s file system or to be downloaded.
  • Resume This method resumes ongoing time consuming actions or actions related to specific states.
  • RevertProcessedSwPackages Revert the changes done by processing (ProcessSwPackage) of one or several software packages.
  • Rollback Rollback the system to the state before the packages were processed.
  • Suspend This method suspends ongoing time consuming actions or actions related to specific states.
  • TransferData Block-wise transfer of a Software Package to UCM.
  • TransferExit Finish the transfer of a Software Package to UCM.
  • TransferStart Start the transfer of a Software Package after having received a Vehicle Package
