يُستخدم لنقل حزم البرمجيات ومجموعات البرمجيات ومعالجتها وتفعيلها ومراقبتها في UCM.

تتحكم واجهة الخدمة PackageManagement في نقل حزم البرمجيات ومعالجتها وتفعيلها على AUTOSAR Adaptive Platform [SWS_UCM_00345]، [SWS_UCM_00352]. وتتيح تحميل الحزم على هيئة كتل، واستخراج مجموعات البرمجيات وتفعيلها بشكل منضبط بالتنسيق مع State Management [SWS_UCM_00346]، [SWS_UCM_00352]. بالإضافة إلى ذلك، توفر الخدمة آليات لمراقبة الحالة وللتراجع وتطهير بيانات الجلسة [SWS_UCM_00353]، [SWS_UCM_00361].

1. دور وسياق نظام واجهة الخدمة

تشكل واجهة الخدمة PackageManagement الواجهة المركزية لـ Update and Configuration Management (UCM) لإدارة حزم البرمجيات ونقلها وتثبيتها على AUTOSAR Adaptive Platform [SWS_UCM_00343]. تعمل نسخة UCM هنا عادة كمزود خدمة (Skeleton)، بينما يعمل منسقو التحديث الأعلى مستوى أو عملاء التشخيص كمستهلكي خدمة (Proxy). ولأغراض التعريف، توفر الخدمة معرف نسخة الوحدة الفريد عبر التابع GetId [SWS_UCM_00343]. وخلال عملية التفعيل، يتفاعل UCM بشكل وثيق مع State Management، الذي يجب عليه إتاحة جلسة التحديث وإجراء عمليات التحقق [SWS_UCM_00352].

2. التوابع والأحداث والحقول

تعمل جميع التوابع المعرفة في واجهة الخدمة بدلالات استدعاء متزامنة أو برسائل الطلب والاستجابة، حيث تم تحديد Fire & Forget false لكافة التوابع [SWS_UCM_00345]. يحتوي حقل الحالة CurrentStatus على دالة جلب (Getter) بالإضافة إلى دالة إشعار (Notifier)، مما يتيح للعملاء الاشتراك في تغييرات حالة UCM الموجهة بالأحداث أو الاستعلام عنها بنشاط [SWS_UCM_00361]. بالإضافة إلى ذلك، يوفر GetProgress معلومات تقدم مفصلة للحالة النشطة الحالية لآلة الحالة [SWS_UCM_00360]. وللاستعلام عن مخزون البرمجيات، يتوفر GetSwPackages لسرد حزم البرمجيات المتاحة [SWS_UCM_00359]، وGetSwClusterInfo لمجموعات البرمجيات المثبتة في الحالة kPresent [SWS_UCM_00357]، وGetSwClusterManifestInfo لبيانات بيان المجموعة (manifest) [SWS_UCM_00358]، بالإضافة إلى GetSwClusterChangeInfo للتغييرات المعلقة في الحالات kAdded أو kUpdating أو kRemoved [SWS_UCM_00356]. وتتوفر إمكانية التتبع التاريخي للإجراءات المنفذة عبر GetHistory مع مرشحات الطابع الزمني [SWS_UCM_00355].

3. دورة الحياة ومسارات الجلسة والاعتماديات على الحالة

ينقسم مسار التحديث النموذجي إلى النقل والمعالجة والتفعيل والإنهاء. يبدأ نقل الحزمة إما بواسطة TransferStart، حيث يتم إنشاء TransferIdType والتفاوض على حجم الكتلة [SWS_UCM_00345]، أو بديلاً عن ذلك عبر RegisterSoftwarePackage بتحديد URI للحزمة [SWS_UCM_00344]. وعند النقل بنظام الكتل، يتم حفظ كتل البيانات باستمرار عبر TransferData مع تحديد عداد الكتل [SWS_UCM_00346] ويتم إنهاؤها بـ TransferExit [SWS_UCM_00347]. بعد ذلك، يستخرج ProcessSwPackage حزمة البرمجيات [SWS_UCM_00349]. ويمكن إلغاء المعالجات الجارية باستخدام Cancel [SWS_UCM_00351]، أو تعليقها واستئنافها باستخدام Suspend وResume [SWS_UCM_00397]، [SWS_UCM_00398]. ويمكن إزالة عمليات النقل التي لم تعد مطلوبة باستخدام DeleteTransfer [SWS_UCM_00348]. وباستخدام Activate، يتم تفعيل مجموعات البرمجيات المستخرجة [SWS_UCM_00352]، بينما ينهي Finish جلسة المعالجة ويطهر البيانات المؤقتة [SWS_UCM_00354]. وفي حال حدوث أخطاء، يتيح RevertProcessedSwPackages إعادة تعيين الحزم المعالجة [SWS_UCM_00350]، كما يتيح Rollback استعادة حالة النظام السابقة لمعالجة الحزمة [SWS_UCM_00353].

مخطط تسلسلي: المسار النموذجي لنقل الحزمة ومعالجتها وتفعيلها عبر PackageManagement. المصادر: [SWS_UCM_00345]، [SWS_UCM_00346]، [SWS_UCM_00347]، [SWS_UCM_00349]، [SWS_UCM_00352]، [SWS_UCM_00354].

4. معالجة الأخطاء و Application Errors

تؤمّن توابع الواجهة شروط الخطأ عبر Application Errors محددة. وعند الاستدعاءات المخالفة للسياق، ترجع توابع مثل Activate وCancel وFinish وProcessSwPackage وTransferData وTransferExit الخطأ kOperationNotPermitted [SWS_UCM_00346]، [SWS_UCM_00347]، [SWS_UCM_00349]، [SWS_UCM_00352]. وتُرفض معرفات النقل غير الصالحة بـ kTransferIdInvalid [SWS_UCM_00346]، [SWS_UCM_00348]، بينما تؤدي تسلسلات الكتل الخاطئة أو اختناقات الذاكرة إلى kBlockIncorrect أو kBlockSizeIncorrect أو kBlockInconsistent أو kMemoryInsufficient [SWS_UCM_00345]، [SWS_UCM_00346]. وتطلق فحوصات الأمان والاتساق أخطاء مثل kAuthenticationFailed وkPackageInconsistent وkPackageManifestInvalid وkPackageVersionIncompatible [SWS_UCM_00346]، [SWS_UCM_00349]. وتُمنع إزالة النظام الأساسي بـ kSwclRemovalDenied [SWS_UCM_00349]. وعند التفعيل، تشير kDependencyMissing أو kUpdateSessionRejected أو kVerificationFailed إلى مشكلات تكامل مع الاعتماديات أو مع State Management [SWS_UCM_00352].

                                                                          تميز معالجة الأخطاء بين أخطاء النقل الهيكلية، ومشاكل الاتساق، وأخطاء التحقق من صحة الحزمة ([SWS_UCM_00346]):
                                                                          
  
                                                                            
    
                                                                          • النقل والموارد: إذا كانت الجلسة غير صالحة أو كان سياق الاستدعاء غير صحيح، يستجيب UCM بـ kTransferIdInvalid أو kOperationNotPermitted. إذا تجاوزت كتلة الحجم المتفق عليه أو الحجم الإجمالي المعلن، يتبع ذلك kBlockSizeIncorrect أو kSizeIncorrect. في حالة عدم كفاية الذاكرة أو حدوث أخطاء أثناء الحفظ الدائم، يتم إرجاع kMemoryInsufficient أو kTransferFailed.
                                                                            • 
    
                                                                          • السلامة والتوافق: إذا فشلت عمليات التحقق من البيانات، يتم الإبلاغ عن kBlockInconsistent أو kPackageInconsistent أو kAuthenticationFailed. علاوة على ذلك، يتم رفض البيانات التعريفية (Manifests) غير الصالحة (kPackageManifestInvalid)، أو الإصدارات غير المتوافقة (kPackageVersionIncompatible، kOldVersion)، أو التنسيقات غير المدعومة (kPackageFormatUnsupported)، أو الإزالة غير المسموح بها للمجموعات الأساسية (Core-Clusters) (kSwclRemovalDenied).
