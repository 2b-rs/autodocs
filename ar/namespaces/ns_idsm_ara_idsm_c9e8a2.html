نطاق أسماء ara::idsm

تم إنشاء هذه الصفحة بالكامل KI استنادًا إلى SWS IntrusionDetectionSystemManager (R25-11) - لا يوجد نص AUTOSAR رسمي ولا توجد صفحة API مستخرجة تلقائيًا مثل بقية الوحدات. البيانات التي تحمل علامة تفسير هي استنتاجات مستمدة من المصادر.

دليل المستخدم مولَّد بالذكاء الاصطناعي / AI generated

وصف مولد تلقائياً، مشتق من حيث المحتوى من وثائق AUTOSAR R25-11 المشار إليها (مواصفة SWS والوثائق المعيارية المصاحبة) — وليس نصاً رسمياً لـ AUTOSAR. العبارات المعلّمة بأنها تفسير هي استنتاجات من المصادر.

حدود Namespace

يحتوي ara::idsm واجهات API الخاصة بـ Event وProvider والمتلقي، مع أنواع البيانات والأخطاء المشتركة بينها. يحدد SWS IdsM §8.2 «common.h» الأنواع المشتركة؛ وتعيّن Headers الأخرى هذه الأنواع إلى Port Interfaces المعنية.

تفسير: يجمع Namespace كائنات الوصول الخاصة بـ Event وProvider وReceiver إلى جانب أنواع البيانات وتمثيل الخطأ؛ ويحدد النموذج وara::core::InstanceSpecifier اقترانها المحدد بـ Port Prototypes.

الفئات والبنى

  • ContextDataProvider يوفر بيانات سياق قابلة للتعديل لـ IdsM.
  • EventReporter Meldet Security Events an IdsM.
  • IdsmErrorDomain نطاق الأخطاء الخاص بـ ara::idsm.
  • IdsmException نوع الاستثناء الخاص بـ ara::idsm.
  • QualifiedEventsReceiver يستقبل الأحداث المؤهلة.
  • ReportingModeProvider يقرأ ويضبط Reporting Modes.
  • TimestampProvider Stellt optionale Zeitstempel bereit.
