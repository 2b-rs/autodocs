وصف مولد تلقائياً، مشتق من حيث المحتوى من وثائق AUTOSAR R25-11 المشار إليها (مواصفة SWS والوثائق المعيارية المصاحبة) — وليس نصاً رسمياً لـ AUTOSAR. العبارات المعلّمة بأنها تفسير هي استنتاجات من المصادر.

الغرض من الاستخدام

تعالج الواجهة بيانات SOVD Content العامة. يستخدم Diagnostic Manager المثيل الممثل عبر DiagnosticSovdContentPortMapping لقراءة بيانات SOVD. تعيد Read، بشكل غير متزامن، DiagnosticSovdContentData لاسم Content؛ وتتولى Write هذه البيانات لـ «Write a Data Value». [SWS_DM_02186] [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_02164]

التفاعل مع الفئات الأخرى

لطلب القراءة، يستدعي المدير Read ويشكل استجابة SOVD من عناصر المحتوى المجمعة. لطلب الكتابة، فإنه يستدعي Write مع DiagnosticSovdContentData، الذي تم إنشاء عناصره باستخدام SetName وSetContent. [SWS_DM_01432] [SWS_DM_02166]

دورة حياة ملكية &

يحصل المنشئ على InstanceSpecifier و SovdContentConcurrencyType. الفصل متحرك. تم تحديد Move-Konstruktion وMove-Zuweisung. [SWS_DM_02187] [SWS_DM_02189] [SWS_DM_02190]

القيود & معالجة الأخطاء

يعيد Read وWrite خطأ SOVD عند النتيجة السلبية. لا يجوز تخزين CancellationHandler أو استخدامه بعد مدة بقاء العملية الجارية. يفعّل Offer إعادة توجيه الطلبات، وينهيها StopOffer؛ وتُبلغ واجهة معروضة بالفعل عن DiagOfferErrc::kAlreadyOffered. الوظائف المعروضة آمنة للخيوط. [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_02193] [SWS_DM_02194]

قواعد المعلمات والنتائج يتلقى Read Content-Name وMetaInfo وCancellationHandler، ويعيد إما بيانات SOVD-Content مجردة لاستجابة إيجابية أو خطأ SOVD. ويتلقى Write معلومات السياق نفسها، إضافة إلى بيانات Content المراد كتابتها؛ وتظل هذه البيانات صالحة حتى إتمام Future أو الإلغاء. المُنشئ والمُدمِّر آمنان للاستثناءات والخيوط. [SWS_DM_02187] [SWS_DM_02188] [SWS_DM_02191] [SWS_DM_02192]

العمليات غير المتزامنة هي نقاط واجهة virtual خالصة؛ لذا ينفذ التطبيق الموفِّر المعالجة المحددة. ويُنشئ Diagnostic Manager الاستجابة الخارجية استنادًا إلى Futures المُوفى بها. [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_01432]

سياق SOVD

تصف البنية GenericDiagnosticSovdContent بوصفها واجهة لبيانات SOVD: يُستدعى Read لـ «Read Single Data Value»، ويُستدعى Write لـ «Write a Data Value» لمثيل SOVD Content المحدد. EXP SWArchitecture §9.8.1.1.10 تُشتق بيانات SOVD منهجيًا من DiagnosticDataIdentifier. EXP SOVD §3.1 «Common use cases in SOVD and UDS»
