يُتيح الإرسال المحدد بالنوع لبرقيات تدفق بيانات IEEE-1722 عبر اتصال مهيأ.

تُستخدم فئة القالب ara::rds::IEEE1722RawDataStreamProducer في AUTOSAR Adaptive Platform لإرسال برقيات تدفق البيانات المحددة بالنوع وفقًا لمعيار IEEE-1722 (AUTOSAR_AP_SWS_RawDataStream, ص. 1). بعد الإنشاء الثابت بواسطة Create، يتم إنشاء الاتصال عبر Connect، ومن ثم يتم نقل بيانات الحمولة عبر WriteData كمتجه [SWS_RDS_90332]. تمتلك الفئة دلالات نقل فقط صارمة وهي غير آمنة بالنسبة للخيوط في عمليات النقل وكذلك في المدمّر. يؤدي الاستدعاء الصريح لـ Shutdown أو إتلاف الكائن إلى إنهاء الاتصال بشكل صحيح.

السياق

توفر فئة القالب ara::rds::IEEE1722RawDataStreamProducer داخل الوحدة rds (Raw Data Stream) في AUTOSAR Adaptive Platform الواجهة المخصصة لإرسال مخططات بيانات تدفق البيانات المحددة بالنوع وفقاً لمعيار IEEE-1722 (AUTOSAR_AP_SWS_RawDataStream, ص. 1). وبصفتها مكوّن منتج، فإنها تغلف عملية إنشاء الاتصال الخاصة بالقناة والبروتوكول وكذلك نقل بيانات الحمولة عبر الشبكة الأساسية.

تتم معالجة تدفق البيانات والربط البرمجي بمثيل تدفق مهيأ عبر تمرير ara::core::InstanceSpecifier إلى دالة الإنشاء [SWS_RDS_90323]. وشركاء التفاعل الأساسيون هم البرمجيات المطبقة التي تُنشئ عناصر بيانات من نوع القالب T، ومكدس شبكة IEEE-1722 الذي ينقل مخططات البيانات فعلياً. يتم تضمين تعريف الفئة عبر الترويسة #include "ara/rds/raw_data_stream_IEEE1722.h" [SWS_RDS_90323].

دورة الحياة

يتم إنشاء مثيل لـ ara::rds::IEEE1722RawDataStreamProducer حصريًا عبر دالة المصنع الثابتة Create [SWS_RDS_90323]. وتخضع الفئة لدلالات نقل فقط صارمة: حيث تم حذف منشئ النسخ [SWS_RDS_90327] وكذلك عامل تعيين النسخ [SWS_RDS_90328] (=delete)، مما يمنع تكرار الموارد.

يمكن نقل المثيل إلى مالكين آخرين عبر منشئ النقل [SWS_RDS_90324] وعامل تعيين النقل [SWS_RDS_90326]. وفيما يتعلق بالتزامن، تم الإعلان عن عمليات النقل وكذلك المدمّر بأنها غير آمنة بالنسبة للخيوط [SWS_RDS_90324]، [SWS_RDS_90326]، [SWS_RDS_90329]؛ وتتطلب عمليات الوصول المتزامنة من خيوط مختلفة مزامنة خارجية.

بعد الإنشاء، يكون المنتج في البداية في حالة غير متصل. ويتم إنشاء الاتصال عبر Connect [SWS_RDS_90330]. يتم إنهاء الاتصال إما صراحةً عبر Shutdown [SWS_RDS_90331] أو تلقائيًا عند إتلاف المثيل: حيث يضمن المدمّر ~IEEE1722RawDataStreamProducer() إيقاف تشغيل أي اتصال لا يزال مفتوحًا [SWS_RDS_90329].

مخطط الحالة: مراحل دورة حياة المنتج من الإنشاء عبر إنشاء الاتصال وحتى الإغلاق. المصادر: [SWS_RDS_90323]، [SWS_RDS_90330]، [SWS_RDS_90331]، [SWS_RDS_90329]، [SWS_RDS_90332].

مسار الاستخدام

ينقسم المسار المنتظم لنقل تدفقات بيانات IEEE-1722 إلى المراحل التالية:

  1. الإنشاء: يُنشئ التطبيق مثيل المنتج عبر Create مع تحديد معرّف instance [SWS_RDS_90323] ويستلم المثيل المُرجع.
  2. إنشاء الاتصال: قبل نقل البيانات، يستدعي التطبيق Connect [SWS_RDS_90330] لفتح قناة الاتصال.
  3. نقل البيانات: بعد ذلك، يتم تسليم مخططات البيانات كمتجه من النوع T عبر WriteData(std::vector<T> data) إلى الشبكة [SWS_RDS_90332]. ويمكن تكرار هذه الخطوة دورياً أو بناءً على الأحداث.
  4. إنهاء الاتصال: بعد اكتمال عمليات النقل، يُنهي Shutdown الاتصال صراحةً [SWS_RDS_90331]. كبديل لذلك، يغلق المدمّر الاتصال عند مغادرة نطاق الصلاحية [SWS_RDS_90329].

مخطط التسلسل: المسار النموذجي لنقل البيانات من إنشاء المثيل وحتى إنهاء الاتصال. المصادر: [SWS_RDS_90323]، [SWS_RDS_90330]، [SWS_RDS_90332]، [SWS_RDS_90331].

سيناريوهات الأخطاء

تم تحديد عمليات الفئة كـ noexcept وتستخدم نموذج الخطأ ara::core::Result:

  • يُرجع Create ara::core::Result<IEEE1722RawDataStreamProducer<T>> [SWS_RDS_90323]. وفي حال وجود تكوين غير صحيح أو نقص في الموارد، تتضمن النتيجة رمز خطأ مطابقاً بدلاً من المثيل.
  • يُبلغ Connect عن فشل إنشاء الاتصال عبر ara::core::Result<void> [SWS_RDS_90330].
  • يُرجع WriteData ara::core::Result<void> [SWS_RDS_90332]. تفسير: يُفترض أن الاستدعاء يتطلب إتمام إنشاء اتصال ناجح مسبقًا بواسطة Connect؛ وفي حال عدم وجود اتصال أو حدوث أخطاء إرسال داخلية، يتم الإبلاغ عن خطأ. سؤال Q-ee438b8710c58062 (مفتوح)
  • يُشير Shutdown أيضًا إلى أي أخطاء محتملة أثناء إغلاق الاتصال عبر ara::core::Result<void> [SWS_RDS_90331].

تفسير: لم يتم تحديد قيم ara::core::ErrorCode ملموسة في مقتطف الواجهة، ويجب التحقق منها بشكل خاص بالتطبيق عبر Result المُرجع. سؤال Q-472e6d4a603c883d (مفتوح)

يستند هذا الدليل حصرياً إلى مواصفات واجهة AUTOSAR Adaptive R25-11 وقد تم إنشاؤه تلقائياً.
