السياق

توفر الفئة ara::per::KeyValueStorage مخزن مفتاح-قيمة دائمًا ضمن AUTOSAR Adaptive Platform. وتتمثل مسؤوليتها الأساسية في تغليف وإدارة مجموعة من المفاتيح الفريدة مع قيم البيانات المقترنة بكل منها. وتعمل الفئة كواجهة معاملات بين العمليات التطبيقية ووسيط التخزين الفيزيائي. وتُنفذ عمليات القراءة والكتابة بشكل غير مقترن عبر دلالات المعاملات، بحيث لا تُثبّت التعديلات بشكل دائم في التخزين الفيزيائي إلا عبر خطوة مزامنة صريحة [SWS_PER_00049].

مخطط السياق: دمج واجهة KeyValueStorage بين التطبيق ووحدة التخزين الفيزيائية. المصادر: [SWS_PER_00042]، [SWS_PER_00046]، [SWS_PER_00049]

دورة الحياة

تخضع نسخ ara::per::KeyValueStorage لقواعد ملكية ودورة حياة صارمة. تم تحديد كل من المنشئ الافتراضي [SWS_PER_00459]، ومنشئات النسخ والنقل [SWS_PER_00324]، [SWS_PER_00322]، وعوامل التعيين [SWS_PER_00325]، [SWS_PER_00323] على أنها محذوفة (=delete). ويتم إنشاء الكائنات عبر الدالة OpenKeyValueStorage() [SWS_PER_00365]. ويُرجح أن إدارة النسخ تتم من قِبل المتصل عبر هياكل ملكية قائمة على المؤشرات مثل Smart Pointer.

أثناء التشغيل، تم تصميم الفئة لتكون آمنة بالنسبة للخيوط: يمكن استدعاء كافة الواجهات الوظيفية بالتوازي من خيوط متعددة، حيث يمكن أن تؤدي الاستدعاءات المتنافسة إلى تأخيرات متبادلة [SWS_PER_00046]، [SWS_PER_00049]. وعند الإتلاف عبر المدمّر [SWS_PER_00050] تنتهي هذه الحماية: إذ تم تحديد المدمّر نفسه صراحةً على أنه غير آمن بالنسبة للخيوط، ويتطلب تحريرًا منسقًا دون وصول متزامن.

مسار الاستخدام

يتضمن مسار الاستخدام النموذجي التحقق من صحة المفاتيح الموجودة، وتعيين القيم أو تحديثها، بالإضافة إلى الحفظ الدائم النهائي:

  1. الفحص والاستعلام: قبل التحديث، يمكن فحص وجود المفتاح باستخدام KeyExists [SWS_PER_00043]. ويمكن سرد المفاتيح الموجودة بالفعل باستخدام GetAllKeys [SWS_PER_00042]، أو تحديد حجمها بالبايت عبر GetCurrentValueSize [SWS_PER_00554]، أو قراءة محتواها عبر GetValue [SWS_PER_00332]، [SWS_PER_00044].
  2. الكتابة المعاملاتية: يتم تخزين القيم المحددة النوع أو الكتابة فوقها عبر SetValue [SWS_PER_00046]. وبالمثل، يزيل RemoveKey [SWS_PER_00047] أو RemoveAllKeys [SWS_PER_00048] الإدخالات. وتسري جميع التغييرات مبدئيًا فقط ضمن المعاملة الحالية.
  3. الإتمام أو الإلغاء: يؤدي استدعاء SyncToStorage [SWS_PER_00049] إلى كتابة جميع التغييرات المعلقة بشكل دائم في وحدة التخزين الفعلية. وإذا كان يتعين التراجع عن التعديلات غير المحفوظة منذ آخر مزامنة أو فتح، يُستخدم DiscardPendingChanges [SWS_PER_00365] لهذا الغرض. وفي حالة وجود أعطال أو أخطاء في التكوين، يمكن إعادة تعيين المفاتيح إلى القيمة الأولية المكونة عبر ResetKey [SWS_PER_00426] أو استعادتها عبر RecoverKey [SWS_PER_00427] بعد أخطاء السلامة.

مخطط تسلسلي: وصول الكتابة مع دلالات المعاملات والتفريغ الفعلي. المصادر: [SWS_PER_00046]، [SWS_PER_00049]

سيناريوهات الأخطاء

تشير طرق KeyValueStorage إلى الأخطاء عبر ara::core::Result باستخدام رموز خطأ محددة من PerErrc:

  • أخطاء المفاتيح والأنواع: إذا حاول المتصل الوصول إلى إدخالات غير موجودة، تُرجع GetValue وGetCurrentValueSize وRemoveKey وRecoverKey الخطأ PerErrc::kKeyNotFound [SWS_PER_00332]، [SWS_PER_00554]، [SWS_PER_00047]، [SWS_PER_00427]. وإذا كان نوع بيانات القالب في SetValue أو GetValue لا يتطابق مع النوع المخزن، ترد واجهة برمجة التطبيقات (API) بـ PerErrc::kDataTypeMismatch [SWS_PER_00046]، [SWS_PER_00044]. وإذا لم تكن هناك قيمة أولية لمفتاح ما، يُرجع ResetKey الرمز PerErrc::kInitValueNotAvailable [SWS_PER_00426].
  • حدود الوصول والسعة: إذا كانت وحدة التخزين للقراءة فقط أو تم تكوينها كـ write-only-once وكان المفتاح موجودًا بالفعل، فإن أي عملية كتابة (مثل SetValue، RemoveKey، SyncToStorage) تؤدي إلى PerErrc::kIllegalWriteAccess [SWS_PER_00046]، [SWS_PER_00049]. ويؤدي تجاوز حجم التخزين إلى PerErrc::kOutOfStorageSpace أو عند الوصول إلى الحد المكوَّن إلى PerErrc::kQuotaExceeded [SWS_PER_00046]، [SWS_PER_00049].
  • أخطاء العتاد والسلامة والأمان: يظهر تعطل وسيط التخزين في PerErrc::kPhysicalStorageFailure. وفي حال فشل مجاميع التحقق، أو عمليات التحقق من الصحة، أو التشفير أو فك التشفير، أو فحوصات MAC، تُبلغ العمليات PerErrc::kIntegrityCorrupted، أو PerErrc::kValidationFailed، أو PerErrc::kEncryptionFailed، أو PerErrc::kAuthenticationFailed [SWS_PER_00042]، [SWS_PER_00046]، [SWS_PER_00049].

يستند هذا الدليل حصريًا إلى متطلبات المواصفات الخاصة بإصدار AUTOSAR Adaptive R25-11 للوحدة per.

ResetKey دالة

Resets a key of this Key-Value Storage to its initial value. ResetKey allows to reset a single key to its initial value. If the key is currently not available in the Key-Value Storage, it is re-created. Afterwards, the key-value pair will appear in both cases as if it was newly installed from the current Target Configuration. ResetKey will fail with kInitValueNotAvailable when neither Application Design nor Target Configuration define an initial value for the key.
