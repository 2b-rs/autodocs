الغرض من الاستخدام

ara::core::Vector<T, Allocator> ينفذ الحاوية std::pmr::vector المتسلسلة مع مورد الذاكرة ذو المعلمات [SWS_CORE_01301] [SWS_CORE_01303]. وهو يوفر إدارة الحجم والسعة، والوصول العشوائي إلى العناصر، والمكررات ومعدلات الحاويات [SWS_CORE_01348] [SWS_CORE_01355] [SWS_CORE_01332] [SWS_CORE_01362] [SWS_CORE_01372].

جيل وأمبير. دمار

يمكن إنشاء الحاوية فارغة، من Allocator، مع عدد من العناصر أو نطاق أو قائمة مُهيئ [SWS_CORE_01318] [SWS_CORE_01319] [SWS_CORE_01320] [SWS_CORE_01322] [SWS_CORE_01325]. تتوفر عمليات النسخ والنقل وآمنة بشكل مشروط اعتمادًا على T وAllocator، على التوالي؛ المدمر هو noexcept [SWS_CORE_01314] [SWS_CORE_01315] [SWS_CORE_01316] [SWS_CORE_01317] [SWS_CORE_01326].

التفاعل مع الفئات الأخرى

يعيد data() مؤشرًا إلى العناصر. تتحكم reserve() وshrink_to_fit() وresize() وcapacity() في السعة أو تراقبها [SWS_CORE_01360] [SWS_CORE_01361] [SWS_CORE_01347] [SWS_CORE_01349] [SWS_CORE_01350] [SWS_CORE_01348]. وتغيّر emplace_back وpush_back وinsert وerase وclear المحتوى [SWS_CORE_01362] [SWS_CORE_01363] [SWS_CORE_01367] [SWS_CORE_01372] [SWS_CORE_01375].

القيود & معالجة الأخطاء

تطلق at() ‏IsoStdOutOfRangeViolation خارج الحدود [SWS_CORE_01354] [SWS_CORE_01355]. وبالنسبة إلى القيم الكبيرة جدًا في reserve() أو resize()، تُحدد IsoStdLengthErrorViolation [SWS_CORE_01347] [SWS_CORE_01350] [SWS_CORE_01351]. كثير من عمليات التعديل ليست آمنة من الاستثناءات؛ وتكون push_back وswap آمنتين من الاستثناءات بشكل مشروط تبعًا لخصائص النوع وAllocator ‏[SWS_CORE_01362] [SWS_CORE_01372] [SWS_CORE_01363] [SWS_CORE_01364] [SWS_CORE_01374].

قاعدة حاوية لأنواع بيانات المتجهات النموذجية

يقوم Core بتشغيل Vector كحاوية مشتقة من مكتبة C++ القياسية. يستخدم ربط اللغة اسمًا مستعارًا لـ C++ مع مُخصص قابل للتكوين وأقصى حجم اختياري لـ Vektor-Datentypen النموذجي. وبالتالي يقوم النوع بتوصيل Container-API العام بأنواع الواجهة التي تم إنشاؤها. SWS Core §7.4 «Core data types» SWS Core §7.4.2 «Data types derived from the C++ standard» SWS LanguageBinding §7.1 «C++ binding for CppImplementationDataTypes» SWS LanguageBinding §8.2.4 «Vector Data Type»

يبقى اختيار Allocator وسلوكه جزءًا من عقد Binding أو التنفيذ المحدد. تفسير: ينبغي تخطيط تغييرات السعة مثل reserve() أو resize()، عند وجود أحجام قصوى ممثلة في النموذج، مقابل حد النموذج هذا، بدلًا من اعتبارها مجرد تحسين محلي لـ Container.

مخطط النشاط: يتم التعبير عن Vektor-Datentyp النموذجي في ربط اللغة كنوع C++ مع قاعدة ara::core::Vector. التفسير الجزئي: العقدة الأخيرة تلخص الاستخدامات المحتملة كحقل أو معلمة. المصادر: SWS LanguageBinding §8.2.4 «Vector Data Type» SWS Core §7.4.2 «Data types derived from the C++ standard».
