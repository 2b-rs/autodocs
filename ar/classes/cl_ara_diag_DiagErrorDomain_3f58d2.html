فئة ara::diag::DiagErrorDomain

[SWS_DM_00517] Upstream: RS_AP_00119

class DiagErrorDomain final :             public ara::core::ErrorDomain {...};

Error domain for diagnostic errors.

دليل المستخدم مولَّد بالذكاء الاصطناعي / AI generated

وصف مولّد تلقائيًا، مستمد مضمونيًا من عناصر مواصفات AUTOSAR-R25-11 المشار إليها — وليس نصًا رسميًا من AUTOSAR. الأدلة: إحالات [SWS_…].

DiagErrorDomain هو Error Domain نهائي للأخطاء التشخيصية ويرث من ara::core::ErrorDomain. المُنشئ الافتراضي هو constexpr وآمن من الاستثناءات وآمن للخيوط. [SWS_DM_00517] [SWS_DM_00520]

تقوم Name() بإرجاع الاسم المختصر لمجال خطأ التطبيق المرتبط. يقوم Message() بترجمة رمز الخطأ إلى نص لا يتم تصفيره أبدًا. ThrowAsException() يطرح الاستثناء المطابق لـ ErrorCode؛ إذا تم تعطيل استثناءات C++، فلن تشارك هذه الطريقة في حل التحميل الزائد. [SWS_DM_00521] [SWS_DM_00522] [SWS_DM_00523]

نظرة عامة على الطريقة

  • constexpr DiagErrorDomain () noexcept; Default constructor.
  • const char * Message (ara::core::ErrorDomain::CodeType errorCode) const noexcept override; Translate an error code value into a text message.
  • const char * Name () const noexcept override; Return the "shortname" ApApplicationErrorDomain.SN of this error domain.
  • void ThrowAsException (const ara::core::ErrorCode &errorCode) const noexcept(false) override; Throw the exception type corresponding to the given ErrorCode
