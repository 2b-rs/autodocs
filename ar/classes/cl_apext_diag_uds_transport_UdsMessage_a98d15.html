فئة apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

الغرض من الاستخدام

يمثل UdsMessage رسالة UDS بين نواة DM العامة أو UdsTransportProtocolMgr وتنفيذ محدد لـ UdsTransportProtocolHandler. ويوفر الكائن ذاكرة لطلبات UDS واستجاباتها. [SWS_DM_00291]

الإنشاء & Ownership

تنشأ المثيلات ذات تخصيص الموارد المحسن حصريًا بواسطة نواة DM؛ ويجوز لـ Protocol Handler قراءتها وكتابتها، لكن لا ينبغي له إنشاؤها بنفسه. لذلك يكون المُنشئ الافتراضي محميًا. عند Indication مقبولة، يملك UdsMessagePtr كائنًا صالحًا بسعة لا تقل عن بايت واحد؛ ويكون Buffer الذي تعيده GetPayload() فارغًا في البداية.
