فئة ara::exec::FunctionGroupState

[SWS_EM_02269] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150, RS_AP_00129

class FunctionGroupState final {...};

Class representing Function Group State defined in meta-model (ARXML). An instance of this class will represent Function Group State defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

تمثل الفئة ara::exec::FunctionGroupState حالة مجموعة وظائف معرّفة في نموذج AUTOSAR الفوقي وتربطها طوال دورة حياتها بمجموعة وظائف محددة وبمسار ARXML المرتبط بها [SWS_EM_02324]. تُنشأ النسخ باستخدام الاسم القصير (Short-Name) للتصريح الهدف، وتدعم دلالات النسخ والنقل الكاملة، وتتيح المقارنة المباشرة للتكافؤ بين حالات النموذج [SWS_EM_02273]. تم تعريف جميع العمليات على أنها آمنة من الاستثناءات وكذلك noexcept، في حين لا يجوز تنفيذ عمليات التعيين المعدِّلة وعمليات الإتلاف بشكل تزامني دون مزامنة، على عكس المقارنات الآمنة خيطياً (thread-safe).

السياق

تمثل الفئة ara::exec::FunctionGroupState حالة مجموعة وظائف معرّفة في نموذج AUTOSAR الفوقي (ARXML). وتعمل نسخة من هذه الفئة داخل الوحدة exec في Adaptive Platform كتمثيل خاص بالتنفيذ لمعلومات النموذج الفوقي المقابلة. ويتم ربط الحالة دائماً بمجموعة وظائف محددة يتم الرجوع إليها عبر نسخة من FunctionGroup، بالإضافة إلى تحديدها كسلسلة نصية عبر الاسم القصير (Short-Name) لـ ModeDeclaration المقترنة بها [SWS_EM_02324]. وباستخدام معامِلات المساواة وعدم المساواة، يمكن مقارنة النسخ ببعضها مباشرةً لتحديد ما إذا كانت تمثل نفس عنصر النموذج الفوقي [SWS_EM_02273] [SWS_EM_02274].

مخطط سياق: دمج FunctionGroupState بين مجموعة الوظائف ونموذج ARXML الفوقي. المصادر: [SWS_EM_02324]، [SWS_EM_02273].

دورة الحياة

يتم إنشاء النسخة عبر المُنشئ ذي المعلمات، والذي يستقبل مرجعاً إلى FunctionGroup المقترنة بالإضافة إلى ara::core::StringView يحمل اسم ModeDeclaration [SWS_EM_02324]. بعد الإنشاء، تظل القيمة الداخلية للكائن مرتبطة بشكل ثابت طوال فترة حياته بمسار ARXML الأساسي. تدعم الفئة دلالات القيمة الكاملة:

  • النسخ: يتيح مُنشئ النسخ [SWS_EM_02325] ومعامِل تعيين النسخ [SWS_EM_02330] تكرار النسخ.
  • النقل: عبر مُنشئ النقل [SWS_EM_02331] ومعامِل تعيين النقل [SWS_EM_02332]، يمكن نقل الموارد بكفاءة إلى نسخ جديدة أو موجودة.
  • الإتلاف: يقوم الهادم بتحرير موارد النسخة على النحو الصحيح [SWS_EM_02272].

فيما يتعلق بالتزامن، يُعد إنشاء نسخة عبر المُنشئ آمناً خيطياً (thread-safe) [SWS_EM_02324]. كما أن عمليات المقارنة آمنة خيطياً أيضاً [SWS_EM_02273] [SWS_EM_02274]. وفي المقابل، تم التصريح بأن جميع عمليات دورة الحياة المعدِّلة — بما في ذلك مُنشئ النسخ [SWS_EM_02325] ومُنشئ النقل [SWS_EM_02331] وتعيين النسخ [SWS_EM_02330] وتعيين النقل [SWS_EM_02332] والهادم [SWS_EM_02272] — غير آمنة خيطياً (not thread-safe).

مسار الاستخدام

يتضمن مسار الاستخدام النموذجي إنشاء تمثيل الحالة وتمريره وتقييمه وإتلافه:

  1. إنشاء النسخة: ينشئ التطبيق كائن FunctionGroupState مع تحديد مجموعة الوظائف المستهدفة واسم ModeDeclaration [SWS_EM_02324].
  2. التمرير أو التعيين: يمكن تمرير الكائن عند الحاجة عبر النسخ [SWS_EM_02325] أو النقل [SWS_EM_02331]، أو تعيينه لمتغيرات موجودة [SWS_EM_02330] [SWS_EM_02332].
  3. مقارنة الحالة: أثناء وقت التشغيل، تتم مقارنة النسخة بنسخة أخرى للتحقق مما إذا كانت الاثنتان تمثلان نفس عنصر النموذج الفوقي [SWS_EM_02273] أو تختلفان عن بعضهما [SWS_EM_02274].
  4. التحرير: عند مغادرة نطاق الصلاحية (Scope)، يتم إتلاف النسخة عبر الهادم [SWS_EM_02272].

سيناريوهات الأخطاء

تم التصريح عن جميع دوال الفئة باستخدام noexcept وتحديدها على أنها آمنة من الاستثناءات (exception safe) [SWS_EM_02324] [SWS_EM_02325] [SWS_EM_02331] [SWS_EM_02330] [SWS_EM_02332] [SWS_EM_02273] [SWS_EM_02274] [SWS_EM_02272]. فلا يتم إطلاق استثناءات C++ ولا يتم الإبلاغ عن رموز أخطاء عبر أنواع الإرجاع مثل ara::core::Result.

الشرط المسبق للإنشاء الخالي من الأخطاء هو توفر FunctionGroup صالحة وModeDeclaration معرّفة في النموذج الفوقي [SWS_EM_02324]. تفسير: نظراً لأن المُنشئ [SWS_EM_02324] لا يُرجع كائنات أخطاء ولا يُطلق استثناءات، فمن المرجح ألا يتم اعتراض تمرير أسماء غير موجودة في النموذج الفوقي عبر رموز أخطاء API القياسية، بل يتطلب على الأرجح نموذج نظام مهيأ بشكل صحيح قبل إنشاء النسخة.

يتعلق سيناريو خطأ آخر بالتزامن غير المنسق: إذا نُفّذت عمليات النسخ أو النقل أو الإتلاف دون مزامنة خارجية بشكل متزامن على نفس النسخة، فإن ذلك يهدد بحدوث حالات سباق (Race Conditions)، لأن هذه الواجهات ليست آمنة خيطياً [SWS_EM_02325] [SWS_EM_02330] [SWS_EM_02331] [SWS_EM_02332] [SWS_EM_02272].

يستند هذا الدليل إلى مواصفة AUTOSAR Adaptive Platform برقم R25-11 للوحدة exec وتم إنشاؤه تلقائياً.
