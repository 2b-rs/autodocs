فئة ara::exec::FunctionGroupState

[SWS_EM_02269] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150, RS_AP_00129

class FunctionGroupState final {...};

Class representing Function Group State defined in meta-model (ARXML). An instance of this class will represent Function Group State defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

قيمة تكوين لمجموعة العمليات

يمثل FunctionGroupState حالة مكوَّنة لـ Function Group. وتحدد هذه الحالة العمليات الممثلة في النموذج التي ينبغي تشغيلها عند تنشيطها؛ وتكون حالة واحدة بالضبط نشطة لكل Function Group SWS EM §7.4.3 «Function Group State».

الاستخدام في Transition-Request

State Management ينشئ الحالات المستهدفة من FunctionGroup وأسماء الحالات ويمررها إلى StateClient::SetState. Execution Management ينهي العمليات التي لم تعد مطلوبة ثم يبدأ العمليات المخصصة للحالة المستهدفة بالترتيب المطلوب SWS EM §7.4.5 «State Transition».

مخطط الحالة: Off هي الحالة الابتدائية الإلزامية؛ والحالة النشطة مكوَّنة على نحو خاص بالمشروع [SWS_EM_01110] SWS EM §7.4 «State Management». تفسير: يجرد العرض أسماء حالات Manifest المحددة.
