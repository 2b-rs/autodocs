[SWS_CORE_06221] Upstream: RS_AP_00130

template <typename E> class Future< void, E > final {...};

Specialization of class Future for "void" values. The implementation shall flag the condition: ( E != ara::core::ErrorCode ) as a compile error.

يتيح الانتظار حتى اكتمال عملية غير متزامنة بدون قيمة معادة، بالإضافة إلى استخراج حالة الخطأ.

تتيح الفئة ara::core::Future<void, E> المزامنة غير المتزامنة والتحقق من الأخطاء للعمليات التي لا تتضمن قيمة معادة في AUTOSAR Adaptive [SWS_CORE_06236]. وباعتبارها نوعًا غير قابل للنسخ، فإنها تتيح الانتظار حتى الاكتمال، بالإضافة إلى استرداد النتيجة الآمن ضد الاستثناءات كـ ara::core::Result<void, E> [SWS_CORE_06236] أو مواصلة المعالجة غير المتزامنة عبر دالة استمرار [SWS_CORE_06231]. بعد استخراج النتيجة، يتم إبطال الحالة المشتركة، بحيث تشكل الاستدعاءات اللاحقة دون حالة صالحة انتهاكًا [SWS_CORE_06236].

السياق

يمثل تخصيص فئة القالب ara::core::Future<void, E> طرف الاستقبال لعملية غير متزامنة في AUTOSAR Adaptive، والتي لا تعيد قيمة عند الاكتمال الناجح، بل تشير فقط إلى وقوع الحدث أو حدوث خطأ. ووفقًا لوصف الفئة، يجب على التنفيذ إنهاء الشرط E != ara::core::ErrorCode بخطأ ترجمة. تتفاعل الفئة عادةً مع ara::core::Promise مطابق يملأ الحالة المشتركة (Shared State) [SWS_CORE_06236]، وكذلك مع سياقات تنفيذ غير متزامنة عند تسجيل دوال الاستمرار [SWS_CORE_06237].

دورة الحياة

مثيلات ara::core::Future<void, E> هي كائنات ذات دلالات نقل بحتة: حيث تم حذف منشئ النسخ [SWS_CORE_06234] وعامل تشغيل التعيين بالنسخ [SWS_CORE_06235] (delete). والكائن الذي يتم إنشاؤه عبر المنشئ الافتراضي لا يمتلك حالة مشتركة ويتصرف بشكل مماثل لـ std::future [SWS_CORE_06222]. ومن خلال الإنشاء بالنقل [SWS_CORE_06223] أو التعيين بالنقل [SWS_CORE_06225]، يتولى مثيل ما ملكية Shared State من مثيل آخر.

تتشكل دورة الحياة بشكل أساسي من خلال وضع Shared State. وعبر الطريقة valid()، يمكن التحقق مما إذا كان المثيل مرتبطًا بـ Shared State وبالتالي قابلاً للاستخدام [SWS_CORE_06227]. وبمجرد استرداد النتيجة بواسطة GetResult() [SWS_CORE_06236] أو get() [SWS_CORE_06226] أو تسجيل استمرار عبر then() [SWS_CORE_06231]، يفقد كائن Future حالته المشتركة ويعيد valid() القيمة false. ويحرر المدمر أي حالة مشتركة متبقية [SWS_CORE_06233]. وفيما يتعلق بالتزامن، فإن عمليات الفحص والتدمير مثل valid() [SWS_CORE_06227] وis_ready() [SWS_CORE_06232] والمدمر [SWS_CORE_06233] آمنة بالنسبة للخيوط (thread-safe)، في حين أن العمليات المعدلة للحالة مثل GetResult() [SWS_CORE_06236] وget() [SWS_CORE_06226] ودوال الانتظار [SWS_CORE_06228] ليست آمنة بالنسبة للخيوط.

مخطط الحالة: انتقالات الحالة وصلاحية <ara::core::Future<void, E. المصادر: [SWS_CORE_06222]، [SWS_CORE_06226]، [SWS_CORE_06227]، [SWS_CORE_06231]، [SWS_CORE_06232]، [SWS_CORE_06233]، [SWS_CORE_06236]

مسار الاستخدام

في مسار الاستخدام المتزامن، ينتظر المستهلك اكتمال العملية غير المتزامنة. وباستخدام is_ready()، يمكن الاستعلام بحد أدنى من الحظر عما إذا كانت هناك قيمة أو خطأ [SWS_CORE_06232]. وبدلاً من ذلك، يمكن الانتظار بشكل حظري بواسطة wait() [SWS_CORE_06228]، أو لفترة زمنية محددة عبر wait_for() [SWS_CORE_06229] وwait_until() [SWS_CORE_06230]. وإذا كانت النتيجة متاحة، يتم الاستعلام عن القيمة ويفضل أن يكون ذلك بأسلوب آمن ضد الاستثناءات عبر GetResult()، وبذلك يُعاد ara::core::Result<void, E> [SWS_CORE_06236].

في المسار غير المتزامن، تتيح الطريقة then() تسجيل دالة استمرار (Continuation) يتم تنفيذها بمجرد توفر النتيجة [SWS_CORE_06231]. وهنا يمكن اختياريًا تمرير سياق تنفيذ (Executor) [SWS_CORE_06237]. وتستقبل دالة الاستمرار Result<void, E> كـ Rvalue. يقوم نوع الإرجاع لـ then() بفك أنواع Future أو Result المتداخلة تلقائيًا (Unwrapping) [SWS_CORE_06231].

مخطط التتابع: التسلسل المتزامن للاستعلام عن النتيجة عبر GetResult. المصادر: [SWS_CORE_06227]، [SWS_CORE_06228]، [SWS_CORE_06232]، [SWS_CORE_06236]

سيناريوهات الأخطاء

إذا تم استدعاء عملية معتمدة على الحالة (مثل GetResult() أو is_ready() أو wait() أو wait_for() أو wait_until() أو then()) على مثيل غير صالح (valid() == false)، فإن ذلك يعد انتهاكًا للشرط المسبق ويُعامل كـ FutureInvalidViolation [SWS_CORE_06228]، [SWS_CORE_06229]، [SWS_CORE_06230]، [SWS_CORE_06231]، [SWS_CORE_06232]، [SWS_CORE_06236]، [SWS_CORE_06237]. وعند استدعاء get() على مثيل غير صالح، يتم بدلاً من ذلك إطلاق FutureException برمز الخطأ kNoState [SWS_CORE_06226]؛ ولا يشارك get() في حل التحميل الزائد (Overload Resolution) عند تعطيل استثناءات ++C [SWS_CORE_06226].

إذا تم تدمير الـ Promise المقابل أو غادر الحالة المشتركة دون تعيين نتيجة أو خطأ صريح، يتم إيداع رمز الخطأ FutureErrc::kBrokenPromise وفقًا لـ [SWS_CORE_00400] في Shared State [SWS_CORE_06226]، [SWS_CORE_06236]. ويتم إرجاع هذا الرمز بواسطة GetResult() كخطأ في Result<void, E> [SWS_CORE_06236]. وإذا أطلقت دالة استمرار مسجلة في then() استثناءً لا ينفذ انتهاكًا، فإن هذا يؤدي إلى FutureContinuationHasThrownViolation [SWS_CORE_06231]، [SWS_CORE_06237].

يستند هذا الدليل حصريًا إلى مواصفة AUTOSAR لـ <ara::core::Future<void, E في الإصدار R25-11.

Let U be the return type of the continuation (i.e. a type equivalent to std::invoke_result_ t<std::decay_t<F>,Result<void,E>>). • If U is Future<T2,E2> for some types T2, E2, then the return type of then() is Future<T2,E2>. No such continuation shall be executed after the destructor of the Future F returns. A continuation that is already being executed shall run to completion. Note: that means that the destructor of Future might block until the currently running continuation has been completed. The continuation shall not throw, except for the purpose of implementing a Violation.                                       template <typename F, typename ExecutorT> auto then (F &&func, ExecutorT &&executor) noexcept -> Future< <see below> >;
                                      

                                      Create a new Future with the content returned by func when passed the Result of this Future. func is called in the context of the provided execution context executor. valid() == false on the original future object immediately after it returns. The Callable input argument "func" takes a Result<void,E> object as parameter. This will be the Result obtained via GetResult from the Future instance itself, on which .then() is being called. The Result is passed to func as an rvalue expression. The return type of then depends on the return type of func (aka continuation). Let U be the return type of the continuation (i.e. a type equivalent to std::invoke_result_ t<std::decay_t<F>,Result<void,E>>). • If U is Future<T2,E2> for some types T2, E2, then the return type of then() is Future<T2,E2>. This is known as implicit Future unwrapping. • If U is Result<T2,E2> for some types T2, E2, then the return type of then() is Future<T2,E2>.
