تعمل كواجهة لتنفيذ تحديثات البرمجيات عبر بروتوكول ASAM SOVD في خادم تشخيص AUTOSAR.

توفر الفئة واجهة من جهة التطبيق لتنفيذ تحديثات البرمجيات القياسية عبر بروتوكول SOVD وفقاً لـ ASAM SOVD [SWS_DM_01796]. بعد إنشاء النسخة، ينشط التطبيق إعادة توجيه طلبات التشخيص إلى معالجات التحديث المحددة عبر الدالة Offer() [SWS_DM_01924]. وتُسجل الحزم وتُجهز وتُثبت آلياً أو يدوياً وتُحذف مجدداً عبر دوال غير متزامنة. وتتم معالجة كافة العمليات ذات الصلة بنقل البيانات ودورة الحياة بشكل غير حاجب عبر كائنات Futures.

السياق

تحدد الفئة ara::diag::SovdSwUpdate الواجهة لتنفيذ تحديثات البرمجيات القياسية وفقاً لـ ASAM SOVD ضمن AUTOSAR Adaptive Platform [SWS_DM_01874]. ونظراً لأن منطق العمل الفعلي لتحديثات البرمجيات لا يقع ضمن الكتلة الوظيفية Diagnostic Management (DM)، فإن التنفيذ يظل من مسؤولية التطبيق المعني، بينما يركز ara::diag::SovdSwUpdate على المعالجة المتوافقة مع المعايير لبروتوكول SOVD الأساسي AUTOSAR_AP_SWS_Diagnostics §7.4 «SOVD Software Update API - concept». وتُستخدم لتحميل ملفات التحديث استراتيجيات نقل كالتي تم تحديدها لخدمة UDS ذات الرمز 0x38 (RequestFileTransfer) AUTOSAR_AP_SWS_Diagnostics §7.4 «SOVD Software Update API - concept»، [SWS_DM_01923].

تشترك ثلاثة مكونات رئيسية في العمليات: عميل SOVD الخارجي، ونسخة خادم التشخيص (DM) لإدارة البروتوكول والمسارات، وتنفيذ المعالج الخاص بالتطبيق لـ ara::diag::SovdSwUpdate [SWS_DM_01796]، [SWS_DM_01924].

مخطط السياق: التفاعل بين عميل SOVD وخادم التشخيص (DM) وara::diag::SovdSwUpdate. المصادر: [SWS_DM_01796]، [SWS_DM_01924]، AUTOSAR_AP_SWS_Diagnostics §7.4 «SOVD Software Update API - concept»

دورة الحياة

يتم إنشاء نسخة من ara::diag::SovdSwUpdate عبر المنشئ مع تحديد ara::core::InstanceSpecifier يشير إلى نموذج أولي لمنفذ تابع لـ DiagnosticSovdUpdateInterface مُصمَّم، بالإضافة إلى نمط التزامن (ConcurrencyType: kConcurrent أو kNotConcurrent) [SWS_DM_01910]. المنشئ محدد ليكون آمناً خيطياً وآمناً من حيث الاستثناءات [SWS_DM_01910]. وباعتباره ممثلاً لنسخة واجهة فريدة، فإن منشئ النسخ ومعامل إسناد النسخ محذوفان (=delete) ومحميان [SWS_DM_01912]، [SWS_DM_01914]. ويتوفر منشئ النقل وإسناد النقل بشكل محمي، إلا أنهما ليسا آمنين خيطياً [SWS_DM_01913]، [SWS_DM_01915].

تتم معالجة تدمير الكائن عبر المُدمّر الافتراضي ~SovdSwUpdate()، والذي يعتبر غير آمن خيطياً [SWS_DM_01911]. ويعتمد ما إذا كان يجب تنفيذ دوال رد الاتصال الافتراضية للفئة بالتوازي بشكل مباشر على ConcurrencyType المُمرَّر إلى المنشئ [SWS_DM_01910]، [SWS_DM_01916].
