توفر الفئة ara::crypto::cryp::HashFunctionCtx واجهة لحساب قيم التجزئة التشفيرية عبر كتل الذاكرة وتدفقات البيانات ([SWS_CRYPT_50060]). تتطلب عمليات البث الالتزام بدورة المعالجة المكونة من التهيئة بواسطة Start()، والتمرير التدريجي للبيانات عبر Update()، والإنهاء بواسطة Finish()، والقراءة اللاحقة عبر GetDigest() ([SWS_CRYPT_21116]). تم تحديد جميع الطرق لتكون آمنة بالنسبة للخيوط، كما أنها تضمن دلالات التراجع وتبلغ عن أخطاء التسلسل أو المخزن المؤقت بشكل حتمي عبر كائنات النتائج.

السياق

تحدد الفئة ara::crypto::cryp::HashFunctionCtx في الوحدة crypto لـ AUTOSAR Adaptive Platform واجهة حساب قيم التجزئة التشفيرية والمجاميع الاختبارية. وباعتبارها تخصيصًا لـ CryptoContext، فإنها توفر طرقًا لعمليات الاستدعاء الفردية عديمة الحالة وكذلك لإجراءات البث ذات الحالة. تتم عادةً إدارة دورة الحياة والملكية عبر الاسم المستعار لنوع المؤشر الذكي Sptr ([SWS_CRYPT_21101])، والمعرّف كـ std::shared_ptr<HashFunctionCtx>.

تشمل أطراف التفاعل الأساسية ما يلي:

  • التطبيق المستدعي: يتحكم في دورة حياة الحساب ويمرر بيانات الإدخال كتلة تلو الأخرى أو كرسالة كاملة.
  • نطاقات الذاكرة: يتم نقل بيانات الإدخال، ومتجهات التهيئة (IV)، بالإضافة إلى مخازن الإخراج والحالة المؤقتة عبر ReadOnlyMemRegion وReadWriteMemRegion.
  • كائنات المفاتيح: عبر CryptoObject::Sptr، يمكن تضمين المفاتيح التشفيرية مباشرةً كمصدر للبيانات في حساب التجزئة ([SWS_CRYPT_50057]).
  • Crypto Provider: تفسير: من المحتمل أن يتم إنشاء حالات HashFunctionCtx عادةً عبر Crypto Provider مرتبط؛ ويتطلب تبادل حالات السياق المصدرة بشكل إلزامي استخدام نفس Crypto Provider ونفس معرّف الخوارزمية ([SWS_CRYPT_50065]).

دورة الحياة

تمر حالة من HashFunctionCtx بعدة حالات منفصلة أثناء معالجة البث:

مخطط الحالة: انتقالات حالة سياق التجزئة أثناء التهيئة والمعالجة والإنهاء. المصادر: [SWS_CRYPT_50152]، [SWS_CRYPT_50153]، [SWS_CRYPT_21113]، [SWS_CRYPT_50058]، [SWS_CRYPT_21115]، [SWS_CRYPT_50064]، [SWS_CRYPT_50065]

بعد الإنشاء، يكون السياق في حالة غير مبدوءة. من خلال استدعاء Start() بدون IV ([SWS_CRYPT_50152]) أو Start(iv) مع متجه تهيئة ([SWS_CRYPT_50153])، ينتقل السياق إلى مرحلة المعالجة النشطة. يتم تجاهل الحسابات الجارية بالفعل ضمنيًا بواسطة استدعاء بدء جديد.

في حالة المعالجة، يتم تجميع بيانات الإدخال عبر استدعاءات متكررة لـ Update() مع أجزاء البيانات الخام ([SWS_CRYPT_21113]) أو المفاتيح ([SWS_CRYPT_50057]). عبر GetIntermediateDigest()، يمكن حساب نتيجة وسيطة دون إنهاء السياق أو مقاطعة تدفق البيانات ([SWS_CRYPT_50059]). يمكن إلغاء عملية بث جارية في أي وقت باستخدام Cancel() ([SWS_CRYPT_50058])، مما يعيد السياق إلى الحالة غير المبدوءة.

يؤدي استدعاء Finish() إلى نقل السياق إلى الحالة «منتهٍ» ([SWS_CRYPT_21115]). في هذه الحالة فقط، يمكن استخراج قيمة التجزئة الناتجة عبر GetDigest() ([SWS_CRYPT_21116]) أو التحقق منها مباشرة مقابل قيمة متوقعة عبر Compare() ([SWS_CRYPT_50154]).

لمقاطعة الحسابات ومتابعتها لاحقًا، يمكن الاستعلام عن حجم المخزن المؤقت المطلوب باستخدام GetContextStateSize() ([SWS_CRYPT_50063]) وحفظ الحالة الداخلية عبر ExportContextState() ([SWS_CRYPT_50064]). وتتم المتابعة عبر ImportContextState() ([SWS_CRYPT_50065]). تم الإعلان عن جميع طرق الواجهة على أنها آمنة من الاستثناءات (exception safe) وآمنة بالنسبة للخيوط (thread-safe).

مسار الاستخدام

تدعم الفئة وضعي معالجة: الحساب المباشر بخطوة واحدة ومعالجة البث المجزأة.

يتم إجراء الحساب بخطوة واحدة عبر CalculateHashDigest() ([SWS_CRYPT_50060]). ويتم هنا تمرير بيانات الإدخال، وIV اختياري بالإضافة إلى نطاق الذاكرة الوجهة، ويتم حساب قيمة التجزئة في عملية ذرية.

بالنسبة لكميات البيانات الأكبر أو تدفقات البيانات المستمرة، يتم استخدام مسار البث:

مخطط التسلسل: التسلسل النموذجي لحساب البث عبر Start وUpdate وFinish وGetDigest. المصادر: [SWS_CRYPT_50152]، [SWS_CRYPT_21113]، [SWS_CRYPT_21115]، [SWS_CRYPT_21116]

  1. فحص السعة: الاستعلام عن حجم الإخراج عبر GetDigestSize() ([SWS_CRYPT_50061]) والحد الأقصى لحجم الكتلة عبر GetMaximumChunkSize() ([SWS_CRYPT_50062]).
  2. التهيئة: إعداد السياق عن طريق استدعاء Start() ([SWS_CRYPT_50152]) أو Start(iv) ([SWS_CRYPT_50153]).
  3. تمرير البيانات: التمرير المتتالي لكتل البيانات عبر Update(data) ([SWS_CRYPT_21113]) أو المفاتيح عبر Update(key) ([SWS_CRYPT_50057]).
  4. الإنهاء: إنهاء تجميع قيمة التجزئة بواسطة Finish() ([SWS_CRYPT_21115]).
  5. تقييم النتيجة: قراءة قيمة التجزئة المحسوبة باستخدام GetDigest() ([SWS_CRYPT_21116]) أو المقارنة الموضعية مع قيمة مرجعية عبر Compare() ([SWS_CRYPT_50154]).

سيناريوهات الأخطاء

تشير طرق HashFunctionCtx إلى الأخطاء عبر ara::core::Result وتضمن دلالات التراجع عند حدوث أخطاء. وتتمثل أسباب الأخطاء النموذجية في:

  • انتهاكات الترتيب:\nإذا تم استدعاء Update() ([SWS_CRYPT_21113]، [SWS_CRYPT_50057]) أو Cancel() ([SWS_CRYPT_50058]) دون استدعاء ناجح مسبق لـ Start()، فسيتم إرجاع CryptoErrc::kProcessingNotStarted.\nإذا تم استدعاء Finish() ([SWS_CRYPT_21115]) أو GetIntermediateDigest() ([SWS_CRYPT_50059]) دون تهيئة مسبقة، يبلغ السياق عن CryptoErrc::kInvalidUsageOrder.\nيفشل جلب النتائج عبر GetDigest() ([SWS_CRYPT_21116]) أو Compare() ([SWS_CRYPT_50154]) قبل تنفيذ Finish() مع ظهور CryptoErrc::kProcessingNotFinished.
  • مشاكل المخزن المؤقت والحجم:\nإذا لم يكن مخزن الإخراج المؤقت كافيًا، ينتج عن CalculateHashDigest() ([SWS_CRYPT_50060]) وGetDigest() ([SWS_CRYPT_21116]) وGetIntermediateDigest() ([SWS_CRYPT_50059]) بالإضافة إلى ExportContextState() ([SWS_CRYPT_50064]) الخطأ CryptoErrc::kInsufficientCapacity.\nتؤدي أطوال الإدخال أو IV غير المدعومة في CalculateHashDigest() وStart(iv) ([SWS_CRYPT_50153]) وUpdate() إلى CryptoErrc::kInvalidInputSize.
  • عدم التوافق ونقص دعم الوظائف:\nيشير CryptoErrc::kUnsupported إلى أن عمليات الاستدعاء الفردية غير مدعومة ([SWS_CRYPT_50060])، أو أن وجود IV لا يتناسب مع دالة التجزئة ([SWS_CRYPT_50152]، [SWS_CRYPT_50153])، أو أن النتائج الوسيطة غير متوفرة ([SWS_CRYPT_50059])، أو أن تصدير/استيراد السياق غير مدعوم ([SWS_CRYPT_50063]، [SWS_CRYPT_50064]، [SWS_CRYPT_50065])، أو أن تجزئة المفاتيح غير مسموح بها ([SWS_CRYPT_50057]).
  • التحقق من صحة الكائن والأذونات:\nعند تمرير المفاتيح عبر Update(key)، يؤدي استخدام مفتاح غير متوافق إلى CryptoErrc::kIncompatibleObject ويؤدي عدم وجود ترخيص لـ kAllowHashCalculation إلى CryptoErrc::kUsageViolation ([SWS_CRYPT_50057]).\nتؤدي محتويات المخزن المؤقت غير الصالحة عند ImportContextState() إلى إنشاء CryptoErrc::kInvalidArgument ([SWS_CRYPT_50065]).
  • اختناقات الموارد:\nإذا كان أحد موارد التشفير المطلوبة مشغولاً، يقر Start() بالمحاولة مع CryptoErrc::kBusyResource ([SWS_CRYPT_50152]، [SWS_CRYPT_50153]).
