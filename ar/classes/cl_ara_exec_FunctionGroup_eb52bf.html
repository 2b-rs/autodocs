فئة ara::exec::FunctionGroup

[SWS_EM_02263] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150

class FunctionGroup final {...};

Class representing Function Group defined in meta-model (ARXML). An instance of this class will represent Function Group defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

حدّ مجموعة عمليات تُدار باتساق

FunctionGroup هو ممثل API لـ Function Group مكوَّنة. وتجمع عمليات النموذج التي تبدأ وتنتهي بصورة متسقة عبر الحالات؛ ولا يجوز إسناد عملية نموذج إلى أكثر من Function Group واحدة SWS EM §7.4.3 «Function Group State».

MachineFG والمجموعات القريبة من التطبيق

تصف Function Group MachineFG حالات الآلة وتخدم بالأساس Lifecycle الآلة. وتتحكم Function Groups أخرى عادةً في مجموعات من تطبيقات User-Level. ويأتي التعيين الفعلي للعمليات من Execution Manifests SWS EM §7.4 «State Management».

مخطط حالات: تطلب State Management انتقال حالة Function Group وتنفذه Execution Management ‏RS Execution Management, State Management (S. 16) SWS EM §7.4.5 «State Transition». تفسير: تمثل الحالة الهدف النشطة، على سبيل المثال، ModeDeclaration محددة في Manifest.
