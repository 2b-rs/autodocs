فئة ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

السياق

تُستخدم الفئة ara::per::ReadAccessor داخل الوحدة per (Persistency) في Adaptive Platform للقراءة التسلسلية لمحتويات الملفات المستمرة. وترث افتراضياً من FileAccessor وتوفر وصولاً للقراءة في كل من الوضع الثنائي ووضع النص. ومن خلال هذا التجريد، تصل التطبيقات إلى البيانات المخزنة دون الحاجة إلى إدارة التخزين المادي بشكل مباشر. وتوفر الواجهة عمليات دقيقة لمعاينة الأحرف أو البايتات الفردية بالإضافة إلى توابع لقراءة المحتويات والسطور على شكل كتل أو بالكامل.

دورة الحياة

تخضع دورة حياة مثيل ara::per::ReadAccessor لمتطلبات صارمة فيما يتعلق بالإنشاء وإدارة الموارد:

  • الإنشاء: تم حذف دالة البناء الافتراضية صراحةً وفقاً لـ [SWS_PER_00461] (delete). وبالتالي يُستبعد التهيئة المباشرة بدون معاملات من قِبل التطبيق. تفسير: من المحتمل بالتالي أن يتم إنشاء مثيل عبر آليات عليا للوصول إلى ملفات الاستمرارية وتمريره إلى المستدعي.
  • الإتلاف: تم التصريح عن دالة الهدم ~ReadAccessor() كافتراضية، ومزودة بـ override ومحددة كـ noexcept [SWS_PER_00417]. وعند إتلاف الكائن، يتم تحرير واصفات القراءة الأساسية.
  • التزامن وأمان الاستثناءات: تم تحديد جميع توابع الفئة على أنها not thread-safe (على سبيل المثال [SWS_PER_00417]، [SWS_PER_00419]). ولذلك يتطلب وصول خيوط متعددة بشكل متزامن إلى المثيل نفسه مزامنة خارجية. وفي الوقت نفسه، فإن جميع عمليات القراءة آمنة من الاستثناءات (exception safe) ومُصرَّح عنها بأنها noexcept؛ ويتم نقل الأخطاء عبر نوع الإرجاع ara::core::Result.

مسار الاستخدام

يميز استخدام ara::per::ReadAccessor بين عمليات المعاينة (دون تغيير الموضع) وعمليات القراءة الاستهلاكية (مع تقدم مؤشر الملف):

  • المعاينة (Peeking): يمكن بواسطة PeekByte() [SWS_PER_00418] أو PeekChar() [SWS_PER_00167] الاستعلام عن البايت أو الحرف الموجود في الموضع الحالي، دون تغيير موضع القراءة. وقد تم التصريح عن كلا التابعين بأنهما const.
  • القراءة التدريجية: تتم قراءة العنصر الحالي عبر GetByte() [SWS_PER_00419] أو GetChar() [SWS_PER_00168] وتقديم المؤشر الداخلي بمقدار موضع واحد.
  • القراءة على أجزاء (الوضع الثنائي): باستخدام ReadBinary(std::uint64_t n) [SWS_PER_00422]، تتم قراءة عدد محدد من البايتات إلى ara::core::Vector<ara::core::Byte>. وإذا تم الوصول إلى نهاية الملف قبل بلوغ n، فسيحتوي المتجه على بايتات أقل من المطلوب. يقرأ التحميل الزائد بدون معاملات ReadBinary() [SWS_PER_00421] جميع البايتات المتبقية حتى نهاية الملف.
  • وضع النص ومعالجة السطور: بواسطة ReadText(std::uint64_t n) [SWS_PER_00165] أو ReadText() [SWS_PER_00420]، تتم قراءة سلاسل الأحرف إلى ara::core::String. وبالنسبة لملفات النصوص المنظمة، يتيح ReadLine(char delimiter = '\n') [SWS_PER_00119] القراءة سطراً بسطر حتى الفاصل. ولا يتم تضمين الفاصل في السلسلة الناتجة. وإذا كان موضع القراءة يقع داخل نقطة ترميز يونيكود، فقد يحتوي النص المعاد على نقاط ترميز غير مكتملة.

مخطط تسلسلي: مسار نموذجي لمعالجة نصية سطراً بسطر تتضمن المعاينة والتعرف على نهاية الملف. المصادر: [SWS_PER_00167]، [SWS_PER_00119]

سيناريوهات الأخطاء

تُرجع جميع توابع القراءة والمعاينة كائن ara::core::Result. وعند حدوث خطأ، تسري دلالات التراجع: لا يتم تغيير موضع قراءة الملف الحالي في حالة الخطأ (محدد من بين أمور أخرى في [SWS_PER_00419]، [SWS_PER_00168]، [SWS_PER_00421]، [SWS_PER_00119]). وقد تم تحديد حالات الخطأ التالية من نطاق الخطأ PerErrc:

  • PerErrc::kEof: يُرجع عندما يكون موضع القراءة الحالي بالفعل عند نهاية الملف أو عندما يكون الملف فارغاً ([SWS_PER_00419]، [SWS_PER_00168]، [SWS_PER_00418]، [SWS_PER_00167]، [SWS_PER_00421]، [SWS_PER_00422]، [SWS_PER_00119]، [SWS_PER_00165]، [SWS_PER_00420]).
  • PerErrc::kPhysicalStorageFailure: يحدث عندما يفشل الوصول المادي للقراءة إلى وسيط التخزين ([SWS_PER_00420]).
  • PerErrc::kValidationFailed: يشير إلى أنه لا يمكن ضمان سلامة أو صحة البيانات المخزنة ([SWS_PER_00419]).
  • PerErrc::kEncryptionFailed: يُرجع عندما تفشل عملية فك تشفير البيانات المفيدة المخزنة ([SWS_PER_00419]).
  • PerErrc::kAuthenticationFailed: يحدث عندما يفشل التحقق من Message Authentication Code (MAC) للبيانات المخزنة ([SWS_PER_00419]).

ReadLine دالة

Reads a complete line of characters into a String, advancing the current position accordingly. The end of the line is demarcated by the delimiter, or by "\\n" (ASCII 0x0a) if that parameter is omitted. The delimiter itself is not included in the returned String. Only Unicode code points with one character (code unit) can be used as delimiters. The returned string may start with an incomplete Unicode code point in case the current read position is in the middle of a code point. If the end of the file is reached, the remaining characters are returned and the current position is set to the end of the file. In case of an error, the current position is not changed.

Reads a number of characters into a String, starting from the current position. The returned string may start and/or end with incomplete Unicode code points in case the current read position and/or the last read character (code unit) is in the middle of a code point. The current position is advanced accordingly. If the end of the file is reached, the number of returned characters can be less than the requested number, and the current position is set to the end of the file. تُستخدم الفئة <code>ara::per::ReadAccessor</code> داخل الوحدة <code>per</code> (Persistency) في Adaptive Platform للقراءة التسلسلية لمحتويات الملفات المستمرة. وترث افتراضياً من <code>FileAccessor</code> وتوفر وصولاً للقراءة في كل من الوضع الثنائي ووضع النص. ومن خلال هذا التجريد، تصل التطبيقات إلى البيانات المخزنة دون الحاجة إلى إدارة التخزين المادي بشكل مباشر. وتوفر الواجهة عمليات دقيقة لمعاينة الأحرف أو البايتات الفردية بالإضافة إلى توابع لقراءة المحتويات والسطور على شكل كتل أو بالكامل.
</p>

<h4>دورة الحياة</h4>
<p>
تخضع دورة حياة مثيل <code>ara::per::ReadAccessor</code> لمتطلبات صارمة فيما يتعلق بالإنشاء وإدارة الموارد:
</p>
<ul>
<li><strong>الإنشاء:</strong> تم حذف دالة البناء الافتراضية صراحةً وفقاً لـ <a class="spec-record-ref" data-req="SWS_PER_00461" href="../spec/record.html?id=SWS_PER_00461">[SWS_PER_00461]</a> (<code>delete</code>). وبالتالي يُستبعد التهيئة المباشرة بدون معاملات من قِبل التطبيق. تفسير: من المحتمل بالتالي أن يتم إنشاء مثيل عبر آليات عليا للوصول إلى ملفات الاستمرارية وتمريره إلى المستدعي.</li>
<li><strong>الإتلاف:</strong> تم التصريح عن دالة الهدم <code>~ReadAccessor()</code> كافتراضية، ومزودة بـ <code>override</code> ومحددة كـ <code>noexcept</code> <a class="spec-record-ref" data-req="SWS_PER_00417" href="../spec/record.html?id=SWS_PER_00417">[SWS_PER_00417]</a>. وعند إتلاف الكائن، يتم تحرير واصفات القراءة الأساسية.</li>
<li><strong>التزامن وأمان الاستثناءات:</strong> تم تحديد جميع توابع الفئة على أنها <code>not thread-safe</code> (على سبيل المثال <a class="spec-record-ref" data-req="SWS_PER_00417" href="../spec/record.html?id=SWS_PER_00417">[SWS_PER_00417]</a>، <a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a>). ولذلك يتطلب وصول خيوط متعددة بشكل متزامن إلى المثيل نفسه مزامنة خارجية. وفي الوقت نفسه، فإن جميع عمليات القراءة آمنة من الاستثناءات (<code>exception safe</code>) ومُصرَّح عنها بأنها <code>noexcept</code>؛ ويتم نقل الأخطاء عبر نوع الإرجاع <code>ara::core::Result</code>.</li>
</ul>

<h4>مسار الاستخدام</h4>
<p>
يميز استخدام <code>ara::per::ReadAccessor</code> بين عمليات المعاينة (دون تغيير الموضع) وعمليات القراءة الاستهلاكية (مع تقدم مؤشر الملف):
</p>
<ul>
<li><strong>المعاينة (Peeking):</strong> يمكن بواسطة <code>PeekByte()</code> <a class="spec-record-ref" data-req="SWS_PER_00418" href="../spec/record.html?id=SWS_PER_00418">[SWS_PER_00418]</a> أو <code>PeekChar()</code> <a class="spec-record-ref" data-req="SWS_PER_00167" href="../spec/record.html?id=SWS_PER_00167">[SWS_PER_00167]</a> الاستعلام عن البايت أو الحرف الموجود في الموضع الحالي، دون تغيير موضع القراءة. وقد تم التصريح عن كلا التابعين بأنهما <code>const</code>.</li>
<li><strong>القراءة التدريجية:</strong> تتم قراءة العنصر الحالي عبر <code>GetByte()</code> <a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a> أو <code>GetChar()</code> <a class="spec-record-ref" data-req="SWS_PER_00168" href="../spec/record.html?id=SWS_PER_00168">[SWS_PER_00168]</a> وتقديم المؤشر الداخلي بمقدار موضع واحد.</li>
<li><strong>القراءة على أجزاء (الوضع الثنائي):</strong> باستخدام <code>ReadBinary(std::uint64_t n)</code> <a class="spec-record-ref" data-req="SWS_PER_00422" href="../spec/record.html?id=SWS_PER_00422">[SWS_PER_00422]</a>، تتم قراءة عدد محدد من البايتات إلى <code>ara::core::Vector&lt;ara::core::Byte&gt;</code>. وإذا تم الوصول إلى نهاية الملف قبل بلوغ <code>n</code>، فسيحتوي المتجه على بايتات أقل من المطلوب. يقرأ التحميل الزائد بدون معاملات <code>ReadBinary()</code> <a class="spec-record-ref" data-req="SWS_PER_00421" href="../spec/record.html?id=SWS_PER_00421">[SWS_PER_00421]</a> جميع البايتات المتبقية حتى نهاية الملف.</li>
<li><strong>وضع النص ومعالجة السطور:</strong> بواسطة <code>ReadText(std::uint64_t n)</code> <a class="spec-record-ref" data-req="SWS_PER_00165" href="../spec/record.html?id=SWS_PER_00165">[SWS_PER_00165]</a> أو <code>ReadText()</code> <a class="spec-record-ref" data-req="SWS_PER_00420" href="../spec/record.html?id=SWS_PER_00420">[SWS_PER_00420]</a>، تتم قراءة سلاسل الأحرف إلى <code>ara::core::String</code>. وبالنسبة لملفات النصوص المنظمة، يتيح <code>ReadLine(char delimiter = '\n')</code> <a class="spec-record-ref" data-req="SWS_PER_00119" href="../spec/record.html?id=SWS_PER_00119">[SWS_PER_00119]</a> القراءة سطراً بسطر حتى الفاصل. ولا يتم تضمين الفاصل في السلسلة الناتجة. وإذا كان موضع القراءة يقع داخل نقطة ترميز يونيكود، فقد يحتوي النص المعاد على نقاط ترميز غير مكتملة.</li>
</ul>

<h4>سيناريوهات الأخطاء</h4>
<p>
تُرجع جميع توابع القراءة والمعاينة كائن <code>ara::core::Result</code>. وعند حدوث خطأ، تسري دلالات التراجع: لا يتم تغيير موضع قراءة الملف الحالي في حالة الخطأ (محدد من بين أمور أخرى في <a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a>، <a class="spec-record-ref" data-req="SWS_PER_00168" href="../spec/record.html?id=SWS_PER_00168">[SWS_PER_00168]</a>، <a class="spec-record-ref" data-req="SWS_PER_00421" href="../spec/record.html?id=SWS_PER_00421">[SWS_PER_00421]</a>، <a class="spec-record-ref" data-req="SWS_PER_00119" href="../spec/record.html?id=SWS_PER_00119">[SWS_PER_00119]</a>). وقد تم تحديد حالات الخطأ التالية من نطاق الخطأ <code>PerErrc</code>:
</p>
<ul>
<li><code>PerErrc::kEof</code>: يُرجع عندما يكون موضع القراءة الحالي بالفعل عند نهاية الملف أو عندما يكون الملف فارغاً (<a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a>، <a class="spec-record-ref" data-req="SWS_PER_00168" href="../spec/record.html?id=SWS_PER_00168">[SWS_PER_00168]</a>، <a class="spec-record-ref" data-req="SWS_PER_00418" href="../spec/record.html?id=SWS_PER_00418">[SWS_PER_00418]</a>، <a class="spec-record-ref" data-req="SWS_PER_00167" href="../spec/record.html?id=SWS_PER_00167">[SWS_PER_00167]</a>، <a class="spec-record-ref" data-req="SWS_PER_00421" href="../spec/record.html?id=SWS_PER_00421">[SWS_PER_00421]</a>، <a class="spec-record-ref" data-req="SWS_PER_00422" href="../spec/record.html?id=SWS_PER_00422">[SWS_PER_00422]</a>، <a class="spec-record-ref" data-req="SWS_PER_00119" href="../spec/record.html?id=SWS_PER_00119">[SWS_PER_00119]</a>، <a class="spec-record-ref" data-req="SWS_PER_00165" href="../spec/record.html?id=SWS_PER_00165">[SWS_PER_00165]</a>، <a class="spec-record-ref" data-req="SWS_PER_00420" href="../spec/record.html?id=SWS_PER_00420">[SWS_PER_00420]</a>).</li>
<li><code>PerErrc::kPhysicalStorageFailure</code>: يحدث عندما يفشل الوصول المادي للقراءة إلى وسيط التخزين (<a class="spec-record-ref" data-req="SWS_PER_00420" href="../spec/record.html?id=SWS_PER_00420">[SWS_PER_00420]</a>).</li>
<li><code>PerErrc::kValidationFailed</code>: يشير إلى أنه لا يمكن ضمان سلامة أو صحة البيانات المخزنة (<a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a>).</li>
<li><code>PerErrc::kEncryptionFailed</code>: يُرجع عندما تفشل عملية فك تشفير البيانات المفيدة المخزنة (<a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a>).</li>
<li><code>PerErrc::kAuthenticationFailed</code>: يحدث عندما يفشل التحقق من Message Authentication Code (MAC) للبيانات المخزنة (<a class="spec-record-ref" data-req="SWS_PER_00419" href="../spec/record.html?id=SWS_PER_00419">[SWS_PER_00419]</a>).</li>
</ul>
