فئة ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

يتيح قراءة بيانات الملفات والبيانات الثنائية المستدامة بنظام الكتل أو الأسطر أو الأحرف.

توفر الفئة ara::per::ReadAccessor دوال متزامنة للقراءة التسلسلية والقائمة على الأسطر للملفات في الوضعين الثنائي والنصي [SWS_PER_00421]، [SWS_PER_00119]. وإلى جانب القراءة المستهلكة للبيانات، فإنها تتيح معاينة محايدة للمؤشر للبايتات أو الأحرف التالية. ونظرًا لأن النسخ غير آمنة ترابطيًا، يجب تنسيق عمليات الوصول المتزامنة خارجيًا، بينما يحمي ضمان التراجع موضع مؤشر القراءة في حالة حدوث خطأ [SWS_PER_00419].

السياق ونطاق المهام

توفر الفئة ara::per::ReadAccessor واجهة للقراءة المتزامنة لمحتويات الملفات ضمن إدارة الاستدامة (الوحدة per)، وتشتق افتراضيًا من FileAccessor. وهي تجرد الوصول بالقراءة إلى وحدات تخزين البيانات المستدامة وتوفر دوال وصول ثنائية ونصية على حد سواء. يمكن للتطبيقات فحص واسترجاع بايتات أو أحرف فردية، بالإضافة إلى قراءة كتل متصلة أو أسطر كاملة عبر دوال متخصصة.

دورة الحياة والتزامن

تم حذف المنشئ الافتراضي للفئة ReadAccessor [SWS_PER_00461]؛ ولذلك يتم إنشاء النسخة عادةً عبر آليات الفتح والوصول ذات المستوى الأعلى لوحدة الاستدامة. ويتم تحرير الواجهة وموارد الوصول المرتبطة بها عبر مدمّر الكائن الافتراضي ~ReadAccessor() [SWS_PER_00417]. تمتلك نسخ ReadAccessor مؤشر قراءة داخليًا يدير الموضع الحالي في الملف. تم تحديد جميع دوال الفئة صراحةً بأنها غير آمنة ترابطيًا (not thread-safe) [SWS_PER_00419]، ولهذا السبب يجب على جهات الاستدعاء مزامنة عمليات القراءة المتزامنة على النسخة نفسها خارجيًا.

مسارات الاستخدام للبيانات الثنائية والنصية

بالنسبة لعمليات الملفات الثنائية، تقدم الفئة دوال للقراءة القابلة للمعاينة أو التسلسلية. باستخدام PeekByte()، يمكن فحص البايت الموجود في موضع القراءة الحالي دون تغيير مؤشر القراءة [SWS_PER_00418]. وفي المقابل، يقرأ GetByte() بايتًا واحدًا بالضبط ويقدم الموضع إلى الأمام [SWS_PER_00419]. يمكن قراءة كتل بيانات أكبر عبر ReadBinary(n) في ara::core::Vector<ara::core::Byte>، مع ضبط الموضع وفقًا لذلك؛ وإذا تم الوصول إلى نهاية الملف قبل الأوان، فسيحتوي المتجه على بايتات أقل من المطلوب [SWS_PER_00422]. ومن خلال ReadBinary()، يمكن الحصول على جميع البايتات المتبقية حتى نهاية الملف في خطوة واحدة [SWS_PER_00421].

مخطط التسلسل: المسار النموذجي لعملية وصول بالقراءة التسلسلية مع فحص مسبق ومعالجة البيانات على أجزاء. المصادر: [SWS_PER_00418]، [SWS_PER_00422]، [SWS_PER_00421].

في الوضع النصي، يوفر PeekChar() معاينة قائمة على الأحرف [SWS_PER_00167]، بينما يستهلك GetChar() الحرف التالي [SWS_PER_00168]. وتتم القراءة سطراً بسطر عبر ReadLine()، الذي يقرأ حتى فاصل محدد (الافتراضي: '\n'، ASCII 0x0a)؛ ولا يتم تضمين الفاصل في السلسلة النصية للنتيجة [SWS_PER_00119]. يمكن قراءة مقاطع بطول n من الأحرف أو كامل المحتوى المتبقي عبر التحميلات الزائدة (Overloads) لـ ReadText() [SWS_PER_00165]، [SWS_PER_00420]. وإذا كان مؤشر القراءة في منتصف حرف متعدد البايتات، فقد تشتمل السلاسل النصية الناتجة على نقاط ترميز Unicode غير مكتملة [SWS_PER_00119]، [SWS_PER_00165].

سيناريوهات الأخطاء ومعالجتها

تُرجع جميع عمليات القراءة لـ ReadAccessor قيمها مغلفة في ara::core::Result، وتم تحديدها على أنها آمنة من الاستثناءات (exception safe) [SWS_PER_00419]. وإذا حدث خطأ أثناء الوصول، تُطبَّق دلالات تراجع صارمة: يظل الموضع الحالي لمؤشر القراءة ثابتًا دون تغيير في حالة حدوث خطأ [SWS_PER_00421]، [SWS_PER_00422]. تتضمن حالات الأخطاء الموثقة النموذجية ما يلي:

  • PerErrc::kPhysicalStorageFailure عند حدوث أخطاء في وسيط التخزين المادي [SWS_PER_00419]، [SWS_PER_00420]،
  • PerErrc::kEof إذا كان مؤشر القراءة عند نهاية الملف أو إذا كان الملف فارغًا [SWS_PER_00419]، [SWS_PER_00168]،
  • PerErrc::kValidationFailed إذا تعذر التحقق من صحة البيانات [SWS_PER_00418]، [SWS_PER_00119]،
  • PerErrc::kEncryptionFailed في حال فشل فك التشفير [SWS_PER_00419]، [SWS_PER_00422]، بالإضافة إلى
  • PerErrc::kAuthenticationFailed إذا فشل التحقق من رمز MAC للبيانات المخزنة [SWS_PER_00167]، [SWS_PER_00421].

يستند هذا الدليل إلى مواصفة AUTOSAR Adaptive R25-11 وقد تم إنشاؤه آليًا.

ReadLine دالة

Reads a complete line of characters into a String, advancing the current position accordingly. The end of the line is demarcated by the delimiter, or by "\\n" (ASCII 0x0a) if that parameter is omitted. The delimiter itself is not included in the returned String. Only Unicode code points with one character (code unit) can be used as delimiters. The returned string may start with an incomplete Unicode code point in case the current read position is in the middle of a code point. If the end of the file is reached, the remaining characters are returned and the current position is set to the end of the file. In case of an error, the current position is not changed.
