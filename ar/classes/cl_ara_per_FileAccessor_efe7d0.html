فئة ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

واجهة Cursor مشتركة

FileAccessor عمليات تحديد موضع وحجم الحزم على الملفات المفتوحة. هذا هو الأساس المشترك للقراءة والكتابة والقراءة/الكتابة Accessor؛ وهذا يعني أن موضع المؤشر يصف الوصول إلى هذا الملف المفتوح بالضبط.

انضباط الموضع

يتم استخدام GetPosition وSetPosition وMovePosition للتنقل، بينما يوفر GetSize حجم الملف الحالي. عمليات الوصول ليست آمنة لمؤشر الترابط: لذلك لا ينبغي استخدام المقبض بواسطة مؤشرات ترابط متعددة في نفس الوقت دون مزامنة خارجية. SWS Persistency §7.4 «File Storage specific Features»

ملاحظة استخدام

افتح الملف عبر FileStorage، وقم بإجراء عمليات المؤشر بحوزة نفس UniqueHandle ثم حرره. إن تغيير الموقف ليس عملية مثابرة؛ تتطلب كتابة البيانات عملية الكتابة المناسبة والمزامنة إذا لزم الأمر.

يدير File Storage مجموعة من الملفات المسماة؛ ويملك Accessor حق الوصول المفتوح المحدد حصريًا. المصادر: SWS Persistency §7.4 «File Storage specific Features» [SWS_PER_00113].
