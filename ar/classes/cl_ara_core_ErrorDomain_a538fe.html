فئة ara::core::ErrorDomain

[SWS_CORE_00110] Upstream: RS_AP_00130

class ErrorDomain {...};

Encapsulation of an ErrorDomain. An ErrorDomain is the controlling entity for ErrorCode’s error code values, and defines the mapping of such error code values to textual representations. This type constitutes a base class for ErrorDomain implementations. This class is a literal type, and subclasses are strongly advised to be literal types as well.

الغرض من الاستخدام

تمثل ara::core::ErrorDomain السياق لشروط الخطأ، وتتحكم في قيم خطأ ErrorCode وتعين لها تمثيلات نصية [SWS_CORE_00110] [SWS_CORE_10303]. وهي الفئة الأساسية لمجالات الأخطاء المحددة وLiteral Type بحد ذاتها [SWS_CORE_00110] [SWS_CORE_10400].

جيل وأمبير. دمار

يتلقى الإنشاء المحمي Domain ID يُتوقع أن تكون فريدة على مستوى النظام [SWS_CORE_00135]. لا يكون Destructor افتراضيًا عمدًا وهو بسيط، إذ لا يلزم تدمير متعدد الأشكال وتبقى خاصية Literal Type محفوظة [SWS_CORE_00136].

دورة حياة ملكية &

يمنع النسخ والنقل بما في ذلك التعيين [SWS_CORE_00131] [SWS_CORE_00132] [SWS_CORE_00133] [SWS_CORE_00134]. تظل مؤشرات الأحرف المقدمة بواسطة Name() وMessage() ملكًا للمجال أو فئته الفرعية ولا يجوز إصدارها بواسطة العملاء [SWS_CORE_00152] [SWS_CORE_00153].

التفاعل مع الفئات الأخرى

Id() تقوم بإرجاع المعرف الفريد. يكون اثنان Domain متساويين إذا وفقط إذا كانت معرفاتهما متساوية [SWS_CORE_00151] [SWS_CORE_00137] [SWS_CORE_10401]. مشتقة Domains تنفيذ Name(), Message() و ThrowAsException(); يجب أن تكون final وتوفر الأسماء المستعارة Errc و Exception [SWS_CORE_00152] [SWS_CORE_00153] [SWS_CORE_00154] [SWS_CORE_10932] [SWS_CORE_10933] [SWS_CORE_10934].

القيود & معالجة الأخطاء

يحدد ThrowAsException() نوع الاستثناء المناسب، ويحتوي على ErrorCode الذي تم تمريره ولا يشارك في تحليل التحميل الزائد إذا تم إلغاء تنشيط استثناءات C++ [SWS_CORE_00154] [SWS_CORE_10304]. باستثناء هذه الوظيفة، يجب أن تكون الوظائف العامة لنطاقات الأخطاء الملموسة noexcept هي [SWS_CORE_10950].

تحديد مجالات الخطأ

توفر ErrorDomains السياق الذي تكون فيه قيمة الخطأ صالحة. وتُخصص Domains مستقلة للأخطاء الخاصة بالمصنّع لكي يظل تعيينها واضحًا؛ وتأخذ التطبيقات المحمولة بها بوصفها الحالة الافتراضية. EXP InterfacesGuidelines §3.1.5 «Standardized vs Vendor-specific ErrorCodes»

توضح Rust binding الفصل نفسه: إذ ينفذ Enum هناك ErrorDomain Trait ويُستخدم لإنشاء كائنات ErrorCode. EXP ARARustApplications §5.6 «Creating a new ErrorDomain»

مخطط التعاون: يحدد Domain سياق الخطأ ويدعم تحويل Exception الصريح لـ ErrorCode. المصادر: EXP InterfacesGuidelines §3.1.2 «Result» EXP ARARustApplications §5.6 «Creating a new ErrorDomain» RS General §4.1.3 «The use of noexcept».

الهوية والرسالة وحدود Exception

يعرّف ErrorDomain معنى قيم أخطائه، بما يشمل هوية مستقرة وإنشاء الرسالة. ودوره ليس مجرد تعداد: فهو يوفر السياق الذي يحتاج إليه ErrorCode للمقارنة والتمثيل النصي والتحويل الصريح إلى Exception. SWS Core §7.2 «Error handling» SWS Core §7.2.5.2 «Error Domain»
