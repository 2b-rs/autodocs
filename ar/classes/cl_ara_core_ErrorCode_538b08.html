فئة ara::core::ErrorCode

[SWS_CORE_00501] Upstream: RS_AP_00130, RS_AP_00140

class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

ملف الترويسة#include "ara/core/error_code.h"
رأس التوجيه#include "ara/core/core_fwd.h"
Scopenamespace ara::core

دليل المستخدم مولَّد بالذكاء الاصطناعي / AI generated

وصف مولد تلقائياً، مشتق من حيث المحتوى من وثائق AUTOSAR R25-11 المشار إليها (مواصفة SWS والوثائق المعيارية المصاحبة) — وليس نصاً رسمياً لـ AUTOSAR. العبارات المعلّمة بأنها تفسير هي استنتاجات من المصادر.

الغرض من الاستخدام

يغلف ErrorCode قيمة خطأ خاماً خاصة بنطاق ما، ومرجعاً إلى ErrorDomain المقابل، وبيانات إضافية اختيارية خاصة بالمصنّع. النوع هو Literal Type. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

جيل وأمبير. تفاعل

يمكن إنشاؤها من Fehler-Enum أو من قيمة ومجال خطأ وبيانات إضافية. Domain()، Value()، SupportData() وMessage() تجعل مكوناته أو نص الخطأ قابلاً للوصول؛ يحدد ThrowAsException() نوع الاستثناء المناسب عبر المجال. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

القيود & معالجة الأخطاء

تراعي المقارنات قيمة الخطأ ومجال الخطأ فقط، لا البيانات الإضافية. يمكن استخدام ErrorCode وأعضائها باستقلال عن ara::core::Initialize وDeinitialize. [SWS_CORE_10301] [SWS_CORE_15002]

سياق الخطأ بدلًا من قيم الخطأ العامة

يقوم ErrorCode بربط قيمة الخطأ المكتوبة بسياق ErrorDomain الخاص بها؛ اختياريًا، يمكن أن يحمل رسالة ومعلومات إضافية خاصة بالشركة المصنعة. تستخدمه واجهات ARA ضمن Result للأخطاء القابلة للاسترداد. EXP InterfacesGuidelines §3.1.2 «Result» EXP ARAComAPI §4.7 «Error Handling»

تتطلب رموز الخطأ الخاصة بالشركة المصنعة مجالات الخطأ الخاصة بها؛ يجب أن تتعامل التطبيقات المحمولة المحايدة للمكدس مع هذه المجالات كحالة افتراضية عامة. EXP InterfacesGuidelines §3.1.5 «Standardized vs Vendor-specific ErrorCodes»

مخطط تعاون: يحصل ErrorCode على السياق والرسالة من Domain الخاص به؛ وتحويل الاستثناء هو مسار Exception الصريح. المصدران: EXP InterfacesGuidelines §3.1.2 «Result» RS General §4.1.3 «The use of noexcept».

قيمة خطأ ممحوة النوع

تصف SWS ErrorCode بأنه قيمة خطأ ذات سياق Domain: يُمحى نوعيًا الكود الخاص بالمجال إلى قيمة عدد صحيح للنقل الموحّد؛ ويمكن تمرير بيانات دعم إضافية. تأخذ المقارنات القيمة وDomain في الحسبان، لا بيانات الدعم. SWS Core §7.2 «Error handling» SWS Core §7.2.5.1 «ErrorCode» [SWS_CORE_10301] [SWS_CORE_10302]
