系统架构与模块集群的角色

该集群构成了 Classic Platform 的 FlexRay 通信协议栈。它涵盖了从收发器、通信控制器（CC）到分段传输协议的范围。在规范未作独立规定的地方，FrTp 遵循 ISO 10681-2 [SWS_FrTp_01005]。网络管理由 State Manager 受 ComM 委托负责。它将其状态反馈给 BswM 和 ComM [SWS_FrSM_00096]。向上，FrTp 为 PduR 提供服务；向下，它使用 FrIf_Transmit [SWS_FrTp_00577]。

FrCC 的驱动程序。它封装 CHI 命令并提供 POC 状态（Fr_POCStatusType）。[SWS_Fr_00017] [SWS_Fr_00012] [SWS_Fr_00510]

交互与数据路径

发送路径始终以 FrTp_Transmit [SWS_FrTp_00136] 开始。该调用仅设置标志 TX_SDU_AVAILABLE，且仅在 ID 有效且通道空闲时设置 [SWS_FrTp_01039]。实际工作在 MainFunction 中进行：

  1. FrTp 通过 PduR_FrTpCopyTxData 查询可用长度 [SWS_FrTp_01042]。
  2. FrTp 占用池中第一个空闲的 FrTpTxPdu [SWS_FrTp_01045]，并决定是否进行分段 [SWS_FrTp_01048]。
  3. FrTp 复制数据 [SWS_FrTp_01123] 并通过 FrIf_Transmit [SWS_FrTp_01050] [SWS_FrIf_05033] 进行传递。
  4. FrTp_TxConfirmation 将 N-PDU 重新置为“idle” [SWS_FrTp_01054]。
  5. 在最后一个段以及必要时的最终确认之后，FrTp 释放通道 [SWS_FrTp_01056] 并通知 PduR_FrTpTxConfirmation [SWS_FrTp_01058]。

发送端存在“Immediate Buffer Access”和“Decoupled Buffer Access”模式 [SWS_FrTp_01084]。在解耦模式下，FrIf 稍后通过 FrTp_TriggerTransmit 获取数据。在此过程中，FrTp 复制地址信息、PCI 和有效负载数据 [SWS_FrTp_00154] [SWS_FrTp_01060]。各版本之间的差异：较新的图表在 FrTp 和 FrIf 之间额外显示了一个 LSduR（FrTp-SWS 第39页）。而 R20-11 图表则直接连接 PduR、FrTp 和 FrIf（FrTp-SWS 第44页）。

时序图：发送请求被同步接收，但在 FrTp_MainFunction 中被异步分段并传输。来源：[SWS_FrTp_01039]、[SWS_FrTp_01042]、[SWS_FrTp_01056]、FrTp-SWS 第44页

接收始于 FrTp_RxIndication [SWS_FrTp_00137]。仅当 ID 有效且地址与某个连接匹配时，FrTp 才会处理 N-PDU [SWS_FrTp_01069] [SWS_FrTp_01071]。后续流程：

  • FrTp 通过 PduR_FrTpStartOfReception 通告新连接 [SWS_FrTp_01078]。
  • 它通过 PduR_FrTpCopyRxData 传递数据 [SWS_FrTp_01138]。
  • 需要时，它会返回发送 FlowControl [SWS_FrTp_01080]。
  • 它通过 PduR_FrTpRxIndication 通知完成 [SWS_FrTp_01083]。

带宽由 PDU 池控制：

  • 多个连接可以共享同一个池 [SWS_FrTp_01020]。该池的 N-PDU 根据网络规划升序排列 [SWS_FrTp_01088]。
  • 活动连接被轮流服务 [SWS_FrTp_01096]。

任务上下文、同步与可重入性

每个模块都有其自身的周期性函数：

  • FrTp_MainFunction 是所有 FrTp 流程的入口点 [SWS_FrTp_00203]。它必须在每个 FlexRay 周期中至少运行一次 [SWS_FrTp_01152]。

可重入性是分级的：

  • 针对每个设备，Fr 服务是不可重入的 [SWS_Fr_00010]。
  • FrIf 包装器针对不同的 FrIf_CtrlIdx 是可重入的 [SWS_FrIf_05004]。而 FrIf_SetState 则是不可重入的 [SWS_FrIf_05174]。
  • FrTp 回调针对不同的 PduId 是可重入的 [SWS_FrTp_00152] [SWS_FrTp_00153]。FrTp_CancelReceive 是不可重入的 [SWS_FrTp_01172]。

Fr 通过 SchM_Enter_Fr/SchM_Exit_Fr 使用临界区 [SWS_Fr_00391]。FrIf_GetGlobalTime 也允许在临界区内调用（FrIf-SWS 第64页、[SWS_FrIf_05015]）。

FrTp 为每个通道使用一个 TxPduPendingCounter 来保护连续帧（Consecutive Frames）的顺序 [SWS_FrTp_01090]。仅当该计数器为零时，连接才会被处理 [SWS_FrTp_01094]。否则，在动态段中发生偏移的帧可能会被超越（FrTp-SWS 第56页）。
