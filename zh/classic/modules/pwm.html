按通道通过周期和占空比控制微控制器硬件的脉宽调制输出。

PWM 驱动程序作为 MCAL 模块按通道控制微控制器的脉宽调制输出，并为此直接访问其寄存器。根据 Pwm_Init，Pwm User 设置占空比，并在具有可变周期的通道上设置周期。它们可以将输出切换到空闲状态（Idle-Zustand），并开启或关闭边沿通知 [SWS_Pwm_91000]。驱动程序可选择性地通过准备和设置来管理两阶段的功率状态切换。在错误检测激活时，它会报告未初始化或无效通道等错误，随后不执行任何操作 [SWS_Pwm_00201]。

PWM 驱动程序是一个 MCAL 模块，通过微控制器的寄存器控制其脉宽调制输出。因此它不需要更底层模块的接口（SWS PWM Driver 第44页）。它通过 Pwm_Init 以及指向配置集 [SWS_Pwm_00095] 的指针进行同步初始化，ECU State Manager 将其作为可选的初始化接口调用（SWS EcuM 第152页）。它通常被 IoHwAb 使用，例如通过功率级驱动程序（Power-Stage-Treiber）（SWS IoHwAb 第37页）。

上下文图：EcuM 初始化驱动程序，Pwm User 操作它，且驱动程序返回通知和错误。来源：[SWS_Pwm_00105]、[SWS_Pwm_00198]、[SWS_Pwm_00104]

控制通过 16 位占空比进行，其中 0x8000 代表 100%（SWS PWM Driver 第18页）。最重要的服务：

  • Pwm_SetDutyCycle 更改占空比 [SWS_Pwm_91000]。在 0% 和 100% 时，它根据极性设置静态电平。
  • Pwm_SetPeriodAndDuty 额外更改周期，但仅适用于 PWM_VARIABLE_PERIOD 类的通道 [SWS_Pwm_00110]。
  • Pwm_SetOutputToIdle 立即切换至空闲电平 [SWS_Pwm_91002]。
  • Pwm_GetOutputState 读取内部电平 [SWS_Pwm_00100]。

状态图：通道通过 API 在调制、静态电平和空闲状态之间切换。来源：[SWS_Pwm_91000]、[SWS_Pwm_91001]、SWS PWM Driver 第31页

边沿通知通过 Pwm_EnableNotification 按通道开启 [SWS_Pwm_91004]，并作为 Pwm_Notification_<#Channel> 送达 Pwm User [SWS_Pwm_00105]。可选地，驱动程序还以两个阶段管理功率状态。Pwm_PreparePowerState 启动准备过程 [SWS_Pwm_00183]，周期性的 Pwm_Main_PowerTransitionManager 将其完成 [SWS_Pwm_00189]。随后 Pwm_SetPowerState 设置状态 [SWS_Pwm_00166]。

在错误检测处于激活状态时，函数会报告诸如 PWM_E_UNINIT、PWM_E_PARAM_CHANNEL 或 PWM_E_PERIOD_UNCHANGEABLE 之类的错误 [SWS_Pwm_00201] 并直接返回而不产生任何效果（SWS PWM Driver 第44页）。在这些情况下，Pwm_GetOutputState 返回 PWM_LOW [SWS_Pwm_30051]。如果在驱动程序仍在使用中时调用 Pwm_SetPowerState，将产生运行时错误 PWM_E_NOT_DISENGAGED [SWS_Pwm_00202]。

在 MCAL 中的角色：位于 PWM 单元与 Pwm User 之间的驱动程序

PWM 驱动程序封装了微控制器的脉冲宽度调制输出。作为 MCAL 层的模块，它直接访问微控制器的寄存器，因此不需要较低层模块的接口（SWS PWM Driver 第44页）。出于同样的原因，它不为下层提供回调（SWS PWM Driver 第40页），也不提供服务接口（SWS PWM Driver 第44页）。其服务可通过 Pwm.h 获取，例如 Pwm_Init [SWS_Pwm_00095]、Pwm_SetDutyCycle [SWS_Pwm_91000] 和 Pwm_GetOutputState [SWS_Pwm_00100]。它从 Std_Types.h [SWS_Pwm_00094] 导入标准类型 Std_ReturnType 和 Std_VersionInfoType。

ECU State Manager 将 Pwm_Init 列在其可选初始化接口中（SWS EcuM 第152页）。在功率输出级的用例中，IoHwAb 的功率级驱动程序调用 PWM、DIO 和 SPI 的服务，以此设置电压和频率等（SWS IoHwAb 第37页）。在相反方向上，该驱动程序调用两类函数：通道特定的通知 Pwm_Notification_<#Channel> [SWS_Pwm_00105] 以及电源管理中的 IoHwAb_Pwm_NotifyReadyForPowerState<#Mode> [SWS_Pwm_00198]。它可选地通过 Det_ReportError [SWS_Pwm_00104] 报告开发错误。如果硬件为不同通道提供不同机制，则不通过厂商特定的 API 中缀进行抽象，而是通过通道号进行抽象（TPS BSWMDT 第122页）。

上下文图：Pwm 驱动程序由 EcuM 初始化并由 Pwm User 操作。它由调度程序周期性调用，向 Pwm User 报告通知并向 DET 报告错误，并通过寄存器控制 PWM 单元。来源：[SWS_Pwm_00104]、[SWS_Pwm_00105]、[SWS_Pwm_00189]、[SWS_Pwm_00198]、SWS EcuM 第152页、SWS IoHwAb 第37页、RS PWM Driver 第14页

信号模型：周期、占空比、极性和通道类别

通道通过数字标识符 Pwm_ChannelType 寻址 [SWS_Pwm_00106]。周期属于类型 Pwm_PeriodType，这是一种具有 8 至 32 位的具体实现特定类型 [SWS_Pwm_00107]。三个概念决定了信号（SWS PWM Driver 第9页）：

  • 极性定义每个周期的起始电平。
  • 占空比指定该起始电平在周期中所占的比例。
  • 空闲状态是 Pwm_SetOutputToIdle 或 Pwm_DeInit 之后的初始状态。

信号描述示意图对比了两种极性 PWM_HIGH 和 PWM_LOW（SWS PWM Driver 第7页）。

占空比是一个 16 位值。0x0000 代表 0%，0x8000 代表 100%。作为实现参考，规范给出了 AbsoluteDutyCycle = ((uint32)AbsolutePeriodTime * RelativeDutyCycle) >> 15;（SWS PWM Driver 第18页）。相应地，Pwm_SetDutyCycle 和 Pwm_SetPeriodAndDuty 将参数 DutyCycle 限制为 Min=0x0000 和 Max=0x8000 [SWS_Pwm_91000] [SWS_Pwm_91001]。

通道类别 Pwm_ChannelClassType 规定了通道在运行时允许更改的内容 [SWS_Pwm_00110]：

  • PWM_VARIABLE_PERIOD：周期和占空比均可更改。
  • PWM_FIXED_PERIOD：仅占空比可更改。
  • PWM_FIXED_PERIOD_SHIFTED：固定的偏移周期，不可更改；仅在硬件支持时可用。

偏移周期示意图显示了具有相同周期且周期起始点分别偏移固定时间的通道（SWS PWM Driver 第23页）。

生命周期与信号控制：从 Pwm_Init 到空闲状态

Pwm_Init 是同步且不可重入的。该函数通过 ConfigPtr 接收指向配置集的指针 [SWS_Pwm_00095]。其类型 Pwm_ConfigType 包含特定于硬件的内容 [SWS_Pwm_00111]。根据初始化示意图，输出在此之后根据配置处于低电平、高电平或调制状态。通知仅在首次调用 Pwm_EnableNotification 之后出现（SWS PWM Driver 第46页）。如果在已初始化的驱动程序上再次调用 Pwm_Init，则必须报告开发错误 PWM_E_ALREADY_INITIALIZED [SWS_Pwm_50002]。

Pwm_DeInit 同样是同步且不可重入的 [SWS_Pwm_00096]。该函数对模块进行去初始化，将输出置于空闲状态，并关闭 PWM 中断以及边沿通知。它可以通过 PwmDeInitApi 启用和禁用（SWS PWM Driver 第27页）。解释：在此之后，模块应再次被视作未初始化，从而允许再次调用 Pwm_Init。

状态图：包含初始化、去初始化以及调用顺序错误时的错误的模块生命周期。在 Pwm_DeInit 之后返回“未初始化”状态属于一种解释。来源：[SWS_Pwm_00095]、[SWS_Pwm_00096]、[SWS_Pwm_50002]、[SWS_Pwm_20002]、[SWS_Pwm_30051]、SWS PWM Driver 第27页

在运行期间，Pwm_SetDutyCycle 设置通道的占空比 [SWS_Pwm_91000]。在 0% 和 100% 时，输出被静态设置（SWS PWM Driver 第28页）：

  • 在 0% 时，电平与配置的极性相反。
  • 在 100% 时，电平与极性一致。
  • 在介于两者之间的值时，根据周期、占空比和极性进行调制。

根据示意图，驱动程序在当前周期结束时采用新的占空比（如果具体实现支持），否则立即采用（SWS PWM Driver 第37页）。

Pwm_SetPeriodAndDuty 同时设置周期和占空比 [SWS_Pwm_91001]。此时适用三条规则（SWS PWM Driver 第30页）：

  • 如果具体实现支持并通过 PwmPeriodUpdatedEndperiod 进行了配置，则在周期结束时更新周期。
  • 必须抑制输出端的毛刺脉冲。
  • 同时传入占空比，以使频率和占空比相互匹配。

活动图：Pwm_SetDutyCycle 和 Pwm_SetPeriodAndDuty 的处理，包含通道类别的检查以及 0% 和 100% 的特殊处理。来源：[SWS_Pwm_40002]、SWS PWM Driver 第28页、SWS PWM Driver 第30页、SWS PWM Driver 第44页

Pwm_SetOutputToIdle 立即将输出设置为配置的空闲状态 [SWS_Pwm_91002]。具有可变周期的通道随后通过 Pwm_SetPeriodAndDuty 重新激活（SWS PWM Driver 第31页）。“Setting Pwm output to idle”示意图准确展示了该序列（SWS PWM Driver 第50页）。Pwm_GetOutputState 同步读取内部输出状态，结果为 PWM_HIGH 或 PWM_LOW [SWS_Pwm_00100] [SWS_Pwm_00108]。需求规范中的示意图将读取的值定位在 PWM 单元的输出端，即在端口逻辑之前，而非物理引脚处（RS PWM Driver 第14页）。

状态图：通道的输出状态（调制、静态电平、空闲）以及在它们之间切换的 API。来源：[SWS_Pwm_91000]、[SWS_Pwm_91001]、[SWS_Pwm_91002]、SWS PWM Driver 第28页、SWS PWM Driver 第31页、SWS PWM Driver 第46页

各通道的边沿通知

Pwm User 使用 Pwm_EnableNotification 启用通道的通知。类型为 Pwm_EdgeNotificationType 的参数选择 PWM_RISING_EDGE、PWM_FALLING_EDGE 或 PWM_BOTH_EDGES [SWS_Pwm_91004] [SWS_Pwm_00109]。该函数丢弃挂起的中断（SWS PWM Driver 第35页）。与 Pwm_DisableNotification [SWS_Pwm_91003] 一样，它仅在启用 PwmNotificationSupported 时存在（SWS PWM Driver 第34页）。

驱动程序根据对 Pwm_EnableNotification 或 Pwm_DisableNotification 的最后一次调用来调用配置的函数 Pwm_Notification_<#Channel>。在此过程中，它会复位相关的中断标志（SWS PWM Driver 第42页）。回调没有参数，并通过 Pwm_Externals.h 声明。它是否可重入取决于 Pwm User 的具体实现 [SWS_Pwm_00105]。

时序图：从初始化到启用和禁用边沿通知，直至不再出现进一步回调的过程。来源：[SWS_Pwm_91004]、[SWS_Pwm_91003]、[SWS_Pwm_00105]、SWS PWM Driver 第52页、SWS PWM Driver 第42页

PWM 外设的电源状态

电源状态控制是一项可选功能。它仅限于 PWM 外设，并要求应用程序、模式管理和 IoHwAb 已经满足上层边界条件（SWS PWM Driver 第17页）。如果 PwmLowPowerStatesSupport 处于活动状态，则生成四个电源状态 API（SWS PWM Driver 第16页）。Pwm_PowerStateType 包含 PWM_FULL_POWER (0x00) 以及代表功耗递减状态的范围 1..255。在 R20-11 中，该类型被定义为枚举 [SWS_Pwm_00197]。而较新版本则将其列为派生自 uint8 的类型（SWS PWM Driver 第25页）。

电源状态的切换分两个阶段进行：

  1. Pwm_PreparePowerState 启动准备工作，并在结果参数中返回 PWM_SERVICE_ACCEPTED 或拒绝原因 [SWS_Pwm_00183] [SWS_Pwm_00165]。无法立即完成的操作由周期性调用的 Pwm_Main_PowerTransitionManager [SWS_Pwm_00189] [SWS_Pwm_00190] 处理。其调用速率是可变的，并且仅在异步模式下发送回调（SWS PWM Driver 第41页）。驱动程序使用 IoHwAb_Pwm_NotifyReadyForPowerState<#Mode> [SWS_Pwm_00198] 报告准备工作已完成。
  2. Pwm_SetPowerState 将硬件置于已准备好的状态 [SWS_Pwm_00166]。负责的 SWC（例如 IoHwAb）必须已经完成了前置工作，例如将所有通道置为 IDLE 并注销所有通知。该函数不执行隐式中间状态（SWS PWM Driver 第36页）。

状态图：包含准备、完成和设置以及时序错误的电源状态两阶段切换。来源：[SWS_Pwm_00183]、[SWS_Pwm_00166]、[SWS_Pwm_00165]、[SWS_Pwm_00190]、SWS PWM Driver 第39页、SWS IoHwAb 第61页

Pwm_GetCurrentPowerState [SWS_Pwm_00177] 返回当前状态，Pwm_GetTargetPowerState [SWS_Pwm_00180] 返回请求的状态。只要没有转换在进行，两者就保持一致（SWS PWM Driver 第38页）。IoHwAb 规范展示了异步情况下 BswM、RTE/SchM、IoHwAb、ADC 和 PWM 的相互协作（SWS IoHwAb 第60页）。在同步情况下，当准备 API 返回时，准备工作就已经完成（SWS IoHwAb 第61页）。

时序图：由 IoHwAb 控制的向低功耗状态的异步切换。该流程已简化，并省略了 ADC。来源：[SWS_Pwm_00183]、[SWS_Pwm_00189]、[SWS_Pwm_00198]、[SWS_Pwm_00166]、SWS IoHwAb 第57页、SWS IoHwAb 第60页

配置、通道容器与并发性

通道的必选参数包括分配的硬件通道、周期和占空比的默认值、极性、空闲电平和通道类别。相位偏移、参考通道和微控制器特定属性是可选的，只要硬件提供即可（SWS PWM Driver 第25页）。在配置模型中，PwmChannelConfigSet 包含至少一个 PwmChannel，并且 PwmDutycycleDefault 限制为 0 至 0x8000（ECUC-Parameter 第545页）。PwmChannelClass 被映射到 Pwm_ChannelClassType。PwmChannelId 被分配给通道容器的符号名称（SWS PWM Driver 第57页）。

可选服务通过配置启用和禁用：PwmSetOutputToIdle（SWS PWM Driver 第31页）、PwmGetOutputState（SWS PWM Driver 第33页）以及上述的 PwmDeInitApi 和 PwmNotificationSupported。

关于并发性：

  • 诸如 Pwm_SetDutyCycle 等通道服务针对不同通道号是可重入的 [SWS_Pwm_91000]。
  • 电源状态 API 是不可重入的 [SWS_Pwm_00183]。
  • 模块必须拒绝包含具体实现不支持的分区分配的配置 [SWS_Pwm_00203]。

BSW 分发指南阐述了直至“多核可重入”的重入级别（BSW Distribution Guide 第18页）。

发生错误时的行为

如果开发错误检测处于激活状态，这些函数会将检测到的错误报告给 Default Error Tracer。随后它们跳过所请求的函数，以避免数据或硬件寄存器被破坏（SWS PWM Driver 第44页）。错误代码为 [SWS_Pwm_00201]：

  • PWM_E_INIT_FAILED (0x10)
  • PWM_E_UNINIT (0x11)，用于初始化前的调用 [SWS_Pwm_20002]
  • PWM_E_PARAM_CHANNEL (0x12)，用于无效通道 [SWS_Pwm_30002]
  • PWM_E_PERIOD_UNCHANGEABLE (0x13)，用于在固定周期通道上更改周期 [SWS_Pwm_40002]
  • PWM_E_ALREADY_INITIALIZED (0x14)
  • PWM_E_PARAM_POINTER (0x15)，用于传给 Pwm_GetVersionInfo 的 NULL 参数

Pwm_GetOutputState 必须始终返回一个值。在初始化之前或通道无效时，该值为 PWM_LOW [SWS_Pwm_30051]。

活动图：开发错误检测激活时通道 API 的常规检查，包含无效果的中止。来源：[SWS_Pwm_20002]、[SWS_Pwm_30002]、[SWS_Pwm_30051]、SWS PWM Driver 第44页

电源状态 API 还通过 Std_ReturnType 和结果类型 Pwm_PowerStateRequestResultType 报告错误。可能的值包括 PWM_NOT_INIT、PWM_SEQUENCE_ERROR、PWM_HW_FAILURE、PWM_POWER_STATE_NOT_SUPP 和 PWM_TRANS_NOT_POSSIBLE [SWS_Pwm_00165]。此外，对于不受支持的状态规定了 PWM_E_POWER_STATE_NOT_SUPPORTED [SWS_Pwm_00174]，对于无法直接达到的状态规定了 PWM_E_TRANSITION_NOT_POSSIBLE [SWS_Pwm_00175]。

如果在仍有通道未处于 IDLE 状态或已注册通知的情况下调用 Pwm_SetPowerState，则会产生运行时错误 PWM_E_NOT_DISENGAGED (0x16) [SWS_Pwm_00202]（SWS PWM Driver 第20页）。Pwm_Main_PowerTransitionManager 直接返回而不进行初始化，并且特意不报告开发错误。原因在于：周期性任务可能在初始化结束之前就已经运行（SWS PWM Driver 第41页）。
