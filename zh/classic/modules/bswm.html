BSW Mode Manager 接收来自 BSW 模块的模式指示以及来自 SWC 的模式请求。它通过配置的规则对它们进行仲裁，规则的结果将触发 True 或 False 动作列表 [SWS_BswM_00035]。根据 BswM_Init，它以此控制基础软件的进一步初始化、与 EcuM 协作的 ECU Mode Handling 以及通信使能（例如 I-PDU 组或以太网端口组）。带有 BSWM_DEFERRED 输入的规则由 BswM_MainFunction 进行周期性求值，所有其他规则立即求值 [SWS_BswM_00075]。在 DET 激活时，无效或在初始化之前到达的请求将被忽略并报错。

BswM 的角色：基础软件的核心模式仲裁

BSW Mode Manager（BswM）接收模式请求与模式指示。据此，它通过配置的规则仲裁应执行哪些动作 [SWS_BswM_00035]、SWS BswM 第26页。模式请求通常来自应用 SWC，但也可以来自诸如 DCM 等 BSW 模块。模式指示始终由其他 BSW 模块提供，例如特定于总线的状态管理器和 EcuM。BswM 对这两种类型同等对待，并将它们统称为“mode arbitration request”SWS BswM 第26页。
