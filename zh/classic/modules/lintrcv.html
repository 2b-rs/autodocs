在LIN接口与收发器芯片之间的角色

LIN Transceiver Driver（LinTrcv）封装了物理LIN收发器的控制。其接口由七个服务组成：

  • 使用LinTrcv_Init进行初始化[SWS_LinTrcv_00001]
  • 使用LinTrcv_SetOpMode进行模式切换[SWS_LinTrcv_00002]
  • 使用 LinTrcv_GetOpMode 查询模式 [SWS_LinTrcv_00005]
  • 使用 LinTrcv_GetBusWuReason 查询唤醒原因 [SWS_LinTrcv_00007]
  • 使用 LinTrcv_SetWakeupMode 控制唤醒通知 [SWS_LinTrcv_00009]
  • 使用 LinTrcv_CheckWakeup 进行唤醒检查 [SWS_LinTrcv_00012]
  • 使用 LinTrcv_GetVersionInfo 进行版本查询 [SWS_LinTrcv_00008]

所有服务均为同步服务。驱动程序的软件状态与器件的硬件状态相互独立。器件支持的状态转换可以多于驱动程序。软件状态具体涵盖哪些硬件状态由实现决定。但实现必须完整提供所描述的功能 LinTrcv-SWS 第16页。

在向上方向，LIN 接口（LinIf）是有效负载中占用的用户。各 LinIf 服务分别调用一个 LinTrcv 服务：

  • LinIf_SetTrcvMode 调用 LinTrcv_SetOpMode 并原样返回其返回值 LinIf-SWS 第90页。
  • LinIf_GetTrcvMode 调用 LinTrcv_GetOpMode LinIf-SWS 第91页。
  • LinIf_GetTrcvWakeupReason 调用 LinTrcv_GetBusWuReason LinIf-SWS 第92页。
  • LinIf_SetTrcvWakeupMode 调用 LinTrcv_SetWakeupMode LinIf-SWS 第93页。

类型 LinTrcv_TrcvModeType 和 LinTrcv_TrcvWakeupModeType 可通过 Lin_GeneralTypes.h 获取 [SWS_LinTrcv_00168] [SWS_LinTrcv_00169]。LinIf 在其签名中直接使用它们。原有的专有类型 LinIf_TrcvModeType 在版本 3.1.5 中被 LinTrcv_TrcvModeType 取代 LinIf-SWS 第4页。

在向下方向，驱动程序使用以下服务：

  • Dio、Det_ReportError 和 EcuM_SetWakeupEvent 的读写服务 [SWS_LinTrcv_91003]
  • 来自 Dio、Spi、Icu 和 EcuM 的类型 [SWS_LinTrcv_91001]
