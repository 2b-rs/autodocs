Core Execution Environment

component Core Execution Environment

S-Core 核心执行环境定义了所有 Eclipse S-Core 服务的基本操作系统抽象、POSIX 运行时保证、容器技术、进程特权模型和编码标准。

Execution Architecture & Key Requirements

从发布 Pin v0.6.0 中提取了以下需求，并通过 S-Core 管理生命周期进行管理：

需求 ID类别功能安全 / 信息安全描述
aou_req__platform__posix_operating_system平台 / 操作系统安全：QM要求底层操作系统符合 IEEE Std 1003.1（POSIX）2004 版或更高版本。
stkh_req__hardware_support__container_tech容器 / 硬件安全：YES要求使用 Linux 内核隔离机制，包括 cgroup、安全策略（secpol）和命名空间，以实现工作负载隔离。
aou_req__os__cxx_preference操作系统 / 运行时ASIL B / 安全组件应优先使用 ISO C++ 标准库接口而非传统的 C API，禁止针对相同功能进行混合调用。
aou_req__os__minimal_privileges安全 / 操作系统安全：YES强制执行最小特权原则，要求进程在初始化后放弃不必要的功能权限。
aou_req__os__nonroot安全 / 过程安全：YES应用程序组件必须作为非特权非 root 用户运行，具有隔离的 UID/GID 命名空间。
aou_req__os__public_api架构安全：QM在公共 API 头文件与私有实现单元之间强制执行严格的接口边界封装。
