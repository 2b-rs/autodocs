Diagnostic Adapter

component Diagnostic Adapter

S-Core 诊断适配器将 AUTOSAR Classic 和 ISO 14229 UDS 诊断服务桥接到 Eclipse S-Core 服务，处理 ODX 配置、DTC 转换、故障数据库和 SOVD 远程信息处理。

Diagnostic Architecture & Key Requirements

从发布 Pin v0.6.0 中提取了以下诊断需求：

需求 ID类别功能安全 / 信息安全描述
feat_req__diagnostics__classic_adapter诊断安全：QM实现 Classic 诊断适配器，将 Classic AUTOSAR DEM/DCM 请求转换为统一的 S-Core 事件。
feat_req__diagnostics__classic_adapter_odxODX / 配置安全：YES要求诊断命令映射和 ECU 行为可通过标准 ODX 容器文件进行配置。
feat_req__diagnostics__db持久性 / 故障安全：QM定义用于记录 DTC 出现、冻结帧和扩展记录的中央诊断数据库模式。
feat_req__diagnostics__db_persistence存储安全：QM保证在 ECU 电源周期之间故障存储器的非易失性持久存储。
