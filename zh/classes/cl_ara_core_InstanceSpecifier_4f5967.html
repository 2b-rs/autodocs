封装 AUTOSAR shortName 路径，用于模型元素的类型安全标识和比较。

类 ara::core::InstanceSpecifier 用作围绕 AUTOSAR shortName 路径的类型安全包装器，用于在 Adaptive Platform 中唯一定位模型实例。首选的创建方式是通过静态工厂方法 Create [SWS_CORE_08032] 以异常安全的方式进行，该方法验证路径并返回 ara::core::Result。作为一项重要约束条件，方法 ToString [SWS_CORE_08041] 仅在最初传入的字符串的生命周期内保证所提供的 StringView 的有效性，因为其自身不管理缓冲区。在运行时，该对象支持完整的比较操作，用于模型比对以及在容器中进行有序存储。

上下文

类 ara::core::InstanceSpecifier 用作 AUTOSAR Instance Specifier 的表示，并封装模型元素的完整 shortName 路径。在 Adaptive Platform 中，它充当 AUTOSAR 元模型路径字符串的类型安全抽象。该类型并非使用未格式化的字符串，而是封装了句法路径结构，并确保可以一致地对实例进行寻址。作为主要交互伙伴的应用组件和平台服务可以唯一定位、比较模型实例或在集合中管理它们。Interpretation：由于规范将该类描述为轻量级模型路径包装器，因此它大概率主要用于在运行时标识服务实例和通信端点并进行配置分配。 问题 Q-6574e1172032e6d9 (未决)

生命周期

为了进行创建，ara::core::InstanceSpecifier 提供了两条具有不同错误和异常语义的路径：静态工厂方法 Create [SWS_CORE_08032] 以及显式构造函数 [SWS_CORE_08021]。工厂方法 Create 接收一个 ara::core::StringView，被指定为 noexcept 且线程安全，并在 ara::core::Result<InstanceSpecifier> 中返回结果。与此相反，直接构造函数被声明为 noexcept(false)，并且在路径结构无效时抛出 ara::core::CoreException，因此它不是异常安全的 [SWS_CORE_08021]。

关于生命周期和所有权，存在一个关键特性：方法 ToString 返回一个 ara::core::StringView，其有效性显式绑定到构造时最初传入的 StringView 所基于的内存生命周期 [SWS_CORE_08041]。因此，该类不会将底层字符串复制到自己的内存区域中，而是引用外部数据。因此，开发人员必须确保源字符串在 InstanceSpecifier 及其派生的 StringView 的整个使用期间保留在内存中。

为了在生命周期中进行进一步管理，提供了拷贝构造函数 [SWS_CORE_08022]、移动构造函数 [SWS_CORE_08023]、拷贝赋值运算符 [SWS_CORE_08024] 和移动赋值运算符 [SWS_CORE_08025]。所有这四种操作都被声明为 noexcept 并保证异常安全性。但在并发方面需要注意的是，只有拷贝构造函数被归类为线程安全。移动操作、赋值运算符以及析构函数 [SWS_CORE_08029] 均不是线程安全的，当并发修改或销毁同一实例时需要外部同步。

使用路径

典型的使用流程包括实例化、查询路径表示以及与其他标识符进行比较。首选调用非抛出异常的工厂函数 Create [SWS_CORE_08032]。应用程序将限定的模型路径作为 ara::core::StringView 传入，并检查生成的 Result 对象是否成功。

时序图：通过 Create 工厂方法进行创建，随后用于路径查询或错误处理。来源：[SWS_CORE_08032]、[SWS_CORE_08041]

成功初始化后，该标识符可以有多种用途：

  • 获取字符串表示：通过 ToString [SWS_CORE_08041]，调用方获得对所建模路径的 StringView 视图。
  • 相等性与不等性检查：实例可以通过 operator== [SWS_CORE_08042] 和 operator!= [SWS_CORE_08044] 直接与其他 InstanceSpecifier 实例进行比较。此外，operator== [SWS_CORE_08043] 和 operator!= [SWS_CORE_08045] 的重载允许直接与 ara::core::StringView 进行比较。这两种检查仅在表示完全相同的模型元素时才返回相等。
  • 排序和容器存储：通过小于运算符 operator< [SWS_CORE_08046] 可以对实例按字典序排序，从而支持将其用作 Map 等有序容器中的键。

错误场景

ara::core::InstanceSpecifier 的错误条件严格限定在构造阶段。如果传入的路径中出现句法或语义缺陷，将识别出两个特定错误：

  • CoreErrc::kInvalidMetaModelShortname：当传入的名称中缺少路径元素或包含非法字符时发出信号 [SWS_CORE_08032]，[SWS_CORE_08021]。
  • CoreErrc::kInvalidMetaModelPath：当字符串未形成指向模型元素的有效路径时发生 [SWS_CORE_08032]，[SWS_CORE_08021]。

错误指示的方式取决于所选的创建路径。使用工厂方法 Create [SWS_CORE_08032] 时，错误码在 ara::core::Result 中返回；适用无异常的回滚语义。相反，如果调用构造函数 InstanceSpecifier [SWS_CORE_08021]，则会抛出带有相应错误码的 ara::core::CoreException。所有后续操作（例如 ToString [SWS_CORE_08041]、赋值以及比较运算符 [SWS_CORE_08042]、[SWS_CORE_08044]、[SWS_CORE_08046]）均不具有已定义的错误状态，并声明为 noexcept。
