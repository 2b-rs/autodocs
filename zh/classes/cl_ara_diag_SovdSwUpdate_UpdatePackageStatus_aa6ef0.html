上下文

结构 ara::diag::SovdSwUpdate::UpdatePackageStatus [SWS_DM_01902] 是 AUTOSAR Adaptive Platform AUTOSAR_AP_SWS_Diagnostics §8.58.5 “Struct: UpdatePackageStatus” 内模块 diag 的核心数据类型。在 Service-Oriented Vehicle Diagnostics (SOVD) 框架下，它用作表示软件更新包状态与进度的信息载体。

其主要职责在于将结构化数据从诊断层传输到进行监控的客户端应用程序。其实例通常通过 API 函数ara::diag::SovdSwUpdate::GetUpdatePackageStatus [SWS_DM_01921]提供AUTOSAR_AP_SWS_Diagnostics §8.58.2.1.3.5 “GetUpdatePackageStatus”。主要交互方包括：

  • 诊断客户端 / 应用软件：发起针对特定软件包的状态查询，接收状态结构体并评估当前执行状态。
  • SOVD 更新服务 (ara::diag::SovdSwUpdate)：控制 Adaptive Platform 上的实际更新过程，确定处理状态并填充UpdatePackageStatus。
  • 本地化和显示系统：利用结构体中包含的翻译标识符，以便按特定语言向用户呈现进度。

生命周期

作为常规 C++ 结构体（struct），UpdatePackageStatus [SWS_DM_01902]具有纯值对象（Data Transfer Object）的特性：

  • 创建与所有权：在查询GetUpdatePackageStatus [SWS_DM_01921]时实例化一个实例，并使用数据包的瞬时数据进行填充。该结构体通过值传递传递给调用组件，从而将完全所有权转移给调用方。
  • 状态表示：该结构体未实现自身的状态逻辑，而是通过属性phase [SWS_DM_01903] (AUTOSAR_AP_SWS_Diagnostics §8.58.5.1.2 “phase”) 和status [SWS_DM_01904] (AUTOSAR_AP_SWS_Diagnostics §8.58.5.1.4 “status”)封装当前状态。
  • 并发性：由于这是没有自身同步机制的被动数据字段，因此对象在面对并发修改时不是线程安全的。在返回给调用上下文后，该实例通常保持线程局部，并可在没有锁的情况下在其中进行检查。
  • 销毁：离开调用作用域时，结构体将自动销毁。在此过程中，动态组件（例如step [SWS_DM_01907]或向量subprogress [SWS_DM_01906]）也会被确定性释放。

使用路径

监控更新过程的常规流程分为以下步骤：

  1. 调用状态查询：客户端调用ara::diag::SovdSwUpdate::GetUpdatePackageStatus [SWS_DM_01921]。
  2. 聚合状态数据：SovdSwUpdate的实例查询内部软件包进度并填充UpdatePackageStatus [SWS_DM_01902]的实例。
  3. 评估宏观状态：调用方通过phase [SWS_DM_01903]检查阶段并通过status [SWS_DM_01904]检查状态，以对总体进度进行分类。
  4. 处理详细信息：如果可用，则读取来自progress [SWS_DM_01905] (AUTOSAR_AP_SWS_Diagnostics §8.58.5.1.3 “progress”) 和subprogress [SWS_DM_01906]的百分比值，以及通过step [SWS_DM_01907]和step_translation_id [SWS_DM_01908]读取描述。
  5. 循环重复：如果更新仍在进行中，客户端将按定义的时间间隔重复查询直至完成。

错误场景

在软件包处理过程中发生错误时，该结构体提供了特定的诊断字段：

  • 通过 error 发送错误信号：成员error被声明为ara::core::Optional<ara::diag::DiagSovdErrc> [SWS_DM_01909] (AUTOSAR_AP_SWS_Diagnostics §8.58.5.1.1 “error”)。当更新状态为失败时，它指定确切的错误代码（“Specifies the error if status is failed”[SWS_DM_01909]）。在成功或正在处理时，该可选字段保持未设置（ara::core::nullopt）。
  • 缺失的进度值：字段progress [SWS_DM_01905]同样是可选的（ara::core::Optional<std::uint8_t>）。在持续时间或程度无法量化的步骤中，该字段大概率保持未设置。因此，调用方在读取之前必须始终检查progress.has_value()是否为真。
  • 对错误状态的响应：如果status [SWS_DM_01904]发出中止信号，调用方大概率会主要评估error，因为进度信息在错误状态下不再具有相关性。

<ul>
<li><strong>诊断客户端 / 应用软件：</strong>发起针对特定软件包的状态查询，接收状态结构体并评估当前执行状态。</li>
