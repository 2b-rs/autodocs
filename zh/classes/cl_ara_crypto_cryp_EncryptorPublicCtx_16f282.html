上下文

接口 ara::crypto::cryp::EncryptorPublicCtx 在 AUTOSAR Adaptive Platform 的 crypto 模块中提供了非对称加密操作的抽象。该类派生自 CryptoContext，作为主要服务提供者，用于在使用非对称公钥的情况下将明文数据转换为密文。它通常与另外两个实体进行交互：请求加密操作并传递数据缓冲区的调用方应用软件，以及非对称密钥对象。密钥源既可以是根据 [SWS_CRYPT_50175] 直接传递的公钥（PublicKey），也可以是根据 [SWS_CRYPT_50086] 的持久化或托管密钥存储槽（KeySlot）。

生命周期

客户端应用程序中 EncryptorPublicCtx 的实例通常通过提供的智能指针类型别名 Sptr（std::shared_ptr<EncryptorPublicCtx>）进行管理 [SWS_CRYPT_50174]。解释：由于该接口声明了纯虚方法，上下文的实例化推测是通过上级加密提供程序的工厂方法进行的。所有接口方法均被指定为异常安全（exception safe）和线程安全（thread-safe）。

上下文在其生命周期内经历明确定义的处理状态：

  • 未初始化（Uninitialized）：创建后，上下文处于 Uninitialized 状态。如果尝试在此状态下处理数据或查询缓冲区大小，各方法将失败并返回 CryptoErrc::kUninitializedContext（[SWS_CRYPT_50090]、[SWS_CRYPT_50087]、[SWS_CRYPT_50177]）。
  • 已初始化（Initialized）：通过使用 PublicKey::Sptr [SWS_CRYPT_50175] 或 KeySlot::Sptr [SWS_CRYPT_50086] 并借助 SetKey() 分配密钥，上下文切换到就绪状态。在此状态下，既可以通过 Encrypt() [SWS_CRYPT_50090] 启动单块处理（Single-Call），也可以启动多阶段流式处理。
  • 流式处理处于活动状态（Processing）：调用 Start() 可使上下文进入活动流式处理阶段 [SWS_CRYPT_50087]。在此状态下，可以通过 Update() 连续处理输入数据 [SWS_CRYPT_50176]。
  • 完成或中止：通过调用 Finish() 可以正常完成流式处理阶段 [SWS_CRYPT_50088]，从而加密最后一个数据块，并且上下文返回到 Initialized 状态。或者，也可以使用 Cancel() 提前放弃正在进行的操作 [SWS_CRYPT_50089]。若未事先调用 Start() 而直接调用 Update()、Finish() 或 Cancel()，将返回 CryptoErrc::kProcessingNotStarted 并被拒绝（[SWS_CRYPT_50176]、[SWS_CRYPT_50088]、[SWS_CRYPT_50089]）。

使用路径

规范规定了两种主要的处理路径：单步处理（Single-Call）以及逐步流式处理。

在单步处理中，应用程序首先分配公钥（SetKey()），并可选择通过 GetMinimumChunkSize() [SWS_CRYPT_50178] 以及 GetMaximumChunkSize() [SWS_CRYPT_50091] 检查允许的输入大小。为了确定所需的输出缓冲区大小，应用程序使用参数 isFinal = true 调用 GetRequiredOutputBufferSize() [SWS_CRYPT_50177]。随后，调用 Encrypt(in, out) 直接一步执行转换 [SWS_CRYPT_50090]。

在流式处理中，执行过程按以下步骤进行：

  1. 密钥分配：通过 SetKey() 使用 PublicKey [SWS_CRYPT_50175] 或 KeySlot [SWS_CRYPT_50086] 配置上下文。
  2. 初始化：调用 Start() 以开启流式会话 [SWS_CRYPT_50087]。
  3. 连续处理：重复将明文段传递给 Update(in, out) [SWS_CRYPT_50176]。中间步骤所需的缓冲区大小可以预先使用 GetRequiredOutputBufferSize(inputSize, false) 确定 [SWS_CRYPT_50177]。
  4. 完成：传递最终数据块并通过 Finish(in, out) [SWS_CRYPT_50088] 完成加密。为此，使用 GetRequiredOutputBufferSize(inputSize, true) 计算输出容量。如果必须提前中止会话，则 Cancel() 会中止该操作 [SWS_CRYPT_50089]。

错误场景

EncryptorPublicCtx 的方法通过返回类型 ara::core::Result 指示错误。所有指定的错误均遵循回滚语义，以便在失败时上下文保持一致状态：

  • ara::crypto::CryptoErrc::kUninitializedContext：该操作要求上下文已配置，但在调用 Encrypt() [SWS_CRYPT_50090]、Start() [SWS_CRYPT_50087] 或 GetRequiredOutputBufferSize() [SWS_CRYPT_50177] 之前未分配任何密钥。
  • ara::crypto::CryptoErrc::kProcessingNotStarted：在之前未成功调用 Start() 的情况下调用 Update() [SWS_CRYPT_50176]、Finish() [SWS_CRYPT_50088] 或 Cancel() [SWS_CRYPT_50089]。
  • ara::crypto::CryptoErrc::kUsageViolation：提供的密钥不具备加密操作所必需的权限 kAllowDataEncryption（[SWS_CRYPT_50175]、[SWS_CRYPT_50087]、[SWS_CRYPT_50090]）。
  • ara::crypto::CryptoErrc::kIncompatibleObject：传入的密钥对象或引用的 KeySlot 与底层转换不兼容（[SWS_CRYPT_50086]、[SWS_CRYPT_50175]、[SWS_CRYPT_50087]、[SWS_CRYPT_50090]）。
  • ara::crypto::CryptoErrc::kEmptyKeySlot：分配的 KeySlot 在执行时不包含任何密钥（[SWS_CRYPT_50087]、[SWS_CRYPT_50090]）。
  • ara::crypto::CryptoErrc::kInsufficientCapacity：为密文提供的缓冲区 out 不足以容纳生成的数据（[SWS_CRYPT_50090]、[SWS_CRYPT_50176]、[SWS_CRYPT_50088]）。
  • ara::crypto::CryptoErrc::kInvalidInputSize 和 ara::crypto::CryptoErrc::kInvalidArgument：输入数据的大小超出了可处理的块边界，或者输入数据包含无效结构（[SWS_CRYPT_50090]、[SWS_CRYPT_50176]、[SWS_CRYPT_50088]）。
  • ara::crypto::CryptoErrc::kUnsupported：具体实现不支持相应的模式（例如流式处理与单步调用）或密钥的分配类型（[SWS_CRYPT_50086]、[SWS_CRYPT_50175]、[SWS_CRYPT_50087]、[SWS_CRYPT_50090]、[SWS_CRYPT_50176]、[SWS_CRYPT_50088]）。
  • ara::crypto::CryptoErrc::kBusyResource：加密模块所需的硬件或软件资源已被占用（[SWS_CRYPT_50087]、[SWS_CRYPT_50090]）。

<li><strong>完成或中止：</strong>通过调用 <code>Finish()</code> 可以正常完成流式处理阶段 <a class="spec-record-ref" data-req="SWS_CRYPT_50088" href="../spec/record.html?id=SWS_CRYPT_50088">[SWS_CRYPT_50088]</a>，从而加密最后一个数据块，并且上下文返回到 <em>Initialized</em> 状态。或者，也可以使用 <code>Cancel()</code> 提前放弃正在进行的操作 <a class="spec-record-ref" data-req="SWS_CRYPT_50089" href="../spec/record.html?id=SWS_CRYPT_50089">[SWS_CRYPT_50089]</a>。若未事先调用 <code>Start()</code> 而直接调用 <code>Update()</code>、<code>Finish()</code> 或 <code>Cancel()</code>，将返回 <code>CryptoErrc::kProcessingNotStarted</code> 并被拒绝（<a class="spec-record-ref" data-req="SWS_CRYPT_50176" href="../spec/record.html?id=SWS_CRYPT_50176">[SWS_CRYPT_50176]</a>、<a class="spec-record-ref" data-req="SWS_CRYPT_50088" href="../spec/record.html?id=SWS_CRYPT_50088">[SWS_CRYPT_50088]</a>、<a class="spec-record-ref" data-req="SWS_CRYPT_50089" href="../spec/record.html?id=SWS_CRYPT_50089">[SWS_CRYPT_50089]</a>）。</li>
</ul>

<h4>使用路径</h4>
<p>规范规定了两种主要的处理路径：单步处理（Single-Call）以及逐步流式处理。</p>
<p>在<strong>单步处理</strong>中，应用程序首先分配公钥（<code>SetKey()</code>），并可选择通过 <code>GetMinimumChunkSize()</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50178" href="../spec/record.html?id=SWS_CRYPT_50178">[SWS_CRYPT_50178]</a> 以及 <code>GetMaximumChunkSize()</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50091" href="../spec/record.html?id=SWS_CRYPT_50091">[SWS_CRYPT_50091]</a> 检查允许的输入大小。为了确定所需的输出缓冲区大小，应用程序使用参数 <code>isFinal = true</code> 调用 <code>GetRequiredOutputBufferSize()</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50177" href="../spec/record.html?id=SWS_CRYPT_50177">[SWS_CRYPT_50177]</a>。随后，调用 <code>Encrypt(in, out)</code> 直接一步执行转换 <a class="spec-record-ref" data-req="SWS_CRYPT_50090" href="../spec/record.html?id=SWS_CRYPT_50090">[SWS_CRYPT_50090]</a>。</p>
<p>在<strong>流式处理</strong>中，执行过程按以下步骤进行：</p>
<ol>
<li><strong>密钥分配：</strong>通过 <code>SetKey()</code> 使用 <code>PublicKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50175" href="../spec/record.html?id=SWS_CRYPT_50175">[SWS_CRYPT_50175]</a> 或 <code>KeySlot</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50086" href="../spec/record.html?id=SWS_CRYPT_50086">[SWS_CRYPT_50086]</a> 配置上下文。</li>
<li><strong>初始化：</strong>调用 <code>Start()</code> 以开启流式会话 <a class="spec-record-ref" data-req="SWS_CRYPT_50087" href="../spec/record.html?id=SWS_CRYPT_50087">[SWS_CRYPT_50087]</a>。</li>
<li><strong>连续处理：</strong>重复将明文段传递给 <code>Update(in, out)</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50176" href="../spec/record.html?id=SWS_CRYPT_50176">[SWS_CRYPT_50176]</a>。中间步骤所需的缓冲区大小可以预先使用 <code>GetRequiredOutputBufferSize(inputSize, false)</code> 确定 <a class="spec-record-ref" data-req="SWS_CRYPT_50177" href="../spec/record.html?id=SWS_CRYPT_50177">[SWS_CRYPT_50177]</a>。</li>
<li><strong>完成：</strong>传递最终数据块并通过 <code>Finish(in, out)</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50088" href="../spec/record.html?id=SWS_CRYPT_50088">[SWS_CRYPT_50088]</a> 完成加密。为此，使用 <code>GetRequiredOutputBufferSize(inputSize, true)</code> 计算输出容量。如果必须提前中止会话，则 <code>Cancel()</code> 会中止该操作 <a class="spec-record-ref" data-req="SWS_CRYPT_50089" href="../spec/record.html?id=SWS_CRYPT_50089">[SWS_CRYPT_50089]</a>。</li>
</ol>

<h4>错误场景</h4>
<p><code>EncryptorPublicCtx</code> 的方法通过返回类型 <code>ara::core::Result</code> 指示错误。所有指定的错误均遵循回滚语义，以便在失败时上下文保持一致状态：</p>
