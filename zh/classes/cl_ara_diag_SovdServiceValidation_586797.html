使用目的

SovdServiceValidation实现制造商或供应商特定的 SOVD 检查。对于每个 SOVD 请求都会调用Validate()；对于资源集合，还会为每个包含的元素额外调用一次。[SWS_DM_01822] [SWS_DM_01827] DM 按规定顺序调用已配置的验证器，一旦其中之一失败，立即以错误终止处理。[SWS_DM_01784] [SWS_DM_01785]

生成和生命周期

该实例是为 DiagnosticSovdServiceValidationInterface 和 ConcurrencyType 的 PortPrototype 创建的。 [SWS_DM_01823]Offer通过DM激活转发，StopOffer停用它。 Offer可以返回kAlreadyOffered或kConfigurationMismatch。 [SWS_DM_01825] [SWS_DM_01826] 析构函数是异常安全的。 [SWS_DM_01824]

限制&错误处理

验证接收 HTTP 方法和 MetaInfo（包括资源路径）并返回成功或 SOVD 错误。 [SWS_DM_01827] 指定服务器配置错误、不满足先决条件、暂时不可用和缺少访问权限等情况。 [SWS_DM_01827] Validate的线程安全依赖于ConcurrencyType； Offer 和 StopOffer 不是线程安全的。 [SWS_DM_01827] [SWS_DM_01825] [SWS_DM_01826]

对于资源集合，DM 首先验证集合，然后验证要返回的每个项目及其在元信息中的自己的路径。 [SWS_DM_01785] 验证函数是异常安全的并返回 Future<void>。 [SWS_DM_01827] 构造函数是异常安全且线程安全的，析构函数是异常安全且非线程安全的。 [SWS_DM_01823] [SWS_DM_01824]

如果发生错误，DM 将不会继续处理请求。 [SWS_DM_01784]

Called for every SOVD request message. Will be called multiple times if the request is for a resource collection: • once for the resource collection, • once for each resource in the resource collection.

使用量AI 生成 / AI generated

源自此 AUTOSAR R25-11 规范元素的自动生成的使用通知 — 非官方 AUTOSAR 文本。文档：[SWS_…]。

每个传入的SOVD请求消息都会调用虚拟方法Validate；对于资源集合，会多次调用 - 一次针对集合本身，一次针对其中包含的每个资源。请求中使用的requestMethod（HTTP方法）和包含请求资源或资源集合路径[SWS_DM_01827]的metaInfo被传递。返回的ara::core::Future<void>如果请求被允许则返回空值，否则返回错误。
