ara::diag::DownloadService是诊断下载的应用接口。 Diagnostic Server 调用RequestDownload() UDS 0x34，DownloadData() TransferData，RequestDownloadExit() UDS 0x37 调用[SWS_DM_00784] [SWS_DM_00867] [SWS_DM_00869] [SWS_DM_00871]。

与其他班级的互动

Offer() 激活由 DM 执行的请求转发，StopOffer() 将其停用 [SWS_DM_00792] [SWS_DM_00793]。纯虚操作接收 Request 数据、MetaInfo 和 CancellationHandler；DownloadData() 和 RequestDownloadExit() 在成功时提供 OperationOutput [SWS_DM_00789] [SWS_DM_00790] [SWS_DM_00791]。
