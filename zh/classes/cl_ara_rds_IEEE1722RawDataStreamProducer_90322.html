上下文

模板类 ara::rds::IEEE1722RawDataStreamProducer 在 AUTOSAR Adaptive Platform 的模块 rds（Raw Data Stream）内提供了用于发送符合 IEEE 1722 标准（AUTOSAR_AP_SWS_RawDataStream, 第1页）的类型化数据流数据报的接口。作为生成器组件，它封装了特定于通道和协议的连接建立以及通过底层网络进行的有效数据传输。

寻址以及在软件端绑定到已配置的 Stream 实例是通过将 ara::core::InstanceSpecifier 传递给创建方法 [SWS_RDS_90323] 来实现的。主要交互方是创建模板类型 T 的数据元素的应用软件，以及物理传输数据报的 IEEE 1722 网络协议栈。类定义通过头文件 #include "ara/rds/raw_data_stream_IEEE1722.h" 包含 [SWS_RDS_90323]。

生命周期

ara::rds::IEEE1722RawDataStreamProducer 的实例化仅通过静态工厂方法 Create [SWS_RDS_90323] 进行。该类遵循严格的移动语义（Move-Only 语义）：复制构造函数 [SWS_RDS_90327] 以及复制赋值运算符 [SWS_RDS_90328] 已被删除（=delete），从而防止了资源的重复。

可以通过移动构造函数 [SWS_RDS_90324] 和移动赋值运算符 [SWS_RDS_90326] 将实例转移给其他所有者。在并发性方面，移动操作以及析构函数被声明为非线程安全 [SWS_RDS_90324]、[SWS_RDS_90326]、[SWS_RDS_90329]；来自不同线程的并发访问需要外部同步。

创建后，Producer 最初处于断开状态。连接通过 Connect 建立 [SWS_RDS_90330]。连接的终止既可以通过 Shutdown [SWS_RDS_90331] 显式进行，也可以在实例销毁时自动进行：析构函数 ~IEEE1722RawDataStreamProducer() 确保关闭仍处于打开状态的连接 [SWS_RDS_90329]。

使用路径

传输 IEEE 1722 数据流的常规流程分为以下几个阶段：

  1. 创建：应用程序通过 Create 指定 instance 标识符 [SWS_RDS_90323] 来实例化 Producer，并接管返回的实例。
  2. 建立连接：在数据传输之前，应用程序调用 Connect [SWS_RDS_90330] 以打开通信通道。
  3. 数据传输：随后，数据报作为类型 T 的 vector 通过 WriteData(std::vector<T> data) 传递给网络 [SWS_RDS_90332]。该步骤可以周期性或事件驱动地重复执行。
  4. 断开连接：传输完成后，Shutdown 显式终止连接 [SWS_RDS_90331]。或者，析构函数在离开作用域时关闭连接 [SWS_RDS_90329]。
