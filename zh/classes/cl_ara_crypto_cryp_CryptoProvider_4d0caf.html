上下文

类 ara::crypto::cryp::CryptoProvider 用作加密原语及其密钥管理的具体实现的核心抽象和工厂接口。它封装了加密操作，并将调用应用程序与特定于硬件的实现或加密库解耦。

作为工厂，CryptoProvider 为不同的加密算法生成专用的上下文对象：

  • 对称算法：通过CreateSymmetricCipherCtx [SWS_CRYPT_20742]实现的流/分组密码、通过CreateAuthCipherCtx [SWS_CRYPT_20745]实现的认证加密、通过CreateHashFunctionCtx [SWS_CRYPT_20747]实现的密码学哈希函数以及通过CreateMessageAuthnCodeCtx [SWS_CRYPT_20746]实现的消息认证码。
  • 非对称算法：通过CreateEncryptorPublicCtx [SWS_CRYPT_20750]实现的公钥加密、通过CreateDecryptorPrivateCtx [SWS_CRYPT_20751]实现的私钥解密、通过CreateSignerPrivateCtx [SWS_CRYPT_20756]实现的签名生成、通过CreateVerifierPublicCtx [SWS_CRYPT_20757]实现的签名验证以及通过CreateKeyAgreementPrivateCtx [SWS_CRYPT_20758]实现的密钥协商。
  • 密钥封装与传输：通过CreateKeyEncapsulatorPublicCtx [SWS_CRYPT_20752]和CreateKeyDecapsulatorPrivateCtx [SWS_CRYPT_20753]实现的密钥封装机制、通过CreateKeyDerivationFunctionCtx [SWS_CRYPT_20748]实现的密钥派生、通过CreateSymmetricKeyWrapperCtx [SWS_CRYPT_20743]实现的对称密钥包装以及通过CreateProtectedKeyImportCtx [SWS_CRYPT_50017]实现的受保护密钥导入。

此外，该实例还与密钥管理资源进行交互。它从KeySlot加载已保存的密钥（[SWS_CRYPT_20762]、[SWS_CRYPT_20763]、[SWS_CRYPT_20764]），生成新密钥（[SWS_CRYPT_20721]、[SWS_CRYPT_20722]），导入序列化密钥（[SWS_CRYPT_50014]、[SWS_CRYPT_20732]、[SWS_CRYPT_50132]），并保护用于导出的密钥（[SWS_CRYPT_20728]）。随机数生成（[SWS_CRYPT_20741]、[SWS_CRYPT_30098]）、安全计数器（[SWS_CRYPT_20098]）和提供程序标识（[SWS_CRYPT_50015]、[SWS_CRYPT_50016]）等平台服务完善了功能范围。

生命周期

CryptoProvider 的实例通过类型别名 Sptr 作为 std::shared_ptr<CryptoProvider> 进行管理 [SWS_CRYPT_20701]。向应用程序提供 Provider 实例很可能是通过平台特定的工厂机制进行的。针对 Provider 的复制和移动操作已被显式禁止：复制构造函数 [SWS_CRYPT_41005]、移动构造函数 [SWS_CRYPT_41006]、复制赋值运算符 [SWS_CRYPT_30216] 和移动赋值运算符 [SWS_CRYPT_30217] 均已被删除（=delete）。

资源的释放通过虚析构函数 ~CryptoProvider [SWS_CRYPT_20710] 以多态方式进行。在执行安全方面，所有接口方法均被声明为线程安全（thread-safe）和异常安全（exception safe）。所有方法均使用 noexcept，并且仅通过返回类型 ara::core::Result 报告错误。

使用路径

密码学操作的典型使用路径包括确定使用权限、提供密钥以及随后创建上下文：

  1. 查询默认使用标志：在生成密钥之前，可通过 GetDefaultAllowedUsage(algId) [SWS_CRYPT_20955] 确定所选算法默认指定了哪些使用标志。根据规范，返回的标志既不包含 kAllowPlaintextExport、kAllowPersist，也不包含 kAllowSecuredExport。
  2. 提供密钥：通过 GenerateSymmetricKey [SWS_CRYPT_20721] 生成新的对称密钥，或通过 GeneratePrivateKey [SWS_CRYPT_20722] 生成非对称密钥对。或者，也可以通过 LoadSymmetricKey [SWS_CRYPT_20762]、LoadPrivateKey [SWS_CRYPT_20764] 或 LoadPublicKey [SWS_CRYPT_20763] 加载现有密钥。在生成私钥时，Provider 会自动派生关联公钥的使用标志，并为其激活 kAllowPlaintextExport 以及 kAllowPersist [SWS_CRYPT_20722]。
  3. 实例化上下文：调用方根据所需的转换创建所需的上下文，例如通过 CreateAuthCipherCtx(algId) [SWS_CRYPT_20745] 创建 AuthCipherCtx。所创建的上下文随后很可能在后续步骤中配置该密钥。
  4. 密钥导出（可选）：如果需要受保护地导出密钥对象，ExportSecuredKey [SWS_CRYPT_20728] 会使用可选的密钥加密密钥（kek）将该对象序列化并加密到输出缓冲区中。

CryptoProvider 的方法在发生错误时保证回滚语义，从而保持系统状态的一致。已定义的错误代码（ara::crypto::CryptoErrc）包括：

<h4>上下文</h4>
<p>类 <code>ara::crypto::cryp::CryptoProvider</code> 用作加密原语及其密钥管理的具体实现的核心抽象和工厂接口。它封装了加密操作，并将调用应用程序与特定于硬件的实现或加密库解耦。</p>
<p>作为工厂，<code>CryptoProvider</code> 为不同的加密算法生成专用的上下文对象：</p>
<ul>
<li>对称算法：通过<code>CreateSymmetricCipherCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20742" href="../spec/record.html?id=SWS_CRYPT_20742">[SWS_CRYPT_20742]</a>实现的流/分组密码、通过<code>CreateAuthCipherCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20745" href="../spec/record.html?id=SWS_CRYPT_20745">[SWS_CRYPT_20745]</a>实现的认证加密、通过<code>CreateHashFunctionCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20747" href="../spec/record.html?id=SWS_CRYPT_20747">[SWS_CRYPT_20747]</a>实现的密码学哈希函数以及通过<code>CreateMessageAuthnCodeCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20746" href="../spec/record.html?id=SWS_CRYPT_20746">[SWS_CRYPT_20746]</a>实现的消息认证码。</li>
<li>非对称算法：通过<code>CreateEncryptorPublicCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20750" href="../spec/record.html?id=SWS_CRYPT_20750">[SWS_CRYPT_20750]</a>实现的公钥加密、通过<code>CreateDecryptorPrivateCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20751" href="../spec/record.html?id=SWS_CRYPT_20751">[SWS_CRYPT_20751]</a>实现的私钥解密、通过<code>CreateSignerPrivateCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20756" href="../spec/record.html?id=SWS_CRYPT_20756">[SWS_CRYPT_20756]</a>实现的签名生成、通过<code>CreateVerifierPublicCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20757" href="../spec/record.html?id=SWS_CRYPT_20757">[SWS_CRYPT_20757]</a>实现的签名验证以及通过<code>CreateKeyAgreementPrivateCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20758" href="../spec/record.html?id=SWS_CRYPT_20758">[SWS_CRYPT_20758]</a>实现的密钥协商。</li>
<li>密钥封装与传输：通过<code>CreateKeyEncapsulatorPublicCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20752" href="../spec/record.html?id=SWS_CRYPT_20752">[SWS_CRYPT_20752]</a>和<code>CreateKeyDecapsulatorPrivateCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20753" href="../spec/record.html?id=SWS_CRYPT_20753">[SWS_CRYPT_20753]</a>实现的密钥封装机制、通过<code>CreateKeyDerivationFunctionCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20748" href="../spec/record.html?id=SWS_CRYPT_20748">[SWS_CRYPT_20748]</a>实现的密钥派生、通过<code>CreateSymmetricKeyWrapperCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20743" href="../spec/record.html?id=SWS_CRYPT_20743">[SWS_CRYPT_20743]</a>实现的对称密钥包装以及通过<code>CreateProtectedKeyImportCtx</code> <a class="spec-record-ref" data-req="SWS_CRYPT_50017" href="../spec/record.html?id=SWS_CRYPT_50017">[SWS_CRYPT_50017]</a>实现的受保护密钥导入。</li>

<h4>生命周期</h4>
<p><code>CryptoProvider</code> 的实例通过类型别名 <code>Sptr</code> 作为 <code>std::shared_ptr&lt;CryptoProvider&gt;</code> 进行管理 <a class="spec-record-ref" data-req="SWS_CRYPT_20701" href="../spec/record.html?id=SWS_CRYPT_20701">[SWS_CRYPT_20701]</a>。向应用程序提供 Provider 实例很可能是通过平台特定的工厂机制进行的。针对 Provider 的复制和移动操作已被显式禁止：复制构造函数 <a class="spec-record-ref" data-req="SWS_CRYPT_41005" href="../spec/record.html?id=SWS_CRYPT_41005">[SWS_CRYPT_41005]</a>、移动构造函数 <a class="spec-record-ref" data-req="SWS_CRYPT_41006" href="../spec/record.html?id=SWS_CRYPT_41006">[SWS_CRYPT_41006]</a>、复制赋值运算符 <a class="spec-record-ref" data-req="SWS_CRYPT_30216" href="../spec/record.html?id=SWS_CRYPT_30216">[SWS_CRYPT_30216]</a> 和移动赋值运算符 <a class="spec-record-ref" data-req="SWS_CRYPT_30217" href="../spec/record.html?id=SWS_CRYPT_30217">[SWS_CRYPT_30217]</a> 均已被删除（<code>=delete</code>）。</p>
<p>资源的释放通过虚析构函数 <code>~CryptoProvider</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20710" href="../spec/record.html?id=SWS_CRYPT_20710">[SWS_CRYPT_20710]</a> 以多态方式进行。在执行安全方面，所有接口方法均被声明为线程安全（thread-safe）和异常安全（exception safe）。所有方法均使用 <code>noexcept</code>，并且仅通过返回类型 <code>ara::core::Result</code> 报告错误。</p>

<h4>使用路径</h4>
<p>密码学操作的典型使用路径包括确定使用权限、提供密钥以及随后创建上下文：</p>
<ol>
<li>查询默认使用标志：在生成密钥之前，可通过 <code>GetDefaultAllowedUsage(algId)</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20955" href="../spec/record.html?id=SWS_CRYPT_20955">[SWS_CRYPT_20955]</a> 确定所选算法默认指定了哪些使用标志。根据规范，返回的标志既不包含 <code>kAllowPlaintextExport</code>、<code>kAllowPersist</code>，也不包含 <code>kAllowSecuredExport</code>。</li>
<li>提供密钥：通过 <code>GenerateSymmetricKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20721" href="../spec/record.html?id=SWS_CRYPT_20721">[SWS_CRYPT_20721]</a> 生成新的对称密钥，或通过 <code>GeneratePrivateKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20722" href="../spec/record.html?id=SWS_CRYPT_20722">[SWS_CRYPT_20722]</a> 生成非对称密钥对。或者，也可以通过 <code>LoadSymmetricKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20762" href="../spec/record.html?id=SWS_CRYPT_20762">[SWS_CRYPT_20762]</a>、<code>LoadPrivateKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20764" href="../spec/record.html?id=SWS_CRYPT_20764">[SWS_CRYPT_20764]</a> 或 <code>LoadPublicKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20763" href="../spec/record.html?id=SWS_CRYPT_20763">[SWS_CRYPT_20763]</a> 加载现有密钥。在生成私钥时，Provider 会自动派生关联公钥的使用标志，并为其激活 <code>kAllowPlaintextExport</code> 以及 <code>kAllowPersist</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20722" href="../spec/record.html?id=SWS_CRYPT_20722">[SWS_CRYPT_20722]</a>。</li>
<li>实例化上下文：调用方根据所需的转换创建所需的上下文，例如通过 <code>CreateAuthCipherCtx(algId)</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20745" href="../spec/record.html?id=SWS_CRYPT_20745">[SWS_CRYPT_20745]</a> 创建 <code>AuthCipherCtx</code>。所创建的上下文随后很可能在后续步骤中配置该密钥。</li>
<li>密钥导出（可选）：如果需要受保护地导出密钥对象，<code>ExportSecuredKey</code> <a class="spec-record-ref" data-req="SWS_CRYPT_20728" href="../spec/record.html?id=SWS_CRYPT_20728">[SWS_CRYPT_20728]</a> 会使用可选的密钥加密密钥（<code>kek</code>）将该对象序列化并加密到输出缓冲区中。</li>
</ol>
