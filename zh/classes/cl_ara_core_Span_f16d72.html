使用目的

ara::core::Span<T, Extent> 将std::span 实现为相关元素的视图； Extent可以是静态的或动态的[SWS_CORE_01900][SWS_CORE_01931]。

生成&销毁

Span 可由指针、C 数组、ara::core::Array、兼容容器或另一个 Span 构造 [SWS_CORE_01942] [SWS_CORE_01943] [SWS_CORE_01944] [SWS_CORE_01945] [SWS_CORE_01947] [SWS_CORE_01950]。Copy 构造、Copy 赋值和析构函数均为 defaulted 且 exception-safe [SWS_CORE_01949] [SWS_CORE_01952] [SWS_CORE_01951]。

生命周期和所有权

该类存储视图，而不是底层元素；该接口提供了用于访问 [SWS_CORE_01915] [SWS_CORE_01916] [SWS_CORE_01917] [SWS_CORE_01971] 的指针、引用和迭代器。引用元素的有效性不是由此类管理的。

与其他班级的互动

first()、last()和subspan()创建部分视图； size()和size_bytes()表示其范围[SWS_CORE_01961][SWS_CORE_01962][SWS_CORE_01963][SWS_CORE_01964][SWS_CORE_01965][SWS_CORE_01966][SWS_CORE_01967][SWS_CORE_01968]。

限制&错误处理

指定的操作是constexpr、noexcept和exception-safe[SWS_CORE_01960][SWS_CORE_01970][SWS_CORE_01969]。该规范没有为 operator[]、front() 或 back() [SWS_CORE_01959] [SWS_CORE_01960] [SWS_CORE_01970] 的限制定义自己的运行时检查。

相关数据的非拥有视图

Core 将 Span 归类为视图类型，因此在概念上它基于 C++ 标准库。类型传达的是视图，而不是元素的所有权；因此，现有 API 块中描述的指针、引用和迭代器访问需要仍然有效的底层序列。 SWS Core §7.4 “Core data types” SWS Core §7.4.2 “Data types derived from the C++ standard”

解释：对于接口，Span适用于要传输连续区域但既不复制也不改变其所有权的情况。此分类遵循作为视图的 SWS 分类和作为元素视图的 API 形式。
