类 ara::diag::DiagnosticSovdRecordContentElementDataView（[SWS_DM_02270]、SWS Diagnostics §8.60.11 “Class: DiagnosticSovdRecordContentElementDataView”）表示对组织为结构化 Record 的诊断内容元素（DiagnosticSovdContentElementData）的类型化视图。在面向服务的车辆诊断（SOVD）框架下，它充当在诊断数据集中管理和操作键值映射的接口。其交互对象包括上层诊断应用程序、底层的 DiagnosticSovdContentElementData 实例以及专用迭代器类型 DiagnosticSovdRecordContentElementDataIterator 和 DiagnosticSovdRecordContentElementDataConstIterator（[SWS_DM_02279]、[SWS_DM_02281]）。为了进行类型化填充，该类提供了重载的 Add 操作，既接受 std::int64_t、std::uint64_t、double、bool 和 ara::core::StringView 等基本数据类型，也接受嵌套的 DiagnosticSovdContentElementData 对象（[SWS_DM_02288] 至 [SWS_DM_02293]）。

生命周期

作为视图类，DiagnosticSovdRecordContentElementDataView 本身并不拥有所管理的数据（解释：该实例充当针对现有数据结构的轻量级访问包装）。正确使用该视图的前提条件是，所引用的基础元素类型为 RecordContentElementData 或 ContentData（[SWS_DM_02273]、[SWS_DM_02288]）。内部状态反映了底层 Record 的占用情况：填充状态可通过 Empty（[SWS_DM_02275]）和 Size（[SWS_DM_02273]）进行监控，而 Capacity（[SWS_DM_02274]）和 Reserve（[SWS_DM_02283]）控制内存分配。使用 Clear（[SWS_DM_02276]）可以重置所有元素。此外，内容的状态可以通过 SetError 显式设置为错误状态（[SWS_DM_02272]），或通过 HasError 进行查询（[SWS_DM_02271]）。在并发性方面，该类的所有成员函数均被指定为线程安全（thread-safe）和异常安全（exception safe）（[SWS_DM_02271] 至 [SWS_DM_02294]）。

使用路径

典型使用路径包括预先进行容量预留、逐步填充 Record 以及对各个字段元素的随机访问：

  1. 预留容量：在插入多个值之前，通过 Reserve 预先保留预计所需的容量（[SWS_DM_02283]）。
  2. 插入元素：通过 Add 的类型特定重载，在指定键的情况下注册数据元素（[SWS_DM_02288] 至 [SWS_DM_02293]）。
  3. 检查存在性与查找：通过 HasContentElement 可以检查键是否存在（[SWS_DM_02284]），或者通过 Find 获取指向该元素的迭代器（[SWS_DM_02285]、[SWS_DM_02286]）。
  4. 读取或修改值：通过 operator[] 获取对所需 DiagnosticSovdContentElementData 的引用（[SWS_DM_02277]、[SWS_DM_02278]）。
  5. 移除元素：不再需要的条目通过 Remove 按键删除（[SWS_DM_02287]），或通过 Erase 使用迭代器删除（[SWS_DM_02294]）。

错误场景

可能发生错误的方法通过返回类型 ara::core::Result 指示失败：

  • 基础实例的数据类型不兼容：如果底层 DiagnosticSovdContentElementData 实例不是 RecordContentElementData 或 ContentData 类型，则 Add、operator[]、HasContentElement、Remove 和 Erase 等修改和查询操作将失败，并在 Result 中返回错误（[SWS_DM_02277]、[SWS_DM_02284]、[SWS_DM_02287]、[SWS_DM_02288]、[SWS_DM_02294]）。
  • 插入时元素类型不允许：如果尝试添加本身为 ContentData 类型的子元素，则对 Add 的调用将失败（[SWS_DM_02288] 至 [SWS_DM_02293]）。
  • 未找到键：对于 operator[]、HasContentElement 或 Remove，如果指定的键在 Record 中不存在，Result 将返回错误（[SWS_DM_02277]、[SWS_DM_02284]、[SWS_DM_02287]）。
  • Erase 时迭代器无效：如果向 Erase 传递了无效迭代器，该函数将返回错误代码 DiagErrc::kInvalidArgument（[SWS_DM_02294]）。
  • 已设置 SOVD 错误：如果内容包含通过 SetError 设置的错误代码（[SWS_DM_02272]），则 HasError 会在 Result 中将该错误作为 ara::diag::DiagSovdErrc 返回（[SWS_DM_02271]）。
