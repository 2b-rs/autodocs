类 apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

使用目的

UdsMessage 表示通用 DM 核心或 UdsTransportProtocolMgr 与 UdsTransportProtocolHandler 的具体实现之间的 UDS 消息。该对象为 UDS 请求和响应提供存储。 [SWS_DM_00291]

生成 & 所有权

优化资源分配的实例由DM核心独家创建； Protocol Handler可以读取和写入它，但不应自行生成它。因此，Default-Konstruktor受到保护。如果该指示被接受，则UdsMessagePtr具有至少一个字节容量的有效对象；最初，GetPayload()提供的缓冲区是空的。 [SWS_DM_09012][SWS_DM_00385][SWS_DM_00392]

与其他班级的互动

非恒定负载访问返回可写的ByteSpan；持续访问可从 SID 传送UDS 数据，无需写入访问。成功指示后，传输Handler将填充SID中的有效负载直至达到容量或直到接收到的消息结束。源、目标和物理或功能目标地址类型可通过 getter 获得； AddMetaInfo() 添加元信息。 [SWS_DM_00301][SWS_DM_00300][SWS_DM_00388][SWS_DM_00297][SWS_DM_00298][SWS_DM_00299][SWS_DM_00302]

限制

析构函数是虚拟的，默认实现并且异常安全。地址获取器是可重入的；有效负载访问和AddMetaInfo()都被指定为非线程安全的。 [SWS_DM_09010][SWS_DM_00297][SWS_DM_00298][SWS_DM_00299][SWS_DM_00300][SWS_DM_00301][SWS_DM_00302]
