用于基于密钥计算和验证加密 Message Authentication Code。

该接口支持对任意长度的消息进行基于密钥的 Message Authentication Code 计算和验证。在使用对称密钥通过 [SWS_CRYPT_22118] 初始化之后，MAC 摘要既可以在单步中处理，也可以在流式处理过程中通过启动、更新和完成调用来处理。随后可以检索生成的检查结果，或直接与期望值进行比对。所有方法均被指定为线程安全的，并通过符合 [SWS_CRYPT_22116] 的标准化返回值来指示错误流程或缓冲区容量不足。

上下文

接口 MessageAuthnCodeCtx 定义了用于生成和验证基于密钥的消息认证码（Message Authentication Code，MAC）的加密操作。它允许通过增量数据流以及单个连续内存块对任意数据量进行真实性和完整性检查。实例的管理通过所提供的智能指针类型 Sptr [SWS_CRYPT_22101] 进行。

调用的应用组件以及密钥对象作为核心交互伙伴出现。上下文既可以直接使用对称密钥对象 SymmetricKey [SWS_CRYPT_22118] 进行配置，也可以通过逻辑存储槽 KeySlot [SWS_CRYPT_50026] 进行配置。数据传递通过缓冲区结构进行，例如用于输入数据的 ReadOnlyMemRegion 以及用于已计算 MAC 摘要的 ReadWriteMemRegion。

生命周期

上下文实例经历从初始化到提供 MAC 结果的定义状态序列：

  • Uninitialized：创建之后，上下文尚不具备密钥，并拒绝计算调用。
  • Configured：通过使用密钥 [SWS_CRYPT_22118] 或密钥存储 [SWS_CRYPT_50026] 调用 SetKey()，上下文被初始化。在此状态下，可以执行单次调用方法或启动流式会话。
  • Processing：在不带初始化向量 [SWS_CRYPT_22111] 或带有 IV [SWS_CRYPT_22110] 的情况下调用 Start() 会开启流式处理。通过重复调用 Update() [SWS_CRYPT_22113] 来送入数据块。可以通过 Cancel() 进行中止 [SWS_CRYPT_50027]。
  • Finished：方法 Finish() [SWS_CRYPT_22115] 完成计算。随后可以查询或比较结果。

解释：完成或中止后，上下文大概率保持在已配置状态，并可重新用于新的操作。该接口的所有方法均被指定为线程安全且异常安全的。

使用路径

该接口支持两种典型的使用路径：增量流式处理和单次调用处理。

在流式路径中，调用方首先通过 SetKey() [SWS_CRYPT_22118] 绑定密钥。在开始之前，可以通过 GetRecommendedIvSize() [SWS_CRYPT_50135] 查询算法参数（例如建议的 IV 大小），并通过 GetMaximumChunkSize() [SWS_CRYPT_50033] 查询最大分块大小。调用 Start() [SWS_CRYPT_22110] 之后，消息分片将通过 Update() 逐次处理 [SWS_CRYPT_22113]。一旦所有数据均已传递，Finish() 便完成计算 [SWS_CRYPT_22115]。生成的摘要随后通过 GetDigest() 复制到缓冲区中 [SWS_CRYPT_22116]，该缓冲区的最小大小可预先通过 GetDigestSize() 确定 [SWS_CRYPT_50134]。或者，Compare() [SWS_CRYPT_50133] 或 CompareSubspan() [SWS_CRYPT_50028] 允许直接与预期的参考值进行比对。

时序图：流式模式下增量 MAC 计算的流程。来源：[SWS_CRYPT_22118]、[SWS_CRYPT_22110]、[SWS_CRYPT_22113]、[SWS_CRYPT_22115]、[SWS_CRYPT_22116]

如果整条消息已经完整可用，则无需流式处理，可通过 Generate() [SWS_CRYPT_50029] 或截短方式通过 GenerateSubspan() [SWS_CRYPT_50030] 在单步中完成计算。对于验证，类似地提供了方法 Verify() [SWS_CRYPT_50031] 和 VerifySubspan() [SWS_CRYPT_50032]。

错误场景

错误通过返回类型 ara::core::Result 发出信号，并涵盖以下原因：

  • 状态错误：在未配置密钥的情况下调用 Start()、Generate() 或 Verify() 将因 kUninitializedContext 而失败 [SWS_CRYPT_22110] [SWS_CRYPT_50029]。未事先启动就调用 Update()、Finish() 或 Cancel() 将报告 kProcessingNotStarted [SWS_CRYPT_22113] [SWS_CRYPT_22115] [SWS_CRYPT_50027]。在完成之前访问结果将返回 kProcessingNotFinished [SWS_CRYPT_22116] [SWS_CRYPT_50133]。
  • 密钥与权限错误：如果传入的密钥与上下文不兼容，则发生 kIncompatibleObject [SWS_CRYPT_22118] [SWS_CRYPT_50026]。若密钥缺少权限 kAllowMac，则导致 kUsageViolation [SWS_CRYPT_22118] [SWS_CRYPT_22110]。如果配置引用了空的 KeySlot，则报告 kEmptyKeySlot [SWS_CRYPT_22110]。
  • 参数与缓冲区错误：过小的输出缓冲区会被拒绝并返回 kInsufficientCapacity [SWS_CRYPT_22116] [SWS_CRYPT_50029]。不受支持的输入或 IV 长度会导致 kInvalidInputSize [SWS_CRYPT_22113] [SWS_CRYPT_50133]。如果算法不支持某些模式或 IV 配置，则产生 kUnsupported [SWS_CRYPT_22110] [SWS_CRYPT_50029]。被占用的加密硬件资源通过 kBusyResource 报告 [SWS_CRYPT_22110]。
