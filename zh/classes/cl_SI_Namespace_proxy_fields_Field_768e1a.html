允许客户端应用程序对服务字段进行异步查询、修改和订阅式监视。

该类用作访问 ServiceInterface 中定义的字段的客户端接口，并汇集了 Getter、Setter 以及通知功能。如果建模了相应操作，则可以通过 [SWS_CM_00112] 和 [SWS_CM_00113] 异步查询和修改值。对于字段更新，使用基于订阅的缓存机制，该机制缓存通知并通过回调处理程序进行转发。一项重要的边界条件是遵守最小发送间隔，以及在写访问时放弃回滚语义。

上下文

在 AUTOSAR Adaptive Platform 的通信管理（ara::com）中，类 <SI-Namespace>::proxy::fields::<Field> 表示在客户端或代理端服务接口中建模的单个字段（Field）。该类汇集了对属性值的访问，并结合了三个功能角色：查询当前值（Getter）、修改值（Setter）以及接收异步值更改（Notifier）（AUTOSAR_AP_EXP_ARAComAPI 第10页）。它充当客户端应用程序与底层通信层（Network Binding）之间的接口。

实例上可用的操作取决于服务接口的定义：仅当配置了 Field.hasGetter == TRUE 时才会生成方法 Get() [SWS_CM_00112]。仅当 Field.hasSetter == TRUE 成立时，方法 Set() 才可用 [SWS_CM_00113]。此时，字段的具体数据类型通过提供的类型别名 FieldType 进行类型安全的映射 [SWS_CM_11403]。

生命周期

字段对象作为上级代理类的成员进行实例化。因此，其生存期推测直接绑定到相应代理实例的生命周期。对于基于事件的 Notifier 机制，该实例经历明确规定的订阅生命周期：

  • 未订阅：最初字段处于状态 kNotSubscribed。
  • 已请求订阅：通过同步调用 Subscribe(maxSampleCount) [SWS_CM_11601] 设置缓冲区并启动注册。Notifier 转换到 kSubscriptionPending，或者在通信层确认后转换到 kSubscribed，其中此状态转换推测是异步完成的。
  • 订阅已结束：通过 Unsubscribe() [SWS_CM_11602] 停止通知流，状态切换回 kNotSubscribed。

当前状态可以随时通过 GetSubscriptionState() 同步查询 [SWS_CM_11604]。为了异步获知状态更改，可以使用 SetSubscriptionStateChangeHandler() 设置回调 [SWS_CM_11607]，可选带有专用执行上下文 [SWS_CM_11608]。在销毁实例之前或在停用时，应通过 UnsetReceiveHandler() [SWS_CM_11606]、UnsetSubscriptionStateChangeHandler() [SWS_CM_11609] 以及 UnsetTransportFaultConditionHandler() [SWS_CM_00126] 显式移除已注册的回调。

状态图：通过 ara::com::SubscriptionState 的 Notifier 订阅生命周期。来源：[SWS_CM_11601]、[SWS_CM_11602]、[SWS_CM_11604]。

使用路径

典型使用路径包括通知注册、接收新数据以及特定时间点的读写访问：

  1. 设置订阅：应用程序调用带有期望缓存容量的 Subscribe() [SWS_CM_11601]，并使用 SetReceiveHandler() 注册无参数通知回调 [SWS_CM_11605]。对于并发架构，可以通过执行器委托执行 [SWS_CM_11611]。此外，还可以针对 Notifier 事件设置传输错误处理程序 [SWS_CM_00109]、[SWS_CM_00110]。
  2. 处理样本：一旦通信管理接收到新字段数据，它就会触发接收处理程序。处理程序通过 GetFreeSampleCount() [SWS_CM_11603] 确定可用缓冲区空间，并通过 GetNewSamples() [SWS_CM_11610] 处理新值。接收到的通知的 E2E 状态可以通过 GetE2EStateMachineStateNotifier() 进行检查 [SWS_CM_11612]。
  3. 显式读取：获取当前值通过 Get() [SWS_CM_00112] 异步完成，并返回 ara::core::Future<FieldType> [SWS_CM_11403]。完成后，可以使用 GetE2EStateMachineStateGetter() 验证 E2E 校验状态 [SWS_CM_00145]。
  4. 显式写入：修改值通过 Set(value) [SWS_CM_00113] 执行。返回的 ara::core::Future<FieldType> 提供 Set 操作的结果，其 E2E 状态可以通过 GetE2EStateMachineStateSetter() 读取 [SWS_CM_00146]。

时序图：与通知交互以及 Get 和 Set 操作的典型流程。来源：[SWS_CM_00112]、[SWS_CM_00113]、[SWS_CM_11601]、[SWS_CM_11605]、[SWS_CM_11610]。

错误场景

使用字段方法时可能会发生各种错误状态：

  • 通信故障：如果在 Get() 或 Set() 时网络传输失败，Future 中将传达错误 ComErrc::kCommunicationFailure [SWS_CM_00112]、[SWS_CM_00113]。对于 Get()，回滚语义生效；对于 Set()，适用 no_rollback_semantics，因此发生超时可能会在服务器上导致不确定状态 [SWS_CM_00113]。
  • 违背发送间隔：如果发送请求的速度快于部署中配置的速度，将导致 ComErrc::kMinimumSendIntervalViolationError [SWS_CM_00112]、[SWS_CM_00113]。
  • 缓冲区限制：如果在 Subscribe() 时无法分配内存，该方法将返回 ComErrc::kMaxSampleCountNotRealizable [SWS_CM_11601]。如果在 GetNewSamples() 时获取了过多样本，则调用因 ComErrc::kMaxSamplesExceeded 失败 [SWS_CM_11610]。
  • 访问和处理程序违规：缺少执行权限会导致 Get()、Set() 或 Subscribe() 处的 InsufficientPermissionsViolation [SWS_CM_00112]、[SWS_CM_00113]、[SWS_CM_11601]。将空或无效的可调用对象传递给处理程序注册将触发 InvalidHandlerViolation [SWS_CM_11605]、[SWS_CM_11607]、[SWS_CM_00109]。
  • 幂等性：在状态 kSubscribed 或 kSubscriptionPending 下以相同缓冲区值再次调用 Subscribe() 不会产生任何效果 [SWS_CM_11601]；同样，在没有活动订阅的情况下调用 Unsubscribe() 也会无效返回 [SWS_CM_11602]。

使用

方法 Get 在代理作用域 <SI-Namespace>::proxy::fields::<Field> 中用于异步检索当前字段值（[SWS_CM_00112]；另见 AUTOSAR_AP_EXP_ARAComAPI §6 “FieldGet”）。该函数通过代理头文件 <SiNamespaceDerivedDirectoryPath>/<SiShortname>_proxy.h 提供，并且仅在为该字段建模了 Field.hasGetter == TRUE 时存在（[SWS_CM_00112]）。它不接受任何参数，并返回一个 ara::core::Future<FieldType>，该对象在成功传输后包含当前值（[SWS_CM_00112]）。

错误处理与边界条件

该接口被定义为 noexcept 且异常安全（[SWS_CM_00112]）。如果操作失败，返回的 ara::core::Future 包含具有回滚语义的错误代码（[SWS_CM_00112]）：

  • ComErrc::kCommunicationFailure：网络绑定报告可恢复的通信错误或安全通信失败（[SWS_CM_00112]）。
  • ComErrc::kMinimumSendIntervalViolationError：发送请求的发生速度快于该元素配置的最小发送间隔（minimumSendInterval）所允许的速度（[SWS_CM_00112]）。
  • InsufficientPermissionsViolation：执行被授权执行（Grant Enforcement）拒绝（[SWS_CM_00112]）。

Getter 不存在应用程序错误（Application Errors）（[SWS_CM_00113]）。

相互作用

在骨架端，Getter 请求的处理以前提为通过 RegisterGetHandler 配置的回调（[SWS_CM_00114]）。每次调用 Get() 都会执行端到端检查（E2E）；由此产生的状态信息可以在代理端通过 GetE2EStateMachineStateGetter 同步查询（[SWS_CM_00145]）。
