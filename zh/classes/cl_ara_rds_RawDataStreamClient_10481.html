上下文

C++ 类ara::rds::RawDataStreamClient是 AUTOSAR Adaptive Platform 在 R25-11 版本中功能集群 Raw Data Stream（rds）的一部分。它用作客户端终结点，用于通过底层网络连接读取和写入二进制原始数据流。通过由ara::core::InstanceSpecifier标识的建模工件，客户端将自身绑定到特定的通信端口，并为应用程序特定的字节流封装连接建立和数据传输。

生命周期

ara::rds::RawDataStreamClient的实例无法通过常规构造函数进行实例化。默认构造函数不是公开可访问的，且拷贝构造函数[SWS_RDS_11303]和拷贝赋值运算符[SWS_RDS_11304]均已被显式删除（move-only）。相反，创建是通过静态工厂方法Create [SWS_RDS_10482]并传递负责的ara::core::InstanceSpecifier来进行的。Create被规范为线程安全，并在成功时在ara::core::Result中返回一个已初始化的客户端实例。

所有权关系是排他的：可以通过移动构造函数[SWS_RDS_11305]和移动赋值运算符[SWS_RDS_11306]来移动实例。这两个操作均使用noexcept进行声明，但不是线程安全的。

创建后，客户端处于断开状态。随后通过Connect建立活动的网络连接[SWS_RDS_10484]，[SWS_RDS_11307]。连接的终止通过Shutdown [SWS_RDS_10485]有序进行。析构函数~RawDataStreamClient [SWS_RDS_10483]确保在离开作用域时自动关闭仍然打开的连接。它被规范为非线程安全。

使用路径

传输二进制数据的常规流程分为创建、连接建立、有效载荷数据传输和连接断开：

  1. 实例化：应用程序使用Create(instance) [SWS_RDS_10482]同步创建客户端。
  2. 连接建立：在首次数据交换之前建立连接。为此，可以使用阻塞式变体Connect() [SWS_RDS_10484]，或者带有std::chrono::milliseconds类型超时的限时重载Connect(timeout) [SWS_RDS_11307]。
  3. 发送数据：写入操作通过WriteData(data, maxLength) [SWS_RDS_10487]或WriteData(data, maxLength, timeout) [SWS_RDS_11310]进行。有效载荷数据作为std::unique_ptr<ara::core::Byte[]>传递，从而使内存缓冲区以独占方式转入发送操作的管理之下。
  4. 接收数据：ReadData(maxLength) [SWS_RDS_10486]或带超时的变体ReadData(maxLength, timeout) [SWS_RDS_11309]用于读取数据。接收成功时，将返回一个ReadDataResult。
  5. 连接断开：数据传输完成后，应用程序通过Shutdown() [SWS_RDS_10485]显式关闭网络连接。

错误场景

ara::rds::RawDataStreamClient的所有功能接口均不使用 C++ 异常，而是通过带有noexcept保证的返回类型ara::core::Result来指示成功或失败：

  • 连接建立失败：如果客户端无法与对端建立连接或指定的时间限制超时，则Connect失败，并在ara::core::Result<void> [SWS_RDS_10484]中返回来自错误域RdsErrc的错误代码。
  • 读写操作错误：如果连接在传输期间中断，或者超过了 WriteData 或 ReadData 的超时时间，则对应的结果对象会包含相应的错误代码 [SWS_RDS_10486]、[SWS_RDS_10487]、[SWS_RDS_11309]、[SWS_RDS_11310]。
  • 配置错误：如果传入的 ara::core::InstanceSpecifier 在系统模型中不存在，或者未分配给有效的通信端口，则 Create 便会失败，并在 Result 对象 [SWS_RDS_10482] 中提供相应的错误原因。

<h4>上下文</h4>
<p>C++ 类<code>ara::rds::RawDataStreamClient</code>是 AUTOSAR Adaptive Platform 在 R25-11 版本中功能集群 <em>Raw Data Stream</em>（<code>rds</code>）的一部分。它用作客户端终结点，用于通过底层网络连接读取和写入二进制原始数据流。通过由<code>ara::core::InstanceSpecifier</code>标识的建模工件，客户端将自身绑定到特定的通信端口，并为应用程序特定的字节流封装连接建立和数据传输。</p>

<h4>生命周期</h4>
<p><code>ara::rds::RawDataStreamClient</code>的实例无法通过常规构造函数进行实例化。默认构造函数不是公开可访问的，且拷贝构造函数<a class="spec-record-ref" data-req="SWS_RDS_11303" href="../spec/record.html?id=SWS_RDS_11303">[SWS_RDS_11303]</a>和拷贝赋值运算符<a class="spec-record-ref" data-req="SWS_RDS_11304" href="../spec/record.html?id=SWS_RDS_11304">[SWS_RDS_11304]</a>均已被显式删除（<em>move-only</em>）。相反，创建是通过静态工厂方法<code>Create</code> <a class="spec-record-ref" data-req="SWS_RDS_10482" href="../spec/record.html?id=SWS_RDS_10482">[SWS_RDS_10482]</a>并传递负责的<code>ara::core::InstanceSpecifier</code>来进行的。<code>Create</code>被规范为线程安全，并在成功时在<code>ara::core::Result</code>中返回一个已初始化的客户端实例。</p>
<p>所有权关系是排他的：可以通过移动构造函数<a class="spec-record-ref" data-req="SWS_RDS_11305" href="../spec/record.html?id=SWS_RDS_11305">[SWS_RDS_11305]</a>和移动赋值运算符<a class="spec-record-ref" data-req="SWS_RDS_11306" href="../spec/record.html?id=SWS_RDS_11306">[SWS_RDS_11306]</a>来移动实例。这两个操作均使用<code>noexcept</code>进行声明，但不是线程安全的。</p>
<p>创建后，客户端处于断开状态。随后通过<code>Connect</code>建立活动的网络连接<a class="spec-record-ref" data-req="SWS_RDS_10484" href="../spec/record.html?id=SWS_RDS_10484">[SWS_RDS_10484]</a>，<a class="spec-record-ref" data-req="SWS_RDS_11307" href="../spec/record.html?id=SWS_RDS_11307">[SWS_RDS_11307]</a>。连接的终止通过<code>Shutdown</code> <a class="spec-record-ref" data-req="SWS_RDS_10485" href="../spec/record.html?id=SWS_RDS_10485">[SWS_RDS_10485]</a>有序进行。析构函数<code>~RawDataStreamClient</code> <a class="spec-record-ref" data-req="SWS_RDS_10483" href="../spec/record.html?id=SWS_RDS_10483">[SWS_RDS_10483]</a>确保在离开作用域时自动关闭仍然打开的连接。它被规范为非线程安全。</p>

<h4>使用路径</h4>
<p>传输二进制数据的常规流程分为创建、连接建立、有效载荷数据传输和连接断开：</p>
<ol>
  <li><strong>实例化：</strong>应用程序使用<code>Create(instance)</code> <a class="spec-record-ref" data-req="SWS_RDS_10482" href="../spec/record.html?id=SWS_RDS_10482">[SWS_RDS_10482]</a>同步创建客户端。</li>
  <li><strong>连接建立：</strong>在首次数据交换之前建立连接。为此，可以使用阻塞式变体<code>Connect()</code> <a class="spec-record-ref" data-req="SWS_RDS_10484" href="../spec/record.html?id=SWS_RDS_10484">[SWS_RDS_10484]</a>，或者带有<code>std::chrono::milliseconds</code>类型超时的限时重载<code>Connect(timeout)</code> <a class="spec-record-ref" data-req="SWS_RDS_11307" href="../spec/record.html?id=SWS_RDS_11307">[SWS_RDS_11307]</a>。</li>
  <li><strong>发送数据：</strong>写入操作通过<code>WriteData(data, maxLength)</code> <a class="spec-record-ref" data-req="SWS_RDS_10487" href="../spec/record.html?id=SWS_RDS_10487">[SWS_RDS_10487]</a>或<code>WriteData(data, maxLength, timeout)</code> <a class="spec-record-ref" data-req="SWS_RDS_11310" href="../spec/record.html?id=SWS_RDS_11310">[SWS_RDS_11310]</a>进行。有效载荷数据作为<code>std::unique_ptr&lt;ara::core::Byte[]&gt;</code>传递，从而使内存缓冲区以独占方式转入发送操作的管理之下。</li>
  <li><strong>接收数据：</strong><code>ReadData(maxLength)</code> <a class="spec-record-ref" data-req="SWS_RDS_10486" href="../spec/record.html?id=SWS_RDS_10486">[SWS_RDS_10486]</a>或带超时的变体<code>ReadData(maxLength, timeout)</code> <a class="spec-record-ref" data-req="SWS_RDS_11309" href="../spec/record.html?id=SWS_RDS_11309">[SWS_RDS_11309]</a>用于读取数据。接收成功时，将返回一个<code>ReadDataResult</code>。</li>
  <li><strong>连接断开：</strong>数据传输完成后，应用程序通过<code>Shutdown()</code> <a class="spec-record-ref" data-req="SWS_RDS_10485" href="../spec/record.html?id=SWS_RDS_10485">[SWS_RDS_10485]</a>显式关闭网络连接。</li>
</ol>

<h4>错误场景</h4>
<p><code>ara::rds::RawDataStreamClient</code>的所有功能接口均不使用 C++ 异常，而是通过带有<code>noexcept</code>保证的返回类型<code>ara::core::Result</code>来指示成功或失败：</p>
<ul>
  <li><strong>连接建立失败：</strong>如果客户端无法与对端建立连接或指定的时间限制超时，则<code>Connect</code>失败，并在<code>ara::core::Result&lt;void&gt;</code> <a class="spec-record-ref" data-req="SWS_RDS_10484" href="../spec/record.html?id=SWS_RDS_10484">[SWS_RDS_10484]</a>中返回来自错误域<code>RdsErrc</code>的错误代码。</li>
  <li><strong>读写操作错误：</strong>如果连接在传输期间中断，或者超过了 <code>WriteData</code> 或 <code>ReadData</code> 的超时时间，则对应的结果对象会包含相应的错误代码 <a class="spec-record-ref" data-req="SWS_RDS_10486" href="../spec/record.html?id=SWS_RDS_10486">[SWS_RDS_10486]</a>、<a class="spec-record-ref" data-req="SWS_RDS_10487" href="../spec/record.html?id=SWS_RDS_10487">[SWS_RDS_10487]</a>、<a class="spec-record-ref" data-req="SWS_RDS_11309" href="../spec/record.html?id=SWS_RDS_11309">[SWS_RDS_11309]</a>、<a class="spec-record-ref" data-req="SWS_RDS_11310" href="../spec/record.html?id=SWS_RDS_11310">[SWS_RDS_11310]</a>。</li>
  <li><strong>配置错误：</strong>如果传入的 <code>ara::core::InstanceSpecifier</code> 在系统模型中不存在，或者未分配给有效的通信端口，则 <code>Create</code> 便会失败，并在 <code>Result</code> 对象 <a class="spec-record-ref" data-req="SWS_RDS_10482" href="../spec/record.html?id=SWS_RDS_10482">[SWS_RDS_10482]</a> 中提供相应的错误原因。</li>
</ul>
