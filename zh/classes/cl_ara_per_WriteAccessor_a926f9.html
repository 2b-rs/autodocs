类 ara::per::WriteAccessor

[SWS_PER_00595] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class WriteAccessor final :              public virtual FileAccessor {...};

WriteAccessor is used to write file data. It provides the WriteBinary and WriteText methods featuring a Result for controlled, unformatted writing, and the operator<< method for simple formatted writing. It also provides SyncToFile() to flush the buffer of the operating system to the physical storage.

用于二进制和文本文件的缓冲写入以及与物理存储的同步。

类 ara::per::WriteAccessor 支持在持久化模块中写入二进制或文本文件内容，并提供用于未格式化写入访问的方法以及格式化流运算符 [SWS_PER_00423]。由于写入操作最初可能会在操作系统中缓冲，调用 SyncToFile() 会强制持久刷新到物理存储中 [SWS_PER_00122]。所有方法均具备异常安全性，但不是线程安全的，因此并发访问必须由应用程序进行保护。

上下文

ara::per::WriteAccessor 是 AUTOSAR Adaptive Platform 持久化模块（per）的 final 类，并虚继承自 FileAccessor。该类提供文件内容的写入操作。它提供了用于通过 ara::core::Result 进行受控未格式化写入并附带错误处理的方法，以及用于格式化写入的重载流运算符。交互对象包括调用应用程序、操作系统的内部文件缓冲区以及物理存储介质。

生命周期

销毁通过虚析构函数 ~WriteAccessor() 进行 [SWS_PER_00597]。该类及其方法被指定为异常安全（“exception safe”）并声明为 noexcept。关于并发性，WriteAccessor 不是线程安全的（“not thread-safe”）[SWS_PER_00597]；对同一实例的并行访问必须由应用程序从外部进行保护。

使用路径

常规流程包括以未格式化或格式化模式写入数据、可选地调整文件大小以及最终的持久化存储：

  • 写入二进制数据：通过 WriteBinary() 将字节区间（ara::core::Span<const ara::core::Byte>）写入文件 [SWS_PER_00423]。
  • 写入文本数据：通过 WriteText() 使用 ara::core::StringView 传递字符串 [SWS_PER_00166]。此外，operator<< 可作为非关键应用场景的便捷函数使用，发生错误时将被静默忽略 [SWS_PER_00125]。
  • 强制持久化：物理存储的时机取决于持久化实现；SyncToFile() 强制将操作系统的缓冲区刷新到存储介质上 [SWS_PER_00122]、[SWS_PER_00423]、[SWS_PER_00166]。
  • 调整文件大小：使用 SetFileSize() 可以截断文件，从而移除超出部分的内容；文件位置保持不变，或被置于最后一个有效位置或 0 [SWS_PER_00428]。

错误场景

方法 WriteBinary()、WriteText()、SyncToFile() 和 SetFileSize() 返回一个 ara::core::Result<void>，在失败时包含特定的错误码：

  • PerErrc::kPhysicalStorageFailure：访问物理存储介质失败 [SWS_PER_00423]、[SWS_PER_00166]、[SWS_PER_00122]、[SWS_PER_00428]。文件状态未知且可能被完全损坏（无回滚语义）。
  • PerErrc::kOutOfStorageSpace：物理存储空间不足 [SWS_PER_00423]、[SWS_PER_00166]、[SWS_PER_00122]。写入时超出部分将被丢弃，位置停留在文件末尾（无回滚语义）。
  • PerErrc::kQuotaExceeded：文件将超出配置的最大大小（AllowedSize）[SWS_PER_00423]、[SWS_PER_00166]、[SWS_PER_00122]（具有回滚语义）。
  • PerErrc::kEncryptionFailed：加密或解密失败 [SWS_PER_00423]、[SWS_PER_00166]、[SWS_PER_00122]、[SWS_PER_00428]。虽然缓冲区和位置会被更新，但文件无法持久化，在存储介质上反映为较旧的版本（具有回滚语义）。
  • PerErrc::kAuthenticationFailed：MAC 的计算或校验失败 [SWS_PER_00423]、[SWS_PER_00166]、[SWS_PER_00122]、[SWS_PER_00428]（具有回滚语义）。
  • PerErrc::kValidationFailed：无法保证存储数据的有效性 [SWS_PER_00423]、[SWS_PER_00166]、[SWS_PER_00428]（具有回滚语义）。
  • PerErrc::kInvalidSize：SetFileSize() 时的新文件大小大于当前文件大小 [SWS_PER_00428]（具有回滚语义）。
