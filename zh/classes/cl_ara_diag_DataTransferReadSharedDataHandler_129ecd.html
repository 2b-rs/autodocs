使用目的

DataTransferReadSharedDataHandler 通过共享数据视图实现读取数据传输到RequestReadFile 或RequestReadDirectory。 Read() 从应用程序内存中以字节范围形式返回完整的文件或目录内容，并接收 ReleaseHandler。 [SWS_DM_01497] [SWS_DM_01504]

所有权和生命周期

应用程序仍然负责分配的内存，直到ReleaseHandler发出释放信号。 ReleaseHandler将为相关MetaInfo保存并使用，直到为同一UDS客户端创建新的Handler。 Handler 无法在每个文件传输会话中复制，但可以移动，并且只能在 ExitRead() 之后销毁。 [SWS_DM_01504][SWS_DM_01501][SWS_DM_01500][SWS_DM_01502][SWS_DM_01499][SWS_DM_01505]

限制&错误处理

Read 和 ExitRead 接收 MetaInfo 及 CancellationHandler。ExitRead 结束传输，并提供用于肯定响应的数据或来自 DiagUdsNrcErrc 的错误。方法为异常安全且非线程安全。[SWS_DM_01504] [SWS_DM_01505]

Provides the whole data to be read out from the application in form of a shared data view. The whole file/directory info content to be sent back to the UDS client will be allocated by the application and its shared ownership (view over the memory location) is passed as a result to AraDiag. The allocated memory must be kept until the ReleaseHandler’s notifier is invoked or the status polled, signalling that the memory, addressed by the Span now can safely be released.
