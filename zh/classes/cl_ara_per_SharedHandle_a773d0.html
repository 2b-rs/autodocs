类 ara::per::SharedHandle

[SWS_PER_00362] Upstream: RS_PER_00002, RS_AP_00122, RS_AP_00140

template <typename T> class SharedHandle final {...};

Handle to a File Storage or Key-Value Storage. A SharedHandle is returned by the functions OpenFileStorage() and OpenKeyValueStorage() and can be passed between threads as needed. It provides the abstraction that is necessary to allow thread-safe implementation of OpenFile Storage() and OpenKeyValueStorage().

SharedHandle 传输打开的 FileStorage 或 KeyValueStorage 的共同生命周期。存储保持打开状态，直到最后一个句柄及其副本过期或平台被取消初始化。 SWS Persistency §7.3 “Key-Value Storage specific Features”SWS Persistency §7.4 “File Storage specific Features”

明智地分享

副本允许多个组件访问同一存储。这使得生命周期更加稳健，但不能取代冲突操作的协调，例如更新、Reset或Recovery。如果组件将句柄传递给线程，则它必须指定技术访问计划。
