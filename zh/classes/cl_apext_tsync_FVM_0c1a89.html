类 apext::tsync::FVM 用作模块的接口，用于为受保护的时间同步报文提供新鲜度值 [SWS_TS_14199]。在投入使用前必须初始化该实例，随后即可获取用于发送以及校验已接收报文的新鲜度值 [SWS_TS_14200]。接收时，会将截断的新鲜度值连同重试计数器一起传递，以重构用于验证身份验证器的完整值。所有接口方法均被指定为异常安全且线程安全。

上下文

类 apext::tsync::FVM 表示 AUTOSAR Adaptive Platform 的 tsync 模块内 Freshness Value Management 的接口。其主要职责是为时间同步服务 ara::tsync 提供当前新鲜度值（Freshness Values），以便对报文进行加密保护以防范重放和欺骗攻击 [SWS_TS_14198]，[SWS_TS_14199]。

TimeSync 功能充当核心交互伙伴，它调用 FVM 为传出以及接收到的受保护报文检索新鲜度值容器（apext::tsync::FVContainer）[SWS_TS_14198]，[SWS_TS_14199]。类声明通过头文件 #include "apext/tsync/fvm.h" 包含。所有指定的方法均声明为线程安全且异常安全（noexcept），因此可以从时间同步的不同执行上下文中并行进行调用 [SWS_TS_14198]，[SWS_TS_14199]，[SWS_TS_14200]。

生命周期

FVM 实例的功能生命周期分为显式初始化阶段和随后的运行阶段：

  • 初始化：在使用查询函数之前，必须调用方法 Initialize() [SWS_TS_14200]。成功完成时，它返回一个空的 ara::core::Result<void>。若初始化失败，它会返回具有回滚语义的错误码 TsyncFvmErrc::kFVInitializeFailed [SWS_TS_14200]。
  • 运行状态：成功的初始化推测是后续新鲜度值请求提供有效结果的必要前提。初始化完成后，实例保持在运行状态并响应针对已配置新鲜度值 ID 的请求。
  • 并发性：由于所有方法均标记为 thread-safe，因此对用于发送和接收的新鲜度值的访问无需外部锁定机制即可并发进行 [SWS_TS_14198]，[SWS_TS_14199]。

使用路径

TimeSync 组件的典型调用顺序包括初始化以及针对发送和接收路径持续确定新鲜度值：

  1. 服务初始化：TimeSync 在启动时执行方法 Initialize() 并检查返回的 ara::core::Result 是否无错误 [SWS_TS_14200]。
  2. 发送受保护报文：在发送报文之前，TimeSync 使用相应的 FreshnessValueID 调用 GetTxFreshness() [SWS_TS_14199]。获取到的 FVContainer 对象提供用于计算身份验证器的新鲜度值 [SWS_TS_14199]。
  3. 接收受保护报文：接收到报文时，TimeSync 调用 GetRxFreshness() 并传递 FreshnessValueID、报文中包含的截断值 TruncatedFreshnessValue 以及先前的身份验证尝试次数 AuthVerifyAttempts [SWS_TS_14198]。FVM 由此确定用于校验身份验证器的完整新鲜度值 [SWS_TS_14198]。

时序图：TimeSync 初始化及检索发送和接收新鲜度值的典型流程。来源：[SWS_TS_14198]，[SWS_TS_14199]，[SWS_TS_14200]

错误场景

所有接口方法均通过 ara::core::Result 发送错误信号并指定了 noexcept [SWS_TS_14198]，[SWS_TS_14199]，[SWS_TS_14200]。以下错误状态和前提条件相关：

  • 初始化失败（TsyncFvmErrc::kFVInitializeFailed）：当 FVM 无法初始化时发生 [SWS_TS_14200]。得益于回滚语义，系统保持在未初始化的确定初始状态。
  • 新鲜度值不可用（TsyncFvmErrc::kFVNotAvailable）：当请求的 ID 没有可用新鲜度值时，由 GetTxFreshness() 或 GetRxFreshness() 返回 [SWS_TS_14198]，[SWS_TS_14199]。发生错误时，操作不会更改其状态（回滚语义）。
  • 接收时的重复校验尝试：参数 AuthVerifyAttempts 从 0 开始，并在每次身份验证尝试失败时递增 [SWS_TS_14198]。该递增推测用于 FVM 逐步调整内部接受窗口，以容忍轻微时间偏移的新鲜度值。
