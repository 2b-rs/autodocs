类 ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

通用光标界面

FileAccessor 捆绑打开文件的位置和大小操作。它是读、写和读/写访问器的共同基础；这意味着光标位置准确描述了对此打开文件的访问。

岗位纪律

GetPosition、SetPosition和MovePosition用于导航，而GetSize提供当前文件大小。访问器操作不是线程安全的：因此，在没有外部同步的情况下，句柄不应被多个线程同时使用。 SWS Persistency §7.4 “File Storage specific Features”

使用说明

通过FileStorage打开文件，在UniqueHandle的占有下执行游标操作，然后释放它。立场的改变不是一个坚持的过程；而是一个过程。写入数据需要适当的写入操作，如有必要，还需要同步。

一个File Storage管理着很多命名文件； Accessor 对特定开放的访问权限具有独占访问权限。来源：SWS Persistency §7.4 “File Storage specific Features”[SWS_PER_00113]。
