上下文

模板特化 ara::core::Result<T&, E> 要么封装对类型为 value_type（[SWS_CORE_00902]）的操作成功结果的引用，要么封装类型为 error_type（[SWS_CORE_00903]）的错误值。作为模块 core 中的标准化返回结构，它实现了容错编程，而无需在常规流程中强制使用 C++ 异常。根据规范，实现会在编译时强制要求错误类型 E 对应于类型 ara::core::ErrorCode；偏离的配置会导致编译错误。交互伙伴包括提供数据服务、用于结果检查的调用组件，以及通过绑定引用直接访问的外部管理目标对象。

生命周期

实例被确定性地初始化为对现有左值的引用或错误。使用引用进行初始化通过构造函数 [SWS_CORE_00908] 或静态工厂方法 FromValue [SWS_CORE_00904] 进行；禁止传递右值。错误状态通过构造函数（[SWS_CORE_00909]、[SWS_CORE_00910]）或诸如 FromError（[SWS_CORE_00905]、[SWS_CORE_00906]、[SWS_CORE_00907]）等工厂创建。不存在默认构造函数。复制和移动构造函数（[SWS_CORE_00911]、[SWS_CORE_00912]）接管另一个实例的当前状态。

关于所有权关系，Result<T&, E> 仅绑定引用，不承担所引用目标对象的所有权或生命周期管理。因此，调用方大概必须确保目标对象在 Result 实例的整个存在期内保持有效。 问题 (未决)运行中的状态切换通过赋值运算符（[SWS_CORE_00914]、[SWS_CORE_00915]）执行，它们将内部引用重新绑定到新目标或传递错误。此外，EmplaceError [SWS_CORE_00916] 直接将实例置于错误状态，而 Swap [SWS_CORE_00917] 交换两个实例的内容。如果 E 是平凡可析构的，则析构函数 [SWS_CORE_00913] 表现为平凡析构。对值或错误的并行读取访问是线程安全的，而诸如赋值、Swap 或 EmplaceError 等改变状态的操作不是线程安全的。

使用路径

常规流程包括状态控制以及针对性的评估：

  • 状态检查：在访问之前，调用方通过 HasValue() [SWS_CORE_00918] 或转换运算符 operator bool [SWS_CORE_00919] 检查是否存在值。
  • 直接访问：在成功情况下，Value()（[SWS_CORE_00924]、[SWS_CORE_00925]）、operator*（[SWS_CORE_00920]、[SWS_CORE_00921]）和 operator->（[SWS_CORE_00922]、[SWS_CORE_00923]）提供引用或指向目标对象的指针。
  • 可选与基于回退的访问：通过 Ok()（[SWS_CORE_00926]、[SWS_CORE_00927]）可以将引用转换为 ara::core::Optional。方法 ValueOr()（[SWS_CORE_00933]、[SWS_CORE_00934]）提供所引用值的副本或传入的替代值。
  • Monadic 操作：使用 Bind() [SWS_CORE_00941] 将转换函数应用于引用并包装结果，同时错误会被自动转发。Resolve()（[SWS_CORE_00939]、[SWS_CORE_00940]）在发生错误时调用提供兼容引用的替代函数。

错误场景

如果实例处于错误状态，Error()（[SWS_CORE_00928]、[SWS_CORE_00929]、[SWS_CORE_00930]）的重载授予对错误对象的访问权限。此外，错误可通过 Err()（[SWS_CORE_00931]、[SWS_CORE_00932]）作为 Optional<E> 获取，或通过 ErrorOr()（[SWS_CORE_00935]、[SWS_CORE_00936]）带有回退值获取。对于特定的错误比对，CheckError() [SWS_CORE_00937] 将所包含的错误与参考错误进行比较。

使用

成员函数 const T * operator-> () const noexcept 允许对 ara::core::Result<T &, E> 对象的被引用值进行同步读取访问 [SWS_CORE_00922]。它不接受任何实参，并返回指向被引用的目标对象的常量指针（const T *）作为返回值 [SWS_CORE_00922]。使用时需包含头文件 #include "ara/core/result.h" [SWS_CORE_00922]。

错误处理

该操作被声明为 noexcept，并具备 exception safe 特性 [SWS_CORE_00922]。如果对象不包含值，则属于前置条件违规（Violation）ResultWithNoValue [SWS_CORE_00922]。因此，调用者必须在解引用之前确保该实例确实持有一个有效值。

并发性与限制

该函数被指定为 thread-safe [SWS_CORE_00922]。由于它是一个常量成员函数，因此对同一实例的并发读取访问是安全的。然而，对目标对象本身的访问受制于类型 T 的线程安全保证。

相互作用

该运算符构成了非常量重载 T * operator-> () noexcept 的常量对应项 [SWS_CORE_00923]。非常量变体返回一个可修改的指针 T* [SWS_CORE_00923]，而该版本则强制对被引用的实例进行不可变访问。
