管理具有 RAII 语义的文件访问器对象的独占式、可移动访问。

类模板 ara::per::UniqueHandle 在严格的仅移动语义框架下管理 AUTOSAR 持久性文件访问器对象的独占所有权。在通过文件访问函数获取后，实例在任何使用前必须强制通过 operator bool() 检查有效性 [SWS_PER_00371]。在空句柄或已转移句柄上调用其他运算符会导致未定义行为 [SWS_PER_00399]。所有操作均声明为 noexcept，其中读取访问是线程安全的，而修改操作则不是。

上下文

类模板 ara::per::UniqueHandle 用作 AUTOSAR Adaptive 持久性资源对象（即 ReadAccessor 或 ReadWriteAccessor）的类型安全访问句柄。它作为函数 OpenFileReadOnly()、OpenFileWriteOnly() 以及 OpenFileReadWrite() 的返回值提供，并封装已打开的文件访问接口的独占所有权。

生命周期

该类实现了严格的仅移动语义（Unique Ownership）。为了防止意外复制访问或共享所有权，复制构造函数 [SWS_PER_00373] 和复制赋值运算符 [SWS_PER_00374] 均定义为已删除（delete）。所有权只能通过移动来转移：调用移动构造函数 [SWS_PER_00371] 或移动赋值 [SWS_PER_00372] 时，传入的源对象将失效，此后不得再使用。

UniqueHandle 在任何时刻都处于有效状态（它表示参数化类的有效对象）或处于空或失效状态（例如在移动转移后出现的状态）[SWS_PER_00399]。在作用域结束时，析构函数 [SWS_PER_00569] 将被执行。推测有效句柄的销毁会自动关闭或清理封装的访问资源。

状态图：UniqueHandle 在有效状态与空状态之间的生命周期和状态转换。来源：[SWS_PER_00371]、[SWS_PER_00372]、[SWS_PER_00399]、[SWS_PER_00569]

使用路径

UniqueHandle 的典型用法遵循固定的步骤顺序：

  1. 接收句柄：应用程序接收句柄作为文件访问调用（如 OpenFileReadOnly()、OpenFileWriteOnly() 或 OpenFileReadWrite()）的结果。
  2. 状态检查：在进行任何进一步操作之前，必须强制通过 operator bool() 验证实例的状态 [SWS_PER_00371]、[SWS_PER_00372]。如果存在有效对象，该运算符返回 true；如果句柄为空，则返回 false [SWS_PER_00399]。
  3. 访问封装对象：在状态有效时，通过箭头运算符 operator->（非常量 [SWS_PER_00360] 或常量 [SWS_PER_00361]）或通过使用 operator* 的解引用（非常量 [SWS_PER_00400] 或常量 [SWS_PER_00401]）访问目标的方法和数据。
  4. 所有权转移或销毁：句柄可以根据需要通过 std::move 转移到另一个组件 [SWS_PER_00371]，或者在生命周期结束时自动销毁 [SWS_PER_00569]。

错误场景

一个核心错误场景是对空句柄或已转移句柄的访问：根据规范，在空句柄上使用除 operator bool() 以外的运算符会导致未定义行为（Undefined Behavior）[SWS_PER_00399]。因此，在任何解引用之前必须强制进行检查 [SWS_PER_00371]、[SWS_PER_00372]。

关于异常安全性和并发性，适用以下规范细节：

  • 异常安全性：所有方法和运算符均带有 noexcept，并被指定为异常安全（exception safe）（[SWS_PER_00371]、[SWS_PER_00372]、[SWS_PER_00399]、[SWS_PER_00400]、[SWS_PER_00401]、[SWS_PER_00360]、[SWS_PER_00361]、[SWS_PER_00569]）。
  • 线程安全性：读取运算符 operator* [SWS_PER_00400]、[SWS_PER_00401]、operator-> [SWS_PER_00360]、[SWS_PER_00361] 以及 operator bool() [SWS_PER_00399] 是线程安全的（thread-safe）。相反，诸如移动赋值 [SWS_PER_00372] 和通过析构函数 [SWS_PER_00569] 销毁等修改性操作显式地不是线程安全的，在并发访问时需要外部同步。
