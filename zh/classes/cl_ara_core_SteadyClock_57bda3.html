类 ara::core::SteadyClock

[SWS_CORE_06401] Upstream: RS_AP_00130

class SteadyClock final {...};

This clock represents a monotonic clock. The time points of this clock cannot decrease as physical time moves forward and the time between ticks of this clock is constant.

ara::core::SteadyClock代表单调时钟：它的时间点不会随着物理时间的推进而减少，并且滴答持续时间是恒定的[SWS_CORE_06401]。满足TrivialClock的要求；他们的纪元是系统启动[SWS_CORE_11800][SWS_CORE_11801]。

时间值使用std::int64_t作为表示，std::nano作为周期，std::chrono::time_point<SteadyClock, duration>作为时间点[SWS_CORE_06412][SWS_CORE_06413][SWS_CORE_06414]。 is_steady 始终是true； now()是noexcept，异常安全和线程安全[SWS_CORE_06431][SWS_CORE_06432]。
