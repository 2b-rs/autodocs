类 ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

支持按块、按行或基于字符读取持久化的文件和二进制数据。

类 ara::per::ReadAccessor 提供了用于在二进制和文本模式下顺序和按行读取文件的同步方法 [SWS_PER_00421]、[SWS_PER_00119]。除了消耗性读取外，它还允许对后续字节或字符进行指针中立的前瞻。由于实例不是线程安全的，因此必须在外部协调并发访问，而在发生错误时，回滚保证可以保护读指针位置 [SWS_PER_00419]。

上下文和职责范围

类 ara::per::ReadAccessor 提供了持久化管理（模块 per）中用于同步读取文件内容的接口，并虚继承自 FileAccessor。它抽象了对持久化数据存储的读取访问，并提供二进制和文本访问方法。应用程序可以通过专用函数检查和检索单个字节或字符，以及读取连续块或完整行。

生命周期和并发

ReadAccessor 的默认构造函数已删除 [SWS_PER_00461]；因此，实例化通常通过持久化模块的上层打开和访问机制间接进行。接口和绑定的访问资源的释放通过虚析构函数 ~ReadAccessor() 执行 [SWS_PER_00417]。ReadAccessor 的实例拥有一个管理文件中当前位置的内部读指针。该类的所有方法都被显式指定为非线程安全（not thread-safe）[SWS_PER_00419]，因此调用方必须在外部同步同一实例上的并发读取操作。

二进制和文本数据的使用路径

对于二进制文件操作，该类提供了用于可前瞻或顺序读取的函数。使用 PeekByte() 可以在不改变读指针的情况下检查当前读取位置处的字节 [SWS_PER_00418]。相比之下，GetByte() 精确读取一个字节并推进位置 [SWS_PER_00419]。可以通过 ReadBinary(n) 将较大的数据块读取到 ara::core::Vector<ara::core::Byte> 中，此时位置会相应调整；如果提前到达文件末尾，则向量包含的字节数将少于请求的字节数 [SWS_PER_00422]。通过 ReadBinary() 可以一步获取直至文件末尾的所有剩余字节 [SWS_PER_00421]。

时序图：带有预先检查和分段数据处理的顺序读取访问典型流程。来源：[SWS_PER_00418]、[SWS_PER_00422]、[SWS_PER_00421]。

在文本模式下，PeekChar() 提供基于字符的前瞻 [SWS_PER_00167]，而 GetChar() 消耗下一个字符 [SWS_PER_00168]。按行读取通过 ReadLine() 进行，它会一直读取到分隔符为止（默认：'\n'，ASCII 0x0a）；分隔符不会被包含在结果字符串中 [SWS_PER_00119]。长度为 n 个字符的片段或全部剩余内容可以通过 ReadText() 的重载来读取 [SWS_PER_00165]、[SWS_PER_00420]。如果读指针位于多字节字符的中间，则生成的字符串可能包含不完整的 Unicode 码点 [SWS_PER_00119]、[SWS_PER_00165]。

错误场景与错误处理

ReadAccessor 的所有读取操作都将其值封装在 ara::core::Result 中返回，并被指定为异常安全（exception safe）[SWS_PER_00419]。如果访问期间发生错误，则会应用严格的回滚语义：在发生错误时，读指针的当前位置始终保持不变 [SWS_PER_00421]、[SWS_PER_00422]。典型的已记录错误状态包括：

  • 物理存储介质出错时的 PerErrc::kPhysicalStorageFailure [SWS_PER_00419]、[SWS_PER_00420]，
  • 读指针位于文件末尾或文件为空时的 PerErrc::kEof [SWS_PER_00419]、[SWS_PER_00168]，
  • 无法验证数据有效性时的 PerErrc::kValidationFailed [SWS_PER_00418]、[SWS_PER_00119]，
  • 解密失败时的 PerErrc::kEncryptionFailed [SWS_PER_00419]、[SWS_PER_00422]，以及
  • 存储数据的 MAC 验证失败时的 PerErrc::kAuthenticationFailed [SWS_PER_00167]、[SWS_PER_00421]。

Reads a complete line of characters into a String, advancing the current position accordingly. The end of the line is demarcated by the delimiter, or by "\\n" (ASCII 0x0a) if that parameter is omitted. The delimiter itself is not included in the returned String. Only Unicode code points with one character (code unit) can be used as delimiters. The returned string may start with an incomplete Unicode code point in case the current read position is in the middle of a code point. If the end of the file is reached, the remaining characters are returned and the current position is set to the end of the file. In case of an error, the current position is not changed.

              类 ara::per::ReadAccessor（头文件 #include "ara/per/read_accessor.h"）的方法 PeekChar 读取文件当前位置处的字符，而不改变读取指针 [SWS_PER_00167]。
              

              使用
              

              该函数的签名是 ara::core::Result<char> PeekChar() const noexcept;。它以同步方式工作，声明为 const 并保证异常安全性（exception safe）[SWS_PER_00167]。返回值是一个 ara::core::Result<char>，在成功时包含读取出的字符 [SWS_PER_00167]。
              

              错误处理
              

              如果发生错误，ara::core::Result 将返回厂商特定错误或来自 PerErrc 的以下错误码之一 [SWS_PER_00167]：
              

                

              • PerErrc::kEof：当前读取位置已达到文件末尾，或者文件为空 [SWS_PER_00167]。
                • 

              • PerErrc::kPhysicalStorageFailure：对物理存储介质的访问失败 [SWS_PER_00167]。
                • 

              • PerErrc::kValidationFailed：无法确保已存储数据的有效性 [SWS_PER_00167]。
                • 

              • PerErrc::kEncryptionFailed：所存储数据的解密失败 [SWS_PER_00167]。
                • 

              • PerErrc::kAuthenticationFailed：数据的消息身份验证码（MAC）验证失败 [SWS_PER_00167]。
                • 

              

              并发性与限制
              

              该操作不是线程安全的（not thread-safe）[SWS_PER_00167]。因此，对同一 ReadAccessor 实例的并发访问必须由调用方进行同步。
