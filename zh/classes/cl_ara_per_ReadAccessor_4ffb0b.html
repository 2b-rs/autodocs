类 ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

读取一个打开的文件

ReadAccessor 是对FileStorage 的文件的独占读取访问权限。文件用OpenFileReadOnly打开；然后，字符、文本和二进制运算允许制定适合内容的阅读策略。 SWS Persistency §7.4 “File Storage specific Features”

光标和EOF

Peek… 向前看而不更新位置； Get… 读取并移动它们。 ReadLine、ReadText 和 ReadBinary 的传输形式不同。检查 IsEof 和 Result 并且不要仅依赖于预期长度。

并发性

访问器方法不是线程安全的。因此，将访问和位置管理保持在受控所有权上下文内，或在外部保护相同的句柄。

一个File Storage管理着很多命名文件； Accessor 对特定开放的访问权限具有独占访问权限。来源：SWS Persistency §7.4 “File Storage specific Features”[SWS_PER_00113]。

ara::core::Result< ara::core::String > ReadLine (char delimiter=’\n’) noexcept;

Reads a complete line of characters into a String, advancing the current position accordingly. The end of the line is demarcated by the delimiter, or by "\\n" (ASCII 0x0a) if that parameter is omitted. The delimiter itself is not included in the returned String. Only Unicode code points with one character (code unit) can be used as delimiters. The returned string may start with an incomplete Unicode code point in case the current read position is in the middle of a code point. If the end of the file is reached, the remaining characters are returned and the current position is set to the end of the file. In case of an error, the current position is not changed.
