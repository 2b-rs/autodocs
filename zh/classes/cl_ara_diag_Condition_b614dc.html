从技术状态到诊断批准

Condition 是一个配置的报告点，应用程序使用它来将其当前条件状态传递给DM。 DM 特别使用条件作为监控处理的 EnableConditions 以及 ClearConditions SWS Diagnostics §7.3.4.1.4 “EnableConditions” SWS Diagnostics §7.3.4.4.5 “Clearing DTCs” 的上下文。因此，它不是通用布尔存储器，而是诊断相关配置路径的一部分。

条件提供了 DM 消耗的发布状态，用于监视和清除处理。来源：SWS Diagnostics §7.3.4.1.4 “EnableConditions”、SWS Diagnostics §7.3.4.2 “Condition Management”、SWS Diagnostics §7.3.4.4.5 “Clearing DTCs”。 部分解释：该图形比较了条件信号的两个指定消耗点。

设置无局部副作用

SetCondition 报告新的 ConditionType 值 [SWS_DM_00715]。该方法应该在技术状态实际发生变化时调用，而不是作为轮询的替代。监视器或 DTC 清除的顺序决定了 DM 配置；应用程序不得推断 DTC 状态立即发生变化。

发布时可用

状态消息是 API 调用的一部分，DM 会在必要时进行缓冲，并在可用时进行处理。这允许应用程序尽早报告其初始状态；它仍然需要保持状态一致SWS Diagnostics §7.3.1 “Interaction between DM and applications”。
