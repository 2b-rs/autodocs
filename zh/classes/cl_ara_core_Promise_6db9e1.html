使用目的

ara::core::Promise<T, E> 是std::promise 的AUTOSAR 变体。错误类型必须是ara::core::ErrorCode。与Future一起，该类可以异步且线程安全地提供值和错误，而无需异常处理。 [SWS_CORE_00340][SWS_CORE_10800]

生命周期和所有权

禁止复制（=delete），可以移动。移动赋值和析构函数放弃任何现有的 Shared State。 [SWS_CORE_00350] [SWS_CORE_00351] [SWS_CORE_00342] [SWS_CORE_00343] [SWS_CORE_00349]

与其他班级的互动

get_future() 返回具有相同 Shared State 的关联 Future<T,E>；每个 Promise 仅允许调用一次。set_value()、SetError() 和 SetResult() 使 Shared State 就绪。[SWS_CORE_00344] [SWS_CORE_00345] [SWS_CORE_00346] [SWS_CORE_00353] [SWS_CORE_00354] [SWS_CORE_00355] [SWS_CORE_00356]

限制&错误处理

重复设置值、错误或结果以及没有共享状态的 setter 调用将被指定为违规。 [SWS_CORE_13015] [SWS_CORE_13016]

提供异步结果

在骨架方面，Promise可以提供已经计算出的值，或者可以推送到异步工作线程中；相应的Future返回给调用者。 EXP ARAComAPI §5.4.6 “Methods”

如果识别到Application Error，则将对应的ErrorCode放入Promise；然后，客户端可以使用 Future 路径将其处理为 Result。 EXP ARAComAPI §4.7 “Error Handling”EXP ARAComAPI §5.4.6 “Methods”

序列图：异步方法的可重用Promise/Future流程。来源：EXP ARAComAPI §4.4 “Method based communication”EXP ARAComAPI §5.4.6 “Methods”。

共同国家条约

Promise 完成了 Future 中观察到的公共状态。相关框架是 Core 中定义的异步值或错误结果的 Future/Promise 概念。 SWS Core §7.2 “Error handling” SWS Core §7.2.5.5 “Future and Promise”

发生错误时的行为

Promise 只能以值、错误或 Result 一次性使其 Shared State 就绪。如果已存储值或错误，后续调用 set_value()、SetError() 或 SetResult() 被规定为 promise_already_satisfied-Violation。没有 Shared State 的 setter 属于独立的 Violation。[SWS_CORE_00345] [SWS_CORE_00346] [SWS_CORE_00353] [SWS_CORE_00354] [SWS_CORE_00355] [SWS_CORE_00356] [SWS_CORE_13015] [SWS_CORE_13016]

每Shared State只能调用一次get_future()。第二次调用被设置为future_already_retrieved违规；如果缺少 Shared State，则适用no_state 违规。这些情况不是通过API合约中的Result报告的应用程序错误。 [SWS_CORE_00344][SWS_CORE_13013][SWS_CORE_13014]

析构函数和移动分配放弃现有的Shared State。如果已经输出Future页面然后等待结果，则其GetResult()返回错误FutureErrc::kBrokenPromise； get() 在例外情况下处理相同的情况。包括设置错误和超时的完整过程如Fehlerpfad-Diagramm von Future所示。 [SWS_CORE_00343][SWS_CORE_00349][SWS_CORE_00336][SWS_CORE_00326]
