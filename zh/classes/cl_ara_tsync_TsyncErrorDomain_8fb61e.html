上下文

类ara::tsync::TsyncErrorDomain为 AUTOSAR Adaptive Platform 内的时间同步（模块tsync）定义了特定的错误域。作为基类ara::core::ErrorDomain的 final 特化，它构成了该模块标准化错误处理模型的基础设施底座。其功能职责包括错误域的唯一标识、将数值错误代码映射到可读的描述文本，以及将错误值转换为类型化的 C++ 异常。

为了进行语义类型化和解耦，该类提供了两个类型定义别名。通过类型别名Errc[SWS_TS_01266]，该域绑定了枚举TsyncErrc，该枚举定义了时间同步的所有特定错误原因。类型别名Exception[SWS_TS_01267]指向异常类TsyncException，该异常类作为发生错误时异常处理的基础类型。

该类的主要交互伙伴包括：

  • ara::core::ErrorDomain：AUTOSAR 核心的上级基类，规定了特定领域错误映射的接口。
  • ara::core::ErrorCode：封装具体错误编号，并指向负责的错误域以进行解释。
  • TsyncErrc：特定于域的错误代码枚举，可通过类型内部别名 Errc [SWS_TS_01266] 访问。
  • TsyncException：表示相应的异常类，可通过别名 Exception [SWS_TS_01267] 访问。

生命周期

实例对象的创建通过无参默认构造函数 TsyncErrorDomain() [SWS_TS_00905] 进行。该构造函数声明为 noexcept 且完全异常安全（exception safe）。

Interpretation: 由于该类作为 AUTOSAR 错误域的最终形式既不包含内部可变状态也不分配动态资源，通常可以作为长生命周期实例保留，存在于应用程序或 tsync 服务的整个生命周期中。

在并发性方面，该类的所有操作均被指定为线程安全（thread-safe）。这既涉及构造 [SWS_TS_00905]，也涉及名称查询 [SWS_TS_00906]、消息转换 [SWS_TS_00907] 和抛出异常 [SWS_TS_00908]。因此，错误域的实例可以安全地从多个线程并行使用，无需额外的同步措施。

使用路径

与 TsyncErrorDomain 的主要交互发生在评估或转换时间同步过程中出现的错误时。典型的使用流程分为以下步骤：

  1. 域标识：通过调用 Name() [SWS_TS_00906] 查询唯一标识该域的字符串常量。返回值大概反映了时间同步的固定标识符。该查询声明为 noexcept 且完全 exception-safe。
  2. 获取错误文本：如果存在错误号，成员函数 Message(errorCode) [SWS_TS_00907] 会将关联的错误文本作为指向常量字符串的指针（const char*）返回。这主要用于诊断输出、日志记录和错误分析。该调用是线程安全的，且保证不会引发异常。
  3. 转换为异常：如果调用应用程序的错误处理策略需要基于异常的控制流，则会使用成员函数 ThrowAsException(errorCode) [SWS_TS_00908]。它根据传入的 ara::core::ErrorCode 实例化相应的 TsyncException 对象，并将其作为 C++ 异常直接抛出。

错误场景

错误状态的定义通过枚举 TsyncErrc 进行，可以通过别名 ara::tsync::TsyncErrorDomain::Errc [SWS_TS_01266] 访问该枚举。这些枚举值映射了该域的离散错误代码。

异常处理与工具链配置的配合需要特别注意：

  • 异常生成：成员函数 ThrowAsException() 带有 noexcept(false) 注解，并被归类为非异常安全（not exception safe），因为其确定性行为就是引发 C++ 异常 [SWS_TS_00908]。抛出的始终是 TsyncException 或 Exception [SWS_TS_01267] 的实例。
  • 禁用的 C++ 异常：对于通过编译器工具链禁用了异常的环境，根据规范 ThrowAsException() 不参与重载解析 [SWS_TS_00908]。在这些配置中调用此函数会导致编译期错误，从而及早防止意外的异常调用。
  • 稳健的错误分析：由于函数 Name() [SWS_TS_00906] 和 Message() [SWS_TS_00907] 声明为 noexcept 且保证异常安全工作，因此确保了即使在异常状态下也能稳定、无副作用地执行错误日志记录和评估。

<p>类<code>ara::tsync::TsyncErrorDomain</code>为 AUTOSAR Adaptive Platform 内的时间同步（模块<code>tsync</code>）定义了特定的错误域。作为基类<code>ara::core::ErrorDomain</code>的 final 特化，它构成了该模块标准化错误处理模型的基础设施底座。其功能职责包括错误域的唯一标识、将数值错误代码映射到可读的描述文本，以及将错误值转换为类型化的 C++ 异常。</p>
<p>为了进行语义类型化和解耦，该类提供了两个类型定义别名。通过类型别名<code>Errc</code><a class="spec-record-ref" data-req="SWS_TS_01266" href="../spec/record.html?id=SWS_TS_01266">[SWS_TS_01266]</a>，该域绑定了枚举<code>TsyncErrc</code>，该枚举定义了时间同步的所有特定错误原因。类型别名<code>Exception</code><a class="spec-record-ref" data-req="SWS_TS_01267" href="../spec/record.html?id=SWS_TS_01267">[SWS_TS_01267]</a>指向异常类<code>TsyncException</code>，该异常类作为发生错误时异常处理的基础类型。</p>
