在报告的流程生命周期中的角色

ExecutionClient 是 Reporting Process 的进程端接口。报告的 kRunning 使 Execution Management 将进程状态置为 Running；Execution State 与内部维护的 Process State 仍是独立模型 SWS EM §7.3.1 “Execution State” SWS EM §7.3.2 “Process States”。

确定性启动和调度

报告进程在完成初始化后和潜在的非确定性服务发现阶段之前报告 kRunning。这允许配置的依赖关系解析为弹性进程状态。根据调度请求，执行管理会触发 SIGTERM； Create 中存储的处理程序由 ExecutionClient [SWS_EM_02562] [SWS_EM_02003] [SWS_EM_02577] 调用。

责任限制

客户端只报告自己的状态；执行管理负责启动、停止和操作系统配置，但不负责进程的持续调度，这取决于操作系统[SWS_EM_01401] SWS Operating System Interface §7.1.2 “Process Handling” SWS Operating System Interface §7.1.3 “Scheduling Policies”。
