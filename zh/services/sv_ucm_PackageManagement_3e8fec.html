用于在 UCM 中传输、处理、激活和监视软件分发包及软件集群。

ServiceInterface PackageManagement 控制 AUTOSAR Adaptive Platform 上的软件分发包的传输、处理和激活 [SWS_UCM_00345]、[SWS_UCM_00352]。它支持分包的分块加载、软件集群的提取以及与 State Management 协调下的受控激活 [SWS_UCM_00346]、[SWS_UCM_00352]。此外，该服务还提供用于状态监视以及回滚和清理会话数据的机制 [SWS_UCM_00353]、[SWS_UCM_00361]。

1. 服务接口的角色和系统上下文

ServiceInterface PackageManagement 构成了 Update and Configuration Management (UCM) 在 AUTOSAR Adaptive Platform 上管理、传输和安装软件分发包的核心接口 [SWS_UCM_00343]。在此，UCM 实例通常充当服务提供方（Skeleton），而上级更新协调器或诊断客户端则充当服务消费方（Proxy）。为了进行标识，服务通过方法 GetId 提供唯一的模块实例标识符 [SWS_UCM_00343]。在激活过程中，UCM 与 State Management 密切交互，后者必须释放更新会话并执行验证 [SWS_UCM_00352]。

2. 方法、事件和字段

由于对所有方法均规范了 Fire & Forget false [SWS_UCM_00345]，服务接口中定义的所有方法都采用同步调用语义或请求-响应消息。状态字段 CurrentStatus 拥有 Getter 以及 Notifier，从而允许客户端通过事件驱动订阅或主动查询 UCM 的状态更改 [SWS_UCM_00361]。此外，GetProgress 针对状态机的各个活动状态提供详细的进度信息 [SWS_UCM_00360]。对于软件清单查询，可使用 GetSwPackages 列出可用的软件分发包 [SWS_UCM_00359]，使用 GetSwClusterInfo 查询处于状态 kPresent [SWS_UCM_00357] 的已安装软件集群，使用 GetSwClusterManifestInfo 查询集群清单数据 [SWS_UCM_00358]，以及使用 GetSwClusterChangeInfo 查询处于状态 kAdded、kUpdating 或 kRemoved [SWS_UCM_00356] 的待处理变更。已执行操作的历史可追溯性通过带有时间戳过滤器的 GetHistory 提供 [SWS_UCM_00355]。

3. 生命周期、会话流程与状态依赖性

典型的更新流程分为传输、处理、激活和完成。分包传输既可以通过 TransferStart 启动——从而创建 TransferIdType 并协商块大小 [SWS_UCM_00345]，也可以通过 RegisterSoftwarePackage 指定分包 URI 进行注册 [SWS_UCM_00344]。在分块传输时，数据块通过 TransferData 指定块计数器进行连续持久化 [SWS_UCM_00346]，并通过 TransferExit 完成 [SWS_UCM_00347]。随后，ProcessSwPackage 提取软件分发包 [SWS_UCM_00349]。正在进行的处理可以使用 Cancel 取消 [SWS_UCM_00351]，或者使用 Suspend 和 Resume 中断或恢复 [SWS_UCM_00397]、[SWS_UCM_00398]。不再需要的传输可以使用 DeleteTransfer 移除 [SWS_UCM_00348]。使用 Activate 激活已提取的软件集群 [SWS_UCM_00352]，而 Finish 结束处理会话并清理临时数据 [SWS_UCM_00354]。如果发生错误，RevertProcessedSwPackages 允许重置已处理的分包 [SWS_UCM_00350]，并且 Rollback 允许恢复分包处理之前的系统状态 [SWS_UCM_00353]。

4. 错误处理与 Application Errors

接口方法通过特定的 Application Errors 防范错误条件。在违背上下文调用时，诸如 Activate、Cancel、Finish、ProcessSwPackage、TransferData 和 TransferExit 等方法将返回错误 kOperationNotPermitted [SWS_UCM_00346]、[SWS_UCM_00347]、[SWS_UCM_00349]、[SWS_UCM_00352]。无效的传输 ID 会被 kTransferIdInvalid 拒绝 [SWS_UCM_00346]、[SWS_UCM_00348]，而错误的块序列或存储瓶颈会导致 kBlockIncorrect、kBlockSizeIncorrect、kBlockInconsistent 或 kMemoryInsufficient [SWS_UCM_00345]、[SWS_UCM_00346]。安全和一致性检查会引发诸如 kAuthenticationFailed、kPackageInconsistent、kPackageManifestInvalid 以及 kPackageVersionIncompatible [SWS_UCM_00346]、[SWS_UCM_00349] 等错误。移除核心系统会被 kSwclRemovalDenied 阻止 [SWS_UCM_00349]。激活时，kDependencyMissing、kUpdateSessionRejected 或 kVerificationFailed 指示与依赖项或 State Management 的集成问题 [SWS_UCM_00352]。
