命名空间边界

ara::idsm 包含事件、提供者和接收者 API 及其公共数据和错误类型。 SWS IdsM §8.2 “common.h” 定义常用类型；他们将其他标头分配给相应的端口接口。

解释：命名空间捆绑了事件、提供者和接收者访问对象，包括数据类型和错误表示；它们与端口原型的具体耦合是通过模型和 ara::core::InstanceSpecifier 确定的。

类与结构体

  • ContextDataProvider 为 IdsM 提供可修改的上下文数据。
  • EventReporter Meldet Security Events an IdsM.
  • IdsmErrorDomain ara::idsm 的错误域。
  • IdsmException ara::idsm 的异常类型。
  • QualifiedEventsReceiver 接收合格事件。
  • ReportingModeProvider 读取并设置 Reporting Modes。
  • TimestampProvider Stellt optionale Zeitstempel bereit.
