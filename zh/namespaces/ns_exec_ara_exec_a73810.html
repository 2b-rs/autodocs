控制进程生命周期，监控执行状态，并协调功能组的状态转换。

该命名空间为 AUTOSAR Adaptive Platform 上的进程管理和功能组控制提供接口。进程使用客户端在成功初始化后向 Execution Management 报告其执行状态 kRunning [SWS_EM_02000]。State Management 通过接口请求功能组的转换，而无效的状态切换或通信错误则通过标准化的错误代码进行记录 [SWS_EM_02281]。严格遵守转换顺序是强制性的。

上下文

命名空间 ara::exec 提供了 AUTOSAR Adaptive Platform 上 Execution Management 的接口。该模块负责启动、控制和监控进程，以及协调上层系统和功能组状态。主要参与者包括应用程序进程、State Management 和 Execution Management 本身。进程使用类 ExecutionClient 向 Execution Management 报告其内部运行时状态。State Management 反过来使用接口 StateClient 请求功能组之间的状态切换（FunctionGroup 和 FunctionGroupState）。对于功能组级别的错误事件，使用可通过 ExecutionErrorEvent 传输的类型别名 ExecutionError [SWS_EM_02541]。

生命周期

进程的执行生命周期由 Execution Management 控制 [SWS_EM_02000]。在调度之后，新启动的进程最初处于隐式状态 Initializing，在此状态下尚未执行任何应用程序代码。Execution Management 假定此初始化状态一直持续，直到进程通过其 ExecutionClient 主动报告状态 ExecutionState::kRunning [SWS_EM_02000]。枚举 ExecutionState 严格限制为可由进程向 Execution Management 报告的状态，因此仅包含状态 kRunning [SWS_EM_02000]。如果 Execution Management 请求终止，则进程进入阶段 Terminating，该阶段随着进程的最终终止而结束 [SWS_EM_02000]。

状态图：从 Execution Management 的视角看进程的生命周期，包含隐式状态和 kRunning 的报告。来源：[SWS_EM_02000]

使用路径

典型使用流程分为以下阶段：

  • 系统启动后，进程由 Execution Management 创建并执行其内部初始化 [SWS_EM_02000]。
  • 一旦初始化成功完成，进程便通过 ExecutionClient 的实例向 Execution Management 报告状态 ExecutionState::kRunning [SWS_EM_02000]。
  • Execution Management 确认此转换；然而，如果进程已处于运行状态时报告了 kRunning，则这将被作为无效转换 ExecErrc::kInvalidTransition 予以拒绝 [SWS_EM_02281]。
  • 在后续运行中，State Management 在需要时通过 StateClient 请求功能组的协调状态转换。

时序图：通过 ExecutionClient 报告状态以及处理错误转换时的调用序列。来源：[SWS_EM_02000]、[SWS_EM_02281]

错误场景

错误情况在命名空间 ara::exec 中通过枚举类型 ExecErrc 和错误域 ExecErrorDomain 映射 [SWS_EM_02281]。对全局域对象的引用由线程安全且异常安全函数 GetExecErrorDomain() 提供 [SWS_EM_02290]。类型为 ara::core::ErrorCode 的具体错误对象通过辅助函数 MakeErrorCode() 在传递错误代码和特定于供应商的上下文数据时创建 [SWS_EM_02291]；此外，类 ExecException 可用于异常处理。

指定的错误原因包括 [SWS_EM_02281]：

  • ExecErrc::kNoCommunication：指示客户端与 Execution Management 之间或 State Management 与 Execution Management 之间的通信错误。在系统级别上，这种状态推测可能需要进入不可恢复状态 [SWS_EM_02281]。
  • ExecErrc::kInvalidTransition：无效转换，例如当进程重复报告 kRunning 时 [SWS_EM_02281]。
  • ExecErrc::kOperationFailed：操作失败，例如当功能组转换由于未及时报告 kRunning 而无法完成时 [SWS_EM_02281]。
  • ExecErrc::kOperationCanceled：功能组的状态切换被更新的请求中止 [SWS_EM_02281]。
  • ExecErrc::kIntegrityOrAuthenticityCheckFailed：待启动进程的完整性或真实性检查失败 [SWS_EM_02281]。
  • ExecErrc::kUnexpectedTermination：转换期间发生异常中止 [SWS_EM_02281]。
  • ExecErrc::kInvalidMetaModelIdentifier 以及 ExecErrc::kInvalidArgument：不允许的元模型标识符或无效的参数值 [SWS_EM_02281]。

Defines the internal states of a Process. Scoped enumeration of uint32_t. Please note that ara::exec::ExecutionState includes only states reportable by the Process to Execution Management and therefore does not include enumerations e.g. the "Initializing" state mentioned in Figure 7.2 and Figure 7.12, which are an implied states for Execution Management. The Initializing state starts when Process is first scheduled (so no code executed yet) and ends when kRunning is reported ([SWS_EM_01004]). The Terminating state starts when termination is requested by Execution Management and ends when the Process terminates ([SWS_EM_01404]). For the reasons mentioned, Execution Management assumes that Process is in initializing state until kRunning will be reported by it.

枚举 ExecErrc [SWS_EM_02281] 基于基础类型 ara::core::ErrorDomain::CodeType 在命名空间 ara::exec 中为 Execution Management 定义错误码。它与 MakeErrorCode [SWS_EM_02291] 一起用于封装在 ara::core::ErrorCode 中，并通过 ara::core::Result 同步或使用 ara::core::Future 异步传递给调用者。

这些枚举项涵盖不同的错误状态 [SWS_EM_02281]：

  • kNoCommunication 表示发送请求或检索结果时的通信错误 [SWS_EM_02281]。如果这发生在 Execution Management 与 State Management 之间，系统可能会进入不可恢复状态（Unrecoverable State）[SWS_EM_02281]。诸如 ExecutionClient 或 StateClient 等客户端仅在下一次方法调用时才会注意到这一点，此时客户端恢复选项有限 [SWS_EM_02281]。
  • kOperationCanceled 和 kOperationFailed 在功能组状态转换时发生 [SWS_EM_02281]，例如在 SetState [SWS_EM_02278] 处，或者当机器启动转换被中止时 [SWS_EM_02279]。
  • kInvalidTransition 指示不允许的进程转换，例如当进程重复报告 kRunning 时 [SWS_EM_02281]，与 ReportExecutionState [SWS_EM_02003] 相关。
  • kIntegrityOrAuthenticityCheckFailed、kUnexpectedTermination、kInvalidMetaModelIdentifier 以及 kInvalidArgument 处理完整性检查中的错误、功能组状态转换期间异常的进程中止，或无效的函数参数 [SWS_EM_02281]。

调用者对这些错误码进行评估，以确定状态转换是成功完成、被后续请求取代，还是因配置错误而被阻塞 [SWS_EM_02281]。
