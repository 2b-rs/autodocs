SecOC Communication Management 中的扩展

apext::com::secoc 捆绑新鲜度值管理和相关错误域的平台扩展。这些 API 解决了通信管理绑定的安全集成问题；它们不是通用服务消费者 API。 SWS CM §7.3.2 “Secure Communication” 和 EXP SW Architecture §9.3.1.1.3 “Interfaces for freshness value management” 提供分类。

具体处理错误代码

ComSecOcFvmErrc与GetComSecOcFvmErrorDomain()和MakeErrorCode()一起集成到AUTOSAR错误机制中。这些代码只能在FVM上下文中进行评估，不能用作ComErrc或E2E状态的替代。
