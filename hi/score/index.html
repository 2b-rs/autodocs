component Core Execution Environment

S-Core Core Execution Environment सभी Eclipse S-Core सेवाओं के लिए मौलिक OS अमूर्तता, POSIX रनटाइम गारंटी, कंटेनर प्रौद्योगिकियों, प्रक्रिया विशेषाधिकार मॉडल और कोडिंग मानकों को परिभाषित करता है।

Execution Architecture & Key Requirements

रिलीज़ पिन v0.6.0 से निम्नलिखित आवश्यकताएँ निकाली गई हैं और S-Core क्यूरेशन जीवनचक्र के माध्यम से प्रबंधित की जाती हैं:

आवश्यकता IDश्रेणीसुरक्षा / सुरक्षाविवरण
aou_req__platform__posix_operating_systemप्लेटफ़ॉर्म / OSसुरक्षा: QMIEEE Std 1003.1 (POSIX), 2004 संस्करण या बाद के संस्करण के अनुरूप एक अंतर्निहित ऑपरेटिंग सिस्टम की आवश्यकता है।
stkh_req__hardware_support__container_techकंटेनर / हार्डवेयरसुरक्षा: हाँकार्यभार रोकथाम के लिए cgroups, सुरक्षा नीतियां (secpol), और नेमस्पेस सहित लिनक्स कर्नेल अलगाव तंत्र की आवश्यकता होती है।
aou_req__os__cxx_preferenceOS / रनटाइमASIL B / सुरक्षाघटकों को लीगेसी C APIs की तुलना में ISO C++ मानक लाइब्रेरी इंटरफेस को प्राथमिकता देनी चाहिए, समान कार्यक्षमता के लिए मिश्रित कॉल को प्रतिबंधित करना चाहिए।
aou_req__os__minimal_privilegesसुरक्षा / OSसुरक्षा: हाँन्यूनतम विशेषाधिकार के सिद्धांत को लागू करता है, जिसके तहत प्रक्रियाओं को इनिशियलाइज़ेशन के बाद अनावश्यक क्षमताओं को छोड़ना आवश्यक होता है।
aou_req__os__nonrootसुरक्षा / प्रक्रियासुरक्षा: हाँएप्लिकेशन घटकों को अलग किए गए UID/GID नेमस्पेस के साथ गैर-विशेषाधिकार प्राप्त गैर-रूट उपयोगकर्ताओं के रूप में चलना चाहिए।
aou_req__os__public_apiआर्किटेक्चरसुरक्षा: QMसार्वजनिक API हेडर और निजी कार्यान्वयन इकाइयों के बीच सख्त इंटरफ़ेस सीमा इनकैप्सुलेशन लागू करता है।
