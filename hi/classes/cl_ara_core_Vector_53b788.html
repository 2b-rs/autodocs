कोर C++ मानक लाइब्रेरी से प्राप्त कंटेनर के रूप में Vector चलाता है। भाषा बाइंडिंग एक कॉन्फ़िगर करने योग्य आवंटनकर्ता और वैकल्पिक अधिकतम आकार के साथ मॉडल किए गए वेक्टर डेटा प्रकारों के लिए C++ उपनाम का उपयोग करती है। इस प्रकार प्रकार सामान्य कंटेनर API को जेनरेट किए गए इंटरफ़ेस प्रकारों से जोड़ता है। SWS Core §7.4 “Core data types” SWS Core §7.4.2 “Data types derived from the C++ standard” SWS LanguageBinding §7.1 “C++ binding for CppImplementationDataTypes” SWS LanguageBinding §8.2.4 “Vector Data Type”

आवंटनकर्ता की पसंद और व्यवहार विशिष्ट बंधन या कार्यान्वयन अनुबंध का हिस्सा रहता है। व्याख्या: क्षमता परिवर्तन जैसे reserve() या resize() को केवल स्थानीय कंटेनर अनुकूलन के रूप में मानने के बजाय, मॉडल किए गए अधिकतम आकारों के लिए इस मॉडल सीमा के विरुद्ध योजना बनाई जानी चाहिए।

गतिविधि आरेख: एक मॉडल किए गए वेक्टर डेटा प्रकार को ara::core::Vector आधार के साथ C++ प्रकार के रूप में भाषा बाइंडिंग में व्यक्त किया जाता है। आंशिक व्याख्या: अंतिम नोड एक फ़ील्ड या पैरामीटर के रूप में संभावित उपयोगों का सारांश देता है। स्रोत: SWS LanguageBinding §8.2.4 “Vector Data Type” SWS Core §7.4.2 “Data types derived from the C++ standard”।
