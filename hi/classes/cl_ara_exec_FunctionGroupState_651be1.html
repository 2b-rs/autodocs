क्लास ara::exec::FunctionGroupState

[SWS_EM_02269] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150, RS_AP_00129

class FunctionGroupState final {...};

Class representing Function Group State defined in meta-model (ARXML). An instance of this class will represent Function Group State defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.
