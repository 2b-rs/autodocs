उपयोग का उद्देश्य

Final class diagnostic reporting errors के लिए error range प्रदान करती है और ara::core::ErrorDomain से derived है। यह error code values को text messages में map करती है और संबद्ध ApApplicationErrorDomain का shortname लौटाती है। [SWS_DM_00996] [SWS_DM_01001] [SWS_DM_01000]

सीमाएँ & error handling

ThrowAsException पारित ErrorCode से जुड़े अपवाद को फेंकता है। यह विधि अपवाद-सुरक्षित नहीं है और C++ अपवाद अक्षम होने पर अधिभार समाधान में भाग नहीं लेती है; दिखाए गए शेष ऑपरेशन अपवाद-सुरक्षित और थ्रेड-सुरक्षित हैं। [SWS_DM_01002] [SWS_DM_00999]
