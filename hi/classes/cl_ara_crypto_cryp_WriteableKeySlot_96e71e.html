Manifest, अधिकार और बंधन

read access किसी KeySlot या client port द्वारा दिया जाता है; changes के लिए write-authorized port आवश्यक है। runtime यह assignment लागू करता है। delete या save करते समय material को तब तक नहीं बदला जा सकता, जब तक वह streaming operation में उपयोग हो रहा हो। [SWS_CRYPT_10000] [SWS_CRYPT_10001] [SWS_CRYPT_60006]
