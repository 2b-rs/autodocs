उपयोग का उद्देश्य

यह class DoIP-Entity-Identification interface प्रदान करती है। application GetEntityId लागू करता है, जो EID को asynchronous रूप से देता है। configuration को eidUseApi पर सेट करने पर Diagnostic Manager यह method कॉल करता है। [SWS_DM_01362] [SWS_DM_01366] [SWS_DM_01361]

पीढ़ी & विनाश

constructor को PortPrototype के लिए InstanceSpecifier और ConcurrencyType मिलता है; यह निर्धारित करता है कि GetEntityId को thread-safe रूप से लागू किया जाना चाहिए या नहीं। destructor virtual है। [SWS_DM_01364] [SWS_DM_01365] [SWS_DM_01366]

अन्य वर्गों के साथ सहभागिता

Offer प्रबंधक को हैंडलर को अनुरोध अग्रेषित करने की अनुमति देता है; StopOffer अग्रेषित करना बंद कर देता है। यदि EID निर्धारण विफल हो जाता है, तो प्रबंधक छह बाइट्स 0xFF भेजता है। [SWS_DM_01367] [SWS_DM_01368] [SWS_DM_01528]

सीमाएँ & error handling

दोबारा Offer करने पर DiagOfferErrc::kAlreadyOffered मिलता है। Offer और StopOffer thread-safe नहीं हैं; GetEntityId standardized errors निर्दिष्ट नहीं करता। [SWS_DM_01367] [SWS_DM_01368] [SWS_DM_01366]
