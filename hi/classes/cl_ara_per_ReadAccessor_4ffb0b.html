क्लास ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

उपयोगकर्ता गाइड AI-जनित / AI generated

स्वचालित रूप से उत्पन्न विवरण, संदर्भित AUTOSAR-R25-11 दस्तावेजों (SWS विनिर्देश और मानक दस्तावेजों के साथ) से प्राप्त सामग्री - आधिकारिक AUTOSAR पाठ नहीं। व्याख्या के रूप में चिह्नित कथन स्रोतों से निकाले गए निष्कर्ष हैं।

एक खुली फ़ाइल पढ़ना

ReadAccessor एक FileStorage की फ़ाइल तक विशेष पढ़ने की पहुंच है। फ़ाइल OpenFileReadOnly के साथ खोली जाती है; बाद में, चरित्र, पाठ और बाइनरी ऑपरेशन एक पढ़ने की रणनीति की अनुमति देते हैं जो सामग्री के अनुकूल होती है। SWS Persistency §7.4 “File Storage specific Features”

कर्सर और EOF

Peek… स्थिति को अपडेट किए बिना आगे देखता है; Get… उन्हें पढ़ता है और स्थानांतरित करता है। ReadLine, ReadText और ReadBinary संचरण के रूप में भिन्न हैं। IsEof के साथ-साथ Result भी जांचें और केवल अपेक्षित लंबाई पर निर्भर न रहें।

संगामिति

एक्सेसर विधियाँ थ्रेड-सुरक्षित नहीं हैं। इसलिए, पहुंच और स्थिति प्रबंधन को नियंत्रित स्वामित्व संदर्भ में रखें या बाहरी रूप से उसी हैंडल की सुरक्षा करें।

File Storage named files के एक set का प्रबंधन करता है; Accessor के पास विशिष्ट open access विशेषाधिकारपूर्वक होता है। स्रोत: SWS Persistency §7.4 “File Storage specific Features” [SWS_PER_00113]।

निम्नलिखित पहले से जुड़े विनिर्देश और API पद उल्लिखित संचालन के लिए विस्तृत दस्तावेज़ के रूप में बने हुए हैं: [SWS_PER_00417] [SWS_PER_00418] [SWS_PER_00167] [SWS_PER_00421] [SWS_PER_00420] [SWS_PER_00524] EXP SWArchitecture §11.3.1.1.1 “Scenario: Read Persistent Data from File” EXP SWArchitecture §9.4.1.1.1 “Interfaces for file storage”। [SWS_PER_00419] [SWS_PER_00168] [SWS_PER_00422] [SWS_PER_00165] [SWS_PER_00119] [SWS_PER_00461] [SWS_PER_00512]
