class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

उपयोग का उद्देश्य

ErrorCode एक डोमेन-विशिष्ट रॉ त्रुटि मान, संबंधित ErrorDomain का संदर्भ और वैकल्पिक विक्रेता-विशिष्ट अतिरिक्त डेटा को समाहित करता है। प्रकार एक शाब्दिक प्रकार है. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

सृजन और अंतःक्रिया

इसे त्रुटि एनम से या मान, त्रुटि डोमेन और अतिरिक्त डेटा से बनाया जा सकता है। Domain(), Value(), SupportData() और Message() इसके घटकों या त्रुटि पाठ को सुलभ बनाते हैं; ThrowAsException() पूरे डोमेन में उचित अपवाद प्रकार निर्धारित करता है। [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

सीमाएँ & error handling

तुलनाएँ केवल त्रुटि मान और त्रुटि डोमेन को ध्यान में रखती हैं, अतिरिक्त डेटा को नहीं। ErrorCode और इसके सदस्यों का उपयोग ara::core::Initialize और Deinitialize से स्वतंत्र रूप से किया जा सकता है। [SWS_CORE_10301] [SWS_CORE_15002]

सामान्य error values के स्थान पर error context

एक ErrorCode एक टाइप किए गए त्रुटि मान को उसके ErrorDomain संदर्भ के साथ जोड़ता है; वैकल्पिक रूप से इसमें एक संदेश और अतिरिक्त निर्माता-विशिष्ट जानकारी हो सकती है। पुनर्प्राप्त करने योग्य त्रुटियों के लिए ARA इंटरफ़ेस इसका उपयोग Result के भीतर करता है। EXP InterfacesGuidelines §3.1.2 “Result” EXP ARAComAPI §4.7 “Error Handling”

निर्माता-विशिष्ट त्रुटि कोड को अपने स्वयं के त्रुटि डोमेन की आवश्यकता होती है; पोर्टेबल, स्टैक-न्यूट्रल अनुप्रयोगों को ऐसे डोमेन को सामान्य डिफ़ॉल्ट मामले के रूप में मानना ​​चाहिए। EXP InterfacesGuidelines §3.1.5 “Standardized vs Vendor-specific ErrorCodes”

सहयोग आरेख: ErrorCode को अपने डोमेन से संदर्भ और संदेश मिलता है; अपवाद परिवर्तन स्पष्ट अपवाद पथ है। स्रोत: EXP InterfacesGuidelines §3.1.2 “Result” RS General §4.1.3 “The use of noexcept”.

मिटाया गया त्रुटि मान टाइप करें

SWS, ErrorCode को Domain context वाले error value के रूप में वर्णित करती है: domain-specific code को एकसमान transport के लिए integer value में type-erased किया जाता है; अतिरिक्त support data आगे भेजा जा सकता है। comparisons value और Domain को ध्यान में रखते हैं, support data को नहीं। SWS Core §7.2 “Error handling” SWS Core §7.2.5.1 “ErrorCode” [SWS_CORE_10301] [SWS_CORE_10302]
