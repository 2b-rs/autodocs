क्लास ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

सामान्य कर्सर इंटरफ़ेस

FileAccessor खुली फ़ाइलों पर स्थिति और आकार संचालन को बंडल करता है। यह पढ़ने, लिखने और पढ़ने/लिखने वाले एक्सेसर्स का सामान्य आधार है; इसका मतलब यह है कि कर्सर की स्थिति बिल्कुल इस खुली फ़ाइल तक पहुंच का वर्णन करती है।

स्थितीय अनुशासन

GetPosition, SetPosition और MovePosition का उपयोग नेविगेशन के लिए किया जाता है, जबकि GetSize वर्तमान फ़ाइल आकार प्रदान करता है। एक्सेसर ऑपरेशंस थ्रेड-सुरक्षित नहीं हैं: इसलिए एक हैंडल को बाहरी सिंक्रनाइज़ेशन के बिना एक ही समय में कई थ्रेड्स द्वारा उपयोग नहीं किया जाना चाहिए। SWS Persistency §7.4 “File Storage specific Features”

उपयोग सूचना

FileStorage के माध्यम से फ़ाइल खोलें, उसी UniqueHandle के कब्जे में कर्सर संचालन करें और फिर इसे छोड़ दें। स्थिति में बदलाव एक निरंतरता प्रक्रिया नहीं है; डेटा लिखने के लिए उपयुक्त लेखन संचालन और, यदि आवश्यक हो, सिंक्रनाइज़ेशन की आवश्यकता होती है।

File Storage named files के एक set का प्रबंधन करता है; Accessor के पास विशिष्ट open access विशेषाधिकारपूर्वक होता है। स्रोत: SWS Persistency §7.4 “File Storage specific Features” [SWS_PER_00113]।
