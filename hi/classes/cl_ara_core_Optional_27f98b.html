उपयोग का उद्देश्य

ara::core::Optional<T> std::optional<T> लागू करता है और संभवतः मौजूद value को model करता है। यह empty construction अथवा nullopt, in-place construction, emplace(), reset(), status queries और value access का समर्थन करता है। [SWS_CORE_01033] [SWS_CORE_01103] [SWS_CORE_01104] [SWS_CORE_01107] [SWS_CORE_01119] [SWS_CORE_01136] [SWS_CORE_01129]

जीवनचक्र और स्वामित्व

कॉपी और मूव निर्माण, असाइनमेंट और विनाश T noexcept के गुणों के आधार पर सशर्त हैं। [SWS_CORE_01105] [SWS_CORE_01106] [SWS_CORE_01114] [SWS_CORE_01115] [SWS_CORE_01112]

अन्य वर्गों के साथ सहभागिता

विनिर्देश को Optional<T&> विशेषज्ञता के माध्यम से लाभ संदर्भों के लिए समर्थन की आवश्यकता होती है। __PROT1___ [SWS_CORE_01032]

सीमाएँ & error handling

एक्सेस operator*, operator-> और value() noexcept हैं, लेकिन यदि कोई मान गायब है तो यह IsoStdBadOptionalAccessViolation को ट्रिगर कर सकता है। एक्सेस करने से पहले, has_value() या बूल रूपांतरण का उपयोग किया जा सकता है। [SWS_CORE_01124] [SWS_CORE_01122] [SWS_CORE_01130] [SWS_CORE_01129] [SWS_CORE_01128]

मॉडल किए गए डेटा सेट में वैकल्पिकता

Optional केवल एक सामान्य सुविधा प्रकार नहीं है: कोर इसे विशेष रूप से श्रेणी STRUCTURE के StdCppImplementationDataType के वैकल्पिक रिकॉर्ड तत्वों के लिए कहता है। दूसरी ओर, अनिवार्य फ़ील्ड सीधे उनके कार्यान्वयन डेटा प्रकार के साथ दिखाई देते हैं। वैकल्पिक रूप से, Optional किसी फ़ंक्शन के संभावित गुम रिटर्न मान को व्यक्त कर सकता है। SWS Core §7.4 “Core data types” SWS Core §7.4.2 “Data types derived from the C++ standard” SWS LanguageBinding §7.1 “C++ binding for CppImplementationDataTypes”

Optional<T&> के लिए assignment rebind व्यवहार का अनुसरण करता है: यह Optional-reference को मूल रूप से bound object में reference के माध्यम से लिखने के बजाय नए object से bind करता है। [SWS_CORE_01032] [SWS_CORE_01034]

गतिविधि आरेख: कड़ाई से मूल्य-आधारित पहुंच से पहले, व्यवसाय की स्थिति की जाँच की जाती है; विकल्प value() तक पहुंच के बिना अनुपस्थिति को संभालता है। स्रोत: SWS Core §7.4.2 “Data types derived from the C++ standard” [SWS_CORE_01129] [SWS_CORE_01130].
