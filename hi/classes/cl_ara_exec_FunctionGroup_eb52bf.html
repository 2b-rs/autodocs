क्लास ara::exec::FunctionGroup

[SWS_EM_02263] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150

class FunctionGroup final {...};

Class representing Function Group defined in meta-model (ARXML). An instance of this class will represent Function Group defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

सुसंगत रूप से नियंत्रित process-समूह की सीमा

FunctionGroup कॉन्फ़िगर किए गए Function Group का API प्रतिनिधि है। यह उन मॉडल प्रक्रियाओं को बंडल करता है जो राज्यों के माध्यम से सुसंगत रूप से शुरू और समाप्त होती हैं; एक मॉडल प्रक्रिया को एकाधिक फ़ंक्शन समूहों SWS EM §7.4.3 “Function Group State” को नहीं सौंपा जाना चाहिए।

मशीनएफजी और एप्लिकेशन-संबंधित समूह

Function Group MachineFG Machine States का वर्णन करती है और मुख्यतः machine lifecycle के लिए प्रयुक्त होती है। अन्य Function Groups सामान्यतः User-Level applications के समूहों को नियंत्रित करती हैं। प्रक्रियाओं का विशिष्ट आवंटन Execution Manifests SWS EM §7.4 “State Management” से आता है।

राज्य आरेख: फ़ंक्शन समूह के राज्य परिवर्तन का अनुरोध राज्य प्रबंधन द्वारा किया जाता है और निष्पादन प्रबंधन RS Execution Management, State Management (S. 16) SWS EM §7.4.5 “State Transition” द्वारा कार्यान्वित किया जाता है। व्याख्या: सक्रिय लक्ष्य स्थिति मैनिफ़ेस्ट में परिभाषित मोडडिक्लेरेशन का एक उदाहरण है।
