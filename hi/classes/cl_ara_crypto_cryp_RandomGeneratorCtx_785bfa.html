स्वचालित रूप से उत्पन्न विवरण, संदर्भित AUTOSAR-R25-11 दस्तावेजों (SWS विनिर्देश और मानक दस्तावेजों के साथ) से प्राप्त सामग्री - आधिकारिक AUTOSAR पाठ नहीं। व्याख्या के रूप में चिह्नित कथन स्रोतों से निकाले गए निष्कर्ष हैं।

क्रिप्टो स्टैक में भूमिका

ara::crypto::cryp::RandomGeneratorCtx एक एल्गोरिदम-विशिष्ट क्रिप्टो संदर्भ है। यह कुंजी और एल्गोरिदम के चयन/बाइंडिंग को एक ठोस ऑपरेशन के निष्पादन से अलग करता है और, जहां समर्थित है, एक समान सिंगल-कॉल या स्ट्रीमिंग पैटर्न का पालन करता है। SWS Cryptography §7.4 “Crypto Contexts”

कॉल पैटर्न

एक संदर्भ उपयुक्त AlgId के साथ बनाया जाता है और कुंजी-बाउंड संचालन से पहले कॉन्फ़िगर किया जाता है। संपूर्ण संदेशों के लिए एकल चरण उपयुक्त हैं; स्ट्रीमिंग एपीआई योजना Start(), एक या अधिक Update() और Finish() का अनुसरण करती है। यदि संबंधित वर्ग यह पेशकश करता है तो आउटपुट आकार और IV आवश्यकताओं के बारे में पहले से पूछताछ की जा सकती है। SWS Cryptography §7.4.1 “Overview”

स्ट्रीमिंग संदर्भों को प्रसंस्करण से पहले कॉन्फ़िगर किया जाता है और पूरा होने या रद्द करने के माध्यम से बाहर निकाला जाता है। स्रोत: SWS Cryptography §7.4.1 “Overview”. आंशिक व्याख्या: राज्य के नाम API अनुक्रमों को संक्षिप्त करते हैं।

त्रुटि और संसाधन मॉडल

कॉल करने वाला ara::core::Result, कुंजी संगतता, अनुमत उपयोग, बफर आकार और संदर्भ स्थिति की जांच करता है। समानांतर में उपयोग किया जाने वाला दूसरा हार्डवेयर संसाधन अस्थायी रूप से अनुपलब्ध हो सकता है; अनिश्चित काल तक ब्लॉक करने के बजाय, प्रदाता व्यस्त त्रुटि की रिपोर्ट कर सकता है। __PROT1___ SWS Cryptography §7.1.6 “Concurrent Access”

विधि सिंहावलोकन

  • virtual ara::core::Result< void > AddEntropy (ReadOnlyMemRegion entropy) noexcept=0; Update the internal state of the RNG by mixing it with the provided additional entropy.
  • virtual ara::core::Result< void > Generate (ReadWriteMemRegion output) noexcept=0; Fill the provided output buffer with a (pseudo)random sequence.
  • virtual ara::core::Result< void > Seed (ReadOnlyMemRegion seed) noexcept=0; Set the internal state of the RNG using the provided seed.
  • virtual ara::core::Result< void > Seed (SymmetricKey::Sptr seed) noexcept=0; Set the internal state of the RNG using the provided seed.
