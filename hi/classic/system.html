Architekturüberblick System Services

Das Cluster System Services vereint grundlegende Steuer- und Sicherheitsmodule der AUTOSAR Classic Platform: Den ECU State Manager (EcuM) [SWS_EcuM_02813], den BSW Mode Manager (BswM) und den Watchdog Manager (WdgM). Es regelt den geordneten Boot- und Shutdown-Ablauf (EcuM_Init, EcuM_StartupTwo) [SWS_EcuM_02815], koordiniert Moduswechsel zwischen BSW-Modulen und sichert durch logische und zeitliche Programmablaufüberwachung die funktionale Sicherheit des Gesamtsystems [SWS_EcuM_02811].

क्युरेशन में जांचें

Die System Services steuern den gesamten ECU-Lebenszyklus von Power-On über Wakeup, Betriebszustände, Modus-Arbitrierung (BswM) bis zum sicheren Herunterfahren und Programmlauf-Überwachung (WdgM).

Module im Cluster

ECU State Manager (EcuM)

Controls ECU lifecycle states: Startup, Run, PostRun, Sleep, and Shutdown.

BSW ID 10 65 APIs (52 Funktionen, 13 Typen) #include "EcuM.h"

BSW Mode Manager (BswM)

Arbitrates mode requests and executes action lists to control system state transitions.

BSW ID 42 35 APIs (32 Funktionen, 3 Typen) #include "BswM.h"

Watchdog Manager (WdgM)

Performs alive supervision, deadline supervision, and logical program flow monitoring.
