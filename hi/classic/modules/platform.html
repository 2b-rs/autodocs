Platform Types (Platform_Types)

Platform-specific fundamental data types (integers, booleans, floating-point numbers) mapped to CPU architecture primitives.

type boolean [SWS_Platform_00026]

typedef unsigned char boolean;

This standard AUTOSAR type shall only be used together with the definitions TRUE and FALSE.

type uint8 [SWS_Platform_00013]

typedef unsigned char uint8;

This standard AUTOSAR type shall be of 8 bit unsigned.

type uint16 [SWS_Platform_00014]

typedef unsigned short uint16;

This standard AUTOSAR type shall be of 16 bit unsigned.

type uint32 [SWS_Platform_00015]

typedef unsigned long uint32;

This standard AUTOSAR type shall be 32 bit unsigned.

type uint64 [SWS_Platform_00066]

typedef unsigned long long uint64;

This standard AUTOSAR type shall be 64 bit unsigned.

type sint8 [SWS_Platform_00016]

typedef signed char sint8;

This standard AUTOSAR type shall be of 8 bit signed.

type sint16 [SWS_Platform_00017]

typedef signed short sint16;

This standard AUTOSAR type shall be of 16 bit signed.

type sint32 [SWS_Platform_00018]

typedef signed long sint32;

This standard AUTOSAR type shall be 32 bit signed.

type sint64 [SWS_Platform_00067]

typedef signed long long sint64;

This standard AUTOSAR type shall be 64 bit signed.

type float32 [SWS_Platform_00041]

typedef float float32;

This standard AUTOSAR type shall follow the 32-bit binary interchange format according to IEEE 754-2008 with encoding parameters specified in chapter 3.6, table 3.5, column "binary32".

type float64 [SWS_Platform_00042]

typedef double float64;

This standard AUTOSAR type shall follow the 64-bit binary interchange format according to IEEE 754-2008 with encoding parameters specified in chapter 3.6, table 3.5, column "binary64".

type VoidPtr [SWS_Platform_91001]

typedef void* VoidPtr;

This standard AUTOSAR type shall be a void pointer Note: This type shall be used for buffers that contain data returned to the caller.

type ConstVoidPtr [SWS_Platform_91002]

typedef const void* ConstVoidPtr;

This standard AUTOSAR type shall be a void pointer to const. Note: This type shall be used for buffers that are passed to the callee.

type CPU_TYPE [SWS_Platform_00064]

This symbol shall be defined as #define having one of the values CPU_TYPE_8, CPU_TYPE_16, CPU_TYPE_32 or CPU_TYPE_64 according to the platform.

type CPU_BIT_ORDER [SWS_Platform_00038]

This symbol shall be defined as #define having one of the values MSB_FIRST or LSB_FIRST according to the platform.

type CPU_BYTE_ORDER [SWS_Platform_00039]

This symbol shall be defined as #define having one of the values HIGH_BYTE_FIRST or LOW_ BYTE_FIRST according to the platform.

type TRUE_FALSE [SWS_Platform_00056]

The symbols TRUE and FALSE shall be defined as follows: #ifndef TRUE #define TRUE 1 #endif #ifndef FALSE #define FALSE 0 #endif
