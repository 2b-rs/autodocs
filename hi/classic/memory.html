रिकॉर्ड CP_MEM रिपॉजिटरी पहचानकर्ता [SWS_CP_MEM_00001] के तहत NvM_WriteBlock(NvM_BlockIdType BlockId, const void* NvM_SrcPtr) का दस्तावेजीकरण करता है। इस टिप्पणी का पृष्ठ असाइनमेंट classic/memory.html है, क्योंकि NVRAM प्रबंधक वहाँ प्रबंधित किया जाता है।

व्याख्या: NvM ब्लॉक ID, एक RAM मिरर और एक कार्य के साथ ब्लॉकों का प्रबंधन करता है। NvM_WriteBlock राइट कार्य को कतारबद्ध करता है। Fee या Ea और अंतर्निहित मेमोरी ड्राइवर इसे निष्पादित करते हैं। कतारबद्ध करने का रिटर्न मान यह पावती नहीं है कि डेटा गैर-वाष्पशील मेमोरी में है।

व्याख्या: सामान्य ब्लॉक प्रबंधन एक एकल ब्लॉक, दो प्रतियों वाले एक रिडंडेंट ब्लॉक और कई तत्वों वाले एक डेटासेट ब्लॉक के बीच अंतर करता है। CRC और राइट सत्यापन कॉन्फ़िगर किए गए संरक्षण का हिस्सा हैं। स्थानीय रिकॉर्ड प्रबंधन के प्रकार को निर्दिष्ट नहीं करता है।

व्याख्या: एक रिडंडेंट ब्लॉक के लिए, यदि सत्यापन सफल होता है तो दूसरी प्रति से क्षतिग्रस्त प्राथमिक प्रति को पढ़ा जा सकता है। यदि दोनों प्रतियाँ अमान्य हैं, तो NvM से एप्लिकेशन मान का कोई तकनीकी पुनर्निर्माण नहीं होता है। दस्तावेज़ का नाम: AUTOSAR_SWS_NVRAMManager, यहाँ पंजीकृत नहीं है।

क्युरेशन में जांचें

Die Memory Services verwalten nicht-flüchtige Datenblöcke (NvM), abstrahieren Flash- und EEPROM-Technologien (MemIf, Fee, Ea) und gewährleisten Datenkonsistenz und Datensicherheit über ECU-Abschaltzyklen hinweg.

Module im Cluster

NVRAM Manager (NvM)

Provides synchronous and asynchronous block-based data management for non-volatile storage (EEPROM, Flash).

BSW ID 20 36 APIs (30 Funktionen, 6 Typen) #include "NvM.h"

Memory Abstraction Interface (MemIf)

Abstracts underlying Flash and EEPROM memory drivers.

BSW ID 22 12 APIs (9 Funktionen, 3 Typen) #include "MemIf.h"

Flash EEPROM Emulation (Fee)

Provides emulation of EEPROM-like data blocks on Flash memory devices.

BSW ID 40 16 APIs (15 Funktionen, 1 Typen) #include "Fee.h"

EEPROM Abstraction (Ea)

Provides uniform access to external and internal EEPROM devices.

BSW ID 41 16 APIs (15 Funktionen, 1 Typen) #include "Ea.h"
