सेवा इंटरफ़ेस PackageManagement

इंटरफ़ेस को ara::com सेवा के रूप में तैयार किया गया; विधियों/फ़ील्डों को उत्पन्न प्रॉक्सी/कंकालों (IN/OUT पैरामीटर दिशा) के माध्यम से कॉल किया जाता है।

उपयोगकर्ता गाइड AI-जनित / AI generated

स्वचालित रूप से उत्पन्न विवरण, संदर्भित AUTOSAR-R25-11 दस्तावेजों (SWS विनिर्देश और मानक दस्तावेजों के साथ) से प्राप्त सामग्री - आधिकारिक AUTOSAR पाठ नहीं। व्याख्या के रूप में चिह्नित कथन स्रोतों से निकाले गए निष्कर्ष हैं।

एक सेवा, तीन पेशेवर स्तर

PackageManagement packet acceptance, packet processing और running Software-Cluster set के परिवर्तन को अलग करता है। CurrentStatus वर्तमान में निष्पादित UCM phase का global view है; Transfer-IDs अलग-अलग transfers को विशिष्ट रूप से निर्दिष्ट करते हैं। SWS UCM अध्याय 7 “Functional specification” [SWS_UCM_00361]

मजबूत ब्लॉक स्थानांतरण

TransferStart संसाधनों को सुरक्षित रखता है और स्थानांतरण ID और अधिकतम ब्लॉक आकार प्रदान करता है। TransferData, ID, ऑर्डर, आकार की जांच करता है और यदि आवश्यक हो, तो स्थिरता को ब्लॉक करता है। TransferExit की अनुमति केवल डेटा ब्लॉक और पूर्णता और पैकेट प्रारूप की जांच के बाद ही दी जाती है। इसलिए स्थानांतरण में त्रुटियों को प्रति स्थानांतरण माना जाना चाहिए और सक्रियण त्रुटियों के रूप में व्याख्या नहीं की जानी चाहिए। [SWS_UCM_00272] [SWS_UCM_00275] [SWS_UCM_00276]

ब्लॉक स्थानांतरण से सक्रियण तक गतिविधि आरेख। स्रोत: SWS UCM §7.3 “Transfer and processing”, SWS UCM §7.5 “Activation and rollback”। आंशिक व्याख्या: प्रतिनिधित्व ग्राहक के आदेश पर जोर देता है, हालांकि व्यक्तिगत स्थानांतरण और प्रसंस्करण को समय में अलग किया जा सकता है।

प्रसंस्करण, सक्रियण और निकासी

ProcessSwPackage के बाद Activate को केवल processed packages की preparation phase से शुरू किया जा सकता है। activation SM पर Update-Session का अनुरोध करता है। verification completion या recovery का निर्णय करती है; Rollback का स्पष्ट failure exit है और kRollingBackFailed से पुनः प्रयास किया जा सकता है। [SWS_UCM_00241] [SWS_UCM_00257] [SWS_UCM_00300] [SWS_UCM_00301]

स्थिति और क्वेरी संचालन

GetProgress, GetSwPackages, cluster queries और GetHistory अवलोकन और auditability के लिए हैं; वे state-bound operation से पहले की status check का स्थान नहीं लेते। Suspend/Resume दीर्घकालिक actions से संबंधित हैं और उन्हें CurrentStatus के संदर्भ में समझना चाहिए। SWS UCM §7.6 “Progress and interruption”

ग्राहक चेकलिस्ट

  1. अधिकतम ब्लॉक आकार का उपयोग करें और TransferStart द्वारा प्रदान किए गए ID को अपरिवर्तित स्थानांतरित करें।
  2. TransferExit से पहले सभी ब्लॉकों को स्थानांतरित करें और प्रत्येक त्रुटि के लिए स्थानांतरण आईडी-विशिष्ट कारण का मूल्यांकन करें।
  3. प्रसंस्करण के बाद, CurrentStatus का निरीक्षण करें और केवल अनुमत चरण में Activate पर कॉल करें।
  4. यदि सत्यापन परिणाम नकारात्मक है, तो पुनः सक्रियण के बजाय दस्तावेज़ीकृत रोलबैक पथ चुनें।

पिछले ब्लॉक से प्राप्त अतिरिक्त साक्ष्य: [SWS_UCM_00361] [SWS_UCM_00343] [SWS_UCM_00344] [SWS_UCM_00345] [SWS_UCM_00346] [SWS_UCM_00347] [SWS_UCM_00348] [SWS_UCM_00349] [SWS_UCM_00351] [SWS_UCM_00350] [SWS_UCM_00352] [SWS_UCM_00353] [SWS_UCM_00354] [SWS_UCM_00355] [SWS_UCM_00356] [SWS_UCM_00357] [SWS_UCM_00358] [SWS_UCM_00359] [SWS_UCM_00360] [SWS_UCM_00390] [SWS_UCM_00397] [SWS_UCM_00398] [SWS_UCM_00030] EXP PlatformDesign §13.2 “Update protocol” EXP SWArchitecture §9.7.1.1.1 “General” [RS_UCM_00026] [RS_UCM_00006] [RS_UCM_00021] [RS_UCM_00008] [RS_UCM_00027].

सदस्य

  • Activate This method activates the Software Clusters extracted from the processed Software Packages.
  • Cancel This method aborts an ongoing processing of a Software Package.
  • CurrentStatus The current status of UCM.
  • DeleteTransfer Delete a transferred Software Package.
  • Finish This method finishes the processing for the current set of processed Software Packages
  • GetHistory Getter method to retrieve all actions that have been performed by UCM.
  • GetId Get the UCM Instance Identifier.
  • GetProgress Get the progress information of the currently active state in the Package Management state machine.
  • GetSwClusterChangeInfo This method returns a list pending changes to the set of SoftwareClusters on the adaptive platform
  • GetSwClusterInfo This method returns a list with information of all SoftwareClusters that are in state kPresent.
  • GetSwClusterManifestInfo This method returns the general information of a Software Cluster that are in state kPresent.
  • GetSwPackages This method returns the Software Packages that available in UCM.
  • ProcessSwPackage Process a previously transferred Software Package or a partly transferred Software Package from a stream.
  • RegisterSoftwarePackage registers a package that could already be in Machine’s file system or to be downloaded.
  • Resume This method resumes ongoing time consuming actions or actions related to specific states.
  • RevertProcessedSwPackages Revert the changes done by processing (ProcessSwPackage) of one or several software packages.
  • Rollback Rollback the system to the state before the packages were processed.
  • Suspend This method suspends ongoing time consuming actions or actions related to specific states.
  • TransferData Block-wise transfer of a Software Package to UCM.
  • TransferExit Finish the transfer of a Software Package to UCM.
  • TransferStart Start the transfer of a Software Package after having received a Vehicle Package
