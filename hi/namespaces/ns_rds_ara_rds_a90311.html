नेमस्पेस ara::rds

यह पेज पूरी तरह से SWS Raw Data Stream (R25-11) पर आधारित KI जेनरेट किया गया है - बाकी मॉड्यूल की तरह कोई आधिकारिक AUTOSAR टेक्स्ट और कोई ऑटो-एक्सट्रैक्टेड API पेज नहीं है। व्याख्या के रूप में चिह्नित कथन स्रोतों से निकाले गए निष्कर्ष हैं।

क्लासें और स्ट्रक्चर

  • RawDataStreamClient Object for reading and writing binary data streams over a network connection.
  • RawDataStreamServer Object for accepting a connection and reading or writing binary data streams.
  • ReadDataResult Result of a RawDataStream read operation.
  • IEEE1722Datagram IEEE 1722 datagram representation: IEEE1722Datagram.
  • IEEE1722Datagram61883_IIDC IEEE 1722 datagram representation: IEEE1722Datagram61883_IIDC.
  • IEEE1722DatagramAAF IEEE 1722 datagram representation: IEEE1722DatagramAAF.
  • IEEE1722DatagramAVTPDUCommonHeaderFields IEEE 1722 datagram representation: IEEE1722DatagramAVTPDUCommonHeaderFields.
  • IEEE1722DatagramAVTPDUCommonStreamHeaderFields IEEE 1722 datagram representation: IEEE1722DatagramAVTPDUCommonStreamHeaderFields.
  • IEEE1722DatagramCRF IEEE 1722 datagram representation: IEEE1722DatagramCRF.
  • IEEE1722DatagramNTSCF IEEE 1722 datagram representation: IEEE1722DatagramNTSCF.
  • IEEE1722DatagramRVF IEEE 1722 datagram representation: IEEE1722DatagramRVF.
  • IEEE1722DatagramTSCF IEEE 1722 datagram representation: IEEE1722DatagramTSCF.
  • IEEE1722RawDataStreamConsumer Consumer for typed IEEE 1722 stream datagrams.
  • IEEE1722RawDataStreamProducer Producer for typed IEEE 1722 stream datagrams.
  • RdsErrorDomain Error domain of Raw Data Stream.
  • RdsException Exception type for Raw Data Stream.
