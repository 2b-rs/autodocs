Communication

component Communication Framework

Het S-Core Communication Framework biedt zero-copy shared memory inter-process communicatie (IPC), service discovery, skeleton/proxy-codegeneratie en SOME/IP-bindings voor gedistribueerde automotive-toepassingen met hoge doorvoer.
