functie TraceArti [SWS_LOG_20000] Upstream: RS_LT_00003

template <typename MsgId, typename... Params> void TraceArti (const MsgId &msg_id, const Params &...                       params) noexcept;

Handles a modeled message, specific to the used trace tool. This function is only called internally by the Logger framework when switching between Log and TraceArti. It represents the interface to trace tools. The runtime overhead of this function shall be kept as minimal as possible, e.g. by using specializations based on the MsgId.

Semantiek van TraceArti

TraceArti is een API-detail van de logging-interface. Het gebruik ervan staat in de context van Logger, LogStream en het geconfigureerde reporting-filter.

Plaatsing in het berichtenpad

De logging-API is no-throw ontworpen; fouten in het framework mogen het applicatieproces niet belasten. De feitelijke uitvoer hangt af van de geconfigureerde sink. SWS Log and Trace §7.1 “Necessary Parameters and Initialization” SWS Log and Trace §7.7 “Output Bindings”
