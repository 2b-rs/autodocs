Publieke toegangspunten

De namespace ara::per bevat de API voor geconfigureerde persistente opslag: openen van key-value- en file-storages, groottebevragingen, reset/recovery evenals update- en callback-functies. Alle gespecificeerde persistency-klassen bevinden zich in deze namespace. SWS Persistency §7.2 “General Features of Persistency”

Openen vóór vakinhoudelijk gebruik

OpenKeyValueStorage en OpenFileStorage nemen een InstanceSpecifier aan en geven shared handles terug. De keuze van de functie volgt het gemanifesteerde storage-type; daarna volgt het elementaire werk op keys of bestanden. SWS Persistency §7.3 “Key-Value Storage specific Features” SWS Persistency §7.4 “File Storage specific Features”

Bedrijfsbewerkingen

Update- en opschoonfuncties horen bij een gecontroleerd deployment-/verificatieverloop. Reset en recovery grijpen in op de databasis en mogen niet worden ingepland als gewone paralleloperaties naast open storages. SWS Persistency §7.2.5 “Installation and Update of Persistent Data” SWS Persistency §7.2.4 “Redundancy Concepts”

Capaciteit bewaken

GetCurrent…StorageSize levert de werkelijk gebruikte omvang inclusief beheer-, redundantie- en back-upgegevens. De bevraging is bij geopende Storage of parallelle bewerking slechts beperkt nauwkeurig. SWS Persistency §7.2.6 “Resource Management Concepts”

Het verloop van het openen en de gegevensupdate is in de gids van de module ara::per — Persistency gedocumenteerd als diagrammen: Sequentiediagram „Storage openen en gebruiken“ en Activiteitendiagram „Actualisering van persistente gegevens”.

ara::core::Result< bool > CheckForManifestUpdate () noexcept;

Checks for updates of the Persistency Target Configuration. This method can be used to detect configuration updates that are installed by UCM while the Adaptive Application that uses Persistency is running. To re-read the updated Target Configuration, the Adaptive Application needs to call ara::per:: ReloadPersistencyManifest.

De vrije functie ara::per::CheckForManifestUpdate [SWS_PER_00576] controleert of een bijgewerkte persistency target configuration aanwezig is, die tijdens de runtime van de adaptive application door UCM is geinstalleerd. De aanroep levert een ara::core::Result<bool>, waarvan de waarde true is wanneer de target configuration sinds het laatste lezen is gewijzigd, anders false. Om de bijgewerkte configuratie in te lezen, moet de applicatie vervolgens ara::per::ReloadPersistencyManifest aanroepen. De functie is niet thread-safe, maar wel exception-safe.

Returns the space in bytes currently occupied by a File Storage. The returned size includes all metadata and the space used for redundancy and backups. The returned size is only guaranteed to be accurate if the File Storage is not opened and no other operation on the File Storage takes place at the same time.
