Class representing Function Group defined in meta-model (ARXML). An instance of this class will represent Function Group defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

Grens van een consistent bestuurde procesverzameling

FunctionGroup is de API-vertegenwoordiger van een geconfigureerde function group. Deze bundelt modelprocessen die via toestanden coherent worden gestart en beeindigd; een modelproces mag niet aan meerdere function groups worden toegewezen SWS EM §7.4.3 “Function Group State”.

MachineFG en applicatienabije groepen

De function group MachineFG beschrijft machine states en dient vooral de machine-lifecycle. Andere function groups sturen doorgaans groepen van user-level-toepassingen aan. De concrete toewijzing van de processen komt uit de execution manifests SWS EM §7.4 “State Management”.

Toestandsdiagram: een toestandswijziging van een Function Group wordt door State Management aangevraagd en door Execution Management uitgevoerd RS Execution Management, State Management (S. 16) SWS EM §7.4.5 “State Transition”. Interpretatie: de actieve doeltoestand staat exemplarisch voor een in het Manifest gedefinieerde ModeDeclaration.
