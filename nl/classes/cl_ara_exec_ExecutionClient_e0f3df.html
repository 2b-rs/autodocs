Rol in de gemelde proceslifecycle

ExecutionClient is de procesgerichte interface voor een reporting process. Een gemeld kRunning laat execution management de processtatus Running bereiken; execution state en de intern bijgehouden process state blijven daarbij afzonderlijke modellen SWS EM §7.3.1 “Execution State” SWS EM §7.3.2 “Process States”.

Deterministische opstart en terminering

Een Reporting Process meldt kRunning na voltooiing van zijn initialisatie en vóór een mogelijk niet-deterministische Service-Discovery-fase. Daardoor kunnen geconfigureerde afhankelijkheden naar een betrouwbare Process State worden opgelost. Bij een terminatieaanvraag activeert Execution Management SIGTERM; de bij Create opgeslagen handler wordt door ExecutionClient aangeroepen [SWS_EM_02562] [SWS_EM_02003] [SWS_EM_02577].

Sequentiediagram: de kRunning-melding verbindt het procesperspectief met de lifecycle-tracking van EM en het starten van de alive-supervisie door PHM SWS EM §7.3.1 “Execution State” SWS PHM §7.2 “Supervision of Supervised Entities”.

Grenzen van verantwoordelijkheid

De client meldt alleen de eigen status; Execution Management is wel verantwoordelijk voor start, stop en OS-configuratie, maar niet voor de lopende scheduling van het proces, die bij het besturingssysteem ligt [SWS_EM_01401] SWS Operating System Interface §7.1.2 “Process Handling” SWS Operating System Interface §7.1.3 “Scheduling Policies”.

Voor de eerste statusmelding

Maak de client eenmaal per Reporting Process aan en registreer een terminatiehandler. De tweede instantie is een violation, omdat de toewijzing van een SIGTERM aan meerdere handlers dubbelzinnig zou zijn [SWS_EM_02582].

Daarna deterministisch melden

Meld kRunning na de initialisatie, voordat service discovery de opstart onbepaald kan verlengen SWS EM §7.3.1 “Execution State”.

Running op het juiste moment melden

Roep de methode alleen aan voor het eigen reporting process en meld kRunning na afronding van de initialisatie. Dan mag Execution Management de process state instellen op Running [SWS_EM_01401] [SWS_EM_01004].

Verkeerd gebruik voorkomen

Een non-reporting process mag deze methode niet gebruiken; een kRunning-melding buiten de process state Starting is een ongeldige transitie [SWS_EM_01403] [SWS_EM_02243].
