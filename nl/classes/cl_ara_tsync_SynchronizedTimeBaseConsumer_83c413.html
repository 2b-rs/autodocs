klasse ara::tsync::SynchronizedTimeBaseConsumer

[SWS_TS_01000] Upstream: RS_TS_00030

class SynchronizedTimeBaseConsumer final {...};

Class SynchronizedTimeBaseConsumer is the access to the synchronized timebase referenced by the InstanceSpecifier. It allows to get the current time_point, the rate deviation, the current status and the received user data

Consumer: synchronisierte Zeit sicher lesen

Der Consumer stellt einer Anwendung eine konfigurierte synchronisierte Zeitbasis bereit. GetTimeWithStatus() liefert nicht nur die aktuelle Global Time, sondern zusammen mit lokaler Zeit, Synchronisationsstatus, Leap-Status und User Data einen zusammenhängenden Snapshot. SWS Time Synchronization §7.1 “General Overview” SWS Time Synchronization §7.2 “Normal Operation” [SWS_TS_14218]

Die Consumer-Abfrage liefert Zeit und Status zusammen; Statuswechsel können gemeldet werden. Quelle: SWS Time Synchronization §7.2 “Normal Operation”; [SWS_TS_14218]; [SWS_TS_00701].

Status statt Zeitwert allein auswerten

Vor dem Vertrauen auf den Zeitwert sollte die Anwendung SynchronizationStatus beachten: initial nicht synchronisiert, synchronisiert, Gateway-basiert oder Timeout. Die Rateabweichung ist separat lesbar und beträgt vor einer Berechnung zunächst 0.0. {sws(TS,"SWS_TS_00202")} {sws(TS,"SWS_TS_00032")}

Notifier mit klarer Ownership betreiben

Status-, Synchronisations-, Leap-, Präzisions- und Validierungsnotifier ergänzen das Polling. Pro Kategorie ist nur ein Notifier registrierbar; eine weitere Registrierung ersetzt den vorherigen. Für Präzisionsdaten wird nicht gepuffert, daher muss der Callback bei Bedarf selbst entkoppeln. {sws(TS,"SWS_TS_00701")} {sws(TS,"SWS_TS_01018")}
