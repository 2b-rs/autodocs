Class representing Function Group State defined in meta-model (ARXML). An instance of this class will represent Function Group State defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

Configuratiewaarde voor de procesverzameling

FunctionGroupState representeert een geconfigureerde status van een Function Group. Een dergelijke status bepaalt welke modelprocessen bij activering ervan moeten draaien; per Function Group is precies één status actief SWS EM §7.4.3 “Function Group State”.

Gebruik in een transition-request

State Management stelt doelstatussen samen uit FunctionGroup en statusnamen en geeft ze door aan StateClient::SetState. Execution Management beëindigt niet meer benodigde processen en start daarna de voor de doelstatus voorziene processen in de vereiste volgorde SWS EM §7.4.5 “State Transition”.

Statusdiagram: Off is de verplichte initiële status; de actieve status is projectspecifiek geconfigureerd [SWS_EM_01110] SWS EM §7.4 “State Management”. Interpretatie: De weergave abstraheert van concrete Manifest-statusnamen.
