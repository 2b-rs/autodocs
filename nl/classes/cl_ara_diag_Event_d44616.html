Beperkingen & foutafhandeling

Voor GetDTCNumber levert de manager DiagErrc::kNoSuchDTC als er geen event-naar-UDS-DTC-toewijzing bestaat; de opvragingen kunnen daarnaast kServiceNotAvailable melden. De meeste statusopvragingen en de notifier zijn niet thread-safe; GetDTCNumber is thread-safe. [SWS_DM_01269] [SWS_DM_00653] [SWS_DM_00649] [SWS_DM_00654] [SWS_DM_00655] [SWS_DM_00656] [SWS_DM_00650]

Functionele context De manager actualiseert eventstatusbits op basis van via Monitor::ReportMonitorAction gemelde testresultaten. Bij kResetTestFailed wordt alleen het bit kTestFailed teruggezet. Bij herstart van een toegewezen OperationCycle zet de manager kTestFailedThisOperationCycle op nul en kTestNotCompletedThisOperationCycle op één; ook het wissen van een DTC zet vastgelegde eventstatusbits terug. [SWS_DM_01025] [SWS_DM_01026] [SWS_DM_01027] [SWS_DM_01028]

De retourwaarde van GetTestComplete is precies dan waar wanneer de FDC -128 of 127 bedraagt. De statusinformatie levert de API telkens via ara::core::Future. [SWS_DM_00655] [SWS_DM_00649] [SWS_DM_00654] [SWS_DM_00656]
