klasse ara::core::Result< void, E >

[SWS_CORE_00801] Upstream: RS_AP_00130

Specialization of class Result for "void" values The implementation shall flag the condition E != ara::core::ErrorCode as a compile error

Gebruiksdoel

ara::core::Result<void,E> is de specialisatie voor synchrone bewerkingen zonder retourwaarde. Zij bevat ofwel void-succes ofwel een fout; E moet ara::core::ErrorCode zijn. [SWS_CORE_00801] [SWS_CORE_10600]

Aanmaak & levenscyclus

Een succesvolle toestand ontstaat door de standaardconstructor of FromValue(), een fouttoestand door foutconstructie of FromError(). Copy- en move-operaties zijn beschikbaar en voorwaardelijk noexcept. [SWS_CORE_00821] [SWS_CORE_00831] [SWS_CORE_00823] [SWS_CORE_00824] [SWS_CORE_00834] [SWS_CORE_00835] [SWS_CORE_00825] [SWS_CORE_00826] [SWS_CORE_00841] [SWS_CORE_00842]

Samenwerking met andere klassen

HasValue(), Error(), Err(), Bind() en Resolve() maken status- en foutverwerking mogelijk. Resolve() voert de doorgegeven functie alleen uit in de foutstatus; Value() bestaat ter ondersteuning van generieke programmering. [SWS_CORE_00851] [SWS_CORE_00857] [SWS_CORE_00868] [SWS_CORE_00870] [SWS_CORE_00867] [SWS_CORE_00855]

Beperkingen & foutafhandeling

Foutentoegang zonder bevatte fout en waardetoegang zonder bevatte waarde zijn gespecificeerd als violation. ValueOrThrow() kan opwerpen. [SWS_CORE_13010] [SWS_CORE_13009] [SWS_CORE_00866]

functie Bind [SWS_CORE_00870] Upstream: RS_AP_00130

template <typename F> auto Bind (F &&f) const -> <see below>;

Call the given Callable, and return a new Result with the result of the call. The Callable is expected to be compatible to one of these two interfaces: • Result<XXX, E> f(); • XXX f(); meaning that the Callable either returns a Result<XXX, E> or a XXX directly, where XXX can be any type that is suitable for use by class Result. The return type of this function is decltype(f()) for a template argument F that returns a Result type, and it is Result<decltype(f()), E> for a template argument F that does not return a Result type. If this instance does not contain a value, a new Result<XXX, E> is still created and returned, with the original error contents of this instance being copied into the new instance
