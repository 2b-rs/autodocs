klasse ara::diag::DynamicAccessListDiagServiceBuilder::ByteRange

[SWS_DM_01182] Upstream: RS_Diag_04251

class ByteRange final {...};

Represents a single byte value closed range. Type alias of a single diagnostic service pattern element in the DynamicAccessList

Headerbestand#include "ara/diag/dynamic_access_list_diag_service_builder.h"
Forwarding-header#include "ara/diag/diag_fwd.h"

User Guide Door AI gegenereerd

Automatisch gegenereerde beschrijving, inhoudelijk afgeleid van de gerefereerde AUTOSAR-R25-11-specificatie-elementen — geen officiele AUTOSAR-tekst. Bewijs: [SWS_…]-verwijzingen.

Gebruiksdoel ByteRange modelleert een gesloten waardebereik van een enkele byte en is een element van een DynamicAccessList-service-patroon. De constructor neemt minimum en maximum aan; GetMin en GetMax leveren respectievelijk de onder- en bovengrens om te matchen. [SWS_DM_01182] [SWS_DM_01183] [SWS_DM_01189] [SWS_DM_01190]

Het type is kopieer- en verplaatsbaar en kopieer- en move-toewijsbaar. Constructies zijn thread-safe; toewijzingen en destructor zijn niet thread-safe. [SWS_DM_01184] [SWS_DM_01185] [SWS_DM_01186] [SWS_DM_01187] [SWS_DM_01188]
