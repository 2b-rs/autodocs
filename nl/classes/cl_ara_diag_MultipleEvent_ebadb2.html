klasse ara::diag::MultipleEvent

[SWS_DM_01704] Upstream: RS_Diag_04151

class MultipleEvent final {...};

Class to implement operations on diagnostic Events with the multiple event interfaces.

User Guide Door AI gegenereerd

Automatisch gegenereerde beschrijving, inhoudelijk afgeleid van de gerefereerde AUTOSAR-R25-11-specificatie-elementen — geen officiele AUTOSAR-tekst. Bewijs: [SWS_…]-verwijzingen.

Gebruiksdoel

MultipleEvent bundelt bewerkingen op meerdere diagnose-events. Via een EventHandleType zijn eventstatus, debounce-status, fault detection counter en het bijbehorende DTC-nummer op te vragen. [SWS_DM_01704] [SWS_DM_01707] [SWS_DM_01710] [SWS_DM_01711] [SWS_DM_01709] Een statuswijzigings-notifier kan per event-handle worden geregistreerd; een volgende registratie vervangt de vorige. [SWS_DM_01708]

Levenscyclus & ownership

De instance wordt aangemaakt voor een PortPrototype van de DiagnosticMultipleEventInterface. [SWS_DM_01705] Ze is niet kopieerbaar, toewijsbaar of verplaatsbaar; de betreffende bewerkingen zijn verwijderd. [SWS_DM_02070] [SWS_DM_02067] [SWS_DM_02069] [SWS_DM_02068] De destructor is noexcept. [SWS_DM_01706]

Beperkingen & foutafhandeling

Event-handles worden uit gemapte events toegekend, bij ontbrekende overrideId in alfabetische volgorde vanaf 0x010000. [SWS_DM_01733] Handles die niet bij deze instantie horen, leiden tot kInvalidArgument. [SWS_DM_01734] Bevragingen kunnen daarnaast kNoSuchDTC of kServiceNotAvailable opleveren; hun thread-safety hangt van ConcurrencyType af. [SWS_DM_01709] [SWS_DM_01710] [SWS_DM_01711] De notifierregistratie is niet thread-safe. [SWS_DM_01708]

De DTC-query houdt rekening met de gevraagde DTCFormatType. [SWS_DM_01709] Voor een event zonder toegewezen DTC kan zij kNoSuchDTC leveren. [SWS_DM_01709] Alle querybewerkingen zijn exception-safe. [SWS_DM_01707] [SWS_DM_01709] [SWS_DM_01710] [SWS_DM_01711] De registratie van de statusnotifier kan bij ongeldige argumenten een fout opleveren. [SWS_DM_01708]

De klasse is final en dus niet bedoeld voor overerving. [SWS_DM_01704] De constructor zelf is exception-safe en thread-safe. [SWS_DM_01705]

De aanroep is wat betreft concurrency gebonden aan de in de constructor doorgegeven ConcurrencyType: per configuratie moet de implementatie thread-safe of niet thread-safe worden uitgevoerd en is volgens het contract exception-safe.

Foutafhandeling

Mogelijke fouten/terugmeldingen:

  • DiagErrc::kInvalidArgument: e.g. kPreFailed with internal debouncing
  • DiagErrc::kNoSuchDTC: er bestaat geen gemapte DTC voor het opgevraagde event.
  • DiagErrc::kServiceNotAvailable: The call cannot be executed, because essential DM functionality is currently not available.
