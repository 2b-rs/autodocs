klasse apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

Gebruiksdoel

UdsMessage representeert een UDS-bericht tussen de generieke DM-kern resp. UdsTransportProtocolMgr en een concrete implementatie van UdsTransportProtocolHandler. Het object stelt geheugen voor UDS-aanvragen en -antwoorden beschikbaar. [SWS_DM_00291]

Creatie & eigendom

Instanties met geoptimaliseerde resourcetoewijzing worden uitsluitend door de DM-kern gemaakt; een Protocol Handler mag ze lezen en schrijven, maar dient ze niet zelf te maken. De defaultconstructor is daarom protected. Bij een geaccepteerde indicatie heeft een UdsMessagePtr een geldig object met een capaciteit van ten minste één byte; aanvankelijk is de door GetPayload() geleverde buffer leeg. [SWS_DM_09012] [SWS_DM_00385] [SWS_DM_00392]

Samenwerking met andere klassen

De niet-constante payload-toegang levert een beschrijfbare ByteSpan; de constante toegang levert de UDS-gegevens vanaf SID zonder schrijftoegang. Een transport-handler vult na succesvolle indicatie de payload vanaf SID tot de capaciteit of tot het einde van het ontvangen bericht. Bron, doel en fysieke respectievelijk functionele doeladressoort zijn via getters beschikbaar; AddMetaInfo() vult metadata aan. [SWS_DM_00301] [SWS_DM_00300] [SWS_DM_00388] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00302]

Beperkingen

De destructor is virtueel, standaard geimplementeerd en exception-safe. De adres-getters zijn reentrant; beide payload-toegangen en AddMetaInfo() zijn aangeduid als niet thread-safe. [SWS_DM_09010] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00300] [SWS_DM_00301] [SWS_DM_00302]
