Gebruiksdoel

ara::core::Array<T, N> implementeert het type std::array voor een tijdens compile-time door N vastgelegd aantal elementen [SWS_CORE_01201]. Het biedt pointer-iterators, groottebevragingen en voorwaartse/achterwaartse iteratie [SWS_CORE_01212] [SWS_CORE_01262] [SWS_CORE_01250] [SWS_CORE_01254].

Levenscyclus & ownership

De specificatie declareert de impliciete speciale ledenfuncties niet expliciet; hun semantiek volgt std::array [SWS_CORE_01201]. fill() en swap() zijn afhankelijk van de eigenschappen van T voorwaardelijk exception-safe [SWS_CORE_01241] [SWS_CORE_01242].

Samenwerking met andere klassen

Via data() is een pointer naar de elementen beschikbaar; bij grootte nul wordt nullptr geleverd [SWS_CORE_01271] [SWS_CORE_01272]. Het type ondersteunt de tuple_element-integratie; een index I >= N is een compile-time-fout [SWS_CORE_01281] [SWS_CORE_01285].

Beperkingen & foutafhandeling

at() werpt bij n >= size() een IsoStdOutOfRangeViolation in plaats van std::out_of_range op [SWS_CORE_01273] [SWS_CORE_01274]. front() en back() op een leeg array zijn compile-time-fouten [SWS_CORE_01267] [SWS_CORE_01268] [SWS_CORE_01269] [SWS_CORE_01270].
