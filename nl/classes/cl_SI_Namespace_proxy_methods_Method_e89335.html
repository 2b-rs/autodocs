Initiate a method call (ClientServerOperation. fireAndForget ==FALSE). The method call will return immediately. The caller’s selection of a synchronous or asynchronous behavior to get the method output is achieved by the use of the returned ara::core::Future object which is used to query for method completion and result including possible error.

De noexcept functie-aanroepoperator <SI-Namespace>::proxy::methods::<Method>::operator start een methodeaanroep (ClientServerOperation.fireAndForget==FALSE) en keert onmiddellijk terug [SWS_CM_00196]. Via het teruggegeven ara::core::Future<Output> kan de aanroeper naar keuze synchroon of asynchroon wachten op de afhandeling van de aanroep inclusief eventuele fouten. De methode is exception-safe.

Foutafhandeling

Bij mislukking bevat de Future een van de volgende fouten: ComErrc::kCommunicationFailure bij een verhelpbare communicatie- of secure-communication-fout van de netwerkbinding; een communicatie-timeout kan daarbij een onveilige status aan serverzijde achterlaten; ComErrc::kUnknownApplicationError (rollback-semantiek), wanneer de externe dienst een niet-geconfigureerde applicatiefout meldt; ComErrc::kServiceNotAvailable (rollback-semantiek), wanneer de eerder via OfferService() aangeboden dienst niet meer beschikbaar is; ComE2EErrc::kUnspecifiedE2EError (rollback-semantiek), wanneer de externe dienst een niet-gespecificeerde E2E-fout meldt; ComErrc::kMinimumSendIntervalViolationError (rollback-semantiek), wanneer een verzendaanvraag sneller plaatsvindt dan de geconfigureerde minimumSendInterval.

Concurrency & beperkingen

Bij contractschending werpt de implementatie een InsufficientPermissionsViolation, wanneer de grant-enforcement-controle de aanroep weigert.
