klasse ara::log::Logger

[SWS_LOG_00172] Upstream: RS_LT_00003, RS_LT_00046

class Logger final {...};

Represents a logger context. The Logging framework defines contexts which can be seen as logger instances within one Application process or process scope. The contexts have the following properties: • Context ID • Description of the Context ID • Default log level A context will be automatically registered against the Logging backend during creation phase, as well as automatically deregistered during process shutdown phase. So the end user does not care for the objects life time. To ensure such housekeeping functionality, a strong ownership of the logger instances needs to be ensured towards the Logging framework. This means that the Application process are not supposed to call the Logger constructor themselves. The user is not allowed to create a Logger object by himself. Logger context needs to be created by one of the ara::log::CreateLogger functions.

Logger als Kontext und Filtergrenze

Ein Logger steht für einen registrierten Log-Kontext. Der konfigurierbare Schwellwert wirkt als Reporting-Filter: Nur Nachrichten mit mindestens dieser Schwere werden verarbeitet; die Kontexttrennung kann zur Laufzeit angepasst werden. SWS Log and Trace §7.1 “Necessary Parameters and Initialization” [SWS_LOG_00254]

Nachrichtenform wählen

Log() und LogWith() adressieren modellierte Nachrichten; ihre Argumentliste muss zum Nachrichtenmodell passen. LogDebug() bis LogFatal() sowie WithLevel() liefern dagegen einen LogStream für nicht modellierte Inhalte. SWS Log and Trace §7.2 “Log Messages” [SWS_LOG_00204] [SWS_LOG_00131]

Der Vorabtest vermeidet die Vorbereitung gefilterter Nachrichten. Quelle: SWS Log and Trace §7.1 “Necessary Parameters and Initialization”; [SWS_LOG_00007].

Aufwand vor dem Aufbau begrenzen

Bei aufwendiger Nutzlastvorbereitung sollte IsEnabled(level) zuerst geprüft werden. Das entspricht dem vorgesehenen Ressourcen-Schutzziel, weil später ohnehin gefilterte Inhalte nicht erst formatiert werden müssen. {sws(LOG,"SWS_LOG_00007")} {sws(LOG,"SWS_LOG_00070")}
