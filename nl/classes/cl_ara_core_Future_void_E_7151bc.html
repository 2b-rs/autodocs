Gebruiksdoel

ara::core::Future<void, E> is de specialisatie voor asynchrone operaties zonder waarde. Het fouttype moet ara::core::ErrorCode zijn; samen met Promise maakt de specialisatie de thread-safe en exceptionvrije latere bevraging van een succes of fout mogelijk. [SWS_CORE_06221] [SWS_CORE_10800]

Levenscyclus & ownership

Kopiëren is verhinderd (=delete), verplaatsen is mogelijk. De destructor geeft de Shared State op; na GetResult(), get() of then() is de oorspronkelijke Future ongeldig. Samenwerking met andere klassen

GetResult() blokkeert tot aan de voltooiing en levert een niet-triggerende Result<void,E>. De then()-overload met Executor gebruikt de uitvoeringscontext daarvan voor de continuation. [SWS_CORE_06236] [SWS_CORE_06237]

Beperkingen & foutafhandeling

Een opgegeven bijbehorende Promise wordt teruggegeven als FutureErrc::kBrokenPromise. is_ready() geeft aan of latere get()-, GetResult()- en wachtaanroepen niet blokkeren. [SWS_CORE_06236] [SWS_CORE_06232]

functie then [SWS_CORE_06231] Upstream: RS_AP_00130

template <typename F> auto then (F &&func) noexcept -> Future< <see below> >;

Create a new Future with the content returned by func when passed the Result of this Future. func may be called in the context of this call or in the context of Promise::set_value() or Promise::SetError() or somewhere else. valid() == false on the original future object immediately after it returns. The Callable input argument "func" takes a Result<void,E> object as parameter. This will be the Result obtained via GetResult from the Future instance itself, on which .then() is being called. The Result is passed to func as an rvalue expression. The return type of then depends on the return type of func (aka continuation). Let U be the return type of the continuation (i.e. a type equivalent to std::invoke_result_ t<std::decay_t<F>,Result<void,E>>). • If U is Future<T2,E2> for some types T2, E2, then the return type of then() is Future<T2,E2>. This is known as implicit Future unwrapping. • If U is Result<T2,E2> for some types T2, E2, then the return type of then() is Future<T2,E2>. This is known as implicit Result unwrapping. • Otherwise it is Future<U,E>. Continuations that are registered with Future::then() are registered in the Future F that Future::then() returns. No such continuation shall be executed after the destructor of the Future F returns. A continuation that is already being executed shall run to completion. Note: that means that the destructor of Future might block until the currently running continuation has been completed. The continuation shall not throw, except for the purpose of implementing a Violation. Note: Exceptions can be used within the continuation, however if they do not realize a Violation, they must not escape the continuation. Note: Users who need to propagate information from closures’ exceptions should translate them to an error and return an ara::core::Result or ara::core::Future from the continuation with the error stored in it.
