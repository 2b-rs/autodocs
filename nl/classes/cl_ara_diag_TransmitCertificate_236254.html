klasse ara::diag::TransmitCertificate

[SWS_DM_01961] Upstream: RS_Diag_04251

class TransmitCertificate {...};

Class to implement the subfunction TransmitCertificate (29 04) of UDS service Authentication as interface to application. This class implements a so called generic interface, where the application has means to handle one ore more certificateEvaluationId transferred certificates.

Gebruiksdoel

ara::diag::TransmitCertificate beeldt de UDS-subfunctie TransmitCertificate (0x29/0x04) af als applicatie-interface. De applicatie kan een of meer overgedragen certificaten aan de hand van de certificateEvaluationId verwerken [SWS_DM_01961].

Aanmaak & vernietiging

De instantie wordt gegenereerd met de InstanceSpecifier van een DiagnosticTransmitCertificateInterface en een ConcurrencyType [SWS_DM_01962]. Het type is niet kopieerbaar of verplaatsbaar; de virtuele destructor is noexcept [SWS_DM_01964] [SWS_DM_01963] [SWS_DM_01966] [SWS_DM_01965] [SWS_DM_01967].

Samenwerking met andere klassen

Offer() activeert het doorsturen van aanvragen door de DM, StopOffer() deactiveert dit [SWS_DM_01969] [SWS_DM_01970]. De af te leiden methode Process() ontvangt de 16-bits CEID, de certificaatgegevens, MetaInfo en een CancellationHandler. De semantiek van de certificaatverwerking berust bij de applicatie [SWS_DM_01968] [SWS_DM_01248].

Beperkingen & foutafhandeling

De threadsafety van Process() wordt bepaald door de bij de constructor gekozen ConcurrencyType [SWS_DM_01962] [SWS_DM_01968]. De cancellation handler staat het opvragen van de afbreekstatus en het registreren van een notifier toe. Voor negatieve UDS-antwoorden moet een passende fout uit DiagUdsNrcErrc gebruikt worden [SWS_DM_01968]. Een herhaald aanbod kan DiagOfferErrc::kAlreadyOffered leveren [SWS_DM_01969].

functie Process [SWS_DM_01968] Upstream: RS_Diag_04251

virtual ara::core::Future< void > Process (std::uint16_t certificate EvaluationId, ara::core::Span< ara::core::Byte const > certificate Data, const MetaInfo &metaInfo, CancellationHandler cancellation Handler) noexcept=0;

This method is used to process certificates send by a diagnostic tester, via the UDS subfunction TransmitCertificate inside the application. There is no specific semantics for the certificate and it is left to the application to process the received certificate and derive the needed actions.
