Rol in het model

Buffer bezit de voor host en accelerator benodigde geheugenresource. Directe gegevensoverdracht wordt niet via buffer-methoden, maar via accessor-objecten uitgedrukt.

Bronverwijzing

Voor de geheugenbeschrijving werkt buffer met SWS SHWA §7.5 — Memory Allocation Specifics. De toegang wordt volgens SWS SHWA §7.3 — Data Access Specifics uitgedrukt via accessor.
