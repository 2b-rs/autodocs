Context

De klasse ara::shwa::Event dient in de module shwa van het AUTOSAR Adaptive Platform als synchronisatieprimitieve voor asynchrone werkprocessen. Deze kapselt de uitvoeringsstatus van taken in en stelt aanroepende applicaties in staat om gericht te synchroniseren op de voltooiing van afhankelijke of geassocieerde taken ([AP_SWS_SHWA_00604], [AP_SWS_SHWA_00605]). Interpretatie: De klasse fungeert vermoedelijk als schakel tussen de gebruikende softwarecomponent en de onderliggende hardwareversneller respectievelijk het taakuitvoeringssysteem om asynchroon geïnitieerde rekenstappen te coördineren.

Naast individuele synchronisatie op afzonderlijke events staat de interface ook de verwerking van meerdere eventobjecten in groepsverband toe. Door het uitlezen van eventlijsten via GetWaitList() ([AP_SWS_SHWA_00603]) evenals statische verzamelwachtfuncties voor vectoren van events ([AP_SWS_SHWA_00605]) interacteert de klasse met containerstructuren (ara::core::Vector<Event>). Daarmee kunnen afhankelijkheden worden geaggregeerd voordat vervolgoperaties op gewijzigde gegevensbestanden voortbouwen.

Levenscyclus

Instanties van ara::shwa::Event worden aangemaakt via het statische factory-pad Event::Create() ([AP_SWS_SHWA_00602]). Deze functie is thread-veilig (thread-safe), garandeert uitzonderingsveiligheid (exception safe) en levert bij succes het geïnitialiseerde object via een ara::core::Result<Event> af aan de aanroeper. Door de kwalificatie als final is overerving of polymorfe specialisatie van de klasse uitgesloten.

Tijdens runtime zijn instanties onderworpen aan specifieke gelijktijdigheidsregels: noch het opvragen van afhankelijkheidslijsten via GetWaitList() ([AP_SWS_SHWA_00603]), noch de synchronisatie-aanroepen Wait() ([AP_SWS_SHWA_00604], [AP_SWS_SHWA_00605]) of WaitFor() ([AP_SWS_SHWA_00606]) zijn thread-veilig (not thread-safe). Parallelle toegang tot dezelfde instantie vanuit meerdere threads vereist derhalve verplicht synchronisatie aan de applicatiezijde.

Wat het foutgedrag betreft, bieden de synchronisatiemethoden geen rollback-semantiek (no_rollback_semantics): bij mislukkingen of time-outs tijdens de taakverwerking moeten de door de taken geraakte gegevens worden beschouwd als op onbedoelde wijze gewijzigd ([AP_SWS_SHWA_00604], [AP_SWS_SHWA_00605], [AP_SWS_SHWA_00606]).

Gebruikspad

Een typisch gebruikstraject omvat de instantiëring, het beheer van afhankelijkheden en de blokkerende of tijdgebonden synchronisatie:

  1. Aanmaak: De applicatie initialiseert een eventobject via Event::Create() ([AP_SWS_SHWA_00602]).
  2. Afhankelijkheidscontrole: Interpretatie: Via GetWaitList() ([AP_SWS_SHWA_00603]) kan de applicatie vermoedelijk gekoppelde events opvragen om de status van eventketens te bepalen.
  3. Synchronisatie: De applicatie blokkeert tot de voltooiing van de openstaande operaties:
    • Instantiegerelateerd via de parameterloze methode Wait() ([AP_SWS_SHWA_00604]).
    • Collectief via de statische overload Wait(eventList) voor meerdere events ([AP_SWS_SHWA_00605]).
    • Tijdgebonden via de statische methode WaitFor(ms) ([AP_SWS_SHWA_00606]), indien onbeperkt blokkeren moet worden vermeden. Interpretatie: De statische signatuur zonder event-parameter wacht vermoedelijk globaal op in de actuele context ingeplande taken.
  4. Resultaatevaluatie: De geretourneerde ara::core::Result<void> zal opgetreden fouten controleren voordat nuttige gegevens verder worden gebruikt.

Sequentiediagram: typische aanroepvolgorde voor het aanmaken en synchroniseren van events. Bronnen: [AP_SWS_SHWA_00602], [AP_SWS_SHWA_00604], [AP_SWS_SHWA_00606].

Foutscenario's

Alle interfaces van ara::shwa::Event gebruiken ara::core::Result voor foutsignalering en werpen geen C++-exceptions (noexcept, exception safe). De volgende foutcodes uit ShwaErrorCode zijn gespecificeerd:

  • ShwaErrorCode::kRuntime: Algemene runtimefout die kan optreden bij het aanmaken ([AP_SWS_SHWA_00602]), het opvragen van de lijst ([AP_SWS_SHWA_00603]) en bij wachtaanroepen ([AP_SWS_SHWA_00604], [AP_SWS_SHWA_00605], [AP_SWS_SHWA_00606]).
  • ShwaErrorCode::kEventInvalidOperation: Signaleert een niet-toegestane operatie op het event, zoals foutief of niet-toegestaan wachten ([AP_SWS_SHWA_00603], [AP_SWS_SHWA_00604], [AP_SWS_SHWA_00605], [AP_SWS_SHWA_00606]).
  • ShwaErrorCode::kTaskExecutionFailure: Geeft aan dat er tijdens de uitvoering van de aan het event gekoppelde taak een fout is opgetreden ([AP_SWS_SHWA_00604], [AP_SWS_SHWA_00605], [AP_SWS_SHWA_00606]).
  • ShwaErrorCode::kTimedOut: Specifiek voor WaitFor(ms) ([AP_SWS_SHWA_00606]), indien het opgegeven tijdsinterval afloopt voordat de taak is voltooid.

<p>Wat het foutgedrag betreft, bieden de synchronisatiemethoden geen rollback-semantiek (<em>no_rollback_semantics</em>): bij mislukkingen of time-outs tijdens de taakverwerking moeten de door de taken geraakte gegevens worden beschouwd als op onbedoelde wijze gewijzigd (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00604" href="../spec/record.html?id=AP_SWS_SHWA_00604">[AP_SWS_SHWA_00604]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00605" href="../spec/record.html?id=AP_SWS_SHWA_00605">[AP_SWS_SHWA_00605]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00606" href="../spec/record.html?id=AP_SWS_SHWA_00606">[AP_SWS_SHWA_00606]</a>).</p>

<h4>Gebruikspad</h4>
<p>Een typisch gebruikstraject omvat de instantiëring, het beheer van afhankelijkheden en de blokkerende of tijdgebonden synchronisatie:</p>
<ol>
<li><strong>Aanmaak:</strong> De applicatie initialiseert een eventobject via <code>Event::Create()</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00602" href="../spec/record.html?id=AP_SWS_SHWA_00602">[AP_SWS_SHWA_00602]</a>).</li>
<li><strong>Afhankelijkheidscontrole:</strong> Interpretatie: Via <code>GetWaitList()</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00603" href="../spec/record.html?id=AP_SWS_SHWA_00603">[AP_SWS_SHWA_00603]</a>) kan de applicatie vermoedelijk gekoppelde events opvragen om de status van eventketens te bepalen.</li>
<li><strong>Synchronisatie:</strong> De applicatie blokkeert tot de voltooiing van de openstaande operaties:
<ul>
<li>Instantiegerelateerd via de parameterloze methode <code>Wait()</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00604" href="../spec/record.html?id=AP_SWS_SHWA_00604">[AP_SWS_SHWA_00604]</a>).</li>
<li>Collectief via de statische overload <code>Wait(eventList)</code> voor meerdere events (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00605" href="../spec/record.html?id=AP_SWS_SHWA_00605">[AP_SWS_SHWA_00605]</a>).</li>
<li>Tijdgebonden via de statische methode <code>WaitFor(ms)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00606" href="../spec/record.html?id=AP_SWS_SHWA_00606">[AP_SWS_SHWA_00606]</a>), indien onbeperkt blokkeren moet worden vermeden. Interpretatie: De statische signatuur zonder event-parameter wacht vermoedelijk globaal op in de actuele context ingeplande taken.</li>
</ul>
</li>
<li><strong>Resultaatevaluatie:</strong> De geretourneerde <code>ara::core::Result&lt;void&gt;</code> zal opgetreden fouten controleren voordat nuttige gegevens verder worden gebruikt.</li>
</ol>

<h4>Foutscenario's</h4>
<p>Alle interfaces van <code>ara::shwa::Event</code> gebruiken <code>ara::core::Result</code> voor foutsignalering en werpen geen C++-exceptions (<code>noexcept</code>, <em>exception safe</em>). De volgende foutcodes uit <code>ShwaErrorCode</code> zijn gespecificeerd:</p>
<ul>
<li><code>ShwaErrorCode::kRuntime</code>: Algemene runtimefout die kan optreden bij het aanmaken (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00602" href="../spec/record.html?id=AP_SWS_SHWA_00602">[AP_SWS_SHWA_00602]</a>), het opvragen van de lijst (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00603" href="../spec/record.html?id=AP_SWS_SHWA_00603">[AP_SWS_SHWA_00603]</a>) en bij wachtaanroepen (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00604" href="../spec/record.html?id=AP_SWS_SHWA_00604">[AP_SWS_SHWA_00604]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00605" href="../spec/record.html?id=AP_SWS_SHWA_00605">[AP_SWS_SHWA_00605]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00606" href="../spec/record.html?id=AP_SWS_SHWA_00606">[AP_SWS_SHWA_00606]</a>).</li>
<li><code>ShwaErrorCode::kEventInvalidOperation</code>: Signaleert een niet-toegestane operatie op het event, zoals foutief of niet-toegestaan wachten (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00603" href="../spec/record.html?id=AP_SWS_SHWA_00603">[AP_SWS_SHWA_00603]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00604" href="../spec/record.html?id=AP_SWS_SHWA_00604">[AP_SWS_SHWA_00604]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00605" href="../spec/record.html?id=AP_SWS_SHWA_00605">[AP_SWS_SHWA_00605]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00606" href="../spec/record.html?id=AP_SWS_SHWA_00606">[AP_SWS_SHWA_00606]</a>).</li>
<li><code>ShwaErrorCode::kTaskExecutionFailure</code>: Geeft aan dat er tijdens de uitvoering van de aan het event gekoppelde taak een fout is opgetreden (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00604" href="../spec/record.html?id=AP_SWS_SHWA_00604">[AP_SWS_SHWA_00604]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00605" href="../spec/record.html?id=AP_SWS_SHWA_00605">[AP_SWS_SHWA_00605]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00606" href="../spec/record.html?id=AP_SWS_SHWA_00606">[AP_SWS_SHWA_00606]</a>).</li>
<li><code>ShwaErrorCode::kTimedOut</code>: Specifiek voor <code>WaitFor(ms)</code> (<a class="spec-record-ref" data-req="AP_SWS_SHWA_00606" href="../spec/record.html?id=AP_SWS_SHWA_00606">[AP_SWS_SHWA_00606]</a>), indien het opgegeven tijdsinterval afloopt voordat de taak is voltooid.</li>
</ul>
