klasse ara::core::ErrorCode

[SWS_CORE_00501] Upstream: RS_AP_00130, RS_AP_00140

class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

Verwendungszweck

ErrorCode kapselt einen domänenspezifischen rohen Fehlerwert, eine Referenz auf den zugehörigen ErrorDomain und optionale herstellerspezifische Zusatzdaten. Der Typ ist ein Literal Type. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

Erzeugung & Zusammenspiel

Er kann aus einem Fehler-Enum oder aus Wert, Fehlerdomäne und Zusatzdaten erzeugt werden. Domain(), Value(), SupportData() und Message() geben seine Bestandteile beziehungsweise den Fehlertext zugänglich; ThrowAsException() bestimmt den passenden Ausnahmetyp über die Domäne. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

Einschränkungen & Fehlerbehandlung

Vergleiche berücksichtigen ausschließlich Fehlerwert und Fehlerdomäne, nicht die Zusatzdaten. ErrorCode und seine Member dürfen unabhängig von ara::core::Initialize und Deinitialize verwendet werden. [SWS_CORE_10301] [SWS_CORE_15002]

Fehlerkontext statt allgemeiner Fehlerwerte

Ein ErrorCode verbindet einen typisierten Fehlerwert mit seinem ErrorDomain-Kontext; optional kann er Nachricht und herstellerspezifische Zusatzinformation tragen. ARA-Schnittstellen verwenden ihn innerhalb von Result für rückgewinnbare Fehler. EXP InterfacesGuidelines §3.1.2 “Result” EXP ARAComAPI §4.7 “Error Handling”

Herstellerspezifische Fehlercodes benötigen eigene ErrorDomains; portable, stack-neutrale Anwendungen sollen solche Domains als allgemeinen Default-Fall behandeln. EXP InterfacesGuidelines §3.1.5 “Standardized vs Vendor-specific ErrorCodes”

Kollaborationsdiagramm: ErrorCode bezieht Kontext und Nachricht aus seiner Domain; die Ausnahmeumwandlung ist der explizite Exception-Pfad. Quellen: EXP InterfacesGuidelines §3.1.2 “Result” RS General §4.1.3 “The use of noexcept”.

Typausgelöschter Fehlerwert

Die SWS beschreibt ErrorCode als Fehlerwert mit Domain-Kontext: Der domänenspezifische Code wird für den einheitlichen Transport in einen ganzzahligen Wert typausgelöscht; zusätzliche Supportdaten können weitergegeben werden. Vergleiche berücksichtigen Wert und Domain, nicht die Supportdaten. SWS Core §7.2 “Error handling” SWS Core §7.2.5.1 “ErrorCode” [SWS_CORE_10301] [SWS_CORE_10302]

ara::core::ErrorCode::ThrowAsException löst laut [SWS_CORE_00519] diesen Fehler als Ausnahme aus: Die Funktion ermittelt den zu diesem ErrorCode passenden Ausnahmetyp gemäß [SWS_CORE_10953] und wirft ihn, wobei die geworfene Ausnahme diesen ErrorCode enthält.
