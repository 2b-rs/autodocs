Bestandsmetadata in context

FileInfo stelt metadata van een bestand in de File Storage beschikbaar. De informatie vult de bestandsoperaties aan en ondersteunt bijvoorbeeld beheer- of diagnosepaden, zonder zelf bestandsinhoud te lezen. SWS Persistency §7.4 “File Storage specific Features”

Betrouwbaar gebruik

Vraag metadata op via de verantwoordelijke FileStorage en behandel deze als momentopname: parallel lopende bestandsbewerkingen kunnen de geobserveerde toestand veranderen. Voor inhoudelijke beslissingen moet de aanroeper de bijbehorende resultaat- en foutafhandeling van de opvraging evalueren.

Constanten / variabelen

  • accessTime Time in nanoseconds since midnight 1970-01-01 UTC at which the file was last accessed.
  • creationTime Time in nanoseconds since midnight 1970-01-01 UTC at which the file was created.
  • fileCreationState Information on how and by whom the file was created.
  • fileModificationState Information on how and by whom the file was last modified.
  • modificationTime Time in nanoseconds since midnight 1970-01-01 UTC at which the file was last modified.
