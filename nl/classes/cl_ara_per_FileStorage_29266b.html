Rol in het opslagmodel

FileStorage representeert een geconfigureerde, directory-achtige verzameling benoemde bestanden. Bestanden kunnen voorgeïnstalleerd zijn, ontstaan bij een update of tijdens runtime worden aangemaakt en verwijderd. SWS Persistency §7.4 “File Storage specific Features”

Van storage naar bestand

Na OpenFileStorage controleren FileExists en GetAllFileNames de voorraad. OpenFileReadOnly, OpenFileWriteOnly en OpenFileReadWrite maken de passende exclusieve accessor aan; de omgang met inhoud ligt dan bij ReadAccessor, WriteAccessor of ReadWriteAccessor.

Schrijven, vergrendelen en terugzetten

Een geopende accessor bindt het bestand exclusief. Plan daarom DeleteFile, ResetFile en RecoverFile niet parallel aan een actieve toegang. Resourcelimieten evenals redundante en backupgegevens tellen mee bij de bezette storage-opslag. SWS Persistency §7.2.6 “Resource Management Concepts”

Foutstrategie

Controleer elke Result, met name bij toegangsrechten, fysiek geheugen, integriteit, versleuteling, authenticatie, opslagruimte en resourceconflicten. Een herstel is geen vervanging voor een functionele consistentiecontrole. SWS Persistency §7.2.4 “Redundancy Concepts”

Een file storage beheert een verzameling benoemde bestanden; de accessor heeft exclusief eigendom van de concrete geopende toegang. Bronnen: SWS Persistency §7.4 “File Storage specific Features” [SWS_PER_00113].

Herstel is best effort; in geval van fouten kan een report de betrokken storage of elementen benoemen. Bron: SWS Persistency §7.2.4 “Redundancy Concepts”. Deels interpretatie: de activiteitenreeks vat meerdere toegestane redundantieprocedures samen.

ara::core::Result< void > ResetFile (ara::core::StringView fileName) noexcept;

Resets a file of this File Storage to its initial content. ResetFile allows to reset a single file to its initial content. If the file is currently not available in the File Storage, it is re-created. Afterwards, the file will appear in both cases as if it was newly installed from the current Target Configuration. It will fail with kResourceBusy when the file is currently open, and with kInitValueNotAvailable when neither Application Design nor Target Configuration define an initial content for the file.
