klasse ara::core::SteadyClock

[SWS_CORE_06401] Upstream: RS_AP_00130

class SteadyClock final {...};

This clock represents a monotonic clock. The time points of this clock cannot decrease as physical time moves forward and the time between ticks of this clock is constant.

Headerbestand#include "ara/core/steady_clock.h"
Forwarding-header#include "ara/core/core_fwd.h"

ara::core::SteadyClock representeert een monotone klok: de tijdspunten ervan gaan bij voortschrijdende fysieke tijd niet terug en de tickduur is constant [SWS_CORE_06401]. Ze voldoet aan de eisen voor TrivialClock; haar epoch is de systeemstart [SWS_CORE_11800] [SWS_CORE_11801].

De tijdwaarde gebruikt std::int64_t als representatie, std::nano als periode en std::chrono::time_point<SteadyClock, duration> als tijdstip [SWS_CORE_06412] [SWS_CORE_06413] [SWS_CORE_06414]. is_steady is steeds true; now() is noexcept, exception-safe en thread-safe [SWS_CORE_06431] [SWS_CORE_06432].

Methodeoverzicht

  • static time_point now () noexcept; Return a time_point representing the current value of the clock.

Typealiassen

  • duration std::chrono::duration<rep, period>
  • period A std::ratio type representing the tick period of the clock, in seconds .
  • rep An arithmetic type representing the number of ticks in the clock’s duration .
  • time_point std::chrono::time_point<ara::core::SteadyClock>

Constanten / variabelen

  • is_steady steady clock flag, always true
