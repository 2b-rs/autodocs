klasse ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

Context

De klasse ara::per::ReadAccessor dient binnen de module per (Persistency) van de Adaptive Platform voor het sequentieel lezen van persistente bestandsinhoud. Zij erft virtueel over van FileAccessor en stelt leestoegang zowel in de binaire modus als in de tekstmodus beschikbaar. Via deze abstractie benaderen applicaties opgeslagen gegevens zonder de fysieke opslag direct te hoeven beheren. De interface biedt granulaire bewerkingen voor de inspectie van afzonderlijke tekens of bytes, evenals methoden voor het bloksgewijs of volledig uitlezen van inhoud en regels.

Levenscyclus

De levenscyclus van een instantie van ara::per::ReadAccessor is onderworpen aan strikte vereisten met betrekking tot creatie en resourcebeheer:

  • Creatie: de default-constructor is conform [SWS_PER_00461] expliciet verwijderd (delete). Een directe parameterloze initialisatie door de applicatie is daarmee uitgesloten. Interpretatie: een instantie wordt vermoedelijk via bovenliggende mechanismen van de persistente bestandstoegang gecreëerd en aan de aanroeper overgedragen.
  • Vernietiging: de destructor ~ReadAccessor() is virtueel gedeclareerd, voorzien van override en gedefinieerd als noexcept [SWS_PER_00417]. Bij de vernietiging van het object worden de onderliggende leesdescriptors vrijgegeven.
  • Gelijktijdigheid en exceptieveiligheid: alle methoden van de klasse zijn gespecificeerd als not thread-safe (bijv. [SWS_PER_00417], [SWS_PER_00419]). Gelijktijdige toegang van meerdere threads tot dezelfde instantie vereist daarom externe synchronisatie. Tegelijkertijd zijn alle leesoperaties exceptieveilig (exception safe) en gedeclareerd als noexcept; fouten worden via het retourtype ara::core::Result getransporteerd.

Gebruikspad

Het gebruik van ara::per::ReadAccessor maakt onderscheid tussen inspectieve operaties (zonder positiewijziging) en consumerende leesoperaties (waarbij de bestandswijzer opschuift):

  • Inspectie (peeking): met behulp van PeekByte() [SWS_PER_00418] of PeekChar() [SWS_PER_00167] kan het byte resp. teken op de actuele positie worden opgevraagd zonder dat de leespositie wordt gewijzigd. Beide methoden zijn gedeclareerd als const.
  • Stapsgewijs lezen: via GetByte() [SWS_PER_00419] resp. GetChar() [SWS_PER_00168] wordt het actuele element gelezen en schuift de interne wijzer één positie op.
  • Deelsgewijs lezen (binaire modus): met ReadBinary(std::uint64_t n) [SWS_PER_00422] wordt een gedefinieerd aantal bytes in een ara::core::Vector<ara::core::Byte> ingelezen. Wordt het einde van het bestand bereikt vóór het bereiken van n, dan bevat de vector minder bytes dan gevraagd. De parameterloze overload ReadBinary() [SWS_PER_00421] leest alle resterende bytes tot aan het einde van het bestand in.
  • Tekstmodus en regelverwerking: met behulp van ReadText(std::uint64_t n) [SWS_PER_00165] of ReadText() [SWS_PER_00420] worden tekenreeksen in een ara::core::String gelezen. Voor gestructureerde tekstbestanden maakt ReadLine(char delimiter = '\n') [SWS_PER_00119] het regelgewijs uitlezen tot aan het scheidingsteken mogelijk. Het scheidingsteken is niet opgenomen in de resulterende string. Als de leespositie binnen een Unicode-codepoint ligt, kan de geretourneerde tekst onvolledige codepoints bevatten.

Foutscenario's

Alle lees- en inspectiemethoden retourneren een ara::core::Result. Bij een opgetreden fout treedt een rollback-semantiek in werking: de actuele leespositie van het bestand wordt in geval van een fout niet gewijzigd (onder meer gespecificeerd in [SWS_PER_00419], [SWS_PER_00168], [SWS_PER_00421], [SWS_PER_00119]). De volgende fouttoestanden uit het foutdomein PerErrc zijn gespecificeerd:

  • PerErrc::kEof: wordt geretourneerd wanneer de actuele leespositie zich al aan het einde van het bestand bevindt of het bestand leeg is ([SWS_PER_00419], [SWS_PER_00168], [SWS_PER_00418], [SWS_PER_00167], [SWS_PER_00421], [SWS_PER_00422], [SWS_PER_00119], [SWS_PER_00165], [SWS_PER_00420]).
  • PerErrc::kPhysicalStorageFailure: treedt op wanneer de fysieke leestoegang tot het opslagmedium mislukt ([SWS_PER_00420]).
  • PerErrc::kValidationFailed: geeft aan dat de integriteit of validiteit van de opgeslagen gegevens niet kan worden gewaarborgd ([SWS_PER_00419]).
  • PerErrc::kEncryptionFailed: wordt geretourneerd wanneer de ontsleuteling van de opgeslagen payload mislukt ([SWS_PER_00419]).
  • PerErrc::kAuthenticationFailed: treedt op wanneer de verificatie van de Message Authentication Code (MAC) van de opgeslagen gegevens mislukt ([SWS_PER_00419]).

ReadLine functie

Reads a complete line of characters into a String, advancing the current position accordingly. The end of the line is demarcated by the delimiter, or by "\\n" (ASCII 0x0a) if that parameter is omitted. The delimiter itself is not included in the returned String. Only Unicode code points with one character (code unit) can be used as delimiters. The returned string may start with an incomplete Unicode code point in case the current read position is in the middle of a code point. If the end of the file is reached, the remaining characters are returned and the current position is set to the end of the file. In case of an error, the current position is not changed.

ReadText functie 2

Reads a number of characters into a String, starting from the current position. The returned string may start and/or end with incomplete Unicode code points in case the current read position and/or the last read character (code unit) is in the middle of a code point. The current position is advanced accordingly. If the end of the file is reached, the number of returned characters can be less than the requested number, and the current position is set to the end of the file. In case of an error, the current position is not changed.

<li><strong>Tekstmodus en regelverwerking:</strong> met behulp van <code>ReadText(std::uint64_t n)</code> <a class="spec-record-ref" data-req="SWS_PER_00165" href="../spec/record.html?id=SWS_PER_00165">[SWS_PER_00165]</a> of <code>ReadText()</code> <a class="spec-record-ref" data-req="SWS_PER_00420" href="../spec/record.html?id=SWS_PER_00420">[SWS_PER_00420]</a> worden tekenreeksen in een <code>ara::core::String</code> gelezen. Voor gestructureerde tekstbestanden maakt <code>ReadLine(char delimiter = '\n')</code> <a class="spec-record-ref" data-req="SWS_PER_00119" href="../spec/record.html?id=SWS_PER_00119">[SWS_PER_00119]</a> het regelgewijs uitlezen tot aan het scheidingsteken mogelijk. Het scheidingsteken is niet opgenomen in de resulterende string. Als de leespositie binnen een Unicode-codepoint ligt, kan de geretourneerde tekst onvolledige codepoints bevatten.</li>
</ul>
