Specification of CAN Interface AUTOSAR CP R20-11 called, the CanIf evaluates the CAN L-PDU for acceptance and prepares the L-SDU for later access by the upper communication layers. The CanIf notifies upper layer modules about this asynchronous event using <User_RxIndication>() (see sub- subsection 8.6.3.3 <User_RxIndication>, [SWS_CANIF_00012]), if configured and if this CAN L-PDU is successfully detected and accepted for further processing.
