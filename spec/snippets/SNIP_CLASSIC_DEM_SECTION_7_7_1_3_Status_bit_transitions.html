The parameter DemEventConfirmationThreshold controls the operation cycle in which the confirmedDTC bit is set based on the first occurrence of the failure. The confirmedDTC bit is always set to 1 when the fault occurs, but the operation cycle in which this is done is depending on the use case. The value is relevant for OEM and legislated requirements on setting the confirmedDTC bit from 0 to 1.
