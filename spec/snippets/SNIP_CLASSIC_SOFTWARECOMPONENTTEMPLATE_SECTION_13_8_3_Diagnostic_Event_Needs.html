13.8.3 Diagnostic Event Needs The meta-classes DiagnosticEventManagerNeeds is used to define requirements in order to configure the Diagnostic Event Manager Service. An SwcInternalBehavior may provide several DiagnosticEventManagerNeeds elements that define the mappings for the general diagnostic event manager behavior (for the terms related to the AUTOSAR Diagnostic Event Manager see [39]).
