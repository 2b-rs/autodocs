5.2.1.2.2 Mapping via SystemSignalGroups The VariableDataPrototype that is referenced by dataElement can be typed by an ApplicationDataType or by an ImplementationDataType. This type decides which reference is used within the SenderRecRecordElementMapping and SenderRecArrayElementMapping. Composite DataPrototypes may nest within composite VariableDataPrototypes. Each element typed by a primitive data type of such nested composite VariableDataPrototype can be mapped to one SystemSignal of a SystemSignalGroup. Please note that not every single element typed by a primitive data type needs to be mapped to a SystemSignal since a partial mapping is also supported that maps a subset of elements of the composite data type to separate SystemSignals of a SystemSignalGroup. The mapping between the SystemSignal and the VariableDataPrototype is provided in the SenderReceiverToSignalGroupMapping (see Figure 5.22).
