3. Dynamisches Verhalten & Sequenzablauf

Als statisches Konfigurationsmetamodell bildet das Diagramm keinen direkten Laufzeit-Callflow ab, steuert jedoch deterministisch die statischen und dynamischen Codepfade zur Laufzeit:

  • Bedingte Code-Generierung (Pre-Compile Switches): Parameter wie UdpNmDevErrorDetect, UdpNmVersionInfoApi, UdpNmUserDataEnabled und UdpNmComControlEnabled steuern #ifdef-Kapselungen in der BSW-Implementierung. Ist ein Feature false, entfallen die entsprechenden API-Endpunkte vollständig aus der Symboltabelle.
  • Callback-Steuerung an obere Schichten:
  • UdpNmStateChangeIndEnabled == true triggert synchrone Aufrufe von Nm_StateChangeNotification() bei Zustandsübergängen im UdpNm-Zustandsautomaten (z. B. Repeat Message State $\rightarrow$ Normal Operation).
  • UdpNmPduRxIndicationEnabled == true leitet eingehende UDP-Pakete aus dem Socket-Adapter (SoAd) nach PDU-Validierung synchron via Nm_PduRxIndication() weiter.

4. Normative Relevanz & Entwickler-Hinweise

  • Speicher- und Laufzeitoptimierung (Footprint):
  • UdpNmDevErrorDetect muss im Serienstand (Production Code) auf false stehen, um Det-Aufrufe (Det_ReportError) und Laufzeit-Overhead im Socket-Pfad zu eliminieren.
  • Deaktivierte Indikations-Switches (StateChangeInd, PduRxInd, RemoteSleepInd) reduzieren den Kontextwechsel- und Inter-Module-Call-Overhead in Richtung des generischen Nm-Moduls signifikant.
  • Dimensionierung von Datenstrukturen:
  • UdpNmNumberOfChannels bestimmt direkt die Dimensionierung statischer Channel-Control-Arrays im RAM (UdpNm_ChannelContext[UdpNmNumberOfChannels]). Ein Wert $> 1$ erfordert kanalindizierte Zugriffe über NetworkHandleType.
  • Architekturkonsistenz & Abhängigkeiten:
  • UdpNmComUserDataSupport = true erzwingt eine konsistente PDU-Konfiguration in den Modulen Com, PduR und SoAd. Direkte API-Pufferzugriffe (UdpNm_SetUserData) werden hierbei typischerweise durch PduR-Routingpfade ersetzt.
  • Wenn Partial Networking genutzt wird (UdpNmDynamicPncToChannelMappingSupport), muss sichergestellt sein, dass das übergeordnete ComM und Nm entsprechend für Partial Networking (PNC) parametriert sind.
