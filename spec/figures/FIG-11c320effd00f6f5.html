1. Diagrammtyp & Architektur-Kontext

  • Klassifikation: UML-Klassendiagramm / Metamodell-Instanziierungsdiagramm der AUTOSAR ECU Configuration Parameter Definition (ECUC-Metamodell).
  • Architektur-Einordnung: Microcontroller Abstraction Layer (MCAL, Layer 1) gem. AUTOSAR Classic Platform Release R2.1 (referenzierte Treiberspezifikation ADC Driver v2.1.4).
  • Technischer Zweck: Formale Definition des Root-Containers und der Sub-Container-Hierarchie zur Konfiguration des BSW-Moduls Adc (Analog-to-Digital Converter). Definiert die Schemavorgabe für Konfigurationseditoren und Codegeneratoren (BSW-Generatoren).

2. Komponenten, Entitäten & Schnittstellen

  • Moduldefinition (Wurzelelement):
    • Adc : ModuleDef:
      • Multiplizität: lowerMultiplicity = 0, upperMultiplicity = 1 (optionales Modul auf ECU-Ebene, jedoch als Singleton ausgelegt).
  • Container-Struktur (ParamConfContainerDef via Komposition +container):
    • AdcPublishedInformation:
      • Container für unveränderliche, hersteller- und derivatespezifische Metadaten des Treibers (Read-only für Anwender, bereitgestellt durch den MCAL-Vendor).
      • Enthaltene Parameter (+parameter via Komposition):
        • AdcMaxChannelResolution : IntegerParamDef – Maximale Hardware-Wandlerauflösung in Bit (z. B. 10 Bit, 12 Bit).
        • AdcChannelValueSigned : BooleanParamDef – Definiert, ob Wandlungsergebnisse vorzeichenbehaftet (sint) oder vorzeichenlos (uint) formatiert werden.
        • AdcGroupFirstChannelFixed : BooleanParamDef – Hardware-/Treibereinschränkung, ob der erste Kanal einer Kanalgruppe fest vorgegeben sein muss.
    • AdcGeneral:
      • Modulglobale, hardware- und gruppenübergreifende Konfigurationsparameter (z. B. Pre-Compile-Schalter wie AdcDevErrorDetect, AdcDeInitApi, AdcVersionInfoApi).
    • AdcConfigSet:
      • Konfigurationsbehälter für hardware- und kanalbezogene Parametersätze (z. B. Kanäle, Conversion Groups, HW-/SW-Triggerquellen, Clock-Prescaler).
      • Tag/Attribut: multipleConfigurationContainer = TRUE – Ermöglicht die Definition mehrerer Konfigurationssätze für Post-Build-Selectable-Szenarien (PB).

3. Dynamisches Verhalten & Sequenzablauf (falls zutreffend)

Als statisches Konfigurationsmetamodell bildet das Diagramm keine Laufzeit-Zustände ab; der Ablauf bezieht sich auf die Generierungs- und Initialisierungsphase:

  1. Konfigurations- und Generierungszeit (Tooling):
    • Der BSW-Konfigurator liest AdcPublishedInformation zur statischen Validierung der Kanalkonfiguration und Wertebereiche ein.
    • AdcGeneral steuert die Makro-Generierung (Adc_Cfg.h).
    • AdcConfigSet instanziiert die Initialisierungsdatenstrukturen (Adc_PBcfg.c bzw. Adc_Lcfg.c).
  2. Laufzeit-Initialisierung (BSW Execution):
    • Über EcuM (ECU State Manager) oder ein modulspezifisches Init-Routing wird Adc_Init(ConfigPtr) aufgerufen.
    • Aufgrund von multipleConfigurationContainer = TRUE referenziert ConfigPtr eine der zur Build-Zeit erzeugten Varianten des AdcConfigSet.

4. Normative Relevanz & Entwickler-Hinweise

  • API- und Typverträge (AdcPublishedInformation):
    • AdcChannelValueSigned steuert unmittelbar die C-Typdefinition von Adc_ValueGroupType (Mapping auf sint16 vs. uint16 in Adc.h).
    • AdcMaxChannelResolution limitiert die maximale Gruppen- bzw. Kanalabtastauflösung; Treiberentwickler müssen hierüber Skalierungs- oder Shift-Operationen für Applikationspuffer absichern.
    • AdcGroupFirstChannelFixed = TRUE erzwingt Einschränkungen in der Gruppen-Konfiguration (Kanalzuordnung muss hardwarekonform an Index 0 angebunden werden).
  • Post-Build-Fähigkeit:
    • Das Flag multipleConfigurationContainer = TRUE verpflichtet den Treiber-Implementierer dazu, Adc_Init() mit flexiblen Zeigerstrukturen auf Adc_ConfigType zu unterstützen, anstatt feste ROM-Konstanten vorauszusetzen.
  • Integrations- und Tooling-Vorgaben:
    • Der Container AdcPublishedInformation darf in Integrations-Tools nicht editierbar sein (Vendor Delivery).
    • Die Kardinalität 0..1 von Adc verbietet Mehrfachinstanziierungen desselben Treibers im selben Core/OS-Partition-Kontext.
