1. Diagrammtyp & Architektur-Kontext

UML-Aktivitätsdiagramm zur Darstellung des sequenziellen Verhaltens bei Heilung (Healing), Ereignisspeicherallokation und Alterung (Aging) zur Löschung von Diagnoseereignissen im Dem (AUTOSAR Classic Platform).

2. Komponenten, Entitäten & Schnittstellen

  • Startknoten mit annotierter PreCondition-Notiz: PreCondition: PDTC == 1 [OCY completed && TFTOC==0 && TNCTOC==0] => PDTC 1->0
  • Entscheidungsknoten:
    • WarningIndicatorOn-CriteriaFulfilled?
    • Event memory entry exists?
  • Zusammenführungsknoten vor try to allocate an event memory entry
  • Aktionen:
    • Process healing mit Schleifenübergang
    • WarningIndicatorOff-CriteriaFulfilled!
    • try to allocate an event memory entry (mit Notiz: Limitation (based on Dem requirements SWS_Dem_00823 & SWS_Dem_00019))
    • Process aging mit Schleifenübergang
    • Delete event memory entry, CDTC=0
  • Endknoten
  • Status- und Steuerungsflags: PDTC (PendingDTC), CDTC (ConfirmedDTC), OCY (Operation Cycle), TFTOC (TestFailedThisOperationCycle), TNCTOC (TestNotCompletedThisOperationCycle), HealingCounter, DemAgingCycleCounterThreshold

3. Dynamisches Verhalten & Sequenzablauf

  1. Der Ablauf beginnt am Startknoten unter der Vorbedingung, dass bei PDTC == 1 und Abschluss des Betriebszyklus mit TFTOC==0 && TNCTOC==0 das PendingDTC-Bit zurückgesetzt wird (PDTC 1->0).
  2. Prüfung WarningIndicatorOn-CriteriaFulfilled?:
    • Bei [TRUE] erfolgt der Übergang zu Process healing [SWS_Dem_00533]. Solange [OCY completed && TFTOC==0 && TNCTOC==0] eintritt, wird HealingCounter-- dekrementiert (Selbstschleife). Tritt ein Fehler auf ([TFTOC==1]), bricht der Ablauf sofort zum Endknoten ab. Sobald [HealingCounter==0] erreicht ist, wird WarningIndicatorOff-CriteriaFulfilled! ausgeführt.
    • Bei [FALSE] wird der Heilungsprozess umgangen und direkt zum nachfolgenden Merge-Knoten verzweigt.
  3. Vom Merge-Knoten führt der Pfad zur Verzweigung Event memory entry exists?:
    • Tritt hierbei [TFTOC==1] auf, endet der Ablauf direkt am Endknoten.
    • Ist kein Eintrag vorhanden ([FALSE]), wird über die Aktion try to allocate an event memory entry versucht, einen Eintrag zu belegen, und der Pfad kehrt vor die Existenzprüfung zurück.
    • Ist der Eintrag vorhanden ([TRUE]), wird Process aging angestoßen.
  4. Während Process aging:
    • Bei fehlerfreiem Zyklusabschluss ([Aging cycle completed && TNCTOC==0]) wird der Alterungszähler weitergezählt (count further AgingCounter).
    • Tritt [TFTOC==1] auf, wird die Alterung abgebrochen und zum Endknoten verzweigt.
    • Erreicht der Zähler den Schwellwert ([DemAgingCycleCounterThreshold reached]), wird Delete event memory entry, CDTC=0 ausgeführt und der Ablauf am Endknoten beendet.

4. Normative Relevanz & Entwickler-Hinweise

Verbindliche Spezifikation der Zyklenüberwachung für Healing und Aging im Dem. Die Kriterien für OCY-Abschluss, TFTOC und TNCTOC müssen für jeden Zählerschritt ausgewertet werden. Ein erneutes Auftreten des Fehlers (TFTOC==1) bricht Healing bzw. Aging unmittelbar ab. Die Allokation eines Ereignisspeichereintrags bei Nichtexistenz unterliegt den referenzierten Einschränkungen aus SWS_Dem_00823 und SWS_Dem_00019. Die Löschung des Eintrags bedingt zwingend das Rücksetzen des ConfirmedDTC (CDTC=0).
