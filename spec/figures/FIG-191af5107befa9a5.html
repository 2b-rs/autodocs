1. Diagrammtyp & Architektur-Kontext

Aktivitäts- und Methodikdiagramm der AUTOSAR-Methodik (Classic Platform) zur Darstellung des Methodikschritts „Generate Base ECU Configuration“. Es zeigt die an dieser Aktivität beteiligten Rollen, Eingangs- und Ausgangs-Arbeitsergebnisse (Work Products / Artefakte) sowie deren Zuordnungs- und Kontrollbeziehungen.

2. Komponenten, Entitäten & Schnittstellen

  • Aktivität / Task:
    • Generate Base Ecu Configuration (mittiges Prozess-Symbol).
  • Rolle / Akteur:
    • ECU Integrator (Rollen-Symbol oberhalb der Aktivität).
  • Eingangsartefakte:
    • Diagnostic ECU Extract (Briefumschlag-Symbol links oben): Multiplizität 0..1, Stereotyp «input».
    • ECU Extract (Briefumschlag-Symbol links Mitte): Multiplizität 1, Stereotyp «input».
    • BSW Module Description (abgeschnitten als BSW Module..., Briefumschlag-Symbol links unten): Multiplizität 1..*, Stereotyp «input».
  • Ausgangsartefakt:
    • ECU Configuration Values (Dokument-Symbol rechts): Multiplizität 1, Stereotyp «output».
  • Beziehungen:
    • ECU Integrator führt die Aktivität aus («performs», Kardinalität 1).
    • Gerichtete Kontroll-/Datenflusspfeile definieren Input- und Output-Rollen der Artefakte.

3. Dynamisches Verhalten & Sequenzablauf

  1. Der ECU Integrator führt die Aktivität Generate Base Ecu Configuration durch.
  2. Für die Erzeugung der Basis-Konfiguration werden obligatorisch genau ein ECU Extract (1) und mindestens eine BSW Module Description (1..*) sowie optional ein Diagnostic ECU Extract (0..1) als Eingangsdaten herangezogen.
  3. Als Resultat wird genau ein Satz an Konfigurationswerten (ECU Configuration Values, Kardinalität 1) generiert.

4. Normative Relevanz & Entwickler-Hinweise

Die optionale Einbindung des Diagnostic ECU Extract (Kardinalität 0..1) erlaubt die frühzeitige Berücksichtigung von Diagnose-Konfigurationsanforderungen bereits bei der Generierung der Basis-ECU-Konfiguration. Weiterhin bleiben das Vorhandensein genau eines ECU Extract und mindestens einer BSW-Modulbeschreibung zwingende Voraussetzungen zur Generierung der initialen ECU Configuration Values.
