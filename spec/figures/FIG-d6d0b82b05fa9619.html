1. Diagrammtyp & Architektur-Kontext

  • Diagrammtyp: AUTOSAR ECU Configuration (ECUC) Parametermodell / UML-Klassendiagramm zur Spezifikation der Konfigurationsmetadaten.
  • Architektur-Kontext: Konfiguration des MCAL-Moduls Eth (Ethernet Driver) gemäß AUTOSAR_SWS_EthernetDriver (Release R23-11). Es definiert die Ingress-Warteschlangen (Hardware-Empfangspfade / RX Queues) eines Ethernet-Controllers mit erweitertem Multi-Kriterien-Sorting (MAC-Zieladresse, VLAN-ID, VLAN-Priorität, EtherType), konfigurierbaren Sortierprioritäten sowie Puffer-, Interrupt- und Handler-Verwaltung.

2. Komponenten, Entitäten & Schnittstellen

  • Container-Hierarchie & Multiplizitäten:
    • EthCtrlConfigIngress (EcucParamConfContainerDef): Root-Container für die Empfangskonfiguration eines Controllers. Aggregiert zwei Sub-Container:
      • EthCtrlConfigIngressQueue (+subContainer, Multiplizität 0..*)
      • EthCtrlConfigIngressQueueSortingPriority (+subContainer, Multiplizität 0..1)
    • EthCtrlConfigIngressQueue (EcucParamConfContainerDef): Konfiguration einer Hardware-RX-Queue. Aggregiert einen Sub-Container:
      • EthCtrlConfigIngressQueueSortingType (+subContainer, Multiplizität 0..1)
  • Parameter von EthCtrlConfigIngressQueue:
    • EthCtrlConfigIngressQueueIdx (EcucIntegerParamDef): Queue-Index (min = 0, max = 255, withAuto = true, symbolicNameValue = true).
    • EthCtrlConfigIngressQueueBufTotal (EcucIntegerParamDef): Gesamtzahl reservierter RX-Puffer (min = 0, max = 65535).
    • EthCtrlConfigIngressQueueBufLenByte (EcucIntegerParamDef): Pufferlänge in Byte (min = 0, max = 65535).
    • EthCtrlEnableIngressQueueInterrupt (EcucBooleanParamDef): Aktivierung des Interrupt-Betriebs für die Queue.
    • EthCtrlConfigIngressQueueOverwriteEnabled (EcucBooleanParamDef): Steuerung des Pufferüberlaufs (defaultValue = false).
    • EthCtrlConfigIngressQueueHandlerFunction (EcucFunctionNameDef): Optionaler RX-Handler-Funktionsname (lowerMultiplicity = 0, upperMultiplicity = 1).
  • Parameter von EthCtrlConfigIngressQueueSortingType (EcucParamConfContainerDef):
    • EthCtrlIngressQueueSortingMacDestinationAssignment (EcucStringParamDef): Ziel-MAC-Filter (minLength = 17, maxLength = 17, Multiplizität 0..1, regularExpression = ([0-9a-fA-F]{2}:){5}[0-9a-fA-F]{2}).
    • EthCtrlIngressQueueSortingVlanIdAssignment (EcucIntegerParamDef): VLAN-ID-Filter (min = 0, max = 65535, Multiplizität 0..1).
    • EthCtrlIngressQueueSortingVlanPriorityAssignment (EcucIntegerParamDef): VLAN-PCP-Filter (min = 0, max = 7, Multiplizität 0..8).
    • EthCtrlIngressQueueSortingEtherTypeAssignment (EcucIntegerParamDef): EtherType-Filter (min = 0, max = 65535, Multiplizität 0..1).
  • Parameter von EthCtrlConfigIngressQueueSortingPriority (EcucParamConfContainerDef):
    • SortingPriorityMacDestinationAssignment (EcucIntegerParamDef): Priorität der MAC-Auswertung (min = 0, max = 3).
    • SortingPriorityVlanIdAssignment (EcucIntegerParamDef): Priorität der VLAN-ID-Auswertung (min = 0, max = 3).
    • SortingPriorityVlanPriorityAssignment (EcucIntegerParamDef): Priorität der VLAN-PCP-Auswertung (min = 0, max = 3).
    • SortingPriorityEtherTypeAssignment (EcucIntegerParamDef): Priorität der EtherType-Auswertung (min = 0, max = 3).

3. Dynamisches Verhalten & Sequenzablauf

Als statisches ECUC-Metamodell determiniert das Diagramm folgendes Ingress-Verhalten:

  1. Frame Ingress & Kriterien-Prüfung: Eingehende Ethernet-Frames werden hardwareseitig anhand von MAC-Zieladresse, VLAN-ID, VLAN-Priorität (PCP) und EtherType klassifiziert.
  2. Prioritätsgewichtung: Bei Mehrfachtreffern oder Filterkonflikten bestimmt EthCtrlConfigIngressQueueSortingPriority über die Werte 0–3 die Rangfolge der Filterkriterien.
  3. Queue-Dispatch: Erfüllt ein Frame die Kriterien von EthCtrlConfigIngressQueueSortingType, wird er in die zugehörige Queue (EthCtrlConfigIngressQueueIdx) geleitet.
  4. Puffer- und Überlaufbehandlung: Der Frame belegt RX-Deskriptoren bis zur konfigurierten Puffergröße EthCtrlConfigIngressQueueBufLenByte. Bei Puffererschöpfung steuert EthCtrlConfigIngressQueueOverwriteEnabled, ob ältere Daten verworfen oder überschrieben werden.
  5. Signalisierung: Der Empfang wird je nach Konfiguration über Interrupts (EthCtrlEnableIngressQueueInterrupt) oder dedizierte Handler-Callbacks (EthCtrlConfigIngressQueueHandlerFunction) an die Treiberlogik bzw. EthIf gemeldet.

4. Normative Relevanz & Entwickler-Hinweise

  • DRAFT-Status: Als DRAFT in R23-11 gekennzeichnet (Figure 10.8).
  • Entwickler-Hinweise: Die Ingress-Konfiguration wurde gegenüber R22-11 von einer reinen VLAN-PCP-Zuordnung auf ein differenziertes Regelsystem mit Priorisierung nach MAC, VLAN und EtherType sowie Interrupt-/Overwrite-Steuerung erweitert; Metadaten zur Header-Konfigurationsklasse wurden im Diagramm entfernt.
