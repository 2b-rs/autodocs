1. Diagrammtyp & Architektur-Kontext

AUTOSAR-ECUC-Metamodell-Diagramm (UML-Klassendiagramm) kombiniert mit einer tabellarischen Spezifikationsübersicht. Dargestellt ist die Konfigurationsstruktur des Moduls EthSwt (Ethernet Switch Driver) für die Funktion Per-stream Filtering and Policing (PSFP gemäß IEEE 802.1Qci). Das Diagramm spezifiziert die Konfigurationscontainer, Sub-Container, Multiplizitäten sowie Konfigurationsparameter und deren Wertebereiche.

2. Komponenten, Entitäten & Schnittstellen

Die Struktur gliedert sich in folgende Entitäten:

  • Tabellarische Spezifikation:
    • SWS-Item: [ECUC_EthSwt_00154]
    • Container-Name: EthSwtPSFP (Parent: EthSwtStreamIdentification, Status: draft)
    • Multiplizitätskonfigurationsklassen: VARIANT-PRE-COMPILE, VARIANT-LINK-TIME, VARIANT-POST-BUILD (alle aktiv / X, Post-Build Variant Multiplicity: true).
    • Enthaltene Container: EthSwtFlowMetering (Multiplizität 0..1), EthSwtStreamGate (Multiplizität 1).
  • UML-Struktur:
    • EthSwtStreamIdentification (EcucParamConfContainerDef): Übergeordneter Container.
    • EthSwtPSFP (EcucParamConfContainerDef, Multiplizität 0..*): Sub-Container von EthSwtStreamIdentification.
    • EthSwtStreamGate (EcucParamConfContainerDef, Multiplizität 1..1): Sub-Container von EthSwtPSFP.
      • Parameter EthSwtStreamGateIPV (EcucIntegerParamDef): Multiplizität 0..1, min = 0, max = 7.
    • EthSwtFlowMetering (EcucParamConfContainerDef, Multiplizität 0..1): Sub-Container von EthSwtPSFP.
      • Parameter EthSwtFlowMeteringCIR (EcucIntegerParamDef): min = 0, max = 4294967295.
      • Parameter EthSwtFlowMeteringCBS (EcucIntegerParamDef): min = 0, max = 255.
      • Parameter EthSwtFlowMeteringEIR (EcucIntegerParamDef): min = 0, max = 4294967295.
      • Parameter EthSwtFlowMeteringEBS (EcucIntegerParamDef): min = 0, max = 255.
      • Parameter EthSwtFlowMeterCF (EcucBooleanParamDef).
      • Parameter EthSwtFlowMeteringColorMode (EcucEnumerationParamDef): Multiplizität 1..1 mit den Literalen (EcucEnumerationLiteralDef) ETHSWT_COLOR_BLIND und ETHSWT_COLOR_AWARE.

3. Dynamisches Verhalten & Sequenzablauf

Als statisches Konfigurationsmetamodell beschreibt das Diagramm keinen sequenziellen Ablauf oder dynamische Zustandsübergänge. Es definiert die statischen Abhängigkeiten zur Konfigurations- und Generierungszeit für das Ethernet-Switch-PSFP-Regelwerk.

4. Normative Relevanz & Entwickler-Hinweise

Normativ bindend für Konfigurationswerkzeuge (BSW-Generatoren) des Ethernet Switch Drivers:

  • EthSwtPSFP und seine Kind-Container sind als Entwurf (atp.Status=draft) markiert.
  • Post-Build-Variabilität ist über Multiplicity Configuration Class unterstützt (true für Pre-Compile, Link und Post-Build).
  • Die Konfiguration verlangt bei Instanziierung von EthSwtPSFP genau ein EthSwtStreamGate und optional maximal ein EthSwtFlowMetering.
  • Farbmodus (EthSwtFlowMeteringColorMode) ist ein Pflichtparameter innerhalb des Flow-Metering-Containers.
