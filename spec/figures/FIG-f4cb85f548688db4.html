1. Diagrammtyp & Architektur-Kontext

Bit- und Byte-Layout eines SOME/IP-Serialisierungs-Tags (Tag-basiertes Member-Encoding) im Kontext des AUTOSAR SOME/IP-Protokolls. Das Diagramm spezifiziert die Bitfeldbelegung innerhalb des zweibändigen Tag-Headers sowie die Anordnung nachfolgender optionaler Längenfelder und Nutzdaten im serialisierten Bytestrom.

2. Komponenten, Entitäten & Schnittstellen

  • Byte n (Tag High Byte):
  • reserved: 1 Bit (Bit 7, MSB).
  • Wire Type: 3 Bit (Bits 6–4).
  • Data ID (Higher Sig. Part): 4 Bit (Bits 3–0).
  • Byte n + 1 (Tag Low Byte):
  • Data ID (Lower Sig. Part): 8 Bit (Bits 7–0).
  • Byte n + 2 ... (Optionales Längenfeld):
  • Length Field (8/16/32 bit): Variabel breites Längenfeld mit Bitindizes 7/15/31 bis 0, geklammert durch eckige Begrenzungssymbole.
  • Folgende Bytes:
  • Member Data ...: Serialisierte Nutzdaten des jeweiligen Strukturelements oder Methodenarguments.

3. Dynamisches Verhalten & Sequenzablauf

  1. Deserialisierer liest Byte n und Byte n + 1 als vollständigen 16-Bit-Tag.
  2. Extraktion des Wire Types aus Bits 6–4 von Byte n zur Bestimmung des Datentyps bzw. des Serialisierungsformats.
  3. Rekonstruktion der 12-Bit-Data-ID aus dem höherwertigen 4-Bit-Teil (Byte n, Bits 3–0) und dem niederwertigen 8-Bit-Teil (Byte n + 1, Bits 7–0) zur Identifikation des Strukturelements oder Methodenarguments.
  4. Bei Wire-Typen, die ein Längenfeld erfordern, Auswertung des Length Field (8/16/32 bit) ab Byte n + 2.
  5. Einlesen bzw. Dekodieren der eigentlichen Elementdaten (Member Data ...) gemäß der zuvor ermittelten Länge oder Typdefinition.

4. Normative Relevanz & Entwickler-Hinweise

  • Ein Tag besitzt eine feste Gesamtlänge von 2 Bytes (16 Bit).
  • Das höchstwertige Bit (Bit 7 in Byte n) ist reserviert und muss entsprechend Spezifikation behandelt werden.
  • Die Data ID ist 12 Bit breit, aufgeteilt in ein oberes 4-Bit-Nibble und ein unteres 8-Bit-Byte.
  • Data IDs müssen innerhalb der direkten Member einer Struktur oder Argumente einer Methode eindeutig sein.
  • Die Auswertung des Length Field ist abhängig vom deklarierten Wire Type (zulässige Längen: 8, 16 oder 32 Bit). Wire-Typen für statische Basistypen tragen kein Längenfeld.
