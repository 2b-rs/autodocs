1. Diagrammtyp & Architektur-Kontext

UML-Aktivitätsdiagramm zur Spezifikation der XML-Schema-Generierungsregeln (AUTOSAR TPS XML Schema Production Rules). Es modelliert die strukturierte Ableitung von XML-Schema-Konstrukten (xsd:complexType, xsd:simpleType, xsd:element, xsd:group, xsd:attributeGroup) aus AUTOSAR-M2-Klassen und ihren Stereotypen bzw. Tagged Values.

2. Komponenten, Entitäten & Schnittstellen

  • Start- und Endknoten: Initialknoten Class, finaler Ablaufknoten.
  • Entscheidungsknoten (Decisions):
    • Verzweigung nach Stereotyp: Stereotype ([not enumeration && not primitive], [enumeration], [primitive]).
    • Verzweigung für komplexe Klassen: class is not abstract gefolgt von simple content ([no], [yes]), danach global element ([xml:globalElement = true], [xml.globalElement = false]).
    • Verzweigung für primitive Klassen: Tagged-Value-Prüfung (['xml.xsd.type' or 'xml.mds.type' is set], ['xml.xsd.customType' is set]) sowie nachgelagert hasattributes ([yes], [no]).
  • Parallelisierungsbalken (Forks & Joins):
    • Linker Fork/Join für komplexe Klassen mit parallelen Pfaden: Typ-Generierung (simple content), Attribut-Gruppen ([has property with 'xml.attribute = false'], [has property with 'xml.attribute = true']) und Subtyp-Referenzierung ([is referenced]).
    • Rechter Fork/Join für primitive Klassen.
    • Zentraler Merge-Knoten vor dem Endzustand.
  • Aktionen (Rules):
    • [TPS_XMLSPR_00003] Create xsd:complexType
    • [TPS_XMLSPR_00024] Create xsd:complexType with simple content
    • [TPS_XMLSPR_00005] Create global xsd:element
    • [TPS_XMLSPR_00001] Create xsd:group
    • [TPS_XMLSPR_00002] Create xsd:attributeGroup
    • [TPS_XMLSPR_00025] Create xsd:simpleType for subtypes
    • [TPS_XMLSPR_00007] Create xsd:simpleType for enumeration
    • [TPS_XMLSPR_00006] Create reference to predefined datatype]
    • [TPS_XMLSPR_00026] Create a custom simple type
    • [TPS_XMLSPR_00001]Create xsd:group
  • Kommentar/Note: Definition der Bedingung simple content = true basierend auf Property-Kardinalitäten, XML-Attribut-Mappings und Tagged Values.

3. Dynamisches Verhalten & Sequenzablauf

  1. Ausgehend vom Initialknoten Class wird der Stereotyp ausgewertet.
  2. Pfad [enumeration]: Direktes Ausführen von [TPS_XMLSPR_00007] Create xsd:simpleType for enumeration und Weiterleitung zum finalen Merge-Knoten.
  3. Pfad [primitive]: Verzweigung anhand gesetzter Typdefinitionen:
    • Bei ['xml.xsd.type' or 'xml.mds.type' is set]: Erzeugung der Referenz via [TPS_XMLSPR_00006] Create reference to predefined datatype].
    • Bei ['xml.xsd.customType' is set]: Erzeugung des benutzerdefinierten Typs über [TPS_XMLSPR_00026] Create a custom simple type. Falls hasattributes [yes] gilt, wird zusätzlich [TPS_XMLSPR_00001]Create xsd:group generiert.
  4. Pfad [not enumeration && not primitive]: Parallelisierung über Fork-Balken:
    • Pfad 1 (nicht-abstrakte Klassen): Verzweigung nach simple content. Bei [yes] Erzeugung via [TPS_XMLSPR_00024], bei [no] via [TPS_XMLSPR_00003]. Anschließend Prüfung von [xml:globalElement = true]; falls erfüllt, Erzeugung von [TPS_XMLSPR_00005] Create global xsd:element.
    • Pfad 2: Bei [has property with 'xml.attribute = false'] Erzeugung von [TPS_XMLSPR_00001] Create xsd:group.
    • Pfad 3: Bei [has property with 'xml.attribute = true'] Erzeugung von [TPS_XMLSPR_00002] Create xsd:attributeGroup.
    • Pfad 4: Bei [is referenced] Erzeugung von [TPS_XMLSPR_00025] Create xsd:simpleType for subtypes.
  5. Alle Zweige synchronisieren auf Joins bzw. den zentralen Merge-Knoten und terminieren.

4. Normative Relevanz & Entwickler-Hinweise

Das Diagramm definiert verbindliche Transformationsregeln für den AUTOSAR XML Schema Production-Prozess:

  • Steuert deterministisch, welche Schema-Elemente aus den M2-Metamodell-Klassen generiert werden.
  • Unterscheidet strikt zwischen primitiven Typen, Aufzählungen und strukturierten Klassen.
  • Regelt das Vorhandensein von XML-Attributen, Kind-Elementgruppen (xsd:group) und globalen Root- bzw. Modellelementen anhand definierter Stereotypen und Tagged Values (xml.attribute, xml:globalElement, xml.xsd.customType).
