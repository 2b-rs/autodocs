1. Diagrammtyp & Architektur-Kontext

Timing-Diagramm zur Darstellung des Übertragungsverhaltens eines I-PDUs im AUTOSAR-COM-Modul (Communication). Es visualisiert den Anwendungsfall 5, Szenario a („Use case 5 scenario a, TM MIXED, here n = 2 (without TMS switch)“) für den Übertragungsmodus MIXED (ComTxModeMode = MIXED) unter Berücksichtigung von Mindestsendeabständen (ComTxModeMinDelayFactor / $t_{r,\min}$), Wiederholungen ereignisbasierter Übertragungen ($n = 2$) und zyklischen Übertragungsintervallen ($t_c$).

2. Komponenten, Entitäten & Schnittstellen

  • Zeitstrahl ($t$): Horizontale Zeitachse für das Sende-Timing des I-PDUs.
  • Zyklische Sendeereignisse (grüne Pfeile): Reguläre zyklische Übertragungszeitpunkte mit dem Intervall $t_c$ (ComTxModeTimePeriod).
  • Signal-Update ($v = x$, rotes Warndreieck): Schreib- bzw. Aktualisierungsereignis eines Signals oder Signal-Group-Werts durch die Oberschicht (z. B. SW-C oder RTE via Com_SendSignal), welches eine ereignisgesteuerte Übertragung anfordert.
  • Ereignis- und Wiederholungssendungen (grüne Pfeile mit Abstand $t_d$): Sofortige bzw. verzögerte Sendung sowie $n = 2$ Wiederholungen (ComTxModeNumberOfRepetitions = 2) im zeitlichen Abstand $t_d$ (ComTxModeRepetitionPeriod).
  • Mindestsendeabstand $t_{r,\min}$ (ComTxModeMinDelayFactor): Sperrzeit (Minimum Delay Time / MDT), die nach einer zyklischen Sendung verstreichen muss, bevor eine ereignisgesteuerte Sendung ausgelöst werden darf.
  • Sendelaufzeit / Frame-Dauer ($dt$): Dauer der physikalischen Übertragung bzw. PDU-Verarbeitung auf dem Bus.

3. Dynamisches Verhalten & Sequenzablauf

  1. Zyklischer Grundbetrieb: Das I-PDU wird periodisch im festen Zeitabstand $t_c$ übertragen.
  2. Signalaktualisierung innerhalb der Sperrzeit: Während der Mindestverzögerungszeit $t_{r,\min}$ nach einer zyklischen Aussendung erfolgt ein Update mit $v = x$, das eine ereignisbasierte Sendung anfordert.
  3. Verzögerter Start der Ereignisübertragung: Die Übertragung wird blockiert, bis $t_{r,\min}$ vollständig abgelaufen ist. Unmittelbar danach erfolgt die erste ereignisgesteuerte Übertragung.
  4. Wiederholungssequenz: Gemäß Konfiguration $n = 2$ folgen auf die erste ereignisgesteuerte Übertragung zwei zusätzliche Wiederholungsaussendungen jeweils im Abstand $t_d$.
  5. Zyklusfortführung: Das reguläre zyklische Sendeintervall $t_c$ läuft unabhängig weiter; nach Ablauf von $t_c$ (gemessen ab dem vorherigen zyklischen Sendezeitpunkt) wird die nächste reguläre zyklische Sendung ausgelöst, gefolgt von weiteren Perioden im Abstand $t_c$.

4. Normative Relevanz & Entwickler-Hinweise

  • Normative Relevanz: Veranschaulicht die Interaktion von ComTxModeMode = MIXED, ComTxModeMinDelayFactor ($t_{r,\min}$), ComTxModeNumberOfRepetitions ($n$) und ComTxModeRepetitionPeriod ($t_d$) gemäß AUTOSAR COM Spezifikation (z. B. SWS_Com_00284, SWS_Com_00282, SWS_Com_00388).
  • Entwickler-Hinweise: Tritt eine Signalaktualisierung innerhalb der Minimum Delay Time auf, darf die ereignisbasierte Übertragung erst exakt nach Ablauf von $t_{r,\min}$ abgesetzt werden. Im dargestellten Szenario bleibt der zyklische Timer unbeeinflusst von den zwischenzeitlichen Ereignisaussendungen (ohne Reset des Period-Timers), sodass die nächste zyklische Aussendung zum regulären Intervall $t_c$ erfolgt. Liegt eine Wiederholungsaussendung oder zyklische Sendung zu nah an einer vorangehenden Sendung, muss stets die Einhaltung von $t_{r,\min}$ garantiert werden.
