1. Diagrammtyp & Architektur-Kontext

UML-Klassendiagramm / Konfigurationsmetamodell-Diagramm (AUTOSAR ECUC Parameter Configuration Description) für die LIN-Schnittstelle (LIN Interface / LinIf) in der AUTOSAR Classic Platform. Das Diagramm spezifiziert die Konfigurationsstruktur und Parametrisierung eines LIN-Slave-Knotens (LinIfSlave).

4. Normative Relevanz & Entwickler-Hinweise

Verbindliche Konfigurationsvorgabe für BSW-Generatoren des LIN-Interfaces (LinIf):

  • Die Slave-Konfiguration ist optional (lowerMultiplicity = 0). Ist sie vorhanden, darf sie höchstens einmal instanziiert werden (upperMultiplicity = 1).
