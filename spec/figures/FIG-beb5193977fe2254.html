1. Diagrammtyp & Architektur-Kontext

  • Klassifikation: UML-Zustandsdiagramm (State Machine Diagram) zur Modellierung der Bit-Logik eines Status-Flags.
  • Technischer Zweck & Einordnung: Spezifikation der Übergangsbedingungen für Bit 6 (TestNotCompletedThisOperationCycle) des normativen UDS-DTC-Statusbytes gemäß ISO 14229-1 innerhalb des AUTOSAR Classic Diagnostic Event Managers (Dem, Service Layer). Es steuert die Verfolgung, ob ein diagnostischer Test für ein Event im aktuellen Betriebszyklus (OperationCycle) bereits ein qualifiziertes Ergebnis (Passed/Failed) geliefert hat.

2. Komponenten, Entitäten & Schnittstellen

  • Entitäten & Zustände:
    • Initial state: Pseudozustand (Startzustand) bei ECU-Start / Event-Initialisierung.
    • TestNotCompletedThisOperationCycle = TRUE (Bitwert 1b): Der Diagnosetest wurde im aktuellen Betriebszyklus noch nicht vollständig abgeschlossen.
    • TestNotCompletedThisOperationCycle = FALSE (Bitwert 0b): Der Diagnosetest wurde im laufenden Betriebszyklus mindestens einmal vollständig ausgeführt (Ergebnis liegt vor).
  • Beteiligte Module & Schnittstellen (APIs):
    • SW-C / BSW-Treiber: Melden Diagnosetestergebnisse an das Dem über:
      • Dem_SetEventStatus mit Guard [EventStatus = DEM_EVENT_STATUS_{FAILED|PASSED}]
    • Zyklus-Steuerung / Dem-intern: Neustart des Betriebszyklus über:
      • Dem_RestartOperationCycle[(OperationCycleId == DemOperationCycleRef)]
    • DCM (Diagnostic Communication Manager): Diagnosedienst UDS 0x14 (Clear Diagnostic Information) über:
      • Dem_ClearDTC
  • Datentypen & Konstanten:
    • Dem_EventStatusType: DEM_EVENT_STATUS_PASSED, DEM_EVENT_STATUS_FAILED.
    • OperationCycleId, DemOperationCycleRef: Identifikator bzw. Referenz des Events auf den Betriebszyklus.
    • Statusbyte-Maske: Bit 6 (0x40).

3. Dynamisches Verhalten & Sequenzablauf

  1. Initialisierung:
    • Eintritt über Initial state → Das Bit wird defaultmäßig auf TRUE (1b) initialisiert.
  2. Transition TRUE → FALSE (Test abgeschlossen):
    • Trigger: Meldung eines Testergebnisses via Dem_SetEventStatus mit Guard EventStatus = DEM_EVENT_STATUS_{FAILED|PASSED}.
    • Wirkung: Sobald das Event als fehlerfrei oder fehlerhaft eingestuft wurde, wechselt Bit 6 deterministisch auf FALSE (0b).
  3. Selbsttransition FALSE → FALSE:
    • Wiederholte Aufrufe von Dem_SetEventStatus mit EventStatus = DEM_EVENT_STATUS_{FAILED|PASSED} belassen das Bit im Zustand FALSE (0b).
  4. Transition FALSE → TRUE (Rücksetzung auf „Nicht abgeschlossen“):
    • Trigger A (Zyklusneustart): Dem_RestartOperationCycle unter der Guard-Bedingung (OperationCycleId == DemOperationCycleRef).
    • Trigger B (Diagnose-Löschbefehl): Aufruf von Dem_ClearDTC (UDS Service 0x14). Das Löschen setzt den Teststatus des betroffenen DTCs zurück auf TRUE (1b).

4. Normative Relevanz & Entwickler-Hinweise

  • Invertierte Logik (ISO 14229-1): Das Bit ist aktiv-high für den unvollständigen Zustand (1 = Not Completed, 0 = Completed). Dies unterscheidet sich von den Fehlermerker-Bits 0 (TestFailed) und 1 (TestFailedThisOperationCycle).
  • Erfordernis aktiver Passed-Meldungen:
    • Wenn eine SW-C oder ein Treiber nur im Fehlerfall DEM_EVENT_STATUS_FAILED meldet und im Gutfall passiv bleibt (kein DEM_EVENT_STATUS_PASSED), verbleibt Bit 6 permanent auf TRUE.
    • Dies blockiert u. a. gesetzliche OBD-Readiness-Gruppen (PID $01), IUMPR-Zähler und EOBD-Inspektionszyklen. Monitore müssen so ausgelegt sein, dass sie im Normalbetrieb aktiv PASSED melden, sobald die Testbedingungen (Enable Criteria) erfüllt waren.
  • Entprellung (Debouncing):
    • DEM_EVENT_STATUS_PREPASSED bzw. PREFAILED triggern die Transition nicht direkt. Die Zustandsänderung nach FALSE erfolgt erst, wenn der Fehlerzähler (Debounce Counter) bzw. zeitbasierte Filter die jeweilige Schwelle erreicht und das Dem das Event intern als PASSED/FAILED qualifiziert.
  • Konfiguration & Zykluszuordnung:
    • Jedes Event muss via Konfigurationsparameter DemOperationCycleRef an einen definierten Zyklus (z. B. DEM_OPCYC_IGNITION, DEM_OPCYC_OBD_DCY) gebunden sein. Ein fehlerhafter Aufruf von Dem_SetOperationCycleState() setzt alle zugeordneten Events synchron auf Bit 6 = 1b zurück.
