2. Komponenten, Entitäten & Schnittstellen

  • Artefakte (Dateiformate / Datenmodelle):
  • ECU Configuration Values [XML]: Vollständige formale Steuergeräte-Konfigurationswerte (ARXML), die alle SWC-Instanzen, Runnables, Port-Mappings, OS-Tasks, Kommunikationsbeziehungen und BSW-Parametrierungen umfassen (Input für Generate RTE).
  • BSW Module Description [XML]: Generierte XML-Modulbeschreibung (BSWMD) für die RTE bzw. den BSW-Scheduler zur formalen Integration in das BSW-Gesamtgefüge (Output von Generate RTE).
  • IOC-Configuration [XML]: Generierte Konfigurationsbeschreibung für den Inter-OS-Application-Communicator des Betriebssystems zur partitions- und kernübergreifenden Kommunikation (Output von Generate RTE).
  • MC-Support [XML]: Generierte Beschreibungsdaten für Mess- und Kalibriersysteme (ASAP2/A2L bzw. McData-Modelle, Output von Generate RTE).
  • RTE Header [H]: Typ- und Schnittstellendefinitionen (Rte.h, Rte_<swc>.h, Rte_Type.h) für SWCs und BSW-Module (Output von Generate RTE, Input für Compile RTE).
  • RTE Code [C]: Generierte C-Quelldateien für Event-Dispatching, Datenübertragung und Runnable-Triggerung (Output von Generate RTE, Input für Compile RTE).
  • Compiled RTE [OBJ]: Zielprozessorspezifische Binärobjektdateien der RTE (Output von Compile RTE).
  • Werkzeuge & Aktivitäten:
  • Generate RTE: Ausführungsaktivität der RTE-Code- und Artefaktsynthese.
  • AUTOSAR RTE Generator: Codegenerierungs-Werkzeug (Tooling-Entität, dargestellt als Hammer-Piktogramm).
  • Compile RTE: Übersetzungsschritt via Target-Cross-Compiler.
  • Kanten & Stereotypen:
  • «input»: Zuleitung von Eingangsartefakten (ECU Configuration Values [XML] zu Generate RTE; RTE Code [C] und RTE Header [H] zu Compile RTE).
  • «output»: Ableitung von Ausgangsartefakten (von Generate RTE zu BSW Module Description [XML], RTE Code [C], RTE Header [H], MC-Support [XML] und IOC-Configuration [XML]; von Compile RTE zu Compiled RTE [OBJ]).
  • «used tool»: Werkzeugzuordnung von Generate RTE zu AUTOSAR RTE Generator.

3. Dynamisches Verhalten & Sequenzablauf

  1. ECU Configuration Completion: Vorliegen der formal abgeschlossenen ECU Configuration Values [XML].
  2. RTE-Synthese (Generate RTE): Das Werkzeug AUTOSAR RTE Generator synthetisiert parallel:
  • Header- und Implementierungsdateien (RTE Header [H], RTE Code [C]).
  • Zusätzliche Konfigurations- und Beschreibungsartefakte: BSW Module Description [XML] (für den BSW-Scheduler), IOC-Configuration [XML] (für die OS-IOC-Multicore-Kommunikation) und MC-Support [XML] (für Messung und Kalibrierung).
  1. Übersetzung (Compile RTE): Der Compiler bindet RTE Header [H] in die Übersetzung von RTE Code [C] ein und generiert Maschinencode.
  2. Objekt-Bereitstellung: Bereitstellung von Compiled RTE [OBJ] für die nachgelagerte Linker-Stufe des Steuergeräte-Gesamtimages.

4. Normative Relevanz & Entwickler-Hinweise

  • Erweiterter Generierungsumfang: Neben C-Quellen und Headern erzeugt der RTE-Generator nun formal standardisierte XML-Artefakte für nachgelagerte Toolchain-Schritte (Multicore-OS-Konfiguration über IOC-Configuration, BSW-Scheduler-Integration via BSW Module Description sowie Mess- und Kalibrier-Tools via MC-Support).
  • Methodik-Konformität: Explizite Kennzeichnung aller Kanten über SPEM-Stereotypen («input», «output», «used tool») und Standardisierung der Dateityp-Zusätze ([XML], [C], [H], [OBJ]).
  • Multicore-Architekturen: Die Generierung der IOC-Configuration ist eine notwendige Voraussetzung für die Konfiguration des Multicore-Betriebssystems zur Absicherung partitions- und kernübergreifender Funktionsaufrufe.
  • Build-Integrität: Jede Aktualisierung der ECU Configuration Values erfordert die Neugenerierung aller abgeleiteten Artefakte und die anschließende Neukompilierung.
