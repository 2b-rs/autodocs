Informelles Methoden- und Architekturdiagramm (Metamodellierungs- und Generierungsmethodik) zur Veranschaulichung der AUTOSAR-Templatedefinition am Beispiel des SystemTemplate. Das Diagramm strukturiert das Zusammenspiel zwischen textuellen Spezifikationsdokumenten, UML-Metamodell-Artefakten (Model M2 Templates), Profildefinitionen, Regelwerken, dem Schema-Generator sowie den daraus abgeleiteten XML-Schemata und XML-Instanzdateien im AUTOSAR-Gesamtkontext.

3. Dynamisches Verhalten & Sequenzablauf

Der methodische Ablauf vollzieht sich in zwei wesentlichen Transformations- und Instanziierungspfaden:

  1. Spezifikations- und Regulierungsfluss (M2-Ebene): Das auf M2 angesiedelte Metamodell Model M2 Templates unterliegt den Vorgaben von UML and the Autosar Template Profile (+isGovernedBy) und wird in den Dokumenten Generic Structure Template und SystemTemplate semantisch beschrieben. Die Serialisierungsvorschriften (specifiesSerialization) werden durch XML Schema Production Rules vorgegeben.
  2. Generierungs- und Instanziierungsfluss (M1/M0-Ebene): Der Schema Generator verarbeitet das Model M2 Templates unter Implementierung der XML Schema Production Rules (+implements) und erzeugt (+generates) das «XML Schema» Data Exchange Format sowie Teile der Dokumentation für das SystemTemplate. Aus dem resultierenden XML-Schema werden schließlich konkrete AUTOSAR-XML-Dateien wie die System Configuration Description und die System Constraint Description als Schema-Instanzen abgeleitet (+instance of).

4. Normative Relevanz & Entwickler-Hinweise

Das Diagramm besitzt methodisch-normativen Charakter für den AUTOSAR-Standardisierungsprozess. Es definiert die Verbindlichkeit der Modellierungs- und Generierungskette: Änderungen am M2-Metamodell dürfen nur im Rahmen des AUTOSAR Template Profiles erfolgen; XML-Schemata dürfen nicht manuell verfasst werden, sondern müssen strikt über den Schema-Generator gemäß den XML Schema Production Rules aus M2 erzeugt werden. XML-Dateien (z. B. System Configuration Description) müssen valide Instanzen des generierten Data Exchange Format Schemas sein.
