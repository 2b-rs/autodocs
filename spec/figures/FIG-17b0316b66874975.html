1. Diagrammtyp & Architektur-Kontext

Tabellarische Spezifikationsmatrix für Modell-Persistenzregeln im AUTOSAR-Metamodell gemäß Anforderung 5.4.11 [APRXML0016] Create composite property representation (0000) [Tc0010Sc0000] und Übergang zu 5.5 Create reference representation [Tc0012]. Die Darstellung definiert Templates und Bedingungen für Eigenschaften, bei denen weder Rollen- noch Typ-Wrapper generiert werden.

2. Komponenten, Entitäten & Schnittstellen

  • Bedingungen und Metamodell-Eigenschaften:
  • Property
  • Tagged-Value-Bedingung: xml.roleWrapperElement == false && xml.roleElement == false && xml.typeWrapperElement == false && xml.typeElement == false.
  • Schema-Template:
  • <xsd:choice minOccurs="<%=lowerMultiplicity%>" maxOccurs="<%=upperMultiplicity%>">
  • Iterator <% for all types { %> mit Gruppenreferenz <xsd:group ref="<%=typeXmlNsPrefix%>:<%=typeXmlName%>"/>.
  • Konkrete Ausprägung: <xsd:choice minOccurs="0" maxOccurs="unbounded"> für AR:B1 / AR:B2 sowie <xsd:choice minOccurs="0" maxOccurs="1"> für AR:C.
  • XML-Instanzstrukturen:
  • Gekapselte Serialisierung mit Elementen <B1>, <B2>, <C> und Kindelementen <ATT-B1>, <ATT-B2>, <ATT-C>.
  • Ungekapselte Serialisierung („See above“) mit direkter Einbettung von <ATT-B1>, <ATT-B2>, <ATT-C> im Wurzelelement <...>.

3. Dynamisches Verhalten & Sequenzablauf

Regelbasierte Transformationsabfolge:

  1. Prüfung der Metadaten-Bedingung: Alle Flags für Rollen- und Typ-Elemente bzw. -Wrapper müssen auf false evaluiert sein.
  2. Schema-Generierung: Dynamische Erzeugung von <xsd:choice> basierend auf <%=lowerMultiplicity%> und <%=upperMultiplicity%> sowie Iteration über alle Subtypen zur Einbettung von <xsd:group>.
  3. XML-Generierung: Gemäß der Spezifikation wird kein eigenes XML-Element für das Property erzeugt; das Inhaltsmodell des Typs und aller Subtypen wird direkt in die xsd:group der besitzenden Klasse eingebettet. Instanzbeispiele verdeutlichen den Unterschied zwischen getaggten/umhüllten Typen und flacher Einbettung.

4. Normative Relevanz & Entwickler-Hinweise

Normativ bindende Spezifikationsregel [APRXML0016] inklusive Testfallzuordnung [Tc0010Sc0000]. Generatorwerkzeuge müssen die logische UND-Verknüpfung der vier Tagged Values validieren, um zu entscheiden, ob kein XML-Element erzeugt und das Inhaltsmodell direkt in die besitzende xsd:group überführt wird. Instanzen ohne Wrapper müssen dem gezeigten Muster direkt eingebetteter Kindelemente entsprechen.
