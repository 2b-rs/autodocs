1. Diagrammtyp & Architektur-Kontext

UML-Klassendiagramm zur Spezifikation des AUTOSAR-Metamodells im Kontext des Software-Komponententemplates (AUTOSAR_TPS_SoftwareComponentTemplate). Das Diagramm illustriert das Metamodell-Muster zur Zuweisung instanzspezifischer Datendefinitionseigenschaften (InstantiationDataDefProps) an Daten- und Parameterprototypen innerhalb eines SwcInternalBehavior.

2. Komponenten, Entitäten & Schnittstellen

  • SwcInternalBehavior (geerbt von InternalBehavior): Enthält die Attribute handleTerminationAndRestart: HandleTerminationAndRestartEnum und supportsMultipleInstantiation: Boolean. Besitzt eine kompositionelle Aggregation (+instantiationDataDefProps, Kardinalität 0..*, stereotypt als «atpVariation») auf InstantiationDataDefProps.
  • InstantiationDataDefProps: Kapselt instanzspezifische Konfigurationen. Besitzt genau eine Komposition (+swDataDefProps, Kardinalität 1) auf SwDataDefProps sowie zwei optionale Kompositionen (0..1), die über ein XOR-Constraint exklusiv zueinander stehen:
  • +parameterInstance: Komposition auf AutosarParameterRef (0..1).
  • +variableInstance: Komposition auf AutosarVariableRef (0..1).
  • AutosarParameterRef: Referenziert über eine gerichtete Assoziation +localParameter (0..1) bzw. über eine «instanceRef»-Beziehung +autosarParameter (0..1) ein DataPrototype.
  • AutosarVariableRef: Referenziert über eine «instanceRef»-Beziehung +autosarVariable (0..1) ein DataPrototype.
  • DataPrototype (spezialisiert von AtpPrototype): Ziel der Parameter- und Variablenreferenzen.
  • SwDataDefProps (stereotypt als «atpVariation»): Bündelt die Datendefinitionseigenschaften mit folgenden Attributen:
  • additionalNativeTypeQualifier: NativeDeclarationString [0..1]
  • displayFormat: DisplayFormatString [0..1]
  • mcFunction: Identifier [0..1]
  • swAlignment: AlignmentType [0..1]
  • swCalibrationAccess: SwCalibrationAccessEnum [0..1]
  • swImplPolicy: SwImplPolicyEnum [0..1]
  • swIntendedResolution: Numerical [0..1]
  • swInterpolationMethod: Identifier [0..1]
  • swIsVirtual: Boolean [0..1]
  • «atpVariation» swValueBlockSize: Numerical [0..1]

3. Dynamisches Verhalten & Sequenzablauf

Statisches Metamodell ohne Verhaltens- oder Sequenzabläufe. Die Modellierung beschreibt deklarative Strukturregeln zur Auslegung instanzspezifischer Datenbeschreibungen für Softwarekomponenten.

4. Normative Relevanz & Entwickler-Hinweise

  • Durch das XOR-Constraint an InstantiationDataDefProps darf eine Instanz von InstantiationDataDefProps entweder genau eine parameterInstance oder genau eine variableInstance referenzieren, niemals beides gleichzeitig.
  • Die Komposition +instantiationDataDefProps ist als variabilitätsfähig («atpVariation») gekennzeichnet mit der Bindungszeit-Vorgabe Vh.latestBindingTime = PreCompileTime.
  • Das Attribut swValueBlockSize innerhalb von SwDataDefProps ist ebenfalls als «atpVariation» spezifiziert und unterliegt separater Variabilitätsbindung.
  • Instanzreferenzen («instanceRef») erlauben die präzise Adressierung von Kontextpfaden für Parameter und Variablen über Hierarchieebenen hinweg.
