1. Diagrammtyp & Architektur-Kontext

Konzeptionelles Architektur- und Zuordnungsdiagramm aus der AUTOSAR Classic Platform Spezifikation des Synchronized Time-Base Manager (StbM). Das Diagramm illustriert die statische Abbildungsrelation und Kopplung zwischen Offset-Zeitbasen (Offset Time Bases) und synchronisierten Zeitbasen (Synchronized Time Bases) über die Systemkonfiguration.

2. Komponenten, Entitäten & Schnittstellen

  • Offset Time Bases: Tabellarische Liste von Zeitbasis-Instanzen im oberen und unteren Block, indiziert von (Offset) Time Base 16 bis (Offset) Time Base 31 (mit Auslassungspunkten zwischen 18 und 30).
    • Zugeordnete Botschaften/Schnittstellenverbindungen links: Bidirektionale Pfeile OFFSET Msg(0), OFFSET Msg(1), OFFSET Msg(2) angebunden an Basis 16, 17, 18 sowie OFFSET Msg(14), OFFSET Msg(15) angebunden an Basis 30, 31.
  • Synchronized Time Bases: Tabellarische Liste von synchronisierten Basis-Instanzen im unteren und oberen Block, indiziert von (Sync.) Time Base 0 bis (Sync.) Time Base 15 (mit Auslassungspunkten zwischen 2 und 14).
    • Zugeordnete Botschaften/Schnittstellenverbindungen rechts: Bidirektionale Pfeile SYNC Msg(0), SYNC Msg(1), SYNC Msg(2) angebunden an Basis 0, 1, 2 sowie SYNC Msg(14), SYNC Msg(15) angebunden an Basis 14, 15.
  • System configuration: Gestrichelter vertikaler Rahmen als Konfigurationsdomäne, der die Zuordnungspfeile zwischen den beiden Zeitbasis-Bereichen umschließt.
  • Verbindungsrelationen:
    • (Offset) Time Base 18 referenziert über gerichteten Pfeil (Sync.) Time Base 2.
    • (Offset) Time Base 17 referenziert über gerichteten Pfeil (Sync.) Time Base 1.
    • (Offset) Time Base 16 referenziert ebenfalls über gerichteten Pfeil (Sync.) Time Base 1.

3. Dynamisches Verhalten & Sequenzablauf

Das Diagramm stellt eine statische Zuordnungsvorschrift dar. Eine Offset-Zeitbasis leitet ihre Basiszeit aus einer übergeordneten synchronisierten Zeitbasis ab, modifiziert um einen spezifischen Offset. Die Pfeilführung verdeutlicht:

  • Eine Offset-Zeitbasis ist genau einer Synchronized Time Base zugeordnet (z. B. Offset 18 auf Sync 2).
  • Eine Synchronized Time Base kann mehreren Offset-Zeitbasen als Referenz dienen (n:1-Beziehung, dargestellt durch die gemeinsame Referenzierung von Sync 1 durch Offset 16 und Offset 17).
  • Der Austausch synchronisierter und offset-bezogener Zeitinformationen mit externen Kommunikationspartnern bzw. BSW-Modulen erfolgt über die Schnittstellenbotschaften SYNC Msg(x) bzw. OFFSET Msg(y).

4. Normative Relevanz & Entwickler-Hinweise

Die Zuordnung zwischen einer Offset Time Base und ihrer zugrundeliegenden Synchronized Time Base erfolgt zur Entwurfs- bzw. Generierungszeit über die Systemkonfiguration (StbM-Konfigurationsparameter). Für die Implementierung bedeutet dies:

  • Der ID-Raum unterscheidet synchronisierte Zeitbasen (hier IDs 0 bis 15) und Offset-Zeitbasen (hier IDs 16 bis 31).
  • Mehrere Offset-Zeitbasen können dieselbe synchronisierte Zeitbasis als Zeitursprung nutzen.
  • Zeitaktualisierungen der synchronisierten Basis propagieren konzeptionell auf alle zugeordneten Offset-Zeitbasen.
