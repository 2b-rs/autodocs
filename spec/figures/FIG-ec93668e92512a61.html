1. Diagrammtyp & Architektur-Kontext

UML-Sequenzdiagramm (sd FrNm_NormalStartUp) zur Spezifikation des dynamischen Verhaltens im AUTOSAR-Basissoftware-Stack. Es beschreibt die Interaktion zwischen dem generischen Netzwerk-Management (Nm) und dem FlexRay-Netzwerk-Management (FrNm) bei der Netzwerkanforderung (Network Request) und Netzwerkfreigabe (Network Release).

2. Komponenten, Entitäten & Schnittstellen

  • Lebenslinien / Entitäten:
  • «module» Nm::Nm: Generisches AUTOSAR-Netzwerk-Management-Modul.
  • «module» FrNm::FrNm: FlexRay-Netzwerk-Management-Modul.
  • Schnittstellen & Operationen:
  • FrNm_NetworkRequest(return, NetworkHandle) : Nm_ReturnType: Synchroner Aufruf von Nm::Nm an FrNm::FrNm.
  • Nm_StateChangeNotification(nmNetworkHandle, nmPreviousState, nmCurrentState): Callback-Operation von FrNm::FrNm an Nm::Nm zur generischen Signalisierung von Zustandsänderungen mit vorherigem und aktuellem Zustand.
  • FrNm_NetworkRelease(return, NetworkHandle) : Nm_ReturnType: Synchroner Aufruf von Nm::Nm an FrNm::FrNm zur Netzwerkfreigabe.
  • Zustände / Zustandsmarkierungen an FrNm:
  • Modus-/Zustandspaare: Bus Sleep Mode / Network Released, Synchronize Mode, Network Mode / Network Requested, Normal Operation State, Repeat Message State / Network Released.

3. Dynamisches Verhalten & Sequenzablauf

  1. Ausgangszustand: FrNm::FrNm befindet sich im Zustand Bus Sleep Mode / Network Released.
  2. Netzwerkanforderung:
  • Nm::Nm ruft FrNm_NetworkRequest(return, NetworkHandle) : Nm_ReturnType an FrNm::FrNm auf, gefolgt von der synchronen Rückkehr.
  • FrNm::FrNm wechselt in den Synchronize Mode und meldet die Zustandsänderung per Nm_StateChangeNotification(nmNetworkHandle, nmPreviousState, nmCurrentState) an Nm::Nm.
  • Bei Erreichen von Network Mode / Network Requested und Eintritt in den Normal Operation State erfolgt eine weitere Nm_StateChangeNotification() an Nm::Nm.
  1. Netzwerkfreigabe:
  • Nm::Nm ruft FrNm_NetworkRelease(return, NetworkHandle) : Nm_ReturnType an FrNm::FrNm auf; der Aufruf kehrt synchron zurück.
  • FrNm::FrNm wechselt in den Zustand Repeat Message State mit Status Network Released und benachrichtigt Nm::Nm über Nm_StateChangeNotification().

4. Normative Relevanz & Entwickler-Hinweise

  • Verbindliche Modellierung der standardisierten AUTOSAR-NM-Zustandsbenachrichtigung über die generische Schnittstelle Nm_StateChangeNotification anstelle modusspezifischer Einzel-Callbacks.
  • Der Aufruf zur Netzwerkfreigabe ist konsistent als FrNm_NetworkRelease deklariert.
  • Nach Freigabe des Netzwerks geht das FlexRay-NM gemäß Protokollablauf zunächst in den Repeat Message State (innerhalb des Netzwerkbetriebs mit Status Network Released) über und nicht unmittelbar in den Bus Sleep Mode.
  • Das Diagramm trägt den Bearbeitungsvermerk Status: proposed / Comments:.
