1. Diagrammtyp & Architektur-Kontext

UML-Zustandsdiagramm (State Chart) für das AUTOSAR-Basissoftwaremodul FlexRay Network Management (FrNm). Das Diagramm modelliert die übergeordneten Betriebsmodi, Betriebszustände, Initialisierungs- und Terminierungsübergänge sowie das zyklus- und ereignisgesteuerte Verhalten der NM-Zustandsmaschine auf einem FlexRay-Cluster.

2. Komponenten, Entitäten & Schnittstellen

Das Diagramm umfasst folgende Zustände, Pseudozustände und Schnittstellenelemente:

  • Pseudozustände: Anfangszustand (Start), Endzustand (Terminate), Kreuzungs-/Eintrittspunkt in Network Mode sowie Exit-Point (Kreis mit Kreuz) am Rand des hierarchischen Zustands Network Mode.
  • Top-Level-Zustände:
    • Uninit: Uninitialisierter Zustand des Moduls.
    • Bus Sleep Mode: Zustand ohne Kommunikationsaktivität; Entry-Aktion: FrNm_NetworkRequest = FALSE, FrNm_RepeatMessage = FALSE.
    • Synchronize: Synchronisationszustand; Entry-Aktion: Notify "Sychronize Mode".
    • Network Mode: Hierarchischer Verbundzustand.
  • Subzustände in Network Mode:
    • Repeat Message: Eintrittszustand; Entry-Aktion: Start RepeateMessage Timer.
    • Normal Operation: Regulärer aktiver Zustand.
    • Ready Sleep: Vorbereitung zum Einschlafen.
    • Pseudo-Verzweigungspunkt (Junction Point / Choice).
  • Notizen / Kommunikationsattribute an Zuständen:
    • Synchronize: „No voting for keeping awake, No data transmission“.
    • Repeat Message: „Vote for keeping awake, Do data transmission“.
    • Normal Operation: „Vote for keeping awake, Do data transmission“.
    • Ready Sleep: „No voting for keeping awake, No data transmission“.
  • Schnittstellen & Bezeichner:
    • APIs / Trigger: FrNm_Init(), FrNm_NetworkRequest(), FrNm_PassiveStartUp(), FrNm_NetworkRelease(), Nm_NetworkRequest().
    • Callbacks / Benachrichtigungen: /Nm_BusSleepMode(), /Notify "Network Mode", Notify "Sychronize Mode".
    • Interne Flags & Zähler: FrNm_NetworkRequest, FrNm_RepeatMessage, FrNm_ReadySleepCnt, StartValue.

3. Dynamisches Verhalten & Sequenzablauf

Der funktionale Ablauf gliedert sich in folgende Phasen:

  1. Initialisierung & Start:
    • Vom Startknoten gelangt die Zustandsmaschine nach Uninit.
    • Durch FrNm_Init() erfolgt der Übergang nach Bus Sleep Mode (Flags FrNm_NetworkRequest und FrNm_RepeatMessage werden auf FALSE gesetzt).
    • Re-Initialisierung über FrNm_Init() ist aus Bus Sleep Mode sowie über eingehende Transitionen aus Synchronize und Network Mode zurück nach Bus Sleep Mode möglich.
    • Über das Ereignis Power Off wechselt Bus Sleep Mode in den Endzustand Terminate.
  2. Netzwerkaktivierung:
    • Bus Sleep Mode wechselt nach Synchronize durch FrNm_NetworkRequest() (mit /FrNm_NetworkRequest = TRUE) oder durch FrNm_PassiveStartUp().
    • Innerhalb von Synchronize verbleibt die Maschine bei Aufrufen von Nm_NetworkRequest() /FrNm_NetworkRequest = TRUE bzw. FrNm_NetworkRelease() /FrNm_NetworkRequest = FALSE.
    • Bei Fehlerbedingung [FrNm_Init OR (FrNm_NetworkRequested == FALSE AND FrNm_StartUp_Error Indication)] wechselt die Maschine von Synchronize zurück nach Bus Sleep Mode.
    • Nach Ablauf eines Zyklus (Repetition Cycle completed) wechselt Synchronize in den hierarchischen Zustand Network Mode, setzt FrNm_RepeatMessage = TRUE, benachrichtigt über /Notify "Network Mode" und tritt in den Subzustand Repeat Message ein (startet dort den Repeat-Message-Timer).
  3. Betrieb innerhalb von Network Mode:
    • Innerhalb von Network Mode existieren globale Ereignistransitionen:
      • RepeatMessagDetected /FrNm_RepeatMessage = TRUE
      • RepeatMessageTimer expired /FrNm_RepeatMessage = FALSE
      • FrNm_NetworkRequest() /FrNm_NetworkRequest = TRUE
      • FrNm_NetworkRelease() /FrNm_NetworkRequest = FALSE
    • Am Ende eines Repetition Cycles führt der Weg über den internen Verzweigungspunkt:
      • Von Repeat Message bei Repetition Cycle completed [FrNm_NetworkRequest = TRUE AND FrNm_RepeatMessage = FALSE] nach Normal Operation.
      • Von Repeat Message bei Repetition Cycle completed [FrNm_NetworkRequest=FALSE AND FrNm_RepeatMessage=FALSE] /FrNm_ReadySleepCnt = StartValue nach Ready Sleep.
      • Von Repeat Message bei Repetition Cycle completed [FrNm_RepeatMessage = TRUE] zyklisch zurück nach Repeat Message.
      • Von Normal Operation bei Repetition Cycle completed [FrNm_RepeatMessage = TRUE] nach Repeat Message.
      • Von Normal Operation bei Repetition Cycle completed [FrNm_NetworkRequest=FALSE AND FrNm_RepeatMessage=FALSE] /FrNm_ReadySleepCnt = StartValue nach Ready Sleep.
      • Von Ready Sleep bei Repetition Cycle completed [FrNm_ReadySleepCnt>0 AND FrNm_RepeatMessage=TRUE] nach Repeat Message.
      • Von Ready Sleep bei Repetition Cycle completed [FrNm_ReaySleepCnt>0 AND FrNm_NetworkRequest=TRUE AND FrNM_RepeatMessage=FALSE ] nach Normal Operation.
      • Innerhalb von Ready Sleep bei Vorliegen eines externen Wachhaltens: ClusterAwakeVote detected /FrNm_ReadySleepCnt = StartValue.
      • Verbleib in Ready Sleep pro Zyklus: Repetition Cycle completed [FrNm_NetworkRequest=FALSE AND FrNm_RepeatMessage=FALSE AND FrNm_ReadSleepCnt>0] /FrNm_ReadySleepCnt = FrNm_ReadySleepCnt - 1.
  4. Busabschaltung / Einschlafen:
    • Ist der Zähler abgelaufen (Repetition Cycle completed [FrNm_ReadySleepCnt < 1]), verlässt die Zustandsmaschine Ready Sleep über den Exit-Point von Network Mode, löst /Nm_BusSleepMode() aus und wechselt in den Bus Sleep Mode.

4. Normative Relevanz & Entwickler-Hinweise

  • Das Diagramm definiert die normativen Zustandsübergangsregeln, Guards und Aktionen des FlexRay NM.
  • Die Zustände steuern direkt die Kommunikationsparameter auf dem FlexRay-Bus: In Repeat Message und Normal Operation wird ein Vote für das Wachhalten abgegeben und Datenübertragung durchgeführt; in Synchronize und Ready Sleep erfolgt kein Voting für das Wachhalten und keine Datenübertragung.
  • Die Synchronisation mit dem FlexRay-Kommunikationszyklus (Repetition Cycle) ist zwingende Voraussetzung für alle Moduswechsel im aktiven Betrieb.
  • Bei Fehlern während des Startup-Vorgangs oder fehlender Busanforderung muss deterministisch in den Bus Sleep Mode zurückgekehrt werden.
