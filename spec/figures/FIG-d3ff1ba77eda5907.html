1. Diagrammtyp & Architektur-Kontext

  • Diagrammtyp: Formalspezifisches SPEM-Prozess- und Datenflussdiagramm (Software & Systems Process Engineering Metamodel).
  • Architektur-Kontext: AUTOSAR Classic Platform (Spezifikationskontext: AUTOSAR_EXP_VFB, Release R22-11; Methodologie-Top-Level-Sicht).
  • Technischer Zweck: Formale Spezifikation der AUTOSAR-Methodologie mit expliziten Stereotypen («input», «output»), Kardinalitäten und Abhängigkeiten zwischen methodischen Aktivitäten und definierten Work-Product-Bundles über fünf Hauptdomänen hinweg bis zur Integration des Zielsteuergeräts.

2. Komponenten, Entitäten & Schnittstellen

Domänen und Strukturierungsbereiche
  • Basic Software: Domäne zur Bereitstellung und Entwicklung von BSW-Basispaketen und BSW-Modul-Lieferständen.
  • System: Domäne für die Top-Level-Systemarchitektur, die abstrakte Systembeschreibung, Dekomposition in Sub-Systeme und die Extraktion von ECU-Ausschnitten.
  • Virtual Functional Bus: Domäne für die standardisierten VFB-Pakete und die Erstellung der VFB-Systembeschreibung.
  • Software Component: Domäne für das Design und die Implementierung atomarer Software-Komponenten.
  • ECU: Integrationsdomäne zur Zusammenführung von BSW, Anwendungs-SWCs und ECU-Extract zur finalen Steuergerätesoftware.
Aktivitäten (Tasks / Prozessschritte)
  • Develop an Abstract System Description: Erstellung der initialen abstrakten Systemmodellierung.
  • Develop a VFB System Description: Spezifikation der Softwarekomponenten-Schnittstellen, Ports und VFB-Kommunikationsbeziehungen.
  • Develop System: Vollständige Systemkonfiguration, Mapping von SWCs auf ECUs, Topologie-, Frame- und Transformer-Design.
  • Develop Sub-System: Rekursive Subsystem-Dekomposition zur Verfeinerung partitionierter Systemstrukturen.
  • Develop Application Software: Implementierung und Bereitstellung der atomaren Softwarekomponenten.
  • Develop Basic Software: Konfiguration und Bereitstellung modulspezifischer BSW-Pakete.
  • Integrate Software for ECU: Finale Integration, Generierung und Verlinkung aller Lieferstände zur lauffähigen Steuergerätesoftware.
Work Products / Artefakte (Deliverables)
  • BSW Standard Package: Standardisierte AUTOSAR-BSW-Basisbeschreibungen und -Spezifikationen.
  • VFB AUTOSAR Standard Package: Standardisierte VFB-Metamodell-Definitionen, Datentypen und Interface-Standards.
  • System Constraint Description: Ressourcen-, Timing- und Topologie-Randbedingungen des Systems.
  • Abstract System Description: Abstrahierte Spezifikation der funktionalen Systemarchitektur.
  • Overall VFB System: Vollständiges VFB-Kommunikations- und Komponentenmodell.
  • Transformer Design Bundle: Spezifikation von Serialisierungs- und Datentransformationsketten (z. B. SOME/IP, E2E).
  • System Extract: Extrahierter Teilausschnitt des Gesamtsystems zur Subsystem-Verfeinerung.
  • ECU Extract: Zielsteuergerätespezifischer Auszug aus dem System- oder Subsystem-Modell (SYSTEM-EXTRACT).
  • BSW Module Delivered Bundle: Konfigurierte und implementierte BSW-Module inklusive BSW-Beschreibungen (BSWMD).
  • Delivered Atomic Software Components: Fertiggestellte atomare Software-Komponenten (SwComponentType inklusive Code/Libraries).
  • ECU Software Delivered: Vollständig integriertes und generiertes Software-Lieferpaket für die Ziel-ECU.
Schnittstellen- und Beziehungssemantik
  • Stereotyp «input»: Kennzeichnet Artefakte, die als Eingangsdaten für eine Aktivität zwingend oder optional vorausgesetzt werden.
  • Stereotyp «output»: Kennzeichnet Artefakte, die von einer Aktivität erzeugt werden.
  • Kardinalitäten:
    • 1: Genau eine Instanz des Artefakts erforderlich bzw. produziert.
    • 0..1: Optionale Artefaktbeziehung.
    • 0..*: Beliebig viele optionale Instanzen.
    • 1..*: Mindestens eine oder mehrere Instanzen zwingend erforderlich bzw. produziert.

3. Dynamisches Verhalten & Sequenzablauf

  • Initiale Definitionsphase:
    • Ausgehend vom VFB AUTOSAR Standard Package und optionalen System Constraint Description (Kardinalität 0..1) wird mittels Develop an Abstract System Description die Abstract System Description erzeugt (Multiplizität 1..*).
    • Parallel dazu speisen das VFB AUTOSAR Standard Package und die Abstract System Description die Aktivität Develop a VFB System Description, welche das Overall VFB System generiert.
  • System-Synthese und Dekomposition:
    • Die Aktivität Develop System konsumiert das Overall VFB System (0..1), die Abstract System Description (0..*) sowie System Constraint Description (0..1).
    • Develop System erzeugt das Transformer Design Bundle (0..*), den System Extract (0..*) für die Rekursion über Develop Sub-System sowie direkt den ECU Extract (1..*).
  • Parallele Komponenten- und BSW-Entwicklung:
    • Das Overall VFB System (1) fließt als «input» in Develop Application Software, woraus Delivered Atomic Software Components (1..*) hervorgehen.
    • Das BSW Standard Package (1) und das Transformer Design Bundle (0..*) fließen in Develop Basic Software, woraus das BSW Module Delivered Bundle (1..*) generiert wird.
  • ECU-Integrationsphase:
    • Die Aktivität Integrate Software for ECU konsumiert zwingend den ECU Extract (1), das BSW Module Delivered Bundle (1..*) und die Delivered Atomic Software Components (1..*).
    • Als finaler «output» entsteht genau ein ECU Software Delivered-Lieferpaket (1).

4. Normative Relevanz & Entwickler-Hinweise

  • Metamodell-Standardisierung: Vollständige Konformität zum SPEM-2.0-Profil von AUTOSAR; Aktivitäten und Artefakte müssen strikt den definierten Kardinalitäten genügen.
  • Transformer- und Subsystem-Integration: Explizite normative Berücksichtigung von Daten-Transformationen (Transformer Design Bundle) und hierarchischer Systemzerlegung (System Extract / Develop Sub-System), wodurch iterative und mehrstufige Zulieferketten formal abgebildet werden.
  • Multi-Provider-Konsistenz: Die Kardinalitäten 1..* bei SWCs und BSW-Modulen dokumentieren normativ, dass ein Steuergerät aus heterogenen Lieferartefakten mehrerer Zulieferer integriert wird, bevor das konsolidierte Artefakt ECU Software Delivered entsteht.
