1. Diagrammtyp & Architektur-Kontext

UML-Aktivitätsdiagramm zur Abbildungsvorschrift von M2-UML-Klassen auf W3C-XML-Schema-Artefakte im Rahmen der AUTOSAR-XML-Persistenzregeln (AUTOSAR_TR_XMLPersistenceRules). Das Diagramm spezifiziert die Entscheidungslogik zur Erzeugung von XSD-Konstrukten (xsd:complexType, xsd:simpleType, xsd:group, xsd:attributeGroup, globales xsd:element) ausgehend von den UML-Stereotypen und Tagged Values einer Klasse.

2. Komponenten, Entitäten & Schnittstellen

  • Eingangsknoten: Startknoten Class.
  • Entscheidungsknoten (Verzweigungen):
    • stereotype: Verzweigung nach Stereotypen ([not enumeration && not primitive], [enumeration], [primitive]).
    • simple content: Fallunterscheidung ([no], [yes]) bei nicht-abstrakten Klassen (class is not abstract).
    • global element: Fallunterscheidung nach [xml.globalElement = true] und [xml.globalElement = false].
    • has attributes: Fallunterscheidung ([yes], [no]) für Klassen mit gesetztem xml.xsd.customType.
    • Zusammenführungsknoten (Merge Nodes) für Pfad-Konsolidierungen vor dem Endzustand.
  • Aktivitätsknoten (Generierungsregeln):
    • [APRXML003] Create xsd:complexType
    • [APRXML0024] Create xsd:complexType with simple content
    • [APRXML0001] Create xsd:group (sowohl für Standard-Properties als auch bedingt nach has attributes)
    • :[APRXML0001] Create xsd:group
    • [APRXML0002] Create xsd:attributeGroup
    • [APRXML0025] Create xsd:simpleType for subtypes
    • [APRXML0007] Create xsd:simpleType for enumeration
    • [APRXML0006] Create reference to predefined datatype
    • [APRXML0005] Create global xsd:element
    • [APRXML0026] Create a custom simple type
  • Parallelisierungs- und Synchronisationsbalken (Fork/Join-Bars):
    • Verzweigung und Zusammenführung paralleler Pfade für reguläre Klassen ([not enumeration && not primitive]) sowie für primitive Typen.
  • Notiz / Bedingungsdefinition:
    • Bedingung für simple content = true: Genau eine (eigene oder abgeleitete) Property ist nicht auf ein XML-Attribut gemappt, deren Typ ist <<primitive>> oder <<enumeration>>, ihre obere Multiplizität ist 1 und xml.*Element-Tagged-Values sind false.

3. Dynamisches Verhalten & Sequenzablauf

  1. Ausgehend von Class erfolgt die Auswertung der Verzweigung stereotype:
    • Pfad [not enumeration && not primitive]:
      • Durchläuft einen Fork-Balken zur parallelen Evaluierung von vier Bedingungen:
        • Für nicht-abstrakte Klassen (class is not abstract) Verzweigung nach simple content: Ergibt [APRXML0024] Create xsd:complexType with simple content (bei [yes]) bzw. [APRXML003] Create xsd:complexType (bei [no]). Anschließend Prüfung auf global element: Wenn [xml.globalElement = true], wird [APRXML0005] Create global xsd:element ausgeführt; bei [xml.globalElement = false] wird die Aktion übersprungen und gemergt.
        • Bedingung [has property with 'xml.attribute = false']: Ausführung von [APRXML0001] Create xsd:group.
        • Bedingung [has property with 'xml.attribute = true']: Ausführung von [APRXML0002] Create xsd:attributeGroup.
        • Bedingung [is referenced]: Ausführung von [APRXML0025] Create xsd:simpleType for subtypes.
      • Alle vier Pfade werden über einen Join-Balken synchronisiert.
    • Pfad [enumeration]:
      • Führt direkt zur Aktion [APRXML0007] Create xsd:simpleType for enumeration.
    • Pfad [primitive]:
      • Verzweigt an einem Fork-Balken in zwei alternative Pfade:
        • Bedingung ['xml.xsd.type' or 'xml.mds.type' is set]: Ausführung von [APRXML0006] Create reference to predefined datatype.
        • Bedingung ['xml.xsd.customType' is set]: Ausführung von [APRXML0026] Create a custom simple type, gefolgt von Verzweigung has attributes: Bei [yes] wird :[APRXML0001] Create xsd:group ausgeführt, bei [no] erfolgt keine zusätzliche Gruppenerzeugung.
      • Beide Zweige werden an einem Join-Balken zusammengeführt.
  2. Alle Hauptstränge münden in einen zentralen Merge-Knoten, der in den Aktivitätsendknoten führt.

4. Normative Relevanz & Entwickler-Hinweise

Das Diagramm definiert verbindliche Transformationsregeln (APRXML*) für Schema-Generatoren zur Erstellung der AUTOSAR-XML-Schemata (ARXML) aus dem M2-Metamodell. Schema-Generatoren müssen sicherstellen, dass bei komplexen Typen ohne Attribute oder ohne Unterelemente die entsprechenden Groups bzw. AttributeGroups nur bedarfsabhängig referenziert oder erzeugt werden. Besondere Beachtung erfordert die semantische Auswertung von simple content, da hier restriktive Vorbedingungen bezüglich Multiplizität und Primitiv-/Enumeration-Typbindung einzuhalten sind.
