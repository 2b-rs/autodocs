1. Diagrammtyp & Architektur-Kontext

  • Klassifikation: UML-Sequenzdiagramm (Interaktionsdiagramm mit opt-Kombinationsfragmenten).
  • Funktionaler Kontext: AUTOSAR Classic Platform (SWS TimeSyncOverEthernet, R24-11), Subsystem Ethernet Time Synchronization (EthTSyn).
  • Technischer Zweck: Spezifikation des asynchronen Verarbeitungsablaufs beim Empfang von Time-Synchronization-Frames (Sync und nachfolgendem Follow_Up) an einem Ethernet-Switch-Port in Szenarien ohne integrierten Global Time Master am Switch (SwitchWithoutGTM). Es visualisiert das Zusammenspiel zwischen Ethernet Interface (EthIf), Large SDU Router (LSduR), Hardware-Switch-Objektverwaltung (EthIfSwitchManagementSupport) und Entkopplung in den Task-Kontext (EthTSyn_MainFunction) bis zur Weitergabe der berechneten Zeitbasis an den Synchronized Time-Base Manager (StbM).

2. Komponenten, Entitäten & Schnittstellen

Akteure / BSW-Module (Lifelines)
  • «module» EthIf (Ethernet Interface): Vermittelt zwischen Switch-Treiber (EthSwt) und oberen Schichten; liefert Rx-Indikationen an den Routing-Layer und verwaltet Switch-Management-Objekt-Puffer.
  • «module» LSduR (Large SDU Router): Vermittlungsinstanz im Ethernet-Empfangspfad; nimmt Rx-Indikationen von EthIf entgegen und leitet PTP-Nachrichten an das Zielmodul EthTSyn weiter.
  • «module» EthTSyn (Time Synchronization over Ethernet): Implementiert das gPTP-Protokoll (IEEE 802.1AS / AUTOSAR-Profil), evaluiert Frame-Inhalte, korreliert Port-Timestamps und führt die Residuen-/Kompensationsberechnungen durch.
  • «module» StbM (Synchronized Time-Base Manager): Zentrale Instanz zur Verwaltung synchronisierter Zeitbasen im Steuergerät; empfängt bereinigte globale Zeitwerte und Messdaten.
Schnittstellen & Datentypen
  • LSduR_EthIfRxIndication():
    • Empfangsindikation des Ethernet-Interfaces an den Large SDU Router zur Weiterleitung empfangener Ethernet-Frames.
  • EthTSyn_RxIndication():
    • Empfangsindikation für PTP-Frames, aufgerufen durch den LSduR zur Übergabe an den Rx-Pfad von EthTSyn.
  • EthIf_GetRxMgmtObject():
    • Synchroner Aufruf zur Reservierung und Abfrage des Zeigers auf die switch-spezifische Management-Struktur (EthSwt_MgmtObjectType) für Hardware-Timestamps und Port-Zuordnungen.
  • EthTSyn_MainFunction():
    • Zyklische BSW-Hauptfunktion (Task-Ebene) zur Entkopplung rechenintensiver Timestamp-Verarbeitung und Validierung.
  • StbM_BusSetGlobalTime():
    • Synchroner Aufruf zur Übergabe der aktualisierten Master-Zeit und Messdaten an StbM.
  • Objekt-Attribute & States:
    • EthSwt_MgmtObjectType: Enthält MgmtInfo (SwitchIdx, SwitchPortIdx) sowie Ownership (ETHSWT_MGMT_OBJ_OWNED_BY_<UPPER_LAYER>, ETHSWT_MGMT_OBJ_UNUSED).
    • Timestamps: Port-Ingress-Timestamp T_4, Port-Egress-Timestamp T_5 (für Verweildauer- bzw. Laufzeitkorrekturen im Switch).

[EthIf]             [LSduR]             [EthTSyn]            [StbM]
   |                   |                    |                  |
   |-- LSduR_EthIfRxIndication() ---------->|                  |
   |                   |-- EthTSyn_RxIndication() ------------>|
   |                   |                    |                  |

   |                   |                    |                  |
   |                       [opt: EthIfSwitchManagementSupport == ON]

   |                   |                    |                  |
   |                   |                    |-- (Task-Trigger) |
   |                   |                    |-- EthTSyn_MainFunction()
   |                   |                    |                  |
   |                       [opt: EthIfSwitchManagementSupport == ON]
   |                   |                    |-- Validiere Switch/Port/Owner
   |                   |                    |-- [Type == Sync]:
   |                   |                    |   Hole T4 / T5   |
   |                   |                    |-- Ownership = UNUSED
   |                   |                    |                  |
   |                   |                    |-- StbM_BusSetGlobalTime() -->|
   |                   |                    |<-- (return) -----|
  1. Empfangskette & Allokation (Rx-Pfad):
    • EthIf signalisiert den Frame-Empfang via LSduR_EthIfRxIndication() an das Modul LSduR.
    • LSduR leitet den Frame über EthTSyn_RxIndication() an EthTSyn weiter.
    • Bei Bedingung [Type == Sync] und aktivem Schalter [EthIfSwitchManagementSupport == ON] ruft EthTSyn synchron EthIf_GetRxMgmtObject() auf.
    • Bei Rückgabe [== E_OK] speichert EthTSyn das Objekt (usedRxMgmtObjectPtr = *MgmtObjectPtr) mit Status ETHSWT_MGMT_OBJ_OWNED_BY_<UPPER_LAYER>.
  2. Entkoppelte Verarbeitung (Task-Pfad):
    • Die Auswertung der Zeitstempel erfolgt asynchron innerhalb der zyklischen Funktion EthTSyn_MainFunction().
    • Unter [EthIfSwitchManagementSupport == ON] prüft EthTSyn die Identität von SwitchIdx, SwitchPortIdx sowie den Status Ownership == ETHSWT_MGMT_OBJ_OWNED_BY_<UPPER_LAYER>.
    • Bei erfolgreicher Prüfung signalisiert der Zustand: usedRxMgmtObject timestamps ready to use.
  3. Zeitstempel-Extraktion & Ressourcenfreigabe:
    • Für [Type == Sync] liest EthTSyn den Port-Ingress-Timestamp T_4 und den Port-Egress-Timestamp T_5 aus.
    • Unmittelbar anschließend erfolgt die Freigabe des Management-Objekts über usedRxMgmtObject->Ownership = ETHSWT_MGMT_OBJ_UNUSED.
  4. Zeitbasis-Aktualisierung:
    • EthTSyn ruft synchron StbM_BusSetGlobalTime() auf, um die berechnete Zeitbasis an das Modul StbM zu übermitteln.

4. Normative Relevanz & Entwickler-Hinweise

  • Rx-Routing über LSduR:
    • Der Empfangspfad führt von EthIf über LSduR zu EthTSyn. Integratoren müssen sicherstellen, dass die Routing-Tabellen im LSduR für PTP-Ethertype-Frames korrekt auf EthTSyn konfiguriert sind.
  • Puffer- und Ressourcen-Management (EthSwt / EthIf):
    • Da Switch-Management-Objekte zwischen dem ISR-Kontext (LSduR_EthIfRxIndication / EthTSyn_RxIndication) und der zyklischen EthTSyn_MainFunction gebunden bleiben, muss der Objekt-Pool in EthSwt ausreichend groß dimensioniert sein, um Pufferüberläufe (E_NOT_OK) bei Burst-Traffic zu vermeiden.
  • Laufzeit- und Thread-Sicherheit:
    • Das Anfordern via EthIf_GetRxMgmtObject() und das Freigeben (Ownership = UNUSED) erfolgen in unterschiedlichen Ausführungskontexten (Rx-Interrupt/Task vs. zyklische MainFunction). Der Zugriff auf die Ownership-Zustände erfordert atomare Operationen oder Critical Sections.
  • Konfigurationsschalter:
    • Das Switch-Timestamp-Handling ist an die Präprozessorkonfiguration EthIfSwitchManagementSupport == ON gekoppelt. Bei inaktiver Option unterbleibt die Ingress-/Egress-Kompensation über Switch-Management-Objekte.
  • Fehlerbehandlung:
    • Bei Nichtübereinstimmung der Switch- bzw. Port-Indizes oder falschem Ownership-Status dürfen T_4 und T_5 nicht verarbeitet werden; das Objekt ist freizugeben und der Frame zu verwerfen.
