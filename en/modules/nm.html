Purpose and model relationship

Network Management controls logical network handles, which can be mapped to partial networks, VLANs and/or physical channels. State Management is the intended user of the NetworkHandle interface. SWS Network Management §7.3 “NetworkControl”

Condition and requirement

GetNetworkState() reports kFullCom only if all assigned power supplies are active; a kFullCom request can request the associated parts. [SWS_ANM_00083] [SWS_ANM_00084]

Interpretation: The API separates the requested state from the actually achieved state, so that state management can treat desired and observed availability separately.
