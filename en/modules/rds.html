Classification & Purpose

Raw data streams transmit binary data as a connection between client and server over IP-based protocols. RawDataStreamClient and RawDataStreamServer are created for modeled port interfaces [SWS_RDS_10481] [SWS_RDS_11311].

IP-based process

The client connects using Connect, the server side waits through WaitForConnection; both sides then read or write data and terminate the connection through Shutdown [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].

Connection and transfer sequence. Source: SWS Raw Data Stream §7.1.4, Chapter 8. The temporal summary is an interpretation.

IEEE 1722

For data transfer on the data link layer, the API describes typed IEEE 1722 datagrams as well as producer and consumer classes [SWS_RDS_90225] [SWS_RDS_90311] [SWS_RDS_90322].

Connection states

Stream connection state diagram. Source: SWS Raw Data Stream §7.1.4. Interpretation: The states condense create, connect and shutdown operations.

System context

The interface is intended for efficient data flows in addition to service-oriented communication (EXP ARACom API); The specification describes configuration, access control and secured channels in Chapter 7.

Interpretation: The page places the separate IP and IEEE 1722 APIs in a shared usage perspective.
