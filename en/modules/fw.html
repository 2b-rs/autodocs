Classification & Purpose

The firewall inspects and filters network packets. It can apply rules depending on the firewall state; For this purpose, the API binds modeled FirewallStateSwitchInterface ports to ara::fw::FirewallStateSwitchInterface [AP_SWS_Fw_82001].

Change of state

An application creates the interface with a InstanceSpecifier and asynchronously requests a change to [AP_SWS_Fw_82002] [AP_SWS_Fw_82008] via SwitchFirewallState. The possible state types and enumerator values ​​are generated from the modeled firewall states according to ara::fw::states [AP_SWS_Fw_81001] [AP_SWS_Fw_81002].

Error handling

FwErrc distinguishes between interrupted communication to the firewall daemon and a state that is not used by any stateful firewall rule [AP_SWS_Fw_83001]. The error domain provides error code and exception bindings [AP_SWS_Fw_83002] [AP_SWS_Fw_83006].

Architecture context

In the platform design, the firewall is to be classified as a security function between network access and applications (EXP Platform Design). The connection to state management in the diagram describes the context of state-dependent rules, not an additional public API.
