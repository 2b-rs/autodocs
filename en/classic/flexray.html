The regular transmission data flow begins at the upper layers (e.g. COM or FrTp), which pass PDUs using FrIf_Transmit [SWS_FrIf_05033]. Typical lifecycles and operating modes

Initialization of the cluster takes place hierarchically: The BSW initialization sequence starts with FrSM_Init, causing all cluster state machines to transition to the base state FRSM_READY [SWS_FrSM_00013] [SWS_FrSM_00126]. Subsequently, the controllers are initialized via FrIf_ControllerInit [SWS_FrIf_05004], and the FrTp module transitions from state FRTP_OFF to FRTP_ON via FrTp_Init [SWS_FrTp_01032] SWS FlexRayStateManager p. 35.

In doing so, the Communication Controller traverses the POC state machine (Protocol Operation Control) in accordance with the FlexRay specification: From state POC:ready, command RUN initiates the transition to POC:startup via Fr_StartCommunication [SWS_Fr_00010]. If the ECU is configured as a coldstart node, the CHI command ALLOW_COLDSTART is issued via Fr_AllowColdstart [SWS_Fr_00114]. After successful integration and synchronization, the controller reaches POC:normal active or POC:normal passive [SWS_Fr_00507] [SWS_Fr_00509] SWS FlexRayDriver p. 42.

Before communication starts, a sleeping bus requires a wakeup sequence: FrSM coordinates single-channel or dual-channel wakeups. The wakeup channel is parameterized via FrIf_SetWakeupChannel, the transceivers are switched to FRTRCV_TRCVMODE_NORMAL, and the wakeup pattern (WUP) is transmitted onto the bus via FrIf_SendWUP and Fr_SendWUP, respectively [SWS_Fr_00009] [SWS_FrIf_05011] [SWS_FrIf_05034]. The wakeup cause can be evaluated via FrTrcv_GetTransceiverWUReason [SWS_FrTrcv_00325] SWS FlexRayStateManager p. 50.

During shutdown, FrSM transitions from COMM_FULL_COM to COMM_NO_COM upon request of ComM. Communication is stopped via FrIf_HaltCommunication, FrIf transitions to offline mode via FrIf_SetState(FRIF_GOTO_OFFLINE), and the transceivers are placed into STANDBY [SWS_FrIf_05006]. For diagnostic or protection cases, clusters can be set to a receive-only mode (ECU Passive) via FrSM_SetEcuPassive [SWS_FrSM_00174]. A complete FrTp stop takes place via FrTp_Shutdown [SWS_FrTp_00148] SWS FlexRayStateManager p. 58.

Incorrect operations and invalid API parameters are recorded via the Development Error Tracer (DET).
