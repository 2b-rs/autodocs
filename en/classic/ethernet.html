Architekturüberblick Ethernet Services

Das Ethernet Services Cluster bildet den Hochgeschwindigkeits-Kommunikationsstack der Classic Platform ab. Es umfasst den Ethernet Driver (Eth) [SWS_Eth_00027], das Ethernet Interface (EthIf) [SWS_EthIf_00024], den TCP/IP-Stack (TcpIp) sowie den Socket Adaptor (SoAd). Das Cluster bietet Zero-Copy-Pufferung via Eth_Transmit [SWS_Eth_00041], VLAN-Tagging nach IEEE 802.1Q und die Grundlage für moderne Service-Orientierte Architekturen (SOME/IP) sowie DoIP-Diagnose.

Interpretation: Eth_Transmit is the driver-level transmit function of the Ethernet interface. It passes a buffer directly to MAC transmit descriptors. Frame header generation precedes this step.

Interpretation: IEEE 802.1Q appears in standard Classic Ethernet architecture as a VLAN assignment on the Ethernet interface: a logical controller carries a VLAN ID, EthIf selects the controller. Record CP_ETH provides no field for this.

Interpretation: AVB (Credit-Based Shaper, 802.1Qav) and TSN (Time-Aware Shaper, 802.1Qbv) require hardware support in the switch or controller. Eth_Transmit is a generic transmit call without traffic class assignment. Document name: AUTOSAR_SWS_EthernetInterface, not registered here.
