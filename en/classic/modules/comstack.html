Communication Stack Types (ComStack_Types)

Standardized types, PDU identifiers, lengths, and buffer request types (PduIdType, PduLengthType, PduInfoType, BufReq_ReturnType) used across all communication layers.

type PduIdType [SWS_COMTYPE_00005]

typedef uint16 PduIdType;

This type is used within the entire AUTOSAR Com Stack except for bus drivers.

type PduLengthType [SWS_COMTYPE_00008]

typedef uint16 PduLengthType;

This type shall be used within the entire AUTOSAR Com Stack of an ECU except for bus drivers.

type PduInfoType [SWS_COMTYPE_00011]

typedef struct {
    uint8* SduDataPtr;
    uint8* MetaDataPtr;
    PduLengthType SduLength;
} PduInfoType;

Variables of this type shall be used to store the basic information about a PDU of any type, namely a pointer variable pointing to its SDU (payload), a pointer to Meta Data of the PDU, and the corresponding length of the SDU in byt es.

type PNCHandleType [SWS_COMTYPE_00036]

typedef uint8 PNCHandleType;

Used to store the identifier of a partial network cluster.

type TPParameterType [SWS_COMTYPE_00031]

typedef enum {
    TP_STMIN,
    TP_BS,
    TP_BC
} TPParameterType;

Specify the parameter to which the value has to be changed (BS or STmin).

type BufReq_ReturnType [SWS_COMTYPE_00012]

typedef enum {
    BUFREQ_OK,
    BUFREQ_E_NOT_OK,
    BUFREQ_E_BUSY,
    BUFREQ_E_OVFL
} BufReq_ReturnType;

Variables of this type shall be used to store the result of a buffer request.

type TpDataStateType [SWS_COMTYPE_00027]

typedef enum {
    TP_DATACONF,
    TP_DATARETRY,
    TP_CONFPENDING
} TpDataStateType;

Variables of this type shall be used to store the state of TP buffer.

type RetryInfoType [SWS_COMTYPE_00037]

typedef struct {
    TpDataStateType TpDataState;
    PduLengthType TxTpDataCnt;
} RetryInfoType;

Variables of this type shall be used to store the information about Tp buffer handling.

type NetworkHandleType [SWS_COMTYPE_00038]

typedef uint8 NetworkHandleType;

Variables of the type Network Handle Type shall be used to store the identifier of a communication channel.
