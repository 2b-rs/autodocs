Architekturüberblick Diagnostic Services

Das Diagnostic Services Cluster der AUTOSAR Classic Platform bündelt den Diagnostic Event Manager (DEM) [SWS_Dem_00183], den Diagnostic Communication Manager (DCM) [SWS_Dcm_00037], den Default Error Tracer (DET) und das Diagnostic Log and Trace (DLT) Modul. Es deckt das vollständige Spektrum fahrzeuginterner Fehlerbehandlung ab: Von der Erfassung temporärer Fehler über Entprellung und Freeze-Frame-Speicherung bis hin zur standardisierten UDS- und OBD-Kommunikation mit Werkstatt-Testern und Entwicklungswerkzeugen [SWS_Dem_00665].

Module im Cluster

Diagnostic Event Manager (DEM)

The DEM is responsible for processing and storing diagnostic events, fault memories, DTC statuses, and associated freeze frame data.

BSW ID 54 141 APIs (109 Funktionen, 32 Typen) #include "Dem.h"

Diagnostic Communication Manager (DCM)

The DCM implements unified diagnostic services according to ISO 14229-1 (UDS) and ISO 15765-4 (OBD). It manages diagnostic sessions, security levels, and service routing.

BSW ID 53 123 APIs (82 Funktionen, 41 Typen) #include "Dcm.h"

Default Error Tracer (DET)

The DET handles development errors, runtime errors, and transient faults across all BSW modules and SW-Cs.
