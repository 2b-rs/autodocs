Record CP_MCAL documents Mcu_Init(const Mcu_ConfigType* ConfigPtr) under repository identifier [SWS_CP_MCAL_00001].

Interpretation: MCAL drivers constitute the register abstraction layer directly above hardware. Mcu_Init configures pin directions, electrical characteristics, and alternate functions. Configuration is generated statically; dynamic reconfiguration is not intended in Classic.

Interpretation: DMA channels belong to driver configuration (e.g., in SPI or ADC). They transfer data blocks without CPU intervention. Mcu_Init does not touch DMA directly, but must run before DMA-coupled peripheral drivers initialize.

Interpretation: Hardware callbacks run in interrupt contexts (ISR Category 1 or 2). Execution time in the Port driver is bounded and deterministic. Non-preemptive sections protect register access.
