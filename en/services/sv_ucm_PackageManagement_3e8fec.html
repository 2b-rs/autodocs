One service, three professional levels

PackageManagement separates packet acceptance, packet processing and modification of the running software cluster set. CurrentStatus is the global view of the currently executing UCM phase; Transfer IDs clearly assign individual transfers. SWS UCM Chapter 7 “Functional specification” [SWS_UCM_00361]

Robust block transfer

TransferStart reserves resources and provides transfer ID and maximum block size. TransferData checks ID, order, size and, if necessary, block consistency. TransferExit is only permitted after data blocks and checks completeness and packet format. Errors in the transfer must therefore be treated per transfer and not interpreted as activation errors. [SWS_UCM_00272] [SWS_UCM_00275] [SWS_UCM_00276]

Activity diagram from block transfer to activation. Sources: SWS UCM §7.3 “Transfer and processing”, SWS UCM §7.5 “Activation and rollback”. Partial interpretation: The representation emphasizes the client order, although individual transfers and processing may be decoupled in time.

Processing, activation and withdrawal

According to ProcessSwPackage, Activate may only be started from the preparation phase for processed packets. Activation requests an update session from SM. Verification determines completion or restoration; Rollback has an explicit false exit and can be retried from kRollingBackFailed. [SWS_UCM_00241] [SWS_UCM_00257] [SWS_UCM_00300] [SWS_UCM_00301]

Status and query operations

GetProgress, GetSwPackages, cluster queries, and GetHistory serve monitoring and auditability; they do not replace a status check before a state-dependent operation. Suspend/Resume concern long-running actions and must be interpreted in conjunction with CurrentStatus. SWS UCM §7.6 “Progress and interruption”

Client checklist

  1. Use the maximum block size and transfer ID provided by TransferStart unchanged.
  2. Transfer all blocks before TransferExit and evaluate the transfer ID-specific cause for each error.
  3. After processing, observe CurrentStatus and only call Activate in the permitted phase.
  4. If the verification result is negative, choose the documented rollback path instead of reactivation.
