Configuration by data ID

This service interface provides verification status configuration for the protection context determined by a data ID. It is part of the platform integration around E2E/Freshness Value Management, not a service modeled by a specialist application.

Embedding

The Communication Management Specification specifies the verification status interfaces related to SecOC/Freshness processing. A caller must use data ID and associated configuration consistently from the same deployment context. (Interpretation: The consistency requirement follows the configuration-based assignment of security functions.) SWS CM §7.3.2 “Secure Communication” gives the context.

Collaboration: The FVM platform extension provides or checks Freshness Values for SecOC; the verification status is passed to the configured status interface. Sources: SWS CM §7.3.2 “Secure Communication”, EXP SW Architecture §9.3.1.1.3 “Interfaces for freshness value management”.
