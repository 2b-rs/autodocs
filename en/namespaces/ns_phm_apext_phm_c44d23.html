Extension point for the watchdog

apext::phm contains the platform extension through which PHM communicates its liveness to the watchdog or triggers a reaction. The namespace is not an application code API for checkpoint messages; these are in ara::phm SWS Platform Health Management §7 “Functional specification”.

System-wide significance

The watchdog route is only used for errors that are critical or can no longer be handled in a coordinated manner, especially if supervision from Execution Management or State Management escalates to kSTOPPED SWS PHM §7.5.2 “Handling of Hardware Watchdog”.
