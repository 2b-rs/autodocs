OEM/integration-related power state types

The namespace contains the power state and the wake-up handler for the optional platform extension. The semantics are tied to suspend-to-RAM and the concrete integration. [SWS_SM_71002] SWS StateManagement Chapter 7 “Functional specification”

Application context

The common State Management application context applies (Manifest- and integration-dependent state coordination, evaluation of return values and errors in the calling role); it is described in the guide for namespace ara::sm § “Application context”.
