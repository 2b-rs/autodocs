Time base building block namespace apext::tsync

apext::tsync belongs to the global and local time base interface. Each timebase provides time value and state snapshot; the synchronization mechanism works in the master/slave context. SWS Time Synchronization §7.1 “General Overview” SWS Time Synchronization §7.2 “Normal Operation”

The API values should be evaluated together with synchronization status, leap information and, if necessary, user data. The specific wire protocol lies outside this SWS and is referenced there as a PRS context. SWS Time Synchronization §7.1 “General Overview”
