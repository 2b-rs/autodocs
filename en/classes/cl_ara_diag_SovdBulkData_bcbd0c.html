intended use

SovdBulkData is the generic interface for SOVD bulk data. It reads metadata, starts download or upload sessions and deletes either all data in a category or a specific instance. [SWS_DM_01841] [SWS_DM_01853] [SWS_DM_01873] [SWS_DM_01854] [SWS_DM_01855] [SWS_DM_01856] The Diagnostic Server calls these methods for the corresponding SOVD methods. [SWS_DM_01791] [SWS_DM_01792] [SWS_DM_01793] [SWS_DM_01794] [SWS_DM_01795]

Creation & lifecycle

The constructor requires a PortPrototype of DiagnosticSovdBulkDataInterface and a ConcurrencyType. [SWS_DM_01847] Offer() enabled, StopOffer() disabled request forwarding; Offer can supply kConfigurationMismatch or kAlreadyOffered. [SWS_DM_01857] [SWS_DM_01858] Copy and copy assignment are prohibited, while move construction and move assignment are provided. [SWS_DM_01848] [SWS_DM_01850] [SWS_DM_01849] [SWS_DM_01851]

Interaction with other classes

A download provides either a reading session with BulkDataMetaDataDescriptor or a HttpRedirect. [SWS_DM_01873] An upload provides a write session with a metadata descriptor; DeleteAllBulkData() returns DeleteByCategoryResult. [SWS_DM_01854] [SWS_DM_01855]

Limitations & Error handling

The data processing methods provide applicable SOVD error codes upon failure and their thread safety depends on the ConcurrencyType. [SWS_DM_01854] [SWS_DM_01855] [SWS_DM_01856] [SWS_DM_01873] CancellationHandler informs about a canceled conversation. [SWS_DM_01853] Offer and StopOffer are not thread-safe. [SWS_DM_01857] [SWS_DM_01858]

GetBulkDataMetaData() returns a vector of all bulk data instances of the requested category and does not specify standardized errors. [SWS_DM_01853] DeleteSpecificBulkData() processes category and bulk data ID, while DeleteAllBulkData() returns a result with successes and deletion errors. [SWS_DM_01855] [SWS_DM_01856] The constructor and the move construction are exception-safe and thread-safe. [SWS_DM_01847] [SWS_DM_01849]
