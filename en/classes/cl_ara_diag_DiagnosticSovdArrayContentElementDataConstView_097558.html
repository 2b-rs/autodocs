Purpose The const view provides read access to a DiagnosticSovdContentElementData of type ArrayContentElementData. It provides const iterators over Begin/End and CBegin/CEnd, as well as size, capacity and empty state. The index access returns a ara::core::Result with constant element reference or an error if the content is not an array. HasError reports an existing DiagSovdErrc. All operations are exception-safe and thread-safe.
