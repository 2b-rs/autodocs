class apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

intended use

UdsMessage represents a UDS message between the generic DM core or UdsTransportProtocolMgr and a concrete implementation of UdsTransportProtocolHandler. The object provides storage for UDS requests and responses. [SWS_DM_00291]

Generation & Ownership

Instances with optimized resource allocation are created exclusively by the DM core; A protocol handler can read and write them, but should not create them itself. The default constructor is therefore protected. If the indication is accepted, a UdsMessagePtr has a valid object with at least one byte capacity; initially its buffer supplied by GetPayload() is empty. [SWS_DM_09012] [SWS_DM_00385] [SWS_DM_00392]

Interaction with other classes

Non-constant payload access returns a writable ByteSpan; Constant access delivers the UDS data from SID without write access. After successful indication, a transport handler fills the payload from SID up to the capacity or until the end of the received message. Source, destination and physical or functional destination address type are available via getters; AddMetaInfo() adds meta information. [SWS_DM_00301] [SWS_DM_00300] [SWS_DM_00388] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00302]

restrictions

The destructor is virtual, implemented by default and exception-safe. The address getters are reentrant; both payload accesses and AddMetaInfo() are designated as not thread-safe. [SWS_DM_09010] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00300] [SWS_DM_00301] [SWS_DM_00302]
