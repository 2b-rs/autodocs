Purpose This const view enables read access to a SOVD element of type RecordContentElementData or ContentData. It provides const iterators, size, capacity and void queries, as well as search and key access. HasContentElement and index access returns ara::core::Result if the type does not match or the key does not exist; HasError may report DiagSovdErrc. All functions shown are exception-safe and thread-safe.
