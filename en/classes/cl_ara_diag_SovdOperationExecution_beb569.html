intended use

SovdOperationExecution represents the execution of an SOVD operation. ExecuteCapability() processes the execute, freeze, or reset capability, GetStatus() reads the status, and Terminate() terminates the current execution. [SWS_DM_02197] [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202] For a status-read call, the DM uses the instance assigned to execution-id and derives the status, capability, and response parameters from GetStatusResponse. [SWS_DM_02180] [SWS_DM_02181]

Lifecycle & Ownership

The constructor and virtual destructor are defaulted and exception-safe. [SWS_DM_02198] [SWS_DM_02199] After termination, the DM discards the instance; further calls with the same execution ID are no longer possible and their result is undefined. [SWS_DM_02179]

Limitations & Error handling

All three operation methods asynchronously return either the respective positive type or an applicable SOVD error. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202] The content data only remains valid until the promise is fulfilled or canceled. The CancellationHandler may not be stored or used beyond the lifespan of the respective operation. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202] The methods are exception-safe and thread-safe. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202]

For an asynchronously started operation, the DM uses the generated execution ID as an assignment to this execution instance. [SWS_DM_02177] Terminate() gets a reason for the termination, while GetStatus gets the current MetaInfo and a CancellationHandler. [SWS_DM_02202] [SWS_DM_02201] The implementation of these three pure virtual functions is up to the application. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202]

The virtual destructor allows destruction via the interface. [SWS_DM_02199]

Usage AI generated

Automatically generated usage note derived from this AUTOSAR R25-11 specification element—not official AUTOSAR text. Evidence: [SWS_…].

The ExecuteCapability virtual method is called to support execute / freeze / reset for the specified SOVD operation. Parameters are the OperationExecutionCapability to be executed, the sovd_content_data (valid until the promise is fulfilled or canceled via the cancellation_handler), meta_info with additional meta information and the cancellation_handler, which informs about a cancellation request and whose object is not stored or accessed beyond the lifetime of the call may be [SWS_DM_02384]. The returned ara::core::Future<OperationExecutionStatus> provides the execution status if the answer is positive, otherwise an SOVD error.

Error handling & concurrency

In the event of an error, an applicable SOVD error code according to ISO 17978-3 / ASAM SOVD 1.1 must be used. The method is thread-safe and exception-safe.
