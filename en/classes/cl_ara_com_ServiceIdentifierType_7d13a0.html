Identity of the service contract

ServiceIdentifierType holds the technical identity of a service interface in the generated communication contract. Together with instance and version information, it enables the binding to clearly classify an offer or a search.

Presentation instead of protocol detail

toString() is suitable for logging or diagnostics. The application should not interpret the value as a cross-transport format because ara::com precisely separates the network binding from the application view. SWS CM §7.1.2 “Design decisions” describes this abstraction.
