intended use

The view provides write and read access to content data of type RecordContentElementData or ContentData. It provides iterators, search, key access, and size and capacity queries. Interaction with other classes

Overloaded Add methods insert keyed elements as signed/unsigned Integer, double, bool, String or DiagnosticSovdContentElementData. Remove, Erase, Clear and Reserve change the record.
