intended use

UdsTransportProtocolPeriodicHandler supports the UDS function 0x2A for periodic data transmission. It provides the transport and connection specific boundaries and the transfer operation. [SWS_DM_01064]

Interaction with other classes

GetMaxPayloadLength() returns the maximum allowable payload length of a single periodic transmission for a channel. The DM uses ReadDataByPeriodicIdentifier to check the length of each requested identifier and responds with NRC 0x14 if it is exceeded. GetNumberOfPeriodicMessages() returns the allowed number of periodic messages for the connection. [SWS_DM_01066] [SWS_DM_01050] [SWS_DM_01065]

PeriodicTransmit() sends the passed message list in order. If a transmission fails, the sending process is ended and a periodic transmit confirmation is triggered with the same list and the number of messages sent; the DM uses this operation for triggered PDID transmissions. [SWS_DM_01067] [SWS_DM_01062]

restrictions

Destructor and methods are exception safe but not thread safe. [SWS_DM_02089] [SWS_DM_01065] [SWS_DM_01066] [SWS_DM_01067]
