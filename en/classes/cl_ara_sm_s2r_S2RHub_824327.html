Coordination of Suspend-to-RAM participants

S2RHub directs the suspend/resume order to the registered satellites and only then to the operating system. The return value of the asynchronous hub calls is only meaningful after the addressed satellites. [SWS_SM_00701] SWS StateManagement Chapter 7 “Functional specification”

Application context

The API is part of manifest and integration-dependent state coordination. Return values ​​and documented errors must be evaluated in the calling role; the configuration determines which instance and which authorization is used.
