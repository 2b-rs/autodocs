intended use

CancellationHandler encapsulates a shared state that signals cancellation of diagnostic service processing. Applications receive it as a parameter of asynchronous service callbacks and use IsCanceled() to check the cancellation status. [SWS_DM_00608] [SWS_DM_00614]

Lifecycle & Ownership

A default constructor is not available to applications; only the DM core creates the handler. Copying and copy assignment are deleted, while move construction and move assignment are available by default. [SWS_DM_00609] [SWS_DM_00611] [SWS_DM_00613] [SWS_DM_00610] [SWS_DM_00612]

Limitations & Error handling

IsCanceled() returns false until the associated conversation is canceled and true thereafter until the handler is destroyed. SetNotifier() registers a function to be executed upon cancellation; a further registration replaces the previous one. If a conversation is canceled during external service processing, the DM triggers all notifiers registered in this way. The methods are exception-safe but not thread-safe. [SWS_DM_00984] [SWS_DM_00615] [SWS_DM_01348] [SWS_DM_00577]
