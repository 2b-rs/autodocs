Configuration value for the set of processes

FunctionGroupState represents a configured state of a function group. Such a state determines which model processes should run when it is activated; There is exactly one active status per function group SWS EM §7.4.3 “Function Group State”.

Use in a transition request

State Management forms target states from FunctionGroup and state names and passes them to StateClient::SetState. Execution Management terminates processes that are no longer required and then starts the processes intended for the target state in the required order SWS EM §7.4.5 “State Transition”.

State diagram: Off is the mandatory initial state; the active state is configured project-specifically [SWS_EM_01110] SWS EM §7.4 “State Management”. Interpretation: The representation abstracts concrete manifest state names.
