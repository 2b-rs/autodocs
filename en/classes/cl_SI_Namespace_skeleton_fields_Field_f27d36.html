intended use

This skeleton field class is generated for each element of the ServiceInterface modeled as a field. The namespace, name, and header <SiNamespaceDerivedDirectoryPath>/<SiShortname>_skeleton.h are derived from the ServiceInterface model of the ARXML manifest. It is used through its own service implementation that inherits from the generated Skeleton class. [SWS_CM_00007]

use

Update(value) updates the internal field value and triggers the transmission of updated data to subscribers; a notification is sent if the field's notifier is present. The return value signals success or a matching ComErrc. [SWS_CM_00119]

Asynchronous handlers can be registered for incoming getter or setter requests. The get handler only exists with Field.hasGetter == TRUE, the set handler only with Field.hasSetter == TRUE; both have overloads for a provided execution context. A transport fault handler can be set and removed. [SWS_CM_00114] [SWS_CM_11360] [SWS_CM_00116] [SWS_CM_11362] [SWS_CM_00096] [SWS_CM_00097] [SWS_CM_00098]

Interaction

The created class is a field member of the service skeleton. The skeleton is instantiated with an InstanceSpecifier, the derived service implementation overrides its pure virtual methods and offers the service via OfferService() or terminates the offer with StopOfferService(). [SWS_CM_00007]
