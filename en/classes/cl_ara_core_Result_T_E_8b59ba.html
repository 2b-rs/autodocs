class ara::core::Result< T &, E >

[SWS_CORE_00901] Upstream: RS_AP_00130

template <typename T, typename E> class Result< T &, E > final {...};

Specialization of class Result for reference to value types. The implementation shall flag the condition E!=ara::core::ErrorCode as a compile error.

intended use

ara::core::Result<T&,E> is the Result specialization for lvalue references. It can contain either a reference to a value or an error, thereby enabling synchronous error handling for reference values ​​without exception. [SWS_CORE_00901] [SWS_CORE_00069] [SWS_CORE_10600]

Lifecycle & Ownership

Copy and move operations are available. When assigning a Result with a value, the contained reference is rebound to the source's referenced object; it does not copy the referenced object. Construction from a value is permitted only from an lvalue reference; otherwise, the program is ill-formed. [SWS_CORE_00911] [SWS_CORE_00912] [SWS_CORE_00914] [SWS_CORE_00915] [SWS_CORE_00908] [SWS_CORE_00070]

Interaction with other classes

Ok(), if applicable, provides a Optional<T&>, Value() a direct reference access; Err() provides the error as Optional<E>. Bind() and Resolve() support processing the value or error. [SWS_CORE_00927] [SWS_CORE_00925] [SWS_CORE_00931] [SWS_CORE_00941] [SWS_CORE_00940]

Limitations & Error handling

Value and error access in the respective non-contained state are specified as violations; ValueOrThrow() can trigger. [SWS_CORE_13009] [SWS_CORE_13010] [SWS_CORE_00938] [SWS_CORE_00949]
