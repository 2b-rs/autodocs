BulkDataMetaDataDescriptor describes metadata of a bulk data instance. [SWS_DM_01830] It contains identification and naming information (id, name, translation_id), file information (file_name, mimetype, optional size), and creation and modification time. [SWS_DM_01831] [SWS_DM_01833] [SWS_DM_01834] [SWS_DM_01836] [SWS_DM_01832] [SWS_DM_01835] [SWS_DM_01837] [SWS_DM_01838] Additionally, hash and hash_algorithm specify the bulk data hash and its algorithm. [SWS_DM_01839] [SWS_DM_01840]
