intended use

ara::core::Map<Key, T, Compare, Allocator> implements the associative std::pmr::map container. The stored value type is std::pair<const Key, T>; Comparison and memory management are parameterized via Compare and Allocator [SWS_CORE_01400] [SWS_CORE_01404] [SWS_CORE_01405] [SWS_CORE_01406].

Generation & destruction

The container is standard, copy and move constructible and can also be constructed from a range, initializer list, comparator or allocator [SWS_CORE_01428] [SWS_CORE_01424] [SWS_CORE_01426] [SWS_CORE_01430] [SWS_CORE_01434]. Copy assignment is defaulted; the exception safety of the move assignment depends on the allocator and comparator [SWS_CORE_01425] [SWS_CORE_01427].

Interaction with other classes

The type provides iterators including reverse iterators, size queries, key access, and search operations [SWS_CORE_01413] [SWS_CORE_01440] [SWS_CORE_01452] [SWS_CORE_01456] [SWS_CORE_01490] [SWS_CORE_01498]. Insert, try_emplace, insert_or_assign, remove, extract and merge follow the std::map semantics [SWS_CORE_01458] [SWS_CORE_01473] [SWS_CORE_01479] [SWS_CORE_01483] [SWS_CORE_01470] [SWS_CORE_01486].

Limitations & Error handling

at() triggers a IsoStdOutOfRangeViolation for a key not included; operator[], on the other hand, follows the std::map semantics [SWS_CORE_01456] [SWS_CORE_01457] [SWS_CORE_01454] [SWS_CORE_01455]. The specification does not provide exception security for numerous container modifying and searching operations [SWS_CORE_01458] [SWS_CORE_01483] [SWS_CORE_01490].
