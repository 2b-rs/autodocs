class ara::diag::DataTransferReadByPullHandler

[SWS_DM_01506] Upstream: RS_Diag_04135

class DataTransferReadByPullHandler {...};

Handles data transfers initiated by RequestReadFile/-Directory with data pulled by AraDiag from the implementation.

intended use

DataTransferReadByPullHandler implements read data transfers to RequestReadFile or RequestReadDirectory, where AraDiag retrieves the data piecemeal from the application. Read() receives a writable byte span pre-allocated by the system and asynchronously delivers the actually entered bytes. [SWS_DM_01506] [SWS_DM_01513]

Lifecycle & Ownership

The handler cannot be copied for one-time use per individual file transfer session, but is movable and move-assignable. It may only be destroyed after ExitRead() has been called. This method ends the current transfer session and asynchronously returns the transfer response parameter record or a UDS error. [SWS_DM_01509] [SWS_DM_01508] [SWS_DM_01511] [SWS_DM_01510] [SWS_DM_01514]

Limitations & Error handling

Read and ExitRead get MetaInfo and CancellationHandler; The data view or the transfer parameter record only remains valid until the future is fulfilled or canceled. Both methods are exception-safe, not thread-safe, and use an appropriate DiagUdsNrcErrc if the result is negative. [SWS_DM_01513] [SWS_DM_01514]
