Role in the Crypto Stack

ara::crypto::Serializable is part of the common crypto API. It supports provider and context interfaces in handling data, errors, formats, or key operations unambiguously. SWS Cryptography §7.1 “Architecture & Concepts”

Classification in use

The API is embedded in a model of providers, key slots, key objects and contexts. An application therefore chooses not only a method, but also an approved provider, a suitable algorithm identifier and, if necessary, an approved key resource. SWS Cryptography §7.1.2 “Usage of Crypto” SWS Cryptography §7.1.5 “Identification of Cryptographic Transformations and Key Types”
