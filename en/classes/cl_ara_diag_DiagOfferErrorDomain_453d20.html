DiagOfferErrorDomain is a final error domain for diagnostic offer errors and derives from ara::core::ErrorDomain. Its constexpr default constructor is exception-safe and thread-safe. [SWS_DM_00989] [SWS_DM_00992]

Name() returns the short name of the application error domain; Message() translates an error code into never-zeroed text. ThrowAsException() throws the exception corresponding to ErrorCode and is designated as not exception-safe; If C++ exceptions are disabled, the method does not take part in overload resolution. The domain's exception alias points to DiagException. [SWS_DM_00993] [SWS_DM_00994] [SWS_DM_00995] [SWS_DM_00991]
