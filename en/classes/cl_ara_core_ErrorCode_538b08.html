class ara::core::ErrorCode

[SWS_CORE_00501] Upstream: RS_AP_00130, RS_AP_00140

class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

intended use

ErrorCode encapsulates a domain-specific raw error value, a reference to the associated ErrorDomain, and optional vendor-specific additional data. The type is a literal type. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

Generation & Interaction

It can be created from an error enum or from value, error domain and additional data. Domain(), Value(), SupportData() and Message() indicate its components and the error text respectively; ThrowAsException() determines the appropriate exception type across the domain. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

Limitations & Error handling

Comparisons only take into account the error value and error domain, not the additional data. ErrorCode and its members may be used independently of ara::core::Initialize and Deinitialize. [SWS_CORE_10301] [SWS_CORE_15002]

Error context instead of general error values

A ErrorCode associates a typed error value with its ErrorDomain context; optionally it can carry a message and additional manufacturer-specific information. ARA interfaces use it within Result for recoverable errors. EXP InterfacesGuidelines §3.1.2 “Result” EXP ARAComAPI §4.7 “Error Handling”

Manufacturer-specific error codes require their own error domains; portable, stack-neutral applications should treat such domains as a general default case. EXP InterfacesGuidelines §3.1.5 “Standardized vs Vendor-specific ErrorCodes”

Collaboration Diagram: ErrorCode gets context and message from its domain; the exception transformation is the explicit exception path. Sources: EXP InterfacesGuidelines §3.1.2 “Result” RS General §4.1.3 “The use of noexcept”.

Type erased error value

The SWS describes ErrorCode as an error value with domain context: the domain-specific code is type-erase into an integer value for uniform transport; additional support information may be shared. Comparisons consider value and domain, not support data. SWS Core §7.2 “Error handling” SWS Core §7.2.5.1 “ErrorCode” [SWS_CORE_10301] [SWS_CORE_10302]

void ThrowAsException () const noexcept(false);

This function will determine the appropriate exception type for this ErrorCode and throw it. The thrown exception will contain this ErrorCode.
