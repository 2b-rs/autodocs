class ara::tsync::SynchronizedTimeBaseConsumer

Consumer: read synchronized time securely

The consumer provides an application with a configured synchronized time base. GetTimeWithStatus() not only provides the current global time, but also a coherent snapshot together with local time, synchronization status, leap status and user data. SWS Time Synchronization §7.1 “General Overview” SWS Time Synchronization §7.2 “Normal Operation” [SWS_TS_14218]

The consumer query returns time and status together; Changes in status can be reported. Source: SWS Time Synchronization §7.2 “Normal Operation”; [SWS_TS_14218]; [SWS_TS_00701].

Evaluate status alone instead of time value

Before relying on the time value, the application should consider SynchronizationStatus: initially not synchronized, synchronized, gateway-based or timeout. The rate deviation can be read separately and is initially 0.0 before a calculation. {sws(TS,"SWS_TS_00202")} {sws(TS,"SWS_TS_00032")}

Operate Notifier with clear ownership

Status, synchronization, leap, precision and validation notifiers complement polling. Only one notifier can be registered per category; another registration replaces the previous one. There is no buffering for precision data, so the callback must decouple itself if necessary. {sws(TS,"SWS_TS_00701")} {sws(TS,"SWS_TS_01018")}
