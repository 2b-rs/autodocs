Initiate a method call (ClientServerOperation. fireAndForget ==FALSE). The method call will return immediately. The caller’s selection of a synchronous or asynchronous behavior to get the method output is achieved by the use of the returned ara::core::Future object which is used to query for method completion and result including possible error.

The noexcept function-call operator <SI-Namespace>::proxy::methods::<Method>::operator initiates a method call (ClientServerOperation.fireAndForget==FALSE) and returns immediately [SWS_CM_00196]. Through the returned ara::core::Future<Output>, the caller can wait either synchronously or asynchronously for completion of the call, including potential errors. The method is exception-safe.

Error handling

If unsuccessful, the Future contains one of the following errors: ComErrc::kCommunicationFailure for a recoverable communication or secure communication error of the network binding; a communication timeout can leave an unsafe state on the server side; ComErrc::kUnknownApplicationError (rollback semantics) if the remote service returns an unconfigured application error; ComErrc::kServiceNotAvailable (rollback semantics) if the service previously offered via OfferService() is no longer available; ComE2EErrc::kUnspecifiedE2EError (rollback semantics) if the remote service returns an unspecified E2E error; ComErrc::kMinimumSendIntervalViolationError (rollback semantics) when a send request occurs faster than the configured minimumSendInterval.

Concurrency & restrictions

On a contract violation, the implementation throws an InsufficientPermissionsViolation if the grant-enforcement check denies the call.
