intended use

Indicator provides access to diagnostic indicators. GetIndicatorState() returns the current status asynchronously; the DM provides it via the associated instance. [SWS_DM_00741] [SWS_DM_00744] [SWS_DM_00888] For events assigned to a DTC, the result is kOnDemand if at least one indicator has this state; if only kOff is delivered, kOff is delivered. [SWS_DM_01974] [SWS_DM_01975]

Generation & destruction

The constructor expects an InstanceSpecifier for a PortPrototype of DiagnosticIndicatorInterface. [SWS_DM_00742] SetNotifier() registers a function for updates; a further registration overwrites the previous one. [SWS_DM_00745] [SWS_DM_01359] The destructor is noexcept and exception-safe. [SWS_DM_00743]

Lifecycle & Ownership

The final class cannot be copied, assigned or moved; all copy and move operations are deleted. [SWS_DM_01629] [SWS_DM_01627] [SWS_DM_01630] [SWS_DM_01628]

Limitations & Error handling

If essential DM functionality is unavailable, GetIndicatorState() can return DiagErrc::kServiceNotAvailable. [SWS_DM_00744] Querying is thread-safe, whereas notifier registration is not thread-safe. [SWS_DM_00744] [SWS_DM_00745]

The indicator status is returned asynchronously as IndicatorStatusType. [SWS_DM_00744] The DM always sets the status bit kWarningIndicatorRequested at the same time as setting kConfirmedDTC. [SWS_DM_01266] If healing conditions are met, the DM resets UDS-DTC status bit 7 at the end of an operation cycle. [SWS_DM_00224] Construction and status query are thread-safe. [SWS_DM_00742] [SWS_DM_00744]

If essential DM functionality is not available, status access returns the specified error and does not change the registered notifier. [SWS_DM_00744] [SWS_DM_00745]
