class ara::diag::TransmitCertificate

[SWS_DM_01961] Upstream: RS_Diag_04251

class TransmitCertificate {...};

Class to implement the subfunction TransmitCertificate (29 04) of UDS service Authentication as interface to application. This class implements a so called generic interface, where the application has means to handle one ore more certificateEvaluationId transferred certificates.

intended use

ara::diag::TransmitCertificate maps the UDS subfunction TransmitCertificate (0x29/0x04) to an application interface. The application can process one or more transferred certificates using certificateEvaluationId [SWS_DM_01961].

Generation & destruction

The instance is created with the InstanceSpecifier of an DiagnosticTransmitCertificateInterface and an ConcurrencyType [SWS_DM_01962]. The type is neither copyable nor movable; the virtual destructor is noexcept [SWS_DM_01964] [SWS_DM_01963] [SWS_DM_01966] [SWS_DM_01965] [SWS_DM_01967].

Interaction with other classes

Offer() enables request forwarding through DM, StopOffer() disables it, [SWS_DM_01969] [SWS_DM_01970]. The method to be derived, Process(), receives the 16-bit CEID, the certificate data, MetaInfo and a CancellationHandler. The semantics of certificate processing lies with the application [SWS_DM_01968] [SWS_DM_01248].

Limitations & Error handling

The thread safety of Process() is determined by ConcurrencyType selected in the constructor [SWS_DM_01962] [SWS_DM_01968]. The Cancellation Handler allows querying cancellation status and registering a notifier. For negative UDS responses, an appropriate error from DiagUdsNrcErrc must be used [SWS_DM_01968]. A repeated offer can return DiagOfferErrc::kAlreadyOffered [SWS_DM_01969].

function Process [SWS_DM_01968] Upstream: RS_Diag_04251

virtual ara::core::Future< void > Process (std::uint16_t certificate EvaluationId, ara::core::Span< ara::core::Byte const > certificate Data, const MetaInfo &metaInfo, CancellationHandler cancellation Handler) noexcept=0;

This method is used to process certificates send by a diagnostic tester, via the UDS subfunction TransmitCertificate inside the application. There is no specific semantics for the certificate and it is left to the application to process the received certificate and derive the needed actions.

Usage AI generated

Automatically generated usage note derived from this AUTOSAR R25-11 specification element—not official AUTOSAR text. Evidence: [SWS_…].

The virtual method Process processes a certificate sent by the diagnostic tester via the UDS subfunction TransmitCertificate within the application; There are no specific semantics for the certificate; it is up to the application to derive the necessary actions. Parameters are the 16-bit certificateEvaluationId from the UDS request message, the certificateData to be checked, the metaInfo of the request and a cancellationHandler, via which the abort status can be queried via IsCanceled or a notifier can be registered via SetNotifier [SWS_DM_01968]. The returned ara::core::Future<void> provides an empty value if successful.

Error handling & concurrency

In the event of an error, an applicable NRC according to ISO 14229-1 must be used via DiagUdsNrcErrc. Whether the implementation must be thread-safe or non-thread-safe is determined by the ConcurrencyType passed in the constructor; the method is exception-safe.
