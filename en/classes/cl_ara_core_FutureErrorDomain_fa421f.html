FutureErrorDomain is the final error range for errors resulting from the interaction of ara::core::Future and ara::core::Promise. Its short name is Future, the identifier is 0x8000’0000’0000’0013. [SWS_CORE_00421] [SWS_CORE_00013]

As a ErrorDomain derivative, it provides text translation using Message(), its name and throwing the appropriate exception type from a ErrorCode. The exception alias is FutureException; Message() does not return a null pointer. [SWS_CORE_00443] [SWS_CORE_00442] [SWS_CORE_00444] [SWS_CORE_00432]
