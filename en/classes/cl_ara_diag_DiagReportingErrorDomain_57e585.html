intended use

The final class provides the error range for diagnostic reporting errors and derives from ara::core::ErrorDomain. It assigns error code values to text messages and provides the short name of the associated ApApplicationErrorDomain. [SWS_DM_00996] [SWS_DM_01001] [SWS_DM_01000]

Limitations & Error handling

ThrowAsException throws the exception associated with the passed ErrorCode. The method is not exception-safe and does not take part in overload resolution when C++ exceptions are disabled; the remaining operations shown are exception-safe and thread-safe. [SWS_DM_01002] [SWS_DM_00999]
