Freshness value manager for secured time messages

FVM provides freshness values ​​for the optional secure time synchronization. The manager must be initialized before use; Sender and receiver use separate Tx/Rx queries in the ICV process. SWS Time Synchronization §7.2 “Normal Operation” [SWS_TS_14178] [SWS_TS_14183] [SWS_TS_14185]

Plan for error scenarios

If a freshness value is temporarily not available, the specification provides for retries up to the configured limit. Once this is reached, generation is aborted or a received message is discarded. [SWS_TS_14184] [SWS_TS_14186]

GetRxFreshness() determines the freshness value for the verification of a secured received time message.
