Platform Power State integration

The PowerStateInterface extension connects the suspend-to-RAM process with the OS-related power state control. Wake-up handlers should be treated as a registration pair so that autonomous wake-up events return to the SM flow in a controlled manner. [SWS_SM_00717] SWS StateManagement Chapter 7 “Functional specification”

Application context

The API is part of manifest and integration-dependent state coordination. Return values ​​and documented errors must be evaluated in the calling role; the configuration determines which instance and which authorization is used.
