Error information to state management

ExecutionErrorEvent describes the error context that Execution Management passes to State Management in the event of an abnormal or unexpected termination. If such an event occurs outside of a requested transition, the affected function group state is set to undefined and the configured callback is triggered [SWS_EM_01309].

Effect in the overall process

The event is a report of an already detected lifecycle error, not a request for the process to self-heal. State Management decides on a subsequent state or recovery strategy based on this context SWS EM §7.4 “State Management”.
