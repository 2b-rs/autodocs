intended use

ara::diag::ServiceValidation is the interface for validating diagnostic services. Depending on the mapping category, Validate() is called as a manufacturer or supplier check within the NRC sequence [SWS_DM_00772] [SWS_DM_01252] [SWS_DM_01253].

Generation & destruction

The instance is created via a InstanceSpecifier to a DiagnosticServiceValidationInterface [SWS_DM_00772]. It is a single entity that cannot be copied and moved; the virtual destructor is noexcept [SWS_DM_01689] [SWS_DM_01690] [SWS_DM_01687] [SWS_DM_01688] [SWS_DM_00773].

Interaction with other classes

After Offer(), DM forwards diagnostic messages to the handler; StopOffer() prevents this [SWS_DM_00776] [SWS_DM_00777]. The virtual method Validate() receives request data and MetaInfo and returns a Future<void>. After completion, Confirmation() informs about the processing result [SWS_DM_00774] [SWS_DM_00775].

Limitations & Error handling

A successful validation continues normal UDS processing. Errors other than kNoProcessingNoResponse result in a negative response with a value of DiagUdsNrcErrc; for kNoProcessingNoResponse the message is discarded [SWS_DM_01254] [SWS_DM_01255] [SWS_DM_00860]. The request data only remains valid until the promise is fulfilled or processing is canceled [SWS_DM_00774].
