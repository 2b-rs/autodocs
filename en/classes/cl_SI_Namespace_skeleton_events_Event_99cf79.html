ara::com::SampleAllocateePtr< SampleType > Allocate ();

Allocating data for event transfer when Communication Management is responsible for the data.

Usage AI generated

Automatically generated usage note derived from this AUTOSAR R25-11 specification element—not official AUTOSAR text. Evidence: [SWS_…].

The <SI-Namespace>::skeleton::events::<Event>::Allocate method allocates memory for an event sample in the event that the communication management implementation is responsible for data management, and returns a ara::com::SampleAllocateePtr<SampleType> on this memory [SWS_CM_90438]. According to the contract , the method is not exception-safe.

Concurrency & restrictions

If the contract is violated, the implementation throws a SampleAllocationViolation if sufficient memory resources cannot be allocated or a AllocateUsageViolation if the allocation was made illegally via its own allocator.
