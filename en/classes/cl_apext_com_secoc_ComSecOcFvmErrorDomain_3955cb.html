Freshness extension error domain

ComSecOcFvmErrorDomain is the fault domain of the Freshness Value Management platform extension. It separates freshness determination and status processing errors from the general ara::com error space. The FVM is a native extension interface in the communication management environment. EXP SW Architecture §9.3.1.1.3 “Interfaces for freshness value management” provides the architectural context.

Propagate error

Name() and Message() are used to classify a code; ThrowAsException() maps it into the associated exception. Result/ErrorCode evaluation remains the appropriate mechanism for communication paths that can be handled regularly. EXP ARAComAPI §4.7 “Error Handling” explains this general error modeling.
