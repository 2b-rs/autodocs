Role in the Crypto Stack

ara::crypto::cryp::SymmetricKey belongs to the crypto provider's runtime key model. Key objects carry algorithm identifier and permitted usage; Persistent material is managed via compatible key slots. SWS Cryptography §7.3.3 “Runtime Key Instantiation and Usage” SWS Cryptography §7.1.4 “Usage Control”

Properties and transitions

Runtime keys can be created by generating, importing or loading from a compatible slot. A persistence step requires a writable, compatible target resource and kAllowPersist. Usage restrictions are not only documented, but also checked during context-bound operations. SWS Cryptography §7.3.3 “Runtime Key Instantiation and Usage” SWS Cryptography §7.3.5 “Plaintext Key Management”

Security decision

Plain text export and import of confidential material are deliberately described as risky routes. If a workflow requires protected storage or transport, protected import/export or wrapping methods are preferable to the plain text route. SWS Cryptography §7.3.5 “Plaintext Key Management” SWS Cryptography §7.3.6 “Protected Key Management”
