HttpRedirect describes an HTTP redirect for a SOVD resource that has been moved or is available under a different URI. The SOVD server uses the type to notify the SOVD client of the new location. [SWS_DM_01828] The url field contains the URL to which the request should be redirected. [SWS_DM_01829] The specification does not define any additional fields or lifecycle rules. [SWS_DM_01828]
