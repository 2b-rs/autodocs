Role in the Crypto Stack

ara::crypto::cryp::DecryptorPrivateCtx is an algorithm-specific crypto context. It separates the selection/binding of key and algorithm from the execution of a concrete operation and, where supported, follows the uniform single-call or streaming pattern. SWS Cryptography §7.4 “Crypto Contexts”

Call pattern

A context is created with an appropriate AlgId and configured before key-bound operations. Single steps are suitable for complete messages; the streaming API follows the scheme Start(), one or more Update() and Finish(). Output sizes and IV requirements can be queried in advance if the respective class offers this. SWS Cryptography §7.4.1 “Overview”

Streaming contexts are configured before processing and exited through completion or cancellation. Source: SWS Cryptography §7.4.1 “Overview”. Partial interpretation: The state names condense the API sequences.

Error and resource model

The caller checks ara::core::Result, key compatibility, allowed usage, buffer size and context state. A second hardware resource that is used in parallel may be temporarily unavailable; Instead of blocking indefinitely, the provider can report a busy error. SWS Cryptography §7.1.6 “Concurrent Access”
