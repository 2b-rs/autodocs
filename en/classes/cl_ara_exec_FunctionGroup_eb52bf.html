class ara::exec::FunctionGroup

[SWS_EM_02263] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150

class FunctionGroup final {...};

Class representing Function Group defined in meta-model (ARXML). An instance of this class will represent Function Group defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

Boundary of a consistently controlled set of processes

FunctionGroup is the API representative of a configured Function Group. It bundles model processes that are started and ended coherently via states; A model process may not be assigned to multiple function groups SWS EM §7.4.3 “Function Group State”.

MachineFG and application-related groups

The Function Group MachineFG describes machine states and is primarily used for the machine lifecycle. Additional function groups typically control groups of user-level applications. The specific assignment of the processes comes from the Execution Manifests SWS EM §7.4 “State Management”.

State diagram: A state change of a function group is requested by State Management and implemented by Execution Management RS Execution Management, State Management (S. 16) SWS EM §7.4.5 “State Transition”. Interpretation: The active target state is an example of a ModeDeclaration defined in the manifest.
