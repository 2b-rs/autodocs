Provider: Control time base at origin

A provider serves a time base configured as a global time master: it sets or updates time and user data and can query the current value regardless of the synchronization status. The transfer to the bus takes place after a local update in the next cycle. SWS Time Synchronization §7.2 “Normal Operation” [SWS_TS_01108]

Provider operations set or update the time; a rate correction is configuration and limit dependent. Source: SWS Time Synchronization §7.2 “Normal Operation”; [SWS_TS_00061].

Rate correction as a controlled intervention

SetRateCorrection() accepts factors below 1.0 to slow down and above 1.0 to speed up. The function is only available if provider correction is activated; outside the permitted range is limited and delivered kLimitsExceeded. {sws(TS,"SWS_TS_00061")} {sws(TS,"SWS_TS_00063")}

Connect validation separately

The optional time validation notification provides measurement blocks for application-side analysis. It does not define a back channel or a validation decision; this remains at the application level. {T72} {sws(TS,"SWS_TS_00425")}
