Status object as an atomic observation value

SynchronizedTimeBaseStatus is a snapshot of a Time Base Resource. It bundles status flags, update and leap information, time values ​​and user data so that an application makes its decision on a consistent basis. SWS Time Synchronization §7.1 “General Overview” [SWS_TS_14218]

States after successful synchronization or timeout. Source: SWS Time Synchronization §7.2 “Normal Operation”; [SWS_TS_00032]; [SWS_TS_00033].

Derive validity from the synchronization status

GetCreationTime() only delivers synchronized generation time if the time base was synchronized at least once; otherwise the optional remains empty. GetLeapJump() only describes jumps up to the creation of this snapshot. {sws(TS,"SWS_TS_01055")} {sws(TS,"SWS_TS_01054")}

Classify correction indicators

A valid rate correction sets RATE_CORRECTED; If the calculated deviation exceeds the configured limit, it is considered invalid and RATE_EXCEEDED is set. {sws(TS,"SWS_TS_14224")} {sws(TS,"SWS_TS_14228")}
