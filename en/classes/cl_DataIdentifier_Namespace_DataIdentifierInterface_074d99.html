intended use

<DataIdentifierInterface> provides an application interface for diagnostic data identifiers. The application implements Read() for the read role and Write() for the write role; Both operations deliver their result asynchronously via ara::core::Future. [SWS_DM_00601] [SWS_DM_00640] [SWS_DM_00598]

Generation & destruction

The constructor binds the interface via a ara::core::InstanceSpecifier and sets the intended implementation contention with ConcurrencyType. Offer() switches on the forwarding of requests to the handler, StopOffer() switches off. If the service is already offered, Offer delivers DiagOfferErrc::kAlreadyOffered. [SWS_DM_00585] [SWS_DM_00599] [SWS_DM_00600]

Lifecycle & Ownership

The interface cannot be copied, moved or assigned because copy and move operations are deleted. It has a virtual destructor. [SWS_DM_01663] [SWS_DM_01664] [SWS_DM_01665] [SWS_DM_01666] [SWS_DM_00586]

Limitations & Error handling

Read and Write each receive a MetaInfo and a CancellationHandler, through which abort status and abort notification are available. Asynchronous method errors are returned as DiagUdsNrcErrc or ApApplicationError; the methods are not thread safe. [SWS_DM_00640] [SWS_DM_00598]
