intended use

The <DataElementInterface> class is the interface of a diagnostic data element. An application implements the purely virtual method Read(); The Diagnostic Manager forwards requests to this handler according to Offer(). The result is returned asynchronously as ara::core::Future with a read output. [SWS_DM_00603] [SWS_DM_00596] [SWS_DM_00597]

Generation & destruction

The instance is created with a ara::core::InstanceSpecifier and a ConcurrencyType. Offer() activates the forwarding by the DM, StopOffer() deactivates it again; a new offer is rejected with DiagOfferErrc::kAlreadyOffered. [SWS_DM_00587] [SWS_DM_00597] [SWS_DM_00617]

Lifecycle & Ownership

Copying as well as move construction and assignment are prohibited (=delete). The class has a virtual, noexcept destructor. [SWS_DM_01659] [SWS_DM_01660] [SWS_DM_01661] [SWS_DM_01662] [SWS_DM_00588]

Limitations & Error handling

Read() receives MetaInfo and a CancellationHandler. The implementation can use this to check the abort status or register a notifier; in the event of a technical failure, a suitable DiagUdsNrcErrc must be used. Read(), Offer and StopOffer are not thread safe. [SWS_DM_00596] [SWS_DM_00597] [SWS_DM_00617]

virtual ara::core::Future< <DataElement>ReadOutput > Read (const ara::diag::MetaInfo &metaInfo, ara::diag::CancellationHandler cancellationHandler) noexcept=0;

Provision of a Read DataElement (DiagnosticDataElementInterface in the role read)

Usage AI generated

Automatically generated usage note derived from this AUTOSAR R25-11 specification element—not official AUTOSAR text. Evidence: [SWS_…].

The virtual method Read provides the read operation of a DataElement (role read of DiagnosticDataElementInterface) and returns the ReadOutput object [SWS_DM_00596] asynchronously via a ara::core::Future. A metaInfo is transferred for inquiry as well as a cancellationHandler, which can be used to query the abort status (IsCanceled) or to register a notification function (SetNotifier).

Error handling

In case of failure, the future contains a corresponding DiagUdsNrcErrc according to ISO 14229-1 or a ApApplicationError. The call is not thread-safe, but exception safe.
