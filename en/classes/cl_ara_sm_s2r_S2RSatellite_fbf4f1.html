Participant in the Suspend-to-RAM sequence

S2RSatellite represents an application that is coordinated before suspend and after wake-up. Participation is activated with Offer; StopOffer terminates it. [SWS_SM_00710] SWS StateManagement Chapter 7 “Functional specification”

Application context

The API is part of manifest and integration-dependent state coordination. Return values ​​and documented errors must be evaluated in the calling role; the configuration determines which instance and which authorization is used.
