Role in the model

Accessor represents the typed access to a buffer. The access type and the target are template parameters; The reference type is const for read accesses and writable for other accesses.

Source reference

SWS SHWA §7.3 describes accessors as a bridge between kernel and data; the AccessMode supports the planning of data access.
