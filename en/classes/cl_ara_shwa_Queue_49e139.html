Role in the model

Queue forwards tasks to a selected device. It has resources and therefore cannot be copied; an ErrorHandler is part of the security concept for asynchronous errors.

Source reference

The submission and (dis)ordered execution are explained in SWS SHWA §7.6 — Task Queuing And Ordering Specifics. Asynchronous errors require the explicit handler described in SWS SHWA §7.2.5.3.
