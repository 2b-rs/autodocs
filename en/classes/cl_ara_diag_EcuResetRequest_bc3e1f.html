intended use

The interface processes ECU reset requests. RequestReset handles all reset subfunctions except Enable/DisableRapidShutdown; EnableRapidShutdown handles these two cases. After the request is accepted, the instantiating process must maintain the decision for later invocation of ExecuteReset. [SWS_DM_01009] [SWS_DM_01013] [SWS_DM_01012] [SWS_DM_01020] [SWS_DM_01021]

Interaction with other classes

During a general reset, the Diagnostic Server first calls RequestReset. Depending on respondToReset, it sends the positive response before or after the reset and calls ExecuteReset accordingly. Once accepted, further UDS requests are ignored; after the future delivered by ExecuteReset has been completed, they will be accepted again. [SWS_DM_00235] [SWS_DM_00268] [SWS_DM_01023] [SWS_DM_00360] [SWS_DM_01090] [SWS_DM_01022] [SWS_DM_01309]

Lifecycle & Ownership

The instance is created with a port InstanceSpecifier. Copying, moving and both forms of assignment are prohibited (=delete). [SWS_DM_01010] [SWS_DM_01621] [SWS_DM_01622] [SWS_DM_01619] [SWS_DM_01620]

Limitations & Error handling

The service functions deliver futures and use applicable UDS-NRCs from DiagUdsNrcErrc in case of errors. If ExecuteReset provides a defined error code, this is used as NRC; for other errors, the server sends 0x10 (kGeneralReject) if there is no final response yet. Offer/StopOffer control forwarding; deliver double offers DiagOfferErrc::kAlreadyOffered. [SWS_DM_01013] [SWS_DM_01014] [SWS_DM_01346] [SWS_DM_01347] [SWS_DM_01016] [SWS_DM_01017]

Creation & Destruction The destructor is virtual, exception-safe and not thread-safe. The essential service operations receive MetaInfo; RequestReset and EnableRapidShutdown also receive a CancellationHandler, which the implementation uses to query the cancellation status or register a notification. For respondBeforeReset, an error reported by ExecuteReset has no effect on the response already sent. [SWS_DM_01011] [SWS_DM_01012] [SWS_DM_01013] [SWS_DM_01014]

function RequestReset [SWS_DM_01013] Upstream: RS_Diag_04169, RS_Diag_04279

virtual ara::core::Future< void > RequestReset (ResetRequestType reset Type, ara::core::Optional< std::uint8_t > id, const MetaInfo &meta Info, CancellationHandler cancellationHandler) noexcept=0;

Called for any EcuReset subFunction, except En-/DisableRapidShutdown. The process, which is instantiating this interface, needs to evaluate carefully if the request to restart parts or the whole machine. Once the request to reset is accepted, the process, which is instantiating this interface, has to rely on this decision for the ExecuteReset() trigger.
