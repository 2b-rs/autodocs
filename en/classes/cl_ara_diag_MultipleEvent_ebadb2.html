intended use

MultipleEvent consolidates operations on multiple diagnostic events. Event status, debounce status, fault detection counter and the associated DTC number can be queried via a EventHandleType. [SWS_DM_01704] [SWS_DM_01707] [SWS_DM_01710] [SWS_DM_01711] [SWS_DM_01709] A status change notifier can be registered per event handle; a subsequent registration replaces the previous one. [SWS_DM_01708]

Lifecycle & Ownership

The instance is created for a PortPrototype of DiagnosticMultipleEventInterface. [SWS_DM_01705] It cannot be copied, assigned or moved; the respective operations are deleted. [SWS_DM_02070] [SWS_DM_02067] [SWS_DM_02069] [SWS_DM_02068] The destructor is noexcept. [SWS_DM_01706]

Limitations & Error handling

Event handles are assigned from mapped events, if overrideId is missing, in alphabetical order starting at 0x010000. [SWS_DM_01733] Handles that do not belong to this instance result in kInvalidArgument. [SWS_DM_01734] queries can also return kNoSuchDTC or kServiceNotAvailable; their thread safety depends on the ConcurrencyType. [SWS_DM_01709] [SWS_DM_01710] [SWS_DM_01711] The notifier registration is not thread-safe. [SWS_DM_01708]

The DTC query takes into account the requested DTCFormatType. [SWS_DM_01709] For an event without an associated DTC, it can deliver kNoSuchDTC. [SWS_DM_01709] All query operations are exception-safe. [SWS_DM_01707] [SWS_DM_01709] [SWS_DM_01710] [SWS_DM_01711] The status notifier registration can return an error if the arguments are invalid. [SWS_DM_01708]

The class is final and therefore not intended for derivation. [SWS_DM_01704] The constructor itself is exception-safe and thread-safe. [SWS_DM_01705]
