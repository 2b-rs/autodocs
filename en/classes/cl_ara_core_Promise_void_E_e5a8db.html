class ara::core::Promise< void, E >

[SWS_CORE_06340] Upstream: RS_AP_00130

template <typename E> class Promise< void, E > final {...};

Specialization of class Promise for void values The implementation shall flag the condition E != *ara::core::ErrorCode as a compile error.

intended use

ara::core::Promise<void, E> is the specialization for asynchronous operations with no value. The error type must be ara::core::ErrorCode; together with Future, the class enables thread-safe, exception-free subsequent delivery of a success or failure. [SWS_CORE_06340] [SWS_CORE_10800]

Lifecycle & Ownership

Copying is prohibited (=delete), moving is possible. The move assignment and destructor abandon any previous shared state. [SWS_CORE_06350] [SWS_CORE_06351] [SWS_CORE_06342] [SWS_CORE_06343] [SWS_CORE_06349]

Interaction with other classes

get_future() delivers the Future<void,E> once with identical shared state. set_value() prepares void success; SetError() and SetResult() set errors respectively Result<void,E>. [SWS_CORE_06344] [SWS_CORE_06345] [SWS_CORE_06353] [SWS_CORE_06354] [SWS_CORE_06355] [SWS_CORE_06356]

Limitations & Error handling

Multiple setting and setter calls without shared state are specified as violations. [SWS_CORE_13015] [SWS_CORE_13016]

Future< void, E > get_future () noexcept;

Return an associated Future with the same shared state as *this The returned Future is set as soon as this Promise receives the result, value, or an error. This fuction must only be called once as it is not allowed to have multiple Futures per Promise.
