Context

The generated proxy class <SI-Namespace>::proxy::<SI>Proxy acts as the primary client-side representative of an AUTOSAR Adaptive service interface within module com. Its central responsibility is to find service instances, establish communication channels, and provide type-safe access to the communication entities defined in the service interface. For this purpose, the class holds dedicated member variables for events via events::<Event> [SWS_CM_99445], fields via fields::<Field> [SWS_CM_99446], and methods via methods::<Method> [SWS_CM_99447].

The primary interaction partners include the local client application, the underlying communication infrastructure (network binding), and registered callback functions for monitoring the service status or for asynchronous search operations.

Context diagram: Interaction partners and embedding of <SI>Proxy into the communication architecture. Sources: [SWS_CM_99445], [SWS_CM_99446], [SWS_CM_99447], [SWS_CM_01074].

Lifecycle

The lifecycle of a proxy is divided into service discovery, instantiation, state monitoring, and controlled release:

  • Finding: Prior to object creation, matching instances are searched for. This is done either synchronously via FindService with ara::com::InstanceIdentifier [SWS_CM_00122] or ara::core::InstanceSpecifier [SWS_CM_00622] EXP ARAComAPI p. 10, respectively, or asynchronously via StartFindService [SWS_CM_00123], [SWS_CM_00623] EXP ARAComAPI p. 10. For asynchronous searches, a user-defined execution context can be passed via ExecutorT [SWS_CM_11352], [SWS_CM_11365] EXP ARAComAPI p. 10. Ongoing searches are stopped with StopFindService [SWS_CM_00125] EXP ARAComAPI p. 10.
  • Creation: The recommended, exception-free creation takes place via the static factory method Create (Named Constructor Idiom) specifying a valid HandleType and returns a ara::core::Result<<SI>Proxy> [SWS_CM_10438]. Alternatively, an explicit constructor <SI>Proxy(const HandleType&) exists that can throw exceptions in case of errors [SWS_CM_00131].
  • Semantics: Proxy instances have move-only semantics: The copy constructor [SWS_CM_00136] and the copy assignment operator [SWS_CM_11551] are deleted (=delete). A transfer of resources is permissible exclusively via the move constructor [SWS_CM_00137] or the noexcept move assignment operator [SWS_CM_11552], respectively. The underlying handle can be queried via GetHandle [SWS_CM_10383].
  • State management: The availability state of the connected service instance can be queried synchronously via GetServiceState [SWS_CM_01073]. For asynchronous state tracking, a ServiceStateHandler is registered using SetServiceStateChangeHandler [SWS_CM_01074] (optionally with execution context ExecutorT [SWS_CM_01076]). Deregistration is performed via UnsetServiceStateChangeHandler [SWS_CM_01075].
  • Destruction: The destructor ~<SI>Proxy() ends the lifetime [SWS_CM_99444]. Prior to destruction, all held data samples must be released to avoid violations.

Usage Path

A typical usage path comprises the synchronous search for a service instance, proxy-based instantiation, monitoring of state changes, and the final cleanup:

  1. Determine service: Call to <SI>Proxy::FindService(instance) to determine available service handles in a ara::com::ServiceHandleContainer [SWS_CM_00122], [SWS_CM_00622].
  2. Create proxy: Passing the selected handle to <SI>Proxy::Create(handle) for exception-free construction [SWS_CM_10438].
  3. Monitor state: Registering a change handler via SetServiceStateChangeHandler [SWS_CM_01074] and querying the current status via GetServiceState [SWS_CM_01073].
  4. Perform communication: Interacting with the members for methods [SWS_CM_99447], events [SWS_CM_99445], and fields [SWS_CM_99446].
  5. Release resources: Deregistering the state handler with UnsetServiceStateChangeHandler [SWS_CM_01075] and controlled destruction of the object [SWS_CM_99444].

Sequence diagram: Typical call sequence from finding the instance through object creation to release. Sources: [SWS_CM_00622], [SWS_CM_10438], [SWS_CM_01074], [SWS_CM_01075], [SWS_CM_99444].
