DiagErrorDomain is a final error domain for diagnostic errors and derives from ara::core::ErrorDomain. The default constructor is constexpr, exception-safe and thread-safe. [SWS_DM_00517] [SWS_DM_00520]

Name() provides the short name of the associated application error domain. Message() translates an error code into never-zeroed text. ThrowAsException() throws the exception corresponding to ErrorCode; If C++ exceptions are disabled, this method does not take part in overload resolution. [SWS_DM_00521] [SWS_DM_00522] [SWS_DM_00523]
