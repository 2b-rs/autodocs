intended use

The interface binds a DiagnosticDoIPActivationLineInterface over a InstanceSpecifier. The application implements the pure virtual queries for activation state and responsible network interface ID; both deliver their values asynchronously as ara::core::Future. [SWS_DM_00830] [SWS_DM_00831] [SWS_DM_00833] [SWS_DM_00835]

Lifecycle & Ownership

Copying, moving and copy/move assignment are prohibited (=delete); This means that the class is defined as a single, unassignable instance. The destructor is virtual and defaulted. [SWS_DM_01633] [SWS_DM_01634] [SWS_DM_01631] [SWS_DM_01632] [SWS_DM_00832]

Interaction with other classes

Offer enables the Diagnostic Manager to monitor changes in activation line status, StopOffer terminates this provision. If the manager detects an activation, it sends vehicle announcement messages in accordance with ISO 13400-2. [SWS_DM_00836] [SWS_DM_00837] [SWS_DM_00816]

Limitations & Error handling

A repeated offer delivers DiagOfferErrc::kAlreadyOffered. Offer and StopOffer are not thread-safe; the queries are thread-safe and do not specify standardized errors. [SWS_DM_00836] [SWS_DM_00837] [SWS_DM_00833] [SWS_DM_00835]
