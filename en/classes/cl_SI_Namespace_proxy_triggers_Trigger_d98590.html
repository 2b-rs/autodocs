intended use

This final proxy trigger class is generated for each element modeled as a trigger in the ServiceInterface. The namespace, class name, and the proxy header are derived from the ServiceInterface model of the ARXML manifest. [SWS_CM_00727]

use

Subscribe() starts the subscription to the associated trigger. If it is already active or pending, another call has no effect; Likewise, Unsubscribe() remains ineffective without an existing subscription. GetNewTriggers() updates the trigger count and returns the number of triggers received since the last call. [SWS_CM_00723] [SWS_CM_00810] [SWS_CM_00226]

A receive handler is called upon trigger input and accesses the counter via GetNewTriggers(). Subscription state and transport fault handlers can be set, partially executed in a provided context, and removed again. All operations mentioned are exception-safe except for UnsetReceiveHandler(), for which no exception safety is guaranteed.
