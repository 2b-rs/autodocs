intended use

This final proxy field class is generated for each element modeled as a field in the ServiceInterface. The namespace, class name and the header <SiNamespaceDerivedDirectoryPath>/<SiShortname>_proxy.h are derived from the ServiceInterface model of the ARXML manifest. [SWS_CM_00008]

use

Get() reads the current field value asynchronously and is only available if the field has a getter. Set() sets a new value asynchronously and is only created if a setter is present; An application error can be identified by a return value that deviates from the requested value. Both calls return a ara::core::Future<FieldType>. [SWS_CM_00112] [SWS_CM_00113]

For field notifications, first call Subscribe(maxSampleCount), then use GetNewSamples() to update the local notification cache. The same already active or pending subscription will not be re-executed; Unsubscribe() without an existing subscription remains ineffective. The free cache space can be queried with GetFreeSampleCount(). Receive and subscription state handlers can be registered, executed in a provided context, and removed again. [SWS_CM_11601] [SWS_CM_11610] [SWS_CM_11602] [SWS_CM_11603] [SWS_CM_11605] [SWS_CM_11611] [SWS_CM_11607] [SWS_CM_11608] [SWS_CM_11609]

E2E & Error handling

The class can register or remove a transport fault handler. The three E2E status queries provide the status from the last E2E check of a Get(), GetNewSamples() or Set() call. The remaining operations mentioned are exception-safe, only GetNewSamples() is not specified as exception-safe; Failed subscription or cache refresh is indicated via ara::core::Result. [SWS_CM_00109] [SWS_CM_00110] [SWS_CM_00126] [SWS_CM_00145] [SWS_CM_11612] [SWS_CM_00146] [SWS_CM_11601] [SWS_CM_11610]

Field semantics

In contrast to an event, a field always has a current value; Notification, Get() and Set() can each be modeled optionally in the service interface. The proxy field wrapper therefore combines event-like notification with method-like get/set requests. EXP ARAComAPI §5.3.7 “Fields” TPS Manifest §4.2 “Service Interface”

The noexcept method <SI-Namespace>::proxy::fields::<Field>::Get reads the current value of the proxy field; it only exists if the field is configured via Field.hasGetter==TRUE [SWS_CM_00112]. Access is asynchronous via a ara::core::Future<FieldType>, which enables synchronous or asynchronous evaluation of the result selected by the caller. The method is exception-safe.

Error handling

If successful, the Future contains the field value; if unsuccessful, ComErrc::kCommunicationFailure (rollback semantics) in the event of a recoverable communication or secure communication error in the network binding; ComErrc::kMinimumSendIntervalViolationError (rollback semantics) reported when a send request occurs faster than the configured minimumSendInterval.

Get() requests the current value from the provider and behaves like a regular method call in terms of the result: The value is provided via a Future. EXP ARAComAPI §5.3.7 “Fields”
