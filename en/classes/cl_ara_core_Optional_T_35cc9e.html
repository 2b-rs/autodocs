intended use

ara::core::Optional<T&> is the specialization of Optional for lvalue references. It supports status queries, reference access, emplace(), reset(), swap() and value_or(). [SWS_CORE_01150] [SWS_CORE_01172] [SWS_CORE_01170] [SWS_CORE_01164] [SWS_CORE_01165] [SWS_CORE_01166] [SWS_CORE_01175]

Lifecycle & Ownership

Copy and move construction, both assignments and the destructor are specified as =default and noexcept. [SWS_CORE_01154] [SWS_CORE_01155] [SWS_CORE_01159] [SWS_CORE_01160] [SWS_CORE_01158]

Limitations & Error handling

An assignment to Optional<T&> rebinds the stored reference to the new object; it does not assign a value to the previously referenced object. [SWS_CORE_01034]
