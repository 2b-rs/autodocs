StartSynchronousExecutionResponse is the return type for the synchronous start of a SOVD operation. [SWS_DM_02208] After a successful synchronous start, the DM forms the parameters of the SOVD response from the DiagnosticSovdContentData of this return value. [SWS_DM_02176] The structure is therefore a transfer value between the implementation of StartExecution and the SOVD response generated by the DM; additional members are not defined in the material provided.
