class ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

Reading an open file

ReadAccessor is the exclusive read access to a file of a FileStorage. The file is opened with OpenFileReadOnly; Afterwards, character, text and binary operations allow a reading strategy that suits the content. SWS Persistency §7.4 “File Storage specific Features”

Cursor and EOF

Peek… looks ahead without advancing the position; Get… reads and advances it. ReadLine, ReadText, and ReadBinary differ in transfer form. Check IsEof and Result rather than relying on an expected length alone.

Concurrency

Accessor methods are not thread-safe. Therefore, keep access and position management within a controlled ownership context or protect the same handle externally.

A file storage manages a set of named files; the accessor has exclusive ownership of the specific opened access. Sources: SWS Persistency §7.4 “File Storage specific Features” [SWS_PER_00113].

In case of an error, the current position is not changed.
