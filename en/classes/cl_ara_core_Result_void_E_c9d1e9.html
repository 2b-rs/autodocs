intended use

ara::core::Result<void,E> is the specialization for synchronous operations without a return value. It contains either a void success or an error; E must be ara::core::ErrorCode. [SWS_CORE_00801] [SWS_CORE_10600]

Creation & lifecycle

A successful state is created by the default constructor or FromValue(), an error state is created by error construction or FromError(). Copy and move operations are available and require noexcept. [SWS_CORE_00821] [SWS_CORE_00831] [SWS_CORE_00823] [SWS_CORE_00824] [SWS_CORE_00834] [SWS_CORE_00835] [SWS_CORE_00825] [SWS_CORE_00826] [SWS_CORE_00841] [SWS_CORE_00842]

Interaction with other classes

HasValue(), Error(), Err(), Bind() and Resolve() allow status and error processing. Resolve() only executes the passed function in an error state; Value() exists to support generic programming. [SWS_CORE_00851] [SWS_CORE_00857] [SWS_CORE_00868] [SWS_CORE_00870] [SWS_CORE_00867] [SWS_CORE_00855]

Limitations & Error handling

Error access without contained error and value access without contained value are specified as violation. ValueOrThrow() can trigger. [SWS_CORE_13010] [SWS_CORE_13009] [SWS_CORE_00866]

Call the given Callable, and return a new Result with the result of the call. The Callable is expected to be compatible to one of these two interfaces: • Result<XXX, E> f(); • XXX f(); meaning that the Callable either returns a Result<XXX, E> or a XXX directly, where XXX can be any type that is suitable for use by class Result. The return type of this function is decltype(f()) for a template argument F that returns a Result type, and it is Result<decltype(f()), E> for a template argument F that does not return a Result type. If this instance does not contain a value, a new Result<XXX, E> is still created and returned, with the original error contents of this instance being copied into the new instance
