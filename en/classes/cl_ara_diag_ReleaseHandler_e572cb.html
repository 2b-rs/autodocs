ReleaseHandler encapsulates a common state for whether processing of a shared resource can be stopped. [SWS_DM_01340] MayRelease() returns true when the resource is no longer used. [SWS_DM_01536] With SetNotifier() you can register a function to be called at the release moment; a later registration overwrites the previous one. [SWS_DM_01537] [SWS_DM_01319] Standard construction, copying and copy assignment are prohibited; Move construction and move assignment are available. [SWS_DM_01530] [SWS_DM_01534] [SWS_DM_01535] [SWS_DM_01532] [SWS_DM_01533] MayRelease() is thread-safe, the notifier registration is not. [SWS_DM_01536] [SWS_DM_01537]
