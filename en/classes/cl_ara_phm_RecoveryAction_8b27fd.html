Role in the recovery path

RecoveryAction provides State Management with the return channel through which PHM reports an expired Global Supervision Status. For kEXPIRED, the notification contains the Function Group-related Execution Error and the causing supervision type [SWS_PHM_00101] SWS PHM §7.5 “Recovery actions”.

Offer, response and escalation

Offer enables calls to the handler, StopOffer disables them. If there is no recovery offered in the event of an error or the response does not come in time, work will not continue in silence: PHM stops the alive message and triggers the watchdog path [SWS_PHM_01147] [SWS_PHM_01148] [SWS_PHM_00104].

Activity diagram: PHM informs State Management about an expired Global Supervision; a missing or unhandleable response leads to Watchdog escalation SWS PHM §7.5 “Recovery actions” SWS PHM §7.5.2 “Handling of Hardware Watchdog”.

Responsibility of implementation

The handler belongs to the project-specific recovery policy of State Management. Which Function Group transitions to which state is therefore not a general property of RecoveryAction, but an integration decision.
