intended use

SovdSwUpdate is the application interface for SOVD software updates. It lists available updates, provides details and status, registers an update via a write session and controls automated, prepared or to-be-run installations and the deletion of a package. [SWS_DM_01874] [SWS_DM_01916] [SWS_DM_01917] [SWS_DM_01921] [SWS_DM_01923] [SWS_DM_01918] [SWS_DM_01919] [SWS_DM_01920] [SWS_DM_01922] The Diagnostic Server calls these methods for the SOVD method of the same name. [SWS_DM_01797] [SWS_DM_01798] [SWS_DM_01799] [SWS_DM_01800] [SWS_DM_01801] [SWS_DM_01802] [SWS_DM_01803] [SWS_DM_01804]

Creation & lifecycle

The constructor requires a PortPrototype of DiagnosticSovdUpdateInterface and a ConcurrencyType. [SWS_DM_01910] Offer() enables DM forwarding and can deliver kConfigurationMismatch or kAlreadyOffered; StopOffer() deactivates it. [SWS_DM_01924] [SWS_DM_01925] Copy and copy assignment are prohibited, move construction and protected move assignment are provided. [SWS_DM_01912] [SWS_DM_01914] [SWS_DM_01913] [SWS_DM_01915]

Interaction with other classes

Details and status are provided as UpdatePackageDetails and UpdatePackageStatus respectively. [SWS_DM_01917] [SWS_DM_01921] The registration provides a DataTransferWriteSession and the generated update package ID. [SWS_DM_01923]

Limitations & Error handling

Operation methods asynchronously return positive results or SOVD error codes; their thread safety depends on ConcurrencyType. [SWS_DM_01917] [SWS_DM_01918] [SWS_DM_01919] [SWS_DM_01920] [SWS_DM_01921] [SWS_DM_01922] CancellationHandler reports the cancellation of a conversation. [SWS_DM_01923] Offer and StopOffer are not thread-safe. [SWS_DM_01924] [SWS_DM_01925]

GetAllUpdates() can get target version and origin filters; if they are not set in the request, the strings remain empty. [SWS_DM_01916] The returned list of package IDs must not be changed until the ReleaseHandler is called. [SWS_DM_01916] Expected size can be specified during package registration. [SWS_DM_01923] Construction and destruction are exception-proof. [SWS_DM_01910] [SWS_DM_01911]
