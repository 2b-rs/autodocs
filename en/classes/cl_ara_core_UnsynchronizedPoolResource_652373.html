intended use

ara::core::UnsynchronizedPoolResource is an implementation of std::pmr::unsynchronized_pool_resource derived from MemoryResource. [SWS_CORE_00045] The interface also contains do_is_equal(const MemoryResource&) with a Boolean return value; this override is noexcept, exception safe and thread safe. [SWS_CORE_00060]

Generation & destruction

The resource provides constructors without arguments, with an upstream MemoryResource*, with PoolOptions, and with options and an upstream resource. Its destructor is noexcept and overrides the base-class destructor. [SWS_CORE_00063] [SWS_CORE_00064] [SWS_CORE_00067] [SWS_CORE_00068] [SWS_CORE_00062]

Lifecycle & Ownership

Copy construction and copy assignment are deleted. Move construction and move assignment are defined by default and noexcept. release(), options() and upstream_resource() are part of the interface and designated as exception safe. [SWS_CORE_00046] [SWS_CORE_00047] [SWS_CORE_00048] [SWS_CORE_00049] [SWS_CORE_00065] [SWS_CORE_00057] [SWS_CORE_00056]

Limitations & Error handling

do_allocate() and do_deallocate() are noexcept, but are explicitly not thread-safe. If the allocation is unsuccessful, do_allocate() returns nullptr instead of possibly std::bad_alloc; Errors from do_deallocate() are silently ignored. The remaining operations listed in the interface are thread-safe. [SWS_CORE_00058] [SWS_CORE_00059] [SWS_CORE_00060] [SWS_CORE_00062] [SWS_CORE_00065]
