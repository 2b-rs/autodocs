Error Domain for E2E protection

ComE2EErrorDomain isolates end-to-end test errors from the general communication error space. It is part of the data paths for events, methods and fields for which the respective E2E profile is configured. SWS CM §7.4 “Safety” describes the protection function.

Evaluation

Name(), Message() and ThrowAsException() form the same fault domain mechanism as the general communication area. For received samples, ProfileCheckStatus provides the finer information visible per sample; An error code therefore does not have to be equated with every status. EXP ARAComAPI §4.7 “Error Handling” provides the general model.

Activity Diagram: The E2E check is mapped to the sample status; Applications evaluate the individual ProfileCheckStatus. Source: SWS CM §7.4.1 “End-to-end communication protection for SOMEIP”.
