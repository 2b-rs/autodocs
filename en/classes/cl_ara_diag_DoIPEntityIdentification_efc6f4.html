intended use

The class provides the DoIP Entity Identification interface. The application implements GetEntityId, which supplies the EID asynchronously. If the configuration is set to eidUseApi, the Diagnostic Manager calls this method. [SWS_DM_01362] [SWS_DM_01366] [SWS_DM_01361]

Generation & destruction

The constructor receives a InstanceSpecifier for the PortPrototype and a ConcurrencyType; this determines whether GetEntityId must be implemented thread-safely. The destructor is virtual. [SWS_DM_01364] [SWS_DM_01365] [SWS_DM_01366]

Interaction with other classes

Offer allows the manager to forward requests to the handler; StopOffer ends the forwarding. If the EID determination fails, the manager sends six bytes 0xFF. [SWS_DM_01367] [SWS_DM_01368] [SWS_DM_01528]

Limitations & Error handling

Another Offer returns DiagOfferErrc::kAlreadyOffered. Offer and StopOffer are not thread-safe; GetEntityId does not specify standardized errors. [SWS_DM_01367] [SWS_DM_01368] [SWS_DM_01366]
