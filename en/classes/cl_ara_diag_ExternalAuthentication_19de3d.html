intended use

The final class provides the application with the ClientAuthentication instance relevant for a diagnostic client. It is created with the InstanceSpecifier of a PortPrototype for DiagnosticExternalAuthenticationInterface. [SWS_DM_01191] [SWS_DM_01193]

Interaction with other classes

Get resolves the ClientAuthentication associated with a client address or MetaInfo; The Diagnostic Manager returns the instance that manages the authentication status of the passed address or MetaInfo. GetAll returns all ClientAuthentication instances currently managed by the manager or an empty list. [SWS_DM_01194] [SWS_DM_01199] [SWS_DM_01200] [SWS_DM_01201] [SWS_DM_01202] [SWS_DM_01203]

Lifecycle & Ownership

Copying is prohibited (=delete); Move construction and move assignment are defaulted. [SWS_DM_01196] [SWS_DM_01197] [SWS_DM_01194] [SWS_DM_01195]

Limitations & Error handling

Both Get overloads can return DiagErrc::kServiceNotAvailable when essential DM functionality is unavailable. The fetch functions shown are thread-safe; the destructor is not thread-safe. [SWS_DM_01199] [SWS_DM_01200] [SWS_DM_01198]
