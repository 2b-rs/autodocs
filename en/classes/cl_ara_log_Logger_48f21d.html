class ara::log::Logger

[SWS_LOG_00172] Upstream: RS_LT_00003, RS_LT_00046

class Logger final {...};

Represents a logger context. The Logging framework defines contexts which can be seen as logger instances within one Application process or process scope. The contexts have the following properties: • Context ID • Description of the Context ID • Default log level A context will be automatically registered against the Logging backend during creation phase, as well as automatically deregistered during process shutdown phase. So the end user does not care for the objects life time. To ensure such housekeeping functionality, a strong ownership of the logger instances needs to be ensured towards the Logging framework. This means that the Application process are not supposed to call the Logger constructor themselves. The user is not allowed to create a Logger object by himself. Logger context needs to be created by one of the ara::log::CreateLogger functions.

Logger as context and filter boundary

A Logger represents a registered log context. The configurable threshold acts as a reporting filter: only messages with at least this severity are processed; context separation can be adjusted at runtime. SWS Log and Trace §7.1 “Necessary Parameters and Initialization” [SWS_LOG_00254]

Select message form

Log() and LogWith() address modeled messages; your argument list must fit the message model. LogDebug() to LogFatal() as well as WithLevel(), on the other hand, provide a LogStream for unmodeled content. SWS Log and Trace §7.2 “Log Messages” [SWS_LOG_00204] [SWS_LOG_00131]

The preliminary test avoids preparation of filtered messages. Source: SWS Log and Trace §7.1 “Necessary Parameters and Initialization”; [SWS_LOG_00007].

Limit effort before construction

If the payload preparation is complex, IsEnabled(level) should be checked first. This corresponds to the intended resource protection goal because content that will later be filtered anyway does not have to be formatted first. {sws(LOG,"SWS_LOG_00007")} {sws(LOG,"SWS_LOG_00070")}
