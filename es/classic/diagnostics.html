Das Diagnostic Services Cluster der AUTOSAR Classic Platform bündelt den Diagnostic Event Manager (DEM) [SWS_Dem_00183], den Diagnostic Communication Manager (DCM) [SWS_Dcm_00037], den Default Error Tracer (DET) und das Diagnostic Log and Trace (DLT) Modul. Verificar en curación

Die Diagnostic Services der AUTOSAR Classic Platform implementieren normierte Diagnoseprotokolle nach ISO 14229 (UDS) und ISO 15765-4 (OBD), Fehlererkennung und -speicherung im Fehlerspeicher (DEM), Entwicklungsfehler-Tracing (DET) sowie strukturiertes Logging (DLT).

Module im Cluster

Diagnostic Event Manager (DEM)

El DEM es responsable de procesar y almacenar eventos de diagnóstico, memorias de fallos, estados de DTC y los datos de freeze frame asociados.

BSW ID 54 141 APIs (109 Funktionen, 32 Typen) #include "Dem.h"

Diagnostic Communication Manager (DCM)

El DCM implementa servicios de diagnóstico unificados según ISO 14229-1 (UDS) e ISO 15765-4 (OBD). Gestiona sesiones de diagnóstico, niveles de seguridad y enrutamiento de servicios.

BSW ID 53 123 APIs (82 Funktionen, 41 Typen) #include "Dcm.h"

Default Error Tracer (DET)

El DET gestiona errores de desarrollo, errores en tiempo de ejecución y fallos transitorios en todos los módulos BSW y SW-C.

BSW ID 15 10 APIs (9 Funktionen, 1 Typen) #include "Det.h"

Diagnostic Log and Trace (DLT)

El módulo DLT recopila mensajes de registro y puntos de seguimiento, formateándolos en tramas DLT estandarizadas para herramientas externas.
