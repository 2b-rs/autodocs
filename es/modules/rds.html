Clasificación & Propósito

Los flujos de datos sin procesar transmiten datos binarios como una conexión entre el cliente y el servidor a través de protocolos basados ​​en IP. RawDataStreamClient y RawDataStreamServer se crean para interfaces de puerto modeladas [SWS_RDS_10481] [SWS_RDS_11311].

Proceso basado en IP

El cliente se conecta a Connect, el lado del servidor espera hasta WaitForConnection; luego, ambos lados leen o escriben datos y finalizan la conexión a través de Shutdown [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].

Secuencia de conexión y transferencia. Fuente: SWS Raw Data Stream §7.1.4, Capítulo 8. El resumen temporal es una interpretación.
