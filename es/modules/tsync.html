La hora global como servicio para aplicaciones.

ara::tsync media entre un Time Base Resource configurado y el código de la aplicación. Provider establecer o actualizar bases de tiempos maestras; Consumer lee la hora y el estado desde una base de tiempo esclava sincronizada. Comportamiento en caso de error

SynchronizedTimeBaseConsumer::GetTimeWithStatus() proporciona una instantánea de la hora global y local, el estado de sincronización, el estado Leap y los datos de usuario. kNotSynchronizedUntilStartup identifica el estado inicial, kTimeOut una sincronización perdida o retrasada; las actualizaciones correctas establecen kSynchronized o kSynchToGateway. Cada instancia Consumer supervisa el período desde la última actualización frente a syncLossTimeout y, al expirar, establece kTimeOut.
