Información de error a State Management

ExecutionErrorEvent describe el contexto de error que Execution Management pasa a State Management en caso de una terminación anormal o inesperada. En caso de que se produzca un evento de este tipo fuera de una transición solicitada, el estado del grupo de funciones afectado se establece en indefinido y se activa el Callback configurado [SWS_EM_01309].

Efecto en el proceso general.

El evento es un informe de un error de ciclo de vida ya detectado, no una solicitud para que el proceso se solucione solo. La gestión estatal utiliza este contexto para decidir sobre un estado posterior o una estrategia de recuperación SWS EM §7.4 «State Management».
