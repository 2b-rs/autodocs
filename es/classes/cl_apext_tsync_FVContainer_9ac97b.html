Estructura de bloque de base de tiempo apext::tsync::FVContainer

apext::tsync::FVContainer pertenece a la interfaz de base de tiempo global y local. Cada base de tiempo proporciona un valor de tiempo y una instantánea del estado; El mecanismo de sincronización funciona en el contexto maestro/esclavo.
