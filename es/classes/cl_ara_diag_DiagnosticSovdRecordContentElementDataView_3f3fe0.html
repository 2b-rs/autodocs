Contexto

La clase ara::diag::DiagnosticSovdRecordContentElementDataView ([SWS_DM_02270], SWS Diagnostics §8.60.11 «Class: DiagnosticSovdRecordContentElementDataView») representa una vista tipificada de un elemento de contenido de diagnóstico (DiagnosticSovdContentElementData) organizado como un registro estructurado. En el marco del diagnóstico vehicular orientado a servicios (SOVD), actúa como interfaz para la gestión y manipulación de asignaciones clave-valor dentro de un conjunto de datos de diagnóstico. Entre sus interlocutores se cuentan aplicaciones de diagnóstico de nivel superior, las instancias de DiagnosticSovdContentElementData subyacentes y los tipos de iterador especializados DiagnosticSovdRecordContentElementDataIterator y DiagnosticSovdRecordContentElementDataConstIterator ([SWS_DM_02279], [SWS_DM_02281]). Para el llenado tipificado, la clase proporciona operaciones Add sobrecargadas que aceptan tanto tipos de datos primitivos como std::int64_t, std::uint64_t, double, bool y ara::core::StringView como objetos DiagnosticSovdContentElementData anidados ([SWS_DM_02288] a [SWS_DM_02293]).

Ciclo de vida

Como clase de vista, DiagnosticSovdRecordContentElementDataView no posee los datos gestionados por sí misma (interpretación: la instancia actúa como una envoltura ligera de acceso a una estructura de datos existente). El requisito previo para un uso correcto de la vista es que el elemento base referenciado sea de tipo RecordContentElementData o ContentData ([SWS_DM_02273], [SWS_DM_02288]). El estado interno refleja la ocupación del registro subyacente: el nivel de llenado se puede monitorizar mediante Empty ([SWS_DM_02275]) y Size ([SWS_DM_02273]), mientras que Capacity ([SWS_DM_02274]) y Reserve ([SWS_DM_02283]) controlan la asignación de memoria. Con Clear ([SWS_DM_02276]) se pueden restablecer todos los elementos. Además, el estado del contenido se puede establecer explícitamente en un estado de error mediante SetError ([SWS_DM_02272]) o consultar mediante HasError ([SWS_DM_02271]). Con respecto a la concurrencia, todas las funciones miembro de la clase están especificadas como seguras para subprocesos (thread-safe) y seguras ante excepciones (exception safe) ([SWS_DM_02271] a [SWS_DM_02294]).

Ruta de uso

Un flujo de uso típico comprende la reserva previa de capacidad, el llenado paso a paso del registro, así como el acceso aleatorio a elementos de campo individuales:

  1. Reservar capacidad: antes de insertar varios valores, se reserva la capacidad previsiblemente requerida mediante Reserve ([SWS_DM_02283]).
  2. Insertar elementos: mediante las sobrecargas específicas de tipo de Add, se registran elementos de datos indicando una clave ([SWS_DM_02288] a [SWS_DM_02293]).
  3. Comprobar existencia y buscar: mediante HasContentElement se puede comprobar la presencia de una clave ([SWS_DM_02284]), o bien se obtiene un iterador hacia el elemento a través de Find ([SWS_DM_02285], [SWS_DM_02286]).
  4. Leer o modificar valores: a través de operator[] se obtiene una referencia al DiagnosticSovdContentElementData deseado ([SWS_DM_02277], [SWS_DM_02278]).
  5. Eliminar elementos: las entradas que ya no se necesitan se eliminan por clave mediante Remove ([SWS_DM_02287]) o a través de un iterador mediante Erase ([SWS_DM_02294]).

Diagrama de secuencia: secuencia típica para la reserva, llenado y consulta basada en claves de un elemento de registro. Fuentes: [SWS_DM_02283], [SWS_DM_02292], [SWS_DM_02277].

Escenarios de error

Los métodos con potencial de error señalan fallos a través del tipo de retorno ara::core::Result:

  • Tipo de datos incompatible de la instancia base: si la instancia de DiagnosticSovdContentElementData subyacente no es de tipo RecordContentElementData o ContentData, las operaciones de modificación y consulta como Add, operator[], HasContentElement, Remove y Erase fallan con un error en Result ([SWS_DM_02277], [SWS_DM_02284], [SWS_DM_02287], [SWS_DM_02288], [SWS_DM_02294]).
  • Tipo de elemento no permitido al insertar: si se intenta agregar un elemento secundario que sea a su vez de tipo ContentData, la llamada a Add falla ([SWS_DM_02288] a [SWS_DM_02293]).
  • Clave no encontrada: en operator[], HasContentElement o Remove, el Result devuelve un error si la clave especificada no existe en el registro ([SWS_DM_02277], [SWS_DM_02284], [SWS_DM_02287]).
  • Iterador no válido en Erase: si se pasa un iterador no válido a Erase, la función devuelve el código de error DiagErrc::kInvalidArgument ([SWS_DM_02294]).
  • Error de SOVD establecido: si el contenido incluye un código de error establecido mediante SetError ([SWS_DM_02272]), HasError devuelve este error como ara::diag::DiagSovdErrc en el Result ([SWS_DM_02271]).
