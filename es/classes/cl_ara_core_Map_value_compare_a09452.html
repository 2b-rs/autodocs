Sirve como objeto de función para comparar dos pares de valores de un Map en función de sus claves.

La clase auxiliar ara::core::Map::value_compare sirve como objeto de función para la comparación relacional de dos pares de valores de un Map en función de sus claves, utilizando un predicado de comparación [SWS_CORE_01421] encapsulado internamente. La instanciación se produce de forma protegida, principalmente por parte de la estructura Map de nivel superior, mientras que las entidades invocadoras llevan a cabo la evaluación a través del operador de llamada operator() [SWS_CORE_01423]. Dado que las operaciones no son seguras frente a excepciones según la especificación, el código invocador debe tener en cuenta las posibles excepciones del predicado subyacente.

Contexto

La clase auxiliar ara::core::Map::value_compare proporciona en el módulo core de la AUTOSAR Adaptive Platform un objeto de función con cuya ayuda se pueden comparar dos elementos clave-valor completos (value_type) de una tabla asociativa. Conforme a la especificación, la clase se orienta al comportamiento consolidado de la biblioteca estándar de C++ para [map]. La tarea central consiste en hacer aplicable a pares de valores completos el predicado de tipo Compare definido para el orden de las claves. Para ello, la clase encapsula una instancia interna de este predicado en la variable miembro protegida comp [SWS_CORE_01421]. De este modo, value_compare interactúa directamente con la estructura de datos de nivel superior ara::core::Map y garantiza externamente que los algoritmos de ordenación o búsqueda puedan comparar pares de valores de manera coherente en función de sus claves.

Ciclo de vida

La instanciación de value_compare está sujeta a estrictas restricciones de acceso: el constructor value_compare(Compare c) cuenta con la visibilidad protected [SWS_CORE_01422]. Interpretación: debido a esta visibilidad protegida, es de suponer que la creación de nuevas instancias esté reservada principalmente a la propia clase contenedora ara::core::Map, mientras que las entidades invocadoras habituales obtienen objetos de función ya preparados a partir del Map. Durante la construcción, el objeto asume el predicado de comparación y lo almacena en la variable protegida comp [SWS_CORE_01421]. No existe un ciclo de vida con transiciones de estado complejas; tras su creación, la instancia permanece en un estado de ejecución inmutable. Para el funcionamiento concurrente, esto significa que los accesos de lectura paralelos a través del operador de llamada no son críticos, siempre que el predicado encapsulado Compare opere sin estado o de manera segura para hilos (thread-safe).

Ruta de uso

La ruta de uso regular se concentra en la evaluación reiterada de pares de valores mediante el operador de llamada a función operator() [SWS_CORE_01423]. Este se declara como método const y recibe dos referencias a elementos constantes de tipo value_type. Interpretación: durante la ejecución, operator() accede a las partes de clave de ambos pares de valores pasados y las transfiere al predicado comp depositado en [SWS_CORE_01421] a fin de devolver el resultado relacional como valor booleano. El siguiente diagrama ilustra este flujo estandarizado:

Esta ruta se aplica típicamente en algoritmos que deben verificar o recorrer elementos de un Map en función de su orden de clasificación, sin que el usuario tenga que desreferenciar manualmente las claves a partir de los pares de valores.

Escenarios de error

En lo que respecta a la robustez y al tratamiento de excepciones, cabe señalar que ni el constructor [SWS_CORE_01422] ni el operador de llamada operator() [SWS_CORE_01423] están especificados como seguros frente a excepciones; ambos están clasificados explícitamente como «not exception safe». Interpretación: en la práctica, esto implica que la clase no encapsula mecanismos propios para el tratamiento de excepciones y que las excepciones que se disparen al copiar o ejecutar el predicado Compare definido por el usuario se propagan directamente a la entidad invocadora. La especificación no define códigos de error específicos para esta clase auxiliar. Por consiguiente, se consideran condiciones previas esenciales para un funcionamiento sin fallos la correcta capacidad de instanciación y ejecución del predicado Compare suministrado, así como la validez de las referencias a value_type transferidas a operator().
