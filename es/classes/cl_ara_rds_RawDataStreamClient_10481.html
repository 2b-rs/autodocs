Contexto

La clase de C++ ara::rds::RawDataStreamClient forma parte del clúster funcional Raw Data Stream (rds) de la AUTOSAR Adaptive Platform en el release R25-11. Sirve como punto final del lado del cliente para leer y escribir flujos de datos binarios sin procesar a través de una conexión de red subyacente. A través de un artefacto de modelado, identificado mediante ara::core::InstanceSpecifier, el cliente se vincula a un puerto de comunicación concreto y encapsula el establecimiento de la conexión, así como el transporte de datos para flujos de bytes específicos de la aplicación.

Ciclo de vida

Una instancia de ara::rds::RawDataStreamClient no se puede instanciar mediante constructores regulares. El constructor predeterminado no es públicamente accesible, y tanto el constructor de copia [SWS_RDS_11303] como el operador de asignación por copia [SWS_RDS_11304] están explícitamente eliminados (move-only). En su lugar, la creación se realiza mediante el método factoría estático Create [SWS_RDS_10482] pasando el ara::core::InstanceSpecifier correspondiente. Create está especificado como seguro para subprocesos y devuelve, en caso de éxito, una instancia de cliente inicializada en un ara::core::Result.

Las relaciones de propiedad son exclusivas: el movimiento de instancias es posible a través del constructor de movimiento [SWS_RDS_11305] y del operador de asignación por movimiento [SWS_RDS_11306]. Ambas operaciones están declaradas con noexcept, pero no son seguras para subprocesos.

Tras la creación, el cliente se encuentra en estado desconectado. La conexión de red activa se establece a continuación mediante Connect [SWS_RDS_10484], [SWS_RDS_11307]. La finalización de la conexión se realiza de forma ordenada mediante Shutdown [SWS_RDS_10485]. El destructor ~RawDataStreamClient [SWS_RDS_10483] garantiza que una conexión que aún permanezca abierta se cierre automáticamente al salir del ámbito. Está especificado como no seguro para subprocesos.

Diagrama de estados: fases del ciclo de vida y transiciones de estado de una instancia de RawDataStreamClient. Fuentes: [SWS_RDS_10482], [SWS_RDS_10484], [SWS_RDS_10485], [SWS_RDS_10483]

Ruta de uso

El flujo regular para la transmisión de datos binarios se divide en creación, establecimiento de la conexión, transmisión de datos útiles y desconexión:

  1. Instanciación: la aplicación crea el cliente de forma síncrona mediante Create(instance) [SWS_RDS_10482].
  2. Establecimiento de la conexión: antes del primer intercambio de datos, se establece la conexión. Para ello, están disponibles la variante bloqueante Connect() [SWS_RDS_10484] o la sobrecarga con límite de tiempo Connect(timeout) [SWS_RDS_11307] con un timeout del tipo std::chrono::milliseconds.
  3. Enviar datos: la escritura se realiza mediante WriteData(data, maxLength) [SWS_RDS_10487] o WriteData(data, maxLength, timeout) [SWS_RDS_11310], respectivamente. Los datos útiles se transfieren como std::unique_ptr<ara::core::Byte[]>, con lo cual el búfer de memoria pasa a ser gestionado exclusivamente por la operación de envío.
  4. Recibir datos: para leer datos se utiliza ReadData(maxLength) [SWS_RDS_10486] o la variante con temporización ReadData(maxLength, timeout) [SWS_RDS_11309]. En caso de recepción correcta, se devuelve un ReadDataResult.
  5. Desconexión: tras finalizar la transferencia de datos, la aplicación cierra explícitamente la conexión de red mediante Shutdown() [SWS_RDS_10485].

Diagrama de secuencia: secuencia típica de llamadas desde la creación y la transferencia de datos hasta la desconexión. Fuentes: [SWS_RDS_10482], [SWS_RDS_10484], [SWS_RDS_10487], [SWS_RDS_10486], [SWS_RDS_10485]

Escenarios de error

Todas las interfaces funcionales de ara::rds::RawDataStreamClient prescinden de excepciones de C++ y señalan el éxito o el fracaso a través del tipo de retorno ara::core::Result con garantía noexcept:

  • Fallo en el establecimiento de la conexión: si el cliente no puede establecer una conexión con el interlocutor o si expira el límite de tiempo especificado, Connect falla y devuelve un código de error del dominio de errores RdsErrc en ara::core::Result<void> [SWS_RDS_10484].
  • Errores en operaciones de escritura y lectura: Si la conexión se interrumpe durante la transmisión o se supera el tiempo de espera de WriteData o ReadData, el objeto de resultado respectivo contiene el código de error correspondiente [SWS_RDS_10486], [SWS_RDS_10487], [SWS_RDS_11309], [SWS_RDS_11310].
  • Error de configuración: Si el ara::core::InstanceSpecifier transmitido no existe en el modelo del sistema o no está asignado a un puerto de comunicación válido, Create ya falla y proporciona la causa del error correspondiente en el objeto Result [SWS_RDS_10482].
