Propósito de uso

ara::diag::ServiceValidation es la interfaz para validar servicios de diagnóstico. Dependiendo de la categoría de mapeo, Validate() se llama como verificación de fabricante o proveedor dentro de la secuencia NRC [SWS_DM_00772] [SWS_DM_01252] [SWS_DM_01253].

Generación y amp; destrucción

La instancia se crea mediante un InstanceSpecifier para un DiagnosticServiceValidationInterface [SWS_DM_00772]. Es una instancia única que no se puede copiar ni mover; el destructor virtual es noexcept [SWS_DM_01689] [SWS_DM_01690] [SWS_DM_01687] [SWS_DM_01688] [SWS_DM_00773].

Interacción con otras clases.

Después de Offer(), DM reenvía mensajes de diagnóstico a Handler; StopOffer() evita esto [SWS_DM_00776] [SWS_DM_00777]. El método virtual Validate() recibe datos de solicitud y MetaInfo y devuelve un Future<void>. Una vez finalizado, Confirmation() informa sobre el resultado del procesamiento [SWS_DM_00774] [SWS_DM_00775].

Limitaciones y Manejo de errores

La validación exitosa continúa el procesamiento normal de UDS. Los errores distintos de kNoProcessingNoResponse dan como resultado una respuesta negativa con un valor de DiagUdsNrcErrc; con kNoProcessingNoResponse se descarta el mensaje [SWS_DM_01254] [SWS_DM_01255] [SWS_DM_00860]. Los datos de Request solo siguen siendo válidos hasta que se cumpla Promise o se cancele el procesamiento de [SWS_DM_00774].
