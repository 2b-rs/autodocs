Se genera para un puerto de DiagnosticAuthenticationInterface con InstanceSpecifier y ConcurrencyType y se puede ofrecer a través de Offer() para DM. [SWS_DM_01123] [SWS_DM_01124] [SWS_DM_01130]

Interacción con otras clases.

La aplicación verifica el certificado y devuelve el desafío y la clave pública efímera en un futuro. [SWS_DM_01126] [SWS_DM_01230]

Para la variante bidireccional, VerifyCertificateBidirectional() comprueba el certificado y el desafío y genera el desafío, la clave pública efímera, la prueba de propiedad y el certificado de servidor para el probador.
