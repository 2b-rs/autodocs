Consumidor: lea la hora sincronizada de forma segura

El consumidor proporciona una aplicación con una base de tiempo sincronizada configurada. GetTimeWithStatus() no solo proporciona la hora global actual, sino también una instantánea coherente junto con la hora local, el estado de sincronización, el estado de salto y los datos del usuario. SWS Time Synchronization §7.1 «General Overview» SWS Time Synchronization §7.2 «Normal Operation» [SWS_TS_14218]

La consulta del consumidor devuelve la hora y el estado juntos; Se pueden informar cambios de estado. Fuente: SWS Time Synchronization §7.2 «Normal Operation»; [SWS_TS_14218]; [SWS_TS_00701].

Evalúe el estado solo en lugar del valor del tiempo

Antes de confiar en el valor del tiempo, la aplicación debe considerar SynchronizationStatus: inicialmente no sincronizado, sincronizado, basado en puerta de enlace o tiempo de espera. La desviación de la tasa se puede leer por separado y es inicialmente 0.0 antes de un cálculo. {sws(TS,"SWS_TS_00202")} {sws(TS,"SWS_TS_00032")}

Operar Notifier con propiedad clara

Los notificadores de estado, sincronización, salto, precisión y validación complementan el Polling. Sólo se puede registrar un Notifier por categoría; otra inscripción reemplaza a la anterior. No hay almacenamiento en búfer para datos de precisión, por lo que Callback debe desacoplarse si es necesario. {sws(TS,"SWS_TS_00701")} {sws(TS,"SWS_TS_01018")}
