Propósito de uso

La clase final proporciona operaciones para un diagnóstico Event. Lee el byte de estado, el estado antirrebote, el contador de detección de fallas, el estado de prueba completa y el número de DTC de forma asincrónica en el formato deseado. Ciclo de vida y propiedad

La instancia se construye a través de un puerto InstanceSpecifier. Está prohibido copiar, mover y ambas formas de asignación (=delete), por lo que representa una única instancia no asignable. [SWS_DM_00647] [SWS_DM_01681] [SWS_DM_01682] [SWS_DM_01679] [SWS_DM_01680]

Interacción con otras clases.

SetEventStatusChangedNotifier registra una función Callback para cada cambio de estado; otra llamada sobrescribe la anterior Notifier. El Diagnostic Manager procesa los bits de estado del evento de acuerdo con los bits de estado UDS-DTC y proporciona el estado actual del evento asociado en GetEventStatus. Limitaciones y Manejo de errores

Para GetDTCNumber, el administrador devuelve DiagErrc::kNoSuchDTC si no existe ninguna asignación de DTC de evento a UDS; las consultas también pueden informar kServiceNotAvailable. La mayoría de las consultas de estado y el notificador no son seguros para subprocesos; GetDTCNumber es seguro para subprocesos. [SWS_DM_01269] [SWS_DM_00653] [SWS_DM_00649] [SWS_DM_00654] [SWS_DM_00655] [SWS_DM_00656] [SWS_DM_00650]

Contexto técnico El administrador actualiza los bits de estado del evento según los resultados de las pruebas informados a través de Monitor::ReportMonitorAction. Para kResetTestFailed, solo se restablece el bit kTestFailed. Al reiniciar un OperationCycle asociado, el administrador establece kTestFailedThisOperationCycle en cero y kTestNotCompletedThisOperationCycle en uno; La eliminación de un DTC también restablece los bits de estado de eventos especificados. [SWS_DM_01025] [SWS_DM_01026] [SWS_DM_01027] [SWS_DM_01028]

El valor de retorno de GetTestComplete es verdadero si y solo si FDC es -128 o 127. La API proporciona la información de estado a través de ara::core::Future. [SWS_DM_00655] [SWS_DM_00649] [SWS_DM_00654] [SWS_DM_00656]
