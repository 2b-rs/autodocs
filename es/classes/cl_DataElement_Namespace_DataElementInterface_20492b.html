Propósito de uso

La clase <DataElementInterface> es la interfaz de un elemento de datos de diagnóstico. Una aplicación implementa el método puramente virtual Read(); El Diagnostic Manager reenvía solicitudes después de Offer() a este Handler. El resultado se devuelve de forma asíncrona como ara::core::Future con una salida de lectura. [SWS_DM_00603] [SWS_DM_00596] [SWS_DM_00597]

Generación y amp; destrucción

La instancia se crea con ara::core::InstanceSpecifier y ConcurrencyType. Offer() activa el reenvío de DM, StopOffer() lo vuelve a desactivar; una nueva oferta será rechazada con DiagOfferErrc::kAlreadyOffered. [SWS_DM_00587] [SWS_DM_00597] [SWS_DM_00617]

Ciclo de vida y propiedad

Se prohíbe la copia, construcción y cesión Move (=delete). La clase tiene un destructor virtual noexcept. [SWS_DM_01659] [SWS_DM_01660] [SWS_DM_01661] [SWS_DM_01662] [SWS_DM_00588]

Limitaciones y Manejo de errores

Read() recibe MetaInfo y un CancellationHandler. La implementación puede usar esto para verificar el estado de aborto o registrar un notificador; En caso de fallo técnico, se debe utilizar un DiagUdsNrcErrc adecuado. Read(), Offer y StopOffer no son seguros para hilos. [SWS_DM_00596] [SWS_DM_00597] [SWS_DM_00617]
