Objeto de estado como valor de observación atómica

SynchronizedTimeBaseStatus es una instantánea de un Time Base Resource. Incluye indicadores de estado, información de actualización y salto, valores de tiempo y datos de usuario para que una aplicación tome su decisión de manera consistente. SWS Time Synchronization §7.1 «General Overview» [SWS_TS_14218]

Estados después de una sincronización exitosa o de un tiempo de espera. Fuente: SWS Time Synchronization §7.2 «Normal Operation»; [SWS_TS_00032]; [SWS_TS_00033].

Derivar validez del estado de sincronización

GetCreationTime() solo entrega tiempo de generación sincronizado si la base de tiempo se sincronizó al menos una vez; de lo contrario, el opcional permanece vacío. GetLeapJump() sólo describe saltos hasta la generación de este Snapshot. {sws(TS,"SWS_TS_01055")} {sws(TS,"SWS_TS_01054")}

Clasificar indicadores de corrección.

Una corrección de tasa válida establece RATE_CORRECTED; Si la desviación calculada excede el límite configurado, se considera no válida y se establece RATE_EXCEEDED. {sws(TS,"SWS_TS_14224")} {sws(TS,"SWS_TS_14228")}
