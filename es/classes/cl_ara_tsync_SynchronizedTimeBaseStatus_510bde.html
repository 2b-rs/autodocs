Objeto de estado como valor de observación atómica

SynchronizedTimeBaseStatus es una instantánea de un Time Base Resource. Incluye indicadores de estado, información de actualización y salto, valores de tiempo y datos de usuario para que una aplicación tome su decisión de manera consistente.
