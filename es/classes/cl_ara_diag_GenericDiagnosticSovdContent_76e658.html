Propósito de uso

La interfaz procesa datos genéricos de SOVD Content. Diagnostic Manager utiliza la instancia representada mediante DiagnosticSovdContentPortMapping para leer datos SOVD. Read proporciona DiagnosticSovdContentData de forma asíncrona para un nombre de Content; Write acepta esos datos para «Write a Data Value». [SWS_DM_02186] [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_02164]

Interacción con otras clases.

Para una solicitud de lectura, el administrador llama a Read y forma la respuesta SOVD a partir de los elementos de contenido agregados. Para una solicitud de escritura, llama a Write con DiagnosticSovdContentData, cuyos elementos se construyen utilizando SetName y SetContent. [SWS_DM_01432] [SWS_DM_02166]

Ciclo de vida y propiedad

El constructor obtiene InstanceSpecifier y SovdContentConcurrencyType. La clase es móvil; Se especifican la construcción del movimiento y la asignación del movimiento. [SWS_DM_02187] [SWS_DM_02189] [SWS_DM_02190]

Limitaciones y Manejo de errores

Read y Write devuelven un error SOVD si el resultado es negativo. CancellationHandler no se puede almacenar ni utilizar más allá de la vida útil de la operación actual. Offer activa el reenvío de solicitudes, StopOffer lo detiene; DiagOfferErrc::kAlreadyOffered informa una interfaz que ya se ofrece. Las funciones presentadas son seguras para subprocesos. [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_02193] [SWS_DM_02194]

Reglas de parámetros y resultados Read recibe ContentName, MetaInfo y CancellationHandler y proporciona datos abstractos de contenido SOVD para una respuesta positiva o un error de SOVD. Write recibe la misma información de contexto así como los datos de contenido a escribir; Estos datos son válidos hasta que se cumpla o cancele el futuro. El constructor y el destructor son seguros para excepciones y subprocesos. [SWS_DM_02187] [SWS_DM_02188] [SWS_DM_02191] [SWS_DM_02192]

Las operaciones asincrónicas son puntos de interfaz puramente virtuales; Por lo tanto, el procesamiento del hormigón implementa la aplicación de suministro. La respuesta externa la forma el Gestor de Diagnóstico en base a los futuros cumplidos. [SWS_DM_02191] [SWS_DM_02192] [SWS_DM_01432]

La arquitectura describe GenericDiagnosticSovdContent como una interfaz para datos SOVD: Read se llama para «Read Single Data Value», Write para «Write a Data Value» de la instancia de contenido SOVD especificada.
