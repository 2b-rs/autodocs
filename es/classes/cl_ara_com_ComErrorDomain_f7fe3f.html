ComErrorDomain resume los errores recuperables de las operaciones estandarizadas ara::com. Por lo tanto, un Result o un Future asíncrono pueden entregar un código ComErrc en lugar de un valor. EXP ARAComAPI §4.7 «Error Handling» especifica el modelo de resultado/código de error.

Usar dominio

Name() describe el dominio, Message() el error individual y ThrowAsException() permite la asignación de Exception. En caso de error, la lógica funcional debe reaccionar primero al dominio y al código enumerado; los errores E2E y FVM se delimitan deliberadamente mediante dominios propios.
