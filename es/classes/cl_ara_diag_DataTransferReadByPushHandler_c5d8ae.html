Propósito de uso

DataTransferReadByPushHandler implementa transferencias de datos de lectura a RequestReadFile o RequestReadDirectory, donde la aplicación pasa el bloque de datos a AraDiag como resultado. Read() recibe una cantidad recomendada de bytes y devuelve los datos de forma asincrónica como ara::core::Vector. [SWS_DM_01515] [SWS_DM_01522]

Ciclo de vida y propiedad

El Handler no se puede copiar para una sesión única de transferencia de archivos, pero se puede mover y asignar. No debe destruirse antes de ExitRead(). ExitRead finaliza la sesión y devuelve el registro del parámetro de respuesta de transferencia o un error de UDS a través de un Future.
