clase ara::exec::StateClient

[SWS_EM_02275] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150

class StateClient final {...};

ara::exec::StateClient is an interface of Execution Management that is used by State Management to request transitions between Function Group States or to perform other related operations. Class used to perform Function Group state management operation needed during lifetime of a Machine. State Management during its own lifetime will need to start and stop software, that is intended to run on a Machine managed by it. This can be achieved by performing state transition of a Function Group to which required software is assigned. Integrator will assign software to run in a particular state (of Function Group) and State Management can start it, by requesting Execution Management to perform state transition (of this Function Group) to the mentioned state. Execution Management will then start mentioned software and report transition result back to State Management. Please note that stopping software can be done in similar way (i.e. Function Group state transition, to a state in which software is not configured to be run).

Límite fiscal entre la gestión estatal y la gestión de ejecución

StateClient es la API a través de la cual State Management solicita cambios de grupo de funciones y estado de la máquina. State Management determina la configuración operativa de la plataforma; Execution Management ejecuta las transiciones de proceso desde SWS EM §7.4 «State Management» SWS EM §7.4.5 «State Transition».

Contrato de transición asincrónica

SetState devuelve un Future, cuya terminación representa la ruta de resultado de la transición. Una nueva solicitud válida para un grupo de funciones en transición puede cancelar la solicitud anterior; una solicitud para el estado que ya se ha alcanzado se ignora con éxito [SWS_EM_02278] [SWS_EM_02298] [SWS_EM_02295].

Fehlerbehandlung und Recovery

Prüfen Sie nach jedem SetState()-Aufruf das zurückgegebene Future. Schlägt während eines Function-Group-Übergangs der Start eines für den Requested State benötigten Process fehl, beendet Execution Management den Übergang und setzt den Current State auf Undefined. Das Future meldet ExecErrc::kOperationFailed; den konfigurierten Fehlerkontext kann State Management über GetExecutionError() lesen [SWS_EM_02259].

Endet ein für den Requested State konfigurierter Process abnormal oder unerwartet, ist ExecErrc::kUnexpectedTermination zu behandeln [SWS_EM_02315]. Berücksichtigen Sie außerdem kOperationCanceled bei ersetzten Requests, kNoCommunication bei fehlender Kommunikation und kInvalidTransition für verbotene oder ungültige Zielzustände [SWS_EM_02278]. Der beim Erzeugen von StateClient registrierte Undefined-State-Callback muss während der gesamten Lebenszeit des Clients aufrufbar bleiben und erhält Function Group sowie ExecutionError als ExecutionErrorEvent.

Diagrama de secuencia: Request procede de State Management, mientras que Execution Management ejecuta la terminación, Start y la resolución de dependencias SWS EM §7.4.4 «State Interaction» SWS EM §7.4.5 «State Transition».

Inicio inicial de la máquina y contexto de error

Execution Management inicia la primera transición al propio MachineFG:Startup. State Management consulta su resultado a través de GetInitialMachineStateTransitionResult. Una salida de proceso anormal puede ingresar a la ruta de error SM a través de la devolución de llamada de estado indefinido y GetExecutionError [SWS_EM_01023] [SWS_EM_02241] [SWS_EM_01309].
