Propósito de uso

CommunicationControl es la interfaz de aplicación del servicio UDS 0x28. La aplicación implementa CommCtrlRequest(); el servidor de diagnóstico llama a este método para procesar un servicio de control de comunicación. [SWS_DM_00804] [SWS_DM_00808] [SWS_DM_00865]

Interacción Generación &

La instancia se crea para un puerto de DiagnosticComControlInterface con InstanceSpecifier y ConcurrencyType. CommCtrlRequest() recibe todos los parámetros de solicitud UDS en ComCtrlRequestParamsType, además de MetaInfo y CancellationHandler, y devuelve un Future. Offer y StopOffer controlan el reenvío a través de DM; Offer informa DiagOfferErrc::kAlreadyOffered si se le llama dos veces. [SWS_DM_00806] [SWS_DM_00808] [SWS_DM_00809] [SWS_DM_00810]
