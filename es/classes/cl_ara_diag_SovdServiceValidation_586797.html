Propósito de uso

SovdServiceValidation implementa comprobaciones SOVD específicas del fabricante o proveedor. Se llama a Validate() para cada solicitud de SOVD y, para colecciones de recursos, una vez por elemento contenido. [SWS_DM_01822] [SWS_DM_01827] El DM llama a los validadores configurados en el orden especificado e inmediatamente finaliza el procesamiento con error tan pronto como uno de ellos falla. [SWS_DM_01784] [SWS_DM_01785]

Generación y ciclo de vida

La instancia se crea para un PortPrototype de DiagnosticSovdServiceValidationInterface con ConcurrencyType. [SWS_DM_01823] Offer habilita el reenvío a través de DM y StopOffer lo deshabilita. Offer puede suministrar kAlreadyOffered o kConfigurationMismatch. [SWS_DM_01825] [SWS_DM_01826] El destructor es seguro para excepciones. [SWS_DM_01824]

Limitaciones y Manejo de errores

Validate recibe el método HTTP y MetaInfo, incluida la ruta del recurso, y devuelve éxito o un error SOVD. [SWS_DM_01827] Los especificados incluyen configuración incorrecta del servidor, no se cumplen los requisitos previos, indisponibilidad temporal y derechos de acceso faltantes. [SWS_DM_01827] La seguridad del subproceso de Validate depende de ConcurrencyType; Offer y StopOffer no son seguros para subprocesos. [SWS_DM_01827] [SWS_DM_01825] [SWS_DM_01826]

Para una colección de recursos, el DM primero valida la colección y luego valida cada elemento que se devolverá con su propia ruta en MetaInfo. [SWS_DM_01785] La función de validación es segura para excepciones y devuelve un Future<void>. [SWS_DM_01827] El constructor es seguro para excepciones y subprocesos, el destructor es seguro para excepciones y no es seguro para subprocesos. [SWS_DM_01823] [SWS_DM_01824]

En caso de error, el DM no continuará procesando la solicitud. [SWS_DM_01784]

Uso Generado por IA / AI generated

Aviso de uso generado automáticamente derivado de este elemento de especificación AUTOSAR-R25-11; no es texto oficial AUTOSAR. Prueba: [SWS_…].

El método virtual Validate se llama para cada mensaje de solicitud SOVD entrante; para una colección de recursos, se llama varias veces: una para la colección misma y otra para cada recurso contenido. Se proporcionan requestMethod (método HTTP) utilizado en el Request y metaInfo, incluida la ruta del recurso o de la colección de recursos solicitados [SWS_DM_01827]. El ara::core::Future<void> devuelto proporciona un valor vacío si la solicitud está permitida; de lo contrario, proporciona un error.

Tratamiento de errores y concurrencia

Los posibles errores son DiagSovdErrc::kSovdServerMisconfigured (servidor SOVD mal configurado), DiagSovdErrc::kPreconditionNotFulfilled (requisitos previos no cumplidos), DiagSovdErrc::kTemporarilyNotAvailable (solicitud actualmente no operable) y DiagSovdErrc::kInsufficientAccessRights (derechos de acceso insuficientes); Se permiten valores DiagSovdErrc adicionales para mensajes de error específicos de SOVD. Si la implementación debe ser segura para subprocesos o no está determinada por el ConcurrencyType pasado en el constructor; el método es seguro frente a excepciones.
