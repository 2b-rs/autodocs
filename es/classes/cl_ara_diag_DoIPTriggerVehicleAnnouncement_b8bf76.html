Propósito de uso

La clase permite que la aplicación active anuncios de vehículos de Diagnostic Manager para una ID de interfaz de red. La función estática GetDoIPTriggerVehicleAnnouncement proporciona una referencia de resultado a la interfaz; TriggerVehicleAnnouncement es puramente virtual.
