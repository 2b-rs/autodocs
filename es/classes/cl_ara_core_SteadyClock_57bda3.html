clase ara::core::SteadyClock

[SWS_CORE_06401] Upstream: RS_AP_00130

class SteadyClock final {...};

This clock represents a monotonic clock. The time points of this clock cannot decrease as physical time moves forward and the time between ticks of this clock is constant.

ara::core::SteadyClock representa un reloj monotónico: sus puntos temporales no retroceden a medida que avanza el tiempo físico y la duración del tick es constante [SWS_CORE_06401]. Cumple los requisitos de TrivialClock; su época es el inicio del sistema [SWS_CORE_11800] [SWS_CORE_11801].

El valor de tiempo utiliza std::int64_t como representación, std::nano como período y std::chrono::time_point<SteadyClock, duration> como tiempo, [SWS_CORE_06412] [SWS_CORE_06413] [SWS_CORE_06414]. is_steady es siempre true; now() es noexcept, [SWS_CORE_06431] [SWS_CORE_06432] seguro para excepciones y subprocesos.
