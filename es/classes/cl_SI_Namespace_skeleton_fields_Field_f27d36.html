Propósito de uso

Esta clase de campo esqueleto se genera para cada elemento de ServiceInterface modelado como Field. Namespace, el nombre y el encabezado <SiNamespaceDerivedDirectoryPath>/<SiShortname>_skeleton.h se derivan del modelo ServiceInterface del manifiesto ARXML. Se utiliza a través de su propia implementación de servicio que hereda de la clase Skeleton generada. [SWS_CM_00007]

usar

Update(value) actualiza el valor del campo interno y activa la transmisión de datos actualizados a los suscriptores; Se envía una notificación si el notificador del campo está presente. El valor de retorno indica éxito o una coincidencia ComErrc. [SWS_CM_00119]

El Handler asincrónico se puede registrar para solicitudes entrantes de captador o definidor. El controlador get solo existe con Field.hasGetter == TRUE, el controlador set solo con Field.hasSetter == TRUE; ambos tienen sobrecargas para un contexto de ejecución proporcionado. Se puede configurar y eliminar un controlador de fallas de transporte. [SWS_CM_00114] [SWS_CM_11360] [SWS_CM_00116] [SWS_CM_11362] [SWS_CM_00096] [SWS_CM_00097] [SWS_CM_00098]
