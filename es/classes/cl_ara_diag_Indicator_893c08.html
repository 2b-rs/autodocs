Propósito de uso

Indicator proporciona acceso a indicadores de diagnóstico. GetIndicatorState() devuelve el estado actual de forma asincrónica; el DM lo proporciona a través de la instancia asociada. [SWS_DM_00741] [SWS_DM_00744] [SWS_DM_00888] Los eventos asignados a un DTC dan como resultado kOnDemand si al menos un indicador tiene este estado; si solo se entrega kOff, se entrega kOff. Generación y amp; destrucción

El constructor espera un InstanceSpecifier para un PortPrototype de DiagnosticIndicatorInterface. [SWS_DM_00742] SetNotifier() registra una función para actualizaciones; otro registro sobrescribe el anterior. [SWS_DM_00745] [SWS_DM_01359] El destructor es noexcept y es seguro para excepciones. Limitaciones y Manejo de errores

Si la funcionalidad esencial de DM no está disponible, GetIndicatorState() puede proporcionar DiagErrc::kServiceNotAvailable. [SWS_DM_00744] El sondeo es seguro para subprocesos, pero el registro del notificador no es seguro para subprocesos. [SWS_DM_00744] [SWS_DM_00745]

El estado del indicador se devuelve de forma asíncrona como IndicatorStatusType. [SWS_DM_00744] El DM siempre establece el bit de estado kWarningIndicatorRequested al mismo tiempo que configura kConfirmedDTC. [SWS_DM_01266] Si se cumplen las condiciones de curación, el DM restablece el bit 7 de estado UDS-DTC al final de un ciclo de operación. [SWS_DM_00224] Construcción y consulta de estado son thread-safe. [SWS_DM_00742] [SWS_DM_00744]

Si la funcionalidad esencial de DM no está disponible, el acceso al estado devuelve el error especificado y no cambia el Notifier registrado. [SWS_DM_00744] [SWS_DM_00745]
