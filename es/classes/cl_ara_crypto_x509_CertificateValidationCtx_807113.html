Papel en la pila criptográfica

ara::crypto::x509::CertificateValidationCtx pertenece a la sección X.509 de Crypto Stack. Esta área separa el análisis, el almacenamiento persistente de certificados y la validación de rutas configurables con información de estado y confianza. SWS Cryptography §7.5 «Certificate handling (X.509 Provider»

Análisis, confianza y validación.

El proveedor X.509 puede transferir certificados o cadenas individuales a objetos en tiempo de ejecución. Un contexto de validación separa la cadena que se va a verificar de la confianza configurada: los certificados confiables sirven como posibles anclajes de confianza, los certificados que no son confiables sirven como posibles certificados intermedios. El tiempo, las extensiones críticas, CRL/OCSP y las opciones afectan la verificación. SWS Cryptography §7.5.1 «X.509 Certificate Parsing» SWS Cryptography §7.5.2 «X.509 Certificate Validation»

Memoria y resultado

Los certificados se pueden conservar individualmente o en grupos. El resultado de la validación permite consultar el estado general, el certificado incorrecto y la cadena encontrada durante la construcción de la ruta. SWS Cryptography §7.5.3 «X.509 Certificate Storage»

función AddOcspResponse [SWS_CRYPT_50124] Upstream: RS_CRYPTO_02306

virtual ara::core::Result< CertificateValidationStatus > AddOcsp Response (OcspResponse::Sptrc ocspResponse, ara::core::Optional< Certificate::Sptrc > trustedOcspIssuerCertificate) noexcept=0;

Validate and add an OCSP response to be used during certificate validation to the set of previously added OCSP responses. Multiple OCSP responses may be added to one context. In order to validate the OCSP response, the issuer of the OCSP response must have been a) set as a trusted or untrusted certificate in this context previously, or b) the CRL must have been signed by another certificate that has the id-kp-OCSPSigning extended key usage set issued by the same CA, or c) the CRL must be signed by a trusted CA passed to this function using the optional trustedOcspIssuerCertificate parameter.
