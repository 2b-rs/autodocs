class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

Propósito de uso

ErrorCode encapsula un valor de error sin formato específico del dominio, una referencia al ErrorDomain asociado y datos adicionales opcionales específicos del proveedor. El tipo es un tipo literal. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

Interacción Generación &

Se puede crear a partir de una enumeración de error o a partir de un valor, un dominio de error y datos adicionales. Domain(), Value(), SupportData() y Message() hacen accesibles sus componentes o texto de error; ThrowAsException() determina el tipo de excepción apropiado en todo el dominio. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

Limitaciones y Manejo de errores

Las comparaciones sólo tienen en cuenta el valor del error y el dominio del error, no los datos adicionales. ErrorCode y sus miembros pueden usarse independientemente de ara::core::Initialize y Deinitialize. [SWS_CORE_10301] [SWS_CORE_15002]

Contexto de error en lugar de valores de error generales

Un ErrorCode asocia un valor de error escrito con su contexto ErrorDomain; Opcionalmente puede llevar un mensaje e información adicional específica del fabricante. Las interfaces ARA lo usan dentro de Result para errores recuperables. EXP InterfacesGuidelines §3.1.2 «Result» EXP ARAComAPI §4.7 «Error Handling»

Los códigos de error específicos del fabricante requieren sus propios dominios de error; Las aplicaciones portátiles y de pila neutral deben tratar dichos dominios como un caso predeterminado general. EXP InterfacesGuidelines §3.1.5 «Standardized vs Vendor-specific ErrorCodes»

Diagrama de colaboración: ErrorCode obtiene contexto y mensaje de su dominio; la transformación de excepción es la ruta de excepción explícita. Fuentes: EXP InterfacesGuidelines §3.1.2 «Result» RS General §4.1.3 «The use of noexcept».

Escriba el valor de error borrado

El SWS describe ErrorCode como un valor de error con contexto de dominio: el código específico del dominio se borra en un valor entero para un transporte uniforme; Es posible que se comparta información de soporte adicional. Las comparaciones consideran el valor y el dominio, no los datos de respaldo. SWS Core §7.2 «Error handling» SWS Core §7.2.5.1 «ErrorCode» [SWS_CORE_10301] [SWS_CORE_10302]
