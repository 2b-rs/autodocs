Propósito de uso

ara::core::Future<T, E> representa el resultado o error disponible posteriormente de una llamada asincrónica. El tipo de error debe ser ara::core::ErrorCode; de lo contrario, se requiere un error en tiempo de compilación. Junto con Promise, el tipo permite el manejo seguro de subprocesos y sin excepciones de valores y errores asincrónicos. [SWS_CORE_00321] [SWS_CORE_10800]

Ciclo de vida y propiedad

Está prohibida la copia (=delete); La construcción de mudanzas y la asignación de mudanzas están disponibles. El destructor abandona cualquier estado compartido. GetResult(), get() y then() invalidan el Future original. [SWS_CORE_00334] [SWS_CORE_00335] [SWS_CORE_00323] [SWS_CORE_00325] [SWS_CORE_00333] [SWS_CORE_00336] [SWS_CORE_00326] [SWS_CORE_00337]

Interacción con otras clases.

GetResult() se bloquea hasta que hay un valor o error y devuelve un Result<T,E> que no se activa. then() crea un Future posterior a partir de una función a través de este Result; la sobrecarga con Executor ejecuta la función en su contexto de ejecución. [SWS_CORE_00336] [SWS_CORE_00331] [SWS_CORE_00337]

Limitaciones y Manejo de errores

Si se abandona el Promise correspondiente, GetResult() devuelve el error FutureErrc::kBrokenPromise. is_ready() se puede verificar antes de bloquear; para true, get(), GetResult() y las llamadas en espera no se bloquean. Las llamadas prohibidas sobre futuros no válidos se especifican como violaciones. [SWS_CORE_00336] [SWS_CORE_00332] [SWS_CORE_13011]

Manejo de errores asincrónicos

Future es el tipo de devolución armonizado para llamadas asincrónicas que pueden devolverse o fallar. A diferencia de get(), GetResult() devuelve un Result con un valor o error después de esperar y no activa un Exception. The return type of then(...) depends on the return type of func (aka continuation).

Return type deduction: • If U is Future<T2,E2> for some types T2, E2, then the return type of then(...) is Future<T2,E2>.
