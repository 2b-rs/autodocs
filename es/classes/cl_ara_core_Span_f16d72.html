Propósito de uso

ara::core::Span<T, Extent> implementa std::span como una vista de elementos relacionados; Extent puede ser estático o dinámico [SWS_CORE_01900] [SWS_CORE_01931].

Generación y amp; destrucción

Un tramo se puede construir a partir de punteros, una matriz C, ara::core::Array, un contenedor compatible u otro tramo [SWS_CORE_01942] [SWS_CORE_01943] [SWS_CORE_01944] [SWS_CORE_01945] [SWS_CORE_01947] [SWS_CORE_01950]. La construcción de copia, la asignación de copia y el destructor son predeterminados y seguros para excepciones [SWS_CORE_01949] [SWS_CORE_01952] [SWS_CORE_01951].

Ciclo de vida y propiedad

La clase almacena una vista, no los elementos subyacentes; la interfaz proporciona punteros, referencias e iteradores para acceder a [SWS_CORE_01915] [SWS_CORE_01916] [SWS_CORE_01917] [SWS_CORE_01971]. Esta clase no gestiona la validez de los elementos referenciados.

Interacción con otras clases.

first(), last() y subspan() crean vistas parciales; size() y size_bytes() indican su alcance [SWS_CORE_01961] [SWS_CORE_01962] [SWS_CORE_01963] [SWS_CORE_01964] [SWS_CORE_01965] [SWS_CORE_01966] [SWS_CORE_01967] [SWS_CORE_01968].

Limitaciones y Manejo de errores

Las operaciones especificadas son constexpr, noexcept y seguras frente a excepciones [SWS_CORE_01960] [SWS_CORE_01970] [SWS_CORE_01969]. La especificación no define aquí una comprobación de tiempo de ejecución propia para los límites de operator[], front() o back() [SWS_CORE_01959] [SWS_CORE_01960] [SWS_CORE_01970].

Vista no propietaria de datos relacionados

Core clasifica Span como un tipo de vista y, por lo tanto, lo basa conceptualmente en la biblioteca estándar de C++. El tipo transmite una visión, no la propiedad de los elementos; Por lo tanto, los accesos de puntero, referencia e iterador descritos en el bloque API existente requieren una secuencia subyacente aún válida. SWS Core §7.4 «Core data types» SWS Core §7.4.2 «Data types derived from the C++ standard»

Interpretación: Span es adecuado para interfaces donde se va a transferir un área contigua pero no se copia ni se cambia su propiedad. Esta clasificación se deriva de la clasificación SWS como vista y del formulario API como vista de elementos.
