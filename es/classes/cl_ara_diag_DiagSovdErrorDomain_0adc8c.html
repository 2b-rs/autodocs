La clase final derivada de ara::core::ErrorDomain representa la región de error para los errores que se originan en SOVD. Proporciona un mensaje de texto para un código de error, el nombre corto Error-Domain y el alias Exception para DiagSovdException. [SWS_DM_01809] [SWS_DM_01814] [SWS_DM_01813] [SWS_DM_01811]
