clase ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

Interfaz de cursor común

FileAccessor agrupa operaciones de posición y tamaño en archivos abiertos. Es la base común de los descriptores de acceso de lectura, escritura y lectura/escritura; Esto significa que la posición del cursor describe el acceso exactamente a este archivo abierto.

Disciplina posicional

GetPosition, SetPosition y MovePosition se utilizan para la navegación, mientras que GetSize proporciona el tamaño del archivo actual. Las operaciones de acceso no son seguras para subprocesos: por lo tanto, varios subprocesos no deben utilizar un identificador al mismo tiempo sin sincronización externa. SWS Persistency §7.4 «File Storage specific Features»

Aviso de uso

Abra el archivo a través de FileStorage, realice las operaciones del cursor en posesión del mismo UniqueHandle y luego suéltelo. Un cambio de posición no es un proceso de persistencia; Escribir datos requiere la operación de escritura adecuada y, si es necesario, sincronización.

Un File Storage gestiona un conjunto de archivos con nombre; el Accessor posee en exclusiva el acceso concreto abierto. Fuentes: SWS Persistency §7.4 «File Storage specific Features» [SWS_PER_00113].
