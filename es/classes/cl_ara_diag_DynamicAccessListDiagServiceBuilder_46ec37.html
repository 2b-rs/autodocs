Propósito de uso

El Builder final crea un patrón para un DynamicAccessList. Se obtiene de DiagnosticServiceDynamicAccessList::MakeServiceBuilder y agrega bytes individuales, secuencias de bytes o áreas cerradas ByteRange. Los métodos Add devuelven la misma instancia de Builder, lo que permite una compilación encadenada con fluidez. Interacción con otras clases.

Any marca una cantidad de bytes como comodines que se ignorarán durante la coincidencia de patrones. EndsWith define un solo byte o área cerrada al final. Build finaliza la lista y se debe llamar antes de destruir el Builder. [SWS_DM_01178] [SWS_DM_01220] [SWS_DM_01179] [SWS_DM_01180] [SWS_DM_01221] [SWS_DM_01181] [SWS_DM_01222]
