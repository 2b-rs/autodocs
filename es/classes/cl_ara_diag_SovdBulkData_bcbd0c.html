Propósito de uso

SovdBulkData es la interfaz genérica para datos masivos SOVD. Lee metadatos, inicia sesiones de descarga o carga y elimina todos los datos de una categoría o de una instancia específica. [SWS_DM_01841] [SWS_DM_01853] [SWS_DM_01873] [SWS_DM_01854] [SWS_DM_01855] [SWS_DM_01856] Para los métodos SOVD correspondientes, el Diagnostic Server llama a estos métodos. [SWS_DM_01791] [SWS_DM_01792] [SWS_DM_01793] [SWS_DM_01794] [SWS_DM_01795]

Generación y ciclo de vida

El constructor requiere un PortPrototype, un DiagnosticSovdBulkDataInterface y un ConcurrencyType. [SWS_DM_01847] Offer() habilitado, StopOffer() deshabilitado reenvío de solicitudes; La oferta puede proporcionar kConfigurationMismatch o kAlreadyOffered. [SWS_DM_01857] [SWS_DM_01858] Se prohíbe la copia y la asignación de copias, mientras que se proporcionan la construcción de movimientos y la asignación de movimientos. [SWS_DM_01848] [SWS_DM_01850] [SWS_DM_01849] [SWS_DM_01851]

Interacción con otras clases.

Una descarga proporciona una sesión de lectura con BulkDataMetaDataDescriptor o HttpRedirect. [SWS_DM_01873] Una carga proporciona una sesión de escritura con un descriptor de metadatos; DeleteAllBulkData() devuelve DeleteByCategoryResult. [SWS_DM_01854] [SWS_DM_01855]

Limitaciones y Manejo de errores

Los métodos de procesamiento de datos proporcionan códigos de error SOVD aplicables en caso de falla y la seguridad de sus subprocesos depende de ConcurrencyType. [SWS_DM_01854] [SWS_DM_01855] [SWS_DM_01856] [SWS_DM_01873] CancellationHandler informa sobre una conversación cancelada. [SWS_DM_01853] Offer y StopOffer no son seguros para subprocesos. [SWS_DM_01857] [SWS_DM_01858]

GetBulkDataMetaData() devuelve un vector de todas las instancias de datos masivos de la categoría solicitada y no especifica errores estandarizados. [SWS_DM_01853] DeleteSpecificBulkData() procesa la categoría y el ID de datos masivos, mientras que DeleteAllBulkData() devuelve un resultado con éxitos y errores de eliminación. [SWS_DM_01855] [SWS_DM_01856] El constructor y la construcción Move son seguros para excepciones y subprocesos. [SWS_DM_01847] [SWS_DM_01849]
