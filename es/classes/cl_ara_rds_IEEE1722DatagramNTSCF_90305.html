Contexto

Dentro del módulo para flujos de datos sin procesar (Raw Data Stream, rds), la clase ara::rds::IEEE1722DatagramNTSCF representa una estructura de datos orientada a datagramas para el Non-Time-Synchronous Control Format (NTSCF) según el estándar de red IEEE 1722. En la Adaptive Platform, el módulo rds sirve para el transporte estructurado y la encapsulación de flujos de datos en los que se transmiten o procesan formatos cercanos al protocolo sin capas de protocolo adicionales.

En esta arquitectura, ara::rds::IEEE1722DatagramNTSCF encapsula los campos específicos del datagrama NTSCF. La clase define esta información fundamental como miembros de datos protegidos (protected). Entre ellos se encuentran el número de secuencia sequenceNum [SWS_RDS_90307] para monitorizar el orden de los datagramas, el identificador único unique_id [SWS_RDS_90309] para la asignación de flujos de control, así como datos de longitud y direccionamiento específicos del protocolo mediante ntscf_data_length [SWS_RDS_90308] y mac_address [SWS_RDS_90306]. Gracias a la visibilidad protegida, la clase actúa como una abstracción base polimórfica cuyos campos se ponen a disposición de derivaciones especializadas o etapas de procesamiento internas del módulo.
