Propósito de uso

ClientAuthentication permite que una aplicación informe el estado de autenticación y las funciones de usuario de un Diagnostic Client al Diagnostic Server. Se obtiene una instancia a través de ExternalAuthentication::Get() para el MetaInfo o la dirección del cliente pasados; GetAll() devuelve todas las instancias existentes. [SWS_DM_01132] [SWS_DM_01202] [SWS_DM_01203]

Interacción con otras clases.

Authenticate() establece el cliente en kAuthenticated, asume los roles pasados ​​y devuelve un ClientAuthenticationHandle. Este identificador puede luego establecer o ampliar listas de acceso dinámicas. La autenticación exitosa restablece los roles predeterminados previamente sobrescritos a los roles predeterminados configurados. [SWS_DM_01142] [SWS_DM_01206] [SWS_DM_01570]

GetState() lee el estado actual. En el estado kDeAuthenticated, OverrideDefaultRoles() puede sobrescribir los roles predeterminados durante un período específico y también proporciona un identificador. SetNotifier() registra una función para cambios de estado, como un tiempo de espera de S3; un registro posterior sobrescribe el existente. [SWS_DM_01143] [SWS_DM_01141] [SWS_DM_01209] [SWS_DM_01144] [SWS_DM_01360]
