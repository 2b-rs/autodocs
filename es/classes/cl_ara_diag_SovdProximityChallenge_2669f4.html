Propósito de uso

SovdProximityChallenge implementa la interfaz SOVD para desafíos de proximidad. GetChallenge() devuelve un desafío generado por la aplicación que incluye la fecha de validez; Si se requiere prueba de proximidad para un SOVD-Operation, el Diagnostic Server coloca este valor en la respuesta correspondiente. [SWS_DM_01481] [SWS_DM_01494] [SWS_DM_01398] ValidateResponse() comprueba la respuesta proporcionada por el cliente. [SWS_DM_01493] [SWS_DM_01395]

Generación y ciclo de vida

El constructor vincula un PortPrototype al DiagnosticSovdProximityChallengeInterface y acepta el requisito de concurrencia. [SWS_DM_01480] Offer() activa y StopOffer() desactiva el reenvío a través de DM. Un Offer puede generar kAlreadyOffered o kConfigurationMismatch. [SWS_DM_01478] [SWS_DM_01495] El destructor es exception-safe. [SWS_DM_01479]

Limitaciones y Manejo de errores

La respuesta de proximidad sólo es válida hasta el cumplimiento de la promesa o procesamiento de cancelación. [SWS_DM_01493] Para programar una operación SOVD, Diagnostic Server debe verificar un proximity_response existente con ValidateResponse(). [SWS_DM_01391] GetChallenge y ValidateResponse dependen de ConcurrencyType para la seguridad de los subprocesos; Offer y StopOffer no son seguros para subprocesos. [SWS_DM_01494] [SWS_DM_01493] [SWS_DM_01478] [SWS_DM_01495]

GetChallenge() y ValidateResponse() proporcionan sus resultados de forma asíncrona y no especifican errores estandarizados. [SWS_DM_01494] [SWS_DM_01493] DM considera válida una Proximity Challenge cuando la validación devuelve kProximityChallengeValidationSuccessful. [SWS_DM_01395] El constructor en sí es seguro para hilos, mientras que el destructor no lo es. [SWS_DM_01480] [SWS_DM_01479]

El desafío en sí y su validez se transmiten mediante GetChallenge() como valor de retorno. [SWS_DM_01494]

Contexto de acceso a SOVD

Un desafío de proximidad SOVD solicita prueba de proximidad antes de ejecutar una operación SOVD. La interfaz SovdProximityChallenge pasa el procedimiento de desafío a la aplicación e informa al Administrador de diagnóstico del resultado; sobre esta base realiza la operación.
