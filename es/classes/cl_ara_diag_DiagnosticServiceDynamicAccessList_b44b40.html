Propósito de uso

La clase final se utiliza para que la aplicación cree un DynamicAccessList. MakeServiceBuilder inicia un nuevo patrón con un ID de servicio o una secuencia de bytes y devuelve un DynamicAccessListDiagServiceBuilder para él. [SWS_DM_01156] [SWS_DM_01164] [SWS_DM_01165] [SWS_DM_01218]

Ciclo de vida y propiedad

La clase tiene constructores de copiar y mover, así como tareas de copiar y mover. El destructor es noexcept, pero no es seguro para hilos. [SWS_DM_01159] [SWS_DM_01160] [SWS_DM_01161] [SWS_DM_01162] [SWS_DM_01158]

Limitaciones y Manejo de errores

Reserve reserva memoria para el número estimado y el tamaño máximo de los patrones de cabecera de servicio; la reserva puede ser una estimación del peor caso y no necesita ser exacta. La creación del Builder y Reserve son seguros frente a excepciones, pero no para hilos. [SWS_DM_01163] [SWS_DM_01164] [SWS_DM_01165]
