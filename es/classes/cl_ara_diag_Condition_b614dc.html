Del estado técnico a la aprobación del diagnóstico

Condition es un punto de informe configurado que una aplicación utiliza para pasar su estado de condición actual al DM. El DM utiliza condiciones en particular como EnableConditions para el procesamiento de Monitor y como contexto para ClearConditions SWS Diagnostics §7.3.4.1.4 «EnableConditions» SWS Diagnostics §7.3.4.4.5 «Clearing DTCs». Por lo tanto, no se trata de una memoria Boolean general, sino que forma parte de una ruta de configuración relevante para el diagnóstico.

Conditions proporcionan un estado de habilitación consumido por DM para el procesamiento de Monitor y Clearing. Fuentes: SWS Diagnostics §7.3.4.1.4 «EnableConditions», SWS Diagnostics §7.3.4.2 «Condition Management», SWS Diagnostics §7.3.4.4.5 «Clearing DTCs». Conjunto sin efectos secundarios locales.

SetCondition informa el nuevo valor ConditionType [SWS_DM_00715]. Se debe llamar al método cuando el estado técnico realmente cambie, no como reemplazo del sondeo. La secuencia para un monitor o borrado de DTC determina la configuración del DM; la solicitud no debe inferir un cambio inmediato de estado del DTC.

Disponibilidad en Start

Los mensajes de estado se encuentran entre las llamadas API que el DM puede almacenar en buffer y procesar cuando estén disponibles. Esto permite que una aplicación informe su estado inicial de manera temprana; Aún debe mantener el estado consistente SWS Diagnostics §7.3.1 «Interaction between DM and applications».
