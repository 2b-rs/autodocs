Class to implement the subfunction TransmitCertificate (29 04) of UDS service Authentication as interface to application. This class implements a so called generic interface, where the application has means to handle one ore more certificateEvaluationId transferred certificates.

Propósito de uso

ara::diag::TransmitCertificate asigna la subfunción UDS TransmitCertificate (0x29/0x04) como la interfaz de la aplicación. La aplicación puede procesar uno o más certificados transferidos en función del certificateEvaluationId [SWS_DM_01961].

Generación y amp; destrucción

La instancia se crea con InstanceSpecifier, DiagnosticTransmitCertificateInterface y ConcurrencyType [SWS_DM_01962]. El tipo no se puede copiar ni mover; el destructor virtual es noexcept [SWS_DM_01964] [SWS_DM_01963] [SWS_DM_01966] [SWS_DM_01965] [SWS_DM_01967].

Interacción con otras clases.

Offer() habilita a DM para reenviar solicitudes, StopOffer() lo deshabilita [SWS_DM_01969] [SWS_DM_01970]. El método a derivar Process() recibe el CEID de 16 bits, los datos del certificado, MetaInfo y un CancellationHandler. La semántica del procesamiento de certificados recae en la aplicación [SWS_DM_01968] [SWS_DM_01248].

virtual ara::core::Future< void > Process (std::uint16_t certificate EvaluationId, ara::core::Span< ara::core::Byte const > certificate Data, const MetaInfo &metaInfo, CancellationHandler cancellation Handler) noexcept=0;

This method is used to process certificates send by a diagnostic tester, via the UDS subfunction TransmitCertificate inside the application. There is no specific semantics for the certificate and it is left to the application to process the received certificate and derive the needed actions.
