Propósito de uso

La clase final es el rango de error derivado de ara::core::ErrorDomain para errores de múltiples clases de diagnóstico. Traduce valores de códigos de error en mensajes de texto que nunca son cero y devuelve el nombre corto del ApApplicationErrorDomain asociado. [SWS_DM_00529] [SWS_DM_00534] [SWS_DM_00533]

Interacción con otras clases.

Si una interfaz ara::diag devuelve un error de este dominio, el Diagnostic Server genera una respuesta negativa con su código de error. En caso de errores al leer un DataElement, se considera que una condición no se ha cumplido; en los DataIdentifiers periódicos se omite la respuesta programada.
