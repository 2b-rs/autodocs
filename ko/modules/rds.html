모듈 ara::rds — Raw Data Streams

이 페이지는 SWS Raw Data Stream(R25-11)를 기반으로 완전히 AI로 생성되었다. 공식 AUTOSAR 텍스트도 없고 나머지 모듈처럼 자동으로 추출된 API 페이지도 없다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

사용자 가이드 AI 생성 / AI generated

자동으로 생성된 설명, 참조된 AUTOSAR R25-11 문서(SWS 사양 및 관련 표준 문서)에서 파생된 콘텐츠 — 공식 AUTOSAR 텍스트가 아닙니다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

개요 및 목적

원시 데이터 스트림은 IP 기반 프로토콜을 통해 클라이언트와 서버 간의 연결로 바이너리 데이터를 전송한다. RawDataStreamClient 및 RawDataStreamServer는 모델링된 포트 인터페이스 [SWS_RDS_10481] [SWS_RDS_11311]용으로 생성되었다.

IP 기반 프로세스

Client는 Connect으로 연결하고 Server 측은 WaitForConnection을 통해 대기한다. 이후 양측은 데이터를 읽거나 쓰고 Shutdown로 연결을 종료한다 [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].

연결 및 전송 순서. 출처 : SWS Raw Data Stream §7.1.4, Chapter 8. 시간적 요약은 해석입니다.

IEEE 1722

데이터 링크 계층에서의 데이터 전송을 위해 API는 형식화된 IEEE 1722 데이터그램과 생산자 및 소비자 클래스 [SWS_RDS_90225] [SWS_RDS_90311] [SWS_RDS_90322]를 설명합니다.

연결 상태

스트림 연결 상태 다이어그램. 출처: SWS Raw Data Stream §7.1.4. 해석: 상태는 생성, 연결 및 종료 작업을 압축합니다.

시스템 컨텍스트

인터페이스는 서비스 지향 통신(EXP ARACom API) 외에도 효율적인 데이터 흐름을 위한 것입니다. 이 사양에서는 7장의 구성, 액세스 제어 및 보안 채널에 대해 설명합니다.

해석: 이 페이지는 분리된 IP 및 IEEE-1722 API를 공통 사용 관점으로 분류한다.
