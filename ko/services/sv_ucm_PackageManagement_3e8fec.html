서비스 인터페이스 PackageManagement

ara::com 서비스로 모델링된 인터페이스. 메서드/필드는 생성된 프록시/Skeleton(IN/OUT 매개변수 방향)를 통해 호출된다.

사용자 가이드 AI 생성 / AI generated

자동으로 생성된 설명, 참조된 AUTOSAR R25-11 문서(SWS 사양 및 관련 표준 문서)에서 파생된 콘텐츠 — 공식 AUTOSAR 텍스트가 아닙니다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

하나의 서비스, 세 가지 의미 계층

PackageManagement는 실행 중인 소프트웨어 클러스터 세트의 패킷 승인, 패킷 처리 및 수정을 분리한다. CurrentStatus은 현재 실행 중인 UCM 단계의 전역 보기이다. 전송 ID는 개별 전송을 명확하게 할당한다. SWS UCM 7장 “Functional specification” [SWS_UCM_00361]

강력한 블록 전송

TransferStart는 리소스를 예약하고 전송 ID와 최대 블록 크기를 제공한다. TransferData는 ID, 순서, 크기를 확인하고 필요한 경우 블록 일관성을 확인한다. TransferExit는 데이터 블록 이후에만 허용되며 완전성과 패킷 형식을 확인한다. 따라서 전송 오류는 전송별로 처리되어야 하며 활성화 오류로 해석되어서는 안 된다. [SWS_UCM_00272] [SWS_UCM_00275] [SWS_UCM_00276]

블록 전송에서 활성화까지의 활동 다이어그램. 출처: SWS UCM §7.3 “Transfer and processing”, SWS UCM §7.5 “Activation and rollback”. 부분 해석: 개별 전송 및 처리가 시간에 따라 분리될 수 있지만 표현은 클라이언트 순서를 강조합니다.

처리, 활성화 및 철회

ProcessSwPackage 이후, Activate는 처리된 패키지의 준비 단계에서만 시작할 수 있다. 활성화는 SM에 업데이트 세션을 요청한다. 검증에 따라 완료 또는 복원이 결정된다. Rollback에는 명시적인 잘못된 종료가 있으며 kRollingBackFailed에서 다시 시도할 수 있다. [SWS_UCM_00241] [SWS_UCM_00257] [SWS_UCM_00300] [SWS_UCM_00301]

상태 및 쿼리 작업

GetProgress, GetSwPackages, Cluster 조회 및 GetHistory는 관찰과 감사 가능성을 위한 것이며, 상태에 종속된 작업 전에 수행하는 상태 검사를 대체하지 않는다. Suspend/Resume는 장기 실행 작업에 관한 것이므로 CurrentStatus와 연관하여 해석해야 한다. SWS UCM §7.6 “Progress and interruption”

클라이언트 체크리스트

  1. TransferStart에서 제공하는 최대 블록 크기를 사용하고 ID을 변경하지 않고 전송합니다.
  2. TransferExit 이전의 모든 블록을 전송하고 각 오류에 대한 전송 ID별 원인을 평가한다.
  3. 처리 후 CurrentStatus를 관찰하고 허용된 단계에서만 Activate를 호출한다.
  4. 검증 결과가 부정적이면 재활성화 대신 문서화된 Rollback 경로를 선택하십시오.

멤버

  • Activate This method activates the Software Clusters extracted from the processed Software Packages.
  • Cancel This method aborts an ongoing processing of a Software Package.
  • CurrentStatus The current status of UCM.
  • DeleteTransfer Delete a transferred Software Package.
  • Finish This method finishes the processing for the current set of processed Software Packages
  • GetHistory Getter method to retrieve all actions that have been performed by UCM.
  • GetId Get the UCM Instance Identifier.
  • GetProgress Get the progress information of the currently active state in the Package Management state machine.
  • GetSwClusterChangeInfo This method returns a list pending changes to the set of SoftwareClusters on the adaptive platform
  • GetSwClusterInfo This method returns a list with information of all SoftwareClusters that are in state kPresent.
  • GetSwClusterManifestInfo This method returns the general information of a Software Cluster that are in state kPresent.
  • GetSwPackages This method returns the Software Packages that available in UCM.
  • ProcessSwPackage Process a previously transferred Software Package or a partly transferred Software Package from a stream.
  • RegisterSoftwarePackage registers a package that could already be in Machine’s file system or to be downloaded.
  • Resume This method resumes ongoing time consuming actions or actions related to specific states.
  • RevertProcessedSwPackages Revert the changes done by processing (ProcessSwPackage) of one or several software packages.
  • Rollback Rollback the system to the state before the packages were processed.
  • Suspend This method suspends ongoing time consuming actions or actions related to specific states.
  • TransferData Block-wise transfer of a Software Package to UCM.
  • TransferExit Finish the transfer of a Software Package to UCM.
  • TransferStart Start the transfer of a Software Package after having received a Vehicle Package
