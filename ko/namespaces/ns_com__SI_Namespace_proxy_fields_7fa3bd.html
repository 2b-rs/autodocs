네임스페이스 <SI-Namespace>::proxy::fields

클래스와 구조체

  • <Field> Service proxy Field class, one for each Field defined in the ServiceInterface in the role field.

네임스페이스의 UML 클래스 다이어그램

둥근 프레임 = 네임스페이스 또는 클래스 범위; 속이 빈 삼각형 화살표 = 상속(기본 클래스를 가리킴); 회색 상자 = 네임스페이스가 아니거나 외부 기본 클래스. 클릭하면 해당 클래스 또는 cpp참조 페이지가 열립니다.

공식 AUTOSAR R25-11 사양 PDF에서 자동 추출 (autosar.org). AUTOSAR 공식 간행물이 아니며, 설명 텍스트는 원문(영어) 그대로입니다.
