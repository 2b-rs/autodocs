건축적 임베딩

ara::diag은 daemon 기반 Functional Cluster Diagnostic Management에 속한다. 이는 Adaptive 프로세스의 진단 Event를 처리하고, 보관 정책에 따라 Event 및 관련 데이터를 영구 저장하며, 표준화된 네트워크 프로토콜을 통해 외부 진단 Client에 접근을 제공한다. EXP SWArchitecture §9.8.1.1.1

UDS 및 SOVD

SOVD를 사용하면 Diagnostic Manager는 기본적으로 SOVD를 서버로 지원하고 독립 소프트웨어 클러스터에 대해 여러 진단 서버 인스턴스를 실행할 수 있습니다. EXP SOVD §2.2 “Diagnostic Manager” 공유 SOVD/UDS 사용 사례는 가능하면 동일한 포트 인스턴스를 사용합니다. SOVD 작업, 데이터 및 오류는 해당 DEXT 개념에서 파생됩니다. EXP SOVD §3.1 “Common use cases in SOVD and UDS”

협업 다이어그램: 단순화된 SOVD 컨텍스트. 출처: EXP SOVD §2.1 “SOVD Gateway”; EXP SOVD §2.2 “Diagnostic Manager”; EXP SOVD §3.1 “Common use cases in SOVD and UDS”. 해석: 표현은 참조 아키텍처와 문서화된 API 인터페이스를 결합하며 전체 네트워크 또는 Deployment 보기를 대체하지 않습니다.
