네임스페이스 apext::log

사용자 가이드 AI 생성 / AI generated

자동으로 생성된 설명, 참조된 AUTOSAR R25-11 문서(SWS 사양 및 관련 표준 문서)에서 파생된 콘텐츠 — 공식 AUTOSAR 텍스트가 아닙니다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

모델링된 추적을 위한 확장점

apext::log::TraceArti는 모델링된 추적 메시지의 확장점이다. 컴파일 타임에 메시지, 네임스페이스 및 실행 파일에 대한 라우팅 결정을 내릴 수 있으므로 런타임 오버헤드가 방지된다. SWS Log and Trace §7.6 “Tracing” [SWS_LOG_20001] [SWS_LOG_20004]

추적과 로그 분리

구성에 따라 생성된 특수화는 로거에만 연결되거나 ARTI에만 연결되거나 메시지를 삭제한다. (해석: 따라서 네임스페이스는 생성된 추적 도구 코드와 표준 로그 API 사이의 의도적인 좁은 다리이다.)

자유 함수 문서

함수 TraceArti [SWS_LOG_20000] Upstream: RS_LT_00003

template <typename MsgId, typename... Params> void TraceArti (const MsgId &msg_id, const Params &...                       params) noexcept;

Handles a modeled message, specific to the used trace tool. This function is only called internally by the Logger framework when switching between Log and TraceArti. It represents the interface to trace tools. The runtime overhead of this function shall be kept as minimal as possible, e.g. by using specializations based on the MsgId.

사용법 AI 생성 / AI generated

공식 AUTOSAR 텍스트가 아닌 참조된 AUTOSAR R25-11 문서에서 파생된 자동 생성된 사용 알림이다.

TraceArti의 의미

TraceArti는 로깅 인터페이스의 API 세부정보이다. 이는 Logger, LogStream 및 구성된 보고 필터와 관련하여 사용된다.

메시지 경로의 분류

로깅 API는 던지지 않도록 설계되었습니다. 프레임워크의 오류가 신청 프로세스에 부담을 주어서는 안 됩니다. 실제 출력은 구성된 싱크에 따라 다릅니다. SWS Log and Trace §7.1 “Necessary Parameters and Initialization” SWS Log and Trace §7.7 “Output Bindings”
