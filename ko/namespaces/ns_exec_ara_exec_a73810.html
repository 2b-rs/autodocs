프로세스 수명 주기를 제어하고, 실행 상태를 모니터링하며, 함수 그룹의 상태 전환을 조정합니다.

이 네임스페이스는 AUTOSAR Adaptive Platform에서 프로세스 관리 및 함수 그룹 제어를 위한 인터페이스를 제공합니다. 프로세스는 클라이언트를 사용하여 성공적으로 초기화된 후 자신의 실행 상태 kRunning을 Execution Management에 보고합니다 [SWS_EM_02000]. State Management는 인터페이스를 통해 함수 그룹의 전환을 요청하는 반면, 허용되지 않는 상태 변경 또는 통신 오류는 표준화된 오류 코드를 통해 기록됩니다 [SWS_EM_02281]. 전환 순서의 엄격한 준수가 반드시 요구됩니다.

컨텍스트

네임스페이스 ara::exec은 AUTOSAR Adaptive Platform에서 Execution Management의 인터페이스를 제공합니다. 이 모듈은 프로세스의 시작, 제어 및 모니터링뿐만 아니라 상위 시스템 및 함수 그룹 상태의 조정을 담당합니다. 주요 주체로는 애플리케이션 프로세스, State Management, 그리고 Execution Management 자체가 있습니다. 프로세스는 클래스 ExecutionClient을 사용하여 자신의 내부 런타임 상태를 Execution Management에 보고합니다. State Management는 인터페이스 StateClient를 사용하여 함수 그룹(FunctionGroup 및 FunctionGroupState) 간의 상태 변경을 요청합니다. 함수 그룹 수준의 오류 이벤트에는 ExecutionErrorEvent을 통해 전달될 수 있는 타입 앨리어스 ExecutionError가 사용됩니다 [SWS_EM_02541].

수명 주기

프로세스의 실행 수명 주기는 Execution Management에 의해 제어됩니다 [SWS_EM_02000]. 스케줄링 후 새로 시작된 프로세스는 초기에 애플리케이션 프로그램 코드가 아직 실행되지 않은 암시적 상태 Initializing에 있습니다. Execution Management는 프로세스가 자신의 ExecutionClient을(를) 통해 상태 ExecutionState::kRunning을(를) 능동적으로 보고할 때까지 이 초기화 상태가 지속된다고 가정합니다 [SWS_EM_02000]. 열거형 ExecutionState은(는) 프로세스에서 Execution Management로 보고될 수 있는 상태로만 엄격하게 제한되므로 오직 상태 kRunning만을 포함합니다 [SWS_EM_02000]. Execution Management가 종료를 요청하면 프로세스는 Terminating 단계로 전환되며, 이는 프로세스의 최종 종료와 함께 완료됩니다 [SWS_EM_02000].

상태 다이어그램: 암시적 상태 및 kRunning 보고를 포함하는 Execution Management 관점에서의 프로세스 수명 주기. 출처: [SWS_EM_02000]

사용 경로

일반적인 사용 흐름은 다음과 같은 단계로 나뉩니다:

  • 시스템 시작 후 프로세스는 Execution Management에 의해 생성되고 내부 초기화를 수행합니다 [SWS_EM_02000].
  • 초기화가 성공적으로 완료되는 즉시, 프로세스는 ExecutionClient의 인스턴스를 통해 상태 ExecutionState::kRunning을(를) Execution Management에 보고합니다 [SWS_EM_02000].
  • Execution Management는 이 전환을 승인합니다. 그러나 프로세스가 이미 실행 중인 상태일 때 kRunning이(가) 보고되면, 이는 허용되지 않는 전환 ExecErrc::kInvalidTransition(으)로 거부됩니다 [SWS_EM_02281].
  • 추가 작동 중에 State Management는 필요에 따라 StateClient을(를) 통해 함수 그룹에 대해 조정된 상태 전환을 요청합니다.

시퀀스 다이어그램: ExecutionClient를 통한 상태 보고 및 잘못된 전환 처리 시의 호출 순서. 출처: [SWS_EM_02000], [SWS_EM_02281]

오류 시나리오

오류 상황은 네임스페이스 ara::exec에서 열거형 타입 ExecErrc 및 오류 도메인 ExecErrorDomain을(를) 통해 매핑됩니다 [SWS_EM_02281]. 글로벌 도메인 객체에 대한 참조는 스레드 및 예외 안전성을 갖춘 함수 GetExecErrorDomain()에서 제공합니다 [SWS_EM_02290]. ara::core::ErrorCode 타입의 구체적인 오류 객체는 오류 코드 및 제조사별 컨텍스트 데이터를 전달하여 헬퍼 함수 MakeErrorCode()을(를) 통해 생성됩니다 [SWS_EM_02291]. 또한 예외 처리를 위해 클래스 ExecException도 제공됩니다.

지정된 오류 원인에는 다음이 포함됩니다 [SWS_EM_02281]:

  • ExecErrc::kNoCommunication: 클라이언트와 Execution Management 간 또는 State Management와 Execution Management 간의 통신 오류를 알립니다. 시스템 수준에서 이러한 상태는 복구 불가능한 상태로의 진입을 요구할 것으로 보입니다 [SWS_EM_02281].
  • ExecErrc::kInvalidTransition: 잘못된 전환입니다. 예를 들어 프로세스가 kRunning을(를) 반복적으로 보고하는 경우입니다 [SWS_EM_02281].
  • ExecErrc::kOperationFailed: 연산이 실패했습니다. 예를 들어 kRunning이(가) 제때 보고되지 않아 함수 그룹 전환을 완료할 수 없는 경우입니다 [SWS_EM_02281].
  • ExecErrc::kOperationCanceled: 더 새로운 요청으로 인해 함수 그룹의 상태 변경이 중단되었습니다 [SWS_EM_02281].
  • ExecErrc::kIntegrityOrAuthenticityCheckFailed: 시작할 프로세스의 무결성 또는 진위성 검사에 실패했습니다 [SWS_EM_02281].
  • ExecErrc::kUnexpectedTermination: 전환 중 비정상적인 중단이 발생했습니다 [SWS_EM_02281].
  • ExecErrc::kInvalidMetaModelIdentifier 및 ExecErrc::kInvalidArgument: 허용되지 않는 메타모델 식별자 또는 유효하지 않은 매개변수 값입니다 [SWS_EM_02281].

이 가이드는 Execution Management(ara::exec) 모듈에 대한 AUTOSAR Adaptive R25-11 사양을 기반으로 합니다.

ExecutionState 열거형

Defines the internal states of a Process. Scoped enumeration of uint32_t. Please note that ara::exec::ExecutionState includes only states reportable by the Process to Execution Management and therefore does not include enumerations e.g. the "Initializing" state mentioned in Figure 7.2 and Figure 7.12, which are an implied states for Execution Management. The Initializing state starts when Process is first scheduled (so no code executed yet) and ends when kRunning is reported ([SWS_EM_01004]). The Terminating state starts when termination is requested by Execution Management and ends when the Process terminates ([SWS_EM_01404]). For the reasons mentioned, Execution Management assumes that Process is in initializing state until kRunning will be reported by it.

열거형 ExecErrc [SWS_EM_02281]은(는) 기본 타입 ara::core::ErrorDomain::CodeType을(를) 기반으로 네임스페이스 ara::exec에서 Execution Management를 위한 오류 코드를 정의합니다. ara::core::ErrorCode에서 캡슐화를 위해 MakeErrorCode [SWS_EM_02291]과(와) 함께 사용되며, ara::core::Result을(를) 통해 동기식으로 또는 ara::core::Future을(를) 통해 비동기식으로 호출자에게 전달됩니다.

열거자는 다양한 오류 상태를 다룹니다 [SWS_EM_02281]:

  • kNoCommunication은(는) 요청 전송 또는 결과 검색 시 통신 오류를 나타냅니다 [SWS_EM_02281]. Execution Management와 State Management 사이에서 이러한 오류가 발생하면 시스템이 복구 불가능한 상태(Unrecoverable State)로 전환될 수 있습니다 [SWS_EM_02281]. ExecutionClient 또는 StateClient과(와) 같은 클라이언트는 다음 메서드 호출 시에야 이를 감지하며, 클라이언트 측 복구 옵션은 제한적입니다 [SWS_EM_02281].
  • kOperationCanceled 및 kOperationFailed은(는) SetState [SWS_EM_02278] 또는 머신 시작 전환이 중단될 때와 같이 함수 그룹의 상태 변경 시 발생합니다 [SWS_EM_02281] [SWS_EM_02279].
  • kInvalidTransition은(는) 유효하지 않은 프로세스 전환을 신호로 알리며, 예를 들어 프로세스가 kRunning을(를) 반복해서 보고하는 경우로서 ReportExecutionState [SWS_EM_02003] 시 관련이 있습니다 [SWS_EM_02281].
  • kIntegrityOrAuthenticityCheckFailed, kUnexpectedTermination, kInvalidMetaModelIdentifier 및 kInvalidArgument은(는) 무결성 검사 오류, 함수 그룹 상태 변경 시 비정상적인 프로세스 중단 또는 유효하지 않은 함수 매개변수를 처리합니다 [SWS_EM_02281].

호출자는 이러한 오류 코드를 평가하여 상태 전환이 성공적으로 완료되었는지, 후속 요청에 의해 선점되었는지, 구성 오류로 인해 차단되었는지를 확인합니다 [SWS_EM_02281].

      enum class ExecutionState :              std::uint32_t {...};
      

      Defines the internal states of a Process. Scoped enumeration of uint32_t. Please note that ara::exec::ExecutionState includes only states reportable by the Process to Execution Management and therefore does not include enumerations e.g. the "Initializing" state mentioned in Figure 7.2 and Figure 7.12, which are an implied states for Execution Management. The Initializing state starts when Process is first scheduled (so no code executed yet) and ends when kRunning is reported ([SWS_EM_01004]). The Terminating state starts when termination is requested by Execution Management and ends when the Process terminates ([SWS_EM_01404]). For the reasons mentioned, Execution Management assumes that Process is in initializing state until kRunning will be reported by it.
