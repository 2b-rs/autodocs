Platform Health Management를 통한 기능 모니터링을 위한 타입 안전한 체크포인트 열거형을 정의합니다.

이 네임스페이스는 Platform Health Management에서 모니터링 대상 엔티티의 체크포인트를 위한 강력한 타입의 열거형을 제공합니다 [SWS_PHM_00424]. 각 모니터링 대상 엔티티는 기본 타입 std::uint32_t을(를) 갖는 자체 범위 지정 열거형(scoped enumeration)을 가지며, 선언된 열거자는 제어 지점으로서 인터페이스 ara::phm::PhmSupervisedEntityInterface에 보고됩니다 [SWS_PHM_00424], [SWS_PHM_00425]. 타입 안전한 네임스페이스에서의 정적 제공을 통해 컴파일 타임에 서로 다른 엔티티의 제어 지점이 혼동되는 것을 확실하게 방지합니다.

컨텍스트

C++ 네임스페이스 namespace ara::phm::supervised_entities::{ <hierarchical-namespace-list-lower-skeleton>}은(는) AUTOSAR Adaptive Platform의 Platform Health Management(PHM) 내에서 모니터링 대상 기능 단위(Supervised Entities)의 타입 안전한 제어 지점(Checkpoints)을 위한 전용 영역으로 사용됩니다. [SWS_PHM_00424]에 따라 이 네임스페이스에는 인터페이스 ara::phm::PhmSupervisedEntityInterface을(를) 위한 불연속 체크포인트를 정의하는 enum class {<phmssi-sn>} : std::uint32_t 형식의 범위 지정 열거형(scoped enumeration)이 포함됩니다. 체크포인트 목록의 구성된 각 요소에 대해 고유한 C++ 열거자 선언이 존재합니다 [SWS_PHM_00425]. 이 상호작용은 세 가지 핵심 기능 컴포넌트를 연결합니다: 모니터링 대상 애플리케이션 소프트웨어(Supervised Entity), 네임스페이스에 의해 모델링된 타입화된 체크포인트, 그리고 모니터링 이벤트가 PHM 서비스로 전달되는 플랫폼 인터페이스 ara::phm::PhmSupervisedEntityInterface입니다.

컨텍스트 다이어그램: 모니터링 대상 애플리케이션 소프트웨어, 타입화된 체크포인트 열거형 및 플랫폼 인터페이스 간의 상호작용. 출처: [SWS_PHM_00424], [SWS_PHM_00425]

수명 주기

네임스페이스 내의 타입과 상수는 정적 컴파일 타임 특성을 가집니다. 이는 힙에서의 할당이나 해제를 통한 동적 런타임 수명 주기의 영향을 받지 않으며, 기본 타입 std::uint32_t을(를) 갖는 타입화된 C++11 범위 지정 열거형으로 제공됩니다 [SWS_PHM_00424]. 해석: 경로와 식별자가 인터페이스의 모델 파라미터에 의존하므로, 정의는 일반적으로 빌드 프로세스 동안 AUTOSAR 서비스 기술로부터 자동 생성됩니다. 인클루드를 위해 표준은 모니터링 대상 단위마다 #include "ara/phm/supervised_entities/{ <si-namespace-derived-directory-path-lower>}/{<phmssi-sn>}.h" 아래에 별도의 헤더 파일을 제공하는 반면, 일반 타입 선언은 포워딩 헤더 #include "ara/phm/phm_fwd.h"을(를) 통해 전방 선언될 수 있습니다 [SWS_PHM_00424]. 따라서 열거자 상수는 프로세스 수명 전반에 걸쳐 불변 상태로 애플리케이션에 제공됩니다 [SWS_PHM_00425].

사용 경로

Supervised Entity로 작동하는 소프트웨어 컴포넌트의 일반적인 사용 경로는 세 가지 순차적 단계로 구성됩니다:

  • 헤더 포함: 애플리케이션은 파일 경로 ara/phm/supervised_entities/{ <si-namespace-derived-directory-path-lower>}/{<phmssi-sn>}.h 또는 중앙 포워딩 ara/phm/phm_fwd.h을(를) 통해 모니터링 대상 단위의 생성된 헤더를 포함합니다 [SWS_PHM_00424].
  • 인터페이스 초기화: 애플리케이션은 열거형의 체크포인트가 선언된 인터페이스 ara::phm::PhmSupervisedEntityInterface을(를) 인스턴스화하거나 바인딩합니다 [SWS_PHM_00424].
  • 체크포인트 신호 전달: 알고리즘의 관련 제어 지점을 통과할 때 애플리케이션은 네임스페이스에서 해당 열거자 {<symbol-phm-checkpoint>}을(를) 선택하고 [SWS_PHM_00425] 이를 ara::phm::PhmSupervisedEntityInterface의 인스턴스에 보고합니다 [SWS_PHM_00424].

기본 타입 std::uint32_t에 대한 바인딩 [SWS_PHM_00424]과 각 제어 지점의 명시적 값 할당 [SWS_PHM_00425]을(를) 통해 런타임에 각 프로그램 단계의 타입 안전하고 혼동 없는 식별이 보장됩니다.

오류 시나리오

이 네임스페이스의 잘못된 사용은 주로 모델 관련 및 타입 관련 구성 오류에서 비롯됩니다. 이는 enum class이므로 [SWS_PHM_00424] C++ 타입 시스템이 암시적 타입 변환을 방지하며, 따라서 잘못된 데이터 타입이나 다른 Supervised Entity의 열거자 사용은 이미 컴파일 타임에 차단됩니다. 모델 설명의 구성이 열거자 목록과 정확히 일치하지 않는 경우 런타임 오류가 발생할 수 있습니다. [SWS_PHM_00425]에 따라 각 체크포인트에 대해 해당 열거자가 선언되어 있어야 합니다. 해석: 애플리케이션이 허용되지 않는 타입 변환이나 오래된 헤더 파일로 인해 모델에 구성되지 않은 std::uint32_t 값을 ara::phm::PhmSupervisedEntityInterface에 전달할 경우, PHM 서비스가 이 체크포인트를 매핑하지 못하고 이를 모니터링 위반으로 간주할 것으로 보입니다.

이 가이드는 오직 AUTOSAR Adaptive Platform R25-11 사양만을 기반으로 한다.
