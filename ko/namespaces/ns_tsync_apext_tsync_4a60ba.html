시간 기반 블록 네임스페이스 apext::tsync

apext::tsync는 글로벌 및 로컬 시간 기반 인터페이스에 속한다. 각 타임베이스는 시간 값과 상태 스냅샷을 제공한다. 동기화 메커니즘은 마스터/슬레이브 컨텍스트에서 작동한다. SWS Time Synchronization §7.1 “General Overview” SWS Time Synchronization §7.2 “Normal Operation”

진행 중인 분류

API 값은 동기화 상태, 도약 정보 및 필요한 경우 사용자 데이터와 함께 평가되어야 한다. 특정 유선 프로토콜은 이 SWS 외부에 있으며 PRS 컨텍스트로 참조된다. SWS Time Synchronization §7.1 “General Overview”

실질적인 한계

구성 및 통합 환경에 따라 실제로 사용 가능한 값과 바인딩이 결정됩니다. 아래에 참조된 API 요구 사항은 유형의 계약상 경계를 지정합니다.
