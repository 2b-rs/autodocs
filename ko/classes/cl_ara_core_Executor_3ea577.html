클래스 ara::core::Executor

[SWS_CORE_00008] Upstream: RS_AP_00130

class Executor {...};

Provides an interface for a executing context, which asynchronously invokes Callable ([4] [func.wrap.func]) objects in a guaranteed thread-safe context. The execute(...) method in [SWS_CORE_00024] returns a ara::core::Future object to the caller for further result/error extraction or management of the asynchronous-context; the execute_oneway(...) method in [SWS_CORE_00025] imply fire-and-forget semantics and thus no asynchronous-context (ara::core::Future) is returned.

참고문헌 SWS 코어: [4] ISO/IEC 14882:2014, Information technology – Programming languages – C++ – www.iso.org

사용 목적

ara::core::Executor는 보장된 스레드로부터 안전한 컨텍스트에서 Callable 개체를 비동기적으로 호출하는 실행 컨텍스트를 제공한다. [SWS_CORE_00008]

다른 클래스와의 상호작용

execute()는 인수를 사용하여 함수를 비동기식으로 호출하고 결과나 오류가 포함된 Future를 반환한다. oneway_execute()도 함수를 비동기식으로 시작하지만 실행 후 잊어버리는 의미를 따르며 Future를 반환하지 않다. [SWS_CORE_00024] [SWS_CORE_00025]

수명주기 & 소유권

복사 및 이동 구성과 복사 및 이동 할당이 가능한다. 이동 작업과 소멸자는 noexcept이다. [SWS_CORE_00009] [SWS_CORE_00015] [SWS_CORE_00017] [SWS_CORE_00018] [SWS_CORE_00019]

미완료 Callables의 소멸

사양은 Executor가 소멸될 때 여전히 실행 중이거나 대기 중인 콜러블에 어떤 일이 발생하는지 지정하지 않는다. [SWS_CORE_00019]는 동작(결합, 분리 또는 중단 없음)에 대한 약속 없이 소멸자를 설명하며 기능 장 SWS Core §7.4.1.2 “ara::core::Executor”에서는 실행 컨텍스트의 수명에 대한 설명도 제공하지 않는다. 사양 자체에서는 동작에 대한 유일한 비공식 설명을 알려진 제한 사항 SWS Core §4.1 “Known limitations”로 지정한다. 따라서 동작은 구현에 따라 다릅니다. 또한 execute()에서 얻은 Future가 실행 프로그램이 삭제된 후에 준비될 것인지 여부도 불분명한다.

Interpretation: Executor는 [SWS_CORE_00009]를 복사할 수 있으므로 공유 실행 컨텍스트의 핸들 의미는 분명한다. 이는 보장되지 않는다. 이식 가능한 코드는 적어도 모든 호출 가능 항목이 시작되는 동안 실행기를 활성 상태로 유지한다. execute()를 사용하면 Future/wait()를 사용하여 파괴하기 전에 전달된 GetResult()를 완료하거나 is_ready()를 확인한다. oneway_execute() 및 Future::then(func, executor)-Continuations의 경우 실행기를 애플리케이션 수명에 연결한다.

해석: 파기 전에 뛰어난 Future 결과를 완료하고 실행 프로그램이 호출 가능 항목 전에 죽도록 두지 않는다.
