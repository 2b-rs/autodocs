클래스 ara::diag::ExternalAuthentication

[SWS_DM_01191] Upstream: RS_Diag_04251

Definition of the ExternalAuthentication class, which is used by the application to receive an instance of the ClientAuthentication Class relevant to the specific client.

사용 목적

마지막 클래스는 진단 클라이언트와 관련된 ClientAuthentication 인스턴스를 애플리케이션에 제공한다. DiagnosticExternalAuthenticationInterface에 대한 PortPrototype의 InstanceSpecifier을 사용하여 생성된다. [SWS_DM_01191] [SWS_DM_01193]

다른 클래스와의 상호작용

Get는 클라이언트 주소 또는 MetaInfo와 관련된 ClientAuthentication을 확인한다. 진단 관리자는 전달된 주소 또는 MetaInfo의 인증 상태를 관리하는 인스턴스를 반환한다. GetAll는 현재 관리자가 관리하는 모든 ClientAuthentication 인스턴스 또는 빈 목록을 반환한다. [SWS_DM_01194] [SWS_DM_01199] [SWS_DM_01200] [SWS_DM_01201] [SWS_DM_01202] [SWS_DM_01203]

복사를 금지합니다(=delete). 이동 구성 및 이동 할당이 기본값으로 설정됩니다. [SWS_DM_01196] [SWS_DM_01197] [SWS_DM_01194] [SWS_DM_01195]
