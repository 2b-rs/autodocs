모델에서의 역할

Buffer는 Host와 가속기에 필요한 메모리 리소스를 보유한다. 직접 데이터 전송은 Buffer 메서드가 아니라 Accessor 객체를 통해 표현된다.

소스 참조

메모리 설명을 위해 Buffer는 SWS SHWA §7.5 — Memory Allocation Specifics과 함께 작동한다. 접근은 SWS SHWA §7.3 — Data Access Specifics에 따라 Accessor를 통해 표현된다.
