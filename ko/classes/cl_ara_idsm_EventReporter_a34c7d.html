클래스 ara::idsm::EventReporter

이 페이지는 SWS IntrusionDetectionSystemManager(R25-11)를 기반으로 완전히 AI로 생성되었다. 공식 AUTOSAR 텍스트도 없고 나머지 모듈처럼 자동으로 추출된 API 페이지도 없다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

분류

EventReporter는 모델링된 Security Events를 보고하기 위한 애플리케이션 접근점이다. SWS IdsM §7.1; [SWS_AIDSM_00103].

해석: 이 클래스는 지정된 포트 및 수명 주기 경계를 따라 사용해야 하며, API 자체는 완전한 애플리케이션 아키텍처를 정의하지 않는다.
