클래스 apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

사용 목적

UdsMessage는 일반 DM 코어 또는 UdsTransportProtocolMgr와 UdsTransportProtocolHandler의 구체적인 구현 간의 UDS 메시지를 나타냅니다. 객체는 UDS 요청 및 응답을 위한 스토리지를 제공합니다. [SWS_DM_00291]

세대 & 소유권

최적화된 리소스 할당을 갖춘 인스턴스는 DM 코어에 의해서만 생성된다. Protocol Handler는 읽고 쓸 수 있지만 자체적으로 생성할 수는 없다. 따라서 Default-Konstruktor는 보호된다. 표시가 승인되면 UdsMessagePtr에는 최소 1바이트 용량의 유효한 개체가 있다. 처음에는 GetPayload()에서 제공하는 버퍼가 비어 있다. [SWS_DM_09012] [SWS_DM_00385] [SWS_DM_00392]

다른 클래스와의 상호작용

일정하지 않은 페이로드 액세스는 쓰기 가능한 ByteSpan를 제공한다. 지속적인 액세스는 쓰기 액세스 없이 SID에서 UDS 데이터를 전달한다. 성공적인 표시 후 전송 핸들러는 SID의 페이로드를 용량까지 또는 수신된 메시지의 끝까지 채웁니다. 소스, 대상 및 물리적 또는 기능적 대상 주소 유형은 getter를 통해 사용할 수 있다. AddMetaInfo()는 메타 정보를 추가한다. [SWS_DM_00301] [SWS_DM_00300] [SWS_DM_00388] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00302]
