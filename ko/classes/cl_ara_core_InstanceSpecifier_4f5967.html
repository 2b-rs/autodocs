Representation of an AUTOSAR Instance Specifier, which is basically an AUTOSAR shortName path wrapper.

자동으로 생성된 설명, 참조된 AUTOSAR R25-11 문서(SWS 사양 및 관련 표준 문서)에서 파생된 콘텐츠 — 공식 AUTOSAR 텍스트가 아닙니다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

사용 목적

ara::core::InstanceSpecifier는 AUTOSAR 인스턴스 지정자를 ShortName 경로 주위의 래퍼로 나타냅니다. 애플리케이션 상호 작용의 경우 유효한 경로는 /로 시작하고 PortPrototype까지 /로 구분된 ShortName을 포함합니다. 기능적 클러스터 상호 작용에는 선행 경로 구분 기호도 필요합니다. [SWS_CORE_08001] [SWS_CORE_10200] [SWS_CORE_10203]

창조와 파괴

StringView의 생성자가 실행될 수 있다. Create() 또는 Result<InstanceSpecifier>를 반환한다. 구문적으로 잘못된 메타 모델 경로는 거부되어야 한다. [SWS_CORE_08021] [SWS_CORE_08032] [SWS_CORE_10201] [SWS_CORE_10202]

수명주기 & 소유권

복사 및 Move-Konstruktion와 두 할당 모두 사용 가능하며 noexcept이다. ToString()에서 반환된 문자열 콘텐츠의 수명은 생성자에 전달된 StringView 콘텐츠의 수명 동안만 보장된다. [SWS_CORE_08022] [SWS_CORE_08023] [SWS_CORE_08024] [SWS_CORE_08025] [SWS_CORE_08041]

제한 사항 및 오류 처리

Create()는 경로 요소가 누락되었거나 유효하지 않은 경우 CoreErrc::kInvalidMetaModelShortname를 반환하고 모델 경로가 유효하지 않은 경우 CoreErrc::kInvalidMetaModelPath를 반환한다. [SWS_CORE_08032]

선언문 참조 및 해결

InstanceSpecifier는 시스템 모델에 정의된 리소스에 대한 애플리케이션 코드를 고유하게 가리키는 /로 구분된 모델 경로 개념입니다. 생성자는 구문을 확인합니다. 기능 클러스터는 지정된 리소스에 액세스할 때 경로의 의미론적 유효성만 확인합니다. EXP ARAComAPI §6.2 “Usage of InstanceSpecifier”

ara::com의 경우 서비스 인스턴스 매니페스트는 이러한 지정자를 포트 프로토타입 인스턴스 및 구체적인 서비스 인스턴스와 연결한다. 결과 InstanceIdentifier는 기술에 따라 다릅니다. EXP ARAComAPI §6.2.1 “Modeling and configuration/mapping” TPS ManifestSpecification §B.5.1 “Relation between Instance Specifier and Instance Ref”

활동 다이어그램: 지정자는 바인딩별 InstanceIdentifier에 대한 해결을 위한 모델에 가까운 입력 역할을 한다. 해석: 노드 “ResolveInstanceIDs”는 기능 클러스터에서 발생하는 의미 분석을 요약한다. 출처: EXP ARAComAPI §6.2 “Usage of InstanceSpecifier” EXP ARAComAPI §6.2.1 “Modeling and configuration/mapping” TPS ManifestSpecification §B.5.1 “Relation between Instance Specifier and Instance Ref”.

모델 컨텍스트의 핵심 데이터 유형

핵심 사양에는 인스턴스 지정자를 AUTOSAR의 자체 데이터 유형으로 나열한다. 따라서 가까운 모델 경로로 사용하고 Functional Cluster에서 이후 해상도를 사용하는 것은 별도의 단계이다. 구체적인 목표 약속은 순수한 신호 경로 밖에서만 발생한다. SWS Core §7.4 “Core data types” SWS Core §7.4.1 – Data types devised by AUTOSAR
