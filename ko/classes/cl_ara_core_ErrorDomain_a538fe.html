클래스 ara::core::ErrorDomain

[SWS_CORE_00110] Upstream: RS_AP_00130

class ErrorDomain {...};

Encapsulation of an ErrorDomain. An ErrorDomain is the controlling entity for ErrorCode’s error code values, and defines the mapping of such error code values to textual representations. This type constitutes a base class for ErrorDomain implementations. This class is a literal type, and subclasses are strongly advised to be literal types as well.

사용 목적

ara::core::ErrorDomain는 오류 조건에 대한 컨텍스트를 제공하고 ErrorCode의 오류 값을 제어하며 [SWS_CORE_00110] [SWS_CORE_10303]에 텍스트 표현을 할당한다. 이는 구체적인 장애 도메인의 기본 클래스이며 그 자체는 Literal Type [SWS_CORE_00110] [SWS_CORE_10400]이다.

창조와 파괴

보호 세대는 예상된 [SWS_CORE_00135]처럼 시스템 전체에 고유한 도메인 ID를 허용한다. 소멸자는 다형성 소멸이 필요하지 않고 리터럴 유형 속성이 [SWS_CORE_00136]로 보존되므로 의도적으로 비가상적이고 사소한다.

수명주기 & 소유권

할당을 포함한 복사 및 이동은 금지됩니다 [SWS_CORE_00131] [SWS_CORE_00132] [SWS_CORE_00133] [SWS_CORE_00134]. Name() 및 Message()에서 제공하는 문자 포인터는 도메인 또는 해당 하위 클래스의 속성으로 유지되며 클라이언트 [SWS_CORE_00152] [SWS_CORE_00153]에서 해제할 수 없습니다.

다른 클래스와의 상호작용

Id()는 고유한 ID를 반환합니다. 두 도메인은 IDs이 [SWS_CORE_00151] [SWS_CORE_00137] [SWS_CORE_10401]와 동일한 경우에만 동일합니다. 파생 도메인은 Name(), Message() 및 ThrowAsException()을 구현합니다. final이어야 하며 별칭 Errc 및 Exception [SWS_CORE_00152] [SWS_CORE_00153] [SWS_CORE_00154] [SWS_CORE_10932] [SWS_CORE_10933] [SWS_CORE_10934]를 제공해야 합니다.

제한 사항 및 오류 처리

ThrowAsException()는 적합한 예외 유형을 결정하고 전달된 ErrorCode를 포함하며 C++ 예외가 비활성화된 경우([SWS_CORE_00154] [SWS_CORE_10304]) 오버로드 해결에 참여하지 않다. 이 함수를 제외하고 구체적인 오류 도메인의 공개 함수는 noexcept [SWS_CORE_10950]여야 한다.

오류 도메인 설명

오류 도메인은 오류 값이 적용되는 컨텍스트를 제공한다. 제조업체별 오류에 대해 별도의 도메인이 제공되므로 할당이 명확하게 유지된다. 그들은 휴대용 애플리케이션을 기본 사례로 간주한다. EXP InterfacesGuidelines §3.1.5 “Standardized vs Vendor-specific ErrorCodes”

Rust 바인딩은 동일한 분리를 보여줍니다. 열거형은 ErrorDomain 특성을 구현하고 ErrorCode 객체를 생성하는 데 사용된다. EXP ARARustApplications §5.6 “Creating a new ErrorDomain”

협업 다이어그램: 도메인은 오류 컨텍스트를 결정하고 ErrorCode의 명시적 예외 변환을 지원한다. 출처: EXP InterfacesGuidelines §3.1.2 “Result” EXP ARARustApplications §5.6 “Creating a new ErrorDomain” RS General §4.1.3 “The use of noexcept”.

정체성, 메시지 및 Exception 경계

ErrorDomain은 안정적인 ID 및 메시지 생성을 포함하여 오류 값의 의미를 정의한다. 그 역할은 단순한 열거형이 아닙니다. ErrorCode 비교, 텍스트 표현 및 명시적인 예외 캐스트에 필요한 컨텍스트를 제공한다. SWS Core §7.2 “Error handling” SWS Core §7.2.5.2 “Error Domain”
