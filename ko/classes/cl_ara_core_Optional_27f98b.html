컨텍스트

템플릿 클래스 ara::core::Optional은 AUTOSAR Adaptive Platform용 C++ 어휘 타입 std::optional<T>의 표준 준수 구현을 제공한다. 이는 힙에 동적 메모리를 할당하지 않고 value_type([SWS_CORE_01102]) 유형의 선택적으로 존재하는 값을 위한 컨테이너 역할을 한다. AUTOSAR 환경에서의 일반적인 적용 분야에는 런타임에 존재 여부를 보장할 수 없는 함수 반환값, 구성 파라미터 또는 메시지 요소가 포함되며, 이를 통해 센티널 값이나 원시 포인터의 사용을 방지한다.

수명 주기

ara::core::Optional의 객체는 어느 시점에서든 정확히 두 가지 개별 상태 중 하나에 있다: 값을 포함하지 않거나(빈 상태), T 유형의 초기화된 인스턴스를 보유한다(값이 채워진 상태).

상태 다이어그램: ara::core::Optional 객체의 수명 주기 및 상태 전이. 출처: [SWS_CORE_01103], [SWS_CORE_01104], [SWS_CORE_01107], [SWS_CORE_01113], [SWS_CORE_01119], [SWS_CORE_01136]

빈 상태로의 생성은 기본 생성자([SWS_CORE_01103])를 통하거나 nullopt_t을 전달([SWS_CORE_01104])하여 이루어지며, 둘 다 무조건 noexcept으로 선언되어 있다. 값이 채워진 상태는 복사 및 이동 생성자([SWS_CORE_01105], [SWS_CORE_01106])를 통해 직접 취하거나, 직접적인 값 전달([SWS_CORE_01109], [SWS_CORE_01110], [SWS_CORE_01111]) 또는 in_place_t를 통한 인플레이스 생성([SWS_CORE_01107], [SWS_CORE_01108])을 통해 취할 수 있다. 이러한 생성자들은 T 유형 자체의 생성이 noexcept로 보장되는지 여부에 따라 조건부로 예외에 안전하다(conditionally noexcept).

런타임의 상태 전이는 값을 그 자리에서 생성하는 메서드 emplace([SWS_CORE_01119], [SWS_CORE_01120])과 참조 한정자 &이 부여된 대입 연산자([SWS_CORE_01114], [SWS_CORE_01115], [SWS_CORE_01116], [SWS_CORE_01117], [SWS_CORE_01118])가 제어한다. 빈 상태로의 복귀 전이는 reset()([SWS_CORE_01136]) 또는 nullopt_t 대입([SWS_CORE_01113])을 통해 수행된다. swap([SWS_CORE_01121])을 통해 두 인스턴스를 맞바꿀 수 있다. 소멸자([SWS_CORE_01112])는 포함된 값이 존재하는 경우 이를 소멸시키며, std::is_nothrow_destructible<T>에 따라 조건부로 예외에 안전하다.

사용 경로

일반적인 사용법에서는 호출 컴포넌트가 값에 접근하기 전에 먼저 값의 존재 여부를 확인한다:

  • 확인: 확인은 has_value()([SWS_CORE_01129])을 통해 명시적으로 수행되거나 명시적 변환 연산자 operator bool()([SWS_CORE_01128])를 통해 수행된다.
  • 직접 접근: 값이 존재하는 것이 보장되는 경우, operator*([SWS_CORE_01124], [SWS_CORE_01125], [SWS_CORE_01126], [SWS_CORE_01127]) 또는 포인터 역참조 operator->([SWS_CORE_01122], [SWS_CORE_01123])를 통해 T의 인스턴스에 직접 접근할 수 있다. 마찬가지로 멤버 함수 value()는 모든 참조 및 const 한정자 형태로 제공된다([SWS_CORE_01130], [SWS_CORE_01131], [SWS_CORE_01132], [SWS_CORE_01133]).
  • 대체값(Fallback): 값이 없을 때 기본값을 사용해야 하는 경우, value_or()([SWS_CORE_01134], [SWS_CORE_01135])은 포함된 값 또는 전달된 대체값을 반환하는 간결한 방법을 제공한다.

오류 시나리오

AUTOSAR에서는 유효하지 않은 접근 시의 오류 동작이 ISO C++ 표준과 의도적으로 상이하다:

  • 빈 상태 접근 위반: value()뿐만 아니라 연산자 operator* 및 operator->도 noexcept으로 선언되어 있다. *this에 값이 포함되어 있지 않은 경우(사전 조건 위반), IsoStdBadOptionalAccessViolation가 발생한다([SWS_CORE_01122], [SWS_CORE_01123], [SWS_CORE_01124], [SWS_CORE_01125], [SWS_CORE_01126], [SWS_CORE_01127], [SWS_CORE_01130], [SWS_CORE_01131], [SWS_CORE_01132], [SWS_CORE_01133]). 해석: 이러한 함수들이 noexcept으로 명세되어 있으므로, 이 위반은 AUTOSAR 런타임 환경에서 캐치 가능한 C++ 예외로 전파되지 않으며 전형적으로 제어된 중단 또는 안전 처리 경로로 이어질 것으로 보인다.
  • value_or의 예외 안전성: value_or()의 오버로드는 명시적으로 not exception safe로 명세되어 있다([SWS_CORE_01134], [SWS_CORE_01135]). 대체값의 생성이나 변환이 실패하면 예외가 외부로 전파될 수 있다.

이 가이드는 ara::core::Optional에 대한 AUTOSAR 명세(릴리스 R25-11)만을 기반으로 한다.

  <h4>컨텍스트</h4>
  <p>템플릿 클래스 <code>ara::core::Optional</code>은 AUTOSAR Adaptive Platform용 C++ 어휘 타입 <code>std::optional&lt;T&gt;</code>의 표준 준수 구현을 제공한다. 이는 힙에 동적 메모리를 할당하지 않고 <code>value_type</code>(<a class="spec-record-ref" data-req="SWS_CORE_01102" href="../spec/record.html?id=SWS_CORE_01102">[SWS_CORE_01102]</a>) 유형의 선택적으로 존재하는 값을 위한 컨테이너 역할을 한다.   <p>빈 상태로의 생성은 기본 생성자(<a class="spec-record-ref" data-req="SWS_CORE_01103" href="../spec/record.html?id=SWS_CORE_01103">[SWS_CORE_01103]</a>)를 통하거나 <code>nullopt_t</code>을 전달(<a class="spec-record-ref" data-req="SWS_CORE_01104" href="../spec/record.html?id=SWS_CORE_01104">[SWS_CORE_01104]</a>)하여 이루어지며, 둘 다 무조건 <code>noexcept</code>으로 선언되어 있다. 값이 채워진 상태는 복사 및 이동 생성자(<a class="spec-record-ref" data-req="SWS_CORE_01105" href="../spec/record.html?id=SWS_CORE_01105">[SWS_CORE_01105]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01106" href="../spec/record.html?id=SWS_CORE_01106">[SWS_CORE_01106]</a>)를 통해 직접 취하거나, 직접적인 값 전달(<a class="spec-record-ref" data-req="SWS_CORE_01109" href="../spec/record.html?id=SWS_CORE_01109">[SWS_CORE_01109]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01110" href="../spec/record.html?id=SWS_CORE_01110">[SWS_CORE_01110]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01111" href="../spec/record.html?id=SWS_CORE_01111">[SWS_CORE_01111]</a>) 또는 <code>in_place_t</code>를 통한 인플레이스 생성(<a class="spec-record-ref" data-req="SWS_CORE_01107" href="../spec/record.html?id=SWS_CORE_01107">[SWS_CORE_01107]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01108" href="../spec/record.html?id=SWS_CORE_01108">[SWS_CORE_01108]</a>)을 통해 취할 수 있다. 이러한 생성자들은 <code>T</code> 유형 자체의 생성이 <code>noexcept</code>로 보장되는지 여부에 따라 조건부로 예외에 안전하다(<code>conditionally noexcept</code>).</p>
  <p>런타임의 상태 전이는 값을 그 자리에서 생성하는 메서드 <code>emplace</code>(<a class="spec-record-ref" data-req="SWS_CORE_01119" href="../spec/record.html?id=SWS_CORE_01119">[SWS_CORE_01119]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01120" href="../spec/record.html?id=SWS_CORE_01120">[SWS_CORE_01120]</a>)과 참조 한정자 <code>&amp;</code>이 부여된 대입 연산자(<a class="spec-record-ref" data-req="SWS_CORE_01114" href="../spec/record.html?id=SWS_CORE_01114">[SWS_CORE_01114]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01115" href="../spec/record.html?id=SWS_CORE_01115">[SWS_CORE_01115]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01116" href="../spec/record.html?id=SWS_CORE_01116">[SWS_CORE_01116]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01117" href="../spec/record.html?id=SWS_CORE_01117">[SWS_CORE_01117]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01118" href="../spec/record.html?id=SWS_CORE_01118">[SWS_CORE_01118]</a>)가 제어한다. 빈 상태로의 복귀 전이는 <code>reset()</code>(<a class="spec-record-ref" data-req="SWS_CORE_01136" href="../spec/record.html?id=SWS_CORE_01136">[SWS_CORE_01136]</a>) 또는 <code>nullopt_t</code> 대입(<a class="spec-record-ref" data-req="SWS_CORE_01113" href="../spec/record.html?id=SWS_CORE_01113">[SWS_CORE_01113]</a>)을 통해 수행된다. <code>swap</code>(<a class="spec-record-ref" data-req="SWS_CORE_01121" href="../spec/record.html?id=SWS_CORE_01121">[SWS_CORE_01121]</a>)을 통해 두 인스턴스를 맞바꿀 수 있다. 소멸자(<a class="spec-record-ref" data-req="SWS_CORE_01112" href="../spec/record.html?id=SWS_CORE_01112">[SWS_CORE_01112]</a>)는 포함된 값이 존재하는 경우 이를 소멸시키며, <code>std::is_nothrow_destructible&lt;T&gt;</code>에 따라 조건부로 예외에 안전하다.</p>

  <h4>사용 경로</h4>
  <p>일반적인 사용법에서는 호출 컴포넌트가 값에 접근하기 전에 먼저 값의 존재 여부를 확인한다:</p>
  <ul>
    <li><strong>확인:</strong> 확인은 <code>has_value()</code>(<a class="spec-record-ref" data-req="SWS_CORE_01129" href="../spec/record.html?id=SWS_CORE_01129">[SWS_CORE_01129]</a>)을 통해 명시적으로 수행되거나 명시적 변환 연산자 <code>operator bool()</code>(<a class="spec-record-ref" data-req="SWS_CORE_01128" href="../spec/record.html?id=SWS_CORE_01128">[SWS_CORE_01128]</a>)를 통해 수행된다.</li>
    <li><strong>직접 접근:</strong> 값이 존재하는 것이 보장되는 경우, <code>operator*</code>(<a class="spec-record-ref" data-req="SWS_CORE_01124" href="../spec/record.html?id=SWS_CORE_01124">[SWS_CORE_01124]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01125" href="../spec/record.html?id=SWS_CORE_01125">[SWS_CORE_01125]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01126" href="../spec/record.html?id=SWS_CORE_01126">[SWS_CORE_01126]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01127" href="../spec/record.html?id=SWS_CORE_01127">[SWS_CORE_01127]</a>) 또는 포인터 역참조 <code>operator-&gt;</code>(<a class="spec-record-ref" data-req="SWS_CORE_01122" href="../spec/record.html?id=SWS_CORE_01122">[SWS_CORE_01122]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01123" href="../spec/record.html?id=SWS_CORE_01123">[SWS_CORE_01123]</a>)를 통해 <code>T</code>의 인스턴스에 직접 접근할 수 있다. 마찬가지로 멤버 함수 <code>value()</code>는 모든 참조 및 const 한정자 형태로 제공된다(<a class="spec-record-ref" data-req="SWS_CORE_01130" href="../spec/record.html?id=SWS_CORE_01130">[SWS_CORE_01130]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01131" href="../spec/record.html?id=SWS_CORE_01131">[SWS_CORE_01131]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01132" href="../spec/record.html?id=SWS_CORE_01132">[SWS_CORE_01132]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01133" href="../spec/record.html?id=SWS_CORE_01133">[SWS_CORE_01133]</a>).</li>
    <li><strong>대체값(Fallback):</strong> 값이 없을 때 기본값을 사용해야 하는 경우, <code>value_or()</code>(<a class="spec-record-ref" data-req="SWS_CORE_01134" href="../spec/record.html?id=SWS_CORE_01134">[SWS_CORE_01134]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01135" href="../spec/record.html?id=SWS_CORE_01135">[SWS_CORE_01135]</a>)은 포함된 값 또는 전달된 대체값을 반환하는 간결한 방법을 제공한다.</li>
  </ul>

  <h4>오류 시나리오</h4>
  <p>AUTOSAR에서는 유효하지 않은 접근 시의 오류 동작이 ISO C++ 표준과 의도적으로 상이하다:</p>
  <ul>
    <li><strong>빈 상태 접근 위반:</strong> <code>value()</code>뿐만 아니라 연산자 <code>operator*</code> 및 <code>operator-&gt;</code>도 <code>noexcept</code>으로 선언되어 있다. <code>*this</code>에 값이 포함되어 있지 않은 경우(사전 조건 위반), <code>IsoStdBadOptionalAccessViolation</code>가 발생한다(<a class="spec-record-ref" data-req="SWS_CORE_01122" href="../spec/record.html?id=SWS_CORE_01122">[SWS_CORE_01122]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01123" href="../spec/record.html?id=SWS_CORE_01123">[SWS_CORE_01123]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01124" href="../spec/record.html?id=SWS_CORE_01124">[SWS_CORE_01124]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01125" href="../spec/record.html?id=SWS_CORE_01125">[SWS_CORE_01125]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01126" href="../spec/record.html?id=SWS_CORE_01126">[SWS_CORE_01126]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01127" href="../spec/record.html?id=SWS_CORE_01127">[SWS_CORE_01127]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01130" href="../spec/record.html?id=SWS_CORE_01130">[SWS_CORE_01130]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01131" href="../spec/record.html?id=SWS_CORE_01131">[SWS_CORE_01131]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01132" href="../spec/record.html?id=SWS_CORE_01132">[SWS_CORE_01132]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01133" href="../spec/record.html?id=SWS_CORE_01133">[SWS_CORE_01133]</a>). 해석: 이러한 함수들이 <code>noexcept</code>으로 명세되어 있으므로, 이 위반은 AUTOSAR 런타임 환경에서 캐치 가능한 C++ 예외로 전파되지 않으며 전형적으로 제어된 중단 또는 안전 처리 경로로 이어질 것으로 보인다.</li>
    <li><strong><code>value_or</code>의 예외 안전성:</strong> <code>value_or()</code>의 오버로드는 명시적으로 <em>not exception safe</em>로 명세되어 있다(<a class="spec-record-ref" data-req="SWS_CORE_01134" href="../spec/record.html?id=SWS_CORE_01134">[SWS_CORE_01134]</a>, <a class="spec-record-ref" data-req="SWS_CORE_01135" href="../spec/record.html?id=SWS_CORE_01135">[SWS_CORE_01135]</a>). 대체값의 생성이나 변환이 실패하면 예외가 외부로 전파될 수 있다.</li>
  </ul>
