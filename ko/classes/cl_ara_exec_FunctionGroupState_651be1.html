class FunctionGroupState final {...};

Class representing Function Group State defined in meta-model (ARXML). An instance of this class will represent Function Group State defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

프로세스 집합의 구성 값

FunctionGroupState은 기능 그룹의 구성 상태를 나타냅니다. 이러한 상태는 활성화될 때 어떤 모델 프로세스를 실행해야 하는지를 결정합니다. 기능 그룹 SWS EM §7.4.3 “Function Group State”당 정확히 하나의 상태가 활성화됩니다.

전환 요청에 사용

State Management은 FunctionGroup 및 주 이름에서 대상 주를 형성하고 이를 StateClient::SetState에 전달합니다. Execution Management은 더 이상 필요하지 않은 프로세스를 종료한 다음 필요한 순서 SWS EM §7.4.5 “State Transition”에 따라 대상 상태를 위한 프로세스를 시작합니다.

상태 다이어그램: Off는 필수 초기 상태입니다. 활성 상태는 프로젝트별로 [SWS_EM_01110] SWS EM §7.4 “State Management”로 구성됩니다. 해석: 표현은 구체적인 매니페스트 상태 이름을 추상화합니다.
