ara::core::Map::value_compare는 Map의 값 비교기이다. 이는 Compare 유형의 비교기를 캡슐화하고 두 개의 value_type 개체에 대한 호출 연산자를 제공한다. Compare 개체에서 생성된다. [SWS_CORE_01419] [SWS_CORE_01421] [SWS_CORE_01422] [SWS_CORE_01423]

기술 분류

유형은 사양에서 독립적으로 공식화되지 않았지만 ISO-C++ 표준 섹션 [map]를 참조하여 정의된다. 대응품은 std::map::value_compare(cppreference: std::map::value_compare)이다. 펑터는 Map의 키 비교기에서 파생되며 해당 키를 기반으로 완전한 키-값 쌍을 주문한다.
