키를 기반으로 Map의 두 값 쌍을 비교하기 위한 함수 객체 역할을 합니다.

도우미 클래스 ara::core::Map::value_compare은(는) 내부에 캡슐화된 비교 조건자 [SWS_CORE_01421]을(를) 사용하여 키를 기반으로 Map의 두 값 쌍을 관계 비교하기 위한 함수 객체 역할을 합니다. 인스턴스화는 주로 상위 Map 구조에 의해 보호되어 수행되는 반면, 호출자는 호출 연산자 operator()을(를) 통해 평가를 수행합니다[SWS_CORE_01423]. 사양에 따르면 해당 연산들은 예외 안전하지 않으므로, 호출 코드는 기본 조건자의 잠재적 예외를 고려해야 합니다.

컨텍스트

도우미 클래스 ara::core::Map::value_compare은(는) AUTOSAR Adaptive Platform의 core 모듈에서 연관 테이블의 두 완전한 키-값 요소(value_type)를 비교할 수 있는 함수 객체를 제공합니다. 사양에 따르면 이 클래스는 [map]에 대한 C++ 표준 라이브러리의 확립된 동작을 따릅니다. 주요 임무는 키 순서를 위해 정의된 Compare 유형의 조건자를 전체 값 쌍에 적용할 수 있도록 만드는 것입니다. 이를 위해 클래스는 보호된 멤버 변수 comp에 이 조건자의 내부 인스턴스를 캡슐화합니다[SWS_CORE_01421]. 이러한 방식으로 value_compare은(는) 상위 데이터 구조 ara::core::Map과(와) 직접 상호작용하며, 정렬 또는 검색 알고리즘이 키를 기반으로 값 쌍을 일관되게 비교할 수 있도록 외부에 보장합니다.

수명 주기

value_compare의 인스턴스화에는 엄격한 접근 제한이 적용됩니다. 생성자 value_compare(Compare c)에는 protected 가시성이 부여되어 있습니다[SWS_CORE_01422]. 해석: 이러한 보호된 가시성으로 인해 새 인스턴스의 생성은 주로 둘러싼 클래스 ara::core::Map 자체에만 허용될 것으로 보이며, 일반 호출자는 Map에서 완성된 함수 객체를 가져옵니다. 생성 시 객체는 비교 조건자를 전달받아 보호된 변수 comp에 저장합니다[SWS_CORE_01421]. 복잡한 상태 전이를 갖는 생명주기는 존재하지 않으며, 인스턴스는 생성된 후 불변의 실행 상태를 유지합니다. 이는 동시성 작동의 경우 캡슐화된 조건자 Compare이(가) 상태가 없거나 스레드 안전하게 작동하는 한, 호출 연산자를 통한 병렬 읽기 접근이 안전함을 의미합니다.

사용 경로

일반적인 사용 경로는 함수 호출 연산자 operator()을(를) 통한 값 쌍의 반복 평가에 집중됩니다[SWS_CORE_01423]. 이는 const 메서드로 선언되어 있으며 value_type 유형의 상수 요소에 대한 두 개의 참조를 전달받습니다. 해석: 실행 시 operator()은(는) 전달된 두 값 쌍의 키 부분에 접근하고 이를 comp에 저장된 조건자 [SWS_CORE_01421]에 전달하여 관계형 결과를 불리언 값으로 반환합니다. 다음 다이어그램은 이 표준화된 흐름을 보여줍니다:

시퀀스 다이어그램: operator() 및 캡슐화된 조건자 comp를 통한 값 비교 흐름. 출처: [SWS_CORE_01421], [SWS_CORE_01423]

이 경로는 일반적으로 사용자가 값 쌍에서 수동으로 키를 역참조할 필요 없이 정렬 순서에 따라 Map의 요소를 검사하거나 순회해야 하는 알고리즘에 적용됩니다.

오류 시나리오

견고성 및 예외 처리와 관련하여, 생성자 [SWS_CORE_01422] 및 호출 연산자 operator()[SWS_CORE_01423] 모두 예외 안전으로 명시되지 않았다는 점에 유의해야 합니다. 둘 다 명시적으로 'not exception safe'로 분류되어 있습니다. 해석: 이는 실제로 클래스가 자체 예외 처리 메커니즘을 캡슐화하지 않으며, 사용자 정의 조건자 Compare의 복사 또는 실행 시 발생하는 예외가 호출자에게 직접 전파됨을 의미합니다. 사양은 이 도우미 클래스에 대해 특정 오류 코드를 정의하지 않습니다. 따라서 오류 없는 작동을 위한 필수 전제 조건은 전달된 조건자 Compare의 오류 없는 인스턴스화 가능성 및 실행 가능성과 operator()에 전달된 value_type에 대한 참조의 유효성입니다.

이 가이드는 릴리스 R25-11용 AUTOSAR Adaptive Platform 사양을 기반으로 합니다.
