구성된 연결을 통해 IEEE 1722 데이터 스트림 텔레그램을 형식화하여 전송할 수 있도록 합니다.

템플릿 클래스 ara::rds::IEEE1722RawDataStreamProducer은(는) AUTOSAR Adaptive Platform에서 IEEE 1722 표준(AUTOSAR_AP_SWS_RawDataStream, 1쪽)에 따른 형식화된 데이터 스트림 텔레그램을 전송하는 데 사용됩니다. Create을(를) 통한 정적 생성 후 Connect을(를) 통해 연결이 수립되며, 그 후 페이로드 데이터가 WriteData을(를) 통해 벡터로 전송됩니다 [SWS_RDS_90332]. 이 클래스는 엄격한 이동 전용(Move-Only) 시맨틱을 가지며 이동 작업 시 및 소멸자에서 스레드 안전하지 않습니다. Shutdown의 명시적 호출 또는 객체 소멸은 연결을 올바르게 종료합니다.

컨텍스트

템플릿 클래스 ara::rds::IEEE1722RawDataStreamProducer은(는) AUTOSAR Adaptive Platform의 rds(Raw Data Stream) 모듈 내에서 IEEE 1722 표준(AUTOSAR_AP_SWS_RawDataStream, 1쪽)에 따른 형식화된 데이터 스트림 데이터그램 전송을 위한 인터페이스를 제공합니다. 프로듀서 컴포넌트로서 이는 채널 및 프로토콜별 연결 수립과 기본 네트워크를 통한 페이로드 데이터 전송을 캡슐화합니다.

구성된 스트림 인스턴스에 대한 어드레싱 및 소프트웨어적 바인딩은 생성 메서드 [SWS_RDS_90323]에 ara::core::InstanceSpecifier을(를) 전달하여 수행됩니다. 주요 상호작용 대상은 템플릿 타입 T의 데이터 요소를 생성하는 애플리케이션 소프트웨어와 데이터그램을 물리적으로 전송하는 IEEE 1722 네트워크 스택입니다. 클래스 정의는 헤더 #include "ara/rds/raw_data_stream_IEEE1722.h"을(를) 통해 포함됩니다 [SWS_RDS_90323].

수명 주기

ara::rds::IEEE1722RawDataStreamProducer의 인스턴스화는 정적 팩토리 메서드 Create [SWS_RDS_90323]을(를) 통해서만 독점적으로 수행됩니다. 이 클래스는 엄격한 이동 전용(Move-Only) 시맨틱을 따릅니다. 복사 생성자 [SWS_RDS_90327] 및 복사 할당 연산자 [SWS_RDS_90328]이(가) 삭제되어(=delete) 리소스 복제가 방지됩니다.

이동 생성자 [SWS_RDS_90324] 및 이동 할당 연산자 [SWS_RDS_90326]을(를) 통해 다른 소유자에게 인스턴스를 전달할 수 있습니다. 동시성과 관련하여 이동 작업 및 소멸자는 스레드 안전하지 않은 것으로 선언되었으므로([SWS_RDS_90324], [SWS_RDS_90326], [SWS_RDS_90329]), 서로 다른 스레드에서의 동시 액세스는 외부 동기화가 필요합니다.

생성 후 프로듀서는 처음에 연결이 끊어진 상태에 있습니다. 연결은 Connect을(를) 통해 수립됩니다 [SWS_RDS_90330]. 연결 종료는 Shutdown [SWS_RDS_90331]을(를) 통해 명시적으로 수행되거나 인스턴스 소멸 시 자동으로 수행됩니다. 소멸자 ~IEEE1722RawDataStreamProducer()은(는) 아직 열려 있는 연결이 정상 종료되도록 보장합니다 [SWS_RDS_90329].

상태 다이어그램: 생성부터 연결 수립 및 종료에 이르는 프로듀서의 수명 주기 단계. 출처: [SWS_RDS_90323], [SWS_RDS_90330], [SWS_RDS_90331], [SWS_RDS_90329], [SWS_RDS_90332].

사용 경로

IEEE 1722 데이터 스트림 전송을 위한 일반적인 절차는 다음 단계로 구성됩니다.

  1. 생성: 애플리케이션은 instance 식별자 [SWS_RDS_90323]을(를) 지정하여 Create을(를) 통해 프로듀서를 인스턴스화하고 반환된 인스턴스를 인수합니다.
  2. 연결 수립: 데이터 전송 전에 애플리케이션은 통신 채널을 열기 위해 Connect을(를) 호출합니다 [SWS_RDS_90330].
  3. 데이터 전송: 이후 WriteData(std::vector<T> data)을(를) 사용하여 타입 T의 벡터 형태인 데이터그램을 네트워크로 전달합니다 [SWS_RDS_90332]. 이 단계는 주기적 또는 이벤트 기반으로 반복될 수 있습니다.
  4. 연결 해제: 전송이 완료된 후 Shutdown이(가) 연결을 명시적으로 종료합니다 [SWS_RDS_90331]. 또는 스코프를 벗어날 때 소멸자가 연결을 닫습니다 [SWS_RDS_90329].

시퀀스 다이어그램: 인스턴스화부터 연결 해제까지의 일반적인 데이터 전송 흐름. 출처: [SWS_RDS_90323], [SWS_RDS_90330], [SWS_RDS_90332], [SWS_RDS_90331].

오류 시나리오

클래스의 작업들은 noexcept(으)로 지정되어 있으며 오류 모델 ara::core::Result을(를) 사용합니다.

  • Create은(는) ara::core::Result<IEEE1722RawDataStreamProducer<T>>을(를) 반환합니다 [SWS_RDS_90323]. 구성이 잘못되었거나 리소스가 부족한 경우 결과에는 인스턴스 대신 해당 오류 코드가 포함됩니다.
  • Connect은(는) ara::core::Result<void>을(를) 통해 연결 수립 실패를 보고합니다 [SWS_RDS_90330].
  • WriteData은(는) ara::core::Result<void>을(를) 반환합니다 [SWS_RDS_90332]. 해석: 호출은 아마도 이전에 Connect을(를) 통한 성공적인 연결 수립을 전제할 것으로 추정되며, 연결이 없거나 내부 전송 오류가 발생한 경우 오류가 보고됩니다.
  • Shutdown은(는) 연결을 닫을 때 발생하는 오류 역시 ara::core::Result<void>을(를) 통해 알립니다 [SWS_RDS_90331].

해석: 구체적인 ara::core::ErrorCode 값은 인터페이스 발췌본에 명시되어 있지 않으며 반환된 Result을(를) 통해 애플리케이션별로 확인해야 합니다.

이 가이드는 AUTOSAR Adaptive R25-11의 인터페이스 사양만을 기반으로 하며 자동으로 생성되었습니다.
