클래스 ara::exec::FunctionGroup

[SWS_EM_02263] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150

class FunctionGroup final {...};

Class representing Function Group defined in meta-model (ARXML). An instance of this class will represent Function Group defined inside meta-model (ARXML). This class is intended to be an implementation specific representation, of information inside meta-model. Once created based on ARXML path, its internal value stays bounded to it for entire lifetime of a object.

일관되게 제어되는 프로세스 집합의 경계

FunctionGroup는 구성된 기능 그룹을 대표하는 API이다. 이는 상태를 통해 일관되게 시작되고 종료되는 모델 프로세스를 묶는다. 모델 프로세스를 여러 기능 그룹 SWS EM §7.4.3 “Function Group State”에 할당하면 안 된다.

MachineFG 및 애플리케이션 관련 그룹

기능 그룹 MachineFG는 기계 상태를 설명하며 주로 기계 수명주기에 사용된다. 추가 기능 그룹은 일반적으로 사용자 수준 애플리케이션의 그룹을 제어한다. 프로세스의 특정 할당은 실행 매니페스트 SWS EM §7.4 “State Management”에서 나옵니다.

상태 다이어그램: Function Group의 상태 변경은 State Management에 의해 요청되고 Execution Management RS Execution Management, State Management (S. 16) SWS EM §7.4.5 “State Transition”에 의해 구현된다. Interpretation: 활성 대상 상태는 Manifest에 정의된 ModeDeclaration.의 예이다.
