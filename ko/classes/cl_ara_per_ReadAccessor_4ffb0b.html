클래스 ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

지속화된 파일 및 바이너리 데이터를 블록 단위, 줄 단위 또는 문자 기반으로 읽을 수 있도록 지원합니다.

ara::per::ReadAccessor 클래스는 바이너리 및 텍스트 모드에서 파일을 순차 및 줄 단위로 읽기 위한 동기 메서드를 제공합니다 [SWS_PER_00421], [SWS_PER_00119]. 소비적 읽기 외에도 후속 바이트나 문자에 대한 포인터 중립적 미리보기를 지원합니다. 인스턴스는 스레드 안전하지 않으므로 병렬 접근은 외부에서 조율되어야 하며, 오류 발생 시에는 롤백 보장이 읽기 포인터 위치를 보호합니다 [SWS_PER_00419].

컨텍스트 및 역할 범위

ara::per::ReadAccessor 클래스는 지속성 관리(모듈 per) 내에서 파일 내용을 동기식으로 읽기 위한 인터페이스를 제공하며 FileAccessor로부터 가상 상속을 받습니다. 이 클래스는 지속화된 데이터 저장소에 대한 읽기 접근을 추상화하고 바이너리 및 텍스트 접근 메서드를 모두 제공합니다. 애플리케이션은 특화된 함수를 통해 개별 바이트나 문자를 검사 및 검색할 수 있을 뿐만 아니라, 연속된 블록이나 전체 줄을 읽어들일 수 있습니다.

수명주기 및 동시성

ReadAccessor의 기본 생성자는 삭제되어 있습니다 [SWS_PER_00461]. 따라서 인스턴스화는 일반적으로 지속성 모듈의 상위 열기 및 접근 메커니즘을 통해 매개되어 이루어집니다. 인터페이스 및 바인딩된 접근 리소스의 해제는 가상 소멸자 ~ReadAccessor()를 통해 수행됩니다 [SWS_PER_00417]. ReadAccessor의 인스턴스는 파일 내의 현재 위치를 관리하는 내부 읽기 포인터를 갖습니다. 클래스의 모든 메서드는 명시적으로 스레드 안전하지 않은 것(not thread-safe)으로 명시되어 있으므로 [SWS_PER_00419], 동일한 인스턴스에 대한 동시 읽기 작업은 호출자에 의해 외부에서 동기화되어야 합니다.

바이너리 및 텍스트 데이터의 사용 경로

바이너리 파일 작업을 위해 클래스는 미리보기가 가능하거나 순차적인 읽기 함수를 제공합니다. PeekByte()을 사용하면 읽기 포인터를 변경하지 않고 현재 읽기 위치의 바이트를 검사할 수 있습니다 [SWS_PER_00418]. 반면에 GetByte()는 정확히 1바이트를 읽고 위치를 전진시킵니다 [SWS_PER_00419]. 더 큰 데이터 블록은 ReadBinary(n)를 통해 ara::core::Vector<ara::core::Byte>로 읽어들일 수 있으며, 이때 위치는 그에 맞게 조정됩니다. 파일 끝에 조기 도달하면 벡터는 요청된 것보다 적은 수의 바이트를 포함하게 됩니다 [SWS_PER_00422]. ReadBinary()을 사용하면 파일 끝까지 남은 모든 바이트를 한 단계로 가져올 수 있습니다 [SWS_PER_00421].

시퀀스 다이어그램: 사전 검사 및 구간별 데이터 처리를 포함한 순차 읽기 접근의 일반적인 흐름. 출처: [SWS_PER_00418], [SWS_PER_00422], [SWS_PER_00421].

텍스트 모드에서 PeekChar()은 문자 기반 미리보기를 제공하며 [SWS_PER_00167], GetChar()는 다음 문자를 소비합니다 [SWS_PER_00168]. 줄 단위 읽기는 구분 기호(기본값: '\n', ASCII 0x0a)까지 읽는 ReadLine()를 통해 수행되며, 이때 구분 기호는 결과 문자열에 포함되지 않습니다 [SWS_PER_00119]. n개 문자 구간 또는 나머지 전체 내용은 ReadText()의 오버로드를 통해 읽어올 수 있습니다 [SWS_PER_00165], [SWS_PER_00420]. 읽기 포인터가 멀티바이트 문자의 중간에 위치한 경우, 결과 문자열에 불완전한 Unicode 코드 포인트가 포함될 수 있습니다 [SWS_PER_00119], [SWS_PER_00165].

오류 시나리오 및 오류 처리

ReadAccessor의 모든 읽기 연산은 ara::core::Result에 캡슐화된 상태로 값을 반환하며, 예외 안전(exception safe)으로 명시되어 있습니다 [SWS_PER_00419]. 접근 중에 오류가 발생하면 엄격한 롤백 시맨틱이 적용되어 오류 발생 시 읽기 포인터의 현재 위치는 항상 변경되지 않고 유지됩니다 [SWS_PER_00421], [SWS_PER_00422]. 문서화된 대표적인 오류 상태는 다음과 같습니다:

  • 물리적 저장 매체 오류 발생 시 PerErrc::kPhysicalStorageFailure [SWS_PER_00419], [SWS_PER_00420],
  • 읽기 포인터가 파일 끝에 있거나 파일이 비어 있는 경우 PerErrc::kEof [SWS_PER_00419], [SWS_PER_00168],
  • 데이터의 유효성을 검증할 수 없는 경우 PerErrc::kValidationFailed [SWS_PER_00418], [SWS_PER_00119],
  • 복호화 실패 시 PerErrc::kEncryptionFailed [SWS_PER_00419], [SWS_PER_00422], 그리고
  • 저장된 데이터의 MAC 검증이 실패한 경우 PerErrc::kAuthenticationFailed [SWS_PER_00167], [SWS_PER_00421].

이 가이드는 AUTOSAR Adaptive R25-11 사양을 기반으로 하며 자동으로 생성되었습니다.
