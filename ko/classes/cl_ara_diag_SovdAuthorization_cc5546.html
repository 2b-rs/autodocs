사용 목적

SovdAuthorization은 애플리케이션 수준의 SOVD Authorization을 구현한다. GetAuthorizationUrl() 및 GetTokenUrl()는 각각 Authorization 및 Token 요청용 URL을 제공하며, DM은 이 URL을 포함한 Location Header와 HTTP 307로 응답한다. [SWS_DM_01485] [SWS_DM_01484] [SWS_DM_01472] [SWS_DM_01471] ValidateAuthorization()은 HTTP-Authorization Header의 Token을 검증하고 전달된 ClientAuthentication에 Authorization된 역할을 표시한다. [SWS_DM_01483] [SWS_DM_01470]

세대 및 수명주기

생성자는 DiagnosticSovdAuthorizationInterface의 PortPrototype을 바인딩하고 ConcurrencyType를 허용합니다. [SWS_DM_01489] Offer()는 전달을 활성화하고, StopOffer()는 다시 비활성화합니다. 제안은 kAlreadyOffered 또는 kConfigurationMismatch를 제공할 수 있습니다. [SWS_DM_01487] [SWS_DM_01486] 소멸자는 예외로부터 안전합니다. [SWS_DM_01488]

제한 사항 및 오류 처리

future가 배포된 후에는 애플리케이션이 더 이상 참조된 ClientAuthentication 개체를 사용할 수 없다. [SWS_DM_01483] 성공적인 반환 값을 통해 DM은 최대 validUntil 역할을 동일한 토큰에 대해 인증된 것으로 처리할 수 있다. [SWS_DM_01469] 검증에서는 kInvalidAccessToken 또는 kTemporarilyNotAvailable를 보고할 수 있다. [SWS_DM_01483] URL 및 유효성 검사 작업은 ConcurrencyType에 따라 다릅니다. 제안 및 StopOffer는 thread-safe가 아닙니다. [SWS_DM_01485] [SWS_DM_01484] [SWS_DM_01483] [SWS_DM_01487] [SWS_DM_01486]

토큰이 아직 유효한 이전에 확인된 토큰과 동일하지 않은 경우 DM은 승인을 다시 확인한다. [SWS_DM_01470] validUntil까지 동일한 토큰과 동일한 반환 ID를 사용하면 클라이언트를 동일하게 처리할 수 있다. [SWS_DM_01781] [SWS_DM_01782] URL 메소드는 요청 쿼리 매개변수와 MetaInfo를 수신하고 각각 비동기적으로 문자열을 반환한다. [SWS_DM_01484] [SWS_DM_01485]

SOVD 액세스 컨텍스트

SOVD 인증은 요청 헤더에 OAuth 토큰을 사용한다. 이러한 요청의 경우 Diagnostic Manager는 SovdAuthorization를 사용하여 애플리케이션에서 인코딩된 권한 부여 역할을 요청한다. 이 역할을 기반으로 승인된 SOVD 작업이 승인되었는지 여부를 결정한다. EXP SOVD §3.2.1 “Access Permissions”

시퀀스 다이어그램: OAuth 토큰을 사용한 SOVD 인증 및 문서에 설명된 역할 검색. 출처: EXP SOVD §3.2.1 “Access Permissions”. Interpretation: 마지막 메시지는 허용/거부로 텍스트에 설명된 권한 부여 결정을 요약한다.

This function validates the authorization token sent by the SOVD client. The application shall validate the authorization token according to the authorization protocol used in the system and then according to the outcome set the respective roles as authorized in the clientAuthentication that is passed as parameter. If OAuth 2.0 is used, this would implement the validation that is supposed to happen in the Resource Server.
