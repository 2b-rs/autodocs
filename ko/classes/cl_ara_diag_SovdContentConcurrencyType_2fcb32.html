SovdContentConcurrencyType SOVD 콘텐츠 관련 포트의 동시성을 설정한다. [SWS_DM_02182] read 및 write 필드는 각각 읽기 및 쓰기에 대한 ConcurrencyType 설정을 결정하며 각각의 기본값은 kNotConcurrent이다. [SWS_DM_02183] [SWS_DM_02184] readWrite 읽기 및 쓰기 API의 동시 실행을 제어한다. kConcurrent에 DM이 동시에 전화할 수 있다. [SWS_DM_02185]

상수/변수

  • read Concurrency type for Reads.
  • readWrite Concurrency type for calling Read and Write methods in a concurrent way
  • write Concurrency type for Writes.
