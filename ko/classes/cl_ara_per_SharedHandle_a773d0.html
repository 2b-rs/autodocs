클래스 ara::per::SharedHandle

[SWS_PER_00362] Upstream: RS_PER_00002, RS_AP_00122, RS_AP_00140

template <typename T> class SharedHandle final {...};

Handle to a File Storage or Key-Value Storage. A SharedHandle is returned by the functions OpenFileStorage() and OpenKeyValueStorage() and can be passed between threads as needed. It provides the abstraction that is necessary to allow thread-safe implementation of OpenFile Storage() and OpenKeyValueStorage().

공유 Storage 수명

SharedHandle는 열린 FileStorage 또는 KeyValueStorage의 공통 수명을 전송합니다. 스토리지는 마지막 핸들과 해당 복사본이 만료되거나 플랫폼이 초기화 해제될 때까지 열려 있습니다. SWS Persistency §7.3 “Key-Value Storage specific Features” SWS Persistency §7.4 “File Storage specific Features”

현명하게 공유하세요

복사본을 사용하면 여러 구성 요소가 동일한 스토리지에 액세스할 수 있다. 이는 서비스 수명을 더욱 견고하게 해주지만 업데이트, 재설정 또는 복구와 같은 충돌하는 작업의 조정을 대체하지는 않는다. 구성 요소가 스레드에 핸들을 전달하는 경우 기술 액세스 계획을 지정해야 한다.

열려면 구성되고 초기화된 지속성이 필요합니다. 출처: SWS Persistency §7.1 “The Architecture of Persistency” SWS Persistency §7.3 “Key-Value Storage specific Features”.
