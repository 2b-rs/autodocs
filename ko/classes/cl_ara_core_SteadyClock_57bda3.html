클래스 ara::core::SteadyClock

[SWS_CORE_06401] Upstream: RS_AP_00130

class SteadyClock final {...};

This clock represents a monotonic clock. The time points of this clock cannot decrease as physical time moves forward and the time between ticks of this clock is constant.

ara::core::SteadyClock는 단조 시계를 나타냅니다. 해당 시점은 물리적 시간이 진행됨에 따라 감소하지 않으며 틱 지속 시간은 [SWS_CORE_06401]로 일정한다. TrivialClock의 요구 사항을 충족한다. 그 시대는 시스템 부팅 [SWS_CORE_11800] [SWS_CORE_11801]이다.

시간 값은 std::int64_t를 표현으로, std::nano를 기간으로, std::chrono::time_point<SteadyClock, duration>를 시점으로 사용한다 [SWS_CORE_06412] [SWS_CORE_06413] [SWS_CORE_06414]. is_steady는 항상 true이다. now()는 noexcept이며 exception-safe 및 thread-safe이다 [SWS_CORE_06431] [SWS_CORE_06432].

방법 개요

  • static time_point now () noexcept; Return a time_point representing the current value of the clock.

유형 별칭

  • duration std::chrono::duration<rep, period>
  • period A std::ratio type representing the tick period of the clock, in seconds .
  • rep An arithmetic type representing the number of ticks in the clock’s duration .
  • time_point std::chrono::time_point<ara::core::SteadyClock>

상수/변수

  • is_steady steady clock flag, always true
