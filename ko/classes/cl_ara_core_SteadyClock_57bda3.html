클래스 ara::core::SteadyClock

[SWS_CORE_06401] Upstream: RS_AP_00130

class SteadyClock final {...};

This clock represents a monotonic clock. The time points of this clock cannot decrease as physical time moves forward and the time between ticks of this clock is constant.

시간 불변 구간 측정 및 데드라인을 위해 나노초 분해능을 갖춘 엄격한 단조 시계를 제공합니다.

이 클래스는 시점이 결코 감소하지 않는 시간 간격 및 기한 측정을 위해 나노초 분해능을 갖춘 단조롭고 균일한 시계를 제공합니다([SWS_CORE_06431], [SWS_CORE_06413]). 애플리케이션은 정적 함수 now()를 통해 스레드 안전하고 예외 위험 없이 현재 타임스탬프를 가져옵니다 [SWS_CORE_06432]. 두 시점의 차이를 구함으로써 작업의 실행 시간을 견고하게 측정할 수 있습니다.

컨텍스트

ara::core::SteadyClock 클래스는 AUTOSAR Adaptive Platform에서 정밀한 시간 측정을 위한 단조 시계를 제공합니다. 주요 책임은 지속적으로 증가하는 시점을 제공하는 것입니다. 이 시계의 시점은 물리적 시간이 진행됨에 따라 결코 감소할 수 없으며 틱 사이의 지속 시간은 일정합니다. is_steady = true 속성을 통해 [SWS_CORE_06431] 이러한 불변성이 보장됩니다.

이 클래스의 시간 모델은 C++ 표준 시계 개념을 따르며 시간 간격 및 시점의 측정 단위를 표준화합니다. 시계의 틱 주기는 형식 별칭 period을 통해 나노초로 정의됩니다([SWS_CORE_06413]: using period = std::nano). 틱 수의 표현 형식으로는 부호 있는 64비트 정수 형식이 사용됩니다([SWS_CORE_06412]: using rep = std::int64_t). 이를 바탕으로 using duration = std::chrono::duration<rep, period>는 상대적인 시간 간격을 나타내며 [SWS_CORE_06411], using time_point = std::chrono::time_point<SteadyClock, duration>은 특정 시점을 이 시계에 바인딩합니다 [SWS_CORE_06414]. 일반적인 상호작용 파트너는 실행 시간을 측정하거나 데드라인을 모니터링해야 하는 애플리케이션 컴포넌트입니다.

수명 주기

이 클래스는 final으로 지정되어 있으며 오직 정적 인터페이스만을 포함합니다. Interpretation: 클래스가 정적 네임스페이스이자 time_point의 형식 식별자 역할을 하므로 실제 사용을 위해 ara::core::SteadyClock의 인스턴스화는 의도되지도 않았고 필요하지도 않습니다. 질문 Q-08b479dc497c8f74 (열림) 상태 전이, 초기화 단계 또는 소멸 루틴이 존재하지 않습니다.

여러 스레드에서의 동시 액세스를 위해 핵심 조회 함수 now()은 명시적으로 스레드 안전(thread-safe)으로 지정되어 있습니다 [SWS_CORE_06432]. 따라서 여러 스레드가 추가적인 외부 동기화 없이 동시적으로 타임스탬프를 획득할 수 있습니다.

사용 경로

ara::core::SteadyClock의 일반적인 사용 경로는 프로그램 섹션의 실행 지속 시간 측정입니다. 시작 시 호출자는 정적 메서드 ara::core::SteadyClock::now()을 통해 현재 타임스탬프를 조회하며 [SWS_CORE_06432], 이를 통해 time_point 형식의 객체가 반환됩니다 [SWS_CORE_06414]. 그 후 애플리케이션은 의도된 작업을 실행합니다. 작업 완료 후 now()에 대한 재호출이 수행됩니다 [SWS_CORE_06432]. 시작 시점을 종료 시점에서 뺌으로써 애플리케이션은 경과된 지속 시간을 duration로 계산합니다 [SWS_CORE_06411]. is_steady는 시계가 뒤로 가지 않음을 보장하므로 [SWS_CORE_06431], 물리적 시간이 진행됨에 따라 결과는 항상 단조적이며 신뢰할 수 있습니다.

시퀀스 다이어그램: 두 시점 획득을 통한 지속 시간 측정의 일반적인 흐름. 출처: [SWS_CORE_06432], [SWS_CORE_06411], [SWS_CORE_06414]

오류 시나리오

ara::core::SteadyClock의 인터페이스는 오류 코드나 오류 상태를 규정하지 않습니다. 함수 now()은 noexcept로 선언되어 있으며 예외 안전(exception safe) 속성을 가집니다 [SWS_CORE_06432]. now() 호출은 어떠한 정상 작동 조건에서도 실패하지 않으며 time_point 형식의 유효한 값을 보장하며 반환합니다 [SWS_CORE_06414].

Interpretation: 카운터 rep의 이론적인 오버플로는 [SWS_CORE_06412] 나노초 틱 기준 64비트 값 범위로 인해 실제 시스템에서 계산상 수백 년의 작동 시간이 지나야 발생할 수 있으므로 현실적인 오류 위험을 나타내지 않는 것으로 추정됩니다. 질문 Q-9ce575da867b8203 (열림)

정적 함수 ara::core::SteadyClock::now()은(는) 클록의 현재 카운터 값을 나타내는 time_point을(를) 동기식으로 반환합니다 [SWS_CORE_06432]. 사용하려면 헤더 파일 ara/core/steady_clock.h을(를) 포함해야 합니다 [SWS_CORE_06432]. 이 메서드는 ara::core::SteadyClock에 정적으로 바인딩되어 있으므로 클래스의 인스턴스화가 필요하지 않으며, 스코프를 통해 직접 접근이 이루어집니다.

오류 처리와 관련하여 이 함수는 noexcept(으)로 선언되어 있으며 예외 안전(exception safe)으로 지정되어 있습니다 [SWS_CORE_06432]. 연산이 오류 없이 반환되는 것이 보장되므로, 호출자는 시간 조회에 대한 예외 처리를 마련할 필요가 없습니다.

동시성 및 제약 조건과 관련하여 now()은(는) 스레드 안전(thread-safe)으로 명시되어 있습니다 [SWS_CORE_06432]. 이 함수는 애플리케이션 측 동기화 없이 임의의 실행 컨텍스트 및 스레드에서 병렬로 호출될 수 있습니다.

ara::core::SteadyClock의 인터페이스 내에서 이 함수는 주로 상대적 구간 측정 및 실행 시간 결정을 위한 시점을 제공하는 역할을 할 것으로 보입니다(해석: 스코프 및 반환 타입 [SWS_CORE_06432]에서 파생됨). 질문 Q-34b2317714fd4e03 (열림)
