클래스 ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

공통 커서 인터페이스

FileAccessor는 열린 파일의 위치 및 크기 작업을 번들로 묶습니다. 이는 읽기, 쓰기 및 읽기/쓰기 접근자의 공통 기반입니다. 이는 커서 위치가 정확히 이 열린 파일에 대한 액세스를 설명한다는 것을 의미합니다.

위치 규율

GetPosition, SetPosition 및 MovePosition는 탐색용이고 GetSize는 현재 파일 크기를 제공한다. 접근자 작업은 스레드로부터 안전하지 않다. 따라서 외부 동기화 없이 동시에 여러 스레드에서 핸들을 사용해서는 안 된다. SWS Persistency §7.4 “File Storage specific Features”

이용안내

FileStorage를 통해 파일을 열고, 동일한 UniqueHandle을 소유한 커서 작업을 수행한 후 놓습니다. 입장 변경은 지속 과정이 아닙니다. 데이터 쓰기에는 적절한 쓰기 작업이 필요하며 필요한 경우 동기화가 필요합니다.

File Storage는 많은 명명된 파일을 관리한다. 접속자는 특정 개방형 액세스에 대한 독점 소유권을 갖다. 출처: SWS Persistency §7.4 “File Storage specific Features” [SWS_PER_00113].
