클래스 ara::per::FileAccessor

[SWS_PER_00588] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class FileAccessor {...};

FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

특화된 파일 접근을 위한 파일 크기 조회 및 위치 탐색의 공통 기본 클래스 역할을 합니다.

ara::per::FileAccessor 클래스는 AUTOSAR 지속성 모듈에서 정렬된 파일 접근([SWS_PER_00424])을 위한 위치 탐색 및 크기 검사의 공통 기본 클래스 역할을 합니다. 삭제된 생성자([SWS_PER_00589])를 통해 직접 인스턴스화 및 복사 작업을 방지합니다. 유효하지 않은 위치 지정 시 현재 포인터 위치를 보호하는 롤백 시맨틱이 적용됩니다. 모든 연산은 예외로부터 안전하지만, 동시성 환경에서 사용할 경우 외부 동기화가 필요합니다.

컨텍스트

ara::per::FileAccessor 클래스는 AUTOSAR Adaptive Platform의 지속성 모듈(ara::per)에서 ReadAccessor 및 WriteAccessor과 같은 파일 접근 객체를 위한 공통 추상 기본 클래스 역할을 합니다. 핵심 책임은 파일 관련 위치 관리 및 크기 검사를 위한 통일된 인터페이스입니다. 이 클래스는 열린 파일 내에서 읽기 및 쓰기 커서를 제어하는 인스턴스로 동작하지만, 실제 데이터 전송(바이트 읽기 또는 쓰기와 같은)을 위한 메서드는 자체적으로 포함하지 않습니다. 탐색은 파일 시작점 기준의 절대 방식 또는 정의된 기준점 대비 상대 방식으로 수행됩니다.

수명 주기

ara::per::FileAccessor 클래스는 직접 인스턴스화하거나 자유롭게 복사할 수 없습니다. 기본 생성자는 복사 생성자([SWS_PER_00592]) 및 복사 대입 연산자([SWS_PER_00593])와 마찬가지로 삭제되어 있습니다([SWS_PER_00589]). 이동 시맨틱 역시 명시적으로 금지되어 있어, 이동 생성자([SWS_PER_00590])와 이동 대입 연산자([SWS_PER_00591])가 모두 삭제되었습니다. 이로부터 인스턴스는 구체적인 서브클래스의 컨텍스트 내에서만 생성 및 관리된다는 해석이 도출됩니다.

기본 클래스 포인터를 통한 다형적 파괴를 가능하게 하는 가상 소멸자 ~FileAccessor()([SWS_PER_00594])이 안전한 해제를 보장합니다. 동시성과 관련하여 모든 멤버 함수는 스레드 안전하지 않은 것으로 명시되어 있습니다([SWS_PER_00162], [SWS_PER_00424], [SWS_PER_00107], [SWS_PER_00163], [SWS_PER_00164]). 따라서 동일한 인스턴스에 대한 서로 다른 스레드의 경쟁 접근은 애플리케이션에 의해 동기화되어야 합니다.

사용 경로

FileAccessor의 전형적인 사용 사례에는 파일 크기 조회, 현재 위치 확인, 그리고 읽기 또는 쓰기 접근을 준비하기 위한 목적별 위치 이동이 포함됩니다:

  • 크기 조회: GetSize()을 통해 바이트 단위의 현재 파일 크기를 확인합니다([SWS_PER_00424]).
  • 위치 조회: 애플리케이션은 GetPosition()을 사용하여 파일 시작점 기준의 현재 바이트 오프셋을 조회하며, 이는 정확히 파일 끝에 위치할 수도 있습니다([SWS_PER_00162]).
  • 절대 위치 지정: SetPosition()은 파일 시작점 기준의 절대 오프셋으로 커서를 설정합니다([SWS_PER_00163]).
  • 상대 이동: MovePosition()은 Origin::kBeginning, Origin::kCurrent 또는 Origin::kEnd에서 시작하여 부호 있는 오프셋만큼 커서를 이동합니다([SWS_PER_00164]).
  • 파일 끝 검사: IsEof() 메서드는 현재 위치가 파일 끝에 도달했는지 여부를 반환합니다([SWS_PER_00107]).

시퀀스 다이어그램: 오류 검사를 포함한 위치 조회 및 탐색 단계의 일반적인 순서. 출처: [SWS_PER_00424], [SWS_PER_00162], [SWS_PER_00163], [SWS_PER_00164], [SWS_PER_00107]

오류 시나리오

FileAccessor의 모든 연산은 예외 안전한 것으로 선언되어 있습니다(noexcept). 탐색 호출 시 발생 가능한 오류 상태는 ara::core::Result를 통해 반환됩니다:

애플리케이션이 SetPosition()을 통해 파일 끝을 벗어난 위치로 이동하려고 시도하면 호출은 오류 코드 PerErrc::kInvalidPosition과 함께 실패합니다([SWS_PER_00163]). 계산된 대상 위치가 음수가 되거나 파일 끝 뒤에 위치하는 경우 MovePosition()에도 동일하게 적용됩니다([SWS_PER_00164]). 두 메서드 모두 엄격한 롤백 시맨틱이 필수적으로 규정되어 있어, 오류가 발생하면 이전에 유효했던 파일 위치가 변경되지 않고 유지됩니다([SWS_PER_00163], [SWS_PER_00164]).

조회 메서드인 GetSize()([SWS_PER_00424]), GetPosition()([SWS_PER_00162]) 및 IsEof()([SWS_PER_00107])는 기본 데이터 타입을 직접 반환하며 특정 오류 코드를 생성하지 않습니다.

이 텍스트는 AI가 AUTOSAR 사양 R25-11을 기반으로 작성했습니다. 탐색 추상화에 대한 전반적인 그림을 제공함으로써 표준 문서를 보완합니다.
