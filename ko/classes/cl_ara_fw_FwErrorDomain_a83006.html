컨텍스트

ara::fw::FwErrorDomain 클래스는 AUTOSAR Adaptive Platform 내의 Firewall 모듈(fw)을 위한 특정 오류 도메인을 나타낸다. 추상 기본 클래스 ara::core::ErrorDomain의 특수화로서 Firewall의 오류 상태를 통일된 플랫폼 전반의 오류 모델에 통합한다. 형식 관련 별칭 Errc을 통해 이 클래스는 모듈에 정의된 오류 코드 집합을 매핑하는 열거형 FwErrc [AP_SWS_Fw_83007]을(를) 참조한다. 또한 별칭 Exception은(는) 연관된 예외 형식 FwException을(를) 바인딩한다 [AP_SWS_Fw_83008].

소프트웨어 아키텍처에서 ara::fw::FwErrorDomain은(는) 숫자 오류 코드를 Firewall 고유의 컨텍스트 정보에 고유하게 매핑하는 역할을 담당한다. 이를 통해 상위 애플리케이션 계층이나 플랫폼 서비스는 도메인 이름을 기반으로 모듈의 오류를 식별하고 추가 처리할 수 있다.

수명 주기

ara::fw::FwErrorDomain의 수명 주기 관리는 런타임에 인스턴스가 임의로 생성되지 않도록 설계되어 있다. 기본 생성자는 명시적으로 삭제되어 있다(FwErrorDomain() = delete;) [AP_SWS_Fw_83009]. 해석: 이 클래스는 프로세스 내에서 수명이 긴 정적 싱글톤으로 제공되며, 애플리케이션 컴포넌트가 전역 인스턴스 함수를 통해 접근할 것으로 보인다.

동시성과 관련하여 관련 조회 및 실행 연산은 스레드 안전한 것으로 명시되어 있다. Name() [AP_SWS_Fw_83010]을(를) 통한 도메인 이름 확인뿐만 아니라 Message() [AP_SWS_Fw_83011]을(를) 통한 오류 코드의 텍스트 확인 및 ThrowAsException() [AP_SWS_Fw_83012]을(를) 통한 예외 변환 모두 스레드 안전성을 보장한다. 여러 동시 스레드가 외부 동기화 없이 이러한 메서드를 호출할 수 있다.

사용 경로

일반적인 사용 경로는 Firewall 하위 시스템의 연산이 실패하여 오류 객체를 생성하거나 검사해야 할 때 발생한다:

  • 이름 확인: Name() 메서드를 통해 오류 도메인의 식별자를 조회하며 [AP_SWS_Fw_83010], 이는 특히 로깅 및 오류 분석에 사용된다.
  • 오류 텍스트 확인: 전달된 오류 값(CodeType)을 기반으로 Message()은(는) 설명 텍스트 메시지를 const char*(으)로 반환한다 [AP_SWS_Fw_83011]. 구현은 이 과정에서 열거형 FwErrc의 값에 의존하는 것으로 추정된다.
  • 예외 발생: 오류 코드를 예외로 변환해야 하는 경우, 이는 ThrowAsException()을(를) 통해 수행된다 [AP_SWS_Fw_83012].

시퀀스 다이어그램: 오류 검사 및 선택적 예외 생성의 일반적인 흐름. 출처: [AP_SWS_Fw_83010], [AP_SWS_Fw_83011], [AP_SWS_Fw_83012].

오류 시나리오

오류 처리 내에서 ara::fw::FwErrorDomain은(는) 반환 기반 오류 코드와 C++ 예외 사이의 중재자 역할을 한다. 메서드 Name() [AP_SWS_Fw_83010] 및 Message() [AP_SWS_Fw_83011]은(는) noexcept(으)로 선언되어 있으며, 어떠한 상황에서도 자체적으로 예외를 발생시키지 않는다.

이와 대조적으로 ThrowAsException()은(는) 명시적으로 noexcept(false)(으)로 정의되며 예외에 안전하지 않음(not exception safe)으로 분류된다 [AP_SWS_Fw_83012]. 이 메서드는 전달받은 ara::core::ErrorCode 인스턴스로부터 FwException 형식(형식 별칭 Exception [AP_SWS_Fw_83008])의 예외 객체를 생성하고 이를 발생시킨다. 해석: 이 호출은 반환 기반 오류 구조보다 예외 기반 제어 흐름을 선호하는 소프트웨어 계층을 위한 표준화된 에스컬레이션 브리지 역할을 할 것으로 보인다.

이 가이드는 fw 모듈에 대한 AUTOSAR Adaptive Release R25-11 사양을 기반으로 한다.
