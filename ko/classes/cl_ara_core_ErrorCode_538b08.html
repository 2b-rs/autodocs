클래스 ara::core::ErrorCode

[SWS_CORE_00501] Upstream: RS_AP_00130, RS_AP_00140

class ErrorCode final {...};

Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

사용 목적

ErrorCode는 도메인별 원시 오류 값, 연관된 ErrorDomain에 대한 참조 및 선택적 공급업체별 추가 데이터를 캡슐화한다. 유형은 리터럴 유형이다. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

생성 및 상호 작용

이는 오류 열거형이나 값, 오류 도메인 및 추가 데이터에서 생성될 수 있다. Domain(), Value(), SupportData() 및 Message()는 해당 구성 요소 또는 오류 텍스트에 액세스할 수 있도록 한다. ThrowAsException()는 도메인 전체에서 적절한 예외 유형을 결정한다. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

제한 사항 및 오류 처리

비교에서는 추가 데이터가 아닌 오류 값과 오류 도메인만 고려한다. ErrorCode 및 해당 멤버는 ara::core::Initialize 및 Deinitialize와 독립적으로 사용될 수 있다. [SWS_CORE_10301] [SWS_CORE_15002]

일반 오류값 대신 오류 컨텍스트

A ErrorCode는 입력된 오류 값을 ErrorDomain 컨텍스트에 연결한다. 선택적으로 메시지와 추가 제조업체별 정보를 전달할 수 있다. ARA 인터페이스는 복구 가능한 오류를 위해 Result 내에서 이를 사용한다. EXP InterfacesGuidelines §3.1.2 “Result” EXP ARAComAPI §4.7 “Error Handling”

제조업체별 오류 코드에는 자체 오류 도메인이 필요한다. 이식 가능하고 스택 중립적인 애플리케이션은 이러한 도메인을 일반적인 기본 사례로 처리해야 한다. EXP InterfacesGuidelines §3.1.5 “Standardized vs Vendor-specific ErrorCodes”

협업 다이어그램: ErrorCode는 해당 도메인에서 컨텍스트와 메시지를 가져옵니다. 예외 변환은 명시적 예외 경로입니다. 출처: EXP InterfacesGuidelines §3.1.2 “Result” RS General §4.1.3 “The use of noexcept”.

지워진 오류 값을 입력하세요.

SWS는 ErrorCode을 도메인 컨텍스트의 오류 값으로 설명한다. 도메인별 코드는 균일한 전송을 위해 정수 값으로 유형 삭제된다. 추가 지원 정보가 공유될 수 있다. 비교에서는 지원 데이터가 아닌 값과 도메인을 고려한다. SWS Core §7.2 “Error handling” SWS Core §7.2.5.1 “ErrorCode” [SWS_CORE_10301] [SWS_CORE_10302]

방법 개요
