클래스 ara::shwa::Accessor

이 페이지는 SWS Safe Hardware Acceleration(R25-11)를 기반으로 완전히 AI로 생성되었다. 공식 AUTOSAR 텍스트도 없고 나머지 모듈처럼 자동으로 추출된 API 페이지도 없다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

버퍼 메모리 영역에 대한 타입화되고 제어된 읽기 및 쓰기 접근을 가능하게 합니다.

템플릿 클래스는 기본 데이터 버퍼의 할당된 메모리에 대한 타입화되고 제어된 접근을 가능하게 합니다. 인스턴스화는 인스턴스를 고유 포인터([AP_SWS_SHWA_00007])로 반환하는 정적 팩토리 메서드를 통해서만 독점적으로 수행됩니다. 런타임에 데이터는 타입 안전한 읽기 및 쓰기 작업이나 인덱스 연산자를 통해 처리될 수 있습니다 ([AP_SWS_SHWA_00011]). 모든 복사 및 이동 작업은 금지되는 반면, 개별 데이터 작업은 스레드 안전성 및 오류 처리에 대한 특정 요구사항의 적용을 받습니다.

컨텍스트

템플릿 클래스 ara::shwa::Accessor은 AUTOSAR Adaptive Platform의 공유 메모리 버퍼에 대한 타입화된 메모리 접근을 위한 핵심 접근 인터페이스를 구성합니다. 이는 기본 ara::shwa::Buffer에 대한 어드레싱 및 접근 로직을 캡슐화하며 데이터 타입(DataT), 차원(Dimensions), 접근 모드(AccessModeType), 대상 디바이스(AccessTargetType) 및 사용된 메모리 할당자(AllocatorT)를 통해 이를 정적으로 매개변수화합니다. 고급 시나리오에서 이 클래스는 버퍼 환경에서 처리 작업을 제어할 것으로 추정되는 TaskHandler을 통합합니다.

모듈 내에서 이 클래스는 세 가지 주요 상호작용 대상과 연계하여 동작합니다:

  • 응용 프로그램 / 호출자: 팩토리 인터페이스를 통해 인스턴스를 요청하고 메서드 또는 연산자를 통해 읽기 또는 쓰기 작업을 수행합니다.
  • ara::shwa::Buffer: 할당된 메모리 영역을 제공하며, Accessor 생성 시 참조로 전달됩니다 ([AP_SWS_SHWA_00007]).
  • TaskHandler: 버퍼 처리 시 작업을 조정하기 위해 생성 중에 필요에 따라 등록됩니다([AP_SWS_SHWA_00008]).

컨텍스트 다이어그램: ara::shwa::Accessor의 상호작용 파트너. 출처: [AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008]

수명 주기

ara::shwa::Accessor의 수명 주기는 액세스 인스턴스의 통제되지 않는 복제 또는 이동을 방지하는 엄격한 의미론적 제약 조건을 따릅니다. 기본 생성자는 명시적으로 삭제되었습니다([AP_SWS_SHWA_00002]). 마찬가지로 복사 생성자([AP_SWS_SHWA_00003])와 이동 생성자([AP_SWS_SHWA_00005])뿐만 아니라 모든 복사 및 이동 대입 연산자도 삭제된 것으로 선언되어 있습니다([AP_SWS_SHWA_00004], [AP_SWS_SHWA_00006]). 따라서 스택에서의 직접적인 인스턴스화나 값 의미론은 배제됩니다.

새 인스턴스의 생성은 정적 팩토리 메서드 Create을 통해서만 독점적으로 수행됩니다([AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008]). 이는 ara::core::Result<std::unique_ptr<Accessor>>을 반환하여 소유권을 호출자에게 독점적으로 이전합니다. 소유권을 가진 std::unique_ptr가 유효 범위를 벗어나는 즉시 객체는 자동으로 파괴됩니다. 생성 메서드는 스레드 안전(thread-safe) 및 예외 안전(exception safe)하도록 명세되어 있습니다([AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008]).

런타임 중의 동시성과 관련하여, 명시적 접근 메서드 Get([AP_SWS_SHWA_00012]) 및 Set([AP_SWS_SHWA_00011])는 스레드 안전한 것으로 분류됩니다. 이와 대조적으로 operator[]를 통한 인덱스 접근([AP_SWS_SHWA_00009], [AP_SWS_SHWA_00010]) 및 HasProperty([AP_SWS_SHWA_00015])과 GetProperty([AP_SWS_SHWA_00016])를 통한 프로퍼티 질의는 스레드 안전하지 않으며 애플리케이션 측의 동기화가 필요합니다.

사용 경로

일반적인 사용 흐름은 객체 생성, 선택적 프로퍼티 검사, 그리고 버퍼에 대한 후속 읽기 또는 쓰기 작업으로 구성됩니다:

  1. 팩토리를 통한 인스턴스화: 애플리케이션은 Accessor::Create을 호출하고 ara::shwa::Buffer에 대한 참조와 선택적으로 구성 프로퍼티 및 TaskHandler를 전달합니다([AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008]). ara::core::Result를 확인한 후 애플리케이션은 std::unique_ptr<Accessor>을 인계받습니다.
  2. 프로퍼티 평가: 템플릿 메서드 HasProperty<PropertyT>()을 통해 특정 특성이 존재하는지 질의할 수 있습니다([AP_SWS_SHWA_00015]). 존재하는 특성은 이어서 GetProperty<PropertyT>()로 판독됩니다([AP_SWS_SHWA_00016]).
  3. 데이터 접근 실행: 실제 데이터 교환을 위해 두 가지 인터페이스 경로가 제공됩니다:
    • 메서드 기반 접근: 쓰기 작업은 Set(index, value)([AP_SWS_SHWA_00011])을 통해, 읽기 작업은 Get(index)([AP_SWS_SHWA_00012])를 통해 수행되며, 각각 차원 식별자(Id<Dimensions>)를 통해 주소 지정됩니다.
    • 연산자 기반 접근: 인덱스 연산자 operator[]은 Id<Dimensions>([AP_SWS_SHWA_00009]) 또는 std::size_t 타입의 선형 오프셋([AP_SWS_SHWA_00010])을 통한 직접적인 주소 지정을 허용합니다. 반환 타입 ReferenceT는 읽기 접근 시 const DataT&으로, 쓰기 접근 시 DataT&로 확인됩니다([AP_SWS_SHWA_00014]).

시퀀스 다이어그램: Accessor를 통한 버퍼 상호작용의 전형적인 호출 순서. 출처: [AP_SWS_SHWA_00007], [AP_SWS_SHWA_00011], [AP_SWS_SHWA_00012], [AP_SWS_SHWA_00015]

오류 시나리오

오류가 발생한 작업은 ShwaErrorCode의 오류 코드를 사용하여 ara::core::Result를 통해 매핑됩니다:

  • ShwaErrorCode::kAccessorFailure: 생성 조건 또는 파라미터가 유효하지 않은 경우 Create 중에 발생합니다([AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008]).
  • ShwaErrorCode::kIntegrityCorrupted: 버퍼의 손상된 메모리 무결성을 알립니다. 이는 인스턴스화 시([AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008])뿐만 아니라 Set를 통한 쓰기 시([AP_SWS_SHWA_00011])에도 발생할 수 있습니다.
  • ShwaErrorCode::kInvalidIndex: 유효한 초기값이 없거나 인덱스가 범위를 벗어난 경우 Get([AP_SWS_SHWA_00012]) 및 Set([AP_SWS_SHWA_00011])에서 보고됩니다.
  • ShwaErrorCode::kInvalidAccessMode: 접근 모드의 조합이 유효하지 않은 경우 Set에서 발생합니다([AP_SWS_SHWA_00011]). 이는 AccessMode::kRead용으로 인스턴스화된 클래스에 대해 쓰기 호출이 수행될 때 해당될 것으로 추정됩니다.
  • ShwaErrorCode::kResourceBusy: 리소스가 현재 사용 중임을 Get([AP_SWS_SHWA_00012]) 및 Set([AP_SWS_SHWA_00011])에서 나타냅니다. 이 오류에 대해서는 롤백 의미론이 보장되므로 이전 상태가 보존됩니다.
  • ShwaErrorCode::kFeatureNotSupported: GetProperty을 통해 요청된 프로퍼티가 지원되지 않을 때 반환됩니다([AP_SWS_SHWA_00016]).

예외 안전성과 관련하여, Create, HasProperty 및 GetProperty는 noexcept로 선언되어 있으며 예외 안전한 것으로 명세되어 있습니다([AP_SWS_SHWA_00007], [AP_SWS_SHWA_00008], [AP_SWS_SHWA_00015], [AP_SWS_SHWA_00016]). 반면에 데이터 접근 작업인 Get, Set 및 operator[]은 예외 안전하지 않은(not exception safe) 것으로 간주됩니다([AP_SWS_SHWA_00009], [AP_SWS_SHWA_00010], [AP_SWS_SHWA_00011], [AP_SWS_SHWA_00012]).

이 가이드는 AUTOSAR Adaptive Platform R25-11용 ara::shwa::Accessor 명세를 기반으로 하며 자동 생성되었습니다.
