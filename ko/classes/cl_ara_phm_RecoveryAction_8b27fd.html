복구 경로에서의 역할

RecoveryAction PHM이 만료된 글로벌 감독 상태를 보고하는 반환 채널을 상태 관리에 제공합니다. kEXPIRED의 경우 알림에는 기능 그룹 관련 실행 오류와 원인이 되는 감독 유형 [SWS_PHM_00101] SWS PHM §7.5 “Recovery actions”이 포함됩니다.

제안, 응답, 에스컬레이션

Offer는 핸들러 호출을 활성화하고, StopOffer는 비활성화한다. 오류 발생 시 복구가 제공되지 않거나 응답이 제때 오지 않으면 작업이 조용히 계속되지 않다. PHM은 활성 메시지를 중지하고 감시 경로 [SWS_PHM_01147] [SWS_PHM_01148] [SWS_PHM_00104]를 트리거한다.

활동 다이어그램: PHM는 만료된 Global Supervision에 대해 State Management에 알립니다. 누락되거나 처리할 수 없는 응답은 감시 확대 SWS PHM §7.5 “Recovery actions” SWS PHM §7.5.2 “Handling of Hardware Watchdog”로 이어집니다.

이행의 책임

이 Handler는 State Management의 프로젝트별 Recovery 정책에 속한다. 어떤 Function Group이 어떤 상태로 전환되는지는 RecoveryAction의 일반 속성이 아니라 통합 결정이다.
