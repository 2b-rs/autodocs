컨텍스트

클래스 ara::shwa::Id은 AUTOSAR Adaptive Platform의 shwa 모듈 내에서 다차원 인덱싱을 위해 설계된 타입화된 식별자입니다. 클래스 정의는 클래스 템플릿 template <int Dimensions = 1> class Id final로 구현됩니다. 해석: shwa 모듈은 공유 하드웨어 또는 워크로드 구조를 다루며, ara::shwa::Id는 최대 3개 차원에 걸쳐 작업 패키지, 버퍼 또는 데이터 포인트를 고유하게 어드레싱하기 위한 구조화된 좌표 또는 인덱스 키 역할을 할 것으로 추정됩니다.

ara::shwa::Id의 상호작용 대상은 주로 이를 사용하는 어댑티브 애플리케이션 및 shwa 서브시스템의 기능 컴포넌트입니다. 이 클래스는 차원과 인덱스를 캡슐화하므로 상위 처리 함수가 위치 관련 매개변수를 타입 안전하게 전달받을 수 있습니다. 이 클래스는 final로 명시되어 있으므로 상속이 불가능하며, 자체 완결적인 값 타입으로 동작합니다.

수명 주기

ara::shwa::Id 인스턴스의 수명주기는 반드시 정적 팩토리 메서드를 통해 시작됩니다. 기본 생성자는 명시적으로 삭제되어([AP_SWS_SHWA_00702]) 컴파일 시점에 불완전하게 초기화된 인스턴스를 방지합니다. 대신 객체 생성은 오버로드된 Create 메서드를 통해 수행되며, 각 메서드는 ara::core::Result에 래핑된 인스턴스를 반환합니다:

  • Create(const std::size_t dim0)([AP_SWS_SHWA_00707])을 통한 1차원 초기화입니다. 이 변형은 스레드 안전(thread-safe)한 것으로 명시되어 있습니다.
  • Create(std::size_t dim0, std::size_t dim1)([AP_SWS_SHWA_00708])을 통한 2차원 초기화입니다. 이 변형은 스레드 안전하지 않은 것으로 선언되어 있습니다.
  • Create(std::size_t dim0, std::size_t dim1, std::size_t dim2)([AP_SWS_SHWA_00709])을 통한 3차원 초기화입니다. 이 변형 역시 스레드 안전하지 않은 것으로 선언되어 있습니다.

소유권 및 복사 모델과 관련하여 ara::shwa::Id은(는) 일반적인 값 타입처럼 동작합니다. 복사 생성자([AP_SWS_SHWA_00703])와 복사 대입 연산자([AP_SWS_SHWA_00704])는 noexcept=default(으)로 정의되어 완전한 예외 안전성(Exception Safe)을 보장합니다. 마찬가지로 이동 생성자([AP_SWS_SHWA_00705])와 이동 대입 연산자([AP_SWS_SHWA_00706])도 noexcept=default(으)로 제공됩니다. 따라서 인스턴스를 효율적으로 이동 및 복사할 수 있으며 표준 컨테이너에 보관할 수 있습니다. 유효 범위를 벗어나면 인스턴스는 자동으로 소멸되며, 추가적인 정리 또는 소멸 단계는 지정되어 있지 않습니다.

동시성과 관련하여, 기존 인스턴스에 대한 Get([AP_SWS_SHWA_00710]) 및 Set([AP_SWS_SHWA_00711])를 통한 읽기 및 쓰기 접근은 사양에 따라 스레드 안전하지 않다는 점에 유의해야 합니다. 여러 실행 스레드가 동일한 인스턴스를 수정하거나 동시에 읽고 쓰는 경우, 호출자가 외부 동기화를 제공해야 합니다.

사용 경로

일반적인 사용 경로는 팩토리 함수 중 하나를 통한 인스턴스화, ara::core::Result의 평가, 개별 차원 값의 선택적 조정 및 인덱스 조회를 포함합니다.

  1. 생성: 애플리케이션은 예를 들어 ara::shwa::Id::Create(dim0)([AP_SWS_SHWA_00707]) 또는 다차원 오버로드([AP_SWS_SHWA_00708], [AP_SWS_SHWA_00709]) 중 하나를 호출합니다.
  2. 결과 검사: 반환된 ara::core::Result<Id>에 오류가 없는지 검사합니다(예: HasValue() 사용). 성공하면 인스턴스를 언패킹합니다.
  3. 수정: Set(dimension, index)([AP_SWS_SHWA_00711])을 통해 특정 차원의 인덱스를 선택적으로 업데이트할 수 있습니다.
  4. 조회: 애플리케이션은 Get(dimension)([AP_SWS_SHWA_00710])을 사용하여 지정된 차원의 저장된 인덱스를 조회합니다.

시퀀스 다이어그램: Id 인스턴스의 생성, 수정 및 조회의 전형적인 흐름. 출처: [AP_SWS_SHWA_00707], [AP_SWS_SHWA_00710], [AP_SWS_SHWA_00711]

오류 시나리오

객체 생성 중 오류 상황은 C++ 예외 없이 AUTOSAR 표준 패턴 ara::core::Result을 통해 전달됩니다. Create 메서드는 "exception safe" 예외 등급을 가지며 noexcept(으)로 선언되어 있습니다([AP_SWS_SHWA_00707], [AP_SWS_SHWA_00708], [AP_SWS_SHWA_00709]). 오류가 발생한 경우 반환값에 오류 코드가 포함됩니다:

  • ShwaErrorCode::kRuntime: 팩토리 실행 중 일반적인 런타임 오류(General runtime error). 이 경우 롤백 시맨틱이 적용되어 유효하지 않은 인스턴스가 남지 않습니다.

요소 접근 메서드 Get([AP_SWS_SHWA_00710]) 및 Set([AP_SWS_SHWA_00711])에 대해 사양에서는 "not exception safe" 등급을 명시합니다. 유효하지 않은 매개변수 값은 런타임 오류로 이어질 수 있으므로, 호출자는 dimension(으)로 객체의 차원 크기 내에 있는 유효한 차원 인덱스가 전달되도록 보장해야 합니다.

이 가이드는 AUTOSAR Adaptive Release R25-11의 사양 요구사항만을 기반으로 합니다.

  <h4>컨텍스트</h4>
  <p>
    클래스 <code>ara::shwa::Id</code>은 AUTOSAR Adaptive Platform의 <code>shwa</code> 모듈 내에서 다차원 인덱싱을 위해 설계된 타입화된 식별자입니다. 클래스 정의는 클래스 템플릿 <code>template &lt;int Dimensions = 1&gt; class Id final</code>로 구현됩니다. 해석: <code>shwa</code> 모듈은 공유 하드웨어 또는 워크로드 구조를 다루며, <code>ara::shwa::Id</code>는 최대 3개 차원에 걸쳐 작업 패키지, 버퍼 또는 데이터 포인트를 고유하게 어드레싱하기 위한 구조화된 좌표 또는 인덱스 키 역할을 할 것으로 추정됩니다.
  </p>
  <p>
    <code>ara::shwa::Id</code>의 상호작용 대상은 주로 이를 사용하는 어댑티브 애플리케이션 및 <code>shwa</code> 서브시스템의 기능 컴포넌트입니다. 이 클래스는 차원과 인덱스를 캡슐화하므로 상위 처리 함수가 위치 관련 매개변수를 타입 안전하게 전달받을 수 있습니다. 이 클래스는 <code>final</code>로 명시되어 있으므로 상속이 불가능하며, 자체 완결적인 값 타입으로 동작합니다.
  </p>

  <h4>수명 주기</h4>
  <p>
    <code>ara::shwa::Id</code> 인스턴스의 수명주기는 반드시 정적 팩토리 메서드를 통해 시작됩니다. 기본 생성자는 명시적으로 삭제되어(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00702" href="../spec/record.html?id=AP_SWS_SHWA_00702">[AP_SWS_SHWA_00702]</a>) 컴파일 시점에 불완전하게 초기화된 인스턴스를 방지합니다. 대신 객체 생성은 오버로드된 <code>Create</code> 메서드를 통해 수행되며, 각 메서드는 <code>ara::core::Result</code>에 래핑된 인스턴스를 반환합니다:
  </p>
  <ul>
    <li><code>Create(const std::size_t dim0)</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00707" href="../spec/record.html?id=AP_SWS_SHWA_00707">[AP_SWS_SHWA_00707]</a>)을 통한 1차원 초기화입니다. 이 변형은 스레드 안전(thread-safe)한 것으로 명시되어 있습니다.</li>
    <li><code>Create(std::size_t dim0, std::size_t dim1)</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00708" href="../spec/record.html?id=AP_SWS_SHWA_00708">[AP_SWS_SHWA_00708]</a>)을 통한 2차원 초기화입니다. 이 변형은 스레드 안전하지 않은 것으로 선언되어 있습니다.</li>
    <li><code>Create(std::size_t dim0, std::size_t dim1, std::size_t dim2)</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00709" href="../spec/record.html?id=AP_SWS_SHWA_00709">[AP_SWS_SHWA_00709]</a>)을 통한 3차원 초기화입니다. 이 변형 역시 스레드 안전하지 않은 것으로 선언되어 있습니다.</li>
  </ul>
  <p>
    소유권 및 복사 모델과 관련하여 <code>ara::shwa::Id</code>은(는) 일반적인 값 타입처럼 동작합니다. 복사 생성자(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00703" href="../spec/record.html?id=AP_SWS_SHWA_00703">[AP_SWS_SHWA_00703]</a>)와 복사 대입 연산자(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00704" href="../spec/record.html?id=AP_SWS_SHWA_00704">[AP_SWS_SHWA_00704]</a>)는 <code>noexcept=default</code>(으)로 정의되어 완전한 예외 안전성(Exception Safe)을 보장합니다. 마찬가지로 이동 생성자(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00705" href="../spec/record.html?id=AP_SWS_SHWA_00705">[AP_SWS_SHWA_00705]</a>)와 이동 대입 연산자(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00706" href="../spec/record.html?id=AP_SWS_SHWA_00706">[AP_SWS_SHWA_00706]</a>)도 <code>noexcept=default</code>(으)로 제공됩니다. 따라서 인스턴스를 효율적으로 이동 및 복사할 수 있으며 표준 컨테이너에 보관할 수 있습니다. 유효 범위를 벗어나면 인스턴스는 자동으로 소멸되며, 추가적인 정리 또는 소멸 단계는 지정되어 있지 않습니다.
  </p>
  <p>
    동시성과 관련하여, 기존 인스턴스에 대한 <code>Get</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00710" href="../spec/record.html?id=AP_SWS_SHWA_00710">[AP_SWS_SHWA_00710]</a>) 및 <code>Set</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00711" href="../spec/record.html?id=AP_SWS_SHWA_00711">[AP_SWS_SHWA_00711]</a>)를 통한 읽기 및 쓰기 접근은 사양에 따라 스레드 안전하지 않다는 점에 유의해야 합니다. 여러 실행 스레드가 동일한 인스턴스를 수정하거나 동시에 읽고 쓰는 경우, 호출자가 외부 동기화를 제공해야 합니다.
  </p>

  <h4>오류 시나리오</h4>
  <p>
    객체 생성 중 오류 상황은 C++ 예외 없이 AUTOSAR 표준 패턴 <code>ara::core::Result</code>을 통해 전달됩니다. <code>Create</code> 메서드는 "exception safe" 예외 등급을 가지며 <code>noexcept</code>(으)로 선언되어 있습니다(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00707" href="../spec/record.html?id=AP_SWS_SHWA_00707">[AP_SWS_SHWA_00707]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00708" href="../spec/record.html?id=AP_SWS_SHWA_00708">[AP_SWS_SHWA_00708]</a>, <a class="spec-record-ref" data-req="AP_SWS_SHWA_00709" href="../spec/record.html?id=AP_SWS_SHWA_00709">[AP_SWS_SHWA_00709]</a>). 오류가 발생한 경우 반환값에 오류 코드가 포함됩니다:
  </p>
  <ul>
    <li>
      <code>ShwaErrorCode::kRuntime</code>: 팩토리 실행 중 일반적인 런타임 오류(General runtime error). 이 경우 롤백 시맨틱이 적용되어 유효하지 않은 인스턴스가 남지 않습니다.
    </li>
  </ul>
  <p>
    요소 접근 메서드 <code>Get</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00710" href="../spec/record.html?id=AP_SWS_SHWA_00710">[AP_SWS_SHWA_00710]</a>) 및 <code>Set</code>(<a class="spec-record-ref" data-req="AP_SWS_SHWA_00711" href="../spec/record.html?id=AP_SWS_SHWA_00711">[AP_SWS_SHWA_00711]</a>)에 대해 사양에서는 "not exception safe" 등급을 명시합니다. 유효하지 않은 매개변수 값은 런타임 오류로 이어질 수 있으므로, 호출자는 <code>dimension</code>(으)로 객체의 차원 크기 내에 있는 유효한 차원 인덱스가 전달되도록 보장해야 합니다.
  </p>
