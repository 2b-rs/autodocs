UDS 0x27의 확장 지점

SecurityAccess는 UDS 서비스 0x27에 대한 애플리케이션별 시드/키 논리를 캡슐화한다. 진단 서버는 요청 검증, 대화 및 권한 부여 컨텍스트를 인계받아 시드 요청 또는 키 비교 SWS Diagnostics §7.3.2.8.9 “SecurityAccess”를 위해 제공되는 인터페이스를 호출한다. 따라서 애플리케이션은 UDS 전송 응답이 아닌 기술 검사를 구현한다.

DM은 서비스 0x27에 대해 두 가지 애플리케이션 구현 단계를 호출합니다. 둘 다 결과를 비동기식으로 전달합니다. 출처: SWS Diagnostics §7.3.2.8.9 “SecurityAccess”, [SWS_DM_00764], [SWS_DM_00765], [SWS_DM_01345].

비동기식 구현

GetSeed는 보안 접속 데이터 기록을 수신하여 바이트 벡터를 전달하고, CompareKey는 키를 수신하여 KeyCompareResultType [SWS_DM_00764] [SWS_DM_00765]를 전달합니다. 두 방법 모두 MetaInfo 및 CancellationHandler를 얻습니다. 콜백은 future를 정확히 한 번 완료하거나 CancellationHandler를 존중해야 합니다. 제공된 범위 및 MetaInfo는 콜백 [SWS_DM_01345]에서만 유효합니다.

책임의 한계

세션 및 보안 검사는 DM UDS 서비스 처리의 일부입니다. 따라서 구현자는 구성된 보안 수준만 확인하고 명확한 비교 결과를 제공해야 합니다. 긍정적 또는 부정적 UDS 응답 할당과 보안 이벤트 기록은 진단 서버 SWS Diagnostics §7.5.1 “Security Events”에 유지됩니다.
