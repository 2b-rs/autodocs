자동으로 생성된 설명, 참조된 AUTOSAR R25-11 문서(SWS 사양 및 관련 표준 문서)에서 파생된 콘텐츠 — 공식 AUTOSAR 텍스트가 아닙니다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

사용 목적

ara::core::Span<T, Extent>는 관련 요소의 보기로 std::span를 구현한다. Extent는 정적 또는 동적 [SWS_CORE_01900] [SWS_CORE_01931]일 수 있다.

창조와 파괴

Span은 포인터, C 배열, ara::core::Array, 호환되는 Container 또는 다른 Span으로부터 생성할 수 있다 [SWS_CORE_01942] [SWS_CORE_01943] [SWS_CORE_01944] [SWS_CORE_01945] [SWS_CORE_01947] [SWS_CORE_01950]. Copy 생성, Copy 대입 및 소멸자는 defaulted 및 exception-safe이다 [SWS_CORE_01949] [SWS_CORE_01952] [SWS_CORE_01951].

수명주기 & 소유권

클래스는 기본 요소가 아닌 뷰를 저장한다. 인터페이스는 [SWS_CORE_01915] [SWS_CORE_01916] [SWS_CORE_01917] [SWS_CORE_01971]에 액세스하기 위한 포인터, 참조 및 반복자를 제공한다. 참조된 요소의 유효성은 이 클래스에서 관리되지 않다.

다른 클래스와의 상호작용

first(), last() 및 subspan()는 부분 뷰를 생성한다. size() 및 size_bytes()는 해당 범위 [SWS_CORE_01961] [SWS_CORE_01962] [SWS_CORE_01963] [SWS_CORE_01964] [SWS_CORE_01965] [SWS_CORE_01966] [SWS_CORE_01967] [SWS_CORE_01968]를 나타냅니다.

제한 사항 및 오류 처리

지정된 작업은 constexpr, noexcept 및 exception-safe [SWS_CORE_01960] [SWS_CORE_01970] [SWS_CORE_01969]이다. 사양은 operator[], front() 또는 back() [SWS_CORE_01959] [SWS_CORE_01960] [SWS_CORE_01970]의 제한에 대한 자체 런타임 검사를 정의하지 않는다.

관련 데이터의 비소유 보기

Core는 Span를 뷰 유형으로 분류하므로 개념적으로 C++ 표준 라이브러리를 기반으로 합니다. 유형은 요소의 소유권이 아닌 보기를 ​​전달합니다. 따라서 기존 API 블록에 설명된 포인터, 참조 및 반복자 액세스에는 여전히 유효한 기본 시퀀스가 ​​필요합니다. SWS Core §7.4 “Core data types” SWS Core §7.4.2 “Data types derived from the C++ standard”

Interpretation: Span는 연속 영역을 전송해야 하지만 복사되거나 소유권이 변경되지 않는 인터페이스에 적합한다. 이 분류는 SWS 분류를 뷰로, API 형식을 요소 뷰로 따릅니다.
