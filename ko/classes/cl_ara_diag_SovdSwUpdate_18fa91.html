컨텍스트

ara::diag::SovdSwUpdate 클래스는 ASAM SOVD 및 ISO 17978-3에 따른 Service-Oriented Vehicle Diagnostics(SOVD) 프로토콜을 통한 소프트웨어 업데이트 처리를 위한 인터페이스를 형성합니다 ([SWS_DM_01874], [SWS_DM_01796]). AUTOSAR Adaptive Platform 내에는 명확한 기능적 역할 분담이 존재합니다: 소프트웨어 업데이트를 수행하고 관리하는 실제 비즈니스 로직은 어댑티브 애플리케이션에 유지되는 반면, 기능 클러스터인 Diagnostics(Diagnostic Server Instance 또는 Diagnostic Management)는 기반이 되는 SOVD 프로토콜의 처리를 담당합니다 (AUTOSAR_AP_SWS_Diagnostics §7.3 “Figure 7.4: SOVD Software Update API”).

추상 기본 클래스로서 SovdSwUpdate은(는) 애플리케이션 소프트웨어에서 구현해야 하는 콜백 인터페이스를 정의합니다. 외부 SOVD 클라이언트의 수신 요청은 Diagnostic Server Instance에 의해 분석되며 SovdSwUpdate의 해당 메서드를 통해 애플리케이션으로 위임됩니다 (AUTOSAR_AP_SWS_Diagnostics §7.3 “SOVD Software Update API”).

컨텍스트 다이어그램: SOVD 소프트웨어 업데이트 시 상호작용 파트너 및 역할 분담. 출처: [SWS_DM_01796], [SWS_DM_01874], AUTOSAR_AP_SWS_Diagnostics §7.3 “Figure 7.4: SOVD Software Update API”

수명 주기

애플리케이션 고유 인스턴스 생성은 인스턴스 식별자(ara::core::InstanceSpecifier) 및 원하는 동시성 모델(ConcurrencyType)을 지정하여 매개변수화된 생성자를 통해 이루어집니다 ([SWS_DM_01910]). 이때 InstanceSpecifier은(는) 소프트웨어 매니페스트에 선언되고 DiagnosticSovdUpdateInterface(으)로 형식화되어야 하는 PortPrototype을(를) 참조합니다 ([SWS_DM_01910]). concurrencyType을(를) 통해 인스턴스의 콜백 메서드가 동시 요청 시 스레드 안전(kConcurrent)하게 호출될지, 아니면 순차적 또는 비스레드 안전(kNotConcurrent)하게 호출될지 정의됩니다 ([SWS_DM_01910]).

SovdSwUpdate의 인스턴스는 서비스 포트에 일대일로 바인딩됩니다. 따라서 복사 생성자 및 할당 연산자는 명시적으로 삭제되었습니다 (=delete) ([SWS_DM_01912], [SWS_DM_01914]). 이동 연산은 보호(protected)로 정의됩니다 (protected) ([SWS_DM_01913], [SWS_DM_01915]).

초기화가 성공적으로 완료된 후 애플리케이션은 Offer()을(를) 사용하여 서비스를 명시적으로 활성화해야 합니다 ([SWS_DM_01924]). 이 호출이 이루어져야만 Diagnostic Manager(DM)가 수신된 SOVD 요청을 등록된 핸들러 메서드로 전달합니다. 핸들러 객체가 소멸되기 전에 요청의 추가 전달을 방지하기 위해 StopOffer()을(를) 통해 서비스 등록을 취소해야 합니다 ([SWS_DM_01925]). 해제 작업은 가상 소멸자 ~SovdSwUpdate()을(를) 통해 완료됩니다 ([SWS_DM_01911]).

사용 경로

전형적인 운영 워크플로는 소프트웨어 업데이트의 여러 연속적인 단계로 구성됩니다:

  1. Dienstangebot: 애플리케이션은 SovdSwUpdate의 파생 클래스를 인스턴스화하고 Offer()을(를) 호출합니다 ([SWS_DM_01924]).
  2. Paketregistrierung und Transfer: Diagnostic Server는 SOVD 클라이언트의 수신 등록 요청을 RequestUpdatePackageRegistration()(으)로 전달합니다 ([SWS_DM_01923]). 이 메서드는 쓰기 세션(DataTransferWriteSession)과 고유 패키지 식별자(updatePackageId)의 튜플이 포함된 ara::core::Future을(를) 반환합니다 ([SWS_DM_01923]). 해석: 업데이트 페이로드의 실제 데이터 전송은 이 제공된 쓰기 세션을 통해 처리될 것으로 보입니다 (AUTOSAR_AP_SWS_Diagnostics §7.3 “Figure 7.4: SOVD Software Update API”).
  3. Paketvorbereitung: 설치 준비를 위해 Diagnostic Server는 PrepareUpdatePackage()을(를) 호출합니다 ([SWS_DM_01800], [SWS_DM_01919]). 대안으로 PutUpdatePackageAutomated()을(를) 통해 자동화된 설치를 시작할 수 있습니다 ([SWS_DM_01799], [SWS_DM_01918]).
  4. 패키지 실행: 준비된 업데이트 패키지의 설치는 ExecuteUpdatePackage() 호출을 통해 시작됩니다([SWS_DM_01801], [SWS_DM_01920]).
  5. Statusabfrage und Inspektion: 진행 중 또는 진행 후에 세부 정보와 상태를 GetUpdatePackageStatus() ([SWS_DM_01802], [SWS_DM_01921]), GetUpdatePackageDetails() ([SWS_DM_01917])을(를) 통해, 또는 전체 목록을 GetAllUpdates() ([SWS_DM_01797], [SWS_DM_01916])를 통해 조회할 수 있습니다. 더 이상 필요하지 않은 패키지는 DeleteUpdatePackage()을(를) 통해 제거됩니다 ([SWS_DM_01922]).

시퀀스 다이어그램: 업데이트 패키지의 등록, 설치 및 상태 조회를 위한 상호작용 패턴. 출처: [SWS_DM_01800], [SWS_DM_01801], [SWS_DM_01802], [SWS_DM_01919], [SWS_DM_01920], [SWS_DM_01921], [SWS_DM_01923], [SWS_DM_01924]

오류 시나리오

오류 조건은 구성 및 모델링 오류, 서비스 상태 오류, 프로토콜 고유 실행 오류로 구분됩니다:

  • Modell- und Instanziierungsfehler: InstanceSpecifier의 확인에 실패하거나 이것이 부적절한 요소를 가리키는 경우 특정 런타임 위반(Violations)이 보고됩니다: InstanceSpecifierMappingIntegrityViolation, PortInterfaceMappingViolation, ProcessMappingViolation 및 해당 식별자가 프로세스 내에서 이미 사용 중인 경우 InstanceSpecifierAlreadyInUseViolation이(가) 보고됩니다 ([SWS_DM_01910]).
  • Angebotsfehler: Offer() 호출은 ara::core::Result<void>을(를) 반환합니다. 오류 발생 시, 서비스가 이미 제공 중인 경우 DiagOfferErrc::kAlreadyOffered이(가), 구성이 진단 추출(DEXT)과 일치하지 않는 경우 DiagOfferErrc::kConfigurationMismatch이(가) 포함됩니다 ([SWS_DM_01924]).
  • 실행 및 프로토콜 오류: 비동기 콜백 메서드는 결과를 ara::core::Future(으)로 반환합니다. 오류 발생 시 ASAM SOVD 1.1 또는 ISO 17978-3에 따른 적용 가능한 오류 코드를 Future에 설정해야 합니다([SWS_DM_01917], [SWS_DM_01918], [SWS_DM_01919], [SWS_DM_01920], [SWS_DM_01921], [SWS_DM_01922], [SWS_DM_01923]).
  • Abbruchbehandlung: 모든 비동기 메서드에 CancellationHandler이(가) 전달됩니다. 조기에 중단된 클라이언트 대화를 정상적으로 종료하기 위해 이를 폴링하는 것은 애플리케이션의 책임입니다 ([SWS_DM_01919], [SWS_DM_01920]).
