클래스 ara::idsm::TimestampProvider

이 페이지는 SWS IntrusionDetectionSystemManager(R25-11)를 기반으로 완전히 AI로 생성되었다. 공식 AUTOSAR 텍스트도 없고 나머지 모듈처럼 자동으로 추출된 API 페이지도 없다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

사용자 가이드 AI 생성 / AI generated

자동으로 생성된 설명, 참조된 AUTOSAR R25-11 문서(SWS 사양 및 관련 표준 문서)에서 파생된 콘텐츠 — 공식 AUTOSAR 텍스트가 아닙니다. 해석으로 표시된 진술은 출처에서 도출된 결론이다.

분류

TimestampProvider를 사용하면 IdsM이 애플리케이션에서 제공하는 타임스탬프를 얻을 수 있다. SWS IdsM §8.8; [SWS_AIDSM_00804].

해석: 이 클래스는 지정된 포트 및 수명 주기 경계를 따라 사용해야 하며, API 자체는 완전한 애플리케이션 아키텍처를 정의하지 않는다.
