클래스 ara::exec::StateClient

[SWS_EM_02275] Upstream: RS_EM_00101, RS_AP_00154, RS_AP_00150

class StateClient final {...};

ara::exec::StateClient is an interface of Execution Management that is used by State Management to request transitions between Function Group States or to perform other related operations. Class used to perform Function Group state management operation needed during lifetime of a Machine. State Management during its own lifetime will need to start and stop software, that is intended to run on a Machine managed by it. This can be achieved by performing state transition of a Function Group to which required software is assigned. Integrator will assign software to run in a particular state (of Function Group) and State Management can start it, by requesting Execution Management to perform state transition (of this Function Group) to the mentioned state. Execution Management will then start mentioned software and report transition result back to State Management. Please note that stopping software can be done in similar way (i.e. Function Group state transition, to a state in which software is not configured to be run).

Machine에서 프로세스를 제어하기 위해 Execution Management에 함수 그룹의 상태 전환을 요청합니다.

인터페이스 ara::exec::StateClient은 State Management가 Machine에서 할당된 프로세스의 실행을 제어하기 위해 Execution Management에 함수 그룹의 상태 전환을 요청할 수 있도록 합니다 [SWS_EM_02278]. Create()를 통한 생성 시 예기치 않은 정의되지 않은 상태에 대한 지속적으로 유효한 콜백을 등록해야 합니다 [SWS_EM_02276]. 복사 불가능한 이 클래스는 비동기 상태 전환 외에도 Machine 시동 결과 쿼리 및 실행 오류에 대한 오류 분석 메서드를 제공합니다 [SWS_EM_02279], [SWS_EM_02542].

컨텍스트

ara::exec::StateClient 클래스는 State Management가 함수 그룹(Function Groups)의 상태 전환을 요청하고 제어하는 Execution Management의 인터페이스를 형성합니다. State Management는 Machine의 전체 작동 시간 동안 이 클라이언트를 사용하여 프로세스를 선택적으로 시작하거나 중지합니다. 통합자는 소프트웨어 컴포넌트를 함수 그룹의 특정 상태에 할당합니다. State Management가 이 소프트웨어를 실행하려는 경우 StateClient을 통해 Execution Management에 해당 함수 그룹 상태로의 전환을 요청하며; 중지는 소프트웨어가 활성화되지 않아야 하는 상태로 전환함으로써 유사하게 수행됩니다 [SWS_EM_02278].

컨텍스트 다이어그램: State Management, StateClient 및 Execution Management 간의 상호작용. 출처: [SWS_EM_02276], [SWS_EM_02278]

수명 주기

StateClient의 인스턴스는 ara::core::Result<StateClient>으로서 명명된 생성자 Create() [SWS_EM_02276]을 통해 생성되거나 정규 생성자 StateClient() [SWS_EM_02561]를 통해 생성될 수 있습니다. 두 생성 경로 모두 std::function<void(const ara::exec::ExecutionErrorEvent&)> 유형의 콜백 매개변수 undefinedStateCallback을 반드시 요구합니다. 이 콜백은 SetState()에 의한 사전 요청 없이 함수 그룹이 예기치 않게 정의되지 않은 상태로 전환될 때 StateClient 라이브러리에 의해 트리거됩니다. 호출자는 이 콜백이 StateClient 인스턴스의 전체 수명 동안 호출 가능한 상태를 유지하도록 보장해야 하며, 이는 std::bind을 통한 객체 바인딩 시 특히 중요합니다 [SWS_EM_02276], [SWS_EM_02561].

StateClient에 대한 복사 연산은 명시적으로 금지됩니다: 복사 생성자 [SWS_EM_02565]과 복사 대입 연산자 [SWS_EM_02568]이 모두 삭제되었습니다(=delete). 소유권 이전은 이동 생성자 [SWS_EM_02566] 및 이동 대입 [SWS_EM_02567]을 통한 이동 시맨틱을 통해서만 가능합니다. 동시성과 관련하여 SetState(), GetExecutionError(), GetInitialMachineStateTransitionResult()과 같은 기능 메서드 및 생성은 스레드 안전하도록 설계되었습니다 [SWS_EM_02276], [SWS_EM_02278], [SWS_EM_02279], [SWS_EM_02542]. 반면 이동 연산과 소멸자 ~StateClient()은 스레드 안전하지 않습니다 [SWS_EM_02277], [SWS_EM_02566], [SWS_EM_02567].

사용 경로

일반적인 애플리케이션 주기는 초기화, 시동 결과 쿼리, 정규 상태 전환 및 오류 모니터링으로 나뉩니다:

  1. 생성: State Management는 Create()을 통해 유효한 오류 신호 콜백을 지정하여 StateClient을 인스턴스화합니다 [SWS_EM_02276].
  2. 초기 시동 결과 쿼리: State Management는 GetInitialMachineStateTransitionResult()을 사용하여 Startup 상태로의 초기 상태 전환 결과를 요청합니다 [SWS_EM_02279]. 이 전환은 Machine의 라이프사이클당 정확히 한 번 발생하므로 반환된 ara::core::Future<void>은 안정적으로 유지되며 재부팅할 때까지 더 이상 변경되지 않습니다.
  3. 상태 전환 요청: State Management는 SetState()을 사용하여 개별 함수 그룹에 대한 비동기 상태 전환을 지시합니다 [SWS_EM_02278]. 이 메서드는 즉시 반환되며 완료 여부를 쿼리하기 위한 ara::core::Future<void>을 제공합니다. 명령이 Execution Management에 수신되면 호출 인스턴스의 추가 수명과 관계없이 실행됩니다.
  4. 오류 상태 조사: 함수 그룹이 예기치 않게 정의되지 않은 상태가 되는 경우 GetExecutionError()을 통해 ara::exec::ExecutionErrorEvent 형식으로 원인이 된 실행 오류를 확인할 수 있습니다 [SWS_EM_02542].

시퀀스 다이어그램: 생성, 시작 상태 쿼리, 비동기 상태 전환 및 오류 분석 흐름. 출처: [SWS_EM_02276], [SWS_EM_02279], [SWS_EM_02278], [SWS_EM_02542]

오류 시나리오

클래스의 연산은 ExecErrorDomain의 오류 코드를 통해 실패를 전달합니다:

  • ExecErrc::kNoCommunication: 예를 들어 IPC 연결이 끊어진 경우와 같이 Execution Management와의 통신 장애를 나타냅니다. Create() [SWS_EM_02276], SetState() [SWS_EM_02278], GetInitialMachineStateTransitionResult() [SWS_EM_02279] 및 GetExecutionError() [SWS_EM_02542]에서 발생합니다. 계획된 복구 조치는 재호출입니다.
  • ExecErrc::kInvalidArgument: 전달된 콜백에 호출 가능한 함수가 포함되어 있지 않은 경우 Create() 및 StateClient()에 의해 보고됩니다 [SWS_EM_02276], [SWS_EM_02561].
  • ExecErrc::kOperationCanceled: SetState()에서 진행 중인 전환이 새로운 요청에 의해 취소되었음을 나타냅니다 [SWS_EM_02278]. GetInitialMachineStateTransitionResult()의 경우 중단된 Machine 업데이트 시퀀스 등으로 인해 초기 시작 전환이 취소된 경우 이 오류가 발생합니다 [SWS_EM_02279].
  • ExecErrc::kInvalidTransition: 요청된 상태 전환이 허용되지 않거나(예: MachineFG의 Off 상태로의 전환), 업데이트 후 해당 상태가 더 이상 존재하지 않습니다 [SWS_EM_02278].
  • ExecErrc::kInvalidMetaModelIdentifier: 전달된 상태가 처리된 매니페스트에 존재하지 않거나 프로세스에 해당 함수 그룹에 대한 매핑이 없습니다 [SWS_EM_02278], [SWS_EM_02542]. GetInitialMachineStateTransitionResult()에서 이 오류가 발생하면 프로세스에 MachineFG에 대한 매핑이 누락된 것이며, 이는 구성 문제를 나타냅니다 [SWS_EM_02279].
  • ExecErrc::kOperationFailed: 전환에 실패했습니다 [SWS_EM_02278]. GetExecutionError()의 경우 이 코드는 함수 그룹이 정의되지 않은 상태에 있지 않으며 문제가 이미 해결되었을 가능성이 있음을 나타냅니다 [SWS_EM_02542].
  • ExecErrc::kIntegrityOrAuthenticityCheckFailed 및 ExecErrc::kUnexpectedTermination: 무결성 검사 실패 또는 전환 중 예기치 않은 프로세스 종료로 인한 SetState() 동안의 특정 실패입니다 [SWS_EM_02278].

이 가이드는 AUTOSAR Adaptive R25-11의 사양 요구사항만을 기반으로 한다.

정적 팩토리 메서드 Create는 ara::exec::StateClient의 인스턴스를 생성하기 위한 네임드 생성자(Named Constructor) 역할을 합니다([SWS_EM_02276]). 필수 매개변수로 undefinedStateCallback이(가) 전달됩니다. 이 콜백은 기능 그룹이 예기치 않게(즉, SetState()을(를) 통한 사전 요청 없이) 정의되지 않은 상태로 전환될 때 클라이언트 라이브러리에 의해 트리거됩니다([SWS_EM_02276]). 이때 영향을 받는 기능 그룹과 오류는 ExecutionErrorEvent을(를) 통해 콜백으로 전달됩니다.

호출 컨텍스트 및 수명과 관련하여 다음과 같은 고정된 제약 조건이 적용됩니다:

  • 이 함수는 thread-safe, exception-safe하며 noexcept(으)로 선언되어 있습니다([SWS_EM_02276]).
  • 전달된 undefinedStateCallback은(는) 생성된 StateClient 인스턴스의 전체 수명 동안 호출 가능한 상태를 유지해야 합니다([SWS_EM_02276]). 이는 (예를 들어 std::bind을(를) 통한) 객체 인스턴스로의 바인딩 시 각별한 주의를 필요로 합니다.

인스턴스화는 동기식으로 수행되며 ara::core::Result<StateClient>을(를) 반환합니다([SWS_EM_02276]). 오류 발생 시 다음과 같은 오류 코드가 정의되어 있습니다:

  • ara::exec::ExecErrc::kInvalidArgument: 전달된 인수에 호출 가능한 함수가 포함되어 있지 않을 때 보고됩니다(롤백 시맨틱, 유효한 함수를 제공하여 해결)([SWS_EM_02276]).
  • ara::exec::ExecErrc::kNoCommunication: 통신 오류를 알립니다(No-Rollback 시맨틱, 재시도를 통해 해결)([SWS_EM_02276]). 이는 실행 환경과의 연결 설정 실패에 기인한 것으로 보입니다.

이 생성 패턴은 네임드 생성자를 통해 필수 콜백과 함께 생성되는 ara::exec::ExecutionClient([SWS_EM_02562])과 같은 관련 실행 클라이언트의 초기화 접근 방식과 구조적으로 일치합니다.

이 사용 지침은 AUTOSAR R25-11 사양 데이터를 기반으로 자동 생성되었습니다.
