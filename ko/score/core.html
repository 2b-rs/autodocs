Core Execution Environment

component Core Execution Environment

S-Core Core Execution Environment는 모든 Eclipse S-Core 서비스에 대한 기본 OS 추상화, POSIX 런타임 보장, 컨테이너 기술, 프로세스 권한 모델 및 코딩 표준을 정의한다.

Execution Architecture & Key Requirements

릴리스 Pin v0.6.0에서 다음 요구사항이 추출되었으며 S-Core 큐레이션 수명 주기를 통해 관리된다:

요구사항 ID범주안전 / 보안설명
aou_req__platform__posix_operating_system플랫폼 / 운영체제안전: QMIEEE Std 1003.1(POSIX), 2004년판 이상을 준수하는 기본 운영체제가 필요하다.
stkh_req__hardware_support__container_tech컨테이너 / 하드웨어보안: YES워크로드 억제를 위해 cgroups, 보안 정책(secpol) 및 네임스페이스를 포함한 Linux 커널 격리 메커니즘이 필요하다.
aou_req__os__cxx_preference운영체제 / 런타임ASIL B / 보안컴포넌트는 레거시 C API보다 ISO C++ 표준 라이브러리 인터페이스를 선호해야 하며, 동일한 기능에 대한 혼합 호출을 금지한다.
aou_req__os__minimal_privileges보안 / 운영체제보안: YES최소 권한의 원칙을 적용하여 프로세스가 초기화 후 불필요한 기능을 삭제하도록 요구한다.
aou_req__os__nonroot보안 / 프로세스보안: YES애플리케이션 컴포넌트는 격리된 UID/GID 네임스페이스를 가진 비특권 비루트 사용자로 실행되어야 한다.
aou_req__os__public_api아키텍처안전: QM공용 API 헤더와 비공개 구현 장치 간에 엄격한 인터페이스 경계 캡슐화를 적용한다.

릴리스 Pin v0.6.0에서 추출된 총 220개의 사양 요소이다. S-Core Curation Review Portal에서 완전한 큐레이션 및 검증이 진행된다.
