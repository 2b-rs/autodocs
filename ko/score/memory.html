자동으로 생성된 설명이다. 인용된 S-Core 후보는 릴리스 Pin v0.6.0(커밋 db1f5bb87ad7f41b40b6aca4b96a889d8798735e)에서 발췌되었으며 큐레이션 트리에서 검증되지 않은 것으로 표시된다. 확인된 릴리스가 아니다. 공식 Eclipse S-Core 텍스트가 아니다.

검증되지 않은 후보 doc__persistency_architecture는 :safety: ASIL_B가 포함된 ID doc__persistency_architecture의 문서 헤더 “Persistency KVS Feature Architecture”이다. 큐레이션 트리에 포함된 텍스트는 문서 속성으로 끝난다. API, 커밋 프로토콜 또는 오류 코드는 여기에 지정되어 있지 않다.

해석: 키-값 저장소라는 제목이 트랜잭션 업데이트를 입증하지는 않는다. 원자성, 커밋 및 롤백은 추출된 헤더에 명시되어 있지 않으며 보충되지 않는다.

해석: 단일 KVS 기능 문서는 해당 핀의 모든 영구 스토리지가 동일한 인터페이스를 통해 실행된다는 증거가 아니다. “통합 지속성(Unified persistence)”은 발췌본의 범위를 벗어난 해석이다.

큐레이션에서 확인

component Persistence & Memory

S-Core Persistence & Memory 컴포넌트는 복원력 있는 비휘발성 데이터 스토리지, POSIX 키-값 스토리지 데이터베이스, 블록 스토리지 인터페이스, 원자적 파일 업데이트 메커니즘 및 플래시 마모도 균등화(Wear-Leveling) 관리를 제공한다.
