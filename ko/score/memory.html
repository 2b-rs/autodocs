Memory & Persistence

component Persistence & Memory

S-Core Persistence & Memory 컴포넌트는 복원력 있는 비휘발성 데이터 스토리지, POSIX 키-값 스토리지 데이터베이스, 블록 스토리지 인터페이스, 원자적 파일 업데이트 메커니즘 및 플래시 마모도 균등화(Wear-Leveling) 관리를 제공한다.

Persistence Architecture & Key Requirements

요구사항 ID범주안전 / 보안설명
feat_req__mem__key_value_store스토리지 엔진안전: QM트랜잭션 지원 및 비정상적인 전원 손실로부터의 자동 복구 기능을 갖춘 원자적 키-값 데이터베이스 스토리지를 구현한다.
feat_req__mem__block_storage블록 I/O안전: QM대용량 스토리지 파티션 및 고주파수 시계열 로깅을 위한 원시 섹터 블록 액세스 추상화를 제공한다.
feat_req__mem__integrity_check데이터 무결성ASIL B모든 영구 저장 레코드에 체크섬(CRC-32 / SHA-256)을 적용하고 복구할 수 없는 비트 반전을 상태 관리에 보고한다.
