LIN State Manager (LinSM)

Manages state transitions of LIN networks.

Funktionen — Übersicht

  • void LinSM_Init (const LinSM_ConfigType* ConfigPtr); This function initializes the Lin SM.
  • Std_ReturnType LinSM_ScheduleRequest (NetworkHandleType network, LinIf_SchHandleType schedule); The upper layer requests a schedule table to be changed on one LIN network.
  • void LinSM_GetVersionInfo (Std_VersionInfoType* versioninfo); -
  • Std_ReturnType LinSM_GetCurrentComMode (NetworkHandleType network, ComM_ModeType* mode); Function to query the current communication mode.
  • Std_ReturnType LinSM_RequestComMode (NetworkHandleType network, ComM_ModeType mode); Requesting of a communication mode.
  • void LinSM_MainFunction (void); Periodic function that runs the timers of different request timeouts
  • void LinSM_ScheduleRequestConfirmation (NetworkHandleType network, LinIf_SchHandleType schedule); The Lin If module will call this callback when the new requested schedule table is active.
  • void LinSM_GotoSleepIndication (NetworkHandleType Channel); The Lin If will call this callback when the go to sleep command is received on the network or a bus idle timeout occurs.
  • void LinSM_GotoSleepConfirmation (NetworkHandleType network, boolean success); The Lin If will call this callback when the go to sleep command is sent successfully or not sent successfully on the network.
  • void LinSM_WakeupConfirmation (NetworkHandleType network, boolean success); The Lin If will call this callback when the wake up signal command is sent not successfully/ successfully on the network.

Typen — Übersicht

  • enum LinSM_ModeType Type used to report the current mode to the Bsw M
  • struct LinSM_ConfigType Data structure type for the post - build configuration parameters.
