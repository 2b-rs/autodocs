자동으로 생성된 설명이다. 로컬 Classic 인벤토리에는 짧은 API 스텁만 포함되어 있으며, 저장소 식별자 [SWS_CP_…]는 Classic PDF에 대해 검증된 AUTOSAR 번호가 아니다. 로컬 참조가 없는 아키텍처 설명은 해석으로 표시된다. 공식 AUTOSAR 텍스트가 아니다. 소스 레지스터 ai/quellen.json에 등록된 Classic 문서가 없다.

레코드 CP_CRYPTO는 저장소 식별자 [SWS_CP_CRYPTO_00001] 아래에 작업 ID, 작동 모드, 입력 및 출력 버퍼와 함께 Csm_Encrypt를 문서화한다.

해석: Crypto Service Manager는 작업을 수락하고 CryIf를 통해 암호화 드라이버로 전달한다. 애플리케이션은 데이터와 작업 ID를 전달한다. 호출은 키를 호출자에게 내보내지 않는다. 스텁은 이 계층화를 표시하지 않는다.

해석: SHE 또는 HSM 프로필은 암호화 드라이버 뒤의 보안 모듈에 키 자료를 보관한다. 레코드 CP_CRYPTO의 Csm_Encrypt에는 SHE나 HSM 모두 매개변수가 아니다.

해석: Secure Onboard Communication은 별도의 모듈이다. 페이로드와 신선도 값을 통해 종종 잘린 MAC을 형성하고 검증에 실패한 PDU를 폐기한다. 이는 성공적인 Csm_Encrypt 작업이 아니며 이를 대체하지 않는다.
