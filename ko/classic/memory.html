AUTOSAR Classic Memory Services

Memory Services는 비휘발성 데이터 블록(NvM), 추상 플래시 및 EEPROM 기술(MemIf, Fee, Ea)을 관리하고 데이터 일관성과 데이터 보안 ECU 종료 주기를 보장합니다.

일반적인 수명 주기 및 동작 모드

클러스터의 수명 주기는 Basic Software Mode Manager(BswM)와 ECU State Manager(EcuM)에 의해 밀접하게 오케스트레이션됩니다. ECU 시작(Startup Phase) 동안 드라이버 다음으로 추상화 모듈이 Fee_Init 또는 Ea_Init([SWS_Fee_00085], [SWS_Ea_00083])을(를) 통해 먼저 동기 초기화된 후, NVRAM Manager가 NvM_Init([SWS_NvM_00447])을(를) 통해 동기 초기화됩니다 AUTOSAR SWS NVRAMManager 156쪽.

초기화에 이어 BswM은 영구로 표시된 모든 RAM 블록을 비휘발성 메모리에서 복원하기 위해 멀티 블록 읽기 작업 NvM_ReadAll을(를) 트리거합니다([SWS_NvM_00460]) ModemanagementGuide 54쪽. NvM은 콜백 함수 BswM_NvM_CurrentJobMode을(를) 통해 진행 상황과 최종 결과를 BswM에 다시 보고합니다([SWS_NvM_00745], [SWS_NvM_00888]). 개별 블록 상태는 BswM_NvM_CurrentBlockMode을(를) 통해 시그널링됩니다([SWS_NvM_00746], [SWS_NvM_00890]) ModemanagementGuide 28쪽.

셧다운 단계에서 시스템은 NvM_WriteAll을(를) 통해 수정된 모든 RAM 블록을 NV 메모리로 영구 다시 쓰도록 지시합니다([SWS_NvM_00461]). Flash 쓰기 주기 횟수를 최적화하기 위해 NvM_SetRamBlockStatus을(를) 통해 블록이 수정되었는지 여부를 지정하여 표시할 수 있습니다([SWS_NvM_00453]) EXP NVDataHandling 18쪽. 조기 웨이크업 이벤트가 발생할 경우 진행 중인 쓰기 프로세스를 NvM_CancelWriteAll을(를) 통해 취소할 수 있습니다([SWS_NvM_00238]) AUTOSAR SWS NVRAMManager 161쪽.

오류 처리, DET 추적 및 성능 저하

클러스터는 다단계 오류 감지 및 디그레이디션 개념을 갖추고 있습니다. 드라이버 및 추상화 레벨에서 발생하는 오류는 반환 상태 MEMIF_JOB_FAILED을(를) MemIf_GetJobResult을(를) 통해 쿼리하거나 NvM_JobErrorNotification을(를) 통해 보고됩니다([SWS_Fee_00091], [SWS_Ea_00095]) ErrorDescription 49쪽.

읽기 오류가 발생하면 NvM은 구성된 복구 메커니즘을 사용합니다. 먼저 재시도(Read Retries)가 수행됩니다([SWS_NvM_00390]). 이것이 실패하면 중복 블록(NVM_BLOCK_REDUNDANT)의 경우 중복 복사본을 읽습니다([SWS_NvM_00171], [SWS_NvM_00531]). 여기서 중복성 손실이 감지되면 NvM은 작업 결과를 NVM_REQ_REDUNDANCY_FAILED(으)로 설정하고 프로덕션 오류 NVM_E_LOSS_OF_REDUNDANCY을(를) DEM에 보고합니다([SWS_NvM_00470], [SWS_NvM_00546]) ErrorDescription 62쪽.

ROM 기본값을 통한 복구에 성공하면 NvM은 결과 NVM_REQ_RESTORED_FROM_ROM을(를) 보고합니다([SWS_NvM_00470]). 모든 복구 조치가 실패하면 NVM_E_REQ_FAILED이(가) DEM에 보고되고([SWS_NvM_00279], [SWS_NvM_00288]) 쿼리 결과가 NVM_REQ_NOT_OK(으)로 설정됩니다([SWS_NvM_00451]). 쓰기 오류가 발생하면 NvM은 요청이 취소되기 전에 쓰기 재시도(NvMMaxNumOfWriteRetries)를 제어합니다([SWS_NvM_00168], [SWS_NvM_00213]) ErrorDescription 56쪽.

이 가이드는 Memory Services 클러스터의 핵심 아키텍처, 모듈 상호작용 및 오류 메커니즘을 요약합니다. 모든 정보는 AUTOSAR Classic Platform의 규범적 사양을 기반으로 합니다.

클러스터의 모듈

NVRAM Manager (NvM)

비휘발성 스토리지(EEPROM, 플래시)를 위한 동기식 및 비동기식 블록 기반 데이터 관리 기능을 제공합니다.

BSW ID 20 36개 API(30개 기능, 6개 유형) #include "NvM.h"

Memory Abstraction Interface (MemIf)

기본 Flash 및 EEPROM 메모리 드라이버를 요약합니다.

BSW ID 22 12개 API(9개 기능, 3개 유형) #include "MemIf.h"

Flash EEPROM Emulation (Fee)

플래시 메모리 장치에서 EEPROM와 유사한 데이터 블록의 에뮬레이션을 제공합니다.

BSW ID 40 16개 API(15개 기능, 1개 유형) #include "Fee.h"

EEPROM Abstraction (Ea)

외부 및 내부 EEPROM 장치에 대한 균일한 액세스를 제공합니다.

BSW ID 41 16개 API(15개 기능, 1개 유형) #include "Ea.h"
