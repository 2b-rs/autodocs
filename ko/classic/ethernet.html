Architekturüberblick Ethernet Services

Das Ethernet Services Cluster bildet den Hochgeschwindigkeits-Kommunikationsstack der Classic Platform ab. Es umfasst den Ethernet Driver (Eth) [SWS_Eth_00027], das Ethernet Interface (EthIf) [SWS_EthIf_00024], den TCP/IP-Stack (TcpIp) sowie den Socket Adaptor (SoAd). Das Cluster bietet Zero-Copy-Pufferung via Eth_Transmit [SWS_Eth_00041], VLAN-Tagging nach IEEE 802.1Q und die Grundlage für moderne Service-Orientierte Architekturen (SOME/IP) sowie DoIP-Diagnose.

자동으로 생성된 설명이다. 로컬 Classic 인벤토리에는 짧은 API 스텁만 포함되어 있으며, 저장소 식별자 [SWS_CP_…]는 Classic PDF에 대해 검증된 AUTOSAR 번호가 아니다. 로컬 참조가 없는 아키텍처 설명은 해석으로 표시된다. 공식 AUTOSAR 텍스트가 아니다. 소스 레지스터 ai/quellen.json에 등록된 Classic 문서가 없다.

레코드 CP_ETH는 저장소 식별자 [SWS_CP_ETH_00001] 아래에 Eth_Transmit(uint8 CtrlIdx, uint8 BufIdx, Eth_FrameType FrameType, boolean TxConfirmation, uint16 LenByte, const uint8* PhysAddrPtr)를 문서화한다. 호출은 이전에 제공된 컨트롤러의 전송 버퍼를 참조한다.

해석: Eth_Transmit는 드라이버 수준 전송 기능이다. 그 위에는 EthIf가 있고 경로에 따라 TcpIp, SoAd, DoIP 또는 SOME/IP가 있다. 로컬 스텁과 페이지 문장 “Ethernet driver, TCP/IP stack, DoIP”는 이 계층화를 자세히 지정하지 않는다. 기능 자체는 VLAN 태그나 TSN 게이트 목록을 전환하지 않는다.

해석: 일반적인 Classic 이더넷 아키텍처에서 IEEE 802.1Q는 이더넷 인터페이스의 VLAN 할당으로 나타난다. 논리적 컨트롤러는 VLAN-ID를 전달하고 EthIf는 컨트롤러를 선택한다. 레코드 CP_ETH에는 이에 대한 필드가 없다.

해석: AVB(Credit-Based Shaper, 802.1Qav) 및 TSN(Time-Aware Shaper, 802.1Qbv)은 이후 이더넷 스위치 및 컨트롤러 구성의 특성이다. 이 작업 트리에는 이러한 스케줄러를 Eth_Transmit의 요구 사항으로 입증하는 Classic-R20-11 발췌 내용이 포함되어 있지 않다. 여기서는 R20-11의 검증된 제품 특성으로 제공되지 않는다.
