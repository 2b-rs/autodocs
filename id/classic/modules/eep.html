AUTOSAR Classic Memory Drivers-Modul EEPROM Driver (Eep, Spezifikation: AUTOSAR_CP_SWS_EEPROMDriver.pdf, AUTOSAR_SWS_EEPROMDriver.pdf, AUTOSAR_SWS_EEPROM_Driver.pdf).

Funktionen — Übersicht

  • void Eep_Init (const Eep_ConfigType* ConfigPtr); Service for EEPROM initialization.
  • void Eep_SetMode (MemIf_ModeType Mode); Sets the mode.
  • Std_ReturnType Eep_Read (Eep_AddressType EepromAddress, uint8* DataBufferPtr, Eep_LengthType Length); Reads from EEPROM.
  • Std_ReturnType Eep_Write (Eep_AddressType EepromAddress, const uint8* DataBufferPtr, Eep_LengthType Length); Writes to EEPROM.
  • Std_ReturnType Eep_Erase (Eep_AddressType EepromAddress, Eep_LengthType Length); Service for erasing EEPROM sections.
  • Std_ReturnType Eep_Compare (Eep_AddressType EepromAddress, const uint8* DataBufferPtr, Eep_LengthType Length); Compares a data block in EEPROM with an EEPROM block in the memory.
  • void Eep_Cancel (void); Cancels a running job.
  • MemIf_StatusType Eep_GetStatus (void); Returns the EEPROM status.
  • MemIf_JobResultType Eep_GetJobResult (void); This service returns the result of the last job.
  • void Eep_GetVersionInfo (Std_VersionInfoType* versioninfo); Service to get the version information of this module.
  • void Eep_MainFunction (void); Service to perform the processing of the EEPROM jobs (read/write/erase/compare).
  • void Eep_JobEndNotification (void); This callback function provided by the module user is called when a job has been completed with a positive result.
  • void Eep_JobErrorNotification (void); This callback function provided by the module user is called when a job has been canceled or finished with negative result.

Typen — Übersicht

  • struct Eep_ConfigType This is the type of the external data structure containing the initialization data for the EEPROM driver.
  • struct Eep_AddressType Used as address offset from the configured EEPROM base address to access a certain EEPROM memory area.
  • struct Eep_LengthType Specifies the number of bytes to read/write/erase/compare.

For an Eep module driving an external EEPROM through SPI: If the SPI access fails, the Eep module shall behave as specified in [SWS_Eep_00068].

The Eep module shall only write (and erase) as many bytes to the EEPROM as supported by the EEPROM hardware within one job processing cycle. For internal EEPROMs, usually 1 data word can be written per time. Some external EEPROMs provide a RAM buffer (e.g. page buffer) that allows writing many bytes in one step.

The Eep module shall erase an EEPROM cell before writing to it if this is not done automatically by the EEPROM hardware.

The Eep module shall preserve data of affected EEPROM cells by performing read – modify – write operations, if the number of bytes to be written are smaller than the erasable and/or writeable data units.

The Eep module shall keep the number of read – modify – write operations during writing a data block as small as possible.

SWS_Eep_00068 requirement

When an error is detected during read job processing, the Eep module shall abort the job, shall set the EEPROM state to MEMIF_IDLE and shall set the job result to MEMIF_JOB_FAILED . If configured, the Eep module shall call the notification defined in the configuration parameter EepJobErrorNotification .

SWS_Eep_00069 requirement

The Eep module shall erase only as many bytes to the EEPROM as supported by the EEPROM hardware within one job processing cycle.

SWS_Eep_00070 requirement

The Eep module shall use block erase commands if supported by the EEPROM hardware and if the given parameters ( EepromAddress and Length ) are aligned to erasable blocks.

SWS_Eep_00072 requirement

The Eep module shall preserve the contents of affected EEP- ROM cells by using read – modify – write operations, if the given erase parameters ( EepromAddress and Length ) do not align with the erasable data units.

SWS_Eep_00073 requirement

For an Eep module driving an external EEPROM through SPI: The Eep's configuration shall be such that the value of the configuration parameter EepFastReadBlockSize fits to the number of bytes that are readable in burst SPI mode.

SWS_Eep_00075 requirement

When it is detected during compare job processing that the com- pared data areas are not equal, the EEPROM driver shall abort the job, set the EEP- ROM state to MEMIF_IDLE and the job result to MEMIF_BLOCK_INCONSISTENT . If configured, the callback function Eep_JobErrorNotification shall be called.
