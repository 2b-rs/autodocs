## Consequential decisions a reviewer must weigh

1. **Read base follows the write base.** With writes moved into the worktree, a
   shared-scope read from the common root could no longer see an entry the caller
   had just written. Reads from a linked worktree therefore resolve against that
   worktree, returning the committed common baseline plus that branch's own
   entries; reading from the shared checkout is unchanged. This touches read
   semantics, which C12 reserves for re-review — flagged deliberately rather than
   buried.
2. **Generated-profile size budget.** The mandatory routing text collides with the
   existing leader-profile size assertion (`< 13000`). The block was compressed to
   fit rather than the budget raised, since raising an existing guard to admit new
   text is a weakening. The wording is consequently terse; if the Architect wants
   the fuller phrasing, the budget question must be decided deliberately.
