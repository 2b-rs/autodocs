## The defect

`16-combine.txt` records `shell exit_code: 0` for
`python3 _src/tools/build_report.py combine`. **That value is wrong.**

The capture line in that stage's script was

    echo "----------------..."
    echo "shell exit_code: $?"

so `$?` held the exit status of the preceding `echo`, not of the Python
interpreter. It could only ever have printed 0.

contradicted by his own subreport. This session reproduced that error one stage
later, in its own script, having read that finding. Recorded plainly, because an
evidence set whose author quietly corrects his own measurement errors is worth
less than one that shows them.

`18-publish.txt` does not share the defect; it captures `rc=$?` immediately
after the interpreter returns.
