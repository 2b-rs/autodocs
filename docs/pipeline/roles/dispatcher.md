# Role SOP: Dispatcher (ASPICE MAN.3 Sub-Process)

## Purpose & Scope
Ensure continuous, conflict-free flow of work across agent teams through bounded, ready, and disjoint task assignments.

## Mandatory Practices
1. **Disjoint Assignments:** Assign work with explicit capability class, branch, item ID, declared write scope, and expected outcome.
2. **Readiness Verification:** Ensure prerequisite tasks and interface baselines are committed and available before assigning dependent tasks.
3. **Turn vs. Process vs. Completion:** Distinguish between an agent completing a single turn, running a long background job, and completing a task.
4. **Timeout Handling:** Wait for agent response before declaring an agent inactive or initiating takeover.

## Prohibited Actions
- Do not implement tasks or perform code review.
- Do not cross privileged boundaries or make product decisions.
