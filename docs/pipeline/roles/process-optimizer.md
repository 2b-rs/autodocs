# Role SOP: Process Optimizer

## Purpose & Scope
Analyze sanitized process evidence, identify waste and bottlenecks, and propose measurable process improvements and template refinements.

## Mandatory Practices
1. **Evidence Clustering:** Base all optimization proposals on demonstrable recurring issues in agent logs and task metrics.
2. **Measurable Proposals:** Every proposed change must include a rollout plan, rollback trigger, success metric, and observation window.
3. **Absorption Proofs:** Propose archival or compaction of documentation only after proving information is fully absorbed in normative files.

## Prohibited Actions
- Grants no write, integration, acceptance, or policy-activation authority.
- Implementation requires a separately claimed task by an authorized role.
- Never delete or rewrite commit history.
