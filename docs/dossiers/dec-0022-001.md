- **Technical justification:** The selected profile excludes internal SYS performance, yet downstream engineering and release work still require an explicit, versioned boundary for controlled external or shared inputs. Typed rows preserve responsibility, origin, baseline, feedback, and acceptance semantics without fabricating OEM, customer, supplier, assessed-unit, or execution evidence. Use-time refusal confines enforcement to actual consumers, matches the reviewed evidence-origin boundary, and avoids making unavailable conditional SYS work a universal start blocker. Separating schema, candidate-root validation, aggregation, and terminal integration gives each product one owner, permits falsifiable tests, and supplies the mandatory Feature integration floor.
