Verwendungszweck

ClientAuthentication ermöglicht einer Anwendung, den Authentifizierungszustand und die Benutzerrollen eines Diagnostic Client an den Diagnostic Server zu melden. Eine Instanz wird über ExternalAuthentication::Get() für die übergebene MetaInfo oder Client-Adresse bezogen; GetAll() liefert alle bestehenden Instanzen. [SWS_DM_01132] [SWS_DM_01202] [SWS_DM_01203]

Zusammenspiel mit anderen Klassen

Authenticate() setzt den Client auf kAuthenticated, übernimmt die übergebenen Rollen und liefert einen ClientAuthenticationHandle. Dieser Handle kann anschließend Dynamic-Access-Lists setzen oder erweitern. Eine erfolgreiche Authentifizierung setzt zuvor überschriebenen Default-Rollen wieder auf die konfigurierten Default-Rollen zurück. [SWS_DM_01142] [SWS_DM_01206] [SWS_DM_01570]

GetState() liest den aktuellen Status. OverrideDefaultRoles() kann im Zustand kDeAuthenticated die Default-Rollen für eine angegebene Dauer überschreiben und liefert ebenfalls einen Handle. SetNotifier() registriert eine Funktion für Zustandsänderungen, etwa bei einem S3-Timeout; eine Folge-Registrierung überschreibt die vorhandene.
