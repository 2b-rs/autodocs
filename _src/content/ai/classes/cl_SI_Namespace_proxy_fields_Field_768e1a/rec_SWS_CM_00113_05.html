Die noexcept Methode <SI-Namespace>::proxy::fields::<Field>::Set setzt einen neuen Wert (value: New value of field) für das Proxy-Field; sie existiert nur, wenn Field.hasSetter==TRUE konfiguriert ist [SWS_CM_00113]. Anwendungsfehler werden nicht über einen separaten Fehlerkanal von Get() gemeldet, sondern dadurch, dass Set() einen vom übergebenen Wert abweichenden Wert zurückliefert. Der Zugriff erfolgt über ein ara::core::Future<FieldType>. Die Methode ist exception-sicher.

Fehlerbehandlung

Bei Misserfolg enthält das Future ComErrc::kCommunicationFailure (ohne Rollback-Semantik) bei einem behebbaren Kommunikations- oder Secure-Communication-Fehler des Netzwerk-Bindings; ein Kommunikations-Timeout kann dabei einen unsicheren Zustand auf der Serverseite hinterlassen; ComErrc::kMinimumSendIntervalViolationError (ohne Rollback-Semantik), wenn eine Sendeanforderung schneller als das konfigurierte minimumSendInterval erfolgt.
