Die Methode ara::per::FileStorage::OpenFileReadOnly [SWS_PER_00114] öffnet eine über fileName angegebene Datei dieses File Storage zum Lesen mit einem definierten mode und liefert ein ara::core::Result<UniqueHandle<ReadAccessor>>. Sofern nicht anders durch mode festgelegt, wird die Leseposition auf den Dateianfang gesetzt; die Datei wird geschlossen, sobald das zurückgegebene UniqueHandle seinen Gültigkeitsbereich verlässt. Die Methode ist threadsicher und exception-safe.
