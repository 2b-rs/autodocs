Die Methode ara::per::FileStorage::OpenFileWriteOnly [SWS_PER_00115] öffnet eine über fileName angegebene Datei dieses File Storage zum Schreiben mit definiertem mode. Sofern nicht anders durch mode festgelegt, wird die Datei geleert (kTruncate); existiert sie nicht, wird sie angelegt. Sie liefert ein ara::core::Result<UniqueHandle<WriteAccessor>>; die Datei wird geschlossen, sobald das zurückgegebene UniqueHandle seinen Gültigkeitsbereich verlässt. Die Methode ist threadsicher und exception-safe.

Fehlerbehandlung

kIllegalWriteAccess wird zurückgegeben, wenn der File Storage als read-only oder als write-only-once mit bereits existierendem Eintrag konfiguriert ist. Weitere Fehler sind u. a. kPhysicalStorageFailure, kIntegrityCorrupted, kValidationFailed, kEncryptionFailed, kResourceBusy, kOutOfStorageSpace, kInvalidOpenMode, kTooManyFiles und kAuthenticationFailed.
