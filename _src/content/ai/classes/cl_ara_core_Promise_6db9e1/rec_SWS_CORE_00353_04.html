SetError (ara::core::Promise) verschiebt (per Move) einen Fehler in den Shared State von ara::core::Promise und markiert diesen anschließend als bereit. Übergeben wird error (der zu speichernde Fehler). Der Aufruf ist laut Spezifikation thread-sicher und bedingt exceptionsicher. [SWS_CORE_00353]

Fehlerbehandlung

  • IsoStdFutureErrcPromiseAlreadySatisfiedViolation: wenn der Shared State bereits einen gespeicherten Wert oder Fehler enthält.
  • PromiseNoSharedStateToSetViolation: wenn *this keinen Shared State besitzt.

Ein Service-Skeleton kann einen erkannten Application Error mit SetError() in die Promise eintragen, damit ihn der Client später über das zugehörige Future erhält. EXP ARAComAPI §5.4.6 „Methods“
