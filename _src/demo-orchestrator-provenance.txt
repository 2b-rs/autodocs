# Brief: End-to-End Orchestrator & Live Demonstration Server

## Objective
Implement an interactive local demonstration server and integration test suite (`_src/serve.py` + `_src/tests/test_e2e_experience.py` + `demo.html`) that makes all 6 core pillars immediately runnable, experiential, and demonstrable in the browser.

## Context
The user requested:
"/goal den geplanten Funktionsumfang (Darstellung von Autosar Classic + S-Core-Doku, ingest von user-feedback, kuratierung und review, UX-Konzept, interaktive Diskussion mit AI-Agenten, automatische Neuerzeugung von AI-kommentaren nach Feedback oder Spec-update) vollständig erlebbar machen."
The system needs a single executable command (`python3 _src/serve.py`) that boots up a local web server serving the documentation, handling API requests (feedback, curation, discuss), running the feedback loop in the background, and providing an interactive guided walkthrough (`demo.html`).

## Deliverables
1. Enhance `_src/serve.py`:
   - Standalone Python HTTP server (using `http.server` / `urllib` / lightweight standard library without external dependencies):
     - Serves static documentation files from root and subdirectories.
     - Implements REST API endpoints:
       - `POST /api/feedback`: Receives user feedback, saves to `_src/spec/feedback-queue/`, returns 201 with receipt.
       - `POST /api/curate`: Receives curator decision (accept, reject, change stereotype, delete mapping), saves envelope, returns 200.
       - `POST /api/discuss`: Receives prompt + context, generates contextual AI reply / proposal, returns 200.
       - `POST /api/feedback-loop/run`: Triggers `feedback_loop.py` to rebuild affected pages and returns execution summary.
       - `GET /api/status`: Returns system status across the 3 universes, pending feedback items, and curation queue counts.
2. Live Walkthrough Page `demo.html`:
   - A dedicated interactive tour page demonstrating all 6 pillars with clickable links and live cards:
     1. Universe Switcher: Adaptive, Classic, S-Core.
     2. UX Shell: 6 global domains (*Explore*, *Trace*, *Curate*, *Review*, *Work*, *Reports*), Dark/Light mode, Density toggle.
     3. Traceability Graph: Interactive Cytoscape / Cuttlefish graph with stereotype badges.
     4. Component Inspector: Live component inspection, stereotype dropdown, and direct delete/unbind action.
     5. Feedback Submission: Live modal with receipt dialog.
     6. Discuss with AI & Closed Feedback Loop: Live chat, context inspector, proposal generation, and triggering of automatic comment regeneration.
3. End-to-End Test Suite:
   - Create `_src/tests/test_e2e_experience.py`:
     - Spawns the server in a test thread.
     - Executes HTTP requests against `/api/status`, `/api/feedback`, `/api/curate`, `/api/discuss`, and `/api/feedback-loop/run`.
     - Validates that each endpoint returns status 200 and performs expected file operations.

## Acceptance Oracle
Run: `python3 -m unittest _src/tests/test_e2e_experience.py` -> All tests PASS.
Commit all changes to your branch with a clear descriptive message.
