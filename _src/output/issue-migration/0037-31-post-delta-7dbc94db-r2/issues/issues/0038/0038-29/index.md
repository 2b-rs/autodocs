## Acceptance criteria

- **AC-001** A tested tool publishes exactly one caller-named subtree to the configured destination. It takes the expected tree digest as a required argument, recomputes it over the actual source directory immediately before writing, and **refuses to publish on mismatch** — the digest procedure is the one implemented in `_src/tools/prepare_score_curation_export.py` (SHA-256 over path-sorted records of UTF-8 relative POSIX path bytes, one NUL byte, and the raw 32-byte per-file SHA-256), and it is documented where the tool is registered so a reviewer can reproduce it by hand. Paths outside the named subtree are never created, modified or deleted
- **AC-002** this is asserted by a test that starts from a destination containing unrelated content and proves it survives byte-identically. Deletion inside the destination subtree happens only for paths the source no longer contains, and any deletion is reported before it is performed. The existing safety guards of `_src/publish.sh` remain in force and are not weakened: no private path (`_src`, `output`, `.gitignore`) may enter the destination, and identity/destination stay explicit parameters with no embedded defaults (`0038-26`). A dry-run mode reports the complete intended effect — created, modified, deleted, with counts and a bounded sample — and is the mode used to satisfy any pre-publication disclosure obligation. The tool never invents authority: it requires an explicit authorisation reference (a commit or record ID) and writes it into the publication evidence

## Definition of Done

Committed with focused tests covering at minimum: digest match, digest **mismatch** (must refuse), unrelated destination content preserved, in-subtree deletion reported, private-path guard, and dry-run output completeness. Registered in [`docs/pipeline/tools.md`](docs/pipeline/tools.md) with the digest procedure written out. `_src/publish.sh` remains the whole-site publisher and is **not** replaced; the relationship between the two is documented so nobody has to guess which one applies. `python3 _src/tools/automation_safety.py` passes for the new tool. No credentials, remote configuration or destination defaults are embedded.
