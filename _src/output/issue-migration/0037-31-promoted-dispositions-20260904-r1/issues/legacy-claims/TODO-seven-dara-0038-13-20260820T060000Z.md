## Design summary

`candidate_root()` is the sole sanctioned generation target: a run-specific
`output/logs/<task_id>/<request_id>/.candidates/` root, reusing the same
request-scoped-directory shape `_src/tools/artifact_retention.py` (`0038-11`,
read-only inspection, not modified) uses for its `.partial` quarantine root —
a candidate is never generated in place over a shared/fixed export path.
A `candidate-budget@v1` document declares the `sole_writer` allowed to
promote into a destination (mirroring the sole-writer hazard class
`_src/tools/legacy_scope_planner.py`, `0038-06`, already detects for
write-scope collisions), `allowed_paths` output patterns, `file_count`/
`total_bytes` budgets, `required_subtrees` (e.g. language trees),
per-category `realism` byte floors (`kind`: rendered/downloaded/submitted),
an optional `require_negative_path` check, a `max_duplicate_digest_ratio`
guard against synthesized/templated placeholder output, and an
`expected_manifest`/`diff_tolerance`/`explained_diffs` comparison against a
golden manifest. `evaluate()` returns a `candidate-budget-report@v1` with the
PASS/FAIL/INCONCLUSIVE discipline `_src/tools/task_validation.py` (`0038-08`,
read-only inspection, not modified) established — a budget violation blocks
even when an upstream generator process exited zero. `promote()` is atomic
and recoverable through a single `current.json` pointer file per destination
(the same atomic-mutable-pointer shape `0038-10` uses for attempt results):
it refuses a non-`PASS` report, refuses to overwrite a destination currently
owned by a different `sole_writer`, never promotes a file outside the
declared `allowed_paths` even if the caller's report is stale (defense in
depth against "no unrelated generated family is swept in"), and a retry
after a crash either repairs the pointer idempotently (the staged tree
already matches the evaluated manifest) or fails closed on a genuine
mismatch.

Fixtures are grounded in this Feature's "Evidence baseline (2026-08-16)"
paragraph rather than generic scenarios: the 4,503-file generation, the
Feature `0021` "synthetic-only green" incident (→ duplicate-digest-ratio
guard), and fixed-path export overwrite risk (→ `sole_writer`
promotion-ownership guard) are all named there.
