## Assumptions / design decisions (recorded per "Autonomous backlog repair" — none required a backlog amendment; recorded here as implementation-determinable design choices)

1. **Historical fixture:** used the real commit `50b20829` ("evidence: record verification logs, qualification runs, and audit trails", 184 files / 10,384 insertions) cited by the Feature `0038` "Evidence baseline (2026-08-16)" paragraph, rather than a synthetic bundle. Its `_src/logs/validate-review-request-ui/**` subtree (28 files) is the DoD demonstration fixture; `logs/backlog-bookkeeping-and-commit/0037-01-*` (present in the same historical commit, genuinely a different Task's evidence) is used to demonstrate the unrelated-run rejection. Both are exercised in `_src/tests/test_task_evidence_pack.py::HistoricalEvidenceBaselineTests`, gated `skipUnless` the commit is reachable.
2. **Tracked-ref vs blob classification rule:** a declared item is a `tracked-ref` (referenced by exact commit + path, no bytes copied) when its extension is a recognized script/source extension (`.py`, `.cjs`, `.js`, `.mjs`, `.sh`, `.ts`, `.applescript`, `.as`) **and** it is verified tracked at the declared (or HEAD) commit; every other item is a content-addressed `blob`, deduplicated by SHA-256 digest. This directly matches the DoD's own example ("duplicate probe scripts/source dumps are eliminated without losing provenance") and is verified against the real historical bundle: `four_url_probe.cjs` and `make_review_fixture.py` each appear twice, verbatim, across two timestamped directories in commit `50b20829`; both become single `tracked-ref` entries.
3. **"Ignored scratch as sole closure proof" rejection:** implemented as: a pack with zero captured `blob`/`tracked-ref` items whose only `full_logs` reference points at a git-ignored path is rejected (`EVP-SCRATCH-SOLE-PROOF`). The schema has no "reference-only, no digest" item kind at all, so an evidence item can never be added without either a copied+deduplicated blob or a verified tracked commit/path.
4. **Unrelated-run detection:** a path is flagged unrelated if it contains a `\d{4}-\d{2}(\.\d{2})?` Task-ID-shaped token (digit-bounded, so `.../20260815-151552/...` timestamps do not false-positive) that is not the pack's own `task_id` and not in an explicit `related_task_ids` allow-list.
5. Environment-identity field (`environment_id`) is a free-form optional string intended to carry `0038-09`'s `environment_doctor.py` `prepared-environment@v1` `environment_id` fingerprint; this tool does not import or invoke `environment_doctor.py` (kept stdlib-only and decoupled per the project's existing module-boundary convention), the caller supplies the fingerprint value.
