function SomeIpTp_TriggerTransmit [SWS_SomeIpTp_00053] 📄 PDF

Std_ReturnType SomeIpTp_TriggerTransmit(PduIdType TxPduId, PduInfoType* PduInfoPtr);

Within this API, the upper layer module (called module) shall check whether the available data fits into the buffer size reported by PduInfoPtr->SduLength. If it fits, it shall copy its data into the buffer provided by PduInfoPtr->SduDataPtr and update the length of the actual copied data in PduInfoPtr->SduLength. If not, it returns E_NOT_OK without changing PduInfoPtr.

The amount of generated SOME/IP segments shall be as little as possible.

requirement SWS_SomeIpTp_00006 [SWS_SomeIpTp_00006] 📄 PDF

Every payload of a segmented SOME/IP message except the last one has to be a multiple of 16 bytes.

requirement SWS_SomeIpTp_00007 [SWS_SomeIpTp_00007] 📄 PDF

The SOME/IP TP module shall buffer the pointer to the Meta-data for every PDU ID separately which is passed by the PduInfoPtr parameter of the API SomeIpTp_Transmit(), and forward this information when PduR_SomeIpTp Transmit() is called for each segment.

requirement SWS_SomeIpTp_00008 [SWS_SomeIpTp_00008] 📄 PDF

The SOME/IP TP module shall store the Request ID, Pro- tocol Version, Interface Version, Message Type, and the Return Code of the SOME/IP header for every PDU ID separately which is returned by the first call of PduR_Some IpTpCopyTxData() triggered by the API call SomeIpTp_Transmit().

requirement SWS_SomeIpTp_00009 [SWS_SomeIpTp_00009] 📄 PDF

If the provided SDU fits into one single PDU, the provided SOME/IP header shall be used with no modification. If the provided SDU does not fit into one single SOME/IP PDU, the SOME/IP TP module shall set the TP-Flag of the Message Type to '1' for every SOME/IP segment which is going to be sent on the bus via the PduR. All the other bits contained in the Message Type field shall stay untouched.

requirement SWS_SomeIpTp_00010 [SWS_SomeIpTp_00010] 📄 PDF

The SOME/IP TP module shall create and attach the Off- set Field, the Reserved bits, and the More Segment Flag to every SOME/IP segment which is going to be sent on the bus.

requirement SWS_SomeIpTp_00011 [SWS_SomeIpTp_00011] 📄 PDF

The Offset Field of the first SOME/IP segment shall be set to '0'.

requirement SWS_SomeIpTp_00012 [SWS_SomeIpTp_00012] 📄 PDF

The SOME/IP TP module shall increase the value of the Offset Field for every successfully transmitted SOME/IP segment by the amount of bytes which have been transmitted by the previous SOME/IP segment divided by 16.

requirement SWS_SomeIpTp_00013 [SWS_SomeIpTp_00013] 📄 PDF

requirement SWS_SomeIpTp_00014 [SWS_SomeIpTp_00014] 📄 PDF

requirement SWS_SomeIpTp_00015 [SWS_SomeIpTp_00015] 📄 PDF

requirement SWS_SomeIpTp_00020 [SWS_SomeIpTp_00020] 📄 PDF

This shall include the following content: • Request ID [32 bit] • Protocol Version [8 bit] • Interface Version [8 bit] • Message Type [8 bit] - see [SWS_SomeIpTp_00028] • Return Code [8 bit]

requirement SWS_SomeIpTp_00038 [SWS_SomeIpTp_00038] 📄 PDF

If the provided SDU fits into one single PDU, the provided SOME/IP header shall be used with no modification. The SOME/IP TP module shall create and attach the Off- set Field, the Reserved bits, and the More Segment Flag to every SOME/IP segment which is going to be sent on the bus.

The Offset Field of the first SOME/IP segment shall be set to '0'.

SWS_SomeIpTp_00012 requirement

The SOME/IP TP module shall increase the value of the Offset Field for every successfully transmitted SOME/IP segment by the amount of bytes which have been transmitted by the previous SOME/IP segment divided by 16.

SWS_SomeIpTp_00013 requirement

The SOME/IP TP module shall set the Reserved bits stati- cally to '000' by the sender and shall be ignored by the receiver.

SWS_SomeIpTp_00014 requirement

SWS_SomeIpTp_00015 requirement

The SOME/IP TP module shall set the More Segment Flag to '0' for the last SOME/IP segment.

SWS_SomeIpTp_00016 requirement

If the API SomeIpTp_Transmit() is called, the SOME/IP TP module shall check for an ongoing segmentation for the provided PDU ID.

SWS_SomeIpTp_00017 requirement
