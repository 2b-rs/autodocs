Контрольная точка перед изменением Update

UpdateRequest соединяет UCM с релевантными для обновления состояниями State Management. UCM сначала открывает сеанс, а затем только позволяет подготовить, проверить или преобразовать затронутый Function Groups для отката. SWS StateManagement §7.3 «Interaction with UCM» SWS StateManagement §7.7.14 «StateMachine support for UCM»

Контракт Session

RequestUpdateSession решает вход; параллельные сеансы отклоняются. В рамках утвержденного сеанса PrepareUpdate, VerifyUpdate и PrepareRollback StateMachines сопоставляются с соответствующими проявленными состояниями. По завершении UCM закрывается с помощью StopUpdateSession. [SWS_SM_00209] [SWS_SM_00206] [SWS_SM_00207] [SWS_SM_00208]

Диаграмма активности сеанса обновления, созданная UpdateRequest. Источники: SWS StateManagement §7.3 «Interaction with UCM», SWS StateManagement §7.7.14 «StateMachine support for UCM».

Сброс и обратная связь о прогрессе

ResetMachine запрашивает перезагрузку машины, а ResetMachineNotifier информирует UCM об изменениях во время и после обработки. Оба являются частью процесса контролируемого обновления и не заменяют сеанс и последовательность подготовки. [SWS_SM_91100] [SWS_SM_91106]

Правило реализации

Контроль доступа предназначен для ограничения использования службы UCM. UCM должен сам вычислить порядок затронутых Function Groups и не выполнять одновременно вызовы подготовки/проверки/отката. [SWS_UCM_00260]
