SecOC-Extension в Communication Management

apext::com::secoc объединяет расширения платформы для управления актуальностью и соответствующей областью ошибок. Эти API предназначены для интеграции безопасности привязки управления связью; они не являются универсальным API-интерфейсом потребителя услуг. SWS CM §7.3.2 «Secure Communication» и EXP SW Architecture §9.3.1.1.3 «Interfaces for freshness value management» обеспечивают классификацию.

Целенаправленно обрабатывать коды ошибок

ComSecOcFvmErrc интегрирован в механизм ошибок AUTOSAR с помощью GetComSecOcFvmErrorDomain() и MakeErrorCode(). Коды следует оценивать только в контексте FVM и не следует использовать в качестве замены статуса ComErrc или E2E.

Взаимодействие привязки SecOC и FVM описано в руководстве по модулю в виде диаграммы сотрудничества: ara::com — Communication Management, диаграмма кооперации «Управление значением свежести на уровне SecOC».
