Точка расширения для моделируемого трассирования

apext::log::TraceArti — это точка расширения для смоделированных сообщений трассировки. Решение о маршрутизации может быть принято для сообщения, пространства имен и исполняемого файла во время компиляции, что позволяет избежать накладных расходов во время выполнения. SWS Log and Trace §7.6 «Tracing» [SWS_LOG_20001] [SWS_LOG_20004]

Разделение трассировки и журнала

В зависимости от конфигурации сгенерированная специализация ведет только к логгеру, только к ARTI, к обоим или отбрасывает сообщение. (Интерпретация: Таким образом, пространство имен является намеренно узким мостом между сгенерированным кодом инструмента трассировки и стандартным API журнала.)

функция TraceArti [SWS_LOG_20000] Upstream: RS_LT_00003

template <typename MsgId, typename... Params> void TraceArti (const MsgId &msg_id, const Params &...                       params) noexcept;

Handles a modeled message, specific to the used trace tool. This function is only called internally by the Logger framework when switching between Log and TraceArti. It represents the interface to trace tools. The runtime overhead of this function shall be kept as minimal as possible, e.g. by using specializations based on the MsgId.

Семантика от TraceArti

TraceArti — это деталь API интерфейса ведения журнала. Его использование происходит в контексте Logger, LogStream и настроенного фильтра отчетов.
