пространство имён ara::idsm

Эта страница полностью сгенерирована искусственным интеллектом на основе SWS IntrusionDetectionSystemManager (R25-11) — без официального текста AUTOSAR и без автоматически извлеченной страницы API, как в остальных модулях. Утверждения, помеченные как интерпретация, представляют собой выводы, сделанные на основе источников.

Руководство пользователя Сгенерировано ИИ / AI generated

Автоматически создаваемое описание, контент получен из ссылочных документов AUTOSAR R25-11 (спецификация SWS и сопроводительные стандартные документы) — не официальный текст AUTOSAR. Утверждения, помеченные как интерпретация, представляют собой выводы, сделанные на основе источников.

Граница Namespace

ara::idsm содержит API Event, Provider и Receiver вместе с их общими типами данных и ошибок. SWS IdsM §8.2 «common.h» определяет общие типы; остальные Header сопоставляют их соответствующим Port-Interfaces.

Интерпретация: Пространство имен объединяет объекты доступа к событию, поставщику и получателю, включая типы данных и представление ошибок; Их конкретная связь с прототипами портов определяется с помощью модели и ara::core::InstanceSpecifier.

Классы и структуры

  • ContextDataProvider Предоставляет изменяемые контекстные данные для IdsM.
  • EventReporter Meldet Security Events an IdsM.
  • IdsmErrorDomain Домен ошибок для ara::idsm.
  • IdsmException Тип исключения для ara::idsm.
  • QualifiedEventsReceiver Принимает квалифицированные события.
  • ReportingModeProvider Читает и задаёт Reporting Modes.
  • TimestampProvider Stellt optionale Zeitstempel bereit.
