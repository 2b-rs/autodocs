Контекст

Шаблонный класс ara::core::Array предоставляет в Adaptive Platform стандартную адаптацию std::array. Он инкапсулирует массив фиксированного размера N с элементами типа T и позволяет избежать динамического выделения памяти во время выполнения. В качестве базового последовательного контейнера ara::core::Array служит функциональным кластерам и приложениям AUTOSAR типобезопасной структурой данных для передачи полезных данных со статически известным количеством элементов.

Интерфейс строго ориентируется на требования стандарта C++, однако определяет специфические адаптации для среды выполнения AUTOSAR. К ним относятся типизированные интерфейсы для индексации, итераторов и запросов к памяти. Псевдонимы типов для ссылок и указателей ([SWS_CORE_01210], [SWS_CORE_01211], [SWS_CORE_01217], [SWS_CORE_01218]), индексов ([SWS_CORE_01214], [SWS_CORE_01215]), а также прямых и обратных итераторов ([SWS_CORE_01212], [SWS_CORE_01213], [SWS_CORE_01219], [SWS_CORE_01220]) обеспечивают интероперабельность со стандартными алгоритмами и обобщенными интерфейсами.

Жизненный цикл

Являясь агрегатным типом, ara::core::Array привязывает содержащиеся элементы непосредственно к собственному представлению в памяти. Неявно объявленные специальные функции-члены (такие как конструкторы по умолчанию, копирования и перемещения, а также деструкторы) согласно спецификации не объявляются явно повторно, а следуют стандартному поведению массивов C++. Таким образом, время жизни всех N элементов неразрывно связано со временем жизни экземпляра контейнера.

Размерность определяется во время компиляции с помощью параметра шаблона N. Методы запроса размера, такие как size() ([SWS_CORE_01262]), max_size() ([SWS_CORE_01263]) и empty() ([SWS_CORE_01264]), объявлены как constexpr и noexcept. Обмен содержимым двух экземпляров одинакового размера осуществляется с помощью swap() ([SWS_CORE_01242]). Безопасность относительно исключений функции swap() условно зависит от того, указан ли тип элементов T через ara::core::is_nothrow_swappable<T>::value как не генерирующий исключений ([SWS_CORE_01242]). В отношении параллелизма ara::core::Array не предоставляет внутренней синхронизации; одновременный доступ для записи к одному и тому же экземпляру должен быть защищен со стороны приложения (интерпретация).

Путь использования

Типичное использование ara::core::Array подразделяется на инициализацию, последовательную обработку данных или обработку с произвольным доступом и передачу низкоуровневым интерфейсам:

  • Инициализация и заполнение: контейнер может быть заполнен изначально или однородно перезаписан копией значения с помощью метода fill() ([SWS_CORE_01241]). Операция является noexcept, если тип элементов безопасен при присваивании (std::is_nothrow_copy_assignable<T>::value).
  • Произвольный и прямой доступ к элементам: для производительного доступа без проверки во время выполнения доступен operator[] ([SWS_CORE_01265], [SWS_CORE_01266]). На граничные элементы можно ссылаться с помощью front() ([SWS_CORE_01267], [SWS_CORE_01268]) и back() ([SWS_CORE_01269], [SWS_CORE_01270]).
  • Обработка, совместимая с итераторами: алгоритмы могут выполнять итерацию по последовательности с использованием прямых итераторов (begin() / end() согласно [SWS_CORE_01250], [SWS_CORE_01251], [SWS_CORE_01252], [SWS_CORE_01253]), константных итераторов (cbegin() / cend() согласно [SWS_CORE_01258], [SWS_CORE_01259]) или обратных итераторов (rbegin() / rend() / crbegin() / crend() согласно [SWS_CORE_01254], [SWS_CORE_01255], [SWS_CORE_01256], [SWS_CORE_01257], [SWS_CORE_01260], [SWS_CORE_01261]).
  • Мост к C-API: с помощью метода data() ([SWS_CORE_01271], [SWS_CORE_01272]) предоставляется прямой указатель на лежащий в основе непрерывный сегмент памяти, например для передачи драйверам или процедурам сериализации.

Сценарии ошибок

В области обработки ошибок и контроля граничных значений ara::core::Array существенно отклоняется от стандарта ISO C++, чтобы соблюсти специфичные для AUTOSAR правила безопасности исключений:

front() / back() empty() == true (d. h. N == 0) Вызов для пустого массива обязательно приводит к ошибке времени компиляции (Compile-Time Error) ([SWS_CORE_01267], [SWS_CORE_01268], [SWS_CORE_01269], [SWS_CORE_01270]).
