Роль в модели

Буферу принадлежит ресурс памяти, необходимый хосту и ускорителю. Прямая передача данных выражается не через методы буфера, а через объекты доступа.

Ссылка на источник

Для описания памяти Buffer работает с SWS SHWA §7.5 — Memory Allocation Specifics. Согласно SWS SHWA §7.3 — Data Access Specifics доступ выражается через Accessor.

Жизненный цикл

Процесс, полученный из фабрик буферов/аксессуаров и RAII. Источники: SWS SHWA §7.3, SWS SHWA §7.5. Частичная интерпретация: последовательность состояний делает видимым соединение документированного объекта.
