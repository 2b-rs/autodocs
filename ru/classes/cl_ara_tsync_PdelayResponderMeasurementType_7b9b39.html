Объединяет временные метки и данные эталонного времени pDelay-респондера для валидации времени.

Структура данных ara::tsync::PdelayResponderMeasurementType служит для объединения подробных данных измерений времени для pDelay-респондера в рамках синхронизации времени. Она фиксирует момент поступления запроса requestReceiptTimestamp [SWS_TS_14170], а также момент отправки ответа responseOriginTimestamp [SWS_TS_14171] в виртуальном локальном времени вместе с соответствующим порядковым номером. Сопутствующий кортеж эталонного глобального времени, состоящий из виртуального локального и глобального времени, позволяет последующим системам точно пересчитывать измеренные значения в глобальные координаты времени.

Контекст

Структура данных ara::tsync::PdelayResponderMeasurementType определена в заголовочном файле ara/tsync/time_validation_measurement_types.h и объединяет точные данные измерений времени для pDelay-респондера внутри функционального кластера синхронизации времени (tsync). В пиринговом методе измерения времени задержки респондер отвечает на запросы времени задержки от соседних сетевых узлов. Чтобы иметь возможность отслеживать и валидировать задержку передачи во времени, а также точность синхронизации на уровне соединения, структура фиксирует определяющие временные метки цикла измерения. Однозначное сопоставление с инициирующим сообщением запроса обеспечивается полем sequenceId [SWS_TS_14174]. Интерпретация: собранные данные измерений, вероятно, предоставляются в первую очередь для механизмов анализа и валидации (Time Validation) с целью мониторинга отклонений и задержек передачи в сети.

Зафиксированные временные метки включают точный момент поступления сообщения запроса requestReceiptTimestamp [SWS_TS_14170], а также момент отправки соответствующего ответа responseOriginTimestamp [SWS_TS_14171]. Оба значения представляются в виде временных меток в виртуальном локальном времени (Virtual Local Time). Для единообразной интеграции в общеплатформенную модель времени структура дополнительно содержит кортеж эталонного времени: он состоит из локального значения времени referenceLocalTimestamp [SWS_TS_14172] и соответствующего глобального значения времени referenceGlobalTimestamp [SWS_TS_14173]. Благодаря этому обрабатывающие инстанции могут точно пересчитывать события, измеренные в локальном виртуальном времени, в глобальную шкалу времени.

Жизненный цикл

Являясь финальным объявлением структуры (struct ... final), PdelayResponderMeasurementType выступает как чистый объект-значение (Plain Old Data) без внутреннего конечного автомата или динамического управления памятью. Создание экземпляра обычно происходит непосредственно после завершения транзакции pDelay. Интерпретация: заполнение структуры, вероятно, происходит синхронно в стеке протоколов респондера, как только после отправки сообщения Pdelay_Resp становятся доступны все аппаратные и интерфейсные временные метки.

В отношении прав владения объект передаётся по значению или через неизменяемые ссылки в последующие подпрограммы диагностики или валидации времени. Поскольку структура не управляет эксклюзивными ресурсами или указателями, процесс уничтожения тривиален и привязан к области видимости вызывающего контекста. С точки зрения параллелизма полностью инициализированный экземпляр потокобезопасен для параллельных операций чтения; модификации с записью требуют внешней синхронизации, если экземпляр повторно используется между потоками.

Путь использования

Типичный процесс сбора и предоставления данных измерений респондера делится на следующие шаги:

  1. Приём запроса: при поступлении кадра Pdelay_Req респондер фиксирует момент поступления как requestReceiptTimestamp в виртуальном локальном времени [SWS_TS_14170] и регистрирует соответствующий порядковый номер sequenceId [SWS_TS_14174].
  2. Отправка ответа: респондер передаёт ответное сообщение Pdelay_Resp. При покидании интерфейса момент отправки также фиксируется как responseOriginTimestamp в виртуальном локальном времени [SWS_TS_14171].
  3. Определение эталонного кортежа: для пересчёта измеренных значений в глобальное время из текущего состояния локального экземпляра глобального времени определяются referenceLocalTimestamp [SWS_TS_14172] и referenceGlobalTimestamp [SWS_TS_14173].
  4. Передача данных измерений: полностью заполненный экземпляр PdelayResponderMeasurementType передаётся в систему валидации, которая проверяет разности времени и точность синхронизации.

Диаграмма последовательности: процесс фиксации временных меток и предоставления данных измерений на pDelay-респондере. Источники: [SWS_TS_14170], [SWS_TS_14171], [SWS_TS_14172], [SWS_TS_14173], [SWS_TS_14174].

Настоящее руководство по классу основано на спецификации AUTOSAR Adaptive R25-11 для модуля tsync и описывает структуру сбора данных измерений.
