Автоматически создаваемое описание, контент получен из ссылочных документов AUTOSAR R25-11 (спецификация SWS и сопроводительные стандартные документы) — не официальный текст AUTOSAR. Утверждения, помеченные как интерпретация, представляют собой выводы, сделанные на основе источников.

Использование по назначению

ara::core::Optional<T> реализует std::optional<T> и моделирует значение, которое может присутствовать. Он поддерживает пустое конструирование либо nullopt, in-place-конструирование, emplace(), reset(), запросы состояния и доступ к значению. [SWS_CORE_01033] [SWS_CORE_01103] [SWS_CORE_01104] [SWS_CORE_01107] [SWS_CORE_01119] [SWS_CORE_01136] [SWS_CORE_01129]

Жизненный цикл и право собственности

Copy- и Move-конструирование, присваивание и уничтожение являются условными в зависимости от свойств T noexcept. [SWS_CORE_01105] [SWS_CORE_01106] [SWS_CORE_01114] [SWS_CORE_01115] [SWS_CORE_01112]

Взаимодействие с другими классами

Спецификация требует поддержки ссылок lvalue посредством специализации Optional<T&>. [SWS_CORE_01032]

Ограничения & Обработка ошибок

Доступы operator*, operator-> и value() — это noexcept, но могут вызвать IsoStdBadOptionalAccessViolation, если значение отсутствует. Перед доступом можно использовать преобразование has_value() или bool. [SWS_CORE_01124] [SWS_CORE_01122] [SWS_CORE_01130] [SWS_CORE_01129] [SWS_CORE_01128]

Опциональность в смоделированных наборах данных

Optional — не просто общий удобный тип: Core явно называет его для необязательных элементов Record StdCppImplementationDataType категории STRUCTURE. Обязательные поля, напротив, отображаются напрямую их типом реализации. В качестве альтернативы Optional может выражать возможно отсутствующее возвращаемое значение функции. SWS Core §7.4 «Core data types» SWS Core §7.4.2 «Data types derived from the C++ standard» SWS LanguageBinding §7.1 «C++ binding for CppImplementationDataTypes»

Для Optional<T&> присваивание следует поведению rebind: оно связывает Optional-ссылку с новым объектом вместо записи через ссылку в исходно связанный объект. [SWS_CORE_01032] [SWS_CORE_01034]

Диаграмма активности: перед строго ориентированным на значение доступом проверяется состояние заполненности; альтернатива обрабатывает отсутствие без доступа к value(). Источники: SWS Core §7.4.2 «Data types derived from the C++ standard» [SWS_CORE_01129] [SWS_CORE_01130].
