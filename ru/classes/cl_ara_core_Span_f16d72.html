Использование по назначению

ara::core::Span<T, Extent> реализует std::span как представление связанных элементов; Extent может быть статическим или динамическим [SWS_CORE_01900] [SWS_CORE_01931].

Поколение & Разрушение

Span может быть сконструирован из указателей, C-массива, ara::core::Array, совместимого Container или другого Span [SWS_CORE_01942] [SWS_CORE_01943] [SWS_CORE_01944] [SWS_CORE_01945] [SWS_CORE_01947] [SWS_CORE_01950]. Copy-конструирование, Copy-присваивание и деструктор являются defaulted и exception-safe [SWS_CORE_01949] [SWS_CORE_01952] [SWS_CORE_01951].

Жизненный цикл и право собственности

Класс хранит представление, а не базовые элементы; интерфейс предоставляет указатели, ссылки и итераторы для доступа [SWS_CORE_01915] [SWS_CORE_01916] [SWS_CORE_01917] [SWS_CORE_01971]. Этот класс не управляет действительностью элементов, на которые имеются ссылки.

Ограничения & Обработка ошибок

Указанные операции являются constexpr, noexcept и безопасными в отношении исключений [SWS_CORE_01960] [SWS_CORE_01970] [SWS_CORE_01969]. Спецификация не определяет здесь отдельной проверки времени выполнения для границ operator[], front() или back() [SWS_CORE_01959] [SWS_CORE_01960] [SWS_CORE_01970].

Невладеющее представление непрерывных данных

Core классифицирует Span как тип View и тем самым концептуально приближает его к стандартной библиотеке C++. Тип передаёт представление, а не владение элементами; описанные в существующем блоке API доступы через указатели, ссылки и Iterator требуют, чтобы базовая последовательность продолжала быть действительной.
