Служит для вычисления и верификации криптографических кодов аутентификации сообщений на основе ключа.

Интерфейс обеспечивает вычисление и верификацию кодов аутентификации сообщений (Message Authentication Codes) на основе ключа для сообщений произвольной длины. После инициализации симметричным ключом через [SWS_CRYPT_22118] дайджесты MAC могут обрабатываться либо за один шаг, либо потоковым методом с помощью вызовов запуска, обновления и завершения. Полученный результат проверки можно затем запросить или напрямую сопоставить с требуемым значением. Все методы специфицированы как потокобезопасные и сигнализируют об ошибочных процессах или недостаточной емкости буфера через стандартизированные возвращаемые значения согласно [SWS_CRYPT_22116].

Контекст

Интерфейс MessageAuthnCodeCtx определяет криптографические операции для формирования и верификации кодов аутентификации сообщений на основе ключа (Message Authentication Codes, MAC). Он позволяет выполнять проверку подлинности и целостности произвольных объемов данных как через инкрементальные потоки данных, так и через отдельные непрерывные блоки памяти. Управление экземплярами осуществляется через предоставляемый тип интеллектуального указателя Sptr [SWS_CRYPT_22101].

В качестве центральных партнеров по взаимодействию выступают вызывающие компоненты приложения, а также ключевые объекты. Контекст может конфигурироваться либо напрямую с помощью объекта симметричного ключа SymmetricKey [SWS_CRYPT_22118], либо через логическое место хранения KeySlot [SWS_CRYPT_50026]. Передача данных осуществляется через буферные структуры, такие как ReadOnlyMemRegion для входных данных и ReadWriteMemRegion для вычисленных дайджестов MAC.

Жизненный цикл

Экземпляр контекста проходит определенную последовательность состояний от инициализации до предоставления результата MAC:

  • Uninitialized: после создания контекст еще не содержит ключа и отклоняет вызовы вычислений.
  • Configured: вызовом SetKey() с ключом [SWS_CRYPT_22118] или хранилищем ключей [SWS_CRYPT_50026] контекст инициализируется. В этом состоянии могут выполняться методы одиночного вызова (Single-Call) или запускаться потоковый сеанс.
  • Processing: вызов Start() без вектора инициализации [SWS_CRYPT_22111] или с IV [SWS_CRYPT_22110] открывает потоковую обработку. С помощью повторяющегося Update() [SWS_CRYPT_22113] подаются блоки данных. Прерывание возможно через Cancel() [SWS_CRYPT_50027].
  • Finished: метод Finish() [SWS_CRYPT_22115] завершает вычисление. Впоследствии результат может быть запрошен или сопоставлен.

Интерпретация: после завершения или прерывания контекст, по-видимому, остается в сконфигурированном состоянии и может повторно использоваться для новых операций. Все методы интерфейса специфицированы как потокобезопасные и бессбойные (exception-safe).

Диаграмма состояний: жизненный цикл и переходы состояний контекста MAC. Источники: [SWS_CRYPT_22118], [SWS_CRYPT_50026], [SWS_CRYPT_22110], [SWS_CRYPT_22111], [SWS_CRYPT_22113], [SWS_CRYPT_22115], [SWS_CRYPT_50027], [SWS_CRYPT_22116], [SWS_CRYPT_50029], [SWS_CRYPT_50031]

Путь использования

Интерфейс поддерживает два типичных сценария использования: инкрементальный потоковый режим и обработку одиночным вызовом.

В потоковом сценарии вызывающая сторона сначала привязывает ключ через SetKey() [SWS_CRYPT_22118]. До начала можно запросить параметры алгоритма, такие как рекомендуемый размер IV через GetRecommendedIvSize() [SWS_CRYPT_50135], а также максимальный размер фрагмента через GetMaximumChunkSize() [SWS_CRYPT_50033]. После вызова Start() [SWS_CRYPT_22110] фрагменты сообщения последовательно обрабатываются с помощью Update() [SWS_CRYPT_22113]. Как только все данные переданы, Finish() завершает вычисление [SWS_CRYPT_22115]. Сформированный дайджест затем копируется с помощью GetDigest() в буфер [SWS_CRYPT_22116], минимальный размер которого может быть предварительно определен через GetDigestSize() [SWS_CRYPT_50134]. В качестве альтернативы Compare() [SWS_CRYPT_50133] или CompareSubspan() [SWS_CRYPT_50028] позволяет выполнить прямое сопоставление с ожидаемым эталонным значением.

Диаграмма последовательности: процесс инкрементального вычисления MAC в потоковом режиме. Источники: [SWS_CRYPT_22118], [SWS_CRYPT_22110], [SWS_CRYPT_22113], [SWS_CRYPT_22115], [SWS_CRYPT_22116]

Если все сообщение уже доступно целиком, вычисление может выполняться без потокового режима через Generate() [SWS_CRYPT_50029] или в усеченном виде через GenerateSubspan() [SWS_CRYPT_50030] за один шаг. Для верификации аналогично доступны методы Verify() [SWS_CRYPT_50031] и VerifySubspan() [SWS_CRYPT_50032].

Сценарии ошибок

Ошибки сигнализируются через возвращаемый тип ara::core::Result и охватывают следующие причины:

  • Ошибки состояния: вызов Start(), Generate() или Verify() без сконфигурированного ключа завершается сбоем с kUninitializedContext [SWS_CRYPT_22110] [SWS_CRYPT_50029]. Вызовы Update(), Finish() или Cancel() без предварительного запуска возвращают kProcessingNotStarted [SWS_CRYPT_22113] [SWS_CRYPT_22115] [SWS_CRYPT_50027]. Доступ к результату до завершения возвращает kProcessingNotFinished [SWS_CRYPT_22116] [SWS_CRYPT_50133].
  • Ошибки ключей и прав доступа: если переданный ключ несовместим с контекстом, возникает kIncompatibleObject [SWS_CRYPT_22118] [SWS_CRYPT_50026]. Если у ключа отсутствует полномочие kAllowMac, это приводит к kUsageViolation [SWS_CRYPT_22118] [SWS_CRYPT_22110]. Если конфигурация указывает на пустой KeySlot, возвращается kEmptyKeySlot [SWS_CRYPT_22110].
  • Ошибки параметров и буфера: слишком малый выходной буфер отклоняется с kInsufficientCapacity [SWS_CRYPT_22116] [SWS_CRYPT_50029]. Неподдерживаемые длины входных данных или IV приводят к kInvalidInputSize [SWS_CRYPT_22113] [SWS_CRYPT_50133]. Если режимы или конфигурации IV не поддерживаются алгоритмом, результатом становится kUnsupported [SWS_CRYPT_22110] [SWS_CRYPT_50029]. Занятые криптографические аппаратные ресурсы возвращаются как kBusyResource [SWS_CRYPT_22110].

Если обработка данных перед вызовом не была надлежащим образом начата с помощью метода Start(), выполнение завершается ошибкой. Идентичное поведение при отмене еще не завершенных потоковых обработок характерно для всех связанных контекстных интерфейсов криптографического модуля:

      Использование

В качестве параметра ожидаемый MAC-дайджест передается через ReadOnlyMemRegion expected. Функция возвращает ara::core::Result<bool>, содержащий true, если вычисленное значение MAC точно совпадает с ожидаемым значением, и false в противном случае [SWS_CRYPT_50133].

      Параллелизм и ограничения
      

      Метод объявлен как const, а также noexcept и в соответствии со спецификацией является потокобезопасным (thread-safe), а также безопасным относительно исключений (exception safe) [SWS_CRYPT_50133]. Существенным предварительным условием является предварительно успешно завершенное вычисление дайджеста через Finish() [SWS_CRYPT_50133].

Выполняющуюся, еще не завершенную потоковую операцию при необходимости можно прервать через Cancel ([SWS_CRYPT_50027]).
