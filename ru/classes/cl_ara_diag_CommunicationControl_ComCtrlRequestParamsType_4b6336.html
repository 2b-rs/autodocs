ComCtrlRequestParamsType is a structure, which holds all parameters of an UDS 0x28 communicationControl request.

ComCtrlRequestParamsType содержит все параметры запроса UDS-0x28 CommunicationControl. Структура содержит controlType, communicationType и целевой nodeIdentificationNumber. Он передается как связанный параметр в CommunicationControl::CommCtrlRequest(), поскольку запрос может содержать необязательные элементы. MetaInfo и CancellationHandler остаются отдельными параметрами обратного вызова. [SWS_DM_00805] [SWS_DM_01562] [SWS_DM_01563] [SWS_DM_01564] [SWS_DM_00808]

Константы / переменные

  • communicationType CommunicationType from UDS request.
  • controlType ControlType from UDS request.
  • nodeIdentificationNumber Node identifier to which the request is addressed to.
