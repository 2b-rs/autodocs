Контекст

C++-класс ara::rds::RawDataStreamClient является частью функционального кластера Raw Data Stream (rds) платформы AUTOSAR Adaptive Platform в релизе R25-11. Он служит клиентской конечной точкой для чтения и записи бинарных потоков необработанных данных через базовое сетевое соединение. Через артефакт моделирования, идентифицируемый с помощью ara::core::InstanceSpecifier, клиент привязывается к конкретному коммуникационному порту и инкапсулирует установление соединения, а также передачу данных для прикладных потоков байтов.

Жизненный цикл

Экземпляр ara::rds::RawDataStreamClient не может быть инстанцирован через обычные конструкторы. Конструктор по умолчанию не является общедоступным, а конструктор копирования [SWS_RDS_11303] и оператор присваивания с копированием [SWS_RDS_11304] явно удалены (move-only). Создание осуществляется вместо этого через статический фабричный метод Create [SWS_RDS_10482] с передачей соответствующего ara::core::InstanceSpecifier. Create специфицирован как потокобезопасный и в случае успеха возвращает инициализированный экземпляр клиента в ara::core::Result.

Отношения владения являются эксклюзивными: перемещение экземпляров возможно с помощью конструктора перемещения [SWS_RDS_11305] и оператора присваивания с перемещением [SWS_RDS_11306]. Обе операции объявлены с noexcept, однако не являются потокобезопасными.

После создания клиент находится в отключенном состоянии. Активное сетевое соединение затем устанавливается через Connect [SWS_RDS_10484], [SWS_RDS_11307]. Завершение соединения выполняется корректно через Shutdown [SWS_RDS_10485]. Деструктор ~RawDataStreamClient [SWS_RDS_10483] гарантирует, что соединение, которое все еще открыто, автоматически закрывается при выходе из области видимости. Он специфицирован как непотокобезопасный.

Диаграмма состояний: фазы жизненного цикла и переходы между состояниями экземпляра RawDataStreamClient. Источники: [SWS_RDS_10482], [SWS_RDS_10484], [SWS_RDS_10485], [SWS_RDS_10483]

Путь использования

Штатный процесс передачи бинарных данных делится на создание, установление соединения, передачу полезных данных и разрыв соединения:

  1. Инстанцирование: Приложение синхронно создает клиент с помощью Create(instance) [SWS_RDS_10482].
  2. Установление соединения: Перед первым обменом данными устанавливается соединение. Для этого доступен либо блокирующий вариант Connect() [SWS_RDS_10484], либо перегрузка с ограничением по времени Connect(timeout) [SWS_RDS_11307] с таймаутом типа std::chrono::milliseconds.
  3. Отправка данных: Запись выполняется через WriteData(data, maxLength) [SWS_RDS_10487] или WriteData(data, maxLength, timeout) [SWS_RDS_11310] соответственно. Полезные данные передаются как std::unique_ptr<ara::core::Byte[]>, в результате чего буфер памяти эксклюзивно переходит под управление операции отправки.
  4. Прием данных: Для чтения данных служит ReadData(maxLength) [SWS_RDS_10486] или вариант с контролем времени ReadData(maxLength, timeout) [SWS_RDS_11309]. При успешном приеме возвращается ReadDataResult.
  5. Разрыв соединения: После завершения передачи данных приложение явно закрывает сетевое соединение через Shutdown() [SWS_RDS_10485].

Диаграмма последовательности: типичная последовательность вызовов от создания до передачи данных и разрыва соединения. Источники: [SWS_RDS_10482], [SWS_RDS_10484], [SWS_RDS_10487], [SWS_RDS_10486], [SWS_RDS_10485]

Сценарии ошибок

Все функциональные интерфейсы ara::rds::RawDataStreamClient не используют исключений C++ и сигнализируют об успехе или неудаче через тип возвращаемого значения ara::core::Result с гарантией noexcept:

  • Сбой установления соединения: Если клиенту не удается установить соединение с противоположной стороной или истекает указанный лимит времени, вызов Connect завершается сбоем и возвращает код ошибки из домена ошибок RdsErrc в ara::core::Result<void> [SWS_RDS_10484].
  • Ошибки операций записи и чтения: если соединение разрывается во время передачи или превышается таймаут WriteData или ReadData, соответствующий объект результата содержит надлежащий код ошибки [SWS_RDS_10486], [SWS_RDS_10487], [SWS_RDS_11309], [SWS_RDS_11310].
  • Ошибка конфигурации: если переданный ara::core::InstanceSpecifier отсутствует в системной модели или не сопоставлен с действительным портом связи, Create завершается сбоем уже на этом этапе и возвращает соответствующую причину ошибки в объекте Result [SWS_RDS_10482].

Настоящее руководство основано исключительно на спецификации AUTOSAR Adaptive Platform Release R25-11.
