Использование по назначению

Интерфейс обеспечивает идентификацию группы DoIP. Приложение реализует GetGidStatus, который асинхронно предоставляет статус GID; без настроенного GID диспетчер диагностики вызывает этот метод. [SWS_DM_00720] [SWS_DM_00724] [SWS_DM_00813]
