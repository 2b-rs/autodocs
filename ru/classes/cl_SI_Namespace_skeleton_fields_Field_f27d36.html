Использование по назначению

Этот скелетный класс поля создается для каждого элемента ServiceInterface, смоделированного как поле. Пространство имен, имя и заголовок <SiNamespaceDerivedDirectoryPath>/<SiShortname>_skeleton.h получены из модели ServiceInterface манифеста ARXML. Он используется через собственную реализацию службы, которая наследуется от сгенерированного класса Skeleton. [SWS_CM_00007]

Использование

Update(value) обновляет внутреннее значение Field и инициирует передачу обновлённых данных подписчикам; уведомление отправляется при наличии notifier у Field. Возвращаемое значение сигнализирует успех или подходящий ComErrc. [SWS_CM_00119]

Асинхронные обработчики могут быть зарегистрированы для входящих запросов получения или установки. Обработчик получения существует только с Field.hasGetter == TRUE, обработчик установки только с Field.hasSetter == TRUE; оба имеют перегрузки для предоставленного контекста выполнения. Обработчик ошибок транспорта можно установить и удалить. [SWS_CM_00114] [SWS_CM_11360] [SWS_CM_00116] [SWS_CM_11362] [SWS_CM_00096] [SWS_CM_00097] [SWS_CM_00098]
