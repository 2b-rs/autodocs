class TransmitCertificate {...};

Class to implement the subfunction TransmitCertificate (29 04) of UDS service Authentication as interface to application. This class implements a so called generic interface, where the application has means to handle one ore more certificateEvaluationId transferred certificates.

Использование по назначению

ara::diag::TransmitCertificate отображает UDS-подфункцию TransmitCertificate (0x29/0x04) как интерфейс приложения. Приложение может обработать один или несколько переданных сертификатов с помощью certificateEvaluationId [SWS_DM_01961].

Поколение & Разрушение

Экземпляр создаётся с InstanceSpecifier DiagnosticTransmitCertificateInterface и ConcurrencyType [SWS_DM_01962]. Тип не копируем и не перемещаем; виртуальный деструктор имеет свойство noexcept [SWS_DM_01964] [SWS_DM_01963] [SWS_DM_01966] [SWS_DM_01965] [SWS_DM_01967].

Взаимодействие с другими классами

Ограничения & Обработка ошибок

Для отрицательных UDS-ответов следует использовать подходящую ошибку из DiagUdsNrcErrc [SWS_DM_01968]. Повторное предложение может вернуть DiagOfferErrc::kAlreadyOffered [SWS_DM_01969].

функция Process [SWS_DM_01968] Upstream: RS_Diag_04251

virtual ara::core::Future< void > Process (std::uint16_t certificate EvaluationId, ara::core::Span< ara::core::Byte const > certificate Data, const MetaInfo &metaInfo, CancellationHandler cancellation Handler) noexcept=0;

This method is used to process certificates send by a diagnostic tester, via the UDS subfunction TransmitCertificate inside the application. There is no specific semantics for the certificate and it is left to the application to process the received certificate and derive the needed actions.

Виртуальный метод Process обрабатывает сертификат, отправленный диагностическим тестером через подфункцию UDS TransmitCertificate внутри приложения; Сертификат не имеет конкретной семантики; приложение должно выполнить необходимые действия. Параметрами являются 16-битный certificateEvaluationId из сообщения запроса UDS, certificateData, который необходимо проверить, metaInfo запроса и cancellationHandler, который можно использовать для запроса статуса прерывания с помощью IsCanceled или регистрации уведомителя с помощью SetNotifier [SWS_DM_01968]. В случае успеха возвращаемый ara::core::Future<void> предоставляет пустое значение.
