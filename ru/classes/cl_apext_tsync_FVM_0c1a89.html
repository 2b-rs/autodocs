Freshness-Value-Manager для защищенных сообщений времени

FVM предоставляет значения актуальности для дополнительной безопасной синхронизации времени. Перед использованием менеджер должен быть инициализирован; Отправитель и получатель используют отдельные запросы Tx/Rx в процессе ICV. SWS Time Synchronization §7.2 «Normal Operation» [SWS_TS_14178] [SWS_TS_14183] [SWS_TS_14185]

Планируйте сценарии ошибок

Если значение актуальности временно недоступно, спецификация предусматривает повторные попытки до заданного предела. Как только это достигается, генерация прерывается или полученное сообщение отбрасывается. [SWS_TS_14184] [SWS_TS_14186]
