Использование по назначению

SovdOperationExecution представляет выполнение операции SOVD. ExecuteCapability() обрабатывает Capability execute, freeze или reset, GetStatus() считывает статус, а Terminate() завершает текущее выполнение. [SWS_DM_02197] [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202] Для вызова считывания статуса DM использует экземпляр, сопоставленный с execution-id, и формирует статус, Capability и параметры ответа из GetStatusResponse. [SWS_DM_02180] [SWS_DM_02181]

Жизненный цикл и право собственности

Конструктор и виртуальный деструктор определены по умолчанию и являются exception-safe. [SWS_DM_02198] [SWS_DM_02199] После Terminate DM отбрасывает экземпляр; дальнейшие вызовы с тем же execution-id больше невозможны, а их результат не определён. [SWS_DM_02179]

Ограничения & Обработка ошибок

Все три метода операций асинхронно возвращают соответствующий положительный тип либо применимую ошибку SOVD. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202] Данные Content действительны только до выполнения Promise или отмены. CancellationHandler нельзя сохранять или использовать за пределами времени жизни соответствующей операции. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202] Методы являются exception-safe и thread-safe. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202]

Для асинхронно запущенной операции DM использует сгенерированный идентификатор выполнения в качестве назначения этому экземпляру выполнения. [SWS_DM_02177] Terminate() получает причину завершения, а GetStatus получает текущий MetaInfo и CancellationHandler. [SWS_DM_02202] [SWS_DM_02201] Реализация этих трех чисто виртуальных функций зависит от приложения. [SWS_DM_02384] [SWS_DM_02201] [SWS_DM_02202]

Виртуальный деструктор позволяет уничтожить объект через интерфейс. [SWS_DM_02199]

Автоматически сформированное примечание по использованию, выведенное из этого элемента спецификации AUTOSAR R25-11, — не официальный текст AUTOSAR. Подтверждение: [SWS_…].

Виртуальный метод ExecuteCapability вызывается для поддержки выполнения/заморозки/сброса указанной операции SOVD. Параметрами являются OperationExecutionCapability, который должен быть выполнен, sovd_content_data (действителен до тех пор, пока обещание не будет выполнено или отменено через cancellation_handler), meta_info с дополнительной метаинформацией и cancellation_handler, который информирует о запросе на прерывание и объект которого не может быть сохранен или доступен после времени жизни вызова. [SWS_DM_02384]. Возвращенное значение ara::core::Future<OperationExecutionStatus> предоставляет статус выполнения, если ответ положительный, в противном случае — ошибку SOVD.

Обработка ошибок & параллелизм

В случае ошибки необходимо использовать применимый код ошибки SOVD согласно ISO 17978-3/ASAM SOVD 1.1. Этот метод является потокобезопасным и безопасным для исключений.
