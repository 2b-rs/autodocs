Использование по назначению

<DataIdentifierInterface> предоставляет прикладной интерфейс для идентификаторов диагностических данных. Приложение реализует Read() для роли чтения и Write() для роли записи; Обе операции доставляют результат асинхронно через ara::core::Future. [SWS_DM_00601] [SWS_DM_00640] [SWS_DM_00598]

Поколение & Разрушение

Конструктор связывает интерфейс через ara::core::InstanceSpecifier и устанавливает предполагаемую конкуренцию реализации с помощью ConcurrencyType. Offer() включает пересылку запросов обработчику, StopOffer() выключает. Если услуга уже предлагается, Offer предоставляет DiagOfferErrc::kAlreadyOffered. [SWS_DM_00585] [SWS_DM_00599] [SWS_DM_00600]

Жизненный цикл и право собственности

Интерфейс нельзя копировать, перемещать или присваивать, поскольку операции Copy и Move удалены. Он имеет виртуальный деструктор. [SWS_DM_01663] [SWS_DM_01664] [SWS_DM_01665] [SWS_DM_01666] [SWS_DM_00586]

Ограничения & Обработка ошибок

При чтении и записи каждый получает MetaInfo, а также CancellationHandler, посредством которого доступны статус прерывания и уведомление о прерывании. Ошибки асинхронного метода возвращаются как DiagUdsNrcErrc или ApApplicationError; методы не являются потокобезопасными. [SWS_DM_00640] [SWS_DM_00598]

  • InstanceSpecifierMappingIntegrityViolation — InstanceSpecifier не может быть разрешён в модели либо не ссылается на PortPrototype.

  • ProcessMappingViolation — существует подходящий InstanceRef, но нет подходящего моделируемого процесса для процесса времени выполнения.
  • InstanceSpecifierAlreadyInUseViolation – InstanceSpecifier уже используется в процессе.
