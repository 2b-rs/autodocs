Генерирует криптографические случайные данные и управляет внутренним состоянием генератора, а также подачей энтропии в него.

Интерфейс ara::crypto::cryp::RandomGeneratorCtx предоставляет потокобезопасный контекст для генерации псевдослучайных чисел в подготовленные буферы [SWS_CRYPT_22915]. В зависимости от реализации контекста внутреннее состояние генератора должно быть предварительно инициализировано через Seed с помощью данных энтропии или ключей ([SWS_CRYPT_22911], [SWS_CRYPT_22912]). При отсутствии инициализации или исчерпании запаса энтропии функция генерации завершает вызов соответствующими стандартизированными кодами ошибок [SWS_CRYPT_22915].

Контекст

Интерфейс ara::crypto::cryp::RandomGeneratorCtx определяет криптографический контекст для генераторов случайных чисел внутри модуля Adaptive crypto. Являясь специализацией CryptoContext, класс служит для генерации криптографически безопасных (псевдо)случайных последовательностей, а также для управления внутренним состоянием генератора. Прикладные службы обычно обращаются к экземплярам этого интерфейса для получения ключевого материала, векторов инициализации или случайных значений для протоколов, критичных к безопасности. Предоставление и обмен экземплярами контекста осуществляются преимущественно через разделяемые умные указатели, для чего предусмотрен псевдоним типа Sptr [SWS_CRYPT_22901].

Жизненный цикл

Время жизни контекста генератора случайных чисел управляется подсчетом ссылок через std::shared_ptr ([SWS_CRYPT_22901]). После инстанцирования генератор, в зависимости от базовой реализации, либо уже находится в готовом к работе состоянии, либо требует предварительной инициализации со стороны приложения. Для инициализации внутреннего состояния генератора служит метод Seed, которому передается либо область сырой памяти через ReadOnlyMemRegion [SWS_CRYPT_22911], либо объект симметричного ключа типа SymmetricKey::Sptr [SWS_CRYPT_22912]. Все ключевые функции-члены (Seed, AddEntropy и Generate) согласно спецификации объявлены безопасными относительно исключений (noexcept) и потокобезопасными ([SWS_CRYPT_22911], [SWS_CRYPT_22912], [SWS_CRYPT_22914], [SWS_CRYPT_22915]), благодаря чему параллельные вызовы из нескольких потоков поддерживаются без блокировок внутри приложения.

Путь использования

Стандартная последовательность использования включает подготовку состояния генератора, опциональное подмешивание дополнительной энтропии и последующее извлечение случайных данных:

  • Инициализация состояния (сидирование): если контекст требует сидирования со стороны вызывающего компонента, выполняется Seed с данными энтропии [SWS_CRYPT_22911] или симметричным ключом [SWS_CRYPT_22912]. Если реализация основана на аппаратных средствах или жестко инициализирована и не поддерживает сидирование, вызов завершается с ошибкой.
  • Подмешивание дополнительной энтропии: с помощью AddEntropy [SWS_CRYPT_22914] внутреннее состояние во время выполнения может быть обогащено вновь полученной энтропией (передаваемой как ReadOnlyMemRegion).
  • Генерация случайной последовательности: метод Generate [SWS_CRYPT_22915] заполняет переданный выходной буфер ReadWriteMemRegion псевдослучайными данными.

Диаграмма последовательности: стандартный процесс инициализации состояния, подачи энтропии и генерации случайных данных в RandomGeneratorCtx. Источники: [SWS_CRYPT_22911], [SWS_CRYPT_22912], [SWS_CRYPT_22914], [SWS_CRYPT_22915]

Сценарии ошибок

Операции возвращают свои результаты в ara::core::Result и обладают определенной семантикой отката при ошибках:

  • Неинициализированный контекст: если приложение вызывает Generate, хотя контекст обязательно требует предварительного сидирования, операция завершается неудачей с ara::crypto::CryptoErrc::kUninitializedContext [SWS_CRYPT_22915].
  • Нехватка энтропии: если контекст временно не может сгенерировать запрошенный объем байтов из-за исчерпания внутреннего пула энтропии, Generate сообщает об ошибке ara::crypto::CryptoErrc::kBusyResource [SWS_CRYPT_22915]. В этом случае приложение может повторить вызов позже или выполнить дополнительное сидирование.
  • Недопустимое использование ключа: если в Seed передается SymmetricKey, в сконфигурированных правах использования которого отсутствует флаг kAllowRngInit, вызов отклоняется с ara::crypto::CryptoErrc::kUsageViolation [SWS_CRYPT_22912].
  • Неподдерживаемая функциональность: если конкретная реализация контекста принципиально не поддерживает установку сида или последующее подмешивание энтропии, Seed ([SWS_CRYPT_22911], [SWS_CRYPT_22912]) и AddEntropy [SWS_CRYPT_22914] завершают вызов с кодом ошибки ara::crypto::CryptoErrc::kUnsupported.

Настоящее руководство основано на спецификации AUTOSAR Adaptive Platform R25-11 (модуль crypto) и опирается исключительно на указанные требования спецификации.

Метод AddEntropy класса ara::crypto::cryp::RandomGeneratorCtx служит для обновления внутреннего состояния генератора случайных чисел (RNG) путем подмешивания дополнительно переданных значений энтропии [SWS_CRYPT_22914]. Объявление доступно через заголовочный файл ara/crypto/cryp/random_generator_ctx.h [SWS_CRYPT_22914]. В качестве входного параметра функция ожидает объект типа ReadOnlyMemRegion с именем entropy, который инкапсулирует область памяти с добавляемым значением энтропии [SWS_CRYPT_22914].

Вызов выполняется синхронно (интерпретация: интерфейс возвращает результат напрямую без асинхронного типа результата). Результат возвращается в виде ara::core::Result<void>, которое в случае успеха является пустым, если метод поддерживается и энтропия была успешно подмешана [SWS_CRYPT_22914]. Если же конкретный контекст генератора случайных чисел не поддерживает добавление энтропии, вызов завершается сбоем и возвращает код ошибки ara::crypto::CryptoErrc::kUnsupported с гарантированной семантикой отката [SWS_CRYPT_22914].

Что касается параллелизма и отказоустойчивости, интерфейс специфицирован как потокобезопасный (thread-safe), а также безопасный относительно исключений (exception safe) и снабжен идентификатором noexcept [SWS_CRYPT_22914]. Таким образом, вызывающие стороны могут безопасно вызывать функцию из нескольких потоков, однако всегда должны анализировать возвращаемое ara::core::Result для обработки отсутствия поддержки ввода энтропии в соответствующем контексте [SWS_CRYPT_22914].

Объявление находится в заголовке ara/crypto/cryp/random_generator_ctx.h с сигнатурой virtual ara::core::Result<void> Seed(ReadOnlyMemRegion seed) noexcept = 0; [SWS_CRYPT_22911].
