Обобщённый шаблон DID

GenericDataIdentifier — это универсальный перехватчик приложения для настроенного Diagnostic Data Identifier. DM назначает UDS ReadDataByIdentifier или WriteDataByIdentifier соответствующему интерфейсу через назначение порта DEXT; класс не обрабатывает «alle DIDs» без конфигурации SWS Diagnostics §7.3.6 «Diagnostic Data Management».

Чтение и письмо

Read получает DID, MetaInfo и CancellationHandler и возвращает OperationOutput для полезной нагрузки или NRC [SWS_DM_00636]. Write также получает данные запроса и успешно завершает [SWS_DM_00637] или NRC. DM обрабатывает услугу UDS и проверку авторизации; приложение только проверяет формат данных, специфичный для DID, и выполняет бизнес-операцию.

Параллелизм и время жизни данных

Параллельные обратные вызовы DID разрешены только для сеансов по умолчанию, нескольких диалогов, обрабатываемых одновременно, одного и того же требуемого порта и DataIdentifierConcurrencyType::kConcurrentType [SWS_DM_00941] [SWS_DM_00942] [SWS_DM_00943]. В противном случае DM подавляет дальнейшие вызовы до тех пор, пока не завершится [SWS_DM_00944]. Не копируйте и не сохраняйте requestData и MetaInfo в асинхронной загробной жизни.
