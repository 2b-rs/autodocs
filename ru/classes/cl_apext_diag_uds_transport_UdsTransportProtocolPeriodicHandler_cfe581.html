Использование по назначению

UdsTransportProtocolPeriodicHandler поддерживает функцию UDS 0x2A для периодической передачи данных. Он обеспечивает транспортировку и соединение конкретных границ и операции передачи. [SWS_DM_01064]

Взаимодействие с другими классами

GetMaxPayloadLength() возвращает максимально допустимую длину полезной нагрузки одной периодической передачи для канала. DM использует ReadDataByPeriodidicIdentifier для проверки длины каждого запрошенного идентификатора и отвечает NRC 0x14, если она превышена. GetNumberOfPeriodicMessages() возвращает разрешенное количество периодических сообщений для соединения. [SWS_DM_01066] [SWS_DM_01050] [SWS_DM_01065]

PeriodicTransmit() отправляет список переданных сообщений по порядку. Если передача не удалась, процесс отправки завершается и запускается периодическое подтверждение передачи с тем же списком и количеством отправленных сообщений; DM использует эту операцию для инициируемых передач PDID. [SWS_DM_01067] [SWS_DM_01062]
