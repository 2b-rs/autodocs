Домен сбоя для защиты E2E

ComE2EErrorDomain изолирует ошибки сквозного тестирования от общего пространства ошибок связи. Это часть путей данных для событий, методов и полей, для которых настроен соответствующий профиль E2E. SWS CM §7.4 «Safety» описывает функцию защиты.

Оценка

Name(), Message() и ThrowAsException() образуют тот же механизм домена сбоя, что и общая область связи. Для полученных сэмплов ProfileCheckStatus предоставляет более точную информацию, видимую для каждого сэмпла; Поэтому код ошибки не обязательно должен ассоциироваться с каждым статусом. EXP ARAComAPI §4.7 «Error Handling» представляет общую модель.

Диаграмма активности: проверка E2E сопоставляется со статусом Sample; приложения оценивают индивидуальный ProfileCheckStatus. Источник: SWS CM §7.4.1 «End-to-end communication protection for SOMEIP».
