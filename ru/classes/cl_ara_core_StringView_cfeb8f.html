Использование по назначению

ara::core::StringView реализует std::basic_string_view с типами значений, указателей и ссылок, специализированными для char [SWS_CORE_02001] [SWS_CORE_02100] [SWS_CORE_02101] [SWS_CORE_02103]. Его можно использовать независимо от ara::core::Initialize и Deinitialize [SWS_CORE_15002].

Поколение & Разрушение

Представление можно создать пустым, начиная с const char* с длиной или без нее, или путем копирования/перемещения. Создание, копирование/перемещение, назначение и уничтожение выполняются constexpr, noexcept и защищены от исключений [SWS_CORE_02112] [SWS_CORE_02113] [SWS_CORE_02114] [SWS_CORE_02115] [SWS_CORE_02117] [SWS_CORE_02116] [SWS_CORE_02118] [SWS_CORE_02119].

Жизненный цикл и право собственности

Класс представляет собой представление и через data() предоставляет const-указатель [SWS_CORE_02136]. Интерфейс не описывает передачу владения базовыми символами; поэтому время жизни ссылаемой памяти должно соответствовать использованию представления.

Взаимодействие с другими классами

Помимо итераторов и запросов размера, тип предлагает удаление префиксов/суффиксов, сравнения, contains, функции поиска, а также substr() [SWS_CORE_02120] [SWS_CORE_02128] [SWS_CORE_02137] [SWS_CORE_02138] [SWS_CORE_02142] [SWS_CORE_02154] [SWS_CORE_02157] [SWS_CORE_02141]. BasicString принимает и создает это представление в нескольких интерфейсах [SWS_CORE_03302] [SWS_CORE_03308] [SWS_CORE_03301].

Ограничения & Обработка ошибок

at(), сравнения на основе позиции, copy() и substr() запускают IsoStdOutOfRangeViolation вместо std::out_of_range из [SWS_CORE_02133] [SWS_CORE_02143] [SWS_CORE_02140] [SWS_CORE_02141], если позиция недействителен. Указанные операции StringView защищены от исключений [SWS_CORE_02131] [SWS_CORE_02156] [SWS_CORE_02158].

Представление UTF-8 и граница времени жизни

Спецификация Core относит StringView к String-Views и ограничивает их в Adaptive Platform значением char, поскольку платформа повсеместно использует UTF-8. Решающее значение имеет правило времени жизни: программист обеспечивает, чтобы View не пережило свой массив символьной памяти. SWS Core §7.4 «Core data types» SWS Core §7.4.2 «Data types derived from the C++ standard»

Привязка языка различает моделируемые строковые типы данных и их псевдонимы C++. Интерпретация: StringView — подходящее представление API для чтения, если сгенерированная строка не должна требовать передачи права собственности; однако сама привязка модели определяет конкретный тип создаваемой строки.
