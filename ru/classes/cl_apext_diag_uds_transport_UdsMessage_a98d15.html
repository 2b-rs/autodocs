класс apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

Использование по назначению

UdsMessage представляет сообщение UDS между общим ядром DM либо UdsTransportProtocolMgr и конкретной реализацией UdsTransportProtocolHandler. Объект предоставляет память для запросов и ответов UDS. [SWS_DM_00291]

Поколение & Право собственности

Экземпляры с оптимизированным распределением ресурсов создаются исключительно ядром DM; Protocol Handler может читать и записывать их, но не должен создавать сам. Поэтому Default-конструктор защищён. При принятой Indication UdsMessagePtr имеет действительный объект ёмкостью не менее одного байта; первоначально Buffer, предоставленный GetPayload(), пуст.
