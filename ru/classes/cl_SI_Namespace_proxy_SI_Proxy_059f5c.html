Взаимодействие с другими классами

Немедленный поиск с использованием FindService() принимает InstanceIdentifier или InstanceSpecifier и возвращает соответствующие дескрипторы. Поиск регистрации с использованием StartFindService() вызывает обработчик при обнаружении соответствующих экземпляров службы; возвращенный FindServiceHandle завершает мониторинг с помощью StopFindService().
