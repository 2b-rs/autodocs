SovdContentConcurrencyType устанавливает параллелизм порта, связанного с контентом SOVD. [SWS_DM_02182] Поля read и write определяют настройку ConcurrencyType для операций чтения и записи соответственно, и каждое из них по умолчанию имеет значение kNotConcurrent. [SWS_DM_02183] [SWS_DM_02184] readWrite управляет одновременным выполнением API чтения и записи; с помощью kConcurrent DM может вызывать их параллельно. [SWS_DM_02185]
