Class representing Function Group defined in meta-model (ARXML). An instance of this class will represent Function Group defined inside meta-model (ARXML). Граница согласованно управляемого множества процессов

FunctionGroup является API представителем настроенного Function Group. Он объединяет модельные процессы, которые последовательно запускаются и завершаются через состояния; Модельный процесс не может быть назначен нескольким Function Groups SWS EM §7.4.3 «Function Group State».

MachineFG и группы, близкие к приложению

Function Group MachineFG описывает Machine States и в основном используется для жизненного цикла машины. Другие Function Groups обычно управляют группами приложений пользовательского уровня. Конкретное назначение процессов происходит из Execution Manifests SWS EM §7.4 «State Management».

Диаграмма состояний: изменение состояния функциональной группы запрашивается Управлением состояниями и реализуется Управлением выполнением RS Execution Management, State Management (S. 16) SWS EM §7.4.5 «State Transition». Интерпретация: активное целевое состояние является примером объявления ModeDeclaration, определенного в манифесте.
