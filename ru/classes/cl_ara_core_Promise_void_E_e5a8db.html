Использование по назначению

ara::core::Promise<void, E> — это специализация для асинхронных операций, не имеющих значения. Тип ошибки должен быть ara::core::ErrorCode; вместе с Future класс обеспечивает поточно-безопасную последующую доставку без исключений при успехе или неудаче. [SWS_CORE_06340] [SWS_CORE_10800]

Жизненный цикл и право собственности

Копирование запрещено (=delete), перемещение возможно. Присвоение перемещения и деструктор отменяют все предыдущие Shared State. [SWS_CORE_06350] [SWS_CORE_06351] [SWS_CORE_06342] [SWS_CORE_06343] [SWS_CORE_06349]

Future< void, E > get_future () noexcept;

Return an associated Future with the same shared state as *this The returned Future is set as soon as this Promise receives the result, value, or an error. This fuction must only be called once as it is not allowed to have multiple Futures per Promise.

Используйте Сгенерировано ИИ / AI generated

Автоматически сформированное примечание по использованию, выведенное из этого элемента спецификации AUTOSAR R25-11, — не официальный текст AUTOSAR. Подтверждение: [SWS_…].

get_future (ara::core::Promise<void, E>) возвращает объект ara::core::Future, относящийся к ara::core::Promise<void, E> и имеющий то же Shared State. Возвращаемый Future устанавливается, как только этот Promise получает результат, значение или ошибку. Функцию разрешается вызывать лишь один раз для каждого Promise, поскольку несколько Futures для одного Promise не допускаются. Согласно спецификации вызов не потокобезопасен и exception-safe. Функция не определяет стандартизированных ошибок. [SWS_CORE_06344]

Обработка ошибок

  • IsoStdFutureErrcFutureAlreadyRetrievedViolation: если функция вызывается более одного раза в одном и том же общем состоянии.
  • IsoStdFutureErrcNoStateViolation: если *this не имеет Shared State.
