Шаблонный класс ara::log::Argument является частью модуля log в Adaptive Platform AUTOSAR для релиза R25-11. Объявление выполняется с синтаксисом template <typename T> class Argument final в виде обобщенного шаблона класса, защищенного от дальнейшего наследования идентификатором final.

В качестве партнеров по взаимодействию выступают прежде всего внутренние процедуры обработки фреймворка логирования, которые обрабатывают протоколируемые значения данных и перенаправляют их в выходные каналы.
