Служит контейнером данных для передачи значений актуальности и их битовой длины в защищенном внутрибортовом взаимодействии.

Структура apext::com::secoc::FVContainer служит в модуле Communication Management транспортным контейнером для значений актуальности с целью защиты внутрибортового взаимодействия [SWS_CM_11286]. Она инкапсулирует битовую длину значения в поле length, а также само значение актуальности в виде байтового вектора в поле value [SWS_CM_11344]. В зависимости от контекста использования вектор передает полные или усеченные значения, причем из-за отсутствия внутренних механизмов синхронизации при параллельном доступе требуется внешняя синхронизация.

Контекст

Структура данных apext::com::secoc::FVContainer является частью интерфейсов расширения платформы (Platform Extension Interfaces) модуля Communication Management и объявлена в заголовке apext/com/secoc/fvm.h [SWS_CM_11286]. Согласно архитектуре AUTOSAR Adaptive Platform интерфейсы Platform Extension Interfaces предназначены для использования или реализации автопроизводителями (OEM) либо интеграторами для адаптации функциональности платформы к проектным требованиям (AUTOSAR_AP_SWS_CommunicationManagement с. 536 §C «Platform Extension Interfaces»).

В рамках защищенного внутрибортового взаимодействия (Secure Onboard Communication, SecOC) apext::com::secoc::FVContainer служит стандартизированным контейнером передачи данных для значений актуальности (Freshness Values) [SWS_CM_11286]. Структура объединяет две взаимосвязанные части информации: точную длину значения актуальности в битах в поле length [SWS_CM_11344] и необработанные данные значения актуальности в виде байтового вектора в поле value [SWS_CM_11345]. При этом она выступает непосредственным интерфейсом между AUTOSAR Communication Management и специфичной для производителя реализацией Freshness Value Manager (FVM).

Контекстная диаграмма: встраивание FVContainer в качестве объекта передачи данных между Communication Management и расширением платформы FVM. Источники: [SWS_CM_11286], AUTOSAR_AP_SWS_CommunicationManagement с. 536 §C «Platform Extension Interfaces».

Жизненный цикл

Будучи структурой C++ (struct) [SWS_CM_11286] исключительно с открытыми переменными-членами, apext::com::secoc::FVContainer следует шаблону проектирования «чистый объект-значение». Создание экземпляра выполняется по мере необходимости либо на стеке, либо динамически в куче вызывающей или вызываемой стороной в зависимости от того, передается ли значение актуальности в метод или предоставляется в качестве возвращаемого значения [SWS_CM_11345].

Время жизни экземпляра в значительной степени связано с содержащимся вектором ara::core::Vector<std::uint8_t> [SWS_CM_11345]. При выходе из области видимости все ресурсы памяти, выделенные для значения актуальности, детерминированно освобождаются. Операции копирования и перемещения соответствуют стандартной семантике типов std::uint64_t [SWS_CM_11344] и ara::core::Vector [SWS_CM_11345]. Структура не содержит внутренних механизмов синхронизации; следовательно, параллельный доступ между потоками, вероятно, полностью возлагается на использующие компоненты (интерпретация).

Путь использования

Типичный сценарий использования включает создание, инициализацию и последующий анализ контейнера при обмене значениями актуальности для защиты или верификации сообщений. В зависимости от того, выступает ли apext::com::secoc::FVContainer параметром метода или возвращаемым значением, вектор value содержит либо полное значение актуальности, либо усеченное значение (truncated value) [SWS_CM_11345].

В процессе верификации или подписи Communication Management сначала запрашивает значение актуальности. Freshness Value Manager создает экземпляр контейнера, задает значащую битовую длину в поле length [SWS_CM_11344] и заполняет вектор value байтовыми значениями [SWS_CM_11345]. После возврата контейнера Communication Management считывает length и value, при этом битовая длина, предположительно, определяет точную границу, а неиспользуемые биты заполнения в последнем байте вектора игнорируются (интерпретация).

Диаграмма последовательности: типичное предоставление и анализ значения актуальности через FVContainer. Источники: [SWS_CM_11286], [SWS_CM_11344], [SWS_CM_11345].
