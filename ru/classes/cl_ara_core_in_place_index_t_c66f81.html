template <std::size_t Index> struct in_place_index_t {...};

Denote an index-distinguishing operation to be performed in-place. An instance of this type can be passed to certain constructors of ara::core::Variant to denote the intention that construction of the contained type shall be done in-place, i.e. without any copying taking place.

Служит тег-типом для прямого in-place-конструирования значения в Variant по его индексу.

Шаблон класса ara::core::in_place_index_t служит тег-типом для обозначения in-place-конструирования по определенному индексу внутри ara::core::Variant во избежание ненужных операций копирования или перемещения целевого значения. Экземпляры целенаправленно передаются подходящим конструкторам Variant, при этом создание осуществляется через конструктор по умолчанию из ara/core/utility.h [SWS_CORE_04032]. Поскольку конструктор определен как explicit и noexcept, неявные преобразования типов исключены, а создание экземпляра гарантированно является исключение-безопасным [SWS_CORE_04032].

Контекст

Шаблон класса ara::core::in_place_index_t представляет собой вспомогательную структуру в модуле core платформы AUTOSAR Adaptive Platform и предоставляется через заголовочный файл ara/core/utility.h [SWS_CORE_04032]. Его функциональная роль заключается в том, чтобы служить уникальным тег-типом для in-place-операций, различаемых по числовому индексу. Экземпляр этого типа передается специфическим конструкторам ara::core::Variant, чтобы указать намерение выполнить конструирование содержащегося типа непосредственно на месте («in-place») без выполнения операций копирования или перемещения.

Во взаимодействии между вызывающей стороной и типом-суммой ara::core::Variant шаблон ara::core::in_place_index_t берет на себя функцию тег-диспетчеризации (tag dispatching). Интерпретация: дифференциация на основе индексов, вероятно, особенно актуальна для экземпляров Variant, содержащих несколько альтернатив одного и того же типа; в этом случае выбор исключительно по типу данных был бы неоднозначным, поэтому адресация через параметр шаблона Index определяет точную альтернативу типа в пакете типов.

Жизненный цикл

Жизненный цикл ara::core::in_place_index_t элементарен и свободен от сложных переходов состояний. Создание выполняется через конструктор по умолчанию explicit in_place_index_t() noexcept = default; [SWS_CORE_04032]. Благодаря обозначению как explicit предотвращается неявное преобразование типов, что обеспечивает явное создание экземпляров со строгой типизацией [SWS_CORE_04032].

Поскольку ara::core::in_place_index_t функционирует как чистый индикатор и не имеет внутренних атрибутов или динамических ресурсов, объект полностью лишен состояния (stateless). Уничтожение тривиально и не влечет за собой побочных эффектов. С точки зрения параллелизма структура по своей сути потокобезопасна: поскольку изменяемые состояния отсутствуют, экземпляры могут использоваться через границы потоков без затрат на синхронизацию.

Путь использования

Типичный порядок использования ara::core::in_place_index_t делится на следующие шаги:

  • Определение индекса: вызывающая сторона определяет числовой параметр шаблона Index, представляющий желаемую альтернативу внутри ara::core::Variant.
  • Создание экземпляра тега: экземпляр ara::core::in_place_index_t<Index> создается через конструктор по умолчанию [SWS_CORE_04032]. Интерпретация: на практике создание, вероятно, предпочтительно выполняется в качестве временного аргумента непосредственно при вызове.
  • Передача в конструктор: экземпляр тега передается в качестве первого аргумента конструктору ara::core::Variant, за которым следуют аргументы конструктора для целевого типа, управляемого в этой позиции.
  • Прямая инициализация: ara::core::Variant конструирует целевой объект непосредственно в выделенной области памяти без предварительного создания временных копий.

Диаграмма последовательности: типичный процесс in-place-конструирования значения Variant через ara::core::in_place_index_t. Источники: [SWS_CORE_04032]

Сценарии ошибок

Что касается отказоустойчивости, ara::core::in_place_index_t отличается максимальной надежностью. Конструктор по умолчанию специфицирован с noexcept и считается безопасным относительно исключений («exception safe») [SWS_CORE_04032]. Для этой структуры не существует ни кодов ошибок, ни определенных состояний ошибок.

Ошибочное использование при неявных преобразованиях отклоняется во время компиляции за счет спецификации в качестве explicit [SWS_CORE_04032]. Если во время выполнения in-place-конструктора ara::core::Variant возникает исключение, оно исходит не от ara::core::in_place_index_t, а обусловлено поведением при ошибках конструируемого целевого типа.
