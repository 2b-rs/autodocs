Использование по назначению

UdsDtcStatusByteType представляет байт состояния UDS-DTC и предоставляет вспомогательные операции constexpr для запроса его битов состояния. Конструктор с переменным числом аргументов может устанавливать биты состояния DTC, передаваемые в качестве аргументов при его создании. [SWS_DM_00659] [SWS_DM_02084]
