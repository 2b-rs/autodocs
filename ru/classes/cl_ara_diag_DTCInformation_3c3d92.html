Просмотр DTC в памяти ошибок

DTCInformation — это интерфейс приложения для DTC связанных результатов соответствующего диагностического события: текущего состояния UDS-DTC, обновлений моментальных снимков, количества сохраненных записей, переполнения и контроля состояния DTC. Эта информация создается при обработке памяти событий и не может быть понята независимо от события, цели хранения и DTC конфигурации SWS Diagnostics §7.3.4.4 «Event memory».

Отслеживайте изменения

Статус UDS-DTC обновляется после обработки Event; SetDTCStatusChangedNotifier регистрирует Callback для этого изменения [SWS_DM_00667]. Другие Notifier разделяют изменения статуса, Snapshot, числа записей памяти и Overflow. Новый вызов регистрации заменяет предыдущий Callback соответствующей категории, поэтому приложению следует централизовать логику приёма.

Информация о DTC следует за обработкой событий и памяти; Уведомители предоставляют соответствующие изменения, а Clear запускает отдельный путь асинхронного удаления. Источники: SWS Diagnostics §7.3.4.4 «Event memory», SWS Diagnostics §7.3.4.4.2 «UDS DTC Status», SWS Diagnostics §7.3.4.4.5 «Clearing DTCs». Частичная интерпретация: на рисунке показаны отношения состояния и уведомлений.

Очистить коды DTC

Clear запускает асинхронное удаление DTC или группы DTC из [SWS_DM_00671]. Дождитесь будущего результата, прежде чем из очищенной памяти будет выполнено последующее техническое действие: ClearConditions и возможные блокировки являются частью обработки очистки DTC SWS Diagnostics §7.3.4.4.5 «Clearing DTCs». Группа всех кодов неисправности имеет в спецификации идентификатор 0xFFFFFF SWS Diagnostics §7.3.4.4.1 «DTC Introduction».

Граница использования

Класс представляет собой интерфейс состояний и уведомлений. Его следует использовать только для настроенного события; DTC номер, устаревание, смещение и запись снимков/расширенная запись данных остаются DM и ответственность за конфигурацию.

Последующая регистрация заменяет предыдущего уведомителя. Поэтому приложение должно предоставить уникального владельца и короткую неблокирующую процедуру обратного вызова для каждого экземпляра DTCInformation.

Предметная классификация

Статус выводится из обработки Event и правил UDS-DTC SWS Diagnostics §7.3.4.4.2 «UDS DTC Status»; поэтому Notifier может иметь несколько причин, например квалифицированный результат Monitor или обработку памяти.
