Использование по назначению

Последний класс предлагает операции для диагностического события. Он считывает байт состояния, статус устранения дребезга, счетчик обнаружения неисправностей, статус завершения теста и номер DTC асинхронно в желаемом формате. Архитектурное встраивание

Архитектура использует Event как общедоступный интерфейс API с доступом к статусу событий, статусу устранения дребезга, счетчику обнаружения неисправностей и соответствующему номеру DTC. EXP SWArchitecture §9.8.1.1.2 Диагностика должна обрабатывать статус события; Прямо упомянутый вариант использования — это оценка результатов мониторинга и действий, вытекающих из них.
