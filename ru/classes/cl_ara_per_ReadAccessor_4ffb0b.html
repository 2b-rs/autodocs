класс ara::per::ReadAccessor

[SWS_PER_00342] Upstream: RS_PER_00004, RS_AP_00122, RS_AP_00146

class ReadAccessor :            public virtual FileAccessor {...};

ReadAccessor is used to read file data. It provides binary and text mode methods for checking or getting the current byte/character (PeekByte/PeekChar, GetByte/GetChar) methods for reading a section of a binary/text file (Read Binary/ReadText), a method to read a line of text (ReadLine).

Чтение открытого файла

ReadAccessor — это эксклюзивный доступ на чтение файла FileStorage. Файл открывается с помощью OpenFileReadOnly; После этого символьные, текстовые и двоичные операции позволяют использовать стратегию чтения, соответствующую содержимому. SWS Persistency §7.4 «File Storage specific Features»

Курсор и EOF

Peek… выполняет просмотр вперёд без изменения позиции; Get… читает и перемещает её. ReadLine, ReadText и ReadBinary различаются формой передачи. Проверяйте IsEof и Result и не полагайтесь только на ожидаемую длину.

Параллелизм

Методы доступа не являются потокобезопасными. Поэтому сохраняйте управление доступом и позициями в контролируемом контексте владения или защищайте один и тот же дескриптор извне.

File Storage управляет набором именованных файлов; Accessor эксклюзивно владеет конкретным открытым доступом. Источники: SWS Persistency §7.4 «File Storage specific Features» [SWS_PER_00113].
