Обеспечивает блочное, построчное или посимвольное чтение сохраненных файловых и бинарных данных.

Класс ara::per::ReadAccessor предоставляет синхронные методы для последовательного и построчного чтения файлов в бинарном и текстовом режимах [SWS_PER_00421], [SWS_PER_00119]. Наряду с чтением с продвижением курсора он позволяет выполнять предварительный просмотр следующих байтов или символов без изменения позиции указателя. Поскольку экземпляры не являются потокобезопасными, параллельный доступ должен координироваться извне, тогда как в случае ошибки гарантия отката защищает позицию указателя чтения [SWS_PER_00419].

Контекст и область задач

Класс ara::per::ReadAccessor предоставляет интерфейс для синхронного чтения содержимого файлов в рамках управления персистентностью (модуль per) и виртуально наследуется от FileAccessor. Он абстрагирует доступ по чтению к персистентным хранилищам данных и предоставляет как бинарные, так и текстовые методы доступа. Приложения могут проверять и считывать отдельные байты или символы с помощью специализированных функций, а также считывать непрерывные блоки или полные строки.

Жизненный цикл и параллелизм

Конструктор по умолчанию ReadAccessor удален [SWS_PER_00461]; поэтому инстанцирование обычно происходит опосредованно через вышестоящие механизмы открытия и доступа модуля персистентности. Освобождение интерфейса и связанных ресурсов доступа выполняется через виртуальный деструктор ~ReadAccessor() [SWS_PER_00417]. Экземпляры ReadAccessor обладают внутренним указателем чтения, который управляет текущей позицией в файле. Все методы класса явно специфицированы как непотокобезопасные (not thread-safe) [SWS_PER_00419], поэтому одновременные операции чтения над одним и тем же экземпляром должны синхронизироваться вызывающими сторонами извне.

Пути использования для бинарных и текстовых данных

Для бинарных файловых операций класс предлагает функции предварительного просмотра или последовательного чтения. С помощью PeekByte() можно проинспектировать байт в текущей позиции чтения без изменения указателя чтения [SWS_PER_00418]. Напротив, GetByte() считывает ровно один байт и продвигает позицию вперед [SWS_PER_00419]. Более крупные блоки данных можно считывать через ReadBinary(n) в ara::core::Vector<ara::core::Byte> с соответствующей корректировкой позиции; если конец файла достигается преждевременно, вектор содержит меньше байтов, чем запрошено [SWS_PER_00422]. С помощью ReadBinary() можно за один шаг получить все оставшиеся байты до конца файла [SWS_PER_00421].

Диаграмма последовательности: типичный процесс последовательного доступа по чтению с предварительной проверкой и фрагментарной обработкой данных. Источники: [SWS_PER_00418], [SWS_PER_00422], [SWS_PER_00421].

В текстовом режиме PeekChar() предоставляет предварительный просмотр на уровне символов [SWS_PER_00167], тогда как GetChar() считывает следующий символ с продвижением курсора [SWS_PER_00168]. Построчное чтение выполняется через ReadLine(), который считывает данные вплоть до разделителя (по умолчанию: '\n', ASCII 0x0a); при этом разделитель не включается в результирующую строку [SWS_PER_00119]. Фрагменты из n символов или все оставшееся содержимое можно считать через перегрузки ReadText() [SWS_PER_00165], [SWS_PER_00420]. Если указатель чтения находится внутри многобайтового символа, результирующие строки могут содержать неполные кодовые точки Unicode [SWS_PER_00119], [SWS_PER_00165].

Сценарии ошибок и обработка ошибок

Все операции чтения ReadAccessor возвращают свои значения, инкапсулированные в ara::core::Result, и специфицированы как безопасные относительно исключений (exception safe) [SWS_PER_00419]. Если во время доступа возникает ошибка, действует строгая семантика отката: текущая позиция указателя чтения в случае ошибки всегда остается неизменной [SWS_PER_00421], [SWS_PER_00422]. Типичные задокументированные состояния ошибок включают:

  • PerErrc::kPhysicalStorageFailure при ошибках физического носителя данных [SWS_PER_00419], [SWS_PER_00420],
  • PerErrc::kEof, если указатель чтения находится в конце файла или файл пуст [SWS_PER_00419], [SWS_PER_00168],
  • PerErrc::kValidationFailed, если достоверность данных не может быть верифицирована [SWS_PER_00418], [SWS_PER_00119],
  • PerErrc::kEncryptionFailed при неудачной расшифровке [SWS_PER_00419], [SWS_PER_00422], а также
  • PerErrc::kAuthenticationFailed, если проверка MAC сохраненных данных завершается сбоем [SWS_PER_00167], [SWS_PER_00421].

Настоящее руководство основано на спецификации AUTOSAR Adaptive R25-11 и создано автоматически.

Reads a complete line of characters into a String, advancing the current position accordingly. The end of the line is demarcated by the delimiter, or by "\\n" (ASCII 0x0a) if that parameter is omitted. The delimiter itself is not included in the returned String. Only Unicode code points with one character (code unit) can be used as delimiters. The returned string may start with an incomplete Unicode code point in case the current read position is in the middle of a code point. If the end of the file is reached, the remaining characters are returned and the current position is set to the end of the file. In case of an error, the current position is not changed.

            • 

          • PerErrc::kEncryptionFailed: произошел сбой при расшифровке сохраненных данных.
            • 

          • PerErrc::kAuthenticationFailed: сбой проверки MAC (Message Authentication Code).
