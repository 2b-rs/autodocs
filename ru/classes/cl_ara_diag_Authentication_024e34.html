Использование по назначению

Authentication — это интерфейс приложения для реализации аутентификации службы диагностики. Он создан для порта DiagnosticAuthenticationInterface с InstanceSpecifier и ConcurrencyType и может быть предложен DM через Offer(). [SWS_DM_01123] [SWS_DM_01124] [SWS_DM_01130]

Взаимодействие с другими классами

С помощью подфункции UDS VerifyCertificateUnidirectional Diagnostic Server вызывает VerifyCertificateUnidirectional() с конфигурацией связи, сертификатом клиента, запросом клиента, MetaInfo и CancellationHandler. Приложение проверяет сертификат и в Future возвращает запрос и эфемерный открытый ключ. [SWS_DM_01126] [SWS_DM_01230]

В двунаправленном варианте VerifyCertificateBidirectional() проверяет сертификат и запрос и генерирует запрос, эфемерный открытый ключ, подтверждение владения и сертификат сервера для тестера. Для подтверждения владения DM вызывает VerifyOwnership() с POWN клиента и ключом клиента; будущее предоставляет информацию о ключе сеанса или ошибку. Обработка ошибок

  • InstanceSpecifierMappingIntegrityViolation — InstanceSpecifier не может быть разрешён в модели либо не ссылается на PortPrototype.
  • PortInterfaceMappingViolation — PortPrototype, на который ссылается DiagnosticAuthenticationPortMapping, должен быть типизирован посредством DiagnosticAuthenticationInterface.
  • ProcessMappingViolation — существует подходящий InstanceRef, но нет подходящего моделируемого процесса для процесса времени выполнения.
  • InstanceSpecifierAlreadyInUseViolation – InstanceSpecifier уже используется в процессе.
