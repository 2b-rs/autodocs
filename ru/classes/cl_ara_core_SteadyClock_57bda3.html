This clock represents a monotonic clock. The time points of this clock cannot decrease as physical time moves forward and the time between ticks of this clock is constant.

Предоставляет строго монотонные часы с наносекундным разрешением для времяинвариантных измерений интервалов и тайм-аутов.

Класс предоставляет монотонные равномерные часы с наносекундным разрешением для измерения временных интервалов и предельных сроков, временные точки которых никогда не убывают ([SWS_CORE_06431], [SWS_CORE_06413]). С помощью статической функции now() приложения потокобезопасно и без риска возникновения исключений получают текущую временную метку [SWS_CORE_06432]. Путем вычисления разности двух временных точек можно надежно определить длительность выполнения операций.

Контекст

Класс ara::core::SteadyClock в AUTOSAR Adaptive Platform предоставляет монотонные часы для точного измерения времени. Его основная ответственность заключается в выдаче непрерывно возрастающих временных точек; значения времени этих часов при продвижении физического времени никогда не могут уменьшаться, а длительность между тиками постоянна. Данная инвариантность гарантируется свойством is_steady = true [SWS_CORE_06431].

Модель времени данного класса опирается на концепции стандартных часов C++ и стандартизирует единицы измерения для интервалов времени и временных точек. Период тика часов определен через псевдоним типа period как наносекунда ([SWS_CORE_06413]: using period = std::nano). В качестве типа представления количества тиков используется 64-битный целочисленный тип со знаком ([SWS_CORE_06412]: using rep = std::int64_t). На этой основе using duration = std::chrono::duration<rep, period> [SWS_CORE_06411] представляет относительный временной интервал, тогда как using time_point = std::chrono::time_point<SteadyClock, duration> [SWS_CORE_06414] привязывает конкретные временные точки к этим часам. Типичными партнерами по взаимодействию выступают компоненты приложения, которым необходимо определять длительность выполнения или контролировать тайм-ауты.

Жизненный цикл

Класс специфицирован как final и содержит исключительно статические интерфейсы. Интерпретация: инстанцирование ara::core::SteadyClock для практического применения не предусмотрено и не требуется, поскольку класс служит статическим пространством имен и идентификатором типа для time_point. В нем отсутствуют переходы состояний, фазы инициализации или процедуры уничтожения.

Для одновременного доступа из нескольких потоков центральная функция запроса now() явно специфицирована как потокобезопасная (thread-safe) [SWS_CORE_06432]. Таким образом, несколько потоков могут считывать временные метки параллельно и без дополнительной внешней синхронизации.

Путь использования

Типичным сценарием использования ara::core::SteadyClock является измерение длительности выполнения участка программы. В начале вызывающий компонент запрашивает текущую временную метку через статический метод ara::core::SteadyClock::now() [SWS_CORE_06432], в результате чего возвращается объект типа time_point [SWS_CORE_06414]. Затем приложение выполняет требуемую операцию. После ее завершения производится повторный вызов now() [SWS_CORE_06432]. Вычитая начальную временную точку из конечной, приложение вычисляет затраченное время как duration [SWS_CORE_06411]. Поскольку is_steady гарантирует, что часы никогда не идут назад [SWS_CORE_06431], результат при продвижении физического времени всегда монотонен и надежен.

Диаграмма последовательности: типовой процесс измерения длительности путем определения двух временных точек. Источники: [SWS_CORE_06432], [SWS_CORE_06411], [SWS_CORE_06414]

Сценарии ошибок

Интерфейс ara::core::SteadyClock не предусматривает кодов ошибок или состояний ошибки. Функция now() объявлена как noexcept и обладает свойством безопасности относительно исключений (exception safe) [SWS_CORE_06432]. Вызов now() не завершается сбоем ни при каких штатных условиях эксплуатации и гарантированно возвращает корректное значение типа time_point [SWS_CORE_06414].

Интерпретация: теоретическое переполнение значения счетчика rep [SWS_CORE_06412] в реальных системах из-за 64-битного диапазона значений при наносекундных тиках расчетно может наступить лишь через несколько сотен лет непрерывной работы и, следовательно, не представляет собой практического риска отказа.

Настоящее руководство основано на спецификации AUTOSAR Adaptive Platform версии R25-11.

Статическая функция ara::core::SteadyClock::now() синхронно возвращает time_point, представляющий текущее значение счетчика часов [SWS_CORE_06432]. Для использования необходимо подключить заголовочный файл ara/core/steady_clock.h [SWS_CORE_06432]. Поскольку метод статически привязан к ara::core::SteadyClock, создание экземпляра класса не требуется; доступ осуществляется непосредственно через область видимости.

Что касается обработки ошибок, функция объявлена с noexcept и обозначена как безопасная относительно исключений (exception safe) [SWS_CORE_06432]. Следовательно, вызывающим сторонам не требуется предусматривать обработку исключений для запроса времени, так как операция гарантированно завершается безошибочно.

Относительно параллелизма и ограничений now() специфицирована как потокобезопасная (thread-safe) [SWS_CORE_06432]. Функцию разрешено вызывать параллельно из любых контекстов выполнения и потоков без синхронизации на стороне приложения.

Внутри интерфейсов ara::core::SteadyClock функция, вероятно, служит прежде всего для предоставления меток времени для измерений относительных интервалов и определения времени выполнения (интерпретация: выведено из области видимости и возвращаемого типа [SWS_CORE_06432]).
