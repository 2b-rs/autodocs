Использование по назначению

DataTransferReadByPullHandler реализует передачу данных чтения в RequestReadFile или RequestReadDirectory, где AraDiag извлекает данные по частям из приложения. Read() получает доступный для записи диапазон байтов, предварительно выделенный системой, и асинхронно доставляет фактически введенные байты. [SWS_DM_01506] [SWS_DM_01513]

Жизненный цикл и право собственности

Обработчик не может быть скопирован для однократного использования в рамках отдельного сеанса передачи файлов, но его можно перемещать и назначать для перемещения. Его можно уничтожить только после вызова ExitRead(). Этот метод завершает текущий сеанс передачи и асинхронно возвращает запись параметра ответа на передачу или ошибку UDS.
