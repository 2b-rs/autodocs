Использование по назначению

SovdServiceValidation реализует тесты SOVD, специфичные для производителя или поставщика. Validate() вызывается для каждого запроса SOVD, а для коллекций ресурсов — один раз для каждого содержащегося элемента. [SWS_DM_01822] [SWS_DM_01827] DM вызывает настроенные валидаторы в указанном порядке и немедленно прекращает обработку с ошибкой, как только один из них выходит из строя. [SWS_DM_01784] [SWS_DM_01785]

Создание & жизненный цикл

Экземпляр создается для PortPrototype DiagnosticSovdServiceValidationInterface с ConcurrencyType. [SWS_DM_01823] Предложение включает пересылку DM, а StopOffer отключает ее. В предложении может быть указано kAlreadyOffered или kConfigurationMismatch. [SWS_DM_01825] [SWS_DM_01826] Деструктор защищен от исключений. [SWS_DM_01824]

Ограничения & Обработка ошибок

Validate получает HTTP-метод и MetaInfo, включая путь к ресурсу, и возвращает либо успех, либо ошибку SOVD. [SWS_DM_01827] Специфицированы в том числе неверная конфигурация Server, невыполненные предусловия, временная недоступность и отсутствие прав доступа. [SWS_DM_01827] Thread-safety Validate зависит от ConcurrencyType; Offer и StopOffer не являются thread-safe. [SWS_DM_01827] [SWS_DM_01825] [SWS_DM_01826]

Для коллекции ресурсов DM сначала валидирует коллекцию, затем каждый возвращаемый элемент с его собственным путём в MetaInfo. [SWS_DM_01785] Функция валидации является exception-safe и возвращает Future<void>. [SWS_DM_01827] Конструктор является exception-safe и thread-safe, деструктор — exception-safe и не thread-safe. [SWS_DM_01823] [SWS_DM_01824]

В случае возникновения ошибки DM не будет продолжать обработку запроса. [SWS_DM_01784]

Виртуальный метод Validate вызывается для каждого входящего сообщения запроса SOVD; для коллекции ресурсов он вызывается многократно — один раз для самой коллекции и один раз для каждого содержащегося ресурса. Возвращаемый ara::core::Future<void> содержит пустое значение, если запрос допустим, и ошибку в противном случае.

Обработка ошибок & параллелизм

Возможные ошибки: DiagSovdErrc::kSovdServerMisconfigured (неверно сконфигурирован SOVD-сервер), DiagSovdErrc::kPreconditionNotFulfilled (предварительные условия не выполнены), DiagSovdErrc::kTemporarilyNotAvailable (запрос в настоящее время не может быть обработан), а также DiagSovdErrc::kInsufficientAccessRights (недостаточные права доступа); допустимы и дополнительные значения DiagSovdErrc для специфичных сообщений об ошибках SOVD. Необходимость потокобезопасной либо непотокобезопасной реализации определяется ConcurrencyType, переданным в конструктор; метод безопасен в отношении исключений.
