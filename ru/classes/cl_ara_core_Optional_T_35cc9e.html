Инкапсулирует опциональную ссылку на объект и обеспечивает безопасный доступ без динамического выделения памяти.

Специализация ara::core::Optional<T &> служит типобезопасным контейнером для опциональных lvalue-ссылок с типом элементов T & [SWS_CORE_01151]. Она позволяет переназначать или сбрасывать ссылку во время выполнения без динамического выделения памяти [SWS_CORE_01164], [SWS_CORE_01165]. Перед каждым доступом через операторы разыменования или потенциально генерирующий исключение метод доступа value() обязательно требуется проверять наличие допустимого целевого объекта [SWS_CORE_01172], [SWS_CORE_01173].

Контекст

Шаблонная специализация ara::core::Optional<T &> предоставляет типобезопасный контейнер для опциональной lvalue-ссылки. Базовый тип элемента определяется псевдонимом типа value_type как T & [SWS_CORE_01151]. В отличие от первичного шаблона для типов значений, эта специализация служит повторно используемой, переназначаемой ссылкой (rebindable reference), которая либо указывает на существующий объект типа T, либо представляет незанятое состояние. Она напрямую взаимодействует с вызывающими программными компонентами и адресуемым целевым объектом без выделения динамической памяти.

Жизненный цикл

Экземпляр ara::core::Optional<T &> всегда находится в одном из двух строго контролируемых состояний: пусто (не занято) или занято (ссылается на объект). Пустое состояние принимается через конструктор по умолчанию [SWS_CORE_01152] или инициализацию с помощью nullopt_t [SWS_CORE_01153]. Привязка к ссылке происходит при конструировании путем передачи совместимого значения или ссылки [SWS_CORE_01156], а также через преобразующие конструкторы [SWS_CORE_01157]. Конструкторы копирования и перемещения переносят состояние исходного контейнера [SWS_CORE_01154], [SWS_CORE_01155].

Во время выполнения состояние может динамически модифицироваться: присваивание значения или ссылки заново связывает Optional с переданным целевым объектом [SWS_CORE_01162], что также происходит через операторы присваивания других контейнеров Optional [SWS_CORE_01159], [SWS_CORE_01160], [SWS_CORE_01163] или метод emplace [SWS_CORE_01164]. Переход в пустое состояние осуществляется через вызов reset [SWS_CORE_01165] или путем присваивания nullopt_t [SWS_CORE_01161]. Кроме того, swap позволяет атомарно обменивать два экземпляра [SWS_CORE_01166]. Деструктор по умолчанию завершает время жизни экземпляра-обертки [SWS_CORE_01158], но при этом, предположительно, не затрагивает исходный адресуемый объект, поскольку ссылка семантически не влечет владения.

Диаграмма состояний: состояния и переходы состояний экземпляра ara::core::Optional<T &>. Источники: [SWS_CORE_01152], [SWS_CORE_01153], [SWS_CORE_01156], [SWS_CORE_01161], [SWS_CORE_01162], [SWS_CORE_01164], [SWS_CORE_01165].

Путь использования

Типичный цикл применения охватывает создание, валидацию и доступ на чтение или изменение к адресуемой цели:

  1. Инициализация: экземпляр создается пустым [SWS_CORE_01152] или заполняется ссылкой на существующий объект [SWS_CORE_01156].
  2. Проверка состояния: перед разыменованием вызывающая сторона проверяет наличие ссылки через оператор явного преобразования operator bool [SWS_CORE_01171] или метод has_value [SWS_CORE_01172].
  3. Доступ: при подтверждении наличия ссылки доступ к адресуемому объекту осуществляется через операторы разыменования operator* [SWS_CORE_01169], [SWS_CORE_01170] или оператор «стрелка» operator-> [SWS_CORE_01167], [SWS_CORE_01168]. В качестве альтернативы value_or возвращает адресуемое значение или указанное значение по умолчанию [SWS_CORE_01175].
  4. Сброс: после завершения обработки ссылка при необходимости явно удаляется через reset [SWS_CORE_01165].

Диаграмма последовательности: типичный ход инициализации, верификации и разыменования опциональной ссылки. Источники: [SWS_CORE_01156], [SWS_CORE_01165], [SWS_CORE_01170], [SWS_CORE_01172].

Сценарии ошибок

Ошибки возникают преимущественно при преждевременных или недопустимых попытках доступа к пустым экземплярам. Если value() вызывается, когда объект не содержит значения, генерируется нарушение типа IsoStdBadOption-alAccessViolation [SWS_CORE_01173], [SWS_CORE_01174]. Соответственно, value(), в отличие от большинства других операций класса, явно классифицирован как небезопасный относительно исключений (not exception safe).

Прямые разыменования с помощью operator* [SWS_CORE_01169], [SWS_CORE_01170], а также operator-> [SWS_CORE_01167], [SWS_CORE_01168] также документируют нарушение категории IsoStdBadOption-alAccessViolation, если экземпляр не содержит ссылки. Хотя эти операторы объявлены с noexcept, их использование обязательно требует соблюдения предусловия о существовании действительной ссылки.

Оператор доступа к членам operator-> шаблонного класса ara::core::Optional<T &> служит для синхронного доступа к членам адресуемого объекта [SWS_CORE_01167]. Функция определена в заголовочном файле #include "ara/core/optional.h", относится к области видимости ara::core::Optional<T &> и не ожидает параметров [SWS_CORE_01167]. В качестве возвращаемого значения предоставляется указатель типа T const *, обеспечивающий прямой доступ для чтения к базовому целевому объекту [SWS_CORE_01167]. Таким образом, тип возвращаемого значения соответствует указателю на константные данные, что исключает модифицирующие обращения через данный оператор.

Что касается обработки ошибок, метод объявлен как noexcept и классифицирован как exception safe [SWS_CORE_01167]. Однако если экземпляр не содержит значения (If *this does not contain a value), спецификация документирует в качестве нарушения IsoStdBadOptionalAccessViolation [SWS_CORE_01167]. Следовательно, перед разыменованием использующее программное обеспечение должно убедиться, что опциональная ссылка содержит корректное значение, чтобы надёжно избежать ошибочных состояний во время выполнения.

Для многопоточности и контекста вызова спецификация не указывает отдельных механизмов защиты; предположительно, операция const не предоставляет внутренней синхронизации против конкурирующих модификаций [SWS_CORE_01167]. Общее поведение согласно спецификации соответствует аналогичному использованию в стандарте C++ для опциональных типов (As per corresponding usage in [optional]) [SWS_CORE_01167].
