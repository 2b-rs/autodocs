Служит для вычисления целевых симметричных ключей из закрытого ключа и внешнего открытого ключа.

Интерфейс ara::crypto::cryp::KeyAgreementPrivateCtx служит для выполнения процедур криптографического согласования ключей на основе локального закрытого ключа и открытого ключа удаленной стороны [SWS_CRYPT_21312]. После назначения собственного ключа и опциональных параметров метод AgreeKey вычисляет общий секрет и возвращает его в виде симметричного объекта ключа. Центральным граничным условием является полная инициализация перед выполнением, поскольку отсутствие параметров или прав доступа для kAllowKeyAgreement приводит к прерыванию с соответствующими кодами ошибок [SWS_CRYPT_21312]. При этом все операции спроектированы потокобезопасными.

Контекст

Интерфейс ara::crypto::cryp::KeyAgreementPrivateCtx служит в модуле crypto платформы Adaptive Platform для выполнения процедур асимметричного согласования ключей (Key Agreement). Его основная ответственность заключается в вычислении общего симметричного ключа из локального закрытого ключа и открытого ключа партнера по коммуникации [SWS_CRYPT_21312]. Являясь специализированным криптоконтекстом, класс взаимодействует с несколькими абстракциями ключей и хранилища: собственный закрытый ключ может быть привязан либо напрямую как объект PrivateKey [SWS_CRYPT_21313], либо по ссылке через KeySlot [SWS_CRYPT_50053]. Противоположная сторона предоставляет свой открытый ключ в виде PublicKey, в то время как результат предоставляется в виде самостоятельного объекта SymmetricKey [SWS_CRYPT_21312]. Дополнительно специфичные для алгоритма параметры конфигурации могут передаваться как область памяти или целое число [SWS_CRYPT_50051], [SWS_CRYPT_50052].

Диаграмма контекста: взаимодействие KeyAgreementPrivateCtx с ключами, слотами для ключей и объектом результата. Источники: [SWS_CRYPT_21312], [SWS_CRYPT_21313], [SWS_CRYPT_50053].

Жизненный цикл

Жизненный цикл и отношения владения KeyAgreementPrivateCtx основаны на shared pointers; спецификация предоставляет для этого псевдоним типа KeyAgreementPrivateCtx::Sptr [SWS_CRYPT_21301]. Интерпретация: инстанцирование, вероятно, происходит через вышестоящую фабрику CryptoProvider, поскольку класс представляет собой чисто виртуальный интерфейс без спецификации конструктора. После создания экземпляр находится в неработоспособном базовом состоянии. Контекст инициализируется только после конфигурации закрытого ключа с помощью SetKey [SWS_CRYPT_21313], [SWS_CRYPT_50053] и назначения всех параметров, необходимых для выбранной схемы [SWS_CRYPT_50051], [SWS_CRYPT_50052].

Если вычисление ключа запускается до завершения этих шагов конфигурации, вызов завершается неудачно [SWS_CRYPT_21312]. В отношении параллелизма все функции-члены специфицированы как потокобезопасные (thread-safe), а также безопасные относительно исключений (exception safe) [SWS_CRYPT_21312], [SWS_CRYPT_21313], [SWS_CRYPT_50051], [SWS_CRYPT_50052], [SWS_CRYPT_50053]. Поскольку функция выполнения AgreeKey объявлена как const [SWS_CRYPT_21312], один и тот же инициализированный контекст может использоваться параллельно для согласований с различными удаленными сторонами.

Путь использования

Практическое применение подразделяется на последовательную цепочку конфигурации и вычисления:

  • Назначение ключа: сначала приложение привязывает собственный закрытый ключ к контексту. Это выполняется либо через SetKey(PrivateKey::Sptr) [SWS_CRYPT_21313] для загруженного объекта ключа, либо через SetKey(KeySlot::Sptr) [SWS_CRYPT_50053] для слота ключа, содержимое которого оценивается только в момент согласования.
  • Определение параметров: если целевой алгоритм требует дополнительных данных инициализации, они передаются через SetParameter в виде буфера ReadOnlyMemRegion [SWS_CRYPT_50051] или в виде 64-разрядного целого числа std::uint64_t [SWS_CRYPT_50052].
  • Согласование ключа: с помощью AgreeKey выполняется криптографический алгоритм [SWS_CRYPT_21312]. Вызывающий компонент передает открытый ключ удаленной стороны (otherSideKey), идентификатор требуемого целевого алгоритма (targetAlgId), а также допустимые флаги использования (allowedUsage).
  • Получение результата: при успешном завершении AgreeKey возвращает объект SymmetricKey, содержащий вычисленный общий секрет [SWS_CRYPT_21312].

Диаграмма последовательности: типичный процесс согласования ключей от распределения ключа до создания симметричного ключа. Источники: [SWS_CRYPT_21312], [SWS_CRYPT_21313], [SWS_CRYPT_50051].

Сценарии ошибок

Методы KeyAgreementPrivateCtx возвращают ошибки через ara::core::Result и гарантируют семантику отката [SWS_CRYPT_21312], [SWS_CRYPT_21313], [SWS_CRYPT_50051], [SWS_CRYPT_50052], [SWS_CRYPT_50053]. Типичные сценарии ошибок включают:

  • CryptoErrc::kUninitializedContext: возникает при AgreeKey, если ранее не был задан ключ или отсутствуют обязательные параметры [SWS_CRYPT_21312].
  • CryptoErrc::kIncompatibleObject: возвращается, если переданный PrivateKey или KeySlot не соответствует типу контекста [SWS_CRYPT_21313], [SWS_CRYPT_50053], или если ключ удаленной стороны otherSideKey несовместим [SWS_CRYPT_21312].
  • CryptoErrc::kUsageViolation: сигнализирует о том, что для закрытого ключа или ключа удаленной стороны не было предоставлено право kAllowKeyAgreement [SWS_CRYPT_21312], [SWS_CRYPT_21313].
  • CryptoErrc::kUnsupported: указывает на то, что реализация контекста поддерживает исключительно другой вариант SetKey [SWS_CRYPT_21313], [SWS_CRYPT_50053], либо запрошенное имя параметра не поддерживается [SWS_CRYPT_50051], [SWS_CRYPT_50052].
  • CryptoErrc::kInvalidArgument: возникает при недопустимых значениях в SetParameter [SWS_CRYPT_50051], [SWS_CRYPT_50052] или недопустимых флагах allowedUsage для целевого ключа [SWS_CRYPT_21312].
  • CryptoErrc::kUnknownIdentifier: генерируется, если идентификатор targetAlgId для целевого алгоритма неизвестен [SWS_CRYPT_21312].
  • CryptoErrc::kEmptyKeySlot и CryptoErrc::kBusyResource: возвращаются методом AgreeKey, если сконфигурированный KeySlot не содержит ключа в момент выполнения или требуемый ресурс занят [SWS_CRYPT_21312].

Метод AgreeKey класса ara::crypto::cryp::KeyAgreementPrivateCtx выполняет алгоритм согласования ключей с использованием закрытого ключа и открытого ключа противоположной стороны для формирования общего симметричного ключа [SWS_CRYPT_21312]. В качестве параметров передаются открытый ключ противоположной стороны (otherSideKey), идентификатор целевого симметричного алгоритма (targetAlgId) и допустимые флаги использования (allowedUsage) [SWS_CRYPT_21312]. При успешном выполнении возвращается ara::core::Result с SymmetricKey::Sptr, содержащим вычисленный общий секрет [SWS_CRYPT_21312]. Интерпретация: поскольку возврат осуществляется напрямую в виде Result, а не через асинхронный тип Future, вычисление ключа, вероятно, выполняется синхронно.

Метод определен как thread-safe, а также exception safe (noexcept) [SWS_CRYPT_21312]. В случае ошибки срабатывает семантика отката и возвращается соответствующий код ошибки [SWS_CRYPT_21312]:

  • UninitializedContext: контекст еще не был инициализирован предоставлением ключа или необходимые параметры не были предварительно установлены через SetParameter() [SWS_CRYPT_21312].
  • CryptoErrc::kIncompatibleObject: открытый ключ несовместим с текущим контекстом [SWS_CRYPT_21312].
  • CryptoErrc::kUsageViolation: ограничения использования закрытого или открытого ключа не содержат kAllowKeyAgreement [SWS_CRYPT_21312].
  • CryptoErrc::kInvalidArgument: переданные флаги allowedUsage недопустимы для симметричного ключа [SWS_CRYPT_21312].
  • ara::crypto::CryptoErrc::kUnknownIdentifier: идентификатор targetAlgId содержит неподдерживаемое значение [SWS_CRYPT_21312].
  • CryptoErrc::kBusyResource или CryptoErrc::kEmptyKeySlot: требуемый ресурс занят или сконфигурированный KeySlot пуст [SWS_CRYPT_21312].

          В качестве входного параметра интерфейс ожидает KeySlot::Sptr, который должен содержать закрытый ключ [SWS_CRYPT_50053]. Материал ключа задействуется и анализируется только в тот момент, когда выполняется само согласование ключей [SWS_CRYPT_50053]. В качестве альтернативы KeySlot контекст через [SWS_CRYPT_21313] допускает прямую передачу PrivateKey::Sptr.
