Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

Использование по назначению

ErrorCode инкапсулирует необработанное значение ошибки, зависящее от домена, ссылку на связанный ErrorDomain и необязательные дополнительные данные, зависящие от поставщика. Тип является буквальным. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

Генерация и взаимодействие

Его можно создать из перечисления ошибок или из значения, домена ошибки и дополнительных данных. Domain(), Value(), SupportData() и Message() делают доступными его компоненты и текст ошибки соответственно; ThrowAsException() определяет соответствующий тип исключения в домене. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

Ограничения & Обработка ошибок

Сравнения учитывают исключительно значение ошибки и домен ошибки, но не дополнительные данные. ErrorCode и его Member можно использовать независимо от ara::core::Initialize и Deinitialize. [SWS_CORE_10301] [SWS_CORE_15002]

Контекст ошибки вместо общих значений ошибок

ErrorCode связывает типизированное значение ошибки со своим контекстом ErrorDomain; опционально он может нести сообщение и дополнительную информацию, специфичную для производителя. Интерфейсы ARA используют его в Result для устранения ошибок. EXP InterfacesGuidelines §3.1.2 «Result» EXP ARAComAPI §4.7 «Error Handling»

Коды ошибок, специфичные для производителя, требуют собственного ErrorDomains; переносимые, нейтральные к стеку приложения должны рассматривать такие домены как общий случай по умолчанию. EXP InterfacesGuidelines §3.1.5 «Standardized vs Vendor-specific ErrorCodes»

Диаграмма взаимодействия: ErrorCode получает контекст и сообщение из своей Domain; преобразование исключения является явным путём Exception. Источники: EXP InterfacesGuidelines §3.1.2 «Result» RS General §4.1.3 «The use of noexcept».

Введите стертое значение ошибки

SWS описывает ErrorCode как значение ошибки с контекстом Domain: специфичный для Domain код для унифицированной передачи стирается по типу в целочисленное значение; могут передаваться дополнительные данные поддержки. Сравнения учитывают значение и Domain, но не данные поддержки. SWS Core §7.2 «Error handling» SWS Core §7.2.5.1 «ErrorCode» [SWS_CORE_10301] [SWS_CORE_10302]

ara::core::ErrorCode::ThrowAsException выдает эту ошибку как исключение в соответствии с [SWS_CORE_00519]: Функция определяет тип исключения, соответствующий этому ErrorCode в соответствии с [SWS_CORE_10953], и выдает его, если выброшенное исключение содержит это ErrorCode. Он ведет себя как this->Domain().ThrowAsException(*this) и не участвует в разрешении перегрузки, когда исключения C++ отключены.

Вызов является потокобезопасным, но не считается безопасным для исключений, поскольку он всегда генерирует исключение типа, определенного соответствующим ErrorDomain.
