класс ara::crypto::CryptoErrorDomain

[SWS_CRYPT_19900] Upstream: RS_AP_00130

class CryptoErrorDomain final :             public ara::core::ErrorDomain {...};

Crypto Error Domain class that provides interfaces as defined by ara::core::ErrorDomain such as a name of the Crypto Error Domain or messages for each error code. This class represents an error domain responsible for all errors that may be reported by public APIs in ara::crypto namespace. .

ara::crypto::CryptoErrorDomain является частью общего Crypto API. Он поддерживает интерфейсы Provider и контекста при однозначной обработке данных, ошибок, форматов или операций с ключами. SWS Cryptography §7.1 «Architecture & Concepts»
