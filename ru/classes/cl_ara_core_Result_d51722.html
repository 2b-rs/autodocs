Инкапсулирует либо значение успешного завершения, либо значение ошибки для синхронной передачи результата без исключений.

Класс представляет собой типобезопасный контейнер, который принимает либо полезное значение, либо код ошибки для синхронной передачи результатов вычислений без исключений C++ [SWS_CORE_00751]. Вызывающие стороны создают экземпляры через выделенные конструкторы или фабричные функции, а затем оценивают результат в зависимости от состояния с помощью функций проверки и доступа, таких как доступ к значению или ошибке. Важным граничным условием является то, что базовый тип ошибки должен строго соответствовать стандартному коду ошибки, поскольку иные типы отклоняются на этапе компиляции. Кроме того, функции для вызова исключений требуют среды компилятора с включенными исключениями C++ [SWS_CORE_00766].

Контекст

Класс ara::core::Result является центральной конструкцией AUTOSAR Adaptive Platform для синхронного типизированного возврата результатов операций без обязательного использования исключений C++. Он представляет собой размеченное объединение (Tagged Union), которое в любой момент времени содержит либо полезное значение типа value_type (T), либо ошибку типа error_type (E) [SWS_CORE_00711] [SWS_CORE_00712]. По умолчанию ara::core::ErrorCode выступает в качестве типа для E; иные определения ошибок пресекаются реализациями еще на этапе трансляции посредством ошибки компиляции.

В архитектуре приложения ara::core::Result выступает посредником между вызываемыми службами и потребителями. Службы инстанцируют объект для возврата статуса, в то время как потребители инициируют дальнейшую обработку через проверки состояния, такие как [SWS_CORE_00751], или функциональные цепочки вызовов, такие как [SWS_CORE_00768]. Кроме того, состояние может быть преобразовано через [SWS_CORE_00770] (Ok) и [SWS_CORE_00772] (Err) в ara::core::Optional.

Жизненный цикл

Инициализация экземпляра выполняется либо напрямую через конструкторы для значений ([SWS_CORE_00721], [SWS_CORE_00722]), либо явно для ошибок ([SWS_CORE_00723], [SWS_CORE_00724]). Дополнительно доступны статические фабричные функции: FromValue для lvalue, rvalue и аргументов in-place ([SWS_CORE_00731], [SWS_CORE_00732], [SWS_CORE_00733]), а также FromError для формирования состояний ошибки ([SWS_CORE_00734], [SWS_CORE_00735], [SWS_CORE_00736]).

ara::core::Result монопольно владеет содержащимися данными и управляет их временем жизни. Он поддерживает полную семантику значений через конструкторы копирования и перемещения ([SWS_CORE_00725], [SWS_CORE_00726]), а также соответствующие операторы присваивания ([SWS_CORE_00741], [SWS_CORE_00742]). Изменение содержимого существующих экземпляров возможно с помощью Swap [SWS_CORE_00745] или путем перезаписи in-place через EmplaceValue [SWS_CORE_00743] либо EmplaceError [SWS_CORE_00744].

Деструктор освобождает активный элемент и считается тривиально уничтожаемым, если как T, так и E являются тривиально уничтожаемыми [SWS_CORE_00727]. Что касается параллелизма, операции исключительно для чтения потокобезопасны, тогда как модифицирующие операции, такие как EmplaceValue, EmplaceError, перемещающие присваивания или Swap, не являются потокобезопасными и требуют внешней синхронизации.

Диаграмма состояний: переходы состояний между состоянием значения и ошибки в течение жизненного цикла экземпляра Result. Источники: [SWS_CORE_00721], [SWS_CORE_00723], [SWS_CORE_00743], [SWS_CORE_00744], [SWS_CORE_00727]

Путь использования

Штатный процесс включает создание, валидацию и извлечение результата:

  1. Предоставление: служба создает результат через [SWS_CORE_00731] или [SWS_CORE_00734] и возвращает экземпляр по значению.
  2. Проверка состояния: вызывающая сторона проверяет с помощью HasValue() [SWS_CORE_00751] или явного оператора преобразования operator bool() [SWS_CORE_00752], присутствует ли значение. Последний отключен, если T сам имеет тип bool.
  3. Доступ к значению и ошибке: если значение присутствует, его можно прочитать через Value() ([SWS_CORE_00755], [SWS_CORE_00756], [SWS_CORE_00775]) или операторы operator* ([SWS_CORE_00753], [SWS_CORE_00759]) и operator-> ([SWS_CORE_00754], [SWS_CORE_00777]). В случае ошибки доступ осуществляется через Error() ([SWS_CORE_00757], [SWS_CORE_00758], [SWS_CORE_00776]) или целенаправленную проверку ошибки с помощью CheckError() [SWS_CORE_00765].
  4. Функциональная трансформация: альтернативно Bind() [SWS_CORE_00768] позволяет выполнять монадическую дальнейшую обработку: переданный вызываемый объект (callable) выполняется только в том случае, если содержится полезное значение; существующая ошибка передается без изменений в новый экземпляр Result. Резервные варианты (fallbacks) можно реализовать с помощью Resolve() [SWS_CORE_00767].

Диаграмма последовательности: типичная последовательность вызовов при запросе и обработке экземпляра Result. Источники: [SWS_CORE_00731], [SWS_CORE_00751], [SWS_CORE_00755], [SWS_CORE_00757], [SWS_CORE_00768]

Сценарии ошибок

Доступ к неактивным состояниям нарушает предусловия класса:

  • Вызов Value(), operator* или operator-> без содержащегося значения инициирует документированное системное нарушение ResultWithNoValueViolation ([SWS_CORE_00755], [SWS_CORE_00753], [SWS_CORE_00754]).
  • Вызов Error() при наличии полезного значения приводит к нарушению ResultWithNoErrorViolation ([SWS_CORE_00757], [SWS_CORE_00776]).

Интерпретация: возникновение такого нарушения предусловия в средах выполнения, как правило, приводит к немедленному аварийному завершению процесса, поскольку стандарт классифицирует эти состояния как серьезные ошибки программирования. Во избежание жестких аварийных завершений можно использовать защитные методы: ValueOr() ([SWS_CORE_00761], [SWS_CORE_00762]) и ErrorOr() ([SWS_CORE_00763], [SWS_CORE_00764]) возвращают заданное значение по умолчанию при отсутствии элемента. Варианты optional, такие как Ok() ([SWS_CORE_00770], [SWS_CORE_00771]) и Err() ([SWS_CORE_00772], [SWS_CORE_00773]), инкапсулируют доступ без исключений.

Если требуется обработка исключений, ValueOrThrow() ([SWS_CORE_00766], [SWS_CORE_00769], [SWS_CORE_00778]) в случае ошибки генерирует исключение C++, связанное с этой ошибкой. Если исключения C++ отключены в компиляторе, ValueOrThrow() исключается из разрешения перегрузок [SWS_CORE_00766]; неконстантная перегрузка lvalue для operator* в этом случае также отключена [SWS_CORE_00774].
