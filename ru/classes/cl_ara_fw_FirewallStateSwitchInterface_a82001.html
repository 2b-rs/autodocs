Обеспечивает асинхронное переключение между различными состояниями Firewall и наборами правил фильтрации.

Шаблонный класс ara::fw::FirewallStateSwitchInterface служит в AUTOSAR Adaptive для переключения между различными состояниями Firewall и связанными с ними наборами правил фильтрации. После потокобезопасного создания через ara::core::InstanceSpecifier [AP_SWS_Fw_82002] смена состояния инициируется асинхронно с помощью SwitchFirewallState и отслеживается через ara::core::Future<void> [AP_SWS_Fw_82008]. Класс реализует исключительно семантику перемещения без возможности копирования, при этом деструктор и операции перемещения не являются потокобезопасными, а ошибки передаются асинхронно через future.

Контекст

Шаблонный класс ara::fw::FirewallStateSwitchInterface служит в функциональном кластере fw (Firewall) платформы AUTOSAR Adaptive Platform основным интерфейсом для переключения между различными состояниями Firewall. Под состоянием Firewall понимается определенная конфигурация наборов правил фильтрации, обеспечивающих безопасность сетевого трафика. Параметр шаблона EnumT представляет собой специфичное для приложения перечисление всех допустимых состояний Firewall. В качестве типичных партнеров по взаимодействию могут выступать вышестоящие экземпляры платформы, такие как управление режимами (Mode Management), которые адаптируют правила фильтрации к изменившимся режимам автомобиля или работы.

Жизненный цикл

Создание экземпляра выполняется явно через конструктор с указанием ara::core::InstanceSpecifier [AP_SWS_Fw_82002]. Данный шаг конструирования специфицирован как потокобезопасный. Через InstanceSpecifier, вероятно, разрешается конкретная привязка к экземпляру Firewall, смоделированному в манифесте платформы.

Класс объявлен как final и реализует чистую семантику перемещения: конструктор копирования [AP_SWS_Fw_82004] и оператор присваивания с копированием [AP_SWS_Fw_82005] удалены (=delete), что предотвращает дублирование. Вместо этого предоставляются конструктор перемещения [AP_SWS_Fw_82006] и оператор присваивания с перемещением [AP_SWS_Fw_82007], оба из которых определены как noexcept. Важным аспектом с точки зрения многопоточности является то, что как деструктор [AP_SWS_Fw_82003], так и операции перемещения не являются потокобезопасными. Поэтому вызывающее приложение должно гарантировать, что операции жизненного цикла и передача владения выполняются локально в потоке или синхронизированы.

Путь использования

Штатный процесс переключения наборов правил состоит из следующих шагов:

  1. Инициализация: объект интерфейса создается с указанием целевого InstanceSpecifier [AP_SWS_Fw_82002].
  2. Запрос переключения состояния: через метод SwitchFirewallState передается желаемое целевое состояние типа EnumT [AP_SWS_Fw_82008].
  3. Ожидание асинхронного подтверждения: метод возвращает ara::core::Future<void> [AP_SWS_Fw_82008]. Вызывающие стороны могут разрешать future с блокировкой или отслеживать его асинхронно до тех пор, пока смена базового набора правил не завершится.

Диаграмма последовательности: типичный процесс асинхронного переключения состояния. Источники: [AP_SWS_Fw_82002], [AP_SWS_Fw_82008].

Сценарии ошибок

Метод SwitchFirewallState объявлен с noexcept и не генерирует исключений C++ [AP_SWS_Fw_82008]. Ошибки при переключении инкапсулируются в возвращаемом ara::core::Future<void>. Для вызова специфицированы следующие коды ошибок [AP_SWS_Fw_82008]:

  • FwErrc::kServiceNotAvailable: соответствующая служба Firewall недоступна или не отвечает [AP_SWS_Fw_82008].
  • FwErrc::kInvalidStateDependentFirewall: запрошенное состояние недопустимо для указанного Firewall или не предусмотрено в конфигурации [AP_SWS_Fw_82008].

В качестве предусловия для переключения выступает то, что объект интерфейса корректно инстанцирован и установлено соединение со службой Firewall. В качестве постусловия в случае успеха активен новый набор правил фильтрации, а в случае ошибки предыдущее состояние остается неизменным.

Данное руководство по классу опирается исключительно на требования спецификации модуля fw платформы AUTOSAR Adaptive Platform R25-11.
