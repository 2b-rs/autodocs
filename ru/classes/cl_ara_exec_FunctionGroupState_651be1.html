Значение конфигурации для множества процессов

FunctionGroupState представляет сконфигурированное состояние Function Group. Такое состояние определяет, какие модельные процессы должны выполняться при его активации; для каждой Function Group активным является ровно одно состояние SWS EM §7.4.3 «Function Group State».

Использование в запросе на переход

State Management формирует целевые состояния из FunctionGroup и имён состояний и передаёт их в StateClient::SetState. Execution Management завершает более не нужные процессы, а затем запускает в необходимой последовательности процессы, предусмотренные для целевого состояния SWS EM §7.4.5 «State Transition».

Диаграмма состояний: Off является обязательным начальным состоянием; активное состояние конфигурируется специфично для проекта [SWS_EM_01110] SWS EM §7.4 «State Management». Интерпретация: представление абстрагируется от конкретных имён состояний Manifest.
