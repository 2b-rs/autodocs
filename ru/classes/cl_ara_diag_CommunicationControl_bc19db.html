Использование по назначению

CommunicationControl — интерфейс приложения для службы UDS 0x28. Приложение реализует CommCtrlRequest(); Diagnostic Server вызывает этот метод для обработки сервиса Communication-Control. [SWS_DM_00804] [SWS_DM_00808] [SWS_DM_00865]

Генерация и взаимодействие

Экземпляр создается для порта DiagnosticComControlInterface с InstanceSpecifier и ConcurrencyType. CommCtrlRequest() получает все параметры запроса UDS в ComCtrlRequestParamsType, а также MetaInfo и CancellationHandler и доставляет будущее. Offer и StopOffer контролируют пересылку DM; Предлагать отчеты DiagOfferErrc::kAlreadyOffered при двойном вызове. [SWS_DM_00806] [SWS_DM_00808] [SWS_DM_00809] [SWS_DM_00810]

CommCtrlRequest вызывается для службы UDS CommunicationControl (0x28) с любой подфункцией, где значение подфункции является частью переданной структуры ComCtrlRequestParamsType, которая инкапсулирует все параметры запроса UDS, включая необязательные элементы [SWS_DM_00808]. Также передаются metaInfo для запроса и cancellationHandler для запроса на отмену или регистрации уведомителя. Результат доставляется асинхронно через ara::core::Future<void>.

Обработка ошибок

В случае неисправности следует использовать подходящий DiagUdsNrcErrc согласно ISO 14229-1. Должна ли реализация быть потокобезопасной, зависит от ConcurrencyType, переданного в конструктор; вызов защищен от исключений.
