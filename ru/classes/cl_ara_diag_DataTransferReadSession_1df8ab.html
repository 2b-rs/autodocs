DataTransferReadSession инкапсулирует варианты считывающей передачи данных. При TransferData 0x36 в контексте RequestFileTransfer Diagnostic Server вызывает метод Read подходящего Handler, зарегистрированного через шаблонные конструкторы; при RequestTransferExit 0x37 он вызывает его метод Exit.
