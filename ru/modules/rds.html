Классификация & назначение

Raw Data Streams передает двоичные данные как соединение между клиентом и сервером через протоколы на основе IP. RawDataStreamClient и RawDataStreamServer созданы для моделируемых интерфейсов портов [SWS_RDS_10481] [SWS_RDS_11311].

Поток на основе IP

Client соединяется с Connect, сторона Server ожидает через WaitForConnection; затем обе стороны читают или записывают данные и завершают соединение через Shutdown [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].

Последовательность подключения и передачи. Источник: SWS Raw Data Stream §7.1.4, глава 8. Временное резюме является интерпретацией.

IEEE 1722

Для передачи данных на канальном уровне API описывает типизированные дейтаграммы IEEE 1722, а также классы производителя и потребителя [SWS_RDS_90225] [SWS_RDS_90311] [SWS_RDS_90322].
