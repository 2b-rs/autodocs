component Core Execution Environment

S-Core Core Execution Environment определяет фундаментальную абстракцию ОС, гарантии времени выполнения POSIX, технологии контейнеров, модели привилегий процессов и стандарты кодирования для всех служб Eclipse S-Core.

Execution Architecture & Key Requirements

Следующие требования были извлечены из release pin v0.6.0 и управляются в рамках жизненного цикла курации S-Core:

Идентификатор требованияКатегорияБезопасность / ЗащитаОписание
aou_req__platform__posix_operating_systemПлатформа / ОСБезопасность: QMТребует базовую операционную систему, соответствующую стандарту IEEE Std 1003.1 (POSIX) редакции 2004 года или более поздней.
stkh_req__hardware_support__container_techКонтейнер / Аппаратное обеспечениеБезопасность: ДАТребует механизмов изоляции ядра Linux, включая cgroups, политики безопасности (secpol) и пространства имен для изоляции рабочих нагрузок.
