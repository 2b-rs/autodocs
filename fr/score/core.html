Core Execution Environment

component Core Execution Environment

Le S-Core Core Execution Environment définit l’abstraction fondamentale de l’OS, les garanties d’exécution POSIX, les technologies de conteneurs, les modèles de privilèges des processus et les normes de codage pour tous les services Eclipse S-Core.
