Communication

component Framework de communication

Le framework de S-Core Communication fournit une communication inter-processus (IPC) en mémoire partagée zéro-copie, la découverte de services, la génération de code skeleton/proxy et des liaisons SOME/IP pour les applications automobiles distribuées à haut débit.
