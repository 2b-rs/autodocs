Limite de namespace

ara::idsm contient les API d'événement, de fournisseur et de récepteur ainsi que leurs données communes et leurs types d'erreurs. SWS IdsM §8.2 « common.h » définit les types courants ; Ils attribuent les autres en-têtes aux interfaces de port respectives.

Interprétation : L'espace de noms regroupe les objets d'accès aux événements, aux fournisseurs et aux destinataires, y compris les types de données et la représentation des erreurs ; Leur couplage spécifique aux prototypes portuaires est déterminé via le modèle et le ara::core::InstanceSpecifier.

Classes et structures

  • ContextDataProvider Fournit des données de contexte modifiables pour l'IdsM.
  • EventReporter Meldet Security Events an IdsM.
  • IdsmErrorDomain Domaine d'erreur pour ara::idsm.
  • IdsmException Type d'exception pour ara::idsm.
  • QualifiedEventsReceiver Reçoit les événements qualifiés.
