Entrée de contrôle d'une StateMachine configurée

StateMachineService est l'interface client de l'application de contrôle pour une StateMachine. RequestTransition transmet la transition souhaitée à State Management ; les ActionLists suivantes exécutent les séquences configurées. SWS StateManagement §7.7.2 « Controlling application » SWS StateManagement §7.7.6 « ActionLists » [SWS_SM_91107]

De la demande à l'état cible

Une demande n’est pas un démarrage immédiat d’un processus. State Management vérifie la transition et les conditions, implémente le StateMachine et fait implémenter les états du groupe de fonctions concernés via Execution Management. Les notifications sont disponibles séparément via StateMachineNotification. SWS StateManagement §7.7.5 « State changes » SWS StateManagement §7.6 « Interaction with EM »

Séquence d’un changement d’état demandé. Sources : SWS StateManagement §7.7.5 « State changes », SWS StateManagement §7.6 « Interaction with EM ». Interprétation partielle : la séquence connecte la StateMachine basée sur la configuration à l'exécution du processus EM.

Note d'intégration

Une machine a exactement un rôle de contrôleur pour les services StateMachine configurés. Les clients doivent donc demander uniquement les transitions destinées à leur rôle de contrôle et ne pas deviner le résultat d'une notification d'état. [SWS_SM_00619]
