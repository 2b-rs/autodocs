Freshness-Value-Manager pour les messages temporels sécurisés

FVM fournit des valeurs de fraîcheur pour la synchronisation temporelle sécurisée en option. Le gestionnaire doit être initialisé avant utilisation ; l'expéditeur et le destinataire utilisent des requêtes Tx/Rx distinctes dans le processus ICV. SWS Time Synchronization §7.2 « Normal Operation » [SWS_TS_14178] [SWS_TS_14183] [SWS_TS_14185]

Planifier les scénarios d'erreur

Si une Freshness Value n’est temporairement pas disponible, la spécification prévoit des tentatives répétées jusqu’à la limite configurée. Une fois celle-ci atteinte, la génération est interrompue ou un message reçu est rejeté. [SWS_TS_14184] [SWS_TS_14186]
