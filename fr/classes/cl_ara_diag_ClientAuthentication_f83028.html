classe ara::diag::ClientAuthentication

[SWS_DM_01132] Upstream: RS_Diag_04251

class ClientAuthentication final {...};

Interface for the application to inform the Diagnostic Server instance about the authentication states and the user roles that are currently authenticated.

But d'utilisation

ClientAuthentication permet à une application de signaler l'état d'authentification et les rôles d'utilisateur d'un client de diagnostic au serveur de diagnostic. Une instance est obtenue via ExternalAuthentication::Get() pour le MetaInfo ou l'adresse client transmise ; GetAll() fournit toutes les instances existantes. [SWS_DM_01132] [SWS_DM_01202] [SWS_DM_01203]

Interaction avec d'autres classes

Authenticate() positionne le client sur kAuthenticated, reprend les rôles transmis et fournit un ClientAuthenticationHandle. Ce handle peut ensuite définir ou étendre des Dynamic-Access-Lists. Une authentification réussie rétablit les Default Roles précédemment remplacés aux Default Roles configurés. [SWS_DM_01142] [SWS_DM_01206] [SWS_DM_01570]

GetState() lit l'état actuel. Dans l'état kDeAuthenticated, OverrideDefaultRoles() peut remplacer les rôles Default pendant une durée donnée et fournit également un handle. SetNotifier() enregistre une fonction pour les changements d'état, par exemple lors d'un timeout S3 ; un enregistrement ultérieur remplace celui qui existe. [SWS_DM_01143] [SWS_DM_01141] [SWS_DM_01209] [SWS_DM_01144] [SWS_DM_01360]

Cycle de vie et limites

La classe n'est pas copiable, mais est mobile et assignable par déplacement. Le destructeur est protégé contre les exceptions. Les opérations ne sont pas thread-safe et peuvent renvoyer DiagErrc::kServiceNotAvailable si la fonctionnalité DM essentielle n'est pas disponible. fonction Authenticate [SWS_DM_01142] Upstream: RS_Diag_04251

ara::core::Result< ClientAuthenticationHandle > Authenticate (ara::core::Vector< DiagnosticAuthRole > userRoles) noexcept;

This function is used by the application to report the authenticated state to the Diagnostic Server instance. The authentication could be either done using the Authentication interfaces of the Diagnostic Server instance, or through other means in the application.
