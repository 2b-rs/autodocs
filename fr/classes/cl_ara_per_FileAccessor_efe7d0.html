FileAccessor contains a common basis for ReadAccessor and WriteAccessor. It provides methods for checking and setting the current position in the file (GetPosition, Set Position, MovePosition, IsEof) and for checking the current size of the file (GetSize).

Interface de curseur commune

FileAccessor regroupe les opérations de position et de taille sur les fichiers ouverts. C'est la base commune des accesseurs en lecture, en écriture et en lecture/écriture ; cela signifie que la position du curseur décrit exactement l'accès à ce fichier ouvert.

Discipline de position

GetPosition, SetPosition et MovePosition servent à la navigation, tandis que GetSize fournit la taille actuelle du fichier. Les opérations accesseurs ne sont pas thread-safe : un handle ne devrait donc pas être utilisé simultanément par plusieurs threads sans synchronisation externe. SWS Persistency §7.4 « File Storage specific Features »

Avis d'utilisation

Ouvrez le fichier via FileStorage, effectuez les opérations de curseur en possession du même UniqueHandle puis relâchez-le. Un changement de position n’est pas un processus de persévérance ; l'écriture des données nécessite l'opération d'écriture appropriée et, si nécessaire, une synchronisation.

Un File Storage gère un ensemble de fichiers nommés ; l’Accessor détient exclusivement l’accès concret ouvert. Sources : SWS Persistency §7.4 « File Storage specific Features » [SWS_PER_00113].
