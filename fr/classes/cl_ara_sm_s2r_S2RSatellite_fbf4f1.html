Le constructeur explicite ara::sm::s2r::S2RSatellite::S2RSatellite crée un objet S2RSatellite basé sur un ara::core::InstanceSpecifier qui fait référence au PPortPrototype d'un SuspendToRamSatelliteInterface [SWS_SM_81003]. Le paramètre instance lie l'instance de port spécifique à l'objet créé.

Gestion des erreurs

  • InstanceSpecifierMappingIntegrityViolation : l'InstanceSpecifier ne peut pas être résolu dans le modèle ou fait référence à un élément de modèle autre qu'un PortPrototype.
  • PortInterfaceMappingViolation : le type de mappage ne correspond pas au type d'interface de port attendu.
  • ProcessMappingViolation : une InstanceRef correspondante existe, mais aucun processus modélisé correspondant.
  • InstanceSpecifierAlreadyInUseViolation : l'InstanceSpecifier est déjà utilisé dans le processus.
  • AraNotInitializedViolation : ara n’est pas initialisé au moment de l’appel.

Concurrence et restrictions

Le constructeur est thread-safe, exception-safe et noexcept.
