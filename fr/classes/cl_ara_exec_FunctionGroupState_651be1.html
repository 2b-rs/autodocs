Valeur de configuration de l'ensemble de processus

FunctionGroupState représente un état configuré d'un groupe de fonctions. Un tel état détermine quels processus de modèle doivent s'exécuter lorsqu'il est activé ; Exactement un état est actif par groupe de fonctions SWS EM §7.4.3 « Function Group State ».

Utilisation dans une Transition Request

State Management forme des états cibles à partir de FunctionGroup et des noms d'état et les transmet à StateClient::SetState. Execution Management termine les processus qui ne sont plus nécessaires, puis démarre les processus destinés à l'état cible dans l'ordre requis SWS EM §7.4.5 « State Transition ».

Diagramme d'état : Off est l'état initial obligatoire ; l'état actif est configuré spécifiquement pour le projet [SWS_EM_01110] SWS EM §7.4 « State Management ». Interprétation : la représentation résume les noms d’états concrets du Manifest.
