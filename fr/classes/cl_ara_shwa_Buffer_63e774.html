Rôle dans le modèle

Buffer possède la ressource mémoire nécessaire à l'hôte et à l'accélérateur. Le transfert direct de données n'est pas exprimé par des méthodes Buffer, mais par des objets Accessor.

Référence source

Pour la description de la mémoire, Buffer fonctionne avec SWS SHWA §7.5 — Memory Allocation Specifics. Selon SWS SHWA §7.3 — Data Access Specifics, l'accès est exprimé via Accessor.
