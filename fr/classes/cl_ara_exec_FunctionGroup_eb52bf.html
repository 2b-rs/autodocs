Limite d'un ensemble de processus constamment contrôlé

FunctionGroup est le représentant API d’un Function Group configuré. Il regroupe des processus de modèle qui sont démarrés et arrêtés de manière cohérente par états ; un processus de modèle ne doit pas être affecté à plusieurs Function Groups SWS EM §7.4.3 « Function Group State ».

MachineFG et groupes liés aux applications

Le Function Group MachineFG décrit les Machine States et sert principalement au cycle de vie de la machine. D’autres Function Groups contrôlent généralement des groupes d’applications User-Level. L’affectation concrète des processus provient des Execution Manifests SWS EM §7.4 « State Management ».

Interpretation : l'état cible actif est un exemple de ModeDeclaration. défini dans le manifeste.
