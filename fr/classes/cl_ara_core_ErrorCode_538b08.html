Encapsulation of an error code. An ErrorCode contains a raw error code value and an Error Domain. The raw error code value is specific to this ErrorDomain.

But d'utilisation

ErrorCode encapsule une valeur d’erreur brute spécifique au domaine, une référence au ErrorDomain associé et des données additionnelles facultatives propres au fabricant. Le type est un Literal Type. [SWS_CORE_00501] [SWS_CORE_10302] [SWS_CORE_10300]

Création et interaction

Il peut être créé à partir d'une énumération d'erreur ou à partir d'une valeur, d'un domaine d'erreur et de données supplémentaires. Domain(), Value(), SupportData() et Message() rendent accessibles ses composants ou le texte d'erreur ; ThrowAsException() détermine le type d'exception approprié dans le domaine. [SWS_CORE_00512] [SWS_CORE_00513] [SWS_CORE_00515] [SWS_CORE_00514] [SWS_CORE_00516] [SWS_CORE_00518] [SWS_CORE_00519]

Restrictions & traitement des erreurs

Les comparaisons tiennent uniquement compte de la valeur d’erreur et du domaine d’erreur, pas des données supplémentaires. ErrorCode et ses membres peuvent être utilisés indépendamment de ara::core::Initialize et Deinitialize. [SWS_CORE_10301] [SWS_CORE_15002]

Contexte d'erreur plutôt que valeurs d'erreur générales

Un ErrorCode associe une valeur d'erreur typée à son contexte ErrorDomain ; il peut facultativement contenir un message et une information supplémentaire propre au constructeur. Les interfaces ARA l'utilisent au sein de Result pour les erreurs récupérables. EXP InterfacesGuidelines §3.1.2 « Result » EXP ARAComAPI §4.7 « Error Handling »

Les codes d'erreur propres au constructeur requièrent leurs propres ErrorDomains ; les applications portables et neutres vis-à-vis de la pile doivent traiter de tels domaines comme un cas général par défaut. EXP InterfacesGuidelines §3.1.5 « Standardized vs Vendor-specific ErrorCodes »

Diagramme de collaboration : ErrorCode obtient le contexte et le message de son domaine ; la transformation d'exception est le chemin d'exception explicite. Sources : EXP InterfacesGuidelines §3.1.2 « Result » RS General §4.1.3 « The use of noexcept ».

Tapez la valeur d'erreur effacée

La SWS décrit ErrorCode comme une valeur d'erreur avec contexte de domaine : le code propre au domaine est effacé en un entier pour un transport uniforme ; des données de support supplémentaires peuvent être transmises. Les comparaisons prennent en compte la valeur et le domaine, mais non les données de support. SWS Core §7.2 « Error handling » SWS Core §7.2.5.1 « ErrorCode » [SWS_CORE_10301] [SWS_CORE_10302]
