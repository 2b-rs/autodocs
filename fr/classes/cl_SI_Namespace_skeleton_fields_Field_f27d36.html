But d'utilisation

Cette classe de champ squelette est générée pour chaque élément du ServiceInterface modélisé comme un champ. L'espace de noms, le nom et l'en-tête <SiNamespaceDerivedDirectoryPath>/<SiShortname>_skeleton.h sont dérivés du modèle ServiceInterface du manifeste ARXML. Il est utilisé via sa propre implémentation de service qui hérite de la classe Skeleton générée. [SWS_CM_00007]

Utilisation

Update(value) actualise la valeur interne du Field et déclenche la transmission des données actualisées aux abonnés ; une notification est envoyée si le notifier du Field est présent. La valeur de retour signale le succès ou un ComErrc approprié. [SWS_CM_00119]

Les gestionnaires asynchrones peuvent être enregistrés pour les requêtes getter ou setter entrantes. Le gestionnaire get n'existe qu'avec Field.hasGetter == TRUE, le gestionnaire set uniquement avec Field.hasSetter == TRUE ; les deux ont des surcharges pour un contexte d'exécution fourni. Un gestionnaire de défauts de transport peut être défini et supprimé. [SWS_CM_00114] [SWS_CM_11360] [SWS_CM_00116] [SWS_CM_11362] [SWS_CM_00096] [SWS_CM_00097] [SWS_CM_00098]

Sans Get-Handler, Communication Management peut répondre avec la valeur la plus récemment définie par Update() ; un gestionnaire uniquement pour cette valeur déjà connue serait inutilement coûteux.
