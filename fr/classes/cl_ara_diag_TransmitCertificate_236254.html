classe ara::diag::TransmitCertificate

[SWS_DM_01961] Upstream: RS_Diag_04251

class TransmitCertificate {...};

Class to implement the subfunction TransmitCertificate (29 04) of UDS service Authentication as interface to application. This class implements a so called generic interface, where the application has means to handle one ore more certificateEvaluationId transferred certificates.

But d'utilisation

ara::diag::TransmitCertificate mappe la sous-fonction UDS TransmitCertificate (0x29/0x04) comme interface d'application. L'application peut traiter un ou plusieurs certificats transférés à l'aide du certificateEvaluationId [SWS_DM_01961].

Création et destruction

L'instance est créée avec le InstanceSpecifier, un DiagnosticTransmitCertificateInterface et un ConcurrencyType [SWS_DM_01962]. Le type ne peut pas être copié ou déplacé ; le destructeur virtuel est noexcept [SWS_DM_01964] [SWS_DM_01963] [SWS_DM_01966] [SWS_DM_01965] [SWS_DM_01967].

Interaction avec d'autres classes

Offer() active le transfert des demandes via DM, StopOffer() le désactive [SWS_DM_01969] [SWS_DM_01970]. La méthode à dériver, Process(), reçoit le CEID 16 bits, les données du certificat, MetaInfo et un CancellationHandler. La sémantique du traitement des certificats réside dans l'application [SWS_DM_01968] [SWS_DM_01248].

Restrictions & traitement des erreurs

La sécurité des threads de Process() est déterminée par le ConcurrencyType [SWS_DM_01962] [SWS_DM_01968] choisi dans le constructeur. Le gestionnaire d'annulation permet d'interroger le statut d'annulation et d'enregistrer un notificateur. Pour les réponses négatives à UDS, utilisez une erreur appropriée de DiagUdsNrcErrc [SWS_DM_01968]. Une offre répétée peut DiagOfferErrc::kAlreadyOffered livrer [SWS_DM_01969].

fonction Process [SWS_DM_01968] Upstream: RS_Diag_04251

virtual ara::core::Future< void > Process (std::uint16_t certificate EvaluationId, ara::core::Span< ara::core::Byte const > certificate Data, const MetaInfo &metaInfo, CancellationHandler cancellation Handler) noexcept=0;

This method is used to process certificates send by a diagnostic tester, via the UDS subfunction TransmitCertificate inside the application. There is no specific semantics for the certificate and it is left to the application to process the received certificate and derive the needed actions.

La méthode virtuelle Process traite un certificat envoyé par le testeur de diagnostic via la sous-fonction UDS TransmitCertificate au sein de l'application ; il n'y a pas de sémantique spécifique pour le certificat ; c'est à l'application d'en dériver les actions nécessaires. Les paramètres sont le certificateEvaluationId 16 bits du message de demande UDS, le certificateData à vérifier, le metaInfo de la demande et un cancellationHandler, qui peut être utilisé pour interroger l'état d'abandon en utilisant IsCanceled ou enregistrer un notificateur en utilisant SetNotifier [SWS_DM_01968]. Le ara::core::Future<void> renvoyé fournit une valeur vide en cas de succès.
