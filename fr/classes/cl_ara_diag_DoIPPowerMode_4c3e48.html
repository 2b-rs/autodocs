But d'utilisation

L'interface fournit le mode d'alimentation DoIP actuel. L'application implémente GetDoIPPowerMode comme une fonction asynchrone purement virtuelle ; le Diagnostic Manager l'appelle lorsqu'il a besoin du Power Mode pour réagir ou répondre à un message DoIP.
