classe apext::diag::uds_transport::UdsMessage

[SWS_DM_00291] Upstream: RS_Diag_04147

class UdsMessage {...};

class represents an UDS message exchanged between DM generic core (UdsTransport ProtocolMgr) and a specific implementation of UdsTransportProtocolHandler on diagnostic request reception path or diagnostic response transmission path. UdsMessage provides the storage for UDS requests/responses.

Instances of UdsMessage (with optimized resource allocation) are only created by DM generic core, the UdsTransportProtocolHandler can read/write on it.

But d'utilisation

UdsMessage représente un message UDS entre le noyau DM générique ou UdsTransportProtocolMgr et une implémentation concrète de UdsTransportProtocolHandler. L'objet fournit un stockage pour les requêtes et les réponses UDS. [SWS_DM_00291]

Génération et propriété

Les instances avec une allocation optimisée des ressources sont créées exclusivement par le noyau DM ; Un gestionnaire de protocole peut les lire et les écrire, mais ne doit pas les créer lui-même. Le constructeur par défaut est donc protégé. Si l'indication est acceptée, un UdsMessagePtr a un objet valide avec au moins un octet de capacité ; initialement son tampon fourni par GetPayload() est vide. [SWS_DM_09012] [SWS_DM_00385] [SWS_DM_00392]

Interaction avec d'autres classes

L'accès non constant à la charge utile fournit un ByteSpan inscriptible ; L'accès constant fournit les données UDS du SID sans accès en écriture. Après une indication réussie, un gestionnaire de transport remplit la charge utile du SID jusqu'à la capacité ou jusqu'à la fin du message reçu. Les types d'adresse source, destination et de destination physique ou fonctionnelle sont disponibles via des getters ; AddMetaInfo() ajoute des méta-informations. restrictions

Le destructeur est virtuel, implémenté par défaut et exception-safe. Les getters d'adresse sont reentrant ; les deux accès Payload et AddMetaInfo() sont indiqués comme non thread-safe. [SWS_DM_09010] [SWS_DM_00297] [SWS_DM_00298] [SWS_DM_00299] [SWS_DM_00300] [SWS_DM_00301] [SWS_DM_00302]
