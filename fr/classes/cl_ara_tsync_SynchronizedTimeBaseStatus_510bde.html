Objet d'état en tant que valeur d'observation atomique

SynchronizedTimeBaseStatus est un instantané d'une ressource de base de temps. Il regroupe les indicateurs d'état, les informations de mise à jour et de saut, les valeurs temporelles et les données utilisateur afin qu'une application prenne sa décision de manière cohérente. SWS Time Synchronization §7.1 « General Overview » [SWS_TS_14218]

États après une synchronisation réussie ou un délai d'attente. Source : SWS Time Synchronization §7.2 « Normal Operation » ; [SWS_TS_00032]; [SWS_TS_00033].

Déduire la validité de l'état de synchronisation

GetCreationTime() ne délivre un temps de génération synchronisé que si la base de temps a été synchronisée au moins une fois ; sinon, l'option reste vide. GetLeapJump() décrit uniquement les sauts jusqu'à la création de cet instantané. {sws(TS,"SWS_TS_01055")} {sws(TS,"SWS_TS_01054")}

Classer les indicateurs de correction

Une correction de taux valide définit RATE_CORRECTED ; Si l'écart calculé dépasse la limite configurée, il est considéré comme invalide et RATE_EXCEEDED est défini. {sws(TS,"SWS_TS_14224")} {sws(TS,"SWS_TS_14228")}
