Rôle dans le modèle

Event représente une dépendance ou l’achèvement d’un travail soumis et fournit des opérations d’attente bloquantes ainsi que limitées dans le temps.

Référence source

SWS SHWA §7.6 associe des Events à la synchronisation de tâches. Des chemins d'attente limités dans le temps doivent éviter le blocage indéterminé du thread hôte.
