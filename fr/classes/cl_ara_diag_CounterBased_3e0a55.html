structure ara::diag::CounterBased

[SWS_DM_00538] Upstream: RS_Diag_04068

struct CounterBased {...};

Represents the parameters for counter-based debouncing.

CounterBased décrit les paramètres d'un anti-rebond basé sur un compteur : seuils, tailles de pas et valeurs de saut pour PreFailed et PrePassed ainsi que les indicateurs pour le saut vers l'échec et le saut vers la réussite. [SWS_DM_00538] [SWS_DM_00621] [SWS_DM_00622] [SWS_DM_00623] [SWS_DM_00624] [SWS_DM_00625] [SWS_DM_00626] [SWS_DM_00627] [SWS_DM_00628]

Le type sert de valeur par défaut lors de la configuration d'un MultipleMonitor avec anti-rebond basé sur un compteur. Une telle surcharge ConfigureMonitor ne peut être appelée qu'une seule fois par moniteur ; Ce n'est qu'alors que le moniteur peut être utilisé. [SWS_DM_01702]

Constantes/variables

  • failedJumpValue failed to jump value
  • failedStepsize Stepsize per pre-failed report.
  • failedThreshold Threshold until qualified failed.
  • passedJumpValue passed to jump value
  • passedStepsize Stepsize per pre-passed report.
  • passedThreshold Threshold until qualified passed.
  • useJumpToFailed is jump supported
  • useJumpToPassed is jump supported
