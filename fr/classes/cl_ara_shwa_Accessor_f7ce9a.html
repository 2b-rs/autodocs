Rôle dans le modèle

Accessor représente l’accès typé à un Buffer. Le type d’accès et la cible sont des paramètres de template ; pour les accès Read, le type de référence est const, et il est accessible en écriture pour les autres accès.

Référence source

SWS SHWA §7.3 décrit les accesseurs comme un pont entre le noyau et les données ; le AccessMode prend en charge la planification de l'accès aux données.
