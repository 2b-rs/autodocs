But d'utilisation

La classe <ExtendedDataRecordElementInterface> est une interface d'application pour un élément d'enregistrement de données étendu. L'application implémente la méthode purement virtuelle Read() ; le résultat est fourni sous forme de sortie de lecture dans un ara::core::Future. [SWS_DM_02146] [SWS_DM_02156]

Création et destruction

Le constructeur reçoit un InstanceSpecifier et ConcurrencyType. Via Offer(), le DM peut transférer des Requests ; via StopOffer(), ce transfert est arrêté. Une seconde offre de la même interface entraîne DiagOfferErrc::kAlreadyOffered. [SWS_DM_02158] [SWS_DM_02152] [SWS_DM_02153]

Interaction avec d'autres classes

Read() obtient MetaInfo et CancellationHandler. Le DM enregistre les données lues de manière non volatile ; Par conséquent, l'implémentation doit toujours fournir une valeur et remplir les données indisponibles avec un modèle de remplissage, par exemple 0xFF. [SWS_DM_02156]

Cycle de vie et limites

Les constructions Copier et Déplacer ainsi que les deux affectations sont supprimées ; le destructeur est virtuel et noexcept. Offer et StopOffer sont thread-safe, tandis que la sécurité des threads de Read() est définie par l'implémentation.
