Erreurs générales de communication

ComErrorDomain résume les erreurs récupérables des opérations standardisées ara::com. Un Result ou un Future asynchrone peut donc renvoyer un code ComErrc au lieu d'une valeur. EXP ARAComAPI §4.7 « Error Handling » définit le modèle Result/ErrorCode.

Utiliser le domaine

Name() décrit le domaine, Message() l’erreur individuelle et ThrowAsException() prend en charge le mappage des exceptions. En cas d’erreur, la logique métier doit d’abord réagir au domaine et au code énuméré ; les erreurs E2E et FVM sont délimitées délibérément par des domaines propres. SWS CM §7.5.22 « API Data Types » classe les données d’erreur en tant que types d’API.
