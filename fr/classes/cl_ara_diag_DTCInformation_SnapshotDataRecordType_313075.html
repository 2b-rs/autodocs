Encapsule le numéro unique et les identificateurs de données d'un enregistrement d'instantané pour les requêtes de diagnostic de DTC.

La structure ara::diag::DTCInformation::SnapshotDataRecordType sert de conteneur de données standardisé pour la collecte structurée d'enregistrements d'instantanés d'un DTC dans AUTOSAR Adaptive Platform [SWS_DM_00661]. Elle associe un numéro d'enregistrement 8 bits unique à un vecteur d'identificateurs de données de diagnostic associés pour les informations de freeze-frame [SWS_DM_02115]. En tant que type valeur sans état, l'instance est lue lors des requêtes de diagnostic et n'offre aucune synchronisation interne. Interprétation : en cas d'utilisation concurrente de la même instance, une synchronisation externe par le logiciel applicatif est nécessaire.

Contexte

La structure de données ara::diag::DTCInformation::SnapshotDataRecordType est définie dans le module de diagnostic d'AUTOSAR Adaptive Platform, dans la portée de la classe ara::diag::DTCInformation [SWS_DM_00661]. Sa responsabilité principale consiste à mettre à disposition de manière structurée les enregistrements d'instantanés (freeze frames) collectés d'un code d'erreur de diagnostic (DTC) AUTOSAR_AP_SWS_Diagnostics §8.48.4 « Struct: SnapshotDataRecordType ». La structure fait office de conteneur de données pour deux attributs centraux : un numéro d'enregistrement unique snapshotRecordNumber de type std::uint8_t [SWS_DM_02114] ainsi qu'une liste d'identificateurs de données associés snapshotDataIdentifiers, typée comme ara::core::Vector<SnapshotDataIdentifierType> [SWS_DM_02115].

Au sein de l'architecture de diagnostic, SnapshotDataRecordType interagit avec la classe englobante ara::diag::DTCInformation, qui est responsable de la lecture des informations d'erreur [SWS_DM_00661], ainsi qu'avec les objets de type SnapshotDataIdentifierType [SWS_DM_02115] qui y sont agrégés. Elle constitue ainsi le lien entre la collecte interne de données de la mémoire de diagnostic et la logique de diagnostic applicative AUTOSAR_AP_SWS_Diagnostics §8.48 « DTCInformation ».

Après interrogation des enregistrements de données d'instantané (snapshot) via l'instance de ara::diag::DTCInformation, l'application évalue les éléments SnapshotDataRecordType fournis AUTOSAR_AP_SWS_Diagnostics §8.48.4 « Struct: SnapshotDataRecordType ».

Typiquement, la variable snapshotRecordNumber est vérifiée en premier lieu [SWS_DM_02114]. Ce numéro de 8 bits identifie de manière univoque l'enregistrement de données d'instantané concret au sein de la mémoire de diagnostic AUTOSAR_AP_SWS_Diagnostics §8.48.4.1.2 « snapshotRecordNumber ». Ensuite, l'application itère sur le vecteur snapshotDataIdentifiers [SWS_DM_02115] afin de traiter les différents identifiants de données (DID) contenus dans l'instantané ainsi que leurs valeurs environnementales enregistrées.
