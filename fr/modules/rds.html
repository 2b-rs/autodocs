Classement et objectif

Les flux de données brutes transmettent des données binaires sous forme de connexion entre le client et le serveur via des protocoles IP. RawDataStreamClient et RawDataStreamServer sont créés pour les interfaces de port modélisées [SWS_RDS_10481] [SWS_RDS_11311].

Déroulement basé sur IP

Le client se connecte à Connect, le côté serveur attend via WaitForConnection ; puis les deux côtés lisent ou écrivent des données et terminent la connexion via Shutdown [SWS_RDS_10484] [SWS_RDS_11319] [SWS_RDS_10485].

Séquence de connexion et de transfert. Source : SWS Raw Data Stream §7.1.4, Chapitre 8. Le résumé temporel est une interprétation.

IEEE 1722

Pour le transfert de données au niveau de la couche liaison de données, l'API décrit les datagrammes IEEE 1722 typés ainsi que les classes de producteur et de consommateur [SWS_RDS_90225] [SWS_RDS_90311] [SWS_RDS_90322].
